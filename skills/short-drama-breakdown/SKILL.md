# 短剧拆解学习

## 快速开始

测量用 [breakdown_tool.py](scripts/breakdown_tool.py)，具体命令见[第 2 步](#2-测量)。安装、升级或排障时运行：

```bash
python3 {技能目录}/scripts/selftest.py
```

## 使用边界与职责分工

- 只读取当前对话提供或明确授权的素材。原片、转写稿、缩略图拼图与还原结果一律放在 `输入/对标/<REF-ID>/` 下，不进入正式交付或公开文件；创作者本地私有的 `项目开发/对标拆解.md` 允许写明真实参考片名、集数与平台出处以便查考（禁止摘抄受版权保护的逐字台词），而学习参考用途（`study` / `study_only`）的对标剧，其真实剧名、专有角色名、逐字台词与独有桥段严禁进入移交至创作者原创项目的文档（`creative-brief.md`、`story-engine.md`、`剧本.md`、`视觉设定.md` 与各类提示词等），也严禁进入公开分享或沉淀复用的材料（`BRK-02`）。
- 还原出来的全套文档只有在明确登记为自有（`owned`）或已获授权（`licensed`）并写明依据时，才能转出对标目录使用。
- 本技能只负责测量、拆解、同尺比对与对标还原；本项目的正式创作文档由对应负责技能修改，实测节奏数值须经 `$short-drama-develop` 拟定方案并由创作者拍板确认后，才写入项目节奏目标。本环节完整规则见 [阶段规范](references/stage-contract.md)。

## 工作流

### 1. 登记对标剧与本轮关注点

给每部对标剧分配固定编号 `REF-ID`，记清素材位置、授权用途（`study` / `owned` / `licensed`，后两种须注明授权依据）、是否允许上传给外部模型服务、投放平台与横竖屏画幅、制作形态。创作者未指定具体关注点时，默认直接拆解开篇立题、单集节奏与集尾衔接，不在开场或集间停工反问。

### 2. 测量

按 [测量与观看](references/measure-and-read.md) 抽取样本集。默认先用 `measure` 生成代表帧缩略图拼版并挂接字幕转写拆解全局，仅对创作者指定的重点集或高光段落按需跑 `shots` 逐镜切片（运行环境 `PATH` 需有 `ffmpeg` 与 `ffprobe`）：

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure <视频...> --out 输入/对标/<REF-ID>/measure
python3 {技能目录}/scripts/breakdown_tool.py transcript <某集.measure.json> <同集字幕.srt>
python3 {技能目录}/scripts/breakdown_tool.py profile <REF-ID>=输入/对标/<REF-ID>/measure --opening 3
```

### 3. 看片细读

对照代表帧拼图与带时间戳的转写稿，按 [拆解维度](references/breakdown-dimensions.md) 逐项梳理整剧集长编排、开场第一拍、信息交代方式、对白密度、镜头分切、集尾留钩与跨集衔接、画幅与制作形态；每一项都分开写明**实测与画面事实**、**作用分析**和**待确认盲区**。

### 3a. 整集或多集还原（按需）

需要反推重点集的完整剧本、设定与提示词来细读，或拿自家老片做续集与重制时，按 [整集与多集还原](references/reconstruct.md) 在 `输入/对标/<REF-ID>/还原/` 下单独建一套标准项目文档，并回查原片核对台词字错率、漏句、节奏偏差与看片模型看错的画面细节。

### 4. 提炼可借鉴手法

在多部对标剧里反复出现、且能说清帮观众解决了什么观看痛点的做法，整理为可借鉴手法（写明适用场景、实际观看效果、什么情况下会失灵、哪些原片独有桥段不能照抄）；只在单部剧里见到的做法标为单部个例。提炼出的手法交 `$short-drama-develop` 汇总，供后续写剧本参考。

### 5. 同尺对照与分工移交

用 `plan` 子命令测算本项目的分镜与剧本计划（输出到 `项目开发/对标拆解/plan/`），或用 `measure` 实测自家成片，按 [差距对照与分工移交](references/gap-and-learning-loop.md) 与对标剧放在同一口径下并排拉出差距表。直接区分建议补强的差距与疑似有意取舍的设计，需要补强的项连同实测依据转交对应的负责技能（新项目刚起步时，把实测数据交 `$short-drama-develop` 作为拟定节奏目标的参考依据）。

### 6. 沉淀拆解记录

将对标清单（本地私有的 `对标拆解.md` 可记真实参考片名、集数与平台出处，但不摘抄受版权保护的逐字台词；移交原创项目或公开脱敏时仅留 `REF-ID`、投放平台、制作形态与机制规律）、实测统计、可借鉴手法、同尺差距表及后续成片同口径复测结果整理写入 `项目开发/对标拆解.md`。
