# 整集与多集还原

## 还原文档放哪里、能不能拿去用

- 动手前对照 [阶段规范](stage-contract.md) 核实两件事：一是 `BRK-01` 外传权限，未确认允许上传外部服务时只在本机跑离线测量脚本；二是 `BRK-02` 与 `BRK-11` 授权边界，登记为 `study` 的对标剧还原结果只能留在本目录做分析对照，只有明确登记为自有（`owned`）或已获授权（`licensed`）并写明依据的作品，才能整套复制成独立新项目继续开发，严禁把单集文件直接混进外层主项目的剧集目录。
- 先建好 `输入/对标/<REF-ID>/还原/` 目录，再用 `$short-drama` 在该目录下单独初始化一个独立项目（项目编号与外层项目分开，标题写 `<REF-ID> 还原`），随后生成 `项目开发/`、`设定集/` 与各集核心文档。多集连拆时一口气按顺序推进，不在集与集之间停工等确认。

## 多模态看片工具使用要点

调用能同时读取视频画面与音轨的多模态模型看片时（仅限已获准上传外部服务，或使用本机离线模型）：

- **单集独立空目录**：每次看片单独建干净临时目录，只放当前一集 `ep.mp4`，避免前序集上下文串味。
- **先实测能不能听见声音**：正式跑前裁掉底部字幕区、剪十几秒带对白片段让模型盲听报秒数，确认接口真读音轨而非只抽帧看图。
- **锁定纯数据输出**：要求只根据当前视频输出单个 JSON 代码块；返回后只修格式括号引号，不涂改识别内容。

## 单集还原四步走

### 1. 脚本实测打底

全局先跑 `measure` 缩略图拼版、`audio` 与 `subtitles`；`shots` 逐镜切片只对本次需要逐镜还原的重点集或高光段落运行，不对非还原样本集全量切片：

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure <各集.mp4> --out 输入/对标/<REF-ID>/measure
python3 {技能目录}/scripts/breakdown_tool.py audio <重点集.mp4> --out 输入/对标/<REF-ID>/audio
python3 {技能目录}/scripts/breakdown_tool.py subtitle-sheet <两三集.mp4> --out 输入/对标/<REF-ID>/subtitles
python3 {技能目录}/scripts/breakdown_tool.py subtitles <重点集.mp4> --out 输入/对标/<REF-ID>/subtitles \
  --band <左,上,右,下> [--color <字色>] --audio 输入/对标/<REF-ID>/audio
python3 {技能目录}/scripts/breakdown_tool.py shots <重点集.mp4> <重点集.measure.json>
```

- **框准烧录字幕区域与字色**：先跑 `subtitle-sheet` 看不同高度描边文字的出现率 `shown` 与变化率 `changed`，挑 `changed` 显著大于 0 的高度带并上下留约 0.02 余量，避开常驻台标、名条或系统面板；彩色字幕用 `--color` 填六位色值（如 `FFD400`）。首集排版不同时单独设框。
- **扫描硬字幕并核查覆盖率**：`subtitles` 按单集运行，导出每条烧录字幕起止时间与裁图。若 `voiced_shown_share` 低于 0.3，排查字框偏移、字色不符或细描边被切碎（字面相同的相邻碎段人工合回一句）。
- **提取音轨响度与重点集逐镜切片**：`audio` 核实画面文字有无配音念出；`shots` 对重点集切出单镜视频与首中尾静帧，并标出镜内低阈值疑似切点（多帧连续变化 `frames > 1` 多为闪白或特效粒子，单帧突变才常是漏检硬切）。

### 2. 整集通看提取全局信息

先把整集视频交给看片模型提取全集底账：
- `lines`：每句人声（含系统音、VO、群杂）的起止时间、说话人、发声方式（画内 / OS / VO / 系统音 / 外放）、逐字台词、情绪，以及把握度档位（硬字幕实录 / 音字双印证 / 推断）；
- `characters`：人物临时编号、姓名及认人依据（名条 / 台词称呼 / 字幕 / 推断）、外观服装、随身道具、声线特点、首次出场秒数；
- `scenes`、`props`、`on_screen_text`、`sfx_music`、`beats`、`opening`、`ending`（集尾是否卡半句话或半截动作）及整体画风 `style`。

### 3. 逐镜细看还原分镜细节

在干净目录中把实测镜头编号与起止时间、镜内疑似切点及人物编号喂给模型，逐镜提取景别、机位角度、运镜、人物站位与视线、动作过程（起点 → 变化 → 终点）、神态反应、落镜台词、画面文字、光影转场，以及可直接改写为首尾帧提示词的画面细节。

### 4. 时间轴校准与人工复核

- **台词时间以硬字幕扫描为准**：扫出硬字幕的句子统一改用 `subtitles` 实测起止时间；无烧录字幕或纯系统面板文字保留模型时间并标为推断（`BRK-12`）。
- **逐句核对错字与镜头归属**：对照字幕裁图与音轨校对同音错字（《剧本.md》按真实发音写正确汉字，原错字记入对齐备注），每集至少抽查 5 处中间帧裁图，并按校准时间与镜头时段交集重算台词归属。
- **核实镜内切点与人物真名**：模型镜内切点与 `shots` 候选吻合且抽帧属实的记为镜内切，不吻合的单列交人工判断；缺乏名条、字幕或台词称呼实锤的角色一律用“黑衣保镖”等身份称呼，不编人名（`BRK-12`）。

## 多集连拆时的跨集衔接

1. **全剧统一人物编号**：给每个角色定唯一总编号，记清各集临时编号映射依据及真名首次实锤集数秒数。
2. **相邻集接缝台账**：逐对记录上集末句末帧、下集首句首帧、半句话硬切、开头重放与伤痕持物连戏状态；若多集定长硬切，先拼回连续段落理顺因果再按原分集点切回。
3. **原片穿帮如实记录**：原片道具变样、战力金额前后打架或交代断档如实记入台账，还原阶段不替原片圆谎。

## 整理成标准项目文档

按各环节文档格式写入 `还原/` 下的 `项目开发/`、`设定集/` 与每集核心文档：

- 《剧本.md》按时间逐字排好，标清 `[VO]`、`[OS]`、系统音与 `[画面文字]`；消音或星号敏感词在备注记原貌，正文与提示词换用贴切可播词。
- 每条实测镜头对应一条 `SHOT-...`，时长填实测秒数，镜内切点写进说明；承接上集半句话的开场镜标明承自跨集接缝台账。
- 首帧提示词沿用《视觉设定.md》外观特征；强风格化画面的《视频提示词.md》统一写成挂首帧参考图的图生视频。

### 用自有或已获授权的还原项目重新出片（`owned` / `licensed`）

- **修掉穿帮空间与木桩背景人**：不照搬缺门少窗或戏完僵立的路人，交 `$short-drama-assets` 与 `$short-drama-storyboard` 理顺空间与退场动线，并在 `审查/` 记下改动。
- **镜内切点拆回独立单镜**：出片时按分镜说明里的镜内切点拆成独立单镜，避免生成出单条不切镜画面；**一秒上下的眼、嘴、手或道具特写是情绪重音，单独成镜，不并入相邻镜**。
- **保戏剧节拍，别硬卡原片秒数**：验收看节拍、台词完整性与单镜戏份到位度，不为死卡原片秒数切碎人物反应或整段硬开倍速。
- **审成片带上还原分镜**：辅助区分本次模型走样与原片刻意拍法（如内心独白不张嘴、背身喊话）。

## 还原准确度核对

还原文档写完后对照原片抽检，结果写入还原项目的 `审查/` 目录：

| 核对项 | 抽检做法 | 统计口径说明 |
|---|---|---|
| 台词字错率 | 抽约 40 句台词，核对中点时刻硬字幕裁图与《剧本.md》 | 按配音修正的原字幕错字与敏感词替换单列为有意修正，不计入错字 |
| 漏句检查 | 抽查至少 2 集，比对 `subtitles` 字幕条数与《剧本.md》台词条数 | 无字幕群杂声与纯面板系统文字单列统计 |
| 节奏吻合度 | 按实测语速填好中英字词速配置，用 `plan` 对比 `measure` 的首句时间与有声占比 | 照搬实测切镜时间时镜数镜长天然一致，不作还原准确证据 |
| 画面看错与跨集接缝 | 抽约 15 镜核对首中尾静帧景别、人物与朝向（重点查首镜承接角色），并逐对核查跨集接缝与人名出处 | |
