# 去模板感：诊断、修订与误报

报告重复或模板化问题（`REV-05`）必须引用作品中**至少两个具体位置**，并说明重复机制造成的叙事或观众损失；单次使用类型惯例不构成缺陷。

## 1. 诊断四层与隐性模板

1. **因果重复**：每轮都靠外人送答案、巧合救场或对手无代价自曝推进。
2. **策略重复**：所有人物都用“质问—否认—拔高音量”交锋，无各自筹码。
3. **表达重复与过度工整**：动作总写“攥拳/眼神一冷”，每句对白后固定跟同长度微动作，或提示词以泛化画质词堆砌开头。
4. **镜头重复**：连续台词一律给特写加推镜（close-up + push），机位不随注意力焦点或关系变化。

不依赖字面重复的表达层问题同样需引用至少两处位置核对：

- **过度解释**：动作、证据或台词已完成表达后，又追补心理翻译、意义说明或道德总结。
- **过度收口**：每场都用总结句或金句封死余波，下一场只能重新起压。
- **信息密度均质**：场内各拍信息量平摊，接收、等待与关键转折缺乏疏密对比。
- **持续代价自动复位**：连载已确立的持续代价在阶段成功后自动消失，后续未继承也无因果解决。

## 2. 修订目标（改机制而非换同义词）

- **因果**：如第二轮只是把第一轮“拿证据打脸”重演一遍，向 `$short-drama-write` 要求让主角在“立刻公开”与“保护顶罪者”等不可兼得项间做选择并产生下轮压力，不在审查中代写台词。
- **对话**：将“你在骗我 / 我没骗你 / 你就是在骗我”改为每轮交换实质筹码（如亮出车库备用钥匙 vs 推出亲属违规签字袋、以沉默收起钥匙完成权衡）。
- **Prompt**：将“高级、电影感、精致、超清的神秘盒子”改为补齐缺失的识别锚点、尺寸比例、材质、状态与画面文字政策，而非单纯禁用形容词。
- **镜头**：连续三句大特写推镜时，按每拍注意力焦点区分观看目的（如第一拍双人同框看关系对峙，第二拍切桌面证物交接，第三拍切收回的手与留白）。

## 3. 误报反例（`taste_option`，不报缺陷）

- 仪式场景刻意重复同句/同构图，且第二次因持有人或处境改变而反转意义；
- 喜剧固定笑点（running gag）重复动作但每次产生不同代价；
- 审讯戏保持固定双人同框（locked two-shot）以制造压迫；
- 多集沿用已确认的固定片头格式，或人物因创伤反复做同一动作以表现停滞。

无法确认重复是否造成实质损失时，记为 `note` 并保留创作者选择。
