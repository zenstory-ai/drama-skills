# 场面调度手册：竖屏站位、轴线正反打与动态连贯

## 1. 竖屏多人纵深与播放界面避让（`SHT-15`）

- **前后纵深代替横排叠罗汉**：9:16 竖屏横向极窄，多人同框优先借前景门框桌沿、中景主人物与后景门口拉开前后三层纵深；摆清谁占主位、谁守门口、谁离证物最近，给在场第三人留出旁听变脸或插话的空间。
- **播放界面 UI 遮挡直接靠构图让开（`SHT-15`）**：当项目声明了成片字幕条、顶部角标或右侧互动栏遮挡范围时，直接在构图和首尾帧提示词里把关键纸面/屏幕字迹抬到画面中段干净区（或切特写拍大）、让人物头顶避开顶栏、让关键掏证物动作避开右侧按钮区，**无需在《分镜.md》里额外写一段 UI 避让文字说明**；未声明遮挡区时不凭空猜安全框。

## 2. 站位关系、轴线正反打与画外视线（`SHT-30`）

### 按需使用场头 `场景站位` 块

人物相对位置分两层转化为画面：先对照 `视觉设定.md` 地点条目的 `固定陈设` 定准谁在哪件家具哪一侧及身体接触尺度（如“贴着柜台外沿站立，台面齐腰”），再在首帧提示词里翻成本镜机位看过去的前中后景、人物胸口朝向、隔挡家具和画面左右（防止生图模型把隔桌对峙的两人画到桌子同侧）。

**三人以上群戏、多区域走位换位或涉及越轴调度的复杂场次**，建议在《分镜.md》该场开头写一段简短的 `## 场景站位 · <场景 ID> · <地点名>` 作为全组标尺；两人对坐、门口拦话等空间关系一目了然的简单场次，直接在各镜 `起点 / 终点` 写清即可，不必每拆两镜都硬补场头站位块：

```markdown
## 场景站位 · EP003-SC002 · 财务室
- 固定陈设：办公桌居中；铁皮保险柜贴背墙；百叶窗在侧墙，房门在对面侧墙
- 人物与轴线：赵经理坐桌后，林秘书立保险柜旁，沈一舟站桌前隔桌正对；主轴线为沈一舟 ↔ 赵经理，机位侧在百叶窗侧（沈一舟落画左，赵经理与林秘书落画右）
- 变化：SHOT-EP003-017 起沈一舟走到百叶窗前转身背对桌后两人
```

### 左右口径、视线衔接与正反打例外

- **左右表述口径统一**：单写“左/右/画左/画右”一律指观众眼里的**画面左右**；角色肢体带人物主语（“他的右手”“她的左肩”）；房间固定门窗家具用陈设相对关系描述。
- **画外视线与未知声源例外**：常规对白单人镜看向画外时，写明看谁及朝画面哪一侧看（如“看向画右桌后的赵经理”），确保反打视线严丝合缝；当角色听到**尚未揭晓身份的异响、暗处脚步或画外冷笑**时，只需写清视线朝向与声源方位（如“猛地转头盯向画左半掩门缝暗处”），不强填未知人名。
- **正反打互补与竖屏居中直视例外**：
  - 常规同侧正反打保持左右视线互补（甲在画左看画右，乙在画右看画左），站坐高低对应的俯仰角成对呼应，过肩镜写清前景虚焦挂谁的肩背。
  - **竖屏居中直视对切例外**：在高压审讯、当众逼问、宿命正面对决或强烈主观代入节点，允许双方在 9:16 竖屏里居中略偏、贴近镜头轴线直视前方对切，用迎面逼视强化压迫感。
  - **跨轴过渡**：确需越轴时，借人物走位穿轴、正面骑轴中性镜或全景重定方位自然过渡，并从该镜起沿用新机位侧。

## 3. 单房对峙、亮证物与群戏站队（`SHT-13`）

- **单房文戏与亮证物**：人物动静紧扣心理博弈与证物控制（手悬在纸袋上未碰、把钥匙推过桌面、松开门把手），不塞倒水望窗等无戏闲动作。亮证物排清谁攥在手里、揭底前露几分、谁先看清、逼出什么变脸；需读清字句时对齐道具字迹规则并留够阅读停留，靠裂口血丝认物时不在提示词里多手编造字样。
- **群戏站队层次（`SHT-13`）**：多人同场先按主角交锋主轴线、护短联手方、把守出入口方与旁观人群分区，把剧本里的站队关系落成远近站位、胸口朝向与眼神落点；只有上前拦路、开口作证或闪身让道时才单给动作，不给背景群演挨个切雷同惊呼特写。

## 4. 动态对象连贯与场景视角对齐（`SHT-09` / `SHT-14`）

- **跨镜运动物件连贯（`SHT-14`）**：球、车辆、兵器或争抢中的信物跨镜传递时，持有人、飞行方向、回合/倒计时进度与落点前后一致（标明时间跳切除外）；关键争夺拍清脱手与易主的空间过程，计分牌或秒表生图写不准时改走后期叠字或画外报分音效。
- **场景视角匹配与前景避挡（`SHT-09`）**：本镜绑定的地点与场景分视角，其观看朝向、同框 `固定陈设` 和主光方向必须与本镜机位一致（门外往屋里拍绝不挂屋里朝门外看的空镜图）；挂场景参考图前留心前景吧台或大桌，拍开阔站立镜头时选前景无遮挡的视角图，防止生图把前景大桌硬塞进人物胸前。
