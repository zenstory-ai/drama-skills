## 边界与瞬间准则

- `SHT-05` — 准确呈现镜头已接受的单一边界（起点或终点），并绑定该边界可见的人物/造型、地点/视角和道具/状态。
- `SHT-06` — 只描述一个可以定格的瞬间。有先后顺序的动作、表情变化过程、镜头运动和正在变化的天气属于运动提示词，不进冻结关键帧。

## 定位与职责

冻结关键帧描述的是单一瞬间能够同时成立的一格画面，用来锚定已接受镜头的边界。关键帧不是压缩版的视频提示词。

## 写作顺序

1. **画面目的**：这一帧最先要让观众注意到什么。
2. **视觉主体**：准确的人物、造型、地点和道具版本。
3. **取景与构图**：景别、机位角度、焦段意图、适配当前画幅的构图。
4. **空间地理**：地点与观察视角、固定空间锚点、前景/中景/后景分区。
5. **边界投影**：准确的起始位置、身体朝向、姿态、视线、双手位置和手持道具。在场的每个人都要写身体朝向——它决定人物占画面哪一侧，以及下一镜反打从哪一侧切；只写视线方向替代不了身体朝向。头部朝向与身体不同时再单独标出。
6. **表演定格**：一个可见的表情或身体紧绷状态，而不是一段变化过程。选当前景别真正读得出的通道——眼神、呼吸屏住、肩背绷紧、手部动作或停在半途的抉择。远景读不出眼皮微颤，特写装不下全身后退。只写情绪词（如“愤怒”）等于把翻译工作甩给下游，而关键帧就是第一帧，翻错就从第一帧错起。
7. **光线与氛围**：继承已接受的光向、时段与天气，只补本帧构图需要的那一点明暗细节。
8. **画面文字政策**：可见表面按已确认政策处理（精确可读、符号化、留白或后期叠加）。
9. **排除项**：本帧容易漂移或与边界冲突的内容。

身份和起止边界由上游记录定义；关键帧自己负责焦点层次、构图、机位焦段、本帧站位投影与排除项。

### 写完之后过一遍可渲染检查

检查接手的人能否读出当前帧必须保持的可见事实。按构图和镜头职责核对下表，
只补本帧实际需要的内容：

| 检查内容 | 信息缺失时的风险 |
|---|---|
| 每个人在哪、彼此距离多少（"站在他正前方约两步"） | 人物间距逐镜漂移，观众读成换了场地 |
| 构图需要纵深时，前景、中景、背景分别承载什么 | 层次不明，主体与背景混在一起 |
| 视线该落在哪（本镜的视觉重点） | 画面平均用力，观众不知道该看谁 |
| 构图方式与景别 | 同一场每镜构图随机，剪不到一起 |
| 机位在轴线哪一侧、俯仰角度、焦段意图 | 越轴；正反打方向对不上 |
| 光从哪来、什么质感 | 同场光位逐镜跳变 |
| 每个在场者的姿态、朝向、手部、持物 | 下一镜接不住，道具凭空易手 |
| 与上一镜连续的关键状态在本帧具体是什么 | 只写“同上”，当前正文无法独立说明状态 |

连续性核对时可以与上一镜比较；可复制正文仍须写出当前帧的位置、持物和其他必要状态，
不能用“与上一镜相同”代替执行端本次需要的事实。

**`craft_default`：关键帧图的空间只从本侧地点图来。** 同一场戏的关键帧，空间只挂本镜机位那一侧的
地点视角图（用途：地理），人物挂角色板（用途：身份）。不拿上一镜的关键帧当空间参考，也不用局部编辑把
背景换掉：上一镜的关键帧带不过去人和锚点的距离，局部改背景又会把房间重画一遍。一次实测里，这两种做法
都让固定陈设逐镜移位；改成只挂本侧地点图和角色板后，同一侧机位的镜头才对得上。定调图照旧只取色调、
光线与质感；近景挂地点图被拉宽时照旧不挂，背景写进正文并写浅景深。出图后交 `$short-drama-review`
对照「场景站位」核对，再送去生成视频。

**`craft_default`：一件事只说一次，不抄整本设定集。** 绑定已接受的资产版本后，只重述本帧防歧义所需的事实：识别锚点、当前造型、关键空间锚点、手持道具、光向与文字状态。合并能自然衔接的句子，删除重复事实和“电影感、8K、大师级”之类替代不了身份、地理与构图的套话。不设通用字数门槛。

以下合成片段示意构图与静态事实的组织方式（前情：暴雨刚停的公交候车亭里，科室主任陈默刚劝实习医生林舒替他签字背下虚报耗材的处分，林舒坐在长凳上听完后沉默未应）：

```text
竖屏 9:16 中近景。机位在轴线左侧、高约一米二，平视略低约五度，中焦 50mm。前景是长凳
扶手与半张湿报纸（占下缘约六分之一）；中景是两人对峙；背景是虚焦的候车牌。三分构图，
林舒落在右三分线上。林舒：坐长凳右端，双手交叠压膝，身体朝向正前，视线落在陈默鞋尖，
无持物，长凳右侧扶手边斜靠着一把收起的黑色长柄伞。陈默：站她正前方约两步、略偏画面左，
双手插袋，身体朝向她，头略偏向出口。光自画面右上顶棚缝隙斜下为主光（硬），左侧留暗，
无补光。视觉重点在林舒压膝的双手。排除：无动作过程，无雨丝拖影。
```

成稿画面里每一个需要认出身份、造型或地理的可见条目，都要写进本镜必填的「视觉依据」字段，并解析到《视觉设定.md》的真实标题；《图片提示词.md》里的 `IMG-...` 条目是另一条轴线，不能代替「视觉依据」，《视觉设定.md》本身也不定义 `IMG-...` ID。「视觉依据」要按写完后的成稿画面回填，不能只按最初的镜头意图填写——最容易漏掉的，往往是写关键帧正文时顺手带进构图的人物或道具。冻结关键帧可以决定某个文字承载面在当前构图下是否看得清，但不能用无法追溯的散文描述替换已确认的精确文字或文字政策；政策未定时如实标明未决，不私自编造候选状态。

## 尾帧：什么时候可以有，以及它换来什么代价（`SHT-17`）

默认每镜一张首帧，冻结「起点」。交付工作流需要首尾帧时，再补一张呈现
「终点」的尾帧；两帧之间的运动仍按分镜边界和运动提示词实现。

**`structural_invariant`**：《分镜.md》的首帧与收尾关键帧分别指向同一镜头已接受的起点与终点。
**尾帧是「终点」的画面呈现，
不是新的终点事实**——它与首帧对「起点」的关系完全一样：可以决定这一帧怎么构图、
用什么景别镜头、光怎么落，不能决定人在哪、手里有什么、看着谁。尾帧与镜头终点不一致时，
错的是尾帧。

每镜的关键帧数量**不是固定的**。默认一张首帧；只有当交付工作流真的要消费尾帧时才加一张，
不为凑齐而画。补尾帧不改变 `SHT-10`：首帧仍然只能写「起点」事实，尾帧只能写「终点」事实，
两张各自守自己的边界，不互相借用。

**代价要说清楚：交出一对首尾帧，等于把两帧之间的运动交给了执行端插值**。 而运动路径本来
是运动规格拥有的东西。所以选了首尾帧接续的镜头，其运动规格不是"照旧再写一遍"，而是被
两端夹住了：它仍然要写清中间必须发生什么（动作顺序、对白落点、摄影机行为），但要意识到
执行端会优先满足两端的画面一致性。因此——

- 中间必须被看到的动作**不要只靠插值兑现**。如果一个动作是本镜存在的理由，两端之间没有
  任何东西保证它会发生，就该拆镜，或者让该动作落在其中一端。
- 两端差异越大，插值越自由，中间越不可控。首尾帧接续适合"状态改变清楚、路径无所谓"的
  镜头（转身、递交完成、坐下），不适合"路径本身是戏"的镜头。
- 终点报告仍然对照镜头「终点」，不对照尾帧。尾帧只是它的画面呈现，不能自证到达。

## 只写起点的草拟纪律

**`SHT-10 · reviewed_invariant`**：关键帧的可复制正文只能包含该帧所声明边界（起点或终点）里的事实。首帧写进任何由运动或终点首次产生的事实是漂移；尾帧写进在它之前就已经消耗掉的事实同样是漂移。两帧各守各的边界，不互相借用。

关键帧默认呈现镜头起点，不能直接选取“本镜最有戏的时刻”。为避免提前写入终点事实：

1. 先明确本帧冻结 `SHOT-...` 的起点，草拟正文时暂不读终点与运动描述；
2. 只填起点已成立的位置、姿态、目光、双手、持物和可见状态；
3. 再对照终点，找出动作后才产生的事实，确保它们未进入起始关键帧正文；
4. 写完 Markdown 后从自然语言反向提取手位、持物、目光和可见状态，与镜头起点再比一次；
   不能只看条目说明而忽略真正交付的正文。

反例（祠堂议事镜头）：分镜「起点」是“家主右手空置垂在身侧、看着跪地的族人”，「终点」是“家主右手握住堂前铜铃绳准备摇铃传家法、看向祠堂大门”。首帧若直接写成“手已握住铃绳”，就会提前透支终点才出现的事实，属于边界漂移。

## 静态画面检验

写完问一句：一名剧照摄影师能不能在同一次快门里拍下正文描述的所有事实？

下列内容一律移交运动提示词：

- 带先后顺序的动词（先、再、随后、最终）；
- 表情从甲状态变到乙状态；
- 摄影机随时间推、摇、移、跟；
- 进门、离场、转身、伸手取物等连续过程；
- 台词发声弧线或声音递进过程；
- 光线或天气在镜头内发生变化。

一个定格姿态可以蓄着张力，但不能要求画面跨越好几个瞬间。

## 常见失误

- 同一帧里混入互斥的造型状态；
- 静帧正文写出“转身、跑开、再回头看”之类连续动作；
- 起手姿势或持物与分镜「起点」不一致；
- 背景改变了地点身份或空间朝向；
- 光向无故重置；
- 要求精确可读的证物文字与全局禁字指令同时出现；
- 提示词只罗列人物和物件，没写彼此的空间位置关系；
- 构图平均用力，没有视觉主次；
- 结构化字段与起点一致，但可复制正文写进了运动过程或终点才出现的事实。
