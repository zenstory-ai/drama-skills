# 测量与观看

先用脚本拿到每集都能复算的数字，再看拼图、读转写。数字只说明去哪里看。某个做法适不适合
本项目，看完才判断，由创作者决定。

## 抽样

一部连载剧动辄上百集，不必全测。按要回答的问题取样：

- **开头几集全拿**（建议第 1–12 集）：首集结构、前几集加长、付费点前的节奏都在这里；
- **之后隔段抽**（例如每 20 集一集）：看中段集长是否定长、节奏有没有变；
- **最后 2–3 集**：看收尾是否换了做法。

相邻两集要成对取，才能看下一集怎样接上一集。比较多部作品时，每部的抽样规则要一样。

先查对标里有没有同一个故事的两版制作（换了片名、画风或演员重拍）。它们的节奏和桥段高度重合，
算作一个故事；报告里写「几部、几个故事」，机制候选按故事数计，不按部数计。

## 转写从哪里来

脚本不做语音识别。按可得程度依次用：

1. 平台或创作者提供的字幕文件（SRT、WebVTT）；
2. 创作者本机已有的语音识别工具导出的带时间分段（JSON 每段带 `start`、`end`、`text`）；
3. 都没有时只测画面，有声占比、语速、首句时刻这些数字留空，不估。

烧录字幕可以帮助核对识别错字，但不要逐帧抄字幕当转写。

## 运行测量

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure 输入/对标/REF-A/E001.mp4 ... --out 输入/对标/REF-A/measure
python3 {技能目录}/scripts/breakdown_tool.py transcript 输入/对标/REF-A/measure/E001.measure.json 输入/对标/REF-A/E001.srt
python3 {技能目录}/scripts/breakdown_tool.py profile REF-A=输入/对标/REF-A/measure REF-B=输入/对标/REF-B/measure --opening 3
```

- `measure` 每集写一份 `*.measure.json`，并出一张代表帧拼图（每个检测到的镜头取中点一帧）；
  集数很多时加 `--no-sheet`，只给要细看的集出拼图。
- 文件名里要有集号（`E001`、`EP01`、`第1集` 都能识别），`profile` 靠它排序和配对相邻集。
- `profile` 把开头几集（`--opening`，默认 3）和之后的集分开统计，再报两件系列层面的事：
  之后各集是否近似定长，以及相邻两集里下一集开头重放上一集结尾的次数。
- 本项目自己的计划用 `plan` 读 `剧集/<EP>/分镜.md` 的镜头时长和 `剧本.md` 的台词，写成同样的
  `*.measure.json`，输出放 `项目开发/对标拆解/plan/`。项目声明了 `format.pacing` 时，`plan` 按语速和每段动作
  秒数把台词排到时间线上（有分镜就把无声部分拉伸到分镜总长，语速不变；没有分镜就用剧本估算的总长），
  于是有声占比、首句、末句后留白也能算；台词比分镜总长还长时只报冲突、不估算。计划的开头和结尾按含动作
  与 VO/OS 的段落比对，重放的动作也算重放。只出场一次、没有表演注、名字又长的说话人用 `--speaker` 点名，
  否则那一段按动作计。
  这些是估算，和成片的实测并排时标明来源。自家成片用 `measure` 测，和对标完全同一口径。
- 对标视频不必放进项目目录；无论在哪里，测量结果都写进本项目的 `输入/对标/<REF-ID>/measure`。

## 数字的盲区

| 数字 | 盲区 | 怎么补 |
|---|---|---|
| 转写时间 | 识别模型偶尔把配乐或静默识别成长段文字，时间超出片长 | `transcript` 挂接时会提示，`profile` 列出这些集并只计片长以内的部分；抽查原片 |
| 切点与镜长 | 帧差阈值漏掉慢溶，把闪白、甩镜、粒子特效算成切 | 动作戏、特效集看拼图核对；必要时调 `--scene-threshold` 重测，报告写明阈值 |
| 有声占比、语速 | 转写不分对白、旁白和系统提示音；配乐里的人声也可能被识别 | 读转写时标出哪些段是旁白或系统音，再算 VO 份额 |
| 首句时刻 | 开场若是纯音效或纯画面钩子，首句晚不代表钩子晚 | 看第一帧拼图，单独记第一拍是什么 |
| 计划的首句时刻 | `plan` 按剧本先后排，开场动作段排在首句之前；分镜把 VO 压在开场画面上时，计划值偏晚 | 有分镜时以首句所在镜的起点为准，报告写明用的是哪个 |
| 末句后时长 | 末句后可能是画面上的反转，也可能只是片尾 | 看最后一帧拼图 |
| 重放上一集结尾 | 只比对文字；纯画面重放、换说法的复述测不出 | 抽两三对相邻集看拼图确认 |
| 近景占比 | 脚本不分景别 | 看拼图人工数；只数到能确认的，未确认的写未知 |

## 看拼图

拼图按镜头顺序排列，一格一镜。每部至少细看第 1 集和中段一集，记：

- **画幅与形态**：横屏还是竖屏，写实、三维国漫、二维还是混合；
- **景别分布**：人脸占画面高度过半的特写、胸口以上的近景、带环境的中远景、无人的插入镜各有多少；
- **固定画面元素**：烧录字幕的位置、人物首次出场的名条（名字加身份）、系统或数据面板、角落提示语；
- **调度惯例**：对峙怎么站位（一人对一群、隔桌、居高临下），正反打用不用过肩，插入镜拍什么物件；
- **动作与特效段**：镜长是否明显变短，速度线、残影、能量特效怎样替代真实动作。

## 读转写

带时间读，不要只读文字。逐集记：

- 第一句在第几秒，是谁、什么性质（指控、命令、自述、求助、系统提示）；
- 主角第一次被压、第一次反击、金手指或底牌第一次出现各在第几秒；
- 旁白在哪几段出现，承担什么：压缩前情、自报身份、解释规则，还是内心反应；
- 集尾最后一句是什么性质：问句、威胁、揭示、半句被打断，还是一句平常话；
- 下一集第一句是接着说、换场，还是复述。

转写和拼图是对标作品的表达，只放在 `输入/对标/` 里，不抄进本项目的剧本、提示词或报告正文。
