# 静帧段

静态漫剧不生成视频：每一镜是已接受的冻结关键帧，声音是逐句生成的配音。它和视频成片用同一份
剪辑单、同一套字幕、画面文字、音效、响度与验收，区别只在来源和声音从哪里来。

## 什么时候用

静帧段只在创作者选了它的时候出现，三种情况：

- 《视觉设定.md》的「制作形态」写明是静态漫剧（关键帧切换加配音）；
- 创作者要求在生成视频之前，先用关键帧加配音剪一版看节奏（动态分镜）；
- 某一镜的视频不可用，创作者同意这一镜先用关键帧顶上。一镜一问，不扩到别的镜。

不因为省钱、生成失败或排队慢就自己把视频镜头换成静帧；视频项目里出现静帧段，必须能指回上面某一条。

## 来源

- 关键帧对应《分镜.md》的某一镜时写 `SHOT-...`。这是默认写法：镜序、职责和场景都从分镜来，
  同场景的相邻静帧也参与自动接镜。
- 画面来自《图片提示词.md》的某一条（场景板、道具特写）而不是某一镜时写 `IMG-...`。
  它追不到场景，不参与自动接镜，也不承担分镜的覆盖。

关键帧的画幅不必等于交付画幅：render 等比铺满后居中裁切，不拉伸。构图重心不在中间的图，
先在外部裁好再引用。

## 每一镜的下落

有 `SHOT-...` 静帧时，《分镜.md》的每一镜都要么进片，要么写进「未采用镜头」并给出理由；
有视频段时，《视频提示词.md》的每一条同样如此。视频与静帧混剪时，一镜只需一个下落：

- 用静帧代替了这一镜的视频，`MOTION-...` 不必另写未采用；
- 用了视频的镜头，对应的 `SHOT-...` 不必另写；
- 未采用写 `MOTION-...` 时，它对应的 `SHOT-...` 一并算有下落；只写 `SHOT-...` 时，
  这条视频仍要说明为什么没用。

对应关系读《视频提示词.md》每条的 `分镜` 行。只有 `IMG-...` 静帧、没有 `SHOT-...` 的剪辑单不查分镜覆盖。

## 运镜

静帧上的运镜是一个在画面上移动的取景框，整段缓入缓出。它替代不了表演，只负责把注意力推到
该看的地方：

- `推近` 用在一句话落到关键信息、人物反应要被看清时；`拉远` 用在交代处境或收尾。
- 平移的方向是镜头的方向：`左移` 时取景框向左，画面内容向右滑。平移时画面先按同样幅度放大，
  移动的距离是画宽（或画高）的这个百分比，图的边缘不会进画。
- 幅度通常 5%–12%。两秒以内的镜头用大幅度会像被拽走；连续几镜同一方向同一幅度会显得机械。
- 读图就够的镜头（屏幕、字条、特写）写 `固定`。

## 配音

先有配音，再定时长：每句生成好之后量出有声的起止，按「开口前留白 + 句长 + 句后反应」给这一镜定 `时长`，
再写 `配音` 的起点和同时间的 `字幕`。重出某一句之后，这一镜的时间要按新文件重排。

一句话不必只配一张图。说话人开口、话落在听者的反应上，是静帧成片摆脱「一句一张图」的主要办法：

- **L-cut**：配音写在说话人那一段，照常往下说，切到听者那一段时声音不断。字幕也写在说话人那一段，
  止写到这句说完，可以超过本段时长。
- **J-cut**：下一段的人先开口、画面后到。配音写在下一段，`起` 写负数，最早到上一段开头；
  字幕写在上一段、从开口的时刻开始。字幕的起始终在它所在的那一段里。

check 按整条片核对：配音和字幕都不得越过成片结尾（配音允许 0.05 秒），任意两句配音、任意两条字幕都不得
同时出现，跨过来的也算。

生成的配音两头常带一小段静音，句尾还可能多一声笑或气口。配音的核对只算文件里有声的部分（比最响处低
40 dB 以内），所以两句可以贴着排；要跳过开头的静音或只要中间一段时，用 `（起点：<秒>）`。
句尾多出来的笑想留就让它跨到下一镜，不想留就把这句写成 `音效`，用 `起-止` 截取。

同一张关键帧可以给几段用，正反打来回切时不必重出图。

字幕照剧本原文写，不照配音文件名或生成时的文本写；两者不一致时以剧本为准，回生产阶段重出这一句。

视频段也可以写 `配音`，用于后期补一句旁白或替换听不清的台词。它叠在原声之上：原声里如果已经有
这句台词，要先在外部把原声处理掉，再用处理后的文件作来源。
