# 摘录链条：一集短剧的四阶段交接示例

本目录保留四份历史 Markdown 节选，展示同一场都市反转戏如何从剧本一路交接到资产、分镜与视频提示词。剧中情节、人物和地名均为虚构。日常创作的完整五文档样例见 [creator-first/](../creator-first/)；结构化校验夹具见 [golden-project/](../golden-project/)。

| 文件 | 环节 | 对应技能 |
|---|---|---|
| [EP001-剧本.md](EP001-剧本.md) | 分集剧本（片场方言格式） | `short-drama-write` |
| [EP001-资产设定.md](EP001-资产设定.md) | 角色三视图 / 场景方位图 / 物品白底图 | `short-drama-assets` + `short-drama-image-prompts` |
| [EP001-分镜.md](EP001-分镜.md) | 原文落实 + 镜头职责 + 观众可见信息 | `short-drama-storyboard` |
| [EP001-视频提示词.md](EP001-视频提示词.md) | 主镜头与局部补拍的视频提示词约定 | `short-drama-video-prompts` |

按上表顺序阅读即可看清跨阶段交接；资产图片提示词与分镜可在资产确认后并行推进。

## 关于剧本格式

[EP001-剧本.md](EP001-剧本.md) 使用国内短剧常见的**片场方言格式**（`【场景】`、`△`、`▲`、`【人物】`），展示创作者常见来稿的写法。
规范化入口和标准语法见 [screenplay-format.md](../../skills/short-drama-write/references/screenplay-format.md)。
当前 `short-drama-write` 将确认后的剧本写入 `剧本.md`。
