# 短剧视频与时间线音乐提示词

把已确认镜头和起始帧写成有边界、可生成、可直接复制的 `剧集/<EP>/视频提示词.md`。每镜使用 `MOTION-...` 标题并引用对应 `SHOT-...`。

## Quick Start

```text
用 $short-drama-video-prompts 把 EP001 分镜逐镜写成可直接复制的视频提示词
```

## 入口与边界

运动提示词拥有从分镜已确认起点到终点的变化（表演动作、道具状态、运镜、节奏和声音提示），不改写分镜边界。先按分镜的「输入参考图」区分路径：

- **可读真实 `REF-...` 或创作者自备 `PLAN-...` 槽位**：走**图生视频**，原样抄入分镜的槽位、顺序、路径/定位符、中文名称、用途、控制与不得控制范围（路径回答送哪张，`用途` 回答负责什么，`顺序` 回答正文标签编号）。`PLAN-...` 表示创作者在生成界面自行按序挂图，不能转 `$short-drama-produce` 投产；要投产需先将真实文件放入项目改写为 `REF-...`。
- **「输入参考图：无（创作者已明确选择文生视频）」**：走**文生视频**，必须写非空「静态视觉锚点」并将该字段内容**逐字原样粘贴**进 `### 可复制提示词`（`creator_markdown_check.py` 做子串匹配，不得改字或调整语序），交代人物、造型、地点、构图和光线中本镜必要的静态事实（不得只写 `preserve/keep/保持已有外观`）。
- **「输入参考图：无（待补参考图：……）」、槽位后带「；待补参考图：……」或普通「无」**：表示**未准备好**，不是文生视频授权。先自动查找可用真实图片并请分镜 owner 刷新绑定；仍有缺失按工作流第 3 步处理。

创作者可读说明跟随项目语言。开始前读取目标模型档案（版本、执行模式、提示词方言、原生时长、参考方式）；本次请求点名了目标模型但 `short-drama.json` 尚未记录时，先转 `$short-drama` 写入 `production_profile`。独立任务无项目配置时，在《视频提示词.md》开头注明模型与方言。视频可复制正文语言优先跟随 `short-drama.json#/creator_authority/production_profile/choices/video_prompt_language`，未声明时回退到 `short-drama.json#/format/prompt_language`（无配置文件时按目标模型或用户当前语言）；对白、VO、OS 的口语语言仍由剧本和声音方向决定。

目标模型命中 `seedance-2.0`、`seedance-2.5`、`minimax-h3` 或 `wan-3.0` 时，只打开对应一份方言文档（[Seedance 2.0 方言](references/seedance-2.0.md)、[Seedance 2.5 方言](references/seedance-2.5.md)、[MiniMax H3 方言](references/minimax-h3.md)、[Wan 3.0 方言](references/wan-3.0.md)）；其他模型按 [目标模型能力档案](references/target-model-profile.md) 通用路径写。

沿用既有骨架：`## MOTION-... · 中文名`，字段名依次为「分镜、时长、生成方式、输入参考图、静态视觉锚点、起始帧、状态链、终点」，正文标题使用 `### 可复制提示词`，小节内只放以 `>` 开头的引用块（不加 `---` 分隔线）。本镜说话角色需保持音色且目标模型接受参考音频时，在「输入参考图」下一行加 `- 参考音频：REF-<slot>（顺序：<n>）· <音频路径>《<中文名称>》（用途：音色；角色：<人物名>；控制：<范围>；不得控制：<范围>）`，多条用 `；` 连接（VID-27）：路径照抄《视觉设定.md》的 `- 声音参考：`，角色须在本镜说出《剧本.md》记在其名下的台词（同场他人也说过同句时在引文前分句点名说话人），`不得控制` 至少写 `台词、语气、情绪`，音频 `顺序` 与图片分开从 1 编号（即 `@音频N` / `<Audio N>` / `音频N`）。

## 工作流

1. 检查每镜「输入参考图」。用户未手工点名图片时，按本镜冻结关键帧及可见人物、地点、道具的一致性需求，在用户输入、「制作成果」和文档已指向媒体中查找真实图片；内容和用途核对后才绑定，不靠相似文件名猜图。
2. 命中真实图片时，在同一请求内先请分镜 owner 按 `REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）` 原地刷新受影响镜头的 `REF-...` 槽位（若旧分镜缺「视觉依据」一并按冻结关键帧补齐），回读格式无误后再复制到视频文档。
3. 仍有图片缺失且创作者未另作选择时，在同一请求内请分镜 owner 将缺口写成 `PLAN-...` 挂图计划，照常写完视频提示词，不伪造路径、不把图片提示词当成图、不静默降级为文生视频；完成报告给出逐镜挂图清单、点名尚无 `IMG-...` 板子的项，并说明改绑 `REF-...` 投产或改走文生视频两条路。只有创作者要求先等图进项目时，分镜才保留「待补参考图」，此时列出缺失镜头、用途和对应 `IMG-...` / 冻结关键帧，不写最终《视频提示词.md》。
4. 原样抄入分镜「输入参考图」，标明「生成方式：图生视频」或「生成方式：文生视频」——该字段只写这两个精确值，不追加模型名或模式说明。具体走首帧（仅一张 `起始帧`）、首尾帧（`起始帧`+`结束帧`）还是多槽参考（含人物/地点/道具图），由各槽位 `用途` 组合读出并按目标方言翻译；首/尾帧与多槽参考互斥的模型，将起始帧并入多槽参考组。
5. 核对本镜时长与分镜一致且落在目标模型原生区间内（超限回分镜修订，不暗改秒数）；有对白/VO/OS 时核对分镜「声音」估时依据与实际可用发声窗口，缺失时按 [对白预算](references/performance-action-timing.md#对白预算) 补判。
6. 按“静态锚点 → 起点 → 唯一动作（触发、方向、接触、落点）→ 次级反应 → 运镜 → 声音 → 终点”组织正文，完整实现分镜的「起点 → 唯一动作 → 终点」（交接、换手和道具落位不跨镜省略），必要时按秒数分段。
7. 同一连续时空中无剪接跳变的相邻生成段（下一段从上一段最后一格接着拍），在目标档案支持续接时默认走“从上一段生成结果续接”，第二段起同时绑定上一段**实际视频**与**实际尾帧**；换景别/换机位/正反打剪接、创作者要求独立重生成或有时间/地点跳变时重新起链。未拿到真实产物前，后续段在《视频提示词.md》标为“待续接、不可提交”并保留内容草案，不降级成独立文生视频。因 `$short-drama-produce` 内置选择器暂不支持绑定续接视频，项目走内置生产且生产档案尚无 `continuation_route` 时，在交付报告请创作者二选一（由 `$short-drama` 写入档案）：
   - **独立起点**（`independent_starts`）：各段重新起链，从已接受起始帧生成（缺起始帧的后续段先交 `$short-drama-storyboard` 补共用切点图或起始帧槽位，参见 [摄影与声音连续性](references/camera-audio-continuity.md)）；
   - **保留续接、外部提交**（`relay_external`）：保持“待续接、不可提交”，由创作者在支持绑定视频与尾帧的外部工具提交。

## 提示词要求

- **去重与锁面**：只在真实参考帧已承载静态外观时删重复外观描述；《视觉设定.md》连续性锁的锁面在命中镜头中必须原样保留。上游持续关系写成贯穿状态和允许动作通道。
- **文字边界**：除非剧本或创作者明确开启，正文用当前提示词语言直接声明全镜任何时刻都不生成非画内字幕、caption 和对白文字叠加（不写抽象“文字层为空”）；画内要求“精确可读”的文字逐字写明字符、语言、承载面和位置，不被全局禁字指令覆盖。
- **声音时间线**：声音同轨时，按来源、说话人、口语语言和顺序写出完整声音时间线；逐字对白在单镜可复制正文中只出现一次（视觉动作段只按时间和说话人引用该事件），事件外回到环境底声或静默，上游已确认的发声禁令（无外语前导、额外人声或重复）在时间线末尾合并写一次。无对白镜写清底声或静默（嘴部按表演写，不强制闭嘴；H3 无非画内配乐时写 `non_diegetic_music: N/A`）。
- **引文真值**：正文引号或 `<d>` 内的四字以上中文引文必须逐字来自《剧本.md》《视觉设定.md》或《分镜.md》（`creator_markdown_check.py` 机械核对，VID-25）；改词须回写作技能改剧本。
- **纯净正文**：可复制正文不含占位符、流程说明、文件路径、规则 ID 或 QA 结论。

## 按需知识

默认只读本 SKILL、当前分镜和必要视觉事实。遇到对应问题时只打开一份：

- 阶段边界与规则分级：[阶段契约](references/stage-contract.md)
- 单镜运动正文的最小配方：[运动配方](references/motion-recipe.md)
- 外部执行需要的明确动作语法：[生产提示词语法](references/production-prompt-grammar.md)
- 多人表演、口型和精确时序：[表演与动作时序](references/performance-action-timing.md)
- 运镜、声音和相邻镜头连续性：[摄影与声音连续性](references/camera-audio-continuity.md)
- 动作负载、形变、生成风险和打斗接触：[可生成性](references/generability.md)
- 目标执行端的时长、参考、声音同轨等能力：[目标模型能力档案](references/target-model-profile.md)
- Seedance 2.0 的中文分镜、素材与声音语法：[Seedance 2.0 方言](references/seedance-2.0.md)
- Seedance 2.5 的长叙事、时间戳和任务类型语法：[Seedance 2.5 方言](references/seedance-2.5.md)
- MiniMax H3 的结构化正文、参考模式与逐切关键帧容器：[MiniMax H3 方言](references/minimax-h3.md)
- Wan 3.0 的中文正文、素材编号与多镜时间段：[Wan 3.0 方言](references/wan-3.0.md)

用户明确要求时间线音乐时，在本文档增加独立章节，写使用区间、剧情功能、进入/退出、动态曲线和禁用项（歌词须来自用户提供或已接受文本）。静态漫剧只需关键帧切换与配音时可跳过逐镜视频运动提示词。

## 完成与投产

每个点名镜头都有明确起点、主变化、时序、运镜/声音边界和可验证终点，且与相邻镜头连续，即完成。实际生成转 `$short-drama-produce`；写完后可转 `$short-drama` 做局部或完整机械核对。
