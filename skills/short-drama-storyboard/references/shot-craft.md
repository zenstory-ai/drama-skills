# 镜头设计方法

## 1. 场次覆盖、节拍拆镜与动作衔接（`SHT-01` / `SHT-08`）

`剧本.md` 每个场次都须落到具体的 `SHOT-...` 镜头上，确需整场删减不拍时在《分镜.md》正文开头注明 `- 未拍场次：<场景 ID>（理由：……）`（`SHT-01`）。按戏剧节拍拆合镜头：

| 剧本节拍类型 | 拆镜与环境带出做法 |
|---|---|
| 一句台词配一个顺手动作 | 目的与起止变化清楚时合在一镜拍完 |
| 连转话锋或逼出听者变脸 | 按双方攻守转换与听者反应节点切开 |
| 爆发推搡或连环动作 | 单镜装不下时按发力阶段拆开，切点锁死双方距离与手位；掌掴等干脆单招一镜落定 |
| 沉默对视或硬憋不响 | 接住重击或暗下决心时单给一镜，不硬塞咽口水、搓手等凑数小动作 |

- **借人物动作顺带交代环境（`craft_default`）**：竖屏短剧默认不单摆空荡荡的大全景定场镜，直接借人物推门、撑桌、落座把房间格局带出来；只有空间距离直接决定追逃输赢或后续复杂群戏方位时，才单设带人物动作的定场镜。
- **起止交接与动作顺接（`SHT-08`）**：每镜顺着 `起点（静止或运动半途均可）→ 动作（核心状态变化与持物交接落点）→ 终点（站位、双手、手中物落定）` 往下游交接。关键状态转变由一个主力镜头完成，禁止无意图地把刚才演完的动作倒回去重演一遍；但下列三种情形完全合规：
  1. **跨镜动作顺接微重叠（Cutting on Action）**：推门、起身、递物在切景别时保留几帧自然动作顺接（如全景抬手递出接特写落入掌心）；
  2. **高潮重播镜**：全集最顶点的掌掴或惊天反转可标明 `高潮重播镜：SHOT-...`，从同一动作前状态多角度分段重放，放完再接动作后状态；
  3. **固定机位时间跳切（Jump Cut）**：表现漫长煎熬等待、机械重复劳作或焦躁递进时，允许固定同一机位与景别做刻意时间跳切（按 `CON-05` 注明时间跳跃即可）。

## 2. 镜头目的、接招反应与悬念藏露（`SHT-02` / `SHT-11` / `SHT-12`）

- **镜头目的（`SHT-02`）**：写明本镜让观众新看懂了什么或场上谁的处境变了（谁堵住退路、亮出铁证、攻守易主、压住悬念），不拿“中景展示两人说话”敷衍。
- **给足接招反应（`SHT-11`）**：重话砸出、当众拆穿或局势翻盘时，画面要交代受影响一方怎么接住这记重击——可单切反应近景、双人同框拍对方僵住后撤，也可借全场死寂或茶面细纹落定；同框已演透时不必多切一刀。
- **悬念藏露对准知情进度（`SHT-12`）**：先藏后露的神秘人物或关键证物，在揭底前用拍背影、局部鞋尖衣角入画、门缝桌沿前景遮挡、浅景深虚化或顺着房间原有窗光灯位站进暗区剪影来藏住真容；轮到本镜亮证物或给关键变脸时，构图绝不让前景杂物把核心信息挡死。

## 3. 景别起伏、机位焦段与运镜选择（`SHT-04` / `SHT-07`）

### 一场戏的景别呼吸与竖屏俯仰

一场戏开场可比核心交锋区略放宽半档摆明人物关系，随即落回本场**主力景别**（多为中景或中近景，9:16 竖屏靠前中后景门框桌沿拉纵深），在主力景别上下一档间来回呼吸；大远景与怼脸大特写留给关键重音，用完退回主力景别，避免前半场就把大特写用尽。竖屏上下窄长，大幅俯仰极易拉扁人物比例，强弱压迫感优先靠站坐高低、前后远近与正侧角度体现，确有必要再上俯仰角。

### 水平角度、机位高度与焦段透视分开写清

| 维度 | 常用写法 | 戏剧作用 | 落盘位置 |
|---|---|---|---|
| **水平角度** | `正面 / 斜侧（四分之三侧）/ 正侧 / 后斜侧 / 背面` | 观众看清几分神色、代入哪一方 | 本镜 `景别/机位` |
| **机位高度** | `贴地 / 低机位仰拍 / 平视 / 高机位俯拍 / 垂直顶拍` | 场上强弱势对比（平视表对等） | 本镜 `景别/机位` |
| **焦段与透视** | 结合精准毫米数与透视效果，如 `24mm 广角拉开前后纵深`、`35mm/50mm 标准焦段自然透视`、`85mm/135mm 中长焦压缩空间、浅景深剥离人物` | 控制空间疏离感或贴脸压迫感（`SHT-07`） | 本镜 `### 首帧提示词`（及尾帧） |

### 运镜选择与手持口径（`SHT-04` / `SHT-07`）

- **运动镜头写清动法与落点，固定镜头免写不动理由**：跟拍/横移用于人物快步走位；摇镜或后拉用于画外新人新物入场；缓推用于压力聚拢或情绪逼近，缓拉用于疏离退场；急推可用于**开场前 3 秒强钩子抓眼球**或**高潮当场反转**（定格与闪白交后期剪辑，分镜只注节点）。运动镜写成「怎么动 + 起止落点」（如 `缓推，越过桌面停在周薄森绷紧的脸上`）；冷眼对峙、屏息等待、证物特写或平稳过招直接写 `运镜：固定`，无需为每个固定镜硬编不动理由。
- **手持机位对齐项目视觉方向（`SHT-07`）**：若项目视觉方向定为纪实冷峻手持风格，日常镜头可按视觉方向保持克制手持呼吸微动；若项目采用常规稳定机位，则把明显的手持晃动留给突发抓拍、受击眩晕或失控追逐。

## 4. 时长推算、对白切法与全集时长核对（`SHT-03` / `SHT-16` / `SHT-28` / `SHT-29`）

### 对白估时

- **按动作容量与声音时间线定镜长（`SHT-03`、`SHT-28`）**：对着单镜秒数掂量动作够不够舒展演完（例如 4–5 秒镜头通常从容演完 1–2 个连贯动作，硬塞三四个大动作极易抽帧变形，装不下就删枝蔓或拆镜）。有对白、`[VO]` 或 `[OS]` 的镜头，在排镜时按台词字句、语速缓急与停顿反应推算所需秒数（有实录干声时按音频实长排），长台词顺着说话人与听者反应拆成两三镜接力演完；**本镜 `- 声音：` 行只需清爽写明现场对白/VO/OS、关键音效与静默点，无需在文档里逐镜贴读秒算术账**。
- **节奏参考区间（`SHT-28`）**：项目启用了 `rhythm_profile` 时，`target_avg_shot_seconds` 与 `close_shot_share_min` 作为全集平均镜长与近景类占比的**参考区间**（密室心理交锋近景可偏高，动作追逐或多人调度场面自然放宽，不作一刀切硬门槛）。

### 对白场切法与全集总时长核对

- **对白场常规切法（`SHT-29`）**：一镜拍完一轮发问或回击，话锋突转处落刀；杀伤力最重的那句台词优先切给听话人看变脸反应；正面对峙守住同一 `机位侧` 正反打；砍掉纯水时长的无戏空镜（屏息听门外脚步的悬念停留除外），善用亮屏手机、攥紧指节、旧戒指等插入镜调节呼吸。
- **全集总时长核对（`SHT-16`）**：末尾如实加总各镜秒数（标明时长待定镜），附与 `target_seconds_per_episode` 的差值说明；秒数浮动不阻断交稿，确需大幅压时长应回剧本精简重复戏份，不靠把每镜硬砍一秒毁掉表演气口。

## 5. 首尾成对与多镜合生（`SHT-17`）

- **尾帧与跨镜接力**：仅当收尾构图非卡准不可且目标视频模型支持垫尾帧时，才补写 `### 尾帧提示词`（适用边界见 [首尾帧构图与写法](keyframe-craft.md)）。同场连续戏且模型支持视频续接时，优先用上一镜成片尾端续接；逐镜独立生成且切点机位构图完全一致时，可先定稿下一镜首帧兼作上一镜 `结束帧`；换景别或换角度顺接时只对齐人物动作姿态，不拿同一张图硬塞两头。需单独出尾帧图时交 `$short-drama-image-prompts` 建独立 `IMG-...` 状态图。
- **单镜到底 vs 多镜合生**：情绪连贯长戏适合一镜到底；短于模型单镜下限的快切镜头，可提议将同场相邻几镜打包做多镜合生（由 `$short-drama-video-prompts` 按目标模型多镜格式落地，合生组总时长对齐模型整数秒要求），或演完动作后稳住终点画面凑足最短秒数。

## 6. 重头戏导演构思与按需拍法比选（`SHT-18` / `SHT-19`）

- **重头戏拆镜前理清拍法（`SHT-18`）**：主角首次亮底、当众甩铁证、关系彻底翻脸或集尾卡点场次，动笔前先理顺七个支点——这场戏翻了什么盘、观众代入谁、怎么借房间家具封堵施压、先给反应还是先亮证物、哪几镜稳架不动哪一下推切、场尾定格在哪一帧、环境声在哪一刻骤停留白——随即直接落进正式分镜。
- **仅在创作者要求比选时暂停等拍板（`SHT-19`）**：常规整集或单场拆镜请求直接一气呵成输出正式《分镜.md》。**只有创作者明确要求“比选几种分镜拍法 / 多机位试排”时**，才先在对话里给出 2–3 套在知情时机、代入视角、主场空间控制（压人物反应 / 压证物细节 / 借空间封堵 / 声音先夺人）或场尾落点上真正拉开差距的方案，待创作者选定后再写正式镜头。
