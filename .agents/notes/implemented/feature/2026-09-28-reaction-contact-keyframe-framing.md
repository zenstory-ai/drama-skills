# Agent Note: 反应镜先点名情绪、接触动作按类型决定拆不拆、关键帧取景与画风统一

Status: implemented

## Problem

三类镜头在真实生成里反复出问题，而套件的写法建议没有实测依据：

- **反应镜**：现行写法把「情绪形容词」当作可删的东西，要求逐段写可见反应链。H3 按这种写法演出来偏弱、偏晚，
  盲评常读成「担心」「若有所思」；只写一个情绪词又会演过头。短剧的爽点多数落在反应镜上。
- **双人接触**：分镜只说「单镜过载时可按力学阶段拆」，没有说哪类动作该拆。只写一个动词时，掌掴三次都是
  碰一下没有反应；推搡一镜写全时被演成轻拍，人没有被推开。
- **关键帧取景**：视频侧已经记录地点板会把景别拉宽，但分镜的冻结关键帧同样挂地点板生成，实测图片模型也被拉宽，
  一张低角度特写出成了全身。
- **关键帧画风**：示例 EP001 的 22 条关键帧照原文生成后，同一间办公室的陈设与冷暖各不相同，部分人脸偏插画，
  剪成静态漫剧时维护者一眼看出「画风不统一」。

## Decision

- `skills/short-drama-video-prompts/references/performance-action-timing.md` 新增「反应镜：先点名，再给两处可见泄露」
  （`craft_default`）：触发 → 一个情绪词点名 → 两处当前景别读得到的泄露 → 落点并定住，反应在触发后一秒半内落下。
- `skills/short-drama-storyboard/references/production-shot-grammar.md` 的「一拍是爆发动作」写明：打击类一镜写全，
  要把人推开、拉住、带离原位的位移拆成「到接触为止」与「从接触后状态起」两镜；「动作是否拆镜」补上拆开后的代价
  和核对方法。
- `skills/short-drama-storyboard/SKILL.md` 增加一条：近景类关键帧挂地点板时写具体取景，仍偏宽就不挂地点板、把背景写进正文。
- 同一处增加一条：一集关键帧用同一句画风词、每场同一句光与色温，先出该场一张中远景定调图，其余镜头只从它取色调、光线与质感。
- 依据与样本量记在 `evaluations/model-behavior-probes.md`。

## Alternatives considered

- **反应镜只写情绪词**：最强的理由是它起反应最早、强度最高，也最省字。不用，因为盲评自然度只有 2.8/5，
  被打脸演成了崩溃大哭、压怒演成龇牙，而「不动声色的得意」这类反应单写一个词会被读错。
- **反应镜保持现行的逐段可见链**：理由是它最自然（4.0/5），也符合「写可见表演」的总原则。不用作默认，
  因为强度只有 1.9/5，四拍里三拍被读成别的情绪；Seedance 样片档里它表现最好，所以链条保留，只是压到两步、前面加点名。
- **所有接触动作都拆两镜**：理由是只有拆开时推搡真的把人推退一步。不用，因为拆开后跨切连续性最差（2.7/5），
  掌掴拆开反而把击打本身切掉了，受击反应才是这一拍的结果。
- **每张关键帧都挂上一张已接受的关键帧（链式参考）**：理由是逐张传递最连续。不用，因为偏差会一张张累积，
  而且参考图同时会把构图带过去；定调图固定一张、只取色调，偏差不累积。
- **关键帧一律不挂地点板**：理由是去掉后取景更准。不用，因为中远景、建立镜头要靠地点板守住空间布局，
  只有近景类才被拉宽。

## Consequences

- 反应镜的写法与剧本侧「不用情绪形容词解释」看起来相反：剧本讲的是人物差异不能靠形容词交代，视频提示词里这个词是
  给模型定调的锚，两处各管各的。审查时不应把反应镜里的单个点名情绪词当成冗余删掉。
- 样本都小：反应每种写法每拍 2 次、接触每种写法每动作 3 次，判断者是同一个模型；结论是默认做法，不是保证，
  生成后仍按实际画面挑。
- 拆两镜的动作多一张接触后关键帧和一次生成，成本上升。
