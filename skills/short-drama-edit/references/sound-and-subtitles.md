# 声音、字幕与音乐

画面接缝靠取舍解决，声音接缝不会自己解决。逐镜生成的素材各自带着一整套声音，直接拼接会在
每一个剪辑点留下一道能听见的断层——即使画面切得干净。

## 音床硬切

有声模型在生成画面的同一次里烧进环境声。两段素材各自的底噪、混响和环境层不同，拼接处就会
听到一次「换房间」的感觉。这个缺陷在逐镜审片时完全听不出来，只在成片上出现。

三条处理路径，按代价排序：

1. **在生成阶段避免。** 视频提示词阶段声明非叙事音乐不由单镜承载（对应该阶段的音乐规则），
   让每段素材只带必要的叙事声音。这是最干净的做法，但要在生产之前决定。
2. **在剪辑点做短交叉淡入。** 只处理音轨，不动画面。适合底噪差异不大的相邻段。
3. **铺一层统一的环境底。** 把各段原声压低到统一水平，再补一条贯穿全片的环境层。
   代价是丢掉一部分逐段的声音细节，且这是一个明显的创作决定，要写进剪辑单的「声音」行。

选哪条取决于差异有多大，先测再选：逐段测底噪水平，差异小的用第 2 条，差异大的才考虑第 3 条。

## 台词必须能听见

成片里每一句留下来的台词都要完整可听。检查方式是**在成片上**重新转写一遍，逐句对照剧本原文：

- 少一句 → 某一刀切掉了它，或者它被别的声音盖住了。
- 半句 → 边界切在了句中，回去按发声区间重定。
- 转写结果和原文有出入 → 转写工具的误差，也可能是生成时口型/发音本身就不清楚。
  分辨方法是听，不是看转写文本。转写只是筛子，不是判据。

转写做在成片上，不做在逐段素材上。逐段都对、拼起来丢了一句，正是这一步要抓的情况。

## 字幕

竖屏短剧默认硬字幕。

字幕文字**逐字取自 `剧本.md`**，不取自转写结果。转写只提供时间。标点可以按字幕排版惯例调整——
句末句号通常去掉——但一个字都不能改。这条是结构规则，不是偏好:
转写会把「诸君，且听龙吟」听成别的字，一旦让转写结果进了字幕，成片上就会出现一句剧本里
根本不存在的台词，而且没有任何环节会再发现它。

其它几条：

- 一行的字数按可读性定，不按句子结构定；一句话太长就**断成几条字幕先后显示**，
  不要让一条字幕在屏上堆成三行、挂五秒——那已经不是字幕，是字幕墙。
- **一镜可以有好几句。** 一次三个来回的对话是一个过肩镜头，不是三个镜头；
  剪辑单里用编号写法把每一句各自写下来并各自带时间。只写一条，另外两句在成片上就没有字幕，
  而且没有任何一步会报错——观众听得见、看不见。
- **字号写在画面像素里，不要再按画面高度乘一遍。** 字幕文件里的字号已经是相对
  `PlayRes` 的单位，渲染时会再按实际画面缩放一次。本套件第一版按画面高度算字号，
  于是被放大了两次：1344 高的竖屏上，本该 46px 的字变成约 161px（画面高的 12%），
  连带底边距从 74px 变成 259px，字幕被推到画面中部，长句两端直接切掉。
  `edit_tool.py` 现在自己写 ASS 并把 `PlayRes` 声明成实际画幅，一个单位就是一个像素。
- 字幕的出入时间跟随发声区间，不跟随剪辑点。
- **字幕时间按实际渲染出来的分段累加，不按剪辑单里声明的时长累加。** 每段落在帧边界上，
  比声明值长几毫秒；按声明值累加会一路漂移，八段之后能差三分之一秒，字幕于是在人还没说完时就消失。
- 画内已有文字（屏幕、招牌、聊天记录）的位置要避开，不要让字幕压在需要看清的信息上。
- 有画内文字要求的镜头，字幕位置在剪辑单的「字幕」行里写明。

### 两条渲染路线

`edit_tool.py` 的 `--subtitles` 选哪一条：

| | `ffmpeg`（默认） | `remotion` |
|---|---|---|
| 依赖 | 无 | Node + 一次 `npm install`，工作区在项目外 |
| 排版 | 白字黑描边，够用 | 字重、描边、行距、安全区、折行、入场动画都可调 |
| 改样式 | 改 `edit_tool.py` 的 ASS 样式 | 改 CSS，`npx remotion studio` 当场可见 |
| 许可 | — | Remotion 个人与小团队免费，超出规模需商业授权 |

两条都只渲染字幕层：`remotion` 出一段透明叠层再由 ffmpeg 合成，画面不经过浏览器重绘。
默认走 `ffmpeg`，因为它零依赖；对排版有要求（尤其要加粗、描边、逐句入场）时再换。

无论走哪条，字幕文字仍然逐字来自 `剧本.md`——换渲染器不改这一条。

## 响度

成片统一做一次响度标准化，目标写在剪辑单开头的交付规格里。

逐段素材的响度差异很大，因为它们是分别生成的。不做统一的结果是观众在播放中途反复调音量，
而这件事在工作环境里几乎察觉不到——工作时是逐段听的，逐段听不出整体起伏。

标准化在最后一步做，做在已经拼接和混音完成的成片上。对逐段素材分别标准化会破坏段间本来
正确的相对关系（一段耳语和一段喊叫会被拉到同一响度）。

## 时间线音乐

生产阶段把音乐的落点、循环、淡入淡出和对白 ducking 交给剪辑，因为供应商通常不能精确承诺
时长。到这里要做的是：

1. 按视频提示词文档里已确认的音乐意图，决定进入点和退出点——通常对着一个画面事件，
   不对着一个整秒。
2. 长度不够就循环，循环点选在乐句边界上，不选在剪辑点上。
3. 有台词的段落把音乐压低，在台词发声区间之外恢复。恢复时机跟着句尾停顿走，
   不要在句子中间的换气处就抬起来。
4. 音乐不填补沉默。剪辑单里写明是沉默的段落就保持沉默——那是一个创作决定，不是待填的空白。

音乐素材本身不在本阶段生产。需要新的音乐回 `$short-drama-produce`，歌词与音乐意图回
`$short-drama-video-prompts`。
