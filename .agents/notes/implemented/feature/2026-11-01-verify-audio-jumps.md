# Agent Note: verify 列出切点音量跳变

Status: implemented

## Problem

`verify` 已经按切点列出亮度跳变（见 [剪辑的同场景自动接镜、切点亮度与坏帧报告](2026-09-27-edit-cut-continuity.md)），
声音却只有整片响度一个数。各段素材的原声、配音与环境声各自生成，切过去时电平常常突然跳一档。
在六部拼好的演示成片上测量，31 个切点里 13 个前后变化超过 6 dB、9 个超过 10 dB；其中有的是有意的冲击，
有的是接缝。回听的人却不知道该先听哪几个切点。

## Decision

- `edit_tool.py verify` 新增「切点音量变化」：由 `_pcm_samples` 把成片声音解成 16 kHz 双声道 s16
  （`probe_audible` 也改用这个函数，按单声道解）；切点时间与亮度报告一致，都由 `_film_spans` 的整帧时长累计得出。
- `_cut_level_jumps` 在每个切点前后各取 `CUT_LEVEL_WINDOW = 0.4` 秒，离切点留 `CUT_LEVEL_GUARD = 0.03` 秒，
  窗口截在相邻切点以内；截后有一侧不足 `CUT_LEVEL_SHORTEST = 0.1` 秒时只报「未比」、不给电平。
  两侧各算均方根电平（dBFS），左右声道分别算、取较响的声道，反相的立体声因此不会在下混里抵消成静音。
  窗口按画面时间取，声音比画面先结束时缺的样本按静音计，所以声音在切点处断掉会测成一次下跌；
  电平最低夹到 `CUT_LEVEL_FLOOR = -70`。每行报切点秒、前后段、切前与切后电平、变化，
  以及同场 / 换场 / 未知（与亮度报告共用 `_scene_change`）。
- 绝对变化超过 `CUT_LEVEL_NOTICE = 10` dB 的切点写进「请回听」，提示用耳朵分辨有意的冲击和接缝。
  这个阈值只决定列出哪些切点，登记为 `EDT-23`（craft_default），不作质量门槛；交付规格目前没有覆盖任何
  verify 阈值的项，这一项也不加。
- 成片没有音轨报「未测（成片没有音轨）」，解码失败报「未测（读不出成片的声音）」；两种情况 verify 都返回 0。
- 做法写在 `references/delivery-verify.md`，`SKILL.md` 的 verify 输出清单补上这一项。

**验证**：`tests/test_edit_cut_continuity.py` 用 ffmpeg 生成三段音量为 0.05、0.05、0.7 的正弦原声，渲染后
从 `main(["verify", ...])` 读输出：平滑的切点变化小于 1 dB 且不列出，约 23 dB 的阶跃被列进「请回听」，退出码为 0；
纯函数测试覆盖静音夹底、过短的段不借用邻段声音并标「未比」、声音比画面先结束、反相立体声、读不出声音时报未测；
另一条 ffmpeg 测试把成片的音轨去掉，确认报未测且退出码为 0。窗口截断、静音夹底、列出阈值和
verify 接线这几处守卫逐条改坏，测试都变红。

## Alternatives considered

- **用 ffmpeg `ebur128` 的瞬时响度（400 ms、K 加权）。** 最强理由是与交付响度同一套计权，低频轰鸣不会虚高。
  不用：它每 100 ms 才出一个值，窗口对不准切点，每侧最多偏出 100 ms；还要解析随版本变化的日志文本。
  均方根窗口能精确截在切点与相邻切点之间，作为「先听哪里」的提示已经够用。
- **6 dB 作阈值。** 最强理由是 6 dB 已经听得出。不用：演示成片上会列出四成切点，提示失去筛选作用；
  10 dB 约等于主观响度翻倍，列出约三成。
- **超过阈值时让 verify 失败或阻断交付。** 最强理由是电平跳变确实常是缺陷。不用：有意的冲击、进出静默、
  换场都会超过它，数字判断不了创作意图；verify 只测量、不下结论（`EDT-15`）。

## Consequences

- **收益**：回听有了具体的切点和前后电平，接缝问题先被听到；与亮度报告同一套切点时间，两份列表能对照。
- **代价**：verify 要多解码一遍成片声音（双声道）；在 Python 里求平方和只算切点附近的窗口，这部分开销与切点数成正比。
  列表里会有有意的冲击，需要人逐条确认。
- **已知上限**：均方根不计权，低频成分会让电平偏高；只比切点两侧各 0.4 秒，渐强渐弱跨过切点时可能低报；
  短于约 0.13 秒（一侧至少 0.1 秒，再加 0.03 秒留白）的段不比；多于两个声道的成片先下混成双声道再测，
  原声道之间的反相仍可能部分抵消。
