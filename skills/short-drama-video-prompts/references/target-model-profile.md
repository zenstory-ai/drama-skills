# 目标模型能力档案

## 档案结构与选型参考

目标模型档案由创作者在 `short-drama.json#/creator_authority/production_profile/choices` 声明一次，本集共用；未知字段留空，不从模型简称推断。生产端供应商字段属于 `$short-drama-produce` adapter，不进创作文档。

```json
{
  "target_video_model": "versioned-model-profile",
  "video_prompt_dialect": "dialect-id",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 4, "max": 15},
  "supported_generation_modes": ["text", "reference"],
  "audio_generation": "same_pass"
}
```

未选定 `target_video_model` 时的选型参考：H3 在建立镜推近、多人同框单人说话表现稳健；Seedance 2.5 在反应镜、走位跟摇、手部插入与夜景情绪近景表现较好；可按本集占比最高的镜头类型优先试拍。

## 九条会改变正文的能力轴

| 能力轴 | 声明内容 | 对正文的影响 |
|---|---|---|
| 模型版本 | 版本化模型档案键 | 只路由到该版本方言，不因名称相近混用 |
| 提示词方言 | 通用自然语言或目标原生结构 | 命中方言时按其字段、素材标记和声音语法写；语言标签不代替方言 |
| 单次原生时长 | 单次生成的最短与最长秒数 | 默认一镜一生成，短动作到位后 hold，长动作按闭合状态拆镜；在[交付形态](delivery-profile.md)声明多镜容器且方言支持时，短镜可与同场相邻镜打包（如 [H3](minimax-h3.md#多镜容器每切一张关键帧) 要求每切都有已接受关键帧） |
| 参考条件方式 | 无 / 首帧 / 首尾帧 / 多槽参考（含槽位上限） | 见[参考条件方式](#参考条件方式) |
| 声音是否同轨生成 | `same_pass` 或 `separate` | 见下节 |
| 画幅与分辨率 | 执行端接受的画幅与分辨率 | 只写项目已接受的一项，不罗列备选 |
| 正文长度上限 | 单次字符数上限 | 超限时先删已被参考帧承载的重复描述；连续性锁锁面、逐字对白和已批准文字位置不删 |
| 运镜词汇 | 是否接受具名运镜术语 | 不接受时改写为可见画面关系变化（主体占画比、边缘进出、前后景遮挡） |
| 视频提示词正文语言 | `zh-CN`、`en` 等 | 可复制正文使用该语言；逐字对白、VO、OS 保留原口语语言 |

## 声音同轨生成

- **不同轨（`separate`，默认）**：写本镜声音职责（谁说话、环境声信息、转场声落点），供后期与审查使用。
- **同轨（`same_pass`）**：写出完整声音时间线（对白、VO、OS、非语言发声、SFX 的相对时机与口语语言，事件间及首尾回到环境底声或静默；逐字对白按[交付形态](delivery-profile.md)围栏保留）。上游已点名排除外语前导、语气词、额外人声或重复时，在时间线末尾合并写一次，并以“以上为完整声音时间线”闭合，不跨项目套固定负面后缀。文字与字幕层分离按 `SKILL.md`「格式要点」第 3 条执行。

## 参考条件方式

| 声明 | 正文职责 |
|---|---|
| 无参考 | 文生视频：静态视觉锚点须自足（人物、造型、地点、构图、光线） |
| 首帧 | 只写从起点开始的变化；静态外观由参考帧与视觉设定共同承载 |
| 首尾帧 | 终点帧只呈现 `SHOT-...` 已接受终点，不发明新结果 |
| 多槽参考 | 按 `REF-...` 或 `PLAN-...` 槽位记账（`顺序` 即挂图次序）；不超槽位上限，连续性锁锁面始终留在正文 |

- **超上限取舍顺序（从高到低保留）**：起始帧 → 说话或主要动作人物身份 → 必须认出的道具（交接、证物、持物） → 地点/地理 → 画面内不说话不动作的人物身份 → 定调图与风格图。放弃项的必要事实写回正文与静态视觉锚点。
- **无起始帧时的具体取景（`craft_default`）**：只挂身份或地点图、无起始帧时，地点图容易把景别拉宽成中远景。正文须写明画面下沿切位（腰/胸口/膝）、主体占画高度、头顶落段、机位高度与物距；有起始帧时由起始帧承载构图。
- **模式由槽位 `用途` 组合决定**：仅一张 `起始帧` 为首帧，`起始帧 + 结束帧` 为首尾帧，`起始帧` 与身份/地理/道具图并存或仅有后者时统一走多槽参考（首尾帧与多槽参考互斥的执行端，起始帧一并作为参考图送入；具体映射见各目标方言文档）。

## 未声明时怎么写

按已接受镜头边界写自足正文：语言回退到 `format.prompt_language`（无项目配置时沿用用户当前语言），写声音职责而非同轨指令，不拆多镜容器，用可见画面关系描述运镜。未声明目标模型属于合法草稿状态，不作为审查阻断项。
