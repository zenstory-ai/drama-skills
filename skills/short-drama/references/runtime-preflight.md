# 项目定位与安全写入

## 定位项目与运行环境

优先使用用户给出的项目路径；无项目配置时可在用户指定目录直接完成单文档任务，需建项目时运行 `python3 <core>/scripts/project_tool.py init <project> --title "项目名"`。

执行脚本前确认解释器为 Python 3.9 或以上（macOS/Linux/WSL 用 `python3`，Windows 原生可用 `py -3` 或 `python`）。创作文档固定写入 `剧集/<EP>/`；只读取当前任务的直接输入，不扫描整个项目补造未请求的上游。

## 写入纪律

- 直接读写五份创作者 Markdown，修改时保留未受影响内容与稳定可见 ID。
- `输入/`、`.short-drama/`、`制作成果/` 与环境凭据不属于创作正文，严禁复制进提示词。
- 文本落盘使用临时文件加原子替换；检测到外部并发编辑时先重新读取，不静默覆盖。输出语言、稳定 ID 与信任边界见 [契约与所有权](contract-and-ownership.md)。
