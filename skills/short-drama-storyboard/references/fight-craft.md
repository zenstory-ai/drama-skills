# 打戏与动作场面分镜

**`SHT-31 · craft_default`**：剧本写明交手双方、所持器械与胜负结果后，分镜负责排清招式拆合、机位角度与受击反馈。兵器或证物跨镜争抢按 [场面调度手册](blocking-playbooks.md)（`SHT-14`）保持归属与落点连贯。

## 1. 多招回合拆法与单招落定

- **多招过手推荐按“起手 → 拆招 → 结果”理顺**：连续交锋的动作戏，推荐按回合梳理「谁从哪件 `固定陈设` 方向起手攻来 → 对方侧闪/架挡/扣腕或受击 → 当合打完双方距离、朝向、器械归属与先手怎么变」，让每一合推进场上态势（如破门清道、夺械封路）。
- **单招突袭与掌掴一拍落定**：迎面一记耳光、突然掀桌、一把揪住衣领按上墙等干脆爆发动作，直接一镜一拍打到底，无需硬凑三步拆招结构。
- **角力僵持与换气放话**：刀刃架死角力、贴身锁腕顶牛、咬牙贴脸放狠话或粗重喘息对峙，本身就是极富短剧张力的动作戏节点，可用近景或双人同框稳稳拍透指节发白与眼神博弈，不必机械删改。

## 2. 单合入镜、多镜合生与特写切点

结合目标模型单次时长与动作节奏灵活选拍法（参考 [镜头设计方法](shot-craft.md) `SHT-28`）：

1. **多镜合生紧剪**：快节奏连招可提议拆成「起手中景 → 招式碰撞/受击近景 → 余波站定中景」装进一次多镜合生，分镜独立编号、成片卡点紧剪。
2. **单镜一气呵成**：动作体量与单镜秒数匹配时（如 3–4 秒演完闪身扣腕反压），架稳机位一镜拍完，单镜秒数贴合动作体量即可，避免给单一下短促出拳挂过长空余秒数导致节奏拖沓（`craft_default`）。
3. **关键结果单拆特写**：刀棍脱手滚远、指节攥血或挨重击后眼神骤变，优先单给特写镜或直接作为下一镜开场起点，防止塞在长镜头末尾被模型漏画；最顶点的重击需要多角度重放时按 `SHT-08` 标明 `高潮重播镜`。

## 3. 拳脚受击与贴身缠斗的镜头技法

- **劈空、格挡、扣腕与砸毁陈设**：优先架侧面或斜侧面中景，在一个画框里亮清来拳路线与闪避空当；棍棒刀锋劈裂桌角、水缸或栏杆爆出木屑水花，能直观放大力量感。
- **实打受击借位显力道**：双人高速碰撞瞬间可用三种成熟拍法稳住画面冲击力——
  - **同侧过肩借位**：机位留在轴线同侧、绕到出拳人斜后方，借前景肩背自然遮住拳肉接触点（守住轴线不翻反方向）；
  - **画外入拳/棍影近景**：单卡受击者近景，拳锋或棍影从画外闯入击中，受击者顺来力方向猛偏头踉跄；
  - **受击余波落定**：借撞翻椅背、扶墙滑落、捂肋弯腰配闷响与飞溅汗水尘土把痛感演实。
- **贴身擒拿**：一镜聚焦一次干净的锁拿、过肩掀翻或挣脱，避免在短短几秒里堆叠三四道复杂的反关节换手拆解。

## 4. 多人围攻调度与动作烈度分档

- **群战围攻方位清晰**：多人围堵时先定清各对手相对主角与房间 `固定陈设` 的方位；既可以车轮战逐个逼上（换对手时用中全景交代新方位防跳轴），也允许**站位与先后次序清晰的双人同框左右夹击或前后合围**（如一人正面架住双手、另一人从侧后逼近），只要攻防焦点清楚、不把多人挤成一团乱影即可。9:16 竖屏打戏多用朝镜头纵深扑退的斜线调度，劈砍与高抬腿给头顶留足挥展空间。
- **动作烈度分档（`taste_option`）**：按项目定调选**写实搏击档**（短促扎实无花哨光效）、**爽感强化档**（密剪配适度击退滑步或高潮重播）或**玄幻超能档**（轰飞撞墙、剑气法术与能量光效；光效形态与主色对齐 `视觉设定.md`，持续时长与爆发节奏在本阶段和视频提示词里排定）。见血与伤痕尺度贴合项目烈度与平台规范。
