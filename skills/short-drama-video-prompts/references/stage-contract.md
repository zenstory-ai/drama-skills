# 视频提示词阶段职责与规则

本阶段负责维护 `剧集/<EP>/视频提示词.md` 中的 `MOTION-...`、`GROUP-...` 条目及按需增补的成片配乐章节。镜头起点、终点、时长、台词和首帧均沿用分镜定稿，不反向改写分镜起止状态或视觉设定（整理参考图时可请 `short-drama-storyboard` 技能就地同步「输入参考图」与「出场设定」），不另建隐藏 JSON 或质检台账。

下表仅注册阻断级不变量（`structural_invariant` 与 `reviewed_invariant`）；动作结构写法、模型默认档、同框表演幅度、音画同出时间线、打戏分段与生成防崩技巧等创作经验（`craft_default` / `taste_option`）见 [视频提示词写作指南](video-prompt-guide.md)、[目标模型与交付配置指南](model-and-delivery-profiles.md)、[表演弧线与动作计时](performance-action-timing.md) 与 [运镜、现场声与跨镜连戏](camera-audio-continuity.md)。

## 本阶段规则

### `VID`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| VID-01 | structural_invariant | 每条 `MOTION-...` 须指向《分镜.md》中已存在的 `SHOT-...`，且填写的 `时长` 必须与对应 `SHOT-...` 的时长完全相等。 |
| VID-03 | structural_invariant | `输入参考图` 绑定了 `REF-...` 或 `PLAN-...` 时填写 `生成方式：图生视频`，每项槽位须符合完整语法并从十项合法词表（`外貌`/`主体`/`造型状态`/`空间布局`/`构图`/`尺度`/`效果`/`起始帧`/`结束帧`/`风格`）选填唯一 `用途`（单条最多一张 `起始帧` 与一张 `结束帧`，挂 `结束帧` 须同时挂 `起始帧`）；未绑定参考图时（`输入参考图` 写 `无（文生视频）` 或简写 `无`）填写 `生成方式：文生视频`，并提供非空的 `- 开场画面：` 交代起点人物、造型、场景、构图与光线（不要求将 `开场画面` 逐字原样粘贴进可复制提示词）。 |
| VID-04 | reviewed_invariant | 精确标秒的互不重叠分段时长相加（声明重叠的时段按合并覆盖区间计算）必须刚好等于本镜分镜时长，既不超时截断，也不留空白余秒。 |
| VID-05 | reviewed_invariant | 未标具体秒数的动作总量必须与本镜时长匹配，确保人物能从容做完关键表演与剧情变化，不塞成走马灯。 |
| VID-06 | reviewed_invariant | 同一时间段内不得同时下达“固定机位”和“移动运镜”指令；由静转动必须写成互不重叠的前后分段。 |
| VID-11 | reviewed_invariant | 画面发生局部变形、碎裂或消失时，写清触发动静、变化部位、变化后的形状状态，以及同框不参与变化的人物、道具、带字表面与室内外参照物保持原状。 |
| VID-12 | reviewed_invariant | 局部补拍版或备选版沿用固定的 `MOTION-...` 编号，说明动作、反应、台词、信息揭晓与终点分别采用哪一版或是否退回分镜调整，不悄悄顶替主镜头版。 |
| VID-13 | structural_invariant | 在完整保留全集逐镜 `MOTION-...` 条目的前提下，多镜合生分组（`GROUP-...`）的 `- 成员：` 须填写同一场次内按分镜顺序紧邻的已有 `MOTION-...` ID（可选分组级 `- 输入参考图：` 与 `- 参考音频：` 须符合槽位语法），且分组 `时长` 等于各成员时长之和。 |
| VID-15 | structural_invariant | 同一集内每个 `MOTION-...` 至多归入一个 `GROUP-...`（组内成员亦不得重复）；各合生分组覆盖的成员镜头加上未归入分组的单拍 `MOTION-...`，必须不重不漏地覆盖本集全部镜头。 |
| VID-17 | reviewed_invariant | 绑定多张参考图时使用固定编号与明确排列顺序，确保正文中每一处指代都准确对应各自的参考图，避免因顺序变动串图换脸。 |
| VID-19 | reviewed_invariant | 若项目配置为某种生成路径规定了必需的固定触发字样，提示词在台词引号或标签之外原字保留该字样，不改字换词。 |
| VID-20 | reviewed_invariant | 多镜合生只改变单次生成的打包粒度（按 `VID-13`、`VID-15` 核对结构与时长），组内成员须共用同一空间布局与人物道具设定且不改变各子镜头的起止状态与逐镜可核查性；跨镜硬切接同一连续动作需从上一段成片续接时，基于实看结果传入上一段视频或真实末帧，并以分镜确认的开场状态为准绳。 |
| VID-22 | reviewed_invariant | 可复制提示词只写要拍出来的画面、动作、声音和必要的画面限制（不写内部编号、流程状态或文件路径）；防字幕负面词按模型特性与文字风险场景按需添加，同时保住剧本批准的画内文字。 |
| VID-24 | reviewed_invariant | 图生视频镜头的 `输入参考图` 可在分镜绑定基础上按目标视频模型实际需要合理增减静态设定板或承接帧，保持每项 `REF-...` 与 `PLAN-...` 的 `用途` 清晰明确，并按 `用途` 组合准确转换成首帧、首尾帧或多图参考写法。 |
| VID-25 | reviewed_invariant | 可复制提示词（含 `MOTION-...` 与 `GROUP-...`）中由说话引导词或 `<d>` 标签引出的显式人物发声引文，须出自《剧本.md》《视觉设定.md》或《分镜.md》定稿，不得私自编造上游未声明的人物发声台词；绑定 `- 参考音频：` 的角色须与本镜（或本组）实际发声角色一致，不得给沉默角色挂音色。 |
| VID-27 | structural_invariant | 角色音色参考单独写在 `MOTION-...` 或 `GROUP-...` 的 `- 参考音频：` 行（`用途：音色`），路径必须指向《视觉设定.md》中该人物登记的真实 `- 声音参考：` 文件；槽位 ID 不与本条目 `输入参考图` 重名，音频 `顺序` 与图片分开从 1 连续编号，同一角色单条至多一条，`控制` 与 `不得控制` 范围互不重叠。 |
| VID-29 | reviewed_invariant | 视频提示词须忠实沿用分镜确认的起点、终点、台词及下一镜衔接状态，不得私自改写；确需调整时退回对应上游负责技能修订。 |

### `CON`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| CON-01 | reviewed_invariant | 相连镜头或场次的前一收尾状态（`终点`）与下一开场状态（`起点`）在站位、朝向、持物与环境状态上必须衔接一致；若有跳变或刻意跳切须写明说明，对不上时退回负责技能修订。 |
| CON-02 | reviewed_invariant | 人物知情范围、伤势污渍、道具归属与开合、天气、光线或空间状态不得在切镜或转场间无剧本依据凭空跳变或自行复原。 |
| CON-07 | reviewed_invariant | `视觉设定.md` 声明的 `- 连戏锁：` 固定唯一 `LOCK-...` 编号、生效目标引用（脚本确定性核对声明语法及指向的 `SHOT-...`/`IMG-...` ID 存在性）与 `锁定词`；点名的静态图片提示词、范围内镜头的首帧提示词，以及无参考图的文生视频和仅挂 `空间布局` / `风格` 等未锁住该外观的图生视频（含合生分组）在正文里原字保留该锁定词，已挂载本镜 `起始帧`（含首帧已带该锁定词的跨镜复用 `PLAN`）或对应设定条目 `主体` / `造型状态` 参考图时自动豁免（正文锁词保留与豁免由审稿按上下文核实）。 |
