# 场次视觉戏剧计划

场次视觉计划是关键场景（主要人物亮相、身份/证据揭示、关系反转、高潮/结尾、复杂多人调度、悬念延迟）进入正式分镜前的可选上下文思考层；普通场景跳过，不另存 plan 文件（`SHT-18`）。

## 在上下文对齐的七个维度

绑定场景标题 ID（如 `EP001-SC003`）与当前视觉设定，明确：

1. **戏剧转向**：哪一种公开关系、信息或选择不可逆地改变；
2. **观众立场**：开场站在哪一方，结束被移到哪里；
3. **空间压力**：入口、距离、占位、遮挡、让路或退路怎样承载人物策略；
4. **视觉推进**：何时让信息、反应或空间先于特写落地；
5. **摄影节奏**：固定、移动、切近和停留分别由什么变化触发；
6. **反应落点**：结尾画面由谁的选择或空间后果承担；
7. **声音策略**：主导声源、主动留白、距离变化、撤出/恢复和声音桥。

确定后直接转化为 `分镜.md` 的镜头职责、景别/机位、起止边界与声音。
