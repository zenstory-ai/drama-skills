# 形态卡：二维动态漫

形态选型与各环节协同见 [制作形态](../production-form-profiles.md)。

## 视觉介质特征

- **认人与连戏**：靠**外轮廓剪影 + 线条笔触特征 + 固定配色分块**（发型剪影、脸型比例、领口袖口色块与醒目发饰）认人；跨镜保持描边粗细、固有色与阴影切分方式统一。
- **画面四层分工**：人物层（线稿与固定色块）、环境层（同机位复用的手绘背景板，控制繁密程度以防吞没主体）、运动层（本镜真正运动的单手、嘴唇、发梢、衣摆或道具）、效果层（光斑、粒子、速度线、冲击波，不盖住人物关键轮廓）。每镜写清哪一层定格（`hold`）、哪一层小幅循环、哪一层做推拉视差、哪一层切换关键姿势。
- **色块与光影画法**：按二维上色层次描述固有色、暗部色与高光色分块，标明阴影硬切边还是柔和晕染、平涂还是笔刷肌理，不混入三维物理渲染术语。
- **有限动画与口型**：一镜优先让承担戏剧重点的运动层做完整动作，其余部分保持定格姿势（`hold pose`）配呼吸发梢微动或视差推进；口型规格（闭嘴 / 两帧开合 / 完整对口型）全剧统一，拟声词与气泡框注明画内生成还是后期叠加。
