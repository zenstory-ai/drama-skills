# Wan 3.0 提示词方言

只在目标档案明确写 `target_video_model: wan-3.0` 时使用。推荐档案：

```json
{
  "target_video_model": "wan-3.0",
  "video_prompt_dialect": "wan-3.0",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 2, "max": 30},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference"],
  "audio_generation": "same_pass"
}
```

Wan 3.0 用中文自然指令，素材写成 `图1`、`视频1`、`音频1`。它和 Seedance 一样读中文长句，
但素材标记、多镜时间段和对白写法都不同，不套用 Seedance 的 `@图片N`、`{…}` 或 `<声音>`。

## 选哪一种模式

| 本镜绑定的图 | Wan 3.0 模式 | 正文怎么指代 |
|---|---|---|
| 没有图，且创作者已明确选择文生视频 | 文生 | 静态视觉锚点写进正文，不出现素材标记 |
| 只有一张 `用途：起始帧` | 首帧 | 从输入帧的可见姿态写起，不另起标记 |
| 一张 `用途：起始帧` + 一张 `用途：结束帧` | 首尾帧 | 终点只投影分镜已接受的终点 |
| 其他任何组合 | 参考 | `图N` 逐张点名职责 |

首帧、尾帧与 `reference_image`、`reference_video`、`reference_audio` 在同一请求里**互斥**。
「起始帧 + 角色图 + 场景图」整组走参考模式，起始帧也作为参考图送入，正文写
「图1 是本镜开场画面」，不拆成首帧加参考图。没有起始帧、只挂身份或地点图时写具体取景，见
[目标模型能力档案](target-model-profile.md#参考条件方式)。首帧与首尾帧模式本套件未实测。

## 素材编号与上限

`图N`、`视频N`、`音频N` 各自从 1 开始，按同类素材在请求数组里的次序编号，也就是本镜
「输入参考图」里的 `顺序`。每次使用都写清这张图负责什么：「图1 中的年轻女子站在图2 的旧书店里」，
不让一张图顺带决定身份、构图和动作。

一次最多 10 张参考图、5 段参考视频、5 段参考音频；视频与音频每段 1–15 秒，各自合计不超过 15 秒。
首帧、尾帧各 1 张。正文不超过 20000 字符。超过上限时在分镜阶段按重要性取舍，并写明放弃了哪些参考。

## 时长

`duration` 为 2–30 的整数秒；带视频输入时，输入视频时长加输出时长不超过 30 秒。`-1` 是智能时长，
由模型自己选。固定时长交付显式传分镜已接受的秒数，不把规划镜长写成自动时长下已经保证的输出长度。
分辨率可选 1080P、720P、480P，画幅按项目已接受的那一个传。

## 多镜时间段

多镜按 `(0:00 - 0:03) 镜头1，远景：…` 写时间段，段与段首尾相接，最后一段终点等于总时长。

几个相邻镜头装进一次生成、每切挂自己的已接受关键帧时，先写一句「图1、图2、图3 依次是三个镜头的
画面，图4 是老人，图5 是年轻女子」，再在各段里写「按图N构图」。成员资格与容器算术按
[交付形态](delivery-profile.md) 的多镜容器记账，关键帧按切的顺序排在参考清单前面。

这种写法可用，但切点不准。一组 9 秒三切的小样本（要求 3.0/6.0 秒切）3 次：切点落在 2.46–3.46 /
4.92–6.17 秒，第三切与关键帧的构图相似度也明显低于前两切。需要准确切点的交付逐镜生成，
或者生成后按实际切点剪辑。

## 对白与语速

- 对白写成 `说道：“逐字台词”`，用中文引号，跟在说话人的可见动作后面：
  「她望着镜头，声音轻而稳，用普通话说道：“……”」。这是官方示例的写法。花括号
  `{年轻女子用中文说：“……”}` 在小样本里同样逐字完整、括号里的说明没有被念出来，但不作为本方言写法。
- 语速按 [对白预算](performance-action-timing.md#对白预算) 先估再排时。Wan 3.0 中文小样本约
  4.6 个可发声字/秒：21 字配 5 秒、41 字配 10 秒都以常速说完。41 字塞进 5 秒仍说完，但赶到
  8.2–8.7 字/秒；66 字塞进 5 秒时只说出前 21–24 字，其余静默丢掉，接口不报错。所以超出容量时
  看不到失败提示，生成后逐字核对台词是否说完。
- 说话人的声音要跟参考音频走时，写「图1 中的女子说话时，音色参考音频1」；这是官方写法，本套件未实测。
- 双人镜里不说话的人按 [对白、口型与声音](camera-audio-continuity.md#精确引用) 的顺序处理；Wan 3.0 的
  小样本太小，写不写「他不说话、嘴唇闭合」没有看出差别。

## 声音与文字

写全本镜声景：环境底声、每个音效事件及其时机，并单独写一句配乐层——需要配乐就写情绪与进出，
不需要就写「无背景音乐」。一组小样本里写全环境声、不提配乐与加「无背景音乐」各 4 次，
8 次都没有配乐；仍把配乐层写明，不留给模型决定。

默认禁字幕时写「全程无字幕，画面中不出现任何文字」；画内获准文字另行逐字说明。

## 智能改写

官方 API 的 `prompt_extend` 默认 `true`，会先用大模型改写提示词再生成。已审过的正文可能被改掉逐字
台词、声音层或镜头数。直接调用 API 时显式传这个参数；所用平台不暴露它时，默认它在改写，
生成后对照正文核对台词、声音层与切数。

## 编辑与延长

编辑和延长都是「`reference_video` + 写明意图的正文」，没有单独的任务类型字段，所以不写
Seedance 2.5 的「任务类型」一行：

- 编辑：「编辑视频，把视频1 中……改成……」，或用「去掉」「替换」「改成」点名要改的那一处，
  其余照原片保留。
- 延长：「将视频1 向后延长 N 秒」「延续」，或「向前延长」；需要 `ratio: adaptive`。
  从输入视频的实际终点写唯一动作和新终点，预算的是新增片段的时长与对白。

连续段需要上一段实际视频和实际尾帧时，因为首帧与参考互斥，两者都走参考模式：视频为 `视频1`，
控制动作、节奏和声音连续；尾帧为 `图1`，只控制新段开场的可见姿态与构图。
