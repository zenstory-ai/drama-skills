# 形态卡：风格化三维

形态选型与各环节协同见 [制作形态](../production-form-profiles.md)。

## 视觉介质特征

- **认人与比例边界**：靠**头身比例 + 肩宽手长体态剪影 + 服装材质分区 + 骨骼绑定（`rig`）可动范围**认人；跨镜保持比例剪影、材质粗糙度、主光方向、空气雾尘与机位轴线一致，文生视频需带三维画风词或挂三维首帧图稳住介质质感。
- **画面四层分工**：人物层（三维角色模型、比例与材质分块）、环境层（空间几何结构、地面高低、走位通道与前景遮挡）、运动层（肢体动作、道具物理摆动碰撞与镜头推拉摇移）、效果层（体积光、漂浮粒子与景深虚化）。若采用三渲二或三维角色配二维手绘背景，逐项写明轮廓线、景深、阴影与运动归属哪一层。
- **材质受光与接触重量感**：写明表面粗糙度与高光形态（哑光漫反射、拉长高光带、半透明透光、轮廓逆光）以及发力接触形变（落脚踩实地面、软垫受压凹陷、握持截位与碰撞回弹）。
- **动作与声效配合**：抓握、推挡、落地等接触动作给足发力与受重过程，常规站立呼吸平稳循环，跨空间位移交剪辑切镜；脚步、搁物、碰撞等接触音效写明具体声源以压实画面重量感。
