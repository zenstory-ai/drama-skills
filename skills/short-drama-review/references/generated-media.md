# 成片看片与返工分流指南

适用于审查单镜生成素材、整集成片，以及根据试拍样片或创作者看片反馈做问题归因与提示词调优（`REV-08`–`REV-10`、`REV-15`）。创作者在对话里随口给出的看片反馈（如“第 3 镜手穿模了”“第 5 镜后半句吞字了”）可直接接手定位病灶并给出修法，无需强求补填看片人、查看工具或查看局限等繁琐表格。

## 一、单镜与成片瑕疵六档分流（`REV-15`）

对照《分镜.md》本镜目的、起止画面与声音要求，先看核心剧情信息、台词、关键道具变化与人物反应是否拍出，再将画面或声音瑕疵归入以下六类处置：

| 处置分类 | 判定标准 | 严重程度 | 后续动作与负责技能 |
|---|---|---|---|
| **保留沿用** | 正常倍速播放不显眼，不影响剧情理解与前后连戏（如单帧边缘微闪、远处路人轻晃） | `note` | 留底告知剪辑，不改提示词、不重抽 → `$short-drama-edit` |
| **裁切避让** | 瑕疵落在有效动作起止点之外（如片头发呆等待、片尾多余变形），掐头去尾后本镜信息完整 | `minor` | 写明剪辑入出点避开问题区间 → `$short-drama-edit` |
| **后期修补** | 挪几帧音频对口型、调色、后期叠字或局部擦除背景穿帮小物即可解决 | `minor` | 写明后期修补做法 → `$short-drama-edit` |
| **建议重抽（创作者可取舍）** | 核心剧情信息与台词能看懂，但存在较明显的人物表情发僵、次要肢体轻微走形、非核心道具细节偏差或口型偏飘，后期难彻底修净但并非完全不可用 | `major` | 给出局部调优重抽方案，**同时允许创作者结合工期与预算拍板直接留用或靠切镜遮掩**，不强制锁死流程 → 对应负责技能 / `$short-drama-edit` |
| **必须重新生成** | 漏掉关键剧情动作、核心台词或必看物证，或人物彻底换脸、空间轴线全反、关键真字乱码扭曲事实，裁切与后期均无法挽回 | `blocker` | 定位提示词、垫图或拆镜症结，退回对应负责技能修改后交 `$short-drama-produce` 重生 |
| **剪辑补回**（仅成片） | 原始生成素材已拍到关键内容，但成片切点下刀太狠或混音叠字把关键信息弄丢 | `blocker` | 指明需调整入出点或音轨的 `CUT-...` 条目 → `$short-drama-edit` |

### 审查结论判定

- `APPROVE`：所有已看片段均完成本镜戏剧任务，无待处理瑕疵。
- `APPROVE_WITH_NOTES`：核心任务均已完成，仅有 `note`（保留沿用）或 `minor`（裁切避让 / 后期修补）项。
- `REVISE`：存在 `blocker` 项，或创作者拍板决定不放行的 `major` 重抽项；已过关片段照常交剪辑推进，复审只核验返工片段，不翻已放行片段旧账。若仅有尚未拍板的 `major` 项，在报告中并列重抽改法与留用/切镜替代方案供创作者定夺。
- `PROVISIONAL`：已看片段无阻断硬伤，但仍有关键片段尚未查看到（一次性列清待看片段与时间段）。

## 二、问题归因与返修尺度（`REV-08`、`REV-10`）

1. **先分清垫图毛病还是出片毛病**：
   - **参考素材本身的问题**：输入参考图底图自带旧水印、杂字、五官模糊、服装画错或空间透视歪斜——写再多防崩提示词也救不回来，直接退回 `$short-drama-assets` / `$short-drama-image-prompts` 换图、裁修或重出设定图。
   - **生成阶段的问题**：垫图干净合规，但在当前提示词、挂图顺序或模型参数下出现动作超载、参考脱绑换脸、运镜冲突或吞台词——针对当前项目与模型配置定位具体字句（结论不跨项目当成死规矩硬套）。
2. **区分“探索试拍单改一项”与“明确错漏一并修完”**：
   - **探索性试拍归因**：试拍重难点镜头（多人调度、复杂走位、手部交接、高反差夜景）出现原因不明的抽风时，优先每次只调整一个变量（如拆短动作、换挂图组合或精简背景词）以便看清哪一处生效。
   - **明确错漏返修**：已经一眼看清的多处确定性错漏（如漏绑角色参考图、台词抄漏半句、运镜前后矛盾、道具拿错左右手），在**同一轮返修中一次性全部修完**，写明修改点与不得误伤的保留内容，绝不机械拆成多轮折腾。
3. **原样重抽与结构重拆的取舍（`craft_default`）**：
   - 垫图与提示词查无明显问题、属模型偶发抽风时可先原样重抽；经验上同一输入连续原样重抽一两次仍反复冒出同一个硬伤，往往说明单镜动作容量超载或写法撞上模型短板，宜及时转为**局部改词**或退回分镜**拆镜重排**，不要往提示词末尾硬塞“高质量、保持一致”等空话盲抽。
   - 若改词与重抽后某个镜头仍迟迟难以生成，立即停下反复试错，列出三条出路请创作者拍板：① 勉强留用现有素材并靠剪辑切点藏拙；② 将该镜承载的信息挪给前后相邻镜头交代；③ 直接删掉这一镜——**前提是该镜不承载关键因果推进与必读台词；若涉及关键剧情信息或台词，必须先完成信息转移或同步更新《分镜.md》的未拍说明，严禁一删了事留下剧情断层**。

## 三、要求优先级与改稿防漏把关（`REV-09`）

压缩提示词字数、局部返修或重排 `GROUP-...` 多镜合生分组时，按由高到低的优先级守住底线：

1. **剧本已定的核心事实、逐字台词与必读画面文字**
2. **分镜已定的本镜目的、起止状态与镜头时长**
3. **视觉设定版本与跨镜连戏状态**
4. **创作者拍板的画风方向与模型模式配置**
5. **目标模型的提示词语法与能力边界**（模型做不到上层要求时挑明汇报并提替代拍法，不悄悄删戏糊弄）
6. **次要环境点缀与画质修饰词**

每次改词或重拆合生分组后快速复核四件事：① 剧本动作、反应与分镜总时长/合生分组覆盖（`SHT-16`、`VID-15`）是否仍严丝合缝；② 首尾帧是否守住各自静态瞬间（`SHT-17`），未指望模型靠首尾两帧自动脑补复杂关键过程；③ 本镜原本立住的构图、光影与表演亮点未被改稿误伤；④ 局部补拍或备选版是否标清了与主镜头的关系（`VID-12`）。遇到缺前置材料（如某镜印字尚未定稿）时，只拦下依赖该字样的直出真字镜头，其余环节照常审理。

## 四、整集成片专项加查

- **跨切点声画衔接与交付响度**：顺着《剪辑单.md》的 `CUT-...` 顺序通看成片，允许对白与环境声借 J-cut / L-cut 跨切点自然过渡；实测响度落在项目声明的 `交付响度` 容差之内即放行。
- **按镜序拼图查空间与比例连戏（`craft_default`）**：审批量首帧图、生成素材或成片切片时，可按镜序把各镜首尾帧拼成缩略图一览表，并排对照《分镜.md》场景站位、地点图、《视觉设定.md》与角色设定，逐镜排查背景左右水平镜像翻反、固定陈设忽近忽远、入画固定物落在人身上的高度跳变或同框及跨镜人物身高比例失真；尾段跳变优先走「裁切避让」，首帧即错或全程穿帮归入「建议重抽」或「必须重新生成」。
