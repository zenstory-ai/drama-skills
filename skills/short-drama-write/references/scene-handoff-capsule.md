# 单集跨上下文交接摘要

长单集分批续写时，在**当前会话上下文**维护一份最小交接摘要，不另存文件；`剧本.md` 仍是唯一剧本权威，摘要与正文冲突时以正文为准。

## 记录项

- 当前集号和最后完成的场景 ID；
- 上一场结束时仍影响后续的地点、在场人物、知识、关系、伤势、持物与风险；
- 已建立但尚未兑现的铺垫与回报；
- 下一场已确定的功能与退出状态（冲突场景含目标、反对与转向）；
- 会改变下一段写法的未决分叉。

不复制正文、角色小传、视觉设定或旧节拍。

## 恢复步骤

1. 读取当前 `剧本.md` 最后一个已完成场景及相邻上下文；
2. 对照摘要核对退出状态、未兑现义务与下一场目标，丢弃已过期信息；
3. 只读取下一场直接依赖的分集规划与连续性事实，不预加载无关引用；
4. 写完新场景后刷新上下文摘要，整集完成后删除。
