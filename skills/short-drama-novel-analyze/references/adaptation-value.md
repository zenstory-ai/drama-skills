## 这一步在回答什么

本阶段根据前面的功能提取，判断哪些剧情单元能直接用于竖屏短剧，哪些需要换载体，哪些应舍弃。

判定对象是**剧情单元**，不是章，也不是情节点。判定的原始依据是 S2（逐章提取）每章写下的
[载体记录](chapter-extraction.md#载体记录)：通道栏走可见行动或对白的，多半能直接成立；
走心理叙述或叙述者旁白的，需要换载体或根本换不了。

## 三类判定

每个单元落进且只落进一类：

| 判定 | 含义 | 后续 |
|---|---|---|
| `screen_ready`（可直接拍） | 关键戏剧作用已由可见行动、可听对白或空间对峙承担 | 直接进候选集 |
| `needs_carrier`（需换表现方式） | 戏剧作用立得住，但原文靠心理独白、叙述总结或背景铺陈传达 | 必须写出新的画面/声音载体，否则降级 |
| `prose_only`（仅限文字） | 效果依赖纯文字叙述诡计或抽象思辨，屏幕上无法兑现 | 明说放弃了什么 |

长段内心权衡、叙述性诡计、日常章里暗藏的关键设定或远距离伏笔回扣，都需要先判断能否保住其戏剧作用。
能用当场行动、对白交锋、物证状态或信息揭晓顺序承载时归 `needs_carrier`；确实依赖纯文字叙述诡计、找不到可行屏幕做法时才归 `prose_only`。

**不要把 `prose_only` 悄悄改写成 `needs_carrier`**。 承认放弃比假装能拍便宜得多——
假装的代价会在分镜阶段才暴露，那时整条链都已经建在上面。

## 载体替换

`needs_carrier` 的单元逐个写：

- **原载体**：原文靠什么传达（抄 S2 载体记录里的通道栏）；
- **新载体**：可见行动 / 物证 / 空间关系 / 对白策略 / 第三方反应 / 简短反差 `[VO]`，任选但要具体到谁做什么；
- **保住了什么**：原先要交代的戏剧作用，逐项对上；
- **改变或失去了什么**：不写「无」。总有东西变了，写不出来说明还没想清楚。

替换后核对观众能否通过新载体感知原功能。网文常见的第一人称回顾、设定百科说明与“脑中轰然炸响”式顿悟，不能靠直接套上 `[VO]` 充当新载体，而要按它在原文里的实际作用改写成当场动作、物证或反差旁白：

| 原著常见写法（通道） | 伪替换（照搬或机械外化） | 有效载体替换或判定 |
|---|---|---|
| 整段回忆十年婚姻如何被丈夫一家吸血：丈夫月薪六千却让她独自养家、婆婆装病住私立医院、小姑子在公司挂名白拿两万月薪（叙述者旁白 / 心理叙述） | 让主角坐在车里闭眼闪回五段往事，或站在客厅念一段“我忍了你们十年，今晚梦该醒了”的长独白 | `needs_carrier`：砍掉干坐回忆，拆进两场当场动作——先拍她坐进车里直接打电话停掉丈夫副卡、重置别墅门禁；再拍次日小姑子大闹财务部要支两百万时，她把厚厚一摞审计单砸在桌上：“挂名三年白拿七十二万工资，虚报假发票八十六万——签字可以，先跟门外经侦把这笔账算清。”损失长篇细腻心路，把十年旧账全变成当场能看清的动作与物证 |
| 主角在心里逐条盘算对手话里的破绽（心理叙述） | 在动作行写“她心中冷笑，瞬间看穿了他的诡计”，或连插四句心声 | `needs_carrier`：改成主角停下签字动作、目光落在对方刚交来的单据背面并追问漏盖的印章或时间差，让破绽落在停顿、视线、物证与对手反应上 |
| 轻喜/误解反差：主角表面乖巧洗碗，心里发狠“等本座恢复修为定将此地夷平”，紧接着三百字科普缸中神水来历（心理叙述 + 设定说明） | 要么把心声与设定科普整段删光变成闷头洗碗的哑剧，要么硬塞一个递玉佩亮身份的动作 | `needs_carrier`：砍掉三百字设定百科，保留“踮脚踩着小木凳使出浑身解数也提不动木瓢、震得虎口发麻”的可见阻力，并配一句短促冷冽的 `[VO]` 反差吐槽；用“画面吃瘪 + 画外放狠话”保住喜剧反差 |
| 情感/年代认知差：主角刚看清信纸上写给旁人的道歉真话，伴侣却捡起信纸、熟稔背出哄她三年的深情假话并伸手探她额温（心理叙述 + 对白） | 改成主角当场掏出放大镜或甩出一纸协议大声斥责，把克制的寒心改成爽剧打脸 | `needs_carrier`：用 `[画面文字]` 拍清信纸上的真话，叠伴侣温和背诵假誓言的声音；主角在他伸手探额头时不动声色退开半步，可配一句简短 `[VO]` 点破“这句词他背了三年”，保住文字与口头错位的刺痛感 |
| 靠叙述者隐瞒视角人物性别或相貌制造整章误导（文字诡计） | 强行拍成正常镜头，指望观众看不出画面里是谁 | `prose_only`：演员一出场即暴露外观，文字叙述诡计在画面上自然失效，直接标明放弃该诡计并改由可见悬念替代 |

## 制作负担

按已接受的制作形态估，不设跨项目阈值。逐单元记：需要几个人物同框、需要哪些不重复的
空间、有没有群戏、动作或特效、可读文字、跨时间的造型变化。

这不是预算表，是**改编排序的依据**：同样是 `screen_ready`，负担低的单元先进候选集。

## 桥段标签

给每个单元打桥段标签，命中就标，逗号分隔。标签的用处是让 `$short-drama-develop`
能按题材检索，也让重复的桥段一眼可见——同一个桥段在一本书里出现五次，
改编时要么是卖点，要么是拖沓，这个判断需要先能数出来。

| 题材 | 常见桥段 |
|---|---|
| 都市/言情 | 先婚后爱、破镜重圆、暗恋拉扯、欢喜冤家、错位乌龙、双向救赎、追妻火葬场、契约婚姻、打脸、马甲掉落、萌宝助攻 |
| 玄幻/修仙 | 废柴逆袭、越级战斗、夺宝、护短打脸、绝境翻盘、机缘逆天、反差收徒 |
| 历史/种田 | 先知先觉、改变历史、科举经商崛起、攒钱起家、守艺兴家 |
| 悬疑/无限 | 信息差、规则怪谈、复盘解谜、设局反制、身份揭穿 |
| 系统流 | 任务奖励、签到、面板升级、强制任务、积分兑换 |
| 重生/穿越 | 前世复仇、改命、身份调换、双重生、未卜先知、年代逆袭 |
| 世情/家庭 | 代际和解、照料羁绊、邻里人情、守艺护家、偏心反击、维权立界、自我觉醒 |

这是**可扩展的种子表，不是封闭枚举**。不在表内但本书确有的桥段照实写；
凑不出标签就留空，不硬凑。

## 分集候选

按**爽点分布、当集戏剧结果与精确交接**切，不按章号、字数或平均分配。先读
[爽点表](aggregation-and-entities.md#爽点表)：候选集的边界跟着爽点走，没有爽点的长间隔
并进相邻候选或标为可删，而不是单独成集；排名靠前、落在后文的高光写进交接摘要，
由 `$short-drama-develop` 决定是否提前或做冷开。章与集不是 1:1——一章撑不起一集时合并，
一章里有两个大爽点时可以拆。

一个候选集必须能回答：

1. 进入时观众已经知道什么；
2. 本集内兑现了哪一部分承诺（不能一条都不兑现）；
3. 出去时留下的具体决定、危险或问题是什么；
4. 下一集必须继承哪些事实。

只留钩子、不兑现任何承诺的集，观众会在第三集停——这是分集候选里最常见的错。

每条候选写进 `episode-candidates.jsonl`，字段见
[分集候选样例](../assets/episode-candidate.example.jsonl)。每条都带：来源单元与章号区间、
承担的功能、判定类别、桥段标签、承接的爽点（`payoffs`，没有就写空并说明这一集靠什么留人）、
未决项、以及 `creator_acceptance: pending`。

**集数不由本技能决定**。 候选可以多于、也可以少于创作者设定的集数；差多少要明说，
由创作者与 `$short-drama-develop` 决定合并还是拆分。

## 回填快评

`adaptation-value.md` 开头写一段**快评对照**：S1 的 `triage.md` 里哪几条判断被全量结果
推翻了，以及为什么。逐条对上六段：故事框架、三类判定比例、开篇替换点、制作负担量级、
三处风险、分集量级。

**其中「三类判定比例」两边的判定对象不同**：S1 抽样判的是章，S5 判的是剧情单元，
两者之间没有换算，也不该造一个——一个单元里的章可以分属不同类别，按章数加权回推
只会得到一个看起来精确的假数字。这一条按方向对照即可：抽样说「多数章走心理叙述」，
全量结论若是「多数单元需要换载体」，就是印证；若方向相反，写清是抽样偏了还是
全书后段变了。其余五段仍逐条对上。

快评全部得到印证时也写明对照结果。

## 交给 develop 之前

自检五条：

- 每个 `screen_ready` / `needs_carrier` 单元都能在候选集里找到落点，或明确说明为什么没有；
- 每条候选的功能都能回溯到某个单元、某条情节点的白描；
- 硬事实（等级、数值、出场章、谁说的话）都能回到白描或原文，回不到的已改成「原文未明确」；
- `prose_only`、被跳过的章与散落清单都出现在交接摘要里，不只是躺在某个文件深处；
- 没有把本技能的判定写成结论——它们是候选，等创作者接受。

交接摘要给创作者读，说清：拆了多少章、跳过哪些、多少单元分别落进三类、
切出多少候选集、排名前列的爽点落在哪几个候选、最大的三处改编风险、快评里被推翻的判断。风险要具体到单元，
不写「改编难度较大」。
