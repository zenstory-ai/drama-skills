# 生产剧本格式方言

本套件的默认规范格式见 [screenplay-format.md](screenplay-format.md)，通用剧作与对白手艺见 [script-craft.md](script-craft.md) 和 [dialogue-craft.md](dialogue-craft.md)。本文档定义行业常见的三角符号制作稿方言，服务两个场景：

1. **规范化入口**：识别创作者来稿中的场次、符号、人物与括注，准确映射到标准格式（规范化流程见 [screenplay-format.md](screenplay-format.md#7-现有文本的规范化入口)）；
2. **交付偏好（`taste_option`）**：创作者明确要求按三角符号制作稿格式交付时使用。

## 一、格式语法

```text
<集标题（仅项目使用集标题时）>
【场景 1：地点 - 内/外（日/夜）】
【人物：甲、乙、丙】
△ 环境陈述或空镜（景物、氛围、光线）
▲ 人物动作（可见行动、反应或状态变化）
【角色名】(表演括注)：台词
…
△ 空镜：<只有转场需要可见画面时才写>
【场景 2：…】
```

- **符号分工**（同一项目内保持一致）：
  - `△` **只用于环境陈述与空镜**：`△红烛高燃，喜堂内一片死寂。`
  - `▲` **只用于人物动作**：`▲李威一把捏住随从甲的手腕，将密奏强行抽走，随从甲手腕被拧得发红。`
  - **台词行**：`【角色名】(表演括注)：台词`，全角冒号，括注可省略。
- **时段槽位**：常用 `日`、`夜`；补充可用 `晨`、`黄昏`、`傍晚`、`深夜`、`凌晨`、`幽暗`（光线当时段用）、`时间不明`。
- **群演写法**：`村民甲/乙/丙`、`员工A/B/C`、`修士若干`、`观众*N`。只承担人数或背景反应的群演不单独起名，避免在下游产生冗余人物资产；一旦某群演有台词、被追踪或跨集回归，须拆出建立独立角色身份。

### 兼容变体（读旧稿须识别，写新稿不用）

| 槽位 | 常见形态 | 较少见形态 | 识别要点 |
|---|---|---|---|
| 场景头 | 场次编号 + 地点/时段/内外三槽以空格分隔，三槽顺序不固定 | 逗号或斜杠分隔；`场：N-N`+`景：…` 双行式；`【场次】`+`【场景】` 键值块 | 先认出各词归属槽位，不依赖槽位先后顺序 |
| 场次编号 | `集号-场序` 写在场景头行首 | 单序号 `N.`；无编号；编号并入括号或冒号 | 先切出编号，再区分集号与场序 |
| 时段 | 单字 `日`/`夜` | 晨、黄昏、傍晚、深夜、凌晨等细分词 | 光线词有时被当时段用 |
| 内外 | 单字 `内`/`外` | `内景`/`外景` | 与地点连写时需切分 |
| 人物行 | `人物：A、B、C`，顿号分隔 | `出场人物：`、`人：`、`角色：`；空格或逗号分隔；整行缺失 | 常紧跟场景头，但并非总在第二行 |
| 动作行 | 行首三角符号，**不编号**；或无任何符号、动作直接写成段落 | 其他符号（`*`、`◆`/`◇`）；逐拍编号 `1▲…15▲`（私有习惯，不用作位置引用） | 对照人物行和 `名：台词` 行识别其余段落职责 |
| 台词行 | `角色名：台词` 与 `角色名（情绪）：台词` | `角色名：（情绪）台词`（括注在冒号后）；`【角色名】` 方括号形式 | 括注在冒号前后均需识别；无括注不等于信息缺失 |
| 独白标记 | 角色名后紧跟 `OS`/`VO`，括号可有可无 | 小写 `os`/`vo`；`V.O.`/`O.S.`；`（画外音）`、`（内心）`；句尾标记；与情绪词并列在同一括注 | 剥去末尾 OS/VO（不区分大小写与括号）再比对本场人物，归入同一角色画外通道 |

- **缺失字段不猜补**：旧稿缺少场次编号、时段或内外时留空交创作者确认（补出的时段直接影响布光）。
- **三角符号按内容识别**：许多旧稿通篇只用一种三角符号写全部动作，读取时按内容区分环境与人物动作，不按符号反推。
- **括注按自由文本读取**：不按封闭词表校验。

## 二、拍（beat）与括注写法

- **动作拍（`▲`）**：记录最小可读行动、反应、信息或状态变化，不要求每拍机械凑齐“主体+动作+受体+结果”四要素：
  ```text
  ▲李威将密奏撕开，碎片落到王怀安面前。
  ▲王怀安没有去捡，仍把手放在扶手上。
  ```
- **悬疑停顿短句（`△`）**：可单独成行控制节奏：
  ```text
  △ 嗒。手电筒打开。
  △ 光柱停住了。
  ```
- **表演括注**：只保留能与本句同时完成的表情、微动作（`(上前握住她的手)`）或语音方式（`(低声)`、`(方言)`）；台词中段可插动作括号：`回国？……（抬眼看向身旁）这三百年……`（`SCR-08`）。若括注包含独立动作、道具交接或新状态结果，必须拆为独立 `▲` 拍，不按字数机械截断。

## 三、画外音与【】指令系统

| 记法 | 语义与边界 |
|---|---|
| `角色（OS）：` | 创作者明确选择的内在声音或同场画外音；不把所有心理解释自动改成 OS |
| `角色 VO：` | 非现场或叙述声音；声源、时空与画面关系须清楚 |
| `规则VO：` | 已接受的系统或世界声音身份；仅在题材与声音方案已建立该身份时使用 |

常用内联指令：`【特写】`、`【音效：砰！砰！砰！】`、`【字幕：…】`（人名/地名/等级标注）、`【闪回】…【闪回结束】`（本人记忆）、`【闪入：场景 内 夜】…【闪入结束】`（他人往事插叙）、`【转场】`、`【空镜：…】`、`【卡点】/【钩子】`（集尾定格）。系统信息是走 `规则VO`、可见文字还是分阶段展示，严格服从项目已接受的文字与声音方案，不自动补字幕或重复播报。

## 四、范例

### 范例 A：对峙场面的方言写法

```text
11-1 边关监军大帐 夜/内
人物：王怀安 随从甲 李威
△油灯跳动，帐外风雪呼啸。
▲王怀安坐在虎皮交椅上，手指有节奏地敲击木制扶手，发出笃笃声响；随从甲双手捧着明黄色绢帛，躬身退后。
王怀安：本监军的密奏，三日内必须送到长安。
随从甲：大人放心，卑职这就去驿站。
▲随从甲刚转过身，营帐门帘被猛地掀开，寒风灌入；李威身披染血战甲大步踏入，铁靴踩在地面发出沉重声响。
李威（厉声）：慢着！
随从甲（声音发颤）：李、李将军？
▲李威一把捏住随从甲的手腕，将密奏强行抽走，随从甲手腕被拧得发红；李威展开密奏扫了一眼。
李威（冷笑）：前线断粮三日，监军大人倒有闲心上奏参我拥兵自重？
王怀安（沉下脸）：李将军，这是本监军呈给圣上的机密，你无权——
▲李威双手用力将密奏撕成碎片，抓起一把碎绢重重扬在王怀安脸上。
李威（俯身逼近）：三万将士在雪地里啃树皮，你再敢拿通敌的罪名往老子头上扣，别怪本将军不给你体面！
▲王怀安猛地往虎皮交椅背上一缩。
王怀安（声音发抖）：你、你敢对本监军……
▲李威呛啷拔出腰刀，刀尖直抵王怀安咽喉。
李威：老子在死人堆里砍了二十年，还怕你这支笔？
▲王怀安瞳孔骤缩，额角渗出冷汗。
▲李威收刀入鞘，拂袖转身大步离开，帐门帘剧烈摆动。
▲王怀安死死攥紧交椅扶手，指节发白，盯着满地碎绢。
王怀安（从牙缝里挤出声音）：好，好得很。
```

### 范例 B：规范化最小对照（只动结构与符号层，逐字保留台词）

原稿：

```text
△礼成后，宾客散去，苏卿润走到两人面前，拍了拍萧尘渊的肩膀。
苏卿润：好好待她。
萧尘渊：放心，我此生定不负她。
```

规范稿：

```text
▲礼成后，宾客散去，苏卿润走到两人面前，拍了拍萧尘渊的肩膀。
【苏卿润】：好好待她。
【萧尘渊】(目光坚定)：放心，我此生定不负她。
```

人物动作 `△` 改为 `▲`，台词加 `【】` 归属并逐字保留；若新增括注（如 `(目光坚定)`）可能改变人物态度，须与纯结构调整分开展示并由创作者确认。

## 五、常见来稿异常与处理

1. **小说段落直贴**：区分可表演反应（如“他笑得合不拢嘴”可演，直接保留）与纯心理说明（与制作稿分开或按创作者选择外化，不自动全塞进 OS）。
2. **PDF 粘贴污染**：清理行中异常断行与全角空格污染（如 `"灰 雾 降 临"`）。
3. **场头/人物/动作挤成单段**：按槽位切分场景头、人物行与首条动作拍。
4. **逐拍编号错漏**：项目使用编号拍时，校验连号并修正重号或漏号。
