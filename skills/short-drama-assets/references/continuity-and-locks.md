# 跨场连戏与连戏锁指南

## 1. 跨场连戏状态记录（`CON-01` / `CON-02`）

`视觉设定.md` 只管跨场次、跨集数的状态接力，不在设定文档里反向抄录下游 `SHOT-...`、`IMG-...` 或 `MOTION-...` 台账：

- **前后衔接与变化有据（`CON-01`、`CON-02`）**：相邻场次的收尾状态与下一场开场状态自然接顺；人物伤势、持物归属、道具开合破损、昼夜晴雨与室内亮灭灯都必须有剧本动作或场次过渡支撑（上集末尾带伤而本集未提痊愈时，默认延续带伤或标待创作者拍板，不凭空复原）。
- **只记影响后续接戏的净变化（`craft_default`）**：只记录影响后续场次、提示词或跨集交接的状态变化，在对应人物、造型、地点或道具条目的 `本集状态` 下简明写清「变化前后状态 + 触发场景 ID 与原因 + 起止有效范围（跨集延续时注明本集结束状态）」，无需每场重抄不变特征，也不在每个条目里反向抄录下游镜号台账。
- **非线性叙事例外（`taste_option`）**：明确标出的蒙太奇、时间省略、梦境幻觉、回忆闪回或主观画面可按创作意图打破常规连戏，点明对应的历史造型或主观状态及进出节点，不覆盖主时间线的当前状态。

示例（跨场与跨集收束写法）：

```markdown
- 本集状态：SC004 开场扣合、内装白瓷号牌搁于柜台下层；SC004 顾禾开匣取牌后保持敞开空匣（本集结束仍敞开搁在柜台面，白瓷号牌由顾禾转交魏叔随身收存）。
```

## 2. 跨镜连戏锁与下游适用范围（`CON-07`）

`- 连戏锁：` 用于锁死跨多镜或设定图反复出现、一旦画偏就会穿帮的静态核心外观（如主力制服颜色版型、关键信物主色材质）。全集精选几处关键服装或核心道具即可，不必给每条 `外观特征` 都加锁。

### 下游生效边界

- **必须原字带入 `锁定词` 的位置**：
  1. 连戏锁点名的**静态图片提示词**（`图片提示词.md` 对应 `IMG-...` 的 `### 可复制提示词`）；
  2. 锁定范围内镜头的**首帧提示词**（`分镜.md` 的 `### 首帧提示词`）；
  3. **未锁住该外观的视频提示词**（`视频提示词.md` 中无参考图的文生视频，以及仅挂了 `空间布局`、`风格` 等未锁住该外观的图生视频与合生分组）。
- **已锁外观的图生视频自动豁免**：`输入参考图` 已挂载本镜 `起始帧`（含 `REF-...`，或指向本镜及首帧已带该锁定词的跨镜复用 `PLAN-...`），或已挂载对应设定条目的 `主体` / `造型状态` 参考图（`PLAN-...` 指向该锁 `图片提示词项：` 中的 `IMG-...`，或槽位 `《<名称>》` / `控制：` 含该《视觉设定.md》条目名，或 `REF-...` 指向该条目已登记的参考图路径）时，自动豁免静态 `LOCK-...` 锁定词，视频动作提示词聚焦动态表演与运镜即可，不必重复硬塞全身服装描述。

### 语法与条目挂载位置

写在 `视觉设定.md` 对应条目下（无需回抄下游 `SHOT-...` 镜号列表，推荐直接用 `镜头：入画`）：

```markdown
## 造型 · 江晨松枝绿常服

- 外观特征：现行松枝绿翻领常服，浅绿衬衣配深绿领带，直筒长裤与黑皮鞋。
- 连戏锁：LOCK-JIANGCHEN-DRESS《江晨松枝绿常服》（镜头：入画；图片提示词项：IMG-JIANGCHEN-SHEET）· 锁定词：pine-green lapel service jacket
```

- `LOCK-...`：本集唯一编号；`《<名称>》` 写明所锁外观对象名称（支持中文或外文）。
- `镜头：`：默认填 `入画`（表示仅对该设定条目在分镜 `出场设定` 中实际入画的镜头生效），也可填 `全集` 或用 `、` 分隔的指定 `SHOT-...`（三者不混写）。`creator_markdown_check.py` 仅校验连戏锁声明语法、`LOCK-...` 唯一性与显式点名的 `SHOT-...` / `IMG-...` ID 是否存在；**服装连戏锁务必挂在 `造型` 条目下并填 `入画`**，下游《分镜.md》在该套服装实际入画的镜头 `- 出场设定：` 中显式列出 `造型「<名称>」` 以界定生效范围，手部或眼部特写看不到衣服时只列 `人物「…」`、不列 `造型「…」`，供审稿区分是否应保留服装锁定词。
- `图片提示词项：`：可选，填需同步锁定的 `IMG-...`（多项用 `、` 分隔），无需约束设定图时整段省略。

### 锁定词写法与复核边界

- **精炼静态名词短语**：用与下游提示词一致的语种写「颜色 + 材质/款式 + 物件」（如 `pale blue chunky knit wool sweater`、`chipped white enamel mug`），不带句号、动作时态、临时方位（如 `in her hand`、`on the desk`）或空泛画质词。生图/首帧（`short-drama.json#/format/prompt_language`）与视频（`video_prompt_language`）语种不一致时，优先用通用专名型号，或直接靠视觉设定文字说明而不挂跨语种逐字锁。
- **原字保留与语义复核（`CON-07 · reviewed_invariant`）**：`creator_markdown_check.py` 不对提示词正文做字面扫描，仅校验连戏锁声明格式与显式 `SHOT-...` / `IMG-...` ID 存在性；生效范围内的原字保留（不随意增删改词、不以反义或否定排除写法充数）以及已锁外观图生视频的豁免判定，由 `short-drama-review` 结合上下文按 `CON-07 · reviewed_invariant` 审定。
