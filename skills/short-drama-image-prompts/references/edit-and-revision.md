# 局部编辑与自然语言修订

## 1. 局部编辑差异四要素（`IMG-06`）

**`structural_invariant` IMG-06**：无论是产出局部编辑提示词（`edit_delta`）还是按自然语言修订既有 `IMG-...` 条目，都不得越权改写 `视觉设定.md` 拥有的身份、固定地理或状态事实（如请求“把这扇门移到另一面墙”，须先退回 `$short-drama-assets` 改地理并交分镜核对）。

每条局部编辑必须写清四个无冲突要素（多个不相干目标拆为独立编辑；复杂重构改走新变体设定板）：

1. **目标（Target）**：元信息指向准确 `IMG-...` 条目，实际待编辑图片另用 `REF-...` 绑定（未提供图片时注明缺口）；正文明确点出修改对象与具体区域（禁用“改背景”“让她更狼狈”等宽泛指令）。
2. **变化（Change）**：按位置、方向、范围、程度与材质/色彩结果写明可观察变化（如“右袖肘部以下呈雨水浸湿后的深色，衣料贴合但无撕裂”）。
3. **保持项（Preserve，`reviewed_invariant`）**：先显式列出最易被误改的高价值事实（面部/体态身份、未变造型单品、固定地理、道具轮廓与文字、构图机位、光向、未选区域），最后才可用“其余内容保持不变”收尾。
4. **连续性影响（Continuity impact）**：指明对应的 `视觉设定.md` 状态及受影响的 `IMG-...` / `SHOT-...`（无影响则写“无”及理由）。

## 2. 自然语言修订与防覆盖流程

对创作者的自然语言修改请求（如“把工作服换成深蓝，保留脸和袖口油渍”）：
1. 读取当前 `视觉设定.md` 对应条目与 `图片提示词.md` 的目标 `IMG-...`（若文件已被人工或其他编辑改动，先重读并合并人工新增的有效语义，严禁直接用旧缓存覆盖）。
2. 若请求为“更有电影感”等抽象词，提供 2–3 个可观察的构图、光比或色彩候选供创作者选择，不堆砌风格词。
3. 展示简短修订预览，获确认后更新该 `IMG-...` 并列出需同步检查的 `SHOT-...` / `IMG-...`：

```markdown
### 提议修改 `IMG-...`
- 变化：深灰蓝工作服 → 深蓝工作服
- 保持：脸型、服装剪裁、右袖口旧油渍形状与位置、背景、构图、光向
- 影响：仅当前造型提示词；若 `视觉设定.md` 尚未登记深蓝变体，先交 `$short-drama-assets` 更新

**新正文预览**
> ...
```
