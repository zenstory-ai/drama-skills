# 交付与验收

检查实际交付文件，并区分实测结果、人工判断和未测项。

| 项 | 怎么核对 |
|---|---|
| 时长与切点 | 对照实际渲染区间、帧边界和用户时长要求 |
| 内容覆盖 | 对照分镜和视频提示词，必要内容有承载，未采用镜头有原因 |
| 台词 | 在成片上回听，必要时转写辅助，逐句对照剧本 |
| 边界帧 | 查看剪辑点前后，检查意外黑白帧、画面断裂和漂移 |
| 声音 | 回听接缝、对白清晰度与已声明静默；测量整片响度 |
| 字幕 | 检查逐字内容、发声时间、字号、折行和画内文字避让 |
| 画内文字 | 按剧本与视觉设定的文字政策检查载体、可读性和指定文字 |
| 画幅与帧率 | 探测输出文件，对照交付规格 |
| 接镜色彩 | 在同场景、同光态下比较可比区域，确认校正没有过冲 |

`verify` 只提供部分技术测量，不能替代回听与画面检查。
分段色彩观测按当前剪辑单读取中间分段，报告平均亮度和蓝减红像素值；它不代表成片局部区域的
接镜残差，也不要求各场景接近同一均值。改动剪辑单后先重新渲染，再测量并查看实际切点。
发现有意黑场、静默或光态变化时按创作意图判断，不因数值异常直接判错。

## 交付

给出成片、剪辑单、可继续编辑的中间文件，以及外部混音或字幕工程（如使用）。
说明是否满足用户要求、仍有哪些内容缺口和取舍；测不了的必要项目写明原因。

需要补素材、改台词或改分镜时，指出对应镜头与发生时间并交给负责阶段。
渲染成功只证明工具完成执行，成片的内容判断需要观看和回听；正式审查由
`$short-drama-review` 或创作者进行。
