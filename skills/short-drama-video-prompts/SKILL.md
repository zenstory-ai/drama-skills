# 短剧视频与配乐提示词

把已定稿的分镜和首帧写成可直接复制的 `剧集/<EP>/视频提示词.md`，或按要求起草成片配乐与主题曲提示词。

## 快速开始

```text
用 short-drama-video-prompts 技能把 EP001 分镜逐镜写成可直接复制的视频提示词
```

## 模式选择（正式项目 vs 轻量起草）

- **轻量 / 草稿模式**：用户仅要求为单场或几个镜头独立起草视频动作提示词、配乐提示词（无完整短剧项目目录）时，直接输出清晰的镜头说明与可直接复制的提示词正文，**不强制套用完整项目的 `MOTION-`/`GROUP-`/`REF-`/`PLAN-` 机读字段**。
- **正式项目模式**：落盘 `剧集/<EP>/视频提示词.md` 或衔接跨文档校验与批量投产时，完整遵循 [视频提示词格式规范](references/format-spec.md)。

## 入口与边界

视频提示词负责描写镜头从起点到终点的动作、表演、道具变化、运镜与声音，不私自改动分镜定好的起止状态与镜头时长。

- **按分镜「输入参考图」分流**：
  - **图生视频（含 `REF-...` 或 `PLAN-...`）**：承接分镜参考项，可按目标视频模型模式与本镜焦点合理增减设定板、承接帧或参考音频，保持 `顺序`、`用途`、控制与不得控制范围清晰。`PLAN-...` 供外部工具按序挂图；需交 `short-drama-produce` 技能内置投产时先落盘实图并改绑 `REF-...`。
  - **文生视频（`无（文生视频）` 或 `无`）**：填写非空「开场画面」（点名条目须与分镜 `出场设定` 一致），并在可复制正文中自然交代人物、造型、地点陈设、景别焦段与光线。
  - **参考图待补（`待补参考图`）**：先在用户输入、`剧集/<EP>/制作成果/` 与已引用媒体中核对可用实图（不靠相似文件名猜图）；仍有缺口且创作者未要求停笔等图时，转为 `PLAN-...` 挂图计划照常成稿并附挂图清单，不擅自改成文生视频。无论改绑 `REF-...` 还是转为 `PLAN-...`，均请 `short-drama-storyboard` 技能同步更新《分镜.md》对应镜头。
- **模型档位与双语配置**：
  - 创作者可读说明跟随项目语言；读取 `short-drama.json` 目标模型配置，**未指定具体模型时直接采用通用档 `generic` 成稿，不停工追问**（新点名未入配置时交 `short-drama` 技能记录或在文首注明）。
  - 视频提示词正文语种优先跟随 `short-drama.json#/creator_authority/production_profile/choices/video_prompt_language`，未声明时回退到 `short-drama.json#/format/prompt_language`（无配置文件时按目标模型惯例或用户当前语言）；角色对白、VO、OS 口语语种始终按剧本与声线设定执行。

## 工作流

1. **核对参考素材与生成模式**：确认每镜走图生视频（按参考项 `用途` 组合与模型互斥规则转换为首帧、首尾帧或多图参考）还是文生视频。相邻镜头默认独立按各自首帧或参考图生成，**不默认锁死为“待续接、不可提交”**；仅在跨镜硬切接同一连续动作需像素级咬合或创作者明确要求视频续写时，按 [运镜、现场声与跨镜连戏](references/camera-audio-continuity.md) 走成片或真实末帧续接。
2. **核算时长与发声窗口**：确认每镜时长与对应 `SHOT-...` 完全相等且落在模型单次支持区间内；含对白、VO 或 OS 时核对留给念词的有效发声窗口（见 [表演弧线与动作计时](references/performance-action-timing.md#台词时长估算)），装不下时精简次要动作或退回分镜/剧本调整。
3. **组织动作、运镜与声音正文**：按「起手姿态 → 核心动作（触发、方向、接触参照物、落点）→ 微表情与反应层次 → 运镜与焦段 → 声音与终点状态」成文。需卡切点时用互不重叠的标秒时段铺满本镜时长（`VID-04`）；项目启用多镜合生时按 [目标模型与交付配置指南](references/model-and-delivery-profiles.md) 增补 `GROUP-...` 分组（`VID-13`、`VID-15`、`VID-27`）。

## 提示词核心要求

- **参考分工与连戏锁（`CON-07`）**：已由 `起始帧` 或对应设定条目 `主体` / `造型状态` 参考图锁住外观的对象，专注描写动作与神态演变，**不重复堆砌已知静态外观，免重抄该条静态 `LOCK-...` 锁定词**；文生视频及尚未覆盖该外观的图生视频（含合生分组）仍须原字保留生效的 `LOCK-...` 锁定词（槽位匹配细则见 [视频提示词格式规范](references/format-spec.md)）。
- **声音分流与台词守真（`VID-23`、`VID-25`）**：后期配音路线（`separate`）专注画面口型与呼吸神态；音画同出路线（`same_pass`）写清声源、说话人、语种、单次逐字台词与环境底声。严禁编造《剧本.md》《视觉设定.md》《分镜.md》未声明的人物发声台词。
- **画面文字与正文纯净度（`VID-22`）**：防字幕负面词仅在易飘伪字幕的模型或含屏幕/纸页/招牌等文字风险场景中按需添加，剧本要求看清的画内文字写明字样、语种与所在物体表面；可复制提示词内不夹带文件名、路径、规则号或流程备注。

## 配乐提示词与下游衔接

- **成片配乐或主题曲**：按用户要求在《视频提示词.md》末尾单开二级标题章节（如 `## 成片配乐与主题曲`，格式见 [视频提示词格式规范](references/format-spec.md)），写明铺乐区间、剧情作用、淡入淡出时机、情绪起伏与禁用元素；歌词须取自用户来稿或定稿剧本，不自行编造。
- **下游路由**：实际调接口生成交 `short-drama-produce` 技能；跨文档格式与连戏自动核对交 `short-drama` 技能。
