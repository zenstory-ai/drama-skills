# 生成素材与成片审查

适用于 `production_outputs` 或审到成片的 `full_episode`（`REV-15`）。判断仅依据创作者提供/授权的观察记录或运行环境经授权直接查看的媒体（注明观察方法与区间）；无观察覆盖的段落一律标为**未知**。

## 一、先判每段是否完成镜头职责

逐段对照 `分镜.md` 的唯一职责、起点、唯一动作、终点和声音，判定观众能否拿到本镜应交付的信息、台词、道具与反应：

- **完成**：核心职责已交付（段内瑕疵进入第二节分流）。
- **未完成**：缺失必要信息/动作/台词/道具，或人物换脸、道具变样、画面文字错乱改变了观众读取的事实。
- **未知**：观察未覆盖职责区间（列为待观察，不作缺陷）。

## 二、四类瑕疵分流与 Finding 映射

| 类别 | 判定条件 | 严重程度 | 修订结果与负责技能 |
|---|---|---|---|
| **剪掉** | 瑕疵在可用带之外，或裁短后镜头职责仍完整 | `minor` | 写明入出点避开区间 → `$short-drama-edit` |
| **后期可修** | 挪音频对口型、替换/插补单帧、调色、修除背景小物可解 | `minor` | 写明剪辑或外部后期处理方案 → `$short-drama-edit` |
| **保留** | 正常播放难察觉，或不影响信息、连续性与理解 | `note` | 「保留，不修改（备注给剪辑）」 → `$short-drama-edit` |
| **必须重新生成** | 未完成镜头职责，无可用带、他镜无法代偿且后期无法补救 | `blocker` | 按 `REV-08` 追溯提示词并按 [项目校准](project-calibration.md) 选最小改法 → 对应负责技能（确认后由 `$short-drama-produce` 重出） |
| **剪辑补回**（仅成片） | 素材本身具备职责内容，但成片切点或后期丢失了该信息 | `blocker` | 写明需调整入出点的 `CUT-...` 或后期补救动作 → `$short-drama-edit` |

**默认非阻断项（`craft_default · REV-15`）**：单帧或不足一秒的撕裂/闪烁/边缘错位、剪辑微调即可对齐的轻微音画偏移、不影响前景职责的背景群演/小物短暂闪烁，默认归入剪掉、后期可修或保留；但若瑕疵恰好毁掉关键证据或道具首次露出的必读帧，仍判为**必须重新生成**。创作者可覆盖此默认并记入审查记录。

## 三、交付结论与重审纪律

- `APPROVE`（可交付）：每段均完成职责，无待处理项。
- `APPROVE_WITH_NOTES`（带备注交付）：每段均完成职责，仅有剪掉、后期可修或保留项。
- `REVISE`（先修再交）：存在至少一项**必须重新生成**或**剪辑补回**。修改清单只列这两类阻断项，其余已放行段落直接交剪辑推进。
- `PROVISIONAL`（待观察）：无阻断项，但存在未知段落（一次性列全待观察段落与区间）。

重出后复审只看重出段落，已放行段不再新开 finding。原样重投上限与退回规则见 [生产质量门](production-quality-gates.md)；改过内容重出后仍未完成职责时停止自动迭代，交创作者三选一（接受现状、改由他镜承担、剪掉本镜）并记入审查记录。

## 四、整集成片附加检查

- **跨切点职责与响度**：按 `剪辑单.md` 的 `CUT-...` 顺序核对成片；允许台词或信息借 L-cut/J-cut 跨切点完成。实测响度落在 `交付响度` 声明容差（含创作者已接受的超差范围）或默认容差内时，不另开 finding。
- **首尾帧拼图查空间连续（`craft_default`）**：审一批关键帧时按镜序排成联系表（contact sheet），审视频段或成片时抽取每段首、尾帧拼成一张图，对照 `分镜.md`「场景站位」、地点图与角色设定并排检查固定陈设位置、背景左右关系（防水平镜像翻转）、人物距锚点远近、固定物落在人身上的高度及人物身高比例。可靠入出点避开的跳变归「剪掉」或「剪辑补回」；起始帧或全段空间错误的归「必须重新生成」。
