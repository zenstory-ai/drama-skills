# 短剧拆解学习

把别人的成片拆成能复算的数字和能迁移的机制，再拿来和自己的剧比。

## Quick Start

测量用 [breakdown_tool.py](scripts/breakdown_tool.py)，命令见[第 2 步](#2-测量)。安装、升级或排障时运行：

```bash
python3 {技能目录}/scripts/selftest.py
```

## 开始前锁定边界

只读用户在当前会话提供或授权的材料。原片、转写、拼图和还原结果放在 `输入/对标/<REF-ID>/`，不进交付、
示例或任何会公开的文件；报告和交给其他技能的内容不写对标的剧名、人名、台词和独特桥段。
还原结果只有在对标登记为创作者自有或已获授权、并记了依据时，才能当起点交给下游。

本技能负责量、拆、比，以及在对标目录里还原对标。本项目的剧本、分镜、提示词由各自的技能改；节奏数值由 `$short-drama-develop`
提出、创作者接受后才进项目节奏档案。阶段规则见 [阶段契约](references/stage-contract.md)。

## 工作流

### 1. 登记对标与本轮问题

每部对标给一个 `REF-ID`，记来源位置、允许用途（学习 `study`、自有 `owned`、已授权 `licensed`，后两种记依据）、
是否允许把原片上传到外部模型服务、播放面（哪个平台、横屏还是竖屏）和制作形态。
写下本轮要回答的问题，例如“我们第 1 集为什么留不住人”“打斗戏节奏差在哪”。问题决定抽哪些集、
看哪些维度；没有问题时先问创作者，不要什么都量。

### 2. 测量

按 [测量与观看](references/measure-and-read.md) 抽样，用脚本测时长、切点与镜长，出代表帧拼图，
有字幕或转写就挂上去，再按系列汇总：

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure <视频...> --out 输入/对标/<REF-ID>/measure
python3 {技能目录}/scripts/breakdown_tool.py transcript <某集.measure.json> <同集字幕.srt>
python3 {技能目录}/scripts/breakdown_tool.py profile <REF-ID>=输入/对标/<REF-ID>/measure --opening 3
```

需要 PATH 上有 ffmpeg 与 ffprobe。脚本不做语音识别，也不判断好坏；数字的盲区见同一份参考资料。

### 3. 看与读

看拼图、带时间读转写，按 [拆解维度](references/breakdown-dimensions.md) 逐项记：系列与集长结构、开场、
信息载体、对白密度、镜头语法、集尾与下一集怎么接、画幅与形态。每项分开写直接观察、解释和未知。
那份资料末尾附一组实测，可用来判断手上的对标是否典型。

### 3a. 还原（需要时）

创作者要看对标的剧本、物料和提示词，或要拿自有作品做续作、重制时，按 [整集与多集还原](references/reconstruct.md)
把一集或连续多集还原成 `输入/对标/<REF-ID>/还原/` 下的一个套件项目：先看校准图定下这部剧的字幕区和字色，
脚本再测切点、字幕时间、有声区间并切出逐镜小段，
能听音轨的视频模型整集听看一遍、逐镜看一遍，两边对齐后按集序统一人物、写接缝表，再写成每集五份文件，
最后用原片回头量字错率、漏句、节奏和画面幻觉。还原出的逐镜事实也是第 3、4 步的证据。

### 4. 提炼机制

几部对标都出现、又说得清解决观众什么问题的做法，写成机制候选：观众状态、戏剧问题、可选机制、
可见效果、适用条件、失效边界、不得复制的部分。只在一部里出现的标为单一来源。机制候选交
`$short-drama-develop` 的创作参考摄取流程，创作者接受后才进写作上下文。

### 5. 和本项目对照

本项目已有剧本或分镜时用 `plan` 量计划（输出放 `项目开发/对标拆解/plan/`），已有成片时用 `measure`
量成片，和对标并排出差距表。每条差距问创作者是不是有意为之；不是有意的，按
[差距对照与出片验证](references/gap-and-learning-loop.md) 交给负责的技能。项目还没开始时，跳过本步，把实测值作为节奏档案的提出依据交给 `$short-drama-develop`。

### 6. 出片验证

负责的技能改完后，挑一段代表差距的戏，用同一模型生成前后两版（画幅相同，除非改的就是画幅），
每版至少两次，用同一把尺子再量一遍；画面判断去掉版本标记后进行。生成本身走 `$short-drama-produce` 或创作者自己的工具。

### 7. 写报告与学习记录

结果写进 `项目开发/对标拆解.md`：对标清单（只写 REF-ID、播放面与形态）、实测汇总表、机制候选、
差距表与创作者的回答、交给了谁、出片验证结果、哪些差距决定保留。下一轮先读这份记录。

## 按需读取

- 抽样、转写来源、运行脚本与数字的盲区：[测量与观看](references/measure-and-read.md)

- 差距表、交给谁、出片验证与学习记录：[差距对照与出片验证](references/gap-and-learning-loop.md)
- 所有权与规则分级：[阶段契约](references/stage-contract.md)
