# 整集与多集还原

把对标的一集或连续多集还原成一个套件项目：逐字台词的剧本、跨集统一的人物、场景与道具、
每个实测镜头一条分镜、每镜关键帧的图片提示词和对应的视频提示词，集与集之间接得上。
时间取脚本测的，内容由能听音轨的视频模型看，两边互相校正，最后用原片回头量一遍。

## 产物放哪、能交给谁

还原前确认登记里的允许用途和是否允许外传（BRK-01）。原片要上传给外部模型时，必须登记过允许外传；
没有登记时只做本机测量，看片那一遍不做。

还原层是一个单独的套件项目，放在 `输入/对标/<REF-ID>/还原/`：先建好这个目录，再用 `$short-drama`
在这里初始化，项目编号与本项目不同，标题写 `REF-ID` 加“还原”，不写对标剧名。目录、文件名和格式与普通项目相同：
`项目开发/`、`设定集/`、`剧集/EP001/` 下五份文件。它不是本项目的剧本或设定，本项目各阶段不读它（BRK-02）。
创作台会把它和你的项目并列列出；在 `还原/` 初始化之前，在对标目录里运行的项目工具会找到外层的本项目，
所以先初始化再写文件。

- 允许用途是 `study`：还原项目只给本技能用，用来提炼机制、和本项目同尺对照，不交给下游。
- 允许用途是 `owned` 或 `licensed` 且记了依据：还原项目可以离开对标目录（BRK-11）。做法是创作者把整个
  `还原/` 复制成一个新项目，或直接在它里面让各阶段技能接着改；不把还原文件合并进当前项目的剧集。

## 看片通道

脚本不看片。本机实测可用的通道是 Antigravity CLI（`agy`）配 `gemini-4-argon-high`：

```bash
mkdir -p <新空目录> && cp <某集.mp4> <新空目录>/ep.mp4 && cd <新空目录>
agy -p "<提示>" --model gemini-4-argon-high --add-dir <新空目录> --mode plan --print-timeout 1500s > out.md 2> err.log
```

- **每次调用都用新的空目录**。同一目录里连续调用，前一次看到的内容会出现在下一次的回答里。
- **先确认它听得到音轨**。裁掉字幕区剪一段十几秒的片段，让它逐字转写台词并给时间。
  `gemini-3.8-flash` 收不到音频，只能读画面；模型自己描述“收到了什么”不可信，同一个模型
  在一次运行里自称只拿到每秒一帧、没有音频，实测却听得到。
- 提示里写明：只根据这个视频回答，不运行终端命令，只输出一个 JSON 代码块。拿到后先校验 JSON，
  只修语法，不改内容。
- 失败或被限流时等一分钟，换新目录重试，最多三次。个人配额用完时报 429，几天后才重置；
  一集一般要调用两次，多集还原前先估算调用次数。

## 每集流程

### 1. 测量

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure <各集.mp4> --out 输入/对标/<REF-ID>/measure
python3 {技能目录}/scripts/breakdown_tool.py audio <各集.mp4> --out 输入/对标/<REF-ID>/audio
python3 {技能目录}/scripts/breakdown_tool.py subtitle-sheet <两三集.mp4> --out 输入/对标/<REF-ID>/subtitles
python3 {技能目录}/scripts/breakdown_tool.py subtitles <各集.mp4> --out 输入/对标/<REF-ID>/subtitles \
  --band <左,上,右,下> [--color <字色>] --audio 输入/对标/<REF-ID>/audio
python3 {技能目录}/scripts/breakdown_tool.py shots <某集.mp4> <某集.measure.json>
```

- **先定字幕区，再扫字幕**。每部剧的字幕位置、字色和描边都可能不同，默认区域（底部居中，
  0.86–0.96 画面高）只适合一部分剧。`subtitle-sheet` 从同一部剧的两三集里挑描边字最多的几帧，
  四边标好比例刻度，拼成 `subtitle-sheet.jpg`；`subtitle-rows.json` 记下每个高度带出现描边字的比例
  （`shown`）和字在相邻采样间换掉的比例（`changed`）。看图后定下：
  - 字幕区：框住对白字幕，上下各留 0.02 左右余量。字幕常换、`changed` 明显大于 0；`shown` 高而
    `changed` 近 0 的是水印、台标；名条、系统面板、招牌也是描边字，不算字幕区。
  - 字色：白字不用设；黄字、彩字用 `--color` 写六位十六进制（如 `FFD400`），按颜色找字形。
    `subtitle-rows.json` 只认白亮字，黄字、彩字要靠看图。
  - 第一集的片头字卡或样式和后面不同时，第一集单独定。定下的值写进登记，整部剧沿用。
- `subtitles` 按定好的区域和字色找带深色描边的字形，判断每句字幕何时出现、何时换成下一句，
  每句存一张裁图，时间精度约 0.1 秒。它不认字，文字要读裁图；没有字幕的人群声、只在系统面板上
  出现的系统音不会出现在结果里。整段读进内存，按集运行，不要拿拼接后的长母版跑。
- **扫完先自检**：给了 `--audio` 时，结果里的 `voiced_shown_share` 是有声时间里屏幕上有字幕的比例。
  烧录字幕的剧一般在 0.5–0.8；明显低于 0.3 时先看裁图和校准图，多半是区域框偏了、字色没设，
  或者是细描边字幕。细描边的字一句常被拆成几段，读裁图时把文字相同的相邻事件并起来。
- `audio` 给出有声区间和响度，不分对白和配乐。用它判断一句画面文字（监控时间、文件特写）有没有人念。
- `shots` 按测量切点切出每镜小段与首、中、尾三帧，并列出镜内低阈值候选切点。
  相邻几帧连着出现的候选（`frames` 大于 1）多半是闪光、粒子或快摇，单独一个的多半是漏检的硬切。

### 2. 整集听看一遍

把整集交给模型，要这些字段：

- `lines`：每句台词，含系统音、旁白、群声，字段有起止时间、说话人、发声方式（画内、OS、VO、系统音、电话）、
  逐字台词、情绪，以及置信档位：字幕实录、音轨与字幕互校、推断；
- `characters`：编号、名字及名字来源（名条、台词称呼、字幕、系统面板、推断）、外形、服装、随身道具、
  声音（性别、年龄感、音色、语速）、首次出现时刻；
- `scenes`、`props`、`on_screen_text`（名条、系统面板、时间地点卡、文件特写）、`sfx_music`、`beats`；
- `opening`、`ending`（最后一句是否说到一半、最后一个动作是否做到一半）和 `style`（渲染、色调、光、镜头、动势、画幅）。

### 3. 逐镜看一遍

另开新目录，把实测镜头的编号与起止时间（到 0.01 秒）、镜内候选切点和上一遍的人物编号一起给模型。
每镜要景别、角度、运镜、主体、站位与视线、动作（起始状态→动作→结束状态）、表情、对应台词、画面文字、光、
特效、进出转场、镜内是否还有切，以及首帧和尾帧。首帧、尾帧要具体，它们就是关键帧提示词的底稿。

### 4. 对齐与自查

- **台词时间以字幕为准**。模型给的时间普遍早 0.3–0.6 秒；有字幕的句子改用 `subtitles` 的起止，
  原值另存。只在面板上出现或没有字幕的句子保留模型时间，标为推断。
- **台词文字两边对照**。读字幕裁图，和模型听到的逐句比。字幕错字（同音字、重复字）常见：
  剧本按音轨写，字幕原文另存，两者不同处注明。
- **切点以测量为准**。模型报的镜内切点和候选切点对得上的，抽帧确认后记为镜内切；对不上的列出来交人判断，
  不自动删也不自动收（BRK-12）。测量切点之间不足 0.2 秒的碎镜（闪切、抖动）单独标出。
- **台词归属按时间重算**：用台词起止和镜头区间求交，不用模型自己写的归属。
- **名字只认画面和台词里的证据**。模型会给没出现过的人编名字；没有名条、称呼或字幕支撑的名字不用，
  用身份称呼（“父亲”“大姐”这类）并注明。文件特写里的小字模型多半读不准，不当证据。
- 每集建议抽五个以上台词中点，读字幕裁图核对文字和时间；剩下的疑点逐条写进这一集的说明。

## 跨集衔接

多集还原时按集序把各集结果合成一条连续的系列时间线，再做三件事：

1. **统一身份**：每个真实人物在全系列只有一个编号。各集的局部编号按名字证据、造型和台词称呼映射过去，
   映射表记下证据和把握（台词、造型、推断、未决）。名字第一次被确认的集和时刻也记下来。
2. **接缝表**：每对相邻集写上一集最后一句与最后一帧、下一集第一句与第一帧、上一集是否断在半句或半个动作上、
   下一集是否重放上一集结尾、带过去的状态（谁在哪、穿什么、伤、道具状态、谁知道了什么、悬而未决的事）。
   开头几集之后各集长度完全相同（比如都是 50.03 秒）时，多半是一条长母版按定长切开，集界常断在半句上，
   这时按连续母版还原，再按集界切回去。
3. **连续性漏洞**：同一道具前后形态不一、数值前后对不上、某段剧情交代缺失，列出来，原样还原，不擅自修。

## 写成套件文件

还原项目里每集写五份文件，格式照各自负责技能的写法：剧本按 `$short-drama-write`，视觉设定与
`设定集/` 按 `$short-drama-assets`，分镜按 `$short-drama-storyboard`，图片与视频提示词按
`$short-drama-image-prompts`、`$short-drama-video-prompts`。还原时多守几条：

- 台词完整、逐字、按序，说话人用统一后的名字，标 VO、OS、系统音；名条和系统面板写成 `[画面文字]`。
- 一个实测镜头写一条分镜，时长取实测值；镜内确认过的切在镜头说明里写出。
- 关键帧提示词复用 `设定集/` 里的造型锚点；视频提示词写动作起止、运镜、带说话人和口型的台词、时长。
  三维国漫这类风格化画面靠文字守不住画风，视频提示词写成挂起始帧的图生视频。
- 某集从上一集半句接着开场时，照实写成承接，注明来自接缝表，不另编开场。
- 原片里被消音（哔声）或字幕用符号遮住的词，对齐记录里照实注明；写进《剧本.md》和下游提示词时，换成字数、
  语气相近的可播词（如“丢人”），不保留哔声和遮蔽符号。
- `项目开发/` 写分集地图（每集时长、功能、开头钩子、结尾钩子、兑现、系统或金手指事件）和系列大纲，
  `设定集/` 另写风格圣经与声音说明。

### 拿还原去出片

允许用途是 `owned` 或 `licensed` 时，还原项目可以接着交给各阶段技能出片：生成关键帧、视频，剪成片，
和原片对照（BRK-11）。生成的图、视频和成片同样只放在 `输入/对标/<REF-ID>/` 下。
**`craft_default`**：出片时有三件事和纯还原不同：

- **原片不合理的地方不照搬**。上一节的连续性漏洞在还原文件里照实记录；出片时，原片本身不成立的空间
  （缺了该有的功能区，人只能站在不合常理的地方；门窗、柜台前后镜位置对不上）、戏已演完
  还留在画面里的人，不带进生成。
  保留节拍、镜头职责和台词，把地点和站位重新设计成说得通的样子，交 `$short-drama-assets` 和
  `$short-drama-storyboard` 按各自的写法定下来，退场的人按动线出画。这些改动单列在 `审查/` 里。
- **对的是节拍，不是秒数**。生成模型开口晚、语速慢，句后还要留反应，成片会比原片长：一次 45 秒、13 镜的
  单集出片，成片长了约 13 秒。验收看节拍、台词和每镜职责是否一致，不为凑原片时长硬切反应或整段提速。
- **审片模型要一并拿到分镜**。用能听音轨的模型帮着挑候选、审成片时，把还原项目的《分镜.md》一起给它。
  它不知道原片怎么拍，常把原片本来就有的拍法（内心独白时嘴不动、背对镜头喊人）当成缺陷扣分；
  它报的问题先对照分镜，分清是生成偏了，还是原片本来如此。

## 保真度核对

写完后用原片回头量，结果写进还原项目的 `审查/`，并按结果修：

| 核对 | 做法 | 只说明什么 |
|---|---|---|
| 台词字错率 | 建议抽 40 句左右，读台词中点的字幕裁图，和剧本逐字比 | 剧本按音轨纠正字幕错字、把消音或遮蔽词换成可播词时，算作有意差异，单列 |
| 漏句 | 数 `subtitles` 的事件，和剧本台词比，抽两集以上 | 没有字幕的群声、面板系统音要另外数 |
| 节奏 | 按实测语速给还原项目设节奏档案，`plan` 量还原剧本，和原片 `measure` 比首句时刻与有声占比 | 分镜照抄测量切点时，镜数、总长、镜长中位必然一致，不算证据 |
| 画面幻觉 | 建议抽 15 镜左右，看首、中、尾三帧，核对景别、主体身份、动作方向、画面文字，记对、部分对、错 | 集界第一镜最容易认错人 |
| 接缝 | 每对相邻集，核对下一集剧本开头确实接上接缝表 | |
| 人名 | 列出每个名字和它的证据 | |

设节奏档案时，台词里夹拉丁字母（“c级”这类）要同时声明字速和词速，否则 `plan` 会报缺单位。

## 一组实测

2026-11-04，一部三维国漫画风的系统流漫剧，16:9，烧录字幕，共 160 集，开头三集 112–148 秒，
之后每集都是 50.03 秒。按本流程还原前 12 集，共 854 秒：

- 台词 371 句。人工读帧抽 46 句 388 字，错 2 字，字错率 0.52%；全量比 350 句 2927 字，字错率 0.34%，
  差异全是剧本按音轨纠正的字幕错字。两集按 0.5 秒采样数字幕，漏句为 0。
- 抽 16 镜：12 镜对，3 镜部分对（动作方向或起止状态写反），1 镜错。错的是一集第一镜的前 0.37 秒，
  实际是上一集尾镜的延续，模型认成了反打里的人。
- 测量阈值 0.28 在一集里漏了 31 处镜内切，单镜最多 8 处；`shots` 的候选切点（阈值 0.1）列出 33 段，覆盖其中 27 处，漏的是软切和一组快切。
- 6 集对照：`subtitles` 的事件与人工校过的台词起点，有字幕的句子相差都在 0.25 秒以内，只有一句差 0.3 秒；
  没对上的是面板系统音和群声，另有一句字幕抖动被拆成 4 段。
- 模型给一位父亲编了一个画面和台词里都没有的名字；一集里两句监控时间被当成台词，按 `audio` 看是配乐底噪，
  改成画面文字。
- 11 对接缝里 3 对断在半句上，5 对在下一集开头重放上一集结尾。
- 成本：12 集并行跑约 110 分钟墙钟，每集两次 Argon 调用，加上返工回听。有一集的整集调用中途中断，
  补跑时个人配额已用尽（报 429，约 6 天后重置），这一集只能靠字幕裁图和拼图补台词，没有逐镜描述。

同日另做字幕区校准：22 部横屏三维漫剧各取一集，另用其中 4 部的画面（裁掉原字幕）合成 7 种字幕样式，
每段 21–26 句、起止已知。

- 默认区域和字色在 22 部里有 1 部一句没扫到（字幕在 0.80–0.86 画面高），1 部是细描边字幕。
  看校准图重框后，前一部有声时间里有字幕的比例从 0 升到 0.60；细描边那部是 0.29，其余各部在 0.49–0.83。
- 合成样本，每种样式 95 句，记起点差 0.25 秒以内的句数：白字描边 95，白字半透明底框 92，
  竖屏字幕在 0.88 高 95；竖屏字幕在 0.75 高，默认区域 0，框定后 95；黄字不设字色 0，设 `--color` 后 95，
  黄字加底框 92。起点差中位不超过 0.02 秒，误报不超过 1 段。
- 细描边仍是短板：95 句命中 80 句，35 句被拆成几段。
