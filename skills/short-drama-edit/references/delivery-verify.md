# 交付与验收

本阶段的验收只回答**可测的事实**。「这条片子好不好看」不在这里回答，也不能用这里的任何一项
数字去暗示它。

## 可测项

渲染完成后逐项测量并回报数字，不回报「通过」：

| 项 | 怎么测 | 判据 |
|---|---|---|
| 成片时长 | 探测输出文件 | 等于各段时长之和；不等说明拼接或转码出了问题 |
| 每一刀的位置 | 按剪辑单区间反查 | 与文档一致 |
| 台词完整性 | 在成片上转写，逐句对剧本原文 | 每一句留下来的台词都能找到 |
| 边界帧 | 抽剪辑点前后各一帧 | 没有黑场帧、白场帧或半渲染帧 |
| 响度 | 测整片响度 | 落在交付规格声明的目标上 |
| 字幕对齐 | 抽有字幕的段落的帧 | 字幕在发声区间内出现，位置没有压住画内文字 |
| 画幅与帧率 | 探测输出文件 | 等于交付规格声明的值 |
| 声明的沉默 | 测该区间的电平，与全片底噪比 | 只高出底噪几分贝；出现语音级事件即为缺陷 |
| 接镜校正残差 | 逐段测亮度与蓝红，与全片中位数比 | 每段都靠近中位数；某一段远离而其余贴合＝那一段的校正过冲了 |
| 画内可读文字 | 抽有画内文字的帧，逐字对《剧本.md》的「画面文字」 | 一字不差；模型自己编出来的文字是缺陷，不是风格 |

后三行都是补上去的，每一行都对应一次真实的漏网。

**画内可读文字**：一集的最后一镜要求银幕上出现「宣传片定版　《且听龙吟》　来源：手机原版」，
成片里是「这说明地层已经开始出现松动。」——模型自己编的一句，和这场戏毫无关系，
而且它就停在全集的落点上。`check` 过了，`verify` 过了，全片响度与时长都正常。
**画内文字此前根本不在验收表里。**

**接镜校正残差**：某一镜的色温校正过冲了 11 点，从全片最暖变成全片最蓝，
观众会看成这个人换了件衣服。而全片的色差**范围**反而更好看了——一段从一个极端荡到
另一个极端，最大值最小值几乎没动。**只有逐段残差能看见它**。

**声明的沉默**：剧本写明「说完之后没有人回应、没有笑声、没有椅子声」的
那三秒半，成片里实际有一个高出底噪 34 分贝的语音级事件——而当时时长、响度、字幕、边界帧
全都测了，唯独没测「该没有声音的地方有没有声音」。**沉默是被写下来的创作决定，和台词一样
需要验收**；它不会在响度均值里露出来，那一整片的均值看着完全正常。

任何一项测不了（缺工具、缺原文、素材不可读）就如实写「未测」和原因。**不要用相邻的、
测得到的那一项去替它作证**——渲染成功不能证明台词还在，时长对上不能证明没有黑场帧。

最容易漏的是字幕那一行：`verify` 返回一整屏数字，看起来已经查完了，但它测不了字幕长
什么样。本套件就这样发过一版字号被放大两倍的成片——改完样式只跑了 `verify`，没抽帧看。
**改动只要影响画面，就必须抽帧看，不管数字多好看。**

## 少一个镜头，成片上是看不出来的

这是本阶段最容易漏、代价也最大的一类缺陷：**观众看不见不存在的东西**。片子里少了
交代前因的那几镜，看片的人只会觉得"这段有点没头没尾"，而不会说"少了七个镜头"——
连做的人自己都不会发现，因为他看的是自己剪出来的东西。

本套件真发生过一次：一集的剪辑单覆盖了后半集，开场七镜从来没有生产过，成片照常
装配、照常通过验收。外部评审看完的第一条结论是「观众看不到被否掉的是什么」——
整场戏的前提缺席了。

所以 `check` 会**反向对账**：《视频提示词.md》里的每一个 MOTION，要么被某一段采用，
要么写进剪辑单开头的「未采用镜头」并给出理由。两样都没有就是 finding。

**被舍弃是正当的创作决定，被静默舍弃不是。** 「未采用镜头」那一行不是形式，它是
唯一能让"这一镜不在成片里"这件事被看见的地方。

## 报告什么

交付时给出四样东西：

1. **成片文件路径**，以及每段切好的中间文件路径。
2. **上表逐项的实测数字**，包括未测项和原因。
3. **目标时长与实际时长的差**，以及为什么是这个差。
4. **仍然存在的取舍选项**——还可以再剪的地方、可以回上游重出的地方，各自的代价。
   列出来交给创作者选，不替他决定要不要再来一版。

不要报告的：任何形式的质量结论、「已经可以发布了」、把技术成功写成创作成功。

## 交回上游的东西

剪辑是第一次同时看到成片和意图的位置，所以它必然会积累一批只有在这里才看得见的发现。
这些发现不属于剪辑单，但属于本轮报告：

- **某一镜的可用带远短于声明时长** → 视频提示词阶段的时长与动作负载不匹配。
- **两镜信息重复** → 分镜阶段的切镜理由不成立。
- **某句台词在成片上说不清** → 剧本层面的语速/字数问题，或声音生成的容量问题。
- **成片整体缺少某种信息**（人物不立、地点没交代、转折没落地）→ 上游结构问题，
  不是剪辑能补的。

逐条点名，写清是在哪一段、哪个时间点观察到的，交给对应 owner。不在剪辑阶段自行修改上游文档。

## 可继续精修的工程

成片是一次交付，不是终点。创作者通常还要在自己的剪辑软件里继续改。因此除了成片，
把切好的中间文件和剪辑单一起交出去——有了这两样，任何人都能在别的工具里复现这一版，
并从这一版继续。

只交一个成片文件，等于要求下一个人从头再剪一遍。
