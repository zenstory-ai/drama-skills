# AI 短剧怎么保证跨集、跨镜头角色一致：三视图之外还要做什么

三视图提供人物外观参考；每一镜还需交代当前服装、持物、朝向和状态。Drama Skills（`zenstory-ai/drama-skills`，开源 MIT，12 个 Claude Code / Codex 短剧 skill）靠三道文字记录防穿帮：在 `视觉设定.md` 里定好人物长相与换装，给跨镜不变的穿着加上「连戏锁」固定短语；参考图提示词、待挂图计划与项目实图分别用 `IMG-*`、`PLAN-*`、`REF-*` 区分；每镜先写「首帧提示词」，再把画面里用到的人物、场景和道具写进「出场设定」。先把设定与引用写成可核对的文字，生成前就能查出前后打架；实际成片里的人物长相、服装与空间连贯度，仍须在出图出片后逐镜验收。

## 为什么只靠三视图会崩

三视图（正、侧、背）是固定长相参考，用来传给 `--cref`、LoRA 或图生视频的参考图位置。但跨镜穿帮多数不是脸变了，而是这些变了：服装颜色、伤口位置、手里的东西、湿没湿、门开没开、站在轴线哪一侧。这些细节会随剧情变化，不能锁死在三视图里；但在相邻镜头里需要前后连贯，不能每镜随手乱写。所以需要一个专门的地方，记清楚“哪些画面外观细节当前需要保持不变”。

## 第一层：视觉设定与连戏锁

`$short-drama-assets` 从剧本拆出人物与造型、场景与机位朝向、道具与状态，写进 `剧集/<EP>/视觉设定.md`，重点区分三件事：

- **固定外貌**：这个人长什么样，跨集不变（对应参考图用途里的「外貌」）。
- **换装或状态造型**：人是同一个人，但服装、伤势、时段、天气、开合或手持状态变了。换了件外套属于新造型，不是新角色。
- **连戏锁**：只锁本场戏里不随剧情改变、一旦走样观众一眼能看穿的外观细节。「锁定词」用提示词语言写成最简短语（例如一枚固定耳饰、某件外套的颜色与版型），会随动作改变的部分留给镜头状态。

每个出场条目都归为四类之一：新建、复用、换装或新状态、待创作者拍板。剧本里指代不清的地方先留待确认，不瞎猜。

## 第二层：提示词、挂图计划与真实参考

`$short-drama-image-prompts` 负责写参考图提示词，并把三类图片记录分开：

| 标记 | 含义 |
|---|---|
| `IMG-*` | 提示词条目，只代表写好了描述，不代表图片已经生成 |
| `PLAN-*` | 计划由创作者在外部生图/生视频界面里自行挂载的参考图 |
| `REF-*` | 已经存放在项目目录里、并且实际核验过的图片文件 |

`REF-*` 绑定项目里可读取的真实图片；`PLAN-*` 标明创作者准备在外部工具里挂哪张图、按什么次序挂，照样能生成视频提示词，但只有换成真实 `REF-*` 后才能交由本套件直接调用接口出片。每张参考图只负责外貌、造型状态、空间布局、构图或风格中的明确几项，并写明 `用途`。加了连戏锁的条目，它的锁定词会原样写进参考图提示词正文，先把跨镜不变的穿着定在参考图上。创作者没手动指定参考图不代表要做文生视频；缺哪张图就列出来，不会擅自改成文生视频。

## 第三层：首帧提示词和出场设定

`$short-drama-storyboard` 把每镜写成 `## SHOT-...`，每镜下有 `### 首帧提示词`（镜头开场那一格能看见的画面），需要时再加 `### 尾帧提示词`（收尾画面）。具体做法：

1. 每镜先写清「起点 → 动作 → 终点」，交代人物、双手和手里拿的东西怎样从开场画面走到收尾画面。
2. 定准人物朝向、站位、视线、手持物、出入口、画面朝向和必要状态，把前面镜头已经留下的状态（如衣服淋湿、门已推开）带进本镜的起点与终点。
3. 首帧提示词只写镜头开场那一瞬间看得见的内容；要到动作结束才出现的姿态或道具变化全部拿掉。
4. 首帧提示词定稿后，对照画面清点这一格里需要保持外貌、造型或空间布局一致的人物、场景和道具，逐项写进「出场设定」。首帧提示词里点到名的条目必须列进出场设定；凡是用到连戏锁造型的镜头，锁定词都要原样写进首帧提示词正文，不以“参考图里有了”为由省略。

`$short-drama-video-prompts` 再把分镜逐镜写成视频提示词，按目标模型（例如 MiniMax H3）挂上已有的 `REF-*` 参考图和本镜起始帧。

## 检查点

`$short-drama-review` 负责核查视觉设定、提示词、分镜和首帧提示词的前后连贯性，只列问题清单和修改建议，不替创作者直接改原始创作文档。调用接口出图出片（`$short-drama-produce`）只在创作者看过预览并明确确认后才执行，仅看预览不算确认。

## 边界

- 把跨镜不变的设定写成可核对的文字，能在生成前提前揪出前后冲突；真正出图出片后有没有变脸、串衣或方位穿帮，仍要逐镜看画面验收。
- 静态漫剧（首帧画面切换加配音）可以跳过视频提示词阶段。
