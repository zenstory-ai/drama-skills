## 1. 什么时候需要变体

变体用于明确有因果、可复用、在一定范围内持续的视觉状态，同时保留持久身份；瞬时表情或手势通常留在镜头中。

先用 `视觉设定.md` 的当前判断区分：

- **直接复用（reuse）**：身份、地理、功能和需要保持的状态都没变，直接复用；
- **建立变体（variant）**：同一身份上出现可逆或时间有界的造型、视图或道具状态差异；
- **新建资产（new asset）**：持久身份、固定地理或基本功能已改变；
- **留作未决（unresolved）**：无法确定，停止写提示词并让创作者选择。

身份归类由资产负责技能决定，图片提示词只呈现已确认变体。

## 2. 基底、变化与有效范围

一个 `IMG-...` 变体条目必须能回答：

1. **派生基底**：它从哪个准确身份或变体 ID 派生？
2. **保持锚点**：哪些人物、地点或道具身份事实不变？
3. **当前变化**：哪里发生了什么可观察变化，范围和强度如何？
4. **变化原因与来源**：变化来自哪个场景、连续性事实或创作者决定？
5. **有效范围**：从哪里开始、持续到哪里、何时恢复或再变化？
6. **受影响工作**：哪些 `IMG-...`、`SHOT-...` 或关键帧需要此变体？

- **`structural_invariant`**：基底、变体 ID、来源与有效范围可解析；不得同时使用不相容变体。
- **`reviewed_invariant`**：当前变化与持久锚点没有混层，也没有超过来源支持的范围。
- **`craft_default`**：正文先短述保持的身份，再把注意力放在当前变化；不要重写全部基底描述。
- **`taste_option`**：单独变体设定板、同版对照或局部细节板由复用目的决定；默认单独设定板更少歧义。

## 3. 三类变体的写法

### 人物造型（Character / Look）

常见变化：衣服/穿法、发型整理、妆面、临时配饰、污湿、血迹、新伤、包扎、年龄跨度。写清身体/衣物位置、覆盖范围、材料反应和未变区域。

示例机制（合成）：同一维修员夜班造型经雨后，只有外套右肩至肘部明显湿深，头发末端微湿；脸型、断眉、服装剪裁、左胸布贴和右袖旧焊痕保持。不要把“雨后”扩成新伤、换装或全身滴水。

一瞬间的眼神、一次抬手或单镜表情归分镜与关键帧管，不单建造型。

### 地点视图与状态（Location / View-state）

常见变化：特定观察方向、临时陈设、营业/停业状态、时间、天气和光线。固定入口、主要分区、建筑结构及关键锚点保持；写清相对基底视图哪些可见条件改变。

夜景不是把门窗重新布局。临时堆放物不要升级为固定地理。若洪水、坍塌等永久改变动线，应由资产阶段判断是否仍算变体。

### 道具状态（Prop / State）

常见变化：开/关、内容物、损坏、污渍、文字、持有者与功能状态。写清铰链/缺口/裂纹位置、内容可见程度、承载面文字政策和未变轮廓材料。

换手不一定需要新的设定板；只有下游识别或连续性确需一个持续状态时才做。道具完全断成两件且功能改变，需要由资产阶段决定是新建状态还是新建资产，提示词阶段不越权代判。

## 4. 变体设定板与局部编辑的区别

- **变体设定板**描述一个已确认、可被多个镜头复用的完整当前状态；它可以从零编写提示词，不以某张待编辑图片为前提。
- **局部编辑差异（`edit_delta`）**指向准确的 `IMG-...` 提示词条目及具体对象和区域，说明变化、保持项与连续性影响；
  实际待编辑图片另作参考绑定，不能把条目 ID 当作图片。

若创作者说“把袖子改湿”：

1. 已有明确的湿衣造型，且目标是复用状态 → 可以写变体设定板或局部编辑；
2. 湿衣造型尚未确认 → 先向资产阶段提变体选择；
3. 只发生在单镜头动作末端、没有持续复用 → 先交分镜处理连续性，不自动创建资产提示词。

不要把变化前后两个互斥人物叠在一张身份板上，除非用途明确是比较板，且两个区域和标签不会造成身份融合；这属于可覆盖的技法选择，不是默认做法。

## 5. 输出、失败与审查

### 失败征兆

- 只有“更脏、更老、更阴森”，没有位置、范围和可观察变化；
- 变化覆盖整个人、地点或物件，实际已改变持久身份却仍叫变体；
- 提示词复制基底全文后，把真正变化藏在末尾；
- 有状态但无原因与有效范围，导致后续镜头不知道何时复用；
- 把姿势、机位或一次即时反应当成资产变体；
- 同一设定板同时画完好与损坏、白天与夜晚或两套造型，未声明比较用途。

### 检查

| 检查 | 分类 |
|---|---|
| 准确基底/变体、来源、有效范围解析 | `structural_invariant` |
| 变化是否保持身份、地理与功能 | `reviewed_invariant` |
| 是否误把瞬时镜头状态升级为资产变体 | `reviewed_invariant` |
| 变化描述是否比基底常规描述更醒目 | `craft_default` |
| 单图或对照板、变化强度与呈现媒介 | `taste_option` |

输出一个写清基底、变化、保持项、有效范围和受影响工作的 `IMG-...` 条目，以及一段聚焦当前状态的
可复制正文。不得生成图片，也不得声称变体画面已经验证成功。
