# 冲突、揭示、反转与回报的条件方法

先明确作品承诺的体验，再按项目条件选择压力、揭示、反转与回报机制，让人物作出有后果的选择，
让观众获得承诺中的回报。

## 1. 从承诺选择压力来源

| 承诺重心 | 可持续压力 | 可变化的回报 |
|---|---|---|
| 身份/伪装 | 暴露风险、两套义务、识别证据 | 观众多知道一层、角色被迫选边 |
| 职场/制度 | 签字权、时限、替罪链、程序筹码 | 规则被反用、责任归属改变 |
| 家庭/遗产 | 照护债、记忆版本、物件归属 | 关系真相或选择成本落地 |
| 复仇/追责 | 证据可信度、共犯关系、代价升级 | 对手失去一项保护，主角承担新债 |
| 悬疑/秘密 | 谁能看见什么、证据可否解释 | 排除一种解释，同时产生更难选择 |
| 轻奇幻 | 有限规则、使用代价、普通秩序摩擦 | 规则被聪明运用，而非不断加大法术 |
| 情感/关系 | 需求不对称、面子、承诺、边界 | 一方改变策略或公开真实代价 |

同一题材可以选不同压力。不要让“霸总=羞辱升级”“悬疑=每集新秘密”代替故事引擎。

## 2. 区分四种动作

- **信息揭示**：观众/角色获得已有事实。
- **方向性反转**：已有事实使计划、解释或关系位置失效。
- **情绪回报**：承诺的恐惧、甜、爽、痛、温暖真正落到可感知结果。
- **情节钩子**：新决定、危险、问题让状态继续运动。

同一次动作可以兼任多项功能，但判断时要分开：只展示秘密却无人改变选择，完成的是信息揭示
（reveal），未必构成方向性反转（turn）；结尾只隐去一句话，属于信息扣留（withholding），
未必形成让观众继续看的钩子（hook）。

## 3. 公平揭示

揭示前检查：

1. 观众是否见过足够的可解释迹象？
2. 谁在此前能接触事实，谁不能？
3. 证据为何现在出现，而不是作者需要时凭空出现？
4. 新事实排除了什么旧解释？
5. 得知后谁必须改变行动？

有效揭示常通过重新连接旧事实，让观众和人物获得新的解释。

合成例：维修员早先发现签字页缺失，只知道有人藏页。她在主管桌上看到订书孔方向相反，
才意识到被拿走的不是最后一页，而是中间一页；这让“补签”计划失效，必须先保护被点名的
新同事。订书孔不是装饰；它改变策略。若此前从未建立页序和装订方式，这个揭示就不公平。

## 4. 有因果的反转

**STY-09 · reviewed_invariant**：揭示/反转必须从已建立事实生长，并且让计划、
解释、关系位置或高代价选择至少一项真正改变。

反转必须能完成一句话：

~~~text
因为 <已建立的事实/选择>，
原计划 <为何不再成立>，
人物现在只能在 <新代价 A/B> 之间行动。
~~~

常见可用反转：

- 胜利触发对手有准备的程序反制；
- 证据是真的，但证明的是另一项责任；
- 被保护者拒绝保护方式；
- 主角的长处暴露新的盲区；
- 关系盟友要求兑现此前承诺；
- 规则没有失效，人物用规则改变了时间或权限。

弱反转：陌生人突然出现宣布一切都是梦。它改变信息，却没有从人物行动长出。

## 5. 回报先于下一股压力

每集至少明确一种已兑现结果（craft_default，不是数量门槛）：

- 主角确实救下/失去/赢得/公开/拒绝了什么；
- 一个旧问题获得部分可验证答案；
- 一段关系的边界真的改变；
- 承诺的能力、亲密、羞耻或恐惧得到一次完整呈现。

然后才问：这项结果让谁失去筹码、暴露什么、产生什么债，形成 outgoing pressure。
“马上要揭晓”不是回报。

## 6. 避免机械轮换

不要按集轮换“打脸—身份—误会—救场”。比较相邻集的机制：

- 压力来源是否学习；
- 主角策略是否改变；
- 代价落在哪种价值；
- 观众获得的是信息、关系、能力还是情绪回报；
- 空间/资产/制作负担是否仍可承担。

重复可以是类型节奏，但第二次应产生新意义或更难选择，而不是形容词更大声。

## 7. 规则分级

- structural_invariant：setup/payoff refs、incoming/outgoing refs 和 accepted constraints 可解析。
- reviewed_invariant：反转由已建立事实引发，揭示不越过知识权限，升级改变状态。
- craft_default：先给局部回报再留压力；让对手学习主角策略。
- taste_option：是否反转、谁先知道、揭示快慢、开放程度与题材强度。
