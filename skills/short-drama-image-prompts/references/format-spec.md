# 图片提示词格式规范（完整项目模式）

撰写并落盘完整项目文档 `剧集/<EP>/图片提示词.md`（用于跨文档自动校验或衔接内置批量出图）时，按本规范组织条目与字段。若仅是轻量起草几条独立生图提示词，按 `SKILL.md` 的轻量模式直接输出即可，不必强套完整槽位语法。

## 一、条目结构与编号

- **二级标题**：每项设定图使用 `## IMG-... · <名称>`。`IMG-` 与 `REF-` 编号后缀仅使用大写英文字母、数字与连字符 `A-Z0-9-`；`IMG-...` 只标识提示词条目，不代表磁盘上已存在成图。
- **字段清单**（字段顺序不限，使用标准字段名即可）：

| 字段 | 类别 | 写法要求 |
|---|---|---|
| `- 参考：` | 脚本必需 | 填写 `无`、`无外部参考`（支持括号说明，如 `无（纯文生图）`）或真实 `REF-...` 槽位，见下文第二节 |
| `- 用途：` | 展示推荐 | 简明交代本张设定图用来固定什么外观、视角、状态或定调意图 |
| `### 可复制提示词` | 脚本必需 | 小节内**只放顶格以 `>` 开头的引用块**，不混入普通列表、分隔线、条目编号、文件路径或流程备注 |

- **语种约定**：创作者说明文字跟随项目语言；`### 可复制提示词` 正文跟随 `short-drama.json#/format/prompt_language`（无配置文件时按已有提示词或项目文档语种推断，未指定时可用用户当前语言）。

## 二、`- 参考：` 槽位语法

- **无外部参考图**：写 `- 参考：无` 或 `- 参考：无外部参考`（支持后接括号或分号补充说明，如 `- 参考：无（纯文生图）`、`- 参考：无外部参考；三视图保持同一脸型与服装细节`）。
- **绑定项目内真实图片**（支持 `.png` / `.jpg` / `.jpeg` / `.webp`，分镜预留的 `PLAN-...` 不能写进图片提示词）：

```text
REF-<slot>（顺序：<n>）· <项目相对路径>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

- 多张参考图之间用中文全角分号 `；` 连接，顺序从 `1` 连续编号；同一张图片在单条内只占一个 `REF-...` 图位。
- `用途` 从固定十项词表中选填**唯一**主作用（一图兼顾两事时把次要作用写入 `控制：`）：
  `外貌` / `主体` / `造型状态` / `空间布局` / `构图` / `尺度` / `效果` / `起始帧` / `结束帧` / `风格`
- 标点使用全角冒号 `：`、全角括号 `（）` 与中点 `·`，不得用 `/` 代替字段分隔符。

## 三、完整条目示例

```markdown
## IMG-XUTANG-SHEET · 许棠角色板

- 用途：固定许棠五官脸型与深灰工装夹克。
- 参考：无（纯文生图）

### 可复制提示词
> <按项目 prompt_language 编写的可直接复制静态图片提示词正文……>
```
