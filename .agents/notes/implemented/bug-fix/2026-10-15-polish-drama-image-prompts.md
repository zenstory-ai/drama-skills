# Agent Note: 图片提示词参考字段与历史格式边界对齐

Status: implemented

## Problem

图片提示词技能入口未写出 creator-first 必填的参考字段，通用配方又要求无媒体时不写参考段，会被现有五文档检查器判为缺字段。部分参考资料把结构化规格、事务生命周期和 restore/adopt 当作默认工作流；独立技能实际上只提供结构化校验器，不负责这类事务操作。文字政策说明还允许保留来源政策却偏离映射，与独立校验器的确定性映射冲突。

## Decision

默认产物仍是《图片提示词.md》的 IMG 条目，明确无外部参考与真实 REF 输入的写法。IMG 是提示词条目 ID；实际待编辑图片另用 REF 绑定，下游 PLAN 挂图计划不证明本条已有真实输入。

结构化模板只用于旧格式追溯与离线回归，当前保留旧 JSON/JSONL 只读；继续旧格式编辑须锁定 `v0.5.0`，升级在新根逐集确认五文档，不向旧记录反写。需要改变文字来源政策时交回资产负责技能，再按已接受政策选择呈现方法。

五文档检查器核对 IMG 标题、参考字段、槽位语法、用途、本地路径与可复制正文；独立 JSONL 检查器只检查当前文件的引用声明、字段、槽位、部分文字映射和提示词语法，不打开目标资产记录或图片。引用声明有效不等于来源已接受或参考像素已验证。

人物板检查表中的“形态未定即结构阻断”改为依赖项范围核对。核心制作形态说明把形态卡列为 `craft_default`，不允许卡片新设结构门槛；Creator-first 工作流只因会显著改变视觉方向的真实分叉停下。完整五文档检查器没有未选形态的全局门禁，IMG 阶段契约也没有此规则。因此仅保留受形态选择影响的识别通道、材质、线条或分层为未决，已确认事实继续编写；具体问题仍按所涉 IMG 原规则等级判断，不创建或降级编号规则。

## Alternatives considered

- 只改入口的参考字段：改动最小，但无参考省略、结构化输出和事务术语仍会把读取 reference 的 agent 带入另一条默认路径，因此同步限定相关说明。
- 新增适配代码以统一两套字段：有机会减少格式差异，但本次目标是文案精修与现有行为对齐；旧格式仍用于追溯与回归，不新增运行时转换。

## Consequences

直接任务能按当前骨架交付，旧结构化模板仍保留其字段与示例。审查者需要继续核对来源实物、接受依据和参考像素；文本校验通过不表示图片效果合格。本次不运行生成、供应商调用或模型评测。

- 全部 16 个既有 fenced block、引用块和 ✅/❌ 标记例句与基线一致。

最终复核：独立review确认旧结构化可写暗示，现按既有五文档迁移决定明确旧产物只读追溯与回归用途、继续旧格式编辑须锁定v0.5.0；当前只更新新根Markdown，不反写JSON。全部fences与IMG编号规则不动。
