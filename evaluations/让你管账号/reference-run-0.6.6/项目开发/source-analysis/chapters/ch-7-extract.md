# ch-7 和钟记者多联系就是工作

## 概要

江晨从「视频被误解的当事人」变成「被军报正式采访的宣传典型」——上一章他还在被质疑，这一章他的名字被写进记者的笔记本。张耀祖与周薄森从背后替他辩护，转为当面把他抬成「火箭军团的新星」「文工团的台柱子」，而两人其实连视频都没看过，他们的背书建立在外部热度而非亲眼所见上。钟嘉嘉对江晨的关注同时落在两处：作品（《亮剑》是他原创）与本人（外形），采访结束时她已成为可持续联络的外部资源。张耀祖用命令的形式把这条私人联络线定性为「工作」，并私下判断钟嘉嘉的实习生身份与她的配车、随行兵力不匹配，这条线的分量被留作后手。

## 情节点

P14 转折 | 张耀祖责怪江晨陪美女记者转了一圈连联系方式都没要，把刚要来的钟嘉嘉电话塞给他，说「我命令你，回头多跟钟记者联络联络」「和钟记者多联系就是工作，你当前的重点工作」；江晨无奈接过，苦笑说自己以工作为重 | 涉及：张耀祖、江晨、钟嘉嘉、电话号码 | 功能：私人联络被上级用命令定性为职务任务，江晨失去回避这条线的余地

## 出场人物

- **江晨**：本章被采访的对象。在门口听到上级为自己辩护，接受钟嘉嘉采访并讲述创作过程，把成绩归给领导，之后奉命当向导带钟嘉嘉逛训练场，最后被张耀祖塞了钟嘉嘉的电话。
- **钟嘉嘉**：《军报》记者，自称专程来采访江晨。掏笔记本挖掘素材、完成采访、参观部队，婉拒饭局离开，留下联系方式。原文提到她是实习生。
- **张耀祖**：团长。介绍钟嘉嘉、拍肩鼓励江晨、安排参观与饭局、主动要来钟嘉嘉联系方式并命令江晨多联络，私下判断钟嘉嘉背景不简单。
- **周薄森**：副团长（原文由江晨的称呼与介绍语「周副团长」指出）。喊江晨进门，向记者夸赞江晨的多项本事。
- **士兵们**：训练场上与江晨熟络的官兵，喊他「江导」「晨哥」「江爷」，催他拍新片。

## 未决项

- 张耀祖与周薄森在门口那段「为自己辩护」的具体内容未在本章写出，指向上一章的事件，本章无法判断被辩护的是哪一件事。
- 钟嘉嘉的实习生身份由张耀祖的内心判断给出，她真实的背景、配车与随行兵力由谁安排，原文未明确。
- 《亮剑》一曲的创作与发布时间点，与江晨「到文工团不到一天」的说法之间的时间关系，原文未明确。
- 周薄森称江晨「唱功也没得说」的依据未写出，本章无法判断他是听过还是转述。
- 张耀祖说的「贵客」与他私下的怀疑是否指向同一层含义，原文未点破。
