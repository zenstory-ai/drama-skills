# 剪辑单格式规范

撰写 `剧集/<EP>/剪辑单.md` 以供 `edit_tool.py` 自动校验、渲染与验收时，按本规范组织交付规格与各剪辑段字段。完整样例可对照 [剪辑单样例](../assets/剪辑单.md)。

## 一、开头交付规格

在首个 `## CUT-...` 之前声明本集交付规格：

- **必填规格**：`成片目标时长`、`画幅与帧率`、`交付响度`、`字幕`。
- **可选全局参数**：`- 接镜匹配：无`（整集关闭同场自动接镜）、`- 颗粒：<0–20|无>`（全片动态颗粒强度）。
- **未采用镜头**（全集交付时填写）：`- 未采用镜头：<MOTION-...、GROUP-...或SHOT-...>（理由：文件缺失｜质量不可用｜叙事取舍——说明）`，多条之间用全角分号 `；` 分隔（传 `--partial` 局部试剪时，未入片镜头自动归入提醒，见 [镜序、镜头下落与打戏切法](editing-guide.md#镜序镜头下落与打戏切法)）。

## 二、剪辑段字段（`## CUT-<EP>-<序号> · <名称>`）

每段使用二级标题 `## CUT-<EP>-<序号> · <名称>`（未改动段落保留原 `CUT-...` 编号）。同一条 `MOTION-...` 或 `GROUP-...` 拆成多段使用时，源视频截取区间默认不得重叠；同一张静帧图片可跨多段复用。

| 字段 | 写法与校验要求 |
|---|---|
| `- 来源：` | 视频段写 `<MOTION-...或GROUP-...> · <项目相对路径>`（对应 `视频提示词.md`）；静帧段写 `<SHOT-...或IMG-...> · <图片路径>`（支持 `.png`/`.jpg`/`.jpeg`/`.webp`，入点固定 `0.00`，出点等于时长；硬下限 `2` 帧即 24fps 下 `0.08` 秒，短于 `0.50` 秒列入提醒） |
| `- 入点：` / `- 出点：` / `- 时长：` | 保留两位小数秒数（不写时码或帧号），须满足 `出点 - 入点 == 时长` |
| `- 取舍：` | 写成 `入点=<理由>；出点=<理由>`，写清入出点那一帧的具体画面动作与切镜理由，不写空泛的「节奏需要」 |
| `- 重放：` | 可选；本段与前序剪辑段截取同一源视频重叠区间（如高潮动作重放、悬念闪回）时填写 `<叙事理由>`，显式豁免同源重叠报错 |
| `- 声音：` | 记录保留原声或外部混音做法（仅作文字记录，`render` 不按自然语言自动混音） |
| `- 画面：` | `无`（采用默认同场自动接镜）、`不校`（跳过自动接镜）或手动调色参数（如 `亮度 +0.06；色温 -6`，取值范围见 [接镜调色与颗粒](editing-guide.md#接镜调色与颗粒)） |
| `- 字幕：` | `<逐字台词原文\|无>`，逐字照抄 `剧本.md` 台词与标点（语音转写只用于找时间点）。一段内多句时连续编号并标明相对本段入点的起止秒数（互不重叠，结束可跨入下一镜）：`- 字幕 1：0.20-1.50 请进`。句末可加 `（重点：<词>｜<词>）` 高亮标黄；工具按剧本角色自动区分字幕色（普通对白白色、`[VO] 系统：` 青色、其余 `[VO]` 浅青色） |
| `- 音效 N：` | 可选；`<起>-<止> <项目相对路径>（起点：<秒>；增益：<dB>）`，时间须落在本段内，增益 `-40` 到 `+6`，括号参数可省 |
| `- 运镜：` | 仅用于静帧段；`<固定\|推近 n%\|推近 r%/秒\|…>`，支持推近/拉远/左移/右移/上移/下移（幅度 `n` 取 `1–30`，速度 `r` 取 `0.1–10`），见 [静帧段与运镜](editing-guide.md#静帧段与运镜) |
| `- 配音 N：` | 可选；`<起> <项目相对路径>（起点：<秒>；增益：<dB>；叠音）`，`起` 可填负数提前入声，尾音可跨切点延续；短于 `0.50` 秒的自然抢话或注明 `叠音` 时列入提醒而不报错 |
| `- 环境声：` | 可选；`[<起>] <项目相对路径>（起点：<秒>；增益：<dB>）` 或 `[<起>] 无`，循环铺底直至下一条 `环境声` |

## 三、可选画面图文叠加层（`- 画面文字 N：`）

`画面文字` 属于**可选**叠加层，需本机配置 [Remotion 图文叠加层](../assets/remotion/README.md) 才能由 `edit_tool.py render` 自动烧录（若无 Node/Remotion 环境，可省略 `画面文字` 行直接走默认 `ffmpeg` 渲染，或输出无叠字成片交外部剪辑软件叠加）。

基本语法为 `- 画面文字 N：<起>-<止> <样式> <项>｜<项>…`（单条可省编号，同屏位置时间段不得重叠）：

- **出处核对**：文字内容须在 `剧本.md` 的 `[画面文字]` 行有原文出处（`字卡` 样式还可直接匹配剧本场头 `## EP...-SC...` 中的时间、地点或场景词）。

### 通用叠加样式

| 样式 | 适用题材与各项结构 |
|---|---|
| `字卡` | 干净无外框的通用字幕卡（适合现代都市、古风悬疑、年代等各类题材的时空地名、人物头衔或关键信息条，支持 1 至多行） |
| `卡片` | 通用数据展示卡，每项一行：首词为名称、末词为数值、中间为单位（如 `本月 订单 128｜退货 3`） |
| `角标` | 右上角单行标签（相邻两段写同一角标且首尾紧接时保持常驻，不重复播入场动画；末尾可选 `（倒计时：<秒>）` 或 `（倒计时：接续）`） |

### 可选题材模板（系统流 / 游戏面板风格）

以下两类为面向系统流/游戏界面题材预置的可选叠加模板，非系统流短剧无需使用：

| 样式 | 各项结构与可选标注 |
|---|---|
| `系统面板` | 首项为打字机逐字浮现的状态行，其余各项为奖励行（组件自动绘制 `【系统提示】` 框头，不写进剪辑单） |
| `任务面板` | 依次为标题、目标（打字机效果）；形如 `<数> / <数>` 的项识别为进度条，其余为奖励标签（组件自动绘制 `【新任务】` 与 `进度` 字样；末尾可选 `（倒计时：<秒>）` 或 `（倒计时：接续）`） |

上述两类模板的奖励项末尾可选标注品阶后缀 `（传说）`、`（史诗）`、`（稀有）`（不标默认稀有，后缀不参与剧本原文核对）。
