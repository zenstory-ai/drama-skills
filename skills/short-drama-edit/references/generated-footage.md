# 生成素材的可用区间

## 先检查素材

逐段播放素材，可按 `0.25–0.5s` 抽帧并在疑似缺陷处加密到逐帧，记录实际时长、可用区间与不可用原因（起始等待、动作回弹、身份/道具漂移、异常提亮、重复表演、口型错位）。

可用区间短于计划时长时：

- 已完整承载信息与表演：直接缩短。
- 其他素材可承接：换镜、调整镜序，或保留完好对白音轨另配画面（在剪辑单记录外部处理）。
- 关键动作、台词或反应缺失：列进「未采用镜头」或报告缺口，并向对应上游反馈缺陷发生时间、具体画面与目标状态。

## 接镜与色彩一致性

`render` 默认在同场景内执行自动接镜（`EDT-20`）：将剪辑单中相邻且经《视频提示词.md》与《分镜.md》追到同一场景 ID 的分段归为一组，按逐通道均值与离散度向组内中位数拉近 `70%`（换场、插叙和追不到场景的分段不动），应用的数值列在输出「自动接镜」中。整集关闭自动接镜可在交付规格写 `- 接镜匹配：无`。

自动接镜受全画面景别与背景面积影响，单段覆盖方式如下（`EDT-16`）：

- 段内存在有意光态变化（关灯、闪回、冷暖对比）：写 `- 画面：不校`（不校正且不计入组内中位数）。
- 自动接镜后仍有可见偏差：按同光态下的脸部、衣物或中性表面比对，写入手动校正（替代自动接镜且不计入中位数）：

```text
- 画面：亮度 +0.06；色温 -6
```

内置支持范围：`亮度`（加法偏移 `−0.25…+0.25`）、`饱和`（倍数 `0…2`）、`色温`（冷暖偏移 `−30…+30`，正数提红压蓝）。超出此范围或需局部调色时用外部工具处理。

## 颗粒

在交付规格写 `- 颗粒：6`（范围 `0–20`；不写或写「无」则不加），由 `render` 在拼接后对整片统一施加动态噪点（`EDT-18`）。
