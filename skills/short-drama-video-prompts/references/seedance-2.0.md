# Seedance 2.0 提示词写法

在目标模型配置明确指定 `target_video_model: seedance-2.0` 时使用。推荐配置：

```json
{
  "target_video_model": "seedance-2.0",
  "video_prompt_dialect": "seedance-2.0",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 4, "max": 15},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference", "extend"],
  "audio_generation": "same_pass"
}
```

## 专属标记语法与多镜切法

- **镜头切分**：单镜按因果先后顺序连贯描写；多镜合生用 `镜头1：`、`镜头2：` 分段（**Seedance 2.0 只认镜头序号、不识别精确时间码**，需精确卡切点时优先逐镜单拍或出片后精剪）。
- **声音与字幕标记**：现场对白写 `{角色用中文说：“逐字台词”}`（保持单一口语语种，专有名词除外）；动作音效写 `<声音>`，音乐写 `（音乐）`；需要显示画面外花字时才用 `【字幕】`，存在乱码叠字风险的场景按需补充“无字幕叠加”且正文不出现 `【】`，画内必读招牌或纸页文字写清所在物体表面与位置。
- **前景遮挡与画外视线**：写清机位架在哪一侧、谁在前景谁在后景、中间隔着什么陈设（避免笼统写“隔桌面对面”导致人物挤到同侧）；看画外角色时点明“看向画外、对方不入画”。

## 三种互斥输入模式与素材编号

首帧（1 张图）、首尾帧（2 张图）与全模态参考（0–9 张图、≤3 段视频、≤3 段音频，音视频单段 2–15 秒且同类总长 ≤15 秒，音频不可单传）在**同一次生成中彼此互斥**：

- **锁构图 vs 多参考取舍**：要求把开场或收尾构图像素级锁死在某张关键帧上时，走**首帧或首尾帧模式**；需要同时挂角色设定图、关键道具图或参考音频时，统一走**全模态参考模式**并在正文写明“`@图片1` 作为开场画面”。
- **标签复现与按焦选图**：正文中每次提到绑定素材都带上对应序号标签（如 `人物 @图片1`、`参考 @视频1 的运镜`、`参考 @音频1 的音色`）。参考图超过 9 张上限时，按本镜景别与视觉焦点灵活取舍（近景特写优先保面部与手持道具图，全景调度优先保空间布局与全身图，见 [模型与交付配置](model-and-delivery-profiles.md)）。
- **视频续写（按需选用）**：需紧接上一段真实成片做连续动作延长时，写明“向后延长 `@视频1`”并可搭配截取的真实尾帧 `@图片1` 稳住接缝姿态（不要笼统写成“参考 `@视频1`”）。

## 字数上限与支持时长

- **字数控制**：官方建议中文不超过 500 字、英文不超过 1000 词（过长易把顺嘴带到的背景摆设全塞进画面或触发意外硬切）。超限时优先删减已由参考图承载的静态背景铺垫，保留核心动作、锁定特征与逐字台词。
- **支持时长**：支持 **4–15 秒整数**或 `duration: -1` 自适应（上限仍为 15 秒）；定长分镜直接传正整数秒，含对白镜头按 [台词时长估算](performance-action-timing.md#台词时长估算) 核对发声时间，出片后实测核查句尾是否完整。
