# Agent Note: 剪辑资料与静帧、配音实现对齐

Status: implemented

## Problem

剪辑已支持静帧来源和独立配音，但阶段规则仍只允许 MOTION 来源，多处说明仍把声画分离全部交给外部工具；声音参考遗漏现有配音与环境声通道，字幕参考又把时间限制在本段，与现有跨切点字幕冲突。

## Decision

已按五步流程精修本技能十份文档，按实际解析与混音实现区分视频自带音轨、独立配音和环境声。统一静帧来源、跨切点字幕和剪辑单原文与渲染标点的范围；保留 EDT ID、四级规则、命令、代码块及样例字段。

## Alternatives considered

- 为文档新增渲染能力可消除限制，但本次已有配音与环境声实现，只需准确交代其范围，不扩展运行时。
- 把所有声音处理继续写成外部完成最简短，但会隐去已支持的独立配音与跨切点路径，因此按具体任务路由。

## Consequences

用户能按已有素材选择视频或静帧剪辑，明确哪些声音可在内置流程处理。代价是区分原视频音轨与独立声音文件仍需结合素材判断，工具测量不能替代回听与画面检查。

既有 selftest 通过；所有代码块和 EDT ID / Class 逐字保护。字幕检查按去标点与空白后匹配描述，逐字照抄仍由作者对照核查。

独立 review 又按 `check_cuts` 的静帧/视频分支修正 EDT-02：静帧没有源视频时长，使用 0 入点、声明时长与最低 0.50 秒；视频段才与源素材实测时长比较。ID 与 Class 不变。

同一静帧可用于多个 CUT；EDT-06 与主文的区间重叠限制明确仅适用于视频源时间，和 `_overlap_findings` 跳过 still 的实现一致。

CI 验证补充：Remotion 官方许可证链接同步登记到精确公开 URL 清单；扫描范围、精确匹配和泄漏阻断行为不变。
