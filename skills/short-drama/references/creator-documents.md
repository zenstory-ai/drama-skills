# 五份创作文档

## 文档归属与输出语言

每集按需维护五份直接面向创作者阅读和编辑的 Markdown 文档，可从任意已有材料直接切入后续环节，未做到的环节不预建空文件；每个技能只修改自己负责的文档，固定编号（`EP001-SC001`、`IMG-...`、`SHOT-...`、`MOTION-...`、`GROUP-...`）写入标题供跨文档直接引用，不另存隐藏索引或哈希副本。规则分级见 [规则与路由索引](knowhow-index.md#规则分级与优先级)。

| 环节 | 负责技能 | 文档路径 |
|---|---|---|
| 剧本 | `short-drama-write` | `剧集/<EP>/剧本.md` |
| 视觉设定 | `short-drama-assets` | `剧集/<EP>/视觉设定.md` |
| 分镜与首尾帧提示词 | `short-drama-storyboard` | `剧集/<EP>/分镜.md` |
| 图片提示词 | `short-drama-image-prompts` | `剧集/<EP>/图片提示词.md` |
| 视频提示词 | `short-drama-video-prompts` | `剧集/<EP>/视频提示词.md` |

| 输出内容 | 有 `short-drama.json` 时 | 无项目配置时默认 |
|---|---|---|
| 面向创作者的说明与审稿意见 | `short-drama.json#/language` | 用户当前使用的语言 |
| 图片提示词、首尾帧可复制正文 | `short-drama.json#/format/prompt_language` | 按文档实际提示词语言或用户指定语言 |
| 视频提示词可复制正文 | `creator_authority.production_profile.choices.video_prompt_language`，未设时沿用 `format.prompt_language` | 按目标视频模型习惯或用户当前语言 |

画面内的角色对白与招牌字样一律以剧本和视觉设定原文为准，不随提示词描述语言改变。

## `剧本.md`

- 一级标题以集号开头（如 `# EP001 集名`）；每场戏用 `## EP001-SC001 内 · 地点 · 时间/天气`，空间性质填 `内`、`外` 或 `内外`。
- 对白写成 `角色（可选表演提示）：台词`；画外音、画外对白、音效、画面文字、连戏说明和转场分别用 `[VO]`、`[OS]`、`[SFX]`、`[画面文字]`、`[连续性]`、`[转场]`，动作描写含冒号时避免误写成人物对白格式。

## `视觉设定.md`

文档开头写明 `- 制作形态：` 与 `- 时代背景：`（年代及电子设备、制服、陈设、照明基准）；正文二级标题固定为 `## <人物|造型|地点|道具> · <名称>`，只记跨镜不变的外观特征、本集造型/状态与变化节点。系统面板、名条等纯后期图形写明 `只在后期叠加`，不送入生图或生视频。

```markdown
## 人物 · 许棠
- 外观特征：窄长眼、左眉尾旧疤、肩背略绷。
- 本集造型：深灰旧西装，右袖口有雨水深痕。
- 状态变化：EP001-SC003 后右手掌沾血。
- 角色声线：青年冷感男中音，语速偏稳。
- 提示词名称：Xutang
- 连戏锁：LOCK-XUTANG-SUIT《许棠深灰旧西装》（镜头：入画；图片提示词项：IMG-XUTANG-SHEET）· 锁定词：dark-grey worn wool suit
```

- **提示词名称**（跨语言点名时选填）：当提示词正文使用的语言与设定条目语言不同（如中文设定配英文提示词）且正文需点名该对象时，填写外文拼写（多个写法用 `、` 分隔，每项至少两个字符）；同语种提示词直接按条目名称核对无需填写；易与普通词撞名且不直接点名的条目可写 `- 提示词名称：无`。
- **角色声线**：需跨集固定角色配音时填写，仅对在 `剧本.md` 中实际有发声对白的人物必填，零台词角色免填；已选定真实样音时写 `- 声音参考：<项目相对路径>（…）`。
- **连戏锁**：只锁跨镜出现且本集不变的硬外观细节。`镜头：` 可填 `入画`、`全集` 或 `SHOT-...` 列表，`；图片提示词项：` 可选，`· 锁定词：` 填简短外观名词短语。锁定词强制覆盖被点名的 `IMG-...`、`SHOT-...` 首帧提示词，以及尚未由对应参考图锁住该外观的 `MOTION-...` / `GROUP-...`（仅当该镜绑定了真实 `REF-...` `起始帧`、绑定本镜或含该锁定词镜头的 `PLAN-...` `起始帧`，或绑定覆盖该具体设定/设定图的 `主体` / `造型状态` 槽位时免贴静态锁定词；`GROUP-...` 自行声明 `- 输入参考图：` 时按分组自身参考图核对，省略时仅在所有受锁成员镜均已豁免时免贴）。

## `分镜.md`

整场决定不拍时在首个 `SHOT-...` 前写 `- 未拍场次：<场景 ID>（理由：……）`；一场拆多镜时可先写 `## 场景站位 · <场景 ID> · <地点>` 定清陈设、站位与轴线。

```markdown
## SHOT-EP001-001 · 门外停步
- 来源：EP001-SC001
- 时长：4s
- 目的：先让观众看见他不敢进门，再听见门内争吵。
- 景别/机位：中近景，门框外侧，轻微低机位。
- 运镜：固定；收手动作需稳稳看清。
- 起点：许棠右手悬在门把上方。
- 动作：门内传来玻璃落地声，许棠猛地收回右手，目光转向门缝。
- 终点：许棠右手垂回身侧，目光落在门缝。
- 图片提示词项：IMG-XUTANG-SHEET《许棠角色板》（控制：外貌、体态、本集造型）
- 输入参考图：无
- 出场设定：《视觉设定.md》·人物「许棠」（控制：外貌、体态、本集造型）；地点「旧走廊」（控制：空间布局、出入口、光向）。

### 首帧提示词
> 按项目提示词语言编写的首帧定格画面正文……
```

- `### 首帧提示词` 对齐「起点」定格瞬间，可选补 `### 尾帧提示词` 对齐「终点」。
- **关联字段**：
  1. **图片提示词项**（可选）：需要关联《图片提示词.md》设定图时填写 `IMG-...《名称》（控制：范围）`，未关联时可省略或写 `无`。
  2. **输入参考图**：挂项目内真实图片用 `REF-...`，外部工具手动挂图用 `PLAN-...`（支持十种 `用途`：`外貌`、`主体`、`造型状态`、`空间布局`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格`，详见 [参考图用途](reference-roles.md)）。正反打（如 A-B-A）等回到同一机位的不同 `SHOT-...` 允许合理复用同一个 `PLAN-...` 预留图位；未垫图走文生视频时可直接写 `- 输入参考图：无`（兼容 `无（文生视频）`），需先等创作者补图时写 `无（待补参考图：……）`。
  3. **出场设定**：按 `### 首帧提示词`、`### 尾帧提示词` 以及文生视频 `- 开场画面：`（同时识别设定条目中文名与非 `无` 的 `提示词名称`）实际点名的设定条目填写（无设定条目时写 `无`；不扫描 `来源` 台词引文逼标画外；若上述文本提到了不在画内的设定名，可在行尾加 `；画外：人物「小明」`）。

```markdown
REF-<slot>（顺序：<n>）· <项目相对路径>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
PLAN-<slot>（顺序：<n>）· <IMG-... 或 SHOT-...>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

常见参考组合示例（无设定图且文生、仅挂项目内实拍/定妆参考图、设定图与参考图并存）：

```markdown
- 图片提示词项：无
- 输入参考图：无
- 出场设定：《视觉设定.md》·人物「许棠」（控制：外貌、体态、本集造型）；地点「旧走廊」（控制：空间布局、出入口、光向）。
```

```markdown
- 图片提示词项：无
- 输入参考图：REF-XUTANG-LOOK（顺序：1）· 输入/参考图/许棠定妆.png《许棠定妆照》（用途：外貌；控制：脸型、体态；不得控制：构图、动作）
- 出场设定：《视觉设定.md》·人物「许棠」（控制：外貌、体态、本集造型）。
```

```markdown
- 图片提示词项：IMG-XUTANG-SHEET《许棠角色板》（控制：外貌、体态、本集造型）
- 输入参考图：REF-XUTANG-LOOK（顺序：1）· 输入/参考图/许棠定妆.png《许棠定妆照》（用途：外貌；控制：脸型、体态；不得控制：构图、动作）；REF-CORRIDOR-LAYOUT（顺序：2）· 输入/参考图/走廊空镜.png《旧走廊空镜》（用途：空间布局；控制：门窗方位、走廊纵深；不得控制：人物姿态）
- 出场设定：《视觉设定.md》·人物「许棠」（控制：外貌、体态、本集造型）；地点「旧走廊」（控制：空间布局、出入口、光向）。
```

## `图片提示词.md`

每个条目对应一张设定图（标题 `## IMG-... · <名称>`），`- 参考：` 填 `无外部参考` 或 `REF-...` 真实图片，提示词写在 `### 可复制提示词` 引用块（`>`）内。

## `视频提示词.md`

每个正式镜头对应一条同编号 `MOTION-...`：

```markdown
## MOTION-EP001-001 · 门外停步
- 分镜：SHOT-EP001-001
- 时长：4s
- 生成方式：文生视频
- 输入参考图：无
- 开场画面：昏黄走廊低机位中近景，许棠身穿深灰旧西装站在木门外，右手悬在黄铜门把上方。
- 起始帧：许棠右手悬在门把上方。
- 动作过程：右手悬停 → 门内传来玻璃碎裂声，许棠猛地缩回右手 → 目光压向门缝
- 终点：右手垂回身侧，目光停在门缝。

### 可复制提示词
> 按目标视频模型语言编写的单次可生成视频提示词正文……
```

- `- 输入参考图：` 可在对应分镜基础上按视频生成需要增减（如已挂起始帧时省去静态设定板，或增挂承接帧）；绑定角色音色时单起一行写 `- 参考音频：`（`控制` 可填 `音色、音区、语气、语速、台词节奏` 的任意非空子集或合理声学描述，不把本镜剧情情绪锁给固定样音）。
- 挂有 `REF-...` 或 `PLAN-...` 时填 `- 生成方式：图生视频`；未垫图（`无` 或 `无（文生视频）`）时填 `- 生成方式：文生视频`，并填写非空的 `- 开场画面：` 交代起始画面（该行点名的设定条目同样纳入本镜 `出场设定` 核对；无需把 `开场画面` 原字作为子串机械粘贴进 `### 可复制提示词`）。
- 可复制提示词中由说话引导词（如 `说：“……”`、`道：「……」`、`says "..."`）或 `<d>` 标签明确引出的角色发声台词，须与《剧本.md》或本镜声音设计一致；招牌字样、成语或声音质感描述不受台词核对限制。
- 同场顺序相邻的多镜做一次多镜合生时，保留逐镜 `MOTION-...`，在文末补充 `## GROUP-... · <名称>`（含 `- 成员：`、等于成员之和的 `- 时长：`、可选 `- 输入参考图：` 与 `### 可复制提示词`）。

## 通用要求

`### 可复制提示词`、`### 首帧提示词` 与 `### 尾帧提示词` 下的引用块（`>`）直接交付模型单次生成，不混入占位符、流程备注、内部路径或环境变量密钥。
