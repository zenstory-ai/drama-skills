# 示例

三份示例分别服务创作者参考与仓库回归测试；日常创作只需看 `creator-first/`。

| 目录 | 回答的问题 | 规模 |
|---|---|---|
| [creator-first/](creator-first/) | 新项目默认到底留下什么？ | 一集五份完整 Markdown，0 JSON/JSONL |
| [excerpt-chain/](excerpt-chain/) | 历史节选：同一场戏如何穿过四个阶段？ | 一集四份 Markdown 节选 |
| [golden-project/](golden-project/) | 维护校验器的完整回归夹具 | 八集结构化测试数据 |

新项目先读 [creator-first/](creator-first/)：它是全套五份创作者文档的完整公开样例。

`excerpt-chain/` 与 `golden-project/` 只服务仓库维护、校验器回归和历史测试覆盖，不作为当前 Skill 的操作说明，也不定义 creator-first 的公开产物；日常创作不需要手写结构化 JSON/JSONL。
