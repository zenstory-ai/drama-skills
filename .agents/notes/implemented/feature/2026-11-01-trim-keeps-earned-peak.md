# Agent Note: 压稿保留有铺垫的爆发与宣判句

Status: implemented

## Problem

写作技能的经济性遍要求删去「回报后多个同方向决定、解释或后果」，`SCR-21` 要求写作者回读自写对白，
删掉不承担动作或冲突的句子。这两条在复仇、逆袭一类靠结算取悦观众的戏里会误伤：一场戏唯一的峰值上，
有铺垫的爆发、紧跟的关系宣判句（例如「我们之间，到此为止。」）和离场动作，会因为
「离场已经表明了决定」被当成同义收尾。

基线：一份合成的逆袭集和一份家庭集都超出目标时长，用现行技能按目标时长压稿，跑 3 次。空喊 3/3 次被删，
没有一处跨句依赖被删断，一句话完成的情感反转 3/3 次被指出；但有铺垫的爆发或宣判句在 2/3 次里被删或压扁，
其中一次把宣判句列为「冗余」，改按项目时长恢复篇幅时也没有放回。

## Decision

`script-craft.md` 的经济性遍新增 `SCR-23`（`craft_default`）：压稿前先认出这场戏的回报。峰值上有铺垫的爆发、
紧跟其后的宣判句和收住这一拍的动作都承重；即使离场已经表明了决定，宣判句也不算同方向收尾。时长不够先删别处，
爆发台词只压缩重复。没有铺垫、不带来新情绪阶段、与前文同义的空喊照删。`SKILL.md` 的压稿指令旁注明这个例外并指向这一段。

候选：同一份材料、同一份答案，用只多出这一段的技能副本跑 3 次。爆发与宣判句 0/3 次被删，空喊仍 3/3 次被删，
没有因此多留别的台词；有一次整场合并后留下一处悬空的人物引入，与这条规则无关。

## Alternatives considered

- **不改，只靠已有的「直白是 `taste_option`」和 `SCR-06`**：规则已经允许直白，再加一条会显得重复。未采用：
  基线读过这两条仍删了宣判句，依据是经济性遍和 `SCR-21`；允许直白，不等于压稿时知道这句承重。
- **改宽「回报后同方向决定」的删除规则**：一处改动覆盖更多情况。未采用：这条规则在大多数场次上正确，
  放宽后基线里本该删的同义收尾也会留下；问题只出在峰值上的结算，改动应只落在那里。
- **在审查技能里加一条防误报说明**：审查也可能把宣判句当成标语。暂不做：这次只测了写作压稿，没有审查误报的证据。

## Consequences

- **收益**：复仇、逆袭等靠结算的戏在压稿后仍保留观众等待的那一下。
- **代价**：证据只有一次合成测试、每臂 3 次，只能说明在这组材料上有效。哪句算「有铺垫的爆发」仍靠写作者判断，
  可能被拿来保护本该删的长篇宣泄；规则写明空喊照删，候选测试里也没有观察到过度保护。
