# 目标模型与交付配置指南

本指南说明目标视频模型的参数读取、未定模型时的 `generic` 通用档默认策略、音画同出与后期配音分流、参考素材取舍，以及单拍、多镜合生与连续动作续接的交付组织方式。

## 一、目标模型配置与 `generic` 默认档（`VID-10`）

项目级模型配置存放在 `short-drama.json#/creator_authority/production_profile/choices`（供应商接口地址与密钥归 `$short-drama-produce` 管理，不写进创作文档）：

```json
{
  "target_video_model": "generic",
  "video_prompt_dialect": "generic",
  "video_prompt_language": "en",
  "native_duration_seconds": {"min": 4, "max": 15},
  "supported_generation_modes": ["text", "reference"],
  "audio_generation": "separate"
}
```

- **命中专属模型卡时只读对应一卡**：`target_video_model` 明确为 `minimax-h3`、`seedance-2.0`、`seedance-2.5` 或 `wan-3.0` 时，只打开对应写法指南，按其专属分段语法、素材标签、时长范围与字数上限排布。
- **未指定具体模型时默认输出 `generic` 通用档，绝不停工追问**：项目尚未敲定具体视频模型、配置留空或独立任务未点名模型时，**直接按 `generic` 通用档完成全部视频提示词**——提示词语言跟随 `short-drama.json#/format/prompt_language`（无项目配置时跟随用户当前语言），采用连贯自然的画面动作叙述，不混入特定模型的专有标签符号，默认逐镜单拍，运镜兼顾专业词与直观画面比例变化。后续创作者选定具体模型时，再按对应模型卡转换方言即可。
- **试拍选型经验参考**：需要选型试拍时，MiniMax H3 在定场推镜、多人同框单人开口对白戏上表现稳健；Seedance 2.5 在细腻反应镜、跟摇走位、手部动作近景与夜景氛围上表现突出；Wan 3.0 适合直出中文长段落与多参考素材组合。

## 二、音画同出与后期配音分流（`VID-14`、`VID-23`）

根据模型能力与项目制作路线，声音处理分为两条清晰路径：

| 路线 | 适用场景 | `### 可复制提示词` 写法 | 镜头说明与下游衔接 |
|---|---|---|---|
| **后期配音与混音（`separate`）** | 画面单出模型、`generic` 通用档、或团队决定后期统一配音/TTS 贴片 | 专注写清人物何时张嘴说话、说话神态、呼吸节奏与触发动作的可见物理过程，**不塞同轨语音标签与防杂音咒语** | 在镜头字段记录本镜对白归属、环境底声与跨切点声桥，交 `$short-drama-produce` 配音、`$short-drama-edit` 对口型混音 |
| **音画同出（`same_pass`）** | 模型原生支持同轨生成对白与音效，且项目采用直出声音 | 按模型语法写出声音时间线：标明声源（画内对白 / VO / OS）、说话人、口语语种与逐字台词定界标记（全文单镜只写一次台词文本），交代动作音效与不说话时段的环境底声 | 防开头外语杂音或重复念词的约束仅在模型有此通病或上游明确要求时在声音时间线末尾合并写一句；单镜默认不混入画外背景音乐（`VID-14`） |

- **固定触发词保留（`VID-19`）**：若项目或模型某种模式（如视频局部编辑、向后延长）要求固定触发字样，在台词定界标记之外原字保留，不翻译或换近义词；无固定触发词要求时不自造口令。

## 三、参考素材输入方式与灵活取舍（`VID-24`）

`生成方式` 字段只填 `图生视频` 或 `文生视频`。图生视频的具体输入形态由本镜绑定的参考项 `用途` 组合决定：

| 参考项组合 | 输入模式 | 写作要点 |
|---|---|---|
| 无参考图（`无（文生视频）` 或 `无`） | 文生视频 | 填写非空 `开场画面`，正文完整交代人物、造型（含生效 `LOCK-...` 锁定词）、场景、景别焦段与光线 |
| 仅 1 张 `用途：起始帧` | 首帧模式 | 起始帧锁死开场构图与外观，正文专注写起手之后的动作、神态与运镜变化 |
| `起始帧` + `结束帧` | 首尾帧模式 | 尾帧只定格分镜既定终点，核心复杂动作仍在正文按顺序写明，不靠首尾插值硬猜 |
| 含 `外貌` / `空间布局` / `造型状态` 等多张参考图 | 多图参考模式 | 按 `顺序` 编号引用；若目标模型首尾帧与多图参考互斥，将起始帧并入多图参考组传入 |

- **允许按模型与镜头需要在分镜基础上合理增减参考项**：视频提示词不必机械逐字死抄分镜的 `输入参考图`——例如近景说话镜可补挂角色面部特写设定板，首帧已完整拍出全身与环境的单人短镜可精简多余的场景远景板，需锁音色时可增挂 `- 参考音频：`（`VID-27`）。
- **参考图超模型上限时的按焦取舍**：不再套用死板的固定丢弃顺序，而是**根据本镜景别与视觉焦点取舍**——特写与近景优先保住起始帧、说话/做动作角色的面部外貌图与手头关键道具图；全景调度与走位镜优先保住起始帧、场景空间布局图与主动作角色全身造型图。被精简掉的参考图所承载的特征直接用几句精炼文字补回提示词正文。
- **无起始帧时补足景别取景（`craft_default`）**：只挂角色设定图或场景空镜图而未挂起始帧时，在正文明确写出景别切线（如切在胸口或腰部）、人物占画面比例与机位俯仰角度。

## 四、生成交付粒度：单拍、多镜合生与连续动作续接

1. **逐镜独立生成（默认）**：每条 `MOTION-...` 独立对应一条 `SHOT-...` 送生，相邻镜头默认按各自的首帧或参考图独立出片，**不把同场相邻镜头默认锁死为不可提交的“待续接”状态**。静态漫剧只需关键帧切换配音时，可跳过逐镜动态提示词。
2. **多镜合生分组（`GROUP-...`，`VID-13` / `VID-15`）**：当目标模型支持单次多切且相邻短镜满足**同场紧邻连续、共用同一空间布局与人物道具参考链、无时间跳跃或换装、总时长落在模型单次上限内**时，可在保留各子镜头 `MOTION-...` 条目的同时增补 `GROUP-...` 分组条目（逐镜单拍时不写）：
   ```markdown
   ## GROUP-EP001-01 · 门外到门内
   - 成员：MOTION-EP001-001、MOTION-EP001-002
   - 时长：8s
   - 理由：同场紧邻连续，共用同一走廊空间布局与人物造型

   ### 可复制提示词
   > 镜头1：…… 镜头2：……
   ```
   分组 `时长` 必须等于各成员分镜时长之和（`VID-13`），同一集内每个镜头最多归入一个分组，分组子镜头与未分组单拍镜头不重不漏覆盖全集入画分镜（`VID-15`）。
3. **连续动作续接（`VID-20`，按需选用）**：仅在创作者明确采用视频向后延长（如一镜到底拆段接力），或跨镜硬切接同一连续动作需从上一段真实成片抽末帧校准时启用，要求基于实看上一段成片传入真实视频与截取末帧（细则见 [运镜、现场声与跨镜连戏](camera-audio-continuity.md)）。
