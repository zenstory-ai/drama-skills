# 短剧故事核、矛盾引擎与人物弧光

起草 `creative-brief.md` 与 `story-engine.md`、构建长线连续短剧人物弧光，或梳理伏笔与信息差时配合使用本文件。单集结构、节拍与节奏标准见 [分集架构与节奏设计](episode-architecture.md)；规则分级与 `STY-*` 规则表见 [开发阶段职责与规则](stage-contract.md#本阶段规则)。

## 1. 从题材标签落到一句话故事核

光贴“复仇”“甜宠”“悬疑”“家庭伦理”标签只说明题材货架，没说明观众每集图什么爽感或牵挂。动笔前答清五个问题（`craft_default`）：

1. **核心主角**：观众全程跟着谁顶住危机、做出一次次抉择？
2. **当前诉求**：眼下火烧眉毛想夺回、守住、查清或挣脱什么？
3. **硬阻力**：谁或哪道现实死坎拦在前面，让他每往前拱一步都得付出代价？
4. **核心拧巴处**：主角最拿手的破局路数，为什么会同时伤到他在乎的人或底线？
5. **每集看点兑现**：每集观众盼着看到哪类看得见的处境变化（夺回话语权、当众拆穿谎言、关系挪位、底牌露出一角或两难割舍）？

把五个答案拧成**一句话故事核**：

> 当【核心主角】靠【拿手做法】去争【当前目标】时，【对手或处境压制】逼着他付出【核心代价】；全剧一集集兑现【观众最盼的看点/爽点】，直到【终局破局点】彻底掀翻原有困局。

### 看点落到实处，先立台子再亮王牌

- **情绪口号必须落成看得见的实处**：比如“让偏心家人/渣男追悔莫及”，要么砸在**情感失去**（如嫌油烟从不下厨的主厨逼走妻子后，在空屋翻出妻子按他胃病手抄五年的药膳本，而新欢连他海鲜过敏都记混），要么砸在**地位实权崩塌**（如丈夫刷妻子副卡替小姑子办订婚宴还逼签股份，妻子当场停卡改门禁并甩出小姑子侵占公款审计单报警）。
- **攒气类题材先搭台子再给王牌**：情感、家庭、复仇等靠前文攒气的戏，宜先立起将来要算账的死对头与公开场合，再让主角摸到翻盘底牌；系统流、重生穿越与草根逆袭等直球爽剧则可在第 1 集直接到账底牌当场反杀（见 [题材卡目录](genre-cards.md)）。
- **四条自检**：换个人名职业就和市面上百部剧一样 → 核心拧巴太空；反派听一句解释就罢手 → 缺少利益死结；主角躺着也能赢 → 缺主动破局狠劲；憋到大结局才爽或每集爽法像复印机 → 缺阶段兑现与升级变数。

## 2. 核心矛盾引擎与机制循环

### 2.1 一轮交锋的推进闭环与六大支点

```text
危机逼上门 → 主角顺着脾气与执念出招 → 对手/死规矩/利益牵绊狠招反扑
→ 主角拿下阶段结果并背上新代价 → 强弱、把柄、关系或退路实质改写
→ 变糟的新局面逼出下一轮更难的两难抉择
```

若抽掉中间的“主角抉择”与“付出代价”剧情仍照常推进，人物就成了推事件的工具人。动笔前核准六个支点（`craft_default`：尽量让外部恶人、情义牵绊与现实死线拧成一股绳施压）：

| 矛盾支点 | 动笔前要问透的问题 |
|---|---|
| 危机源头 | 哪个人、死规矩、秘密、资源缺口或人情债会一茬接一茬找上门？ |
| 对手筹码 | 对手攥着什么真能卡脖子的实权或把柄，而不只是嘴臭嗓门大？ |
| 主角路数与软肋 | 主角习惯怎么摆平麻烦？这招好使在哪，又有什么致命盲点？ |
| 为何退无可退 | 为什么不能一走了之、直接报警、摊牌认怂或换个活法？ |
| 局面升级切口 | 交锋一轮轮打下去，实权、知情差、关系底线、秘密范围、钱物时限、伤势空间或良心代价哪一项会变？ |
| 全剧收尾条件 | 哪桩真相大白、哪次蜕变或哪段关系了断会让拉锯彻底画上句号？ |

### 2.2 按核心看点挑选施压支点

| 核心看点重心 | 持续施压手段 | 每集换花样兑现 |
|---|---|---|
| 掉马甲 / 伪装潜伏 | 随时穿帮的风险、两头顾不过来、验明正身的铁证 | 观众多看透一层、关键配角被迫重站队 |
| 职场 / 行业规矩 | 审批权、死线考核、甩锅链、流程漏洞把柄 | 拿死规矩反将一军、黑锅当众物归原主 |
| 家庭 / 家产偏心 | 养老照护债、旧账两套说法、房本存折归属 | 扯下温情遮羞布亮真账，或划清关系界限 |
| 复仇 / 清算旧债 | 铁证能否服众、仇人串供、反扑代价越滚越大 | 拔掉一层护身符，主角也背上更险赌注 |
| 悬疑 / 追查隐情 | 谁亲眼见过、物证多种说法、死无对证盲区 | 筛掉一种假说法，撞上更棘手的生死两难 |
| 轻奇幻 / 规则异能 | 严苛限制、肉疼反噬代价、奇招撞上现实俗规 | 巧用规则盲区四两拨千斤，不靠堆特效 |
| 婚恋 / 情感拉扯 | 谁更离不开谁、死要面子、旧诺未兑现、越界底线 | 硬撑方先软下身段换打法，或摊开暗中代价 |

### 2.3 机制循环与主题两难

- **机制循环适用边界（`craft_default`）**：仅适用于**系统流、规则怪谈、行业闯关、高密度夺权博弈**等靠同一手艺反复闯关的题材（**温情生活流、日常市井与纯粹情感剧靠人物心境与关系冷暖流淌，切勿硬套机械闯关齿轮**）。适用题材按三条防写疲：
  1. **调换顺序测试**：首回合演透打法，后续每回合若与上一回合对调顺序剧情仍顺畅，说明原地炒冷饭；必须让对手防备升级、知情名单扩大或老退路封死。
  2. **见顶即换招**：老办法被对手焊死时，用**彻底收束**（绝版底牌一锤定音并牵出新隐患）、**翻新规则**（换场合/出面人/赌注）或**攻守易手**（对手学会同招反制）开启新单元。
  3. **付费卡点按体量动态落位**：不套“固定第 3/10 集”死公式，随全剧总集数与重头爽点自然排布。
- **把主题放进两难抉择**：不喊说教口号，把主题拧成两样无法两全的价值（如“守规矩 vs 护身边弱者”“独立尊严 vs 虚假温情”），让不同人物拿真金白银的代价选不同路。

## 3. 人物驱动、双向拿捏与弧光推进

### 3.1 人物小传、观众缘与双向牵制

- **人物小传八个支点**：明面诉求、绝不肯换的死守底线、心里如何替越界找理（自洽逻辑）、遇事习惯打法、真能逼人让步的筹码、性格盲点、平时打死不干的破戒红线，以及彻底变招的拐点。
- **首集立住观众缘（四选一，悬疑/反英雄/喜剧可改靠险境、魅力或乌龙反差）**：正替人背一眼可见的黑锅；正替露了面的弱者扛雷；拼命护住普通人共情的尊严或公道；亮出令人直呼过瘾的看家绝活。
- **把关系写成双向拿捏**：不填干巴巴的“母女/上下级”，写清“甲有求于/忌惮/拿捏乙什么 ↔ 乙有求于/忌惮/反制甲什么”，配角与反派都要有真实算盘与筹码。市井温情或轻喜剧可落在“暗中兜底却嘴硬、刀子嘴豆腐心护短、好心办坏事的乌龙错位”上，不硬套苦大仇深的算计。

### 3.2 人物前史三档管法（别塞进首集台词）

只梳理真能解释“眼下为何非这么选”的旧事，按亮底时机分三档，绝不在第 1 集借角色之口背简历：

1. **第 1 集画面当场看懂的**：不交代就看不懂眼前动作（如冷链主管林岚凌晨两点熟门熟路模仿弟弟笔迹把空白温控栏补填成 `-18℃`）。
2. **作者心里有账、不必台词点破的**：五年前这套核查规矩正是她亲手定的，用来支撑她改账有多老练，无需配角在旁夸她资历老。
3. **先捂实、留到中后段引爆的**：三年前父母住院那笔救命钱其实是弟弟赌博输光的窟窿，留到中段翻出原始缴费单再炸开。

### 3.3 在硬仗与两难中推进弧光（`craft_default`）

人物弧光靠一桩桩逼老办法失灵的危机推着走，全剧转变统一记在 `story-engine.md`，少靠嘴上喊“我醒悟了”代替行动转变：

`原有路数 → 撞上硬茬危机 → 死守老招 / 试换新法 / 心软退回 → 当场阶段结果 → 咽下苦果代价 → 迎头撞上更要命的考验`

典型六步台阶（以替弟改账的林岚为例）：① 尝到甜头继续护短 → ② 信念裂开第一道缝（改平断电记录差点害医院退回变质血清）→ ③ 试立规矩却没狠下心（抽检员一来又替弟挡了五分钟）→ ④ 心软打回原形（老母求情后又背处分）→ ⑤ 斩断退路的决断（撞破亲弟夹带假药还欲嫁祸自己，当众落锁封库交出原始底账）→ 或 ⑥ 执迷不悟滑向悲剧警示结局。

- **防外来转机把主角挤成看客**：当救兵、铁证或反派内讧从外面送上门时，须同时写清主角前面干了哪件实事才引得转机**偏偏此刻**赶到，以及主角接过转机后**当场拍板做了什么处置**（如被抢手机架出酒店时一拳砸响消防警报逼停保安再亮工牌封账，而非干等秘书路过救驾）。

## 4. 冲突真升级、信息差与伏笔回收

### 4.1 四问核查真升级与四种推法（`reviewed_invariant · STY-03`）

重头冲突戏前后必核四问：攻守主动权换人了没有？谁新拿到或丢掉了铁证/帮手/资格？两人关系更近、生分还是强弱更悬殊？哪一步棋落子无悔且令下一仗代价更肉疼？常用四种推法：

- **扩圈**：关门小摩擦烧到公开台面或更重问责；
- **反制**：对手摸透老招后焊死退路（如知道主角录音便先开屏蔽收手机）；
- **代价兑现**：前文图救急埋下的隐患反成勒脖子的绳索；
- **反转改义**：新物证让前文画面换了全新意思且严丝合缝。

巧合主要用于开场或中途惹麻烦，避免危急关头靠天降巧合白送退路（错位喜剧/闹剧刻意用连环巧合当包袱除外）。

### 4.2 信息差三层物证分寸与伏笔回收（`reviewed_invariant · STY-05`）

排悬念与误会时列清“客观底细 / 各人以为的版本 / 观众已知进度 / 亮出哪件铁证砸醒谁”，每件物证卡准三层分寸（`craft_default`）：

1. **画面可见物证（`visible_carrier`）**：如蓝牙弹窗显示两只耳机电量 100%、昨晚佩戴 0 分钟；
2. **当场能坐实的结论（`supported_claim`）**：丈夫撒谎没戴耳机、半夜心率飙升必有猫腻；
3. **留待深挖的疑点（`unresolved_inference`）**：单凭满电耳机绝锤不死“摸进主卧的是谁”，须等下一件独立铁证，严禁开天眼乱指认。

**自然埋线、记账回收**：伏笔必披一层**当场顺理成章的表面理由**，并在分集大纲 `setup_payoff` 中对账回收（例如第 1 集 ATM 余额为 0 遭质疑私吞彩礼，新娘顺口说“这卡是三个月前定亲那天您和许浩陪我去办的专卡”，当场只为自证没拿错卡；第 3 集查出钱被办卡当天刷脸开通的第三方代扣秒扣，第 1 集随口那句话瞬间变成抓未婚夫内鬼的铁锤）。

**跨集连戏备忘录**：每定稿一集，对照 `story-engine.md` 的「跨集连戏备忘录」只更新变动项，已结清旧事浓缩或移出；若备忘与定稿剧本有出入，一律以定稿剧本为准。

## 6. 合成示例（共享厨房）

> **故事核**：商业街改造在即，物业紧盯“私自替班或台账造假”把柄欲无偿收回低租共享厨房。排班员叶澄为保十几个小摊主饭碗，常年私下替急事摊主顶班并涂改明面排班本，把真实换班垫付记在冷柜夹缝底账里；她每次暗中包办救场都让明账破绽百出，既赢得摊主喘息又引来不知情摊主猜忌倒戈，直到必须在“一人暗扛”与“摊开底账众人共担”间做了断。

- **矛盾支点**：危机源头（一号猛火灶档期、互防摊主、伺机收铺的物业）；主角路数（私下顶班+涂改明账）；对手反扑（摊主抓对不上号的账闹事，物业顺势持内部举报进场收权）；退无可退（自己饭碗与对老街坊的承诺拴在此处）；收尾条件（改明规共担或厨房被收回）。
- **假升级 vs 真升级**：
  - *假升级*：又有摊主迟到吵了一架，叶澄又好心帮忙调灶位（处境零变化）。
  - *真升级*：凌晨三点叶澄替孩子急诊的新摊主老周顶班、代签鲜肉送货单并将明面排班本改回原排班老摊主齐曼；今早送货商拿着黄色底联找齐曼结肉款，齐曼当众拍单对质——矛盾瞬间从“争灶位”炸成“叶澄私改台账连累全厨房面临清退”，威信与物业收铺把柄同时易位。

动笔排 [分集架构与节奏设计](episode-architecture.md) 前，核准六件事：第 1 集前危机为何已燃眉、首回合如何带出绝活与软肋、后续靠哪几步处境台阶上拱、伏笔何时回收、离终局隔几道大坎、场面规模是否超出制作条件。
