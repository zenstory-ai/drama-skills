# 分镜脚本怎么写：短剧分镜表模板，把剧本逐镜拆开

分镜先把定稿剧本中的动作、对白、声音和必读文字落实到镜头，再为每镜确定观众要看懂什么、从谁的视角看、起止状态、景别机位和声音时间线。切镜后保持人物、谁知道什么、谁拿着什么和空间位置一致，不要求两镜是同一幅画面。有对白先排完整声音与必要动作，再选择容得下它的镜长；文字模板便于规划，skill 实际输出的是逐镜的 Markdown 段落。

## 分镜脚本模板：先记事实与镜头作用

下面是编辑手写的简化记录，尖括号换成已确认内容。正式 skill 使用逐镜文档块，不把这张表作为生产格式。

| 镜头 | 一镜的记录 |
|---|---|
| SHOT-001 | **来源**：<真实场景ID、必要短引文>。**职责**：<本镜让观众理解什么>。**画面**：<景别、水平角度、高度、轴线侧、运镜起止与理由>。**起点**：<影响动作的位置、朝向、持物和空间关系>。**动作与终点**：<连续行动怎样到达结果>。**声音**：<原句、说话者、画内/画外/VO、声音发生次序>。**估时**：<录音区间或标明文本估计的依据、需另占时间的反应>。 |
| SHOT-002 | 按同一记录写本镜；延续SHOT-001的实际事实，明确时间省略、重排或有意回放。换机位不会使钥匙再次回到原主人手里。 |

检查来源是否真实、关键内容是否遗漏、镜头职责是否可读、动作先后和持物是否一致、声音是否完整。单一主要动作可以是一条连续行动链，不按动词数量删戏；有意回放指向主要镜头，同一事实只改变一次。

正式short-drama-storyboard按每镜标题写职责、来源、起点、行动、终点、声音、时长和冻结关键帧等内容，并按实际画面补上视觉依据与图片参考。提示词条目不等于已有图片；已有图片仍要读内容、核对用途。

## 短剧分镜表每一栏怎么填

- **镜号**：按顺序编 SHOT-001、SHOT-002，改稿时没受影响的镜头保留原号。
- **来源**：场景 ID 加一句短引文。剧本一改，顺着这一栏就能找到要复核的镜头。
- **镜头职责**：一句话写清谁做了什么、这一镜为什么存在，比如交出证据、暂扣信息、权力易手、接住反应。只写“开场”两个字，审稿时无从查起。
- **景别·机位**：景别看观众要读的信息落在哪个尺度，后果在两人距离上用中景，证据在指节上才给大特写。水平角度（正面、斜侧、正侧、背面）和机位高度（仰、平视、俯）分开写，再注明在轴线哪一侧。
- **运镜**：固定机位适合观察和紧张；推近、拉远改变亲近或压力，摇和俯仰转移注意，跟拍留给移动本身有意义的人物。同一段时间里别同时要求固定和移动。
- **起点、动作→终点**：起点写位置、朝向、双手和道具落点；动作写一条走到终点的可见链，放下、递交、取回要写清谁碰、落在哪。下一镜继承这些实际事实，画面角度与可见范围可以变；有省略或回放则明确声明。
- **对白/声音**：原句照抄，标说话者和画内、画外。
- **时长估计**：有录音就用实际发声区间；没有，就照原文、说话人的节奏、情绪和换气估出一个区间，写明“文本估计”和估算依据。

## 从剧本到镜头的五个判断

1. **原文先落实**：动作、对白、声音与必读文字都要由镜头承担，或明确省略理由。几段可合一镜，一段可由几镜承担，不按段落数拆镜。
2. **先职责，后景别**：确定关键动作、观众理解、体验位置与必须看清的起止信息，再选机位。空间、等待、余波也可承担职责，不必每镜都新增秘密。
3. **在有用的变化处切**：信息、注意、关系、空间或节奏变化支持切点。同景别同角度的切镜通常先问作用；有意跳切、停顿或风格安排按作者选择评估，不为变化随意跨轴。
4. **状态只改变一次**：放钥匙、开门或递交，各有主要落实镜头；细节与反应不再重新完成动作。峰值回放可有意重复，但标清同一动作前后，而不是结果上再来一次。
5. **声音先排完**：顺序对白累加，能并行的动作共用时间，必须等说完才发生的另占时间。放不下时调整镜长、切画面保留连续声音，或经作者选择修剧本，不擅自删词。

**景别收放**可从交代空间的镜头进入工作距离，再在需要读细节或后果时改变；不要求每一刀固定换一档，也不强制所有场都先宽后紧。

**冻结关键帧**只描述起点能看见的状态：要在镜内拿钥匙，首帧里钥匙仍在原处。可选尾帧描述终点，不能证明中间过程已经正确。原生时长或节奏档案已接受时按它们核对；未接受时按本场需要规划，不猜统一供应商秒数。

## 分镜脚本范例：一场排练室的戏拆成四镜

下面保留同一场排练室戏的四镜方案。秒数全部是按本页台词与动作作的文本规划，未实际录音，也不是目标模型的官方档位。确定生成模型后再核对已接受时长；SHOT-004若需拆开，可在拿回钥匙后的清楚状态闭合点分开。

> SC01　内景·排练室门口·夜
> 窄桌横在中间。岑夏站在桌子左侧，右手捏着一把系绿布环的黄铜钥匙；周屿坐在右侧。岑夏身后有一把空椅。
> 岑夏说话间把钥匙搁到桌子正中间，收回右手。
> 岑夏：我先走了。这把钥匙你收着。
> 周屿抬眼看着她，双手搭在膝上没动。
> 周屿：（克制）门我可以替你锁，但散伙这话，我没法替你跟他们张嘴。
> 岑夏伸手去拿钥匙，指尖停在钥匙上方，抬眼看向周屿。
> 岑夏：行，那我等他们过来当面说。
> 她用右手拿回钥匙，左手把身后的椅子拉近，坐下。

| 镜头 | 记录 |
|---|---|
| SHOT-001 | **来源**: SC01「这把钥匙你收着」; **职责**: 立起她要走、他不接茬; **画面**: 中景双人·平视·固定（机位在桌子一侧，岑夏画左、周屿画右）; **起点**: 钥匙在岑夏右手，桌面中间空着，周屿双手搭在膝上; **动作与终点**: 她把钥匙搁到桌子中间，松手收回→钥匙留在桌上，周屿没接; **声音**: 岑夏（画内）：“我先走了。这把钥匙你收着。”与放钥匙重叠; **估时**: 6 秒：短句 2–3 秒，余下给放钥匙和他不接 |
| SHOT-002 | **来源**: SC01「门我可以替你锁」; **职责**: 他拒绝替她宣布散伙; **画面**: 周屿中近景·平视·固定（同一侧，视线朝画左）; **起点**: 钥匙在桌子中间，周屿没伸手; **动作与终点**: 他说完整句，手始终不碰钥匙→岑夏还没再伸手; **声音**: 周屿（画内，按括注克制）：“门我可以替你锁，但散伙这话，我没法替你跟他们张嘴。”; **估时**: 10 秒：整句 6–8 秒含停顿，说完留约 2 秒 |
| SHOT-003 | **来源**: SC01「指尖停在钥匙上方」; **职责**: 把“掉头就走”变成没做完的动作; **画面**: 岑夏中近景·平视·固定（同一侧，视线朝画右，右手和钥匙在画面下缘）; **起点**: 岑夏右手已收回，钥匙在桌子中间; **动作与终点**: 她右手伸向钥匙，碰到前停住，抬眼看周屿→手悬在钥匙上方; **声音**: 无对白，留住停顿; **估时**: 6 秒：伸手到停住约 2 秒，悬停对视约 4 秒 |
| SHOT-004 | **来源**: SC01「行，那我等他们过来当面说」及取钥匙、拉椅、坐下; **职责**: 她决定留下当面说清，新状态落地; **画面**: 中景双人·平视·固定（同一侧，身后椅子入画）; **起点**: 右手悬在钥匙上方，左手空着; **动作与终点**: 先说完短句，再右手拿回钥匙，左手拉椅坐下→岑夏坐在桌子左侧，钥匙在她右手，其他成员还没来; **声音**: 岑夏（画内）：“行，那我等他们过来当面说。”; **估时**: 10 秒：短句 2–3 秒，取钥匙和坐下 4–5 秒，坐定再停一下 |

- **景别跟着要读的东西走。** SHOT-001 的中景交代桌子、钥匙和两人距离，空间随放钥匙的动作一起到达，省掉空景全景；SHOT-002 收到周屿，读他的拒绝；SHOT-003 反打岑夏，中近景留住她悬着的手；SHOT-004 退回双人中景，让身后的椅子入画。
- **轴线不动。** 四镜机位都在桌子同一侧；双人镜里岑夏在画左、周屿在画右，单人反打分别保留朝右与朝左的视线。人物未入画时不硬说她仍占画面左侧。
- **钥匙只动两次。** 放下归 SHOT-001，拿回归 SHOT-004；SHOT-002、SHOT-003 里钥匙一直停在桌子中间，谁也没碰。

按上表当前估算，后三镜的顺序内容放不进一个8秒镜头；真实表演时长仍需录音或排练核对。不要为了压时长把周屿整句删成“你自己说”，或让岑夏在规定的听完之前伸手。可改切点、安排连续声音覆盖，或由作者修订停顿与剧情；不声称只有两种处理办法。

## 分镜常见问题与修法

| 问题 | 修法 |
|---|---|
| 表格只是改写剧本 | 补观众从哪看、必须看懂什么；已有画面能承担就合并，不把气氛与等待自动判无用 |
| 切镜没有可读作用 | 检查注意、关系、空间、节奏；按明确风格安排判断，不随机跨轴制造变化 |
| 同一动作被再次执行 | 记主要镜头、动作前后和其他镜头作用；有意回放注明，不让持物逐次累加 |
| 道具切镜后换位 | 对照实际空间与持物；画外不等于物件消失，补真实动作或声明省略 |
| 对白有了，后果不可读 | 给听者反应、同框调度、声音或物件状态；已有后果清楚就不额外加反应镜 |
| 一个关键帧被当整段成功保证 | 首帧只固定起始图，尾帧也不能证明中间动作，生成后逐段核对 |
| 用统一秒数压完整台词 | 以声音与动作时间线排镜，再按接受的项目档案与生成方式处理 |

文章里的两列表是手写规划；交正式skill时提供当前剧本与视觉事实，让每镜按原生块结构写，别把文章表格反当工具格式。

## 用 Drama Skills 怎么做

装好本仓库的 skill 后（对应 [short-drama-storyboard](../skills/short-drama-storyboard/SKILL.md)）：在 Claude Code 里说：“用 /short-drama-storyboard 给 EP001 拆分镜，每镜写冻结关键帧”（Codex 里写作 `$short-drama-storyboard`）。它读当前的 `剧集/EP001/剧本.md` 和视觉设定，写出 `剧集/EP001/分镜.md`，只交文字，不生成图片或视频；视频提示词、生产和审查要另外点名。

## 常见问题

**分镜脚本一个镜头多少秒？**

没有统一秒数。先排完整对白、关键声音、动作与必要反应；有实际录音就用发声区间，没有就标明文本估计。已接受的项目节奏档案与模型时长决定后续分配；放不下可延长、切画面保留连续声音或修剧本。一张首帧图没有适用于所有模型的5–8秒保证。

**分镜脚本和剧本有什么区别？**

剧本决定谁做什么、说什么、结尾意味着什么；分镜脚本继承这些事实，决定观众从什么距离、什么角度、在哪一刻看到和听到。要改台词、动作先后或结尾，回剧本改完再拆镜。从小说起步的，先看[小说改编短剧](https://zenstory.ai/zh/drama-skills/novel-to-short-drama)。

**不会画画怎么写分镜脚本？**

用文字分镜表就行。每镜写清起点、动作、终点和声音，再配一段冻结关键帧提示词描述起点画面，交给出图工具生成起始帧。Drama Skills 的分镜技能就只产出文字，图片和视频在后面的环节生成。
