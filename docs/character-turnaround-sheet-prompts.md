# 角色三视图提示词怎么写（附模板与 6 个范例）

角色三视图提示词先写这张参考图给后续镜头复用什么，再写换衣服也不变的外观特征、唯一一套当前造型，以及正面、侧面、背面各靠哪个特征认人。光线按要对比的内容选，背景只求不干扰认人，并写明画面内无视图标签、箭头和图注。

## 角色三视图提示词模板（可复制）

人物外观和造型由创作者在视觉设定里先定好；视图、光线、背景和排除项按这张图的用途来选，项目或创作者另定了版式时，按项目约定走。人物外观还没定准时，先列出备选方案请创作者拍板，别靠空泛词句糊弄过去。

| 字段 | 写什么 | 依据 |
|---|---|---|
| 用途 | 下游镜头要靠这张图保持什么：认脸认体态、认这套衣服、认某个状态或某个局部细节 | 下游镜头的复用需要 |
| 外观特征 | 少量换装后仍成立、看得见、彼此不重复的特征，如脸型轮廓、头身比例、局部胎记或痣、一组颜色或材质关系 | 视觉设定（已确认） |
| 当前造型 | 从头到脚只写一套，先写剪裁、层次、领口袖口、材质和主次色，再写整体气质 | 视觉设定（已确认） |
| 视图 | 按用途挑最少够用的视图；多视图并排时保持同一时刻、同一造型 | 按用途选，项目有固定版式时按项目约定走 |
| 侧背认人特征 | 侧面和背面各靠哪个外观特征认人 | 从已确认的外观特征里挑，逐个视图核对 |
| 光线 | 让要对比的结构看得清的光 | 按要对比的内容选 |
| 背景 | 不抢主体、不干扰认人的纯色或简洁背景 | 按用途选，创作者可改 |
| 保持与排除 | 这张图最容易多画出来或跑偏走样的东西 | 这张图的走样风险 |

### 可复制的三视图提示词骨架

1. 【项目风格标签】人物设定参考图，用于后续镜头认出〔角色名〕和〔这套造型／这个状态／某个部位〕。
2. 外观特征：〔换衣服也不变的可见特征：脸型、发际、体型、永久痕迹、长期配饰〕。
3. 当前造型：〔从头到脚只写一套：发型整理方式、上衣、下装、鞋、配饰及其佩戴位置〕。
4. 视图：同一时刻、同一造型的〔正面／左或右侧面／背面〕全身视图并排，等高，自然站立，表情〔平静／克制〕；侧面选辨识特征所在的那一侧。
5. 侧面与背面：〔哪几个特征在侧面、背面也要看得见，例如扎起头发后露出的后颈胎记、肩背轮廓〕。
6. 光线：〔五官位置用均匀正面光；骨骼体积用侧光；布料纹理用大面积柔光；剪影用轮廓光〕。
7. 背景：〔不干扰认人的纯色或简洁背景〕。
8. 版面：画面内无视图标签、无引线箭头、无尺寸标注、无图注。
9. 保持与排除：〔这张图最可能多画出来的东西，如第二套衣服、手持道具、新伤、通用美颜套话〕；不出现可读文字。

填完删掉空项、括号和“外观特征：”“视图：”这类字段名，读起来像一段能直接交给画师的工作说明。多角色时每个角色单独写一条，只有身形对比图才把几个人放进同一张；角色名与视觉设定里的登记名一致。风格标签按项目统一前置，例如【真人风格，写实风格】或【国漫风，二次元画风】，设计描述本身不带风格词。

## 6 个角色三视图提示词范例

六个范例用同一部江边轮渡题材的[漫剧](https://zenstory.ai/zh/glossary/manju)：售票员苗秋禾二十出头，船老大宋满仓六十岁出头，两人的外观特征和造型已在视觉设定里确认。

### 范例 1：全身三视图（基础人物设定图）

> 【国漫风，二次元画风】人物设定参考图，用于后续镜头认出苗秋禾和她的售票造型。二十出头的女性，圆脸，下巴短，眉距略宽，左耳垂一颗小黑痣，肩窄，上背微圆。齐肩黑直发在脑后扎低马尾，露出后颈右侧一块指甲盖大小的浅褐胎记；藏青立领短外套拉链拉到胸口，内搭浅灰圆领针织衫，右小臂套一只橙色布袖套，深灰直筒裤，黑色平底帆布鞋。同一时刻、同一造型的正面、左侧面、背面全身视图并排，三者等高，自然站立，双手垂在身侧，表情平静。均匀柔和的正面光。浅米色纯色背景。画面内无视图标签、无引线箭头、无尺寸标注、无图注。不加首饰，不拿票夹或任何道具，不出现可读文字。

全身三视图靠体态和轮廓认人：背面看上背弧度、马尾和后颈胎记，侧面看上背弧度和马尾；耳垂痣留给范例 2。袖套写明“右小臂”，三个视图就不会各戴各的。

### 范例 2：头肩面部识别板

> 【国漫风，二次元画风】苗秋禾头肩面部识别参考图：圆脸，下巴短，眉距略宽，左耳垂一颗小黑痣，齐肩黑直发扎低马尾，发际线完整露出。正面头肩与左侧面头肩两个视图（露出左耳垂）并排等高，表情平静。均匀的正面平光，浅米色背景。画面内无视图标签、无引线箭头、无图注。只画到领口，不表现服装全貌。

平光让五官位置好对比，代价是脸部立体感变平；服装交给范例 1。

### 范例 3：服装造型板（正面加背面）

> 【国漫风，二次元画风】宋满仓船上工作装参考图，用于核对衣服层次和挂件位置。六十岁出头的男性，个子矮，腿短，腰身粗，肩膀宽厚，方下巴，花白寸头。他穿褪色的深蓝帆布马甲，敞着怀，里面是洗白的军绿长袖衫，袖口卷到小臂中段，腰后右侧别一条旧白毛巾，黑色胶鞋，裤脚塞进鞋口。正面与背面全身视图并排等高，头身比例按他本人的矮壮体型，双臂自然下垂。大面积柔光，看清帆布磨白的纹理和毛巾的垂挂位置。浅灰背景。画面内无视图标签、无引线箭头、无图注。马甲上没有文字或标志。

毛巾别在腰后，正面看不到，所以补背面；服装层次靠正背两面已够核对，侧面省掉。

### 范例 4：状态板（同一造型加包扎）

> 【国漫风，二次元画风】苗秋禾状态参考图，沿用她的售票造型：圆脸、耳垂痣、低马尾、右小臂袖套和整套衣服保持不变，只在右手掌缠一圈白纱布，结打在虎口一侧，四根手指露出。正面全身一个视图，右手自然抬到腰前，让包扎可见，表情平静。均匀柔光，浅米色背景。不加血迹或其他伤口，不换衣服，不出现可读文字。

受伤起因和持续集数（第 6 集缆绳擦伤，持续到第 8 集）记在条目说明里，提示词正文只写画面变化和保持项。

### 范例 5：不合模板身材的角色（全身三视图）

> 【国漫风，二次元画风】人物设定参考图，用于后续镜头认出宋满仓本人。六十岁出头的男性，个子矮，腿短，腰身粗，肩膀宽厚，方下巴，花白寸头，右手小指缺了末节。他穿船上工作装：深蓝帆布马甲敞穿，军绿长袖衫卷袖，腰后右侧别一条旧白毛巾，黑色胶鞋。同一时刻、同一造型的正面、右侧面、背面全身视图并排等高，头身比例按他本人的矮壮体型，不拉长腿部，双臂自然下垂。高位斜侧光，让方下巴、肩背厚度和腰腹体积在侧面清楚可比。浅灰背景。画面内无视图标签、无引线箭头、无尺寸标注、无图注。

矮壮是他的辨识特征，直接写进视图句，免得通用美颜词里的“修长”把他拉高；侧光让肩背和腰腹体积更好对比。

### 范例 6：剪影对比板（漫剧远景用）

> 【国漫风，二次元画风】剪影对比参考图，用于远景和逆光镜头分清苗秋禾与宋满仓。两人并排，宋满仓比苗秋禾矮约半个头，各一个右侧面全身视图：苗秋禾窄肩，上背微圆，脑后低马尾在轮廓上形成一个小凸起；宋满仓矮而宽，肩背厚，寸头轮廓平，腰后毛巾在轮廓外垂出一角。深色纯色背景，轮廓光勾出外形与发型剪影。画面内无标签、无箭头、无图注。

轮廓光会把脸压进暗部，所以这张只做远景剪影对比，认脸仍靠范例 1 和 2。

## 三视图提示词为什么先写用途

用途决定后面每个字段怎么取舍：近景认脸做头肩面部板，全身调度里认衣服做全身板并补上必要的背面，跨镜头复用的伤势或特殊状态单独做状态板。背景和视图数量不属于人物自身设定，按用途挑。

人物设定图要让后面的镜头认出同一个人此刻的这一套造型。一张基础设定图只画同一个人、同一套自洽衣服，几套换装、几种情绪不挤进同一张；要对比两个角色的高矮胖瘦，另做对比板（见范例 6）；一次抬手、一个眼神属于单镜表演，交给分镜和[视频提示词](https://zenstory.ai/zh/drama-skills/seedance-prompts)。

## 三视图侧面和背面靠什么认人

正面看得到整张脸，侧面只剩侧脸，背面看不到脸。逐个视图问一遍：观众凭什么认出这个人？

- 正面：脸型、五官相对位置、正面可见的配饰。
- 侧面：面部侧轮廓、上背弧度和站姿重心、发型剪影；痣或胎记只在它所在的那一侧看得见，要写明画左侧面还是右侧面。
- 背面：发际形状和发型剪影、肩背宽窄与重心、后颈的永久痕迹。

辨识特征得在对应视图里看得见。眉距、瞳色、唇形这类只在正脸看得清的细节撑不起侧面和背面；按这张图的实际用途，检查侧面和背面有没有能认出人的特征，不把“每面至少凑够一个”当成死指标。全身视图主要靠体态和轮廓认人，面部小标记留给近景和头肩板。

多视图并排常见的毛病是变脸、换衣服、配饰换边，比如右臂的袖套到了背面跑到左臂；把佩戴位置和相对大小写进几个视图共用的造型句里就能稳住。跨镜头的一致性做法见 [AI 短剧角色一致性](https://zenstory.ai/zh/drama-skills/character-consistency)。

漫剧如果主要靠剪影认人，外观特征不换，只换画法：发际形状落到发型剪影的缺口上，体态落到肩背重心上。找不到可靠画法时交回创作者商量，别擅自改成更好画的另一张脸。

## 三视图提示词要不要写“正面”“侧面”标签？

标签不要画进图里。这张图之后要当参考图喂给模型，图上的字很容易被带进后面的镜头，提示词里再加“不要文字”也清不掉，只能先裁切、涂抹遮盖或换参考图。多视图并排时直接写“画面内无视图标签、无引线箭头、无尺寸标注、无图注”，再写清画几个视图、怎么并排、是否等高。

## 三视图用什么光：按要比较的东西选

每种光让一类结构看得清，同时压掉另一类，所以先问这张图要对比什么。

| 要对比什么 | 选什么光 | 代价 |
|---|---|---|
| 五官相对位置、妆面、服色和图案 | 均匀正面光 | 颧骨、鼻梁、下颌的立体感变平 |
| 骨骼体积和轮廓起伏 | 侧光或高位斜侧光 | 暗侧细节丢失，左右不对称被放大 |
| 布料纹理、肤质 | 大面积柔光 | 轮廓边缘变软 |
| 磨损、金属反光、工艺痕迹 | 小面积硬光 | 明暗过渡变硬，表面瑕疵被放大 |
| 发型剪影、服装廓形 | 轮廓光或逆光边缘光 | 面部信息被压掉，不能单独当基础认人图 |

顶光让眼窝、鼻下、颌下的纵向结构更好对比，代价是暗区里的面部细节和服装层次会丢；底光颠倒日常明暗，做认人参考图时不用。状态板可以用场景里的实际光源，光线方向要和已定好的场景一致。

光型只按要对比的内容挑，“女角色一律柔光、男角色一律侧光”这类按性别、年龄、贫富或题材套用的刻板默认套路，先删掉。强戏剧阴影若遮住脸或服装结构，就不适合直接当基础认人参考图。

## 三视图提示词里的九头身等模板词为什么会改掉角色

人物设定模板如果给每个角色都挂上同一串通用美颜套话，比如“九头身、修长双腿、完美五官”，遇到和已定人物外观冲突的角色，人物设定优先，套话让位。宋满仓矮壮腿短，挂上“九头身”就成了另一个人；又因为这句话出现在每张图上，下游模型会把它当成全剧统一画风。本来就身材修长的角色，也要靠他自己的体态特征写出修长。

排查办法：把一批角色的提示词摆在一起，找出逐字重复、又和角色本身无关的套话。能对应到角色视觉设定的留下，对应不上的删掉，或改写成这个角色真实的外观特征。

“网红脸、顶级美女、8K、杰作”同理，既挤占提示词重心，又给不出具体的画面细节。审美词要么落到构图、材质或光线方向这类看得见的选择上，要么直接删掉。

## 三视图提示词常见错误与改法

- 一张图里出现两套衣服、两种发长或干湿并存：一张图只定一套造型，其他造型拆成独立条目。
- 手持道具和当下表情写进了人物固定外观设定里：道具需要跨镜反复识别时才单独建图，单镜表情交给分镜；基础认人图常用平静表情，表情测试图可按用途画出几个神态，但不把不同剧情时刻的动作拼进同一个站姿里。
- 表单字段直接贴进正文，比如“角色：船老大／年龄：60”：改写成连贯的自然描述。
- 生成结果跑偏走样后原样重发同一段描述：先看是五官体态、构图、多余文字还是服装状态出了问题，再改对应的那一句。

发出前用这张清单过一遍：

- [ ] 第一句写了用途和角色名
- [ ] 外观特征在换衣服后仍然成立
- [ ] 整张图只有一套造型
- [ ] 每个视图都有看得见的认人特征
- [ ] 光线对应要对比的内容
- [ ] 写了画面内无标签、箭头、尺寸标注和图注
- [ ] 没有与人物设定冲突的通用美颜套话

## 用 Drama Skills 怎么做

装好本仓库的 skill 后（对应 [short-drama-image-prompts](../skills/short-drama-image-prompts/SKILL.md)）：在 Claude Code 里说：“用 /short-drama-image-prompts 为 EP001 已确定的人物写三视图提示词”（Codex 里写作 `$short-drama-image-prompts`）。它会把带 `IMG-...` 编号的可复制提示词存进 `剧集/<EP>/图片提示词.md`，本身不直接出图；需要调用接口生成图片时转用 `short-drama-produce`，看过任务预览并明确确认后才会执行。

## 常见问题

**三视图一定要白底吗？**

不用。Drama Skills 把白底三视图当作一种可选版式；浅灰、浅米等纯色或带环境的背景都可以，只要不干扰认人，也不把某场戏一次性的环境光和陈设写进人物固定外观设定里。

**三视图提示词用中文还是英文写？**

跟随项目设定。Drama Skills 的可复制提示词按项目配置 `short-drama.json` 里的提示词语言输出；没有 `short-drama.json` 时按已有提示词或项目文档语种推断，未指定时可用用户当前语言，同一批任务里保持同一种语言。

**角色受伤或换衣服要重做三视图吗？**

基础三视图不用重做。换装或伤势会跨镜头出现、影响认人时，先在视觉设定里登记成新的造型或状态条目，再补写造型板（新衣服）或状态板（只写变化项和保持项）；只在单个镜头里出现的，直接写进那一镜的分镜。
