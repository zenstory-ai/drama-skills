# 短剧美术设定图提示词

将视觉设定写成可直接复制的角色设定图、场景空镜设定图、道具设定图、状态变化图、局部改图或视觉定调图（Lookdev）提示词。

## 快速开始

```text
使用 short-drama-image-prompts 技能，为 EP001 已确定的人物、地点和道具写可直接复制的图片提示词
```

## 模式选择（正式项目 vs 轻量起草）

- **轻量 / 草稿模式**：用户仅要求为单个角色、场景、道具或测试画面快速起草几条静态图片提示词（无完整短剧项目目录）时，直接输出简短用途说明与可直接复制的提示词正文，**不强制套用完整项目的 `IMG-...` / `REF-...` 槽位语法**。
- **正式项目模式**：落盘 `剧集/<EP>/图片提示词.md` 或衔接跨文档自动校验、创作台展示与内置批量出图时，完整遵循 [图片提示词格式规范](references/format-spec.md)（含 `## IMG-... · <名称>`、`- 参考：` 语法与 `### 可复制提示词` 引用块）。

## 语种与工作流要求

- **双语分工**：说明文字跟随项目语言；可复制提示词正文跟随 `short-drama.json#/format/prompt_language`（无配置文件时按已有提示词或项目文档语种推断，未指定时使用用户当前语言）。
- **核心工作流**：
  1. **核对设定与板式**：对照 `视觉设定.md` 确认本项属于角色设定图、换装/状态图、场景空镜图、道具设定图、分栏对照设定板、视觉定调图还是局部改图（分镜需单出尾帧图时，可将定稿「尾帧提示词」落成独立 `IMG-...` 状态图条目）。
  2. **核心特征优先落笔**：按「设定图类型与主体 → 固定核心外观 → 本张造型/视角/状态 → 构图版式与尺寸参照 → 材质色彩与布光 → 背景清场与字迹排除项」组织正文（见 [美术设定图与视觉定调指南](references/sheet-prompt-guide.md)）。单图默认画单一共存状态，同板展示开合或多分区对照须明确声明分栏；多视图并排时按当前提示词语言补充无视图标签/尺寸标注约束。
  3. **落实连戏锁与字迹规则**：被 `视觉设定.md` 的 `连戏锁` 点名的 `IMG-...` 条目须把 `锁定词` 原字带入 `### 可复制提示词`；画面字迹严格遵循设定规则，要求生成可读文字时绝不同时挂全局禁字词（详见 [阶段规则](references/stage-contract.md)）。
  4. **干净正文与直接改稿**：`### 可复制提示词` 内不夹条目编号、文件路径或流程备注；收到明确的改词或局部改图要求时，先读最新磁盘文件后直接更新对应 `IMG-...`（见 [换装状态图与局部改图指南](references/variants-and-edits.md)）。整集请求一次写完所有指定条目。

## 完成与投产

所有指定条目具备唯一 `IMG-...`、合规 `- 参考：` 与干净可复制的 `### 可复制提示词` 即完成（同轮连带修改分镜时同步更新对应 `- 图片提示词项：`）。完成后可移交 `short-drama` 技能做局部或整集格式校验；实际出图移交 `short-drama-produce` 技能预览确认后执行。
