# 改编压缩、合并与信息视觉化

改编先找出原著吸引观众的爽点，把它们排到观众能尽早获得回报的位置，再保住让爽点成立的
戏剧功能，为屏幕、单集边界和制作条件寻找合适载体。压缩顺序服从因果与创作者的改编边界。

## 1. 先建立改编契约

| 类别 | 含义 | 处理 |
|---|---|---|
| 不可改承诺 | 核心人物的立场与性情、核心关系、主线、关键选择、结局含义、必要世界规则 | 保持事实与功能 |
| 可换载体 | 叙述顺序、场景、配角、信息出现方式 | 可压缩/合并，但记录替代关系 |
| 可删冗余 | 重复说明、只连接路程的段落、无新状态的复述 | 删除并说明没有损失什么 |
| 未决歧义 | 原材料本身矛盾或授权不清 | 保留问题，不替作者定案 |

### 长材料导入：先分段理清人物与作用，再进分集

- **先分段立账**：长篇小说、多集散稿或混合材料保存在非公开的 `输入/` 目录；按章节、场景切换、视角与时间跳转分段，记录原文位置、出场称谓、地点、关键道具、信息差、戏剧作用及待决指代，不直接用正则命中发布剧集或资产。
- **去引用映射**：`项目开发/adaptation-map.jsonl` 只登记原文位置区间、去引用的功能摘要、待确认人名/物件、去向（`disposition`）及损失说明，不复制大段原文。
- **候选与定稿分离**：分集按当集戏剧结果和集尾交接切分；经创作者确认后再由 `$short-drama-write` 写 `剧集/<EP>/剧本.md`、由 `$short-drama-assets` 从定稿剧本建资产。

### 写下游内容时定点回原文

写分集或单集剧本需回原文补细节（动作先后、物件归属、当场反应）时，遵守三条（`craft_default · STY-22`）：

1. **用事件锚点检索，不用概念词**：“人物 + 地点/物件 + 当前动作或冲突”（如 `<角色名> 后院 药炉 当众被夺`），不用全书高频概念词（如 `修炼 突破 功法`）；命中为空时换更具体的场面锚点。
2. **回读原文段落，不凭检索摘要写**：核对动作先后、谁先开口、物件在谁手里。
3. **核对知情状态，防后文穿帮**：将命中片段的知情范围、结盟关系、能力边界与当前集进入状态逐项比对；超前于当前进度的片段仅作参考。回原文只补足已接受契约的细节；若要提前后文高光，须先在分集地图中作 `move_earlier` 或 `cold_open` 修订。

## 2. 用功能账本压缩

**`STY-07 · reviewed_invariant`**：合并、换载体、压缩、重排、新增均须保住原著核心人物的立场与做事方式、核心关系和主线，不与原著事实矛盾（创作者已接受的改动除外）；人物或场景合并还须保留戏剧作用、知情范围、关系位置和因果桥。例如嘴硬心软、不信徒弟能成的老师傅可外化为当众说出不信，但不能改成暗中使绊子的反派；若提议改动人物立场或关系，须在 `lost_or_changed` 写明并保持 `creator_acceptance.status: pending` 交创作者拍板。

为候选人物、场景和信息登记功能账本：谁迫使主角作选择、谁持有证据/秘密/资源/许可、哪个场景改变状态、哪段建立误信/承诺、哪个空间限制迫使冲突现在发生。

### 先按爽点取舍

**`craft_default · STY-28`**：压缩先按原著分析的爽点表留下观众收益最高的情节点（爽点、糖点、虐点），再删减不服务主线的支线、合并功能重复的人物；集数与章数跟着爽点分布走（无爽点长段并入相邻集或删去，一章双爽点可拆两集，后文高光可提前），不按章节 1:1 切分。需要控制规模时，可将“核心人物 3–5 人、全剧 ≤ 20 人、高潮集新增 ≤ 2 人”作为可覆盖的工艺参考，不设保留比例或人数硬门槛。

### 先删线，再合并

**先删支线、再做人物合并**（防合并完的目标角色随支线被删而作废）。按五项判据核对支线去留：

1. **兑现依赖**：正反双向核对 `setup_ids` 与 `payoff_ids`，确认它是否承载后文翻盘伏笔或正在兑现前文承诺；
2. **行动手段来源**：主角是否靠它获得唯一的证据、盟友、权限或技能；
3. **世界规模 vs 主线推进**：仅负责垫大世界广度、不推进主线兑现的支线优先删除；
4. **信息权限落差**：是否承担“观众知而主角不知”的关键悬念；
5. **孤儿铺垫清理**：删线时同步删除或改写前文为它埋下的铺垫。

慢线若包含让快线成立的铺垫、代价或信息落差，删慢线前须将这些条件压缩或换载体转移到保留线上，并在账本中写清接收方具体多承担了什么（不只写“合并到主线”）。

### 合并人物

仅当两个角色的功能可由同一人的目标、知识范围和关系位置自洽承担时才合并，逐项核对：两人是否知情不同（防提前泄密）、是否分属支持与施压（防对抗消失）、是否需不同伦理位置、同一时点能否完成两项行动、合并后背叛或牺牲是否失去代价。

- **生硬合并（断桥）**：“配角太多，干脆把门店会计和房东合并成一个人。”
- **保住因果的合并（先核对秘密，再转交线索）**：原著女主查餐饮店假账，既有“门店会计”扣着底账，又有“舅舅房东”催租逼宫；若原著后文反转为“会计背着房东用假发票吃回扣，房东也被蒙在鼓里”，硬捏成一人就会变成“房东自己瞒自己”。合并时让舅舅房东兼管账目承担当面施压，同时把“只有会计知道的假发票回扣”改由冻品供货商发来的催款对账单揭开——既省掉配角，又保住证据链。

### 合并场景

场景合并须同时满足：时间/地点连续、双方诉求可同场交锋、信息出现不改变因果顺序、关键反应仍有空间。

## 3. 信息视觉化阶梯

**`STY-08 · craft_default`**：将“人物知道/回忆/解释”按阶梯转译，优先用有后果的行为与证据承载：

1. **行动后果**：不报门牌，直接用旧钥匙开门；
2. **可争夺证据**：缺页、录音、伤痕、持物、屏显；
3. **空间与关系行为**：谁挡出口、避开座位、退后半步错开触碰、改了称呼；
4. **对话策略**：试探、误导、讨价、圆场、拒绝，而非中性说明；
5. **声音/主观表达**：`[VO]` / `[OS]` / 主观画面，补充画面与台词给不出的言行反差或跨时认知。

不把心理活动机械改成“倒水、看窗外、摸旧物、攥拳头”等不改变处境的假忙活：

- **前史综述与设定报菜名拆进当场交锋（必改）**：小说花两页综述“父母过世后二叔一家如何霸占老宅田产、逼兄妹俩签字画押”，或花整章罗列门派编制与规矩；改短剧时**砍掉原地回忆与设定旁白**，直接从二叔踹开院门把抵债婚书拍在石桌上切入，拍哥哥把妹妹护在身后、一手亮出父亲留下的老房契、一手拔出插在门框上的猎矛逼退众人——**观众第一秒就看到谁在欺负谁、主角手里有什么依仗**。
- **心理转折改成改变处境的动作（必改，忌一刀切改手部小动作）**：小说写“她看着冷掉的饭菜，想起三年来每次纪念日都在空等，终于彻底死心”；**按题材改成当场改变关系边界的动作**——强冲突戏拍“她把墙上圈着纪念日的台历撕下一页扔进垃圾桶，当着推门进来的丈夫面把失约短信摁灭”；克制生活戏则拍“她对着满桌冷菜静坐片刻，等丈夫进门时平静收起碗筷、把备用钥匙留在玄关柜上，进屋反锁房门”。
- **言行反差或跨时认知差保留短促 `[VO]`（合理保留，不强行删光）**：轻喜、宅斗或悬疑情感戏里，当人物表面动作与真实盘算相反（如假千金哭得梨花带雨替姐姐求情，真千金表面递纸巾、画外一句冷幽默拆穿“她这滴眼药水比我进门时的茶水还烫”），或平静画面需跨时间认知点破多年积怨时，**保留一两句短促 `[VO]` 与画面动作同框对撞，不必一刀切删成哑剧**。

## 4. 保住因果桥

压缩时间后按 `原因事实 -> 人物理解 -> 选择 -> 对手反制 -> 可见后果 -> 新压力` 核对：若被删段落承担“人物为何相信”“对手如何得知”“道具如何到手”，须在新版本建立等价可见桥，并记录原功能、新载体、保住的因果、损失项及创作者确认状态。

### 重排也要登记

`adaptation-map.jsonl` 的 `disposition` 取值：`preserve`（保留）、`merge`（合并）、`change_carrier`（换载体）、`compress`（压缩）、`omit`（删去）、`move_earlier`（后文提前）、`cold_open`（提作冷开再切回原时序）、`add`（新增）、`unresolved`（待决）。

将后文高光标为 `move_earlier` 或 `cold_open` 时，必须在映射的 `causal_compensation` 中补齐三件事（`reviewed_invariant · STY-29`）：

- **必要前因跟着提前**：被提上来的那一拍依赖哪条关键事实，在更早场次用可见动作埋下，或在开场后用一两句当场交锋/极短闪回立刻补齐；
- **时间定位与顺序衔接**：冷开切回正叙时靠字幕卡（如“48 小时前”）、同一物件新旧状态对照或台词定位时间；直接改顺序的须重新接顺前后因果；
- **处理被掏空的原位置**：原位置不得再原样演一遍——直接删去、改成摊牌后的余波与反扑，或换另一爽点顶上。

**小说后文高光前移与补前因示例**：

- **原著写法**：小说第 1–3 章写妻子在三年婚姻里一次次忍让丈夫偏袒青梅竹马（摘下玄关婚纱照、岳父做心脏手术时丈夫去给青梅做生日餐），妻子心死后悄悄去民政局补办了结婚证；直到第 4 章丈夫三年来第一次下厨摆酒哄她，她才在餐桌上一声不吭摆出三样东西——**补办的结婚证、后天飞外地的单程机票、签好字的离婚协议**，丈夫看见那本崭新的红本子瞬间血色尽失。
- **只挪高潮、漏掉前因（断桥）**：把第 4 章“餐桌亮出结婚证与离婚协议”直接提到第 1 集开场，却没交代结婚证有什么特别，观众看不明白丈夫为何看见结婚证就脸色惨白。
- **前移高光 + 补齐因果桥（成立）**：第 1 集先用 15 秒冷开拍家宴餐桌上丈夫举杯说“以后都听你的”，妻子平静摆出崭新结婚证与离婚协议，丈夫盯着红本子失声问“你什么时候去补办的？！”妻子冷冷打断：“三年前在民政局门口，你当众把结婚证撕成两半，说没这本子我就永远离不成——现在它补好了。”随后画面切回字幕“两天前 · 心外科手术室外”，接妻子独自签手术同意书的正叙开篇；原第 4 章位置则改成丈夫拒签后追去机场拦人的余波反扑。

### 新增也要登记

原著独角查证、隔空博弈或纯心理拉锯在竖屏里需要新增当场阻碍、限时危机或施压对手时，不得混入 `change_carrier`，必须单独登记为 `add`（`craft_default · STY-30`）：

1. **插入位置与功能**：在映射中记入 `source_span` 与 `preserved_functions`；
2. **新增理由与事实核对（`addition_rationale`）**：说明为何原著已有人事无法承担（对手优先从原著质疑者、起哄群体、规章期限中找；原著确无对手时可报出节奏档案偏差，不把支持者硬改成反派），并核对新增内容不会让反派提前暴露底牌或抢走主角高潮功劳；
3. **列入创作简报**“原著没有、本轮新增的内容”清单交创作者确认。

**原著独角查证戏新增当场压力示例**：

- **原著写法**：未婚夫一家在订婚宴上用“先转入 88 万改口费、一分钟后由第三方空壳公司自动代扣划走”的连环局诬陷女主借网贷，逼她拿父母的学区房签抵押协议。小说第 5–6 章写女主假装答应回娘家拿房产证，实则独自去网吧查空壳公司股东名单，又独自去未婚夫公司地库坐在副驾驶戴耳机听行车记录仪录音找出密谋铁证。
- **照搬原著（冷场）或乱加支线（跑偏）**：照搬则连着两场都是女主独自盯屏幕；硬加“黑客男闺蜜破译银行后台”又抢走女主破局主线、废掉后文家宴当众放录音的底牌。
- **在原有人物关系内新增限时阻碍（成立）**：保留女主去地库拔行车记录仪内存卡查证的主线，**新增（`add`）当场时间压迫**：女主刚坐进副驾把内存卡插上平板筛选录音，手机就弹出未婚夫发来的定位共享请求，紧接着地库电梯口传来未婚夫和婆婆边走边聊“趁她爸妈还没回过味，今天必须押她把房产证拿出来按手印”的脚步声！女主必须在两人走到车位前的几十秒内导出音频、插回内存卡并从后排溜走。

## 5. 单集化而不肢解

把长叙事拆成多集时，每集须兑现原材料的一部分吸引力、由本集选择产生结尾压力、停在下一次揭晓之前，并以精确事实交接至下一集。

## 5b. 登记不等于兑现

**`STY-23 · reviewed_invariant`**：创作简报登记为不可更改的来源事实，在本轮覆盖范围内必须落定为以下两者之一（世界设定可延后到首次改变人物选择的那一集，首集只交代本集冲突用到的规则）：

- **落在第几集、可见载体是什么**：该载体必须同时写进对应集的分集记录与剧本正文；
- **显式延后到第几集**：写明集号。

单集内部同理：分集记录声明的可见载体必须在剧本里实际演出；需要前后对照才成立的载体**两端都要拍出**（例如分集记录写“靠妹妹绑定替唱系统前后哼同一句曲调的换气点不同来识破调包”，剧本不能只拍“绑定后唱得完美无瑕”，前面必须先拍出“她平时唱到高音必会卡顿换气”）。规则分级见 [阶段契约](stage-contract.md#本阶段规则)。
