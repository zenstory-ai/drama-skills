# Agent Note: 出片实测复盘（二）：比例、共用段落、镜内切、电话声与按集拆批

Status: implemented

## Problem

继 [出片实测沉淀：空间、音色与切点](2026-11-06-generation-continuity-learnings.md) 之后，又把同一部对标剧的三集还原拿去出片（每集以一场戏为主，共约 80 镜，关键帧做首帧图生视频）。看片人和一次模型辅助审片发现：

- **台面高度逐镜跳**：地点条目没写柜台高度，关键帧正文也没写台面落在人身上哪里，同一个人身前的台面逐镜从胯部跳到胸口。
- **凭空多人、特写变中景**：为统一比例，给每镜拼进同一段“柜台约 90 厘米、三个人各多高、机位站立眼高”和同一段写着厨师与排烟罩的视角说明。结果下一集的空店镜头里多出厨师和别的角色，后仓长出排烟罩，双眼极特写、手背、打火机、手机屏幕这类镜头也都被拉成中景。
- **镜内快切丢失**：还原分镜把每条实测镜头记成一条分镜、镜内切点只写在说明里，生成时每条只出一个连续镜头，原片接电话前一秒一切的眼、嘴特写变成一个慢推。
- **电话声像当面说**：提示词写了“从听筒里传出、略带电话音质”，音画同轨模型生成的仍是干净的全频人声，而且逐镜不一样；内心独白的混响同样逐镜不一。
- **额度中途用完**：一次提交两集的全部镜头，额度用完时第一集出齐，第二集十四镜只出了一镜，剪不成片。

## Decision

以下都是 `craft_default`，不新增规则编号，分别写进负责的技能：

- `short-drama-assets` 的 `location-and-view.md`：人会靠、撑、坐的固定物写明高度和落在人身上的位置；合成例的柜台补上高度。
- `short-drama-storyboard` 的 `keyframe-craft.md`：写作顺序第 2 步补“入画固定物落在人身上的高度”；新增“整场共用的段落按镜裁剪”，拼进每镜前删掉不在场的人和看不到的陈设、写明本镜只有哪些人，特写和道具插入镜不带比例与房间描述。
- `short-drama-review` 的 `generated-media.md`：首尾帧拼图检查补“固定物落在人身上的高度及人物身高比例”，对照基准加上角色设定。
- `short-drama-breakdown` 的 `reconstruct.md`「拿还原去出片」：出片时按镜内切点拆成单镜，一秒上下的眼、嘴、手、道具特写单独成镜。
- `short-drama-edit` 的 `sound-and-subtitles.md`：电话、免提、扩音人声在时间线统一加带通滤波，内心独白统一加轻混响，记入剪辑单。
- `short-drama-produce` 的 `SKILL.md`：额度有限时按集拆批，一集跑完再建下一集的 job。

## Alternatives considered

- **同场各镜机位高度一致。** 好处是台面在画面里的位置最稳。但把“机位站立眼高”拼进每镜会把特写和仰俯镜头都压平，所以只在固定物入画时写它落在人身上的高度。
- **候选先审画面再看台词、核对画面里每只手的归属、排查无对白镜头里模型自己加的声音。** 都是这次遇到的问题。第一条是“别只看一个指标”的常识，后两条已由审查技能的看画面要求和剪辑技能的“拼接后回听”覆盖，不另立规则。
- **剪辑统一补 0.6 秒句尾、成片不加配乐、特写也挂地点图、一个上传失败就停整批。** 这次都踩了，但技能已有明确规定（句尾留约 0.4 秒、配乐由时间线层负责、近景偏宽就不挂地点图、拆小批并在中断时先查后取），是执行没照做，不另加规则。
- **记录 Seedance 2.5 首帧图生视频开口晚 1–2 秒。** 是实测事实，能帮着估镜长；但它是单个模型版本的行为，换版本要重测，这次只收跨模型成立的做法。

## Consequences

- 收益：提示词不再混进别的镜、别的集的人和陈设；特写保住景别；还原出片保住原片的快切重音；电话声和内心独白的质感在时间线一次定下；额度不够时仍能交出完整的集。
- 代价：每镜的共用段落要按在场人物和视角裁剪；镜内切拆开后镜头数和生成次数变多；带通滤波和混响要在剪辑外部工具里做并记入剪辑单。
- 局限：结论只来自一部剧的三集、一个图像模型和两个视频模型的这一轮实测。
