# Seedance提示词怎么写：起点、动作顺序、终点三步写法

Seedance 提示词先写开场定格画面，再按先后顺序写清动作和收尾画面，注明镜头怎么动、声音在哪一刻响。Drama Skills 的 Seedance 2.5 多镜合生写法采用连续整数秒区间；官方指南也支持按镜头序号分段。Seedance 2.0 写法采用动作先后顺序加镜头序号（官方说明精确时间码支持不稳定）。提示词方案、参考图对应关系与实际生成出来的成片要分开核对，别指望光写上时间码、卡字数或加一句“无字幕”就能保证一次成片到位。

## Seedance提示词要写哪几项？七项清单

下面按 Drama Skills 的动作提示词写法整理成七项自查表，帮你把分镜定好的内容写具体；表里例句仅示范写法，生成后仍需看成片核对效果。

| 项目 | 怎么写 |
|---|---|
| 起始画面 | 要点：人物姿势、朝向、双手位置与手持物。例：她坐在窗边椅上，左手握着半杯凉茶。漏写后果：模型自己乱选开场状态，接不上前一镜。 |
| 动作顺序 | 要点：动作起因、主体、朝向与肢体接触。例：听见敲门后，她先放下茶杯，再从椅子上起身。漏写后果：几个动作挤在同一秒发生，先后顺序全乱。 |
| 动作落点 | 要点：停在哪个接触点或参照位置。例：杯底碰到桌面，手指松开；人最后停在门前。漏写后果：只写“往前走”却没写停在哪儿。不必给每镜硬编角度或厘米数。 |
| 同步变化 | 要点：只有确实同时发生、互不打架的变化才写“与此同时”。例：她放杯的同时，窗帘被风吹起一角。漏写后果：本该同步的画面脱节；没有同步动作时直接略过，别为了填表硬加一阵风或路人。 |
| 收尾画面 | 要点：最终站位、姿态、视线、双手与物件位置。例：她站在门前，双手空着，茶杯留在桌上。漏写后果：结尾跑偏，接不上下一镜。 |
| 运镜 | 要点：固定机位，或写清何时起动、往哪移、停在什么景别。例：固定中景，完整拍下放杯与起身。漏写后果：没写清机位，模型随机乱晃镜头。 |
| 声音 | 要点：有台词时按声音先后顺序逐字写清，标明谁在什么时刻开口。例：站到门前后，{她用中文说：“那我自己去。”}。无台词镜写明环境底声或安静无声。漏写后果：台词重读、吞字或口型错位。 |

可按需套用这句起草骨架：`从［开场定格画面］开始；接着［按先后顺序的动作与接触］；必要时与此同时［互不打架的同步变化］；最终停在［收尾画面］。镜头［固定构图，或移动轨迹与起止时机］。声音［逐字台词、音效先后顺序或环境底声］。`

复制使用前把方括号换成这一镜的具体内容，删掉用不上的分句；这只是正文句式参考，完整文档字段以 `视频提示词.md` 为准。

## Seedance视频提示词的核心：起点、动作顺序、终点

起点和终点在分镜阶段就已定好，视频提示词不改头尾设定，专心写清中间怎么动：谁在什么起因下做了什么，最后停在哪儿。分镜怎么定起止，见[已有剧本怎样直接做分镜](https://zenstory.ai/zh/drama-skills/script-to-storyboard)；开场定格画面的写法见[首帧提示词](https://zenstory.ai/zh/glossary/dongjie-guanjianzhen)。

### 起点：用此刻的静态状态写

起点写成镜头开场那一瞬间的定格画面——如果写成“他正要推门”，其实已经把后面的动作提前塞进起点了。只写动作起步前必须交代清楚的事：身体重心和朝向、视线落点、哪只手拿着什么，以及离门、桌子或旁人有多远。

如果已经挂了真实的本镜起始帧图片，且图里把人物外观和构图交代清楚了，提示词正文可以省掉重复的外貌描写，只保留和本镜动作直接相关的双手、手持物、接触点与视线。如果只挂了人物外貌参考图或场景空镜图，这些图不等于本镜的开场构图，人物站位和当下状态仍要写清楚。文生视频没有参考图，人物长相、服装、场景陈设、构图和光线都要写进正文。跨镜头稳住同一张脸的做法见[AI 短剧角色跨镜一致](https://zenstory.ai/zh/drama-skills/character-consistency)。

### 连续动作与表演：用触发串起来

每一步写清谁、做什么、朝哪边、碰到什么、停在什么状态，再用因果先后串起来：先听见或看见什么，眼神转过去，手上的活停住，最后身体才动起来。“缓缓、自然、电影感”这类词告诉不了模型动作往哪走、走多远；人物情绪要落到呼吸、眼神、停顿或手部小动作上，比如把“紧张地等”写成“手指停在杯沿，呼吸变浅，目光两次扫向门口”。

每镜尽量围绕一个核心变化来组织动作和反应；只要先后层次清楚，写连贯的几步动作也没问题，不硬卡动作个数。如果几个互不相干的变化挤在一起看不清，再回分镜拆成两镜。

### 摄影机与声音：机位要有动机，声音排成一条时间线

机位要么固定不动，要么只走一条有明确用意的轨迹：什么时刻起动、往哪边推拉摇移、最后停在什么景别。Seedance 同一次生成画面和声音时，把这一镜里的对白、画外音和音效按先后顺序排成一条清楚的声音时间线，有声节点之间回到写明的环境底声或安静状态。

### 终点：写完逐项对照

写完提示词后，拿结尾跟分镜的「终点」逐项核对：人物姿态、站位、视线、双手、手持物。全部对得上才算定稿；漏了哪项补哪项，如果真要改结尾状态，先回分镜改好再同步过来，不在视频提示词里另起炉灶。

提示词写齐了，只代表文字方案接住了分镜；视频生成出来后，还要看成片逐段检查中段动作顺不顺、手拿东西准不准、台词有没有吞字，光看最后一帧截图不够。

## Seedance 2.5：时间轴与镜头序号怎样选

截至 2026-09-30 核对的[火山引擎 2.5 指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)，可以用镜头序号或时间轴组织多镜头情节；时间戳按秒描述，单段塞进太多内容容易漏拍或生硬切断，写太少又容易让模型自己乱加戏。

Drama Skills 的 2.5 多镜合生配置采用连续整数秒区间，例如 `镜头 1 [0:00–0:05]：`。这是本套件的统一写法：总时长定好后，各段首尾相接不留空档，最后一段终点正好对齐总时长；并非所有 2.5 提示词都非这样写不可，短单镜直接按动作先后和触发词写就行。

- 逐段核对起止秒数，别写成“中间空两秒、末尾超两秒、加起来刚好相等”，把要演的动作、台词和反应安放在各自的秒段里。
- 一段里塞太多动作容易漏拍或硬切，写太少模型又容易自由发挥；发现松紧不对就回头调整分段或镜长。
- 时间轴只是排期计划，出片后仍要对照实际视频检查切点准不准、台词有没有赶词或吞尾音、收尾画面到没到位。
- 每次提到参考素材都顺手写明它的用途，如 `人物 @图片1`、`参考 @视频1 的表演节奏`，图片和视频编号按当次实际上传顺序核对。
- 收尾画面要求严时，可按分镜终点补做一张尾帧图，提交时把首尾两张图分别挂到 `first_frame` 和 `last_frame`；注意中间的过渡动作仍要看成片验收。
- 局部改片时写清“保留 A、B，只把 C 改成……”；视频续接则接着输入视频的实际最后一刻往下写，提交前核对原视频和尾帧文件是否真挂上了。

官方指南也提醒过，写上“不要字幕”并不能百分百杜绝画面冒字。提示词里照常保留无字幕要求，出片后仍要肉眼检查参考图和成片画面里有没有夹带多余文字。

## Seedance 2.0 视频提示词怎么写：动作顺序加镜头序号

截至 2026-09-30 核对的[火山引擎 2.0 指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)，官方推荐按事件先后写“镜头 1、镜头 2”，并说明精确时间码支持不稳定——它并非完全不认时间戳，只是没法靠时间码锁死切镜点。

Drama Skills 的 2.0 模型配置据此采用“动作先后顺序 + 镜头序号”，分镜里的秒数只作内部时长估算。单镜不用标序号；多镜合生时逐镜写清谁、在哪儿、做什么、镜头怎么拍。提示词正文语言按项目选定的模型配置走，人物开口说的台词语言按剧本走。

本套件把对白统一标成 `{角色用中文说：“逐字台词”}`，音效标成 `<声音>`，配乐标成 `（音乐）`；这是本套件的统一标法，不是官方唯一固定写法。不要字幕的要求直接写进正文末尾，出片后仍要看一眼画面里有没有冒出野生字幕。

每次提到参考素材都写明用途，例如 `人物 @图片1`。要接着上一段成片往下续拍时，写清续接动作，并按所用续接方式核对上一段生成的真实视频或截取的尾帧是否挂好。如果对切镜时间点要求极严，与其赌多镜合生的切点，不如拆成单镜分别生成后再剪辑。

## Seedance提示词示例：同一组镜头的 2.5 版和 2.0 版

设定：末班公交进站，司机正要熄火，最后一排传来手机震动。分镜两镜共 8 秒：镜头 1 司机回头，5 秒；镜头 2 空座上的手机，3 秒。文生视频，不要字幕。

2.5 版的时间段首尾相接，到 `0:08` 正好对齐总时长；文生视频要写出司机的长相和穿着，台词只在声音时间线里出现一次：

> 镜头 1 [0:00–0:05]：夜里的末班公交停在终点站，车厢灯全亮。四十岁上下的男司机穿深蓝色工作服，坐在驾驶座，右手捏着插在锁孔里的钥匙，左手搭在方向盘上，视线落在前挡风玻璃。车厢后部传来震动声，他的视线先移到车内后视镜；接着右手松开钥匙，上身向他自身右后方转，直到能看向最后一排；与此同时，车外站台的灯箱熄灭；最终他侧身定住，左手仍搭在方向盘上，看向最后一排，随即开口，口型与台词同步。固定中近景，从前门一侧平视，全程不动，让观众看清他松开钥匙的那只手。
> 镜头 2 [0:05–0:08]：同一节车厢的最后一排，空座位上一部手机屏幕朝上亮着，随震动在座面中央轻微挪动，保持在座面上；随后震动停下，屏幕仍亮着。固定近景，略俯拍座面。
> 声音时间线：全程底声是发动机怠速的低鸣；司机转头前，车厢后部响起<手机震动声>；司机定住后：{司机用中文说：“谁的手机？”}；镜头 2 开头<手机震动声>再响一次，停下后回到怠速低鸣。全程无字幕、无对白文字叠加。

Seedance 2.0 版只改两处：去掉方括号里的时间段，改成 `镜头1：`、`镜头2：`；在镜头 1 的起点句后面补一句“开头保持一拍”。改完的开头如下：

> 镜头1：夜里的末班公交停在终点站，车厢灯全亮。……视线落在前挡风玻璃。开头保持一拍。车厢后部传来震动声……

其余内容照 2.5 版保留。本套件的 2.0 提示词正文不写时间戳，5 秒、3 秒只作内部时长估算。如果对切镜点要求很准，可以把两镜拆开单独生成后再剪接；但拆成单镜提交前要先核对平台接口的最短时长限制（比如合生里原本只占 3 秒的子镜头，拆出来单独提交可能低于平台单次生成的最短秒数，需要先调整镜长）。

## Seedance提示词常见错误与改法

- **通篇空泛形容词**：把“缓缓、电影感”换成具体的移动方向、肢体接触落点和最终姿态。
- **所有动作挤在同一刻**：从动作起因开始按先后串起来，“与此同时”只留给互不打架的同步变化。
- **正文混进文件名、版本号、锁定编号**：这些内部标记容易被模型当成画面文字画出来，只留在提示词外面的条目说明栏里，别贴进可复制正文。
- **台词塞不下就硬催语速或乱删字**：回分镜拉长镜长或拆成两镜；真要精简台词就回剧本改。
- **文生视频只写一句“保持原有外观”**：文生视频没挂参考图，模型不知道“原有外观”长什么样，需把人物长相、服装、场景陈设和光线写进正文。

## 用 Drama Skills 怎么做

装好本仓库的 skill 后（对应 [short-drama-video-prompts](../skills/short-drama-video-prompts/SKILL.md)）：在 Claude Code 里说：“用 /short-drama-video-prompts 把 EP001 的分镜一镜一条写成视频提示词”（Codex 里写作 `$short-drama-video-prompts`）；还没有分镜就先用 `short-drama-storyboard`。项目配置里还没定目标模型时，直接说“按 Seedance 2.5 写”，它会先通过 `short-drama` 记进项目配置再出稿；参考图还没备齐时，会先查项目里已有的实图，你也可以自己准备参考图，用 `PLAN-...` 挂图计划照常往下写提示词。只有明确不用参考图时才走文生视频；还缺关键参考图时会列出缺口清单等你拍板。

## 常见问题

**Seedance提示词写多少字合适？**

没有适合所有镜头的固定字数。本套件把短单镜两百字左右当作少写废话的参考经验，既不是模型上限，也不是质量门槛；多镜合生、文生视频和长台词镜头自然会写得更长。删掉重复的机位套话和空泛形容词，把人物特征、连续动作、逐字台词、音效和收尾画面写扎实，别为了凑短字数删掉关键剧情动作。

**Seedance 2.0 能用时间戳吗？**

官方 2.0 指南说明精确时间码支持不稳定，倒不是完全不认时间戳，只是切点容易飘。所以 Drama Skills 的 2.0 配置改用“动作先后顺序 + 镜头序号”，秒数只留作内部时长估算；精准切点靠生成后剪辑下刀把关。

**Seedance 2.5 首尾帧怎么用？**

首帧、尾帧两个槽位各挂一张图；收尾状态要求严时，照着分镜终点补做一张尾帧图。这两张帧图同样占图片序号，正文里的 `@图片N` 按实际挂图顺序连续往下数。首尾帧能不能同时再混挂其他人物或场景参考图，要看所用接口的当期文档并实测确认，中间的过渡动作仍要看成片验收。
