# 去模板感：诊断、修订与误报

先定位重复机制怎样伤害当前故事，再把具体修订目标交给负责技能；“像模板”本身不足以构成 finding。

## 1. 诊断四层

1. **因果重复**：每轮都靠陌生人带来答案、巧合救场、对手自曝。
2. **策略重复**：所有人物都用质问—否认—提高音量，没有各自筹码。
3. **表达重复或过度工整**：动作总是“攥拳/眼神一冷”，每句对白都跟同构微动作，
   或 prompt 总以泛化质量词开头。
4. **镜头重复**：每句台词 close-up + push，camera 不随 attention/关系变化。

只有能引用至少两个位置并说明损失，才发重复 finding。单次使用类型惯例不是模板罪证。

表达层还要检查不依赖逐字重复的情况：

- **过度解释**：动作、证据或台词已经表达人物选择，后面又补一句意义说明、心理翻译或
  道德总结，夺走观众推断空间；
- **过度收口**：每场都用总结句、金句或完整结论封死余波，下一场只能重新制造压力；
- **过度工整**：每轮台词都配相同长度的微表情/手部动作，每场都以同构对仗或反问落点，
  人物和场面失去自己的节奏。
- **信息密度均匀**：每拍携带的新信息量几乎相同，重要事件没有获得相应分量。把一场戏的
  各拍放在一起比较，检查信息接收、等待和关键变化是否形成疏密；逐拍成立仍可能掩盖整场节奏单一。
- **代价被自动清空**：连载已经把某项代价设为持续压力，却在成功后自动复位，后续不再继承。
  对照代价建立的位置与后续落点，说明丢失了什么后果。代价在本集得到有因果的解决、单集完整收束，
  或创作者有意选择开放与封闭的结尾，本身都不构成缺陷。

Reviewer 要引用当前作品中至少两个位置，说明被重复解释、封死或抹平的
具体意义；有意的仪式、喜剧节拍、人物口癖、方言和创作者选择继续按下文反例处理。

## 2. 修订不是换同义词

### 因果

弱：主管再次嘲笑她。她拿出另一份证据，所有人震惊。

诊断：证据无需选择便出现；第二轮只把第一轮“拿证据打脸”再演一次。

给 write owner 的目标：保留公开施压与主角掌握证据；让主角必须在“马上公开”与“先保护
会被顶罪者”之间作不可兼得的选择，并让选择产生下轮压力。不要在 finding 里代写完整台词。

### 对话

弱：

~~~text
A：你在骗我。
B：我没有骗你。
A：你就是在骗我。
~~~

若 B 手里有纸袋，A 手里有钥匙，可要求每轮改变筹码：A 用钥匙证明到访；B 用“拆袋即选边”
重定义信任；A 选择拿走钥匙但不拆袋。沉默和物件完成第三轮，不必更响。

### Prompt

弱：“高级、电影感、精致、超清的神秘盒子。”

Finding 应指出缺少哪个 accepted identity/scale/material/state/text policy。修订目标是补这些
识别事实，不是禁用“高级”一词。

### 镜头

三个连续台词都 extreme close + push。先问每句 attention：第一轮是双方关系，可留 two-shot；
第二轮证物被推过桌面，attention 落到手/边界；第三轮对方不碰证物，reaction 可由手和负空间
完成。不是为了“景别多样化”，而是每个 cut 有不同 viewing purpose。

## 3. 误报反例

以下不能仅凭表面重复判模板：

- 仪式场景刻意重复同一句/同构图，第二次因持有人改变而意义反转；
- 喜剧 running gag 重复动作，但每次让新人物付出不同代价；
- 审讯保持 locked two-shot，以拒绝剪切制造压迫；
- 类型短剧多集使用相同片头结构，这是 accepted format；
- 人物因创伤反复做同一动作，作品正在表现停滞而非遗漏变化。

Reviewer 必须说明：重复是否是 creator choice、第二次新增了什么、若保留会伤害什么。
无法确认重复造成损失时，记为 note/question，保留创作者选择。

## 4. Finding 示例

~~~markdown
## Major · REV-003 · 连续两集用同一种自曝完成揭示
- 位置：剧本.md / EP002-SC003；剧本.md / EP003-SC002
- 证据：两场都由主管主动说出隐藏事实，主角没有选择。
- 影响：主角策略不参与揭示，连续两集的回报来自对手自曝。
- 修订结果：保留两项事实，但让至少一项揭示由主角有代价的策略触发。
- Owner：short-drama-write
- 规则：SCR-04 · craft_default
~~~

位置只使用文件名、标题 ID、行号或必要短引文。不要复制上游快照，也不要为审查另建记录 ID。

## 5. 分级

- structural_invariant：finding 的位置、严重程度、owner 与结论明确且可复核。
- reviewed_invariant：下游没有改写 source meaning；需证据判断。
- craft_default：避免无意义的因果/策略/表达/镜头重复；可由创作者说明覆盖。
- taste_option：类型惯例、仪式重复、running gag、固定镜头风格本身不阻断。
