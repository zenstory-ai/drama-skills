# Agent Note: 维护者知识学习文档的观察归因与盲评时序对齐

Status: implemented

## Problem

维护者技能只研究文本；卡片契约把 `media_observed` 定义为制卡 agent 本人是否看过媒体，并固定为
`false`。提示词研究参考却只在“没有可信媒体观察”时要求写 `false`，容易把他人的授权观察误记为
agent 自己看过。卡片说明中的“纯文本链固定为 none”也没有分清只有项目文本与另含合格文字观察报告的情况。Promotion ledger 的“揭盲后才写 verdict”也没有区分揭盲前冻结的盲评初步结论与
揭盲后记录的最终生命周期决定，与盲测协议的时序衔接不清。

## Decision

逐份执行五步精修，保留只读授权、隔离研究、去标识、去复刻、角色分离与独立批准边界。让提示词研究
沿用卡片定义：维护者 agent 始终写 `media_observed: false`，他人的观察归因于 `observer_report`；
没有合格观察报告时选择 `none`；输入参考只能支持输入参考事实，生成结果校准仍须绑定准确版本和观察范围。Ledger 先冻结匿名包与输出，
再冻结揭盲前的逐项偏好和初步结论，揭盲后核对映射及公共 diff，最后记录最终决定。

只改技能文档中的说明；所有 YAML schema、合成示例、字段名与取值保持原文。此次只使用公开仓库资料，
不读取非公开来源，也不运行学习、模型评测或 promotion。

## Alternatives considered

- **保留原文，由读者对照其他参考推断**：最强理由是卡片与盲测协议已有正确要求，熟悉流程的维护者能够
  自行消歧。不采用，因为各参考按需独立加载，歧义会直接影响证据归因与评审冻结时点。
- **新增字段或自动评测工具**：最强理由是能机械区分观察者和各阶段结论。不采用，因为既有 schema、
  `observer_report` 与独立审查流程已能表达事实，只需对齐说明。

## Consequences

- 收益：证据说明、卡片字段和盲评交接时序一致，读者能分清 agent 的文本阅读与他人的媒体观察。
- 代价：真实媒体效果与去复刻充分性仍依赖获授权的观察和独立审查，文档精修不提供这些证明。
