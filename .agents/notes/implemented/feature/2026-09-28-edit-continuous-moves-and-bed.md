# Agent Note: 按速度写的运镜、跨切点的环境声与接镜提醒

Status: implemented

## Problem

静帧样片的画风和配音统一之后，维护者仍觉得镜头之间接得不自然。量下来有三处：

- 每段运镜都整段缓入缓出，镜头在每个切点都停一下；同一场相邻两段的切点前后三帧，平均位移只有段中的一小部分。
- 运镜只能写整数百分比，同一个速度落到不同时长的段上要各自换算，1.4 秒的段只能取 4%（2.9%/秒）或 3%（2.1%/秒）。
- 环境声只能按段写成音效，每段结尾 50 毫秒淡出，底噪在每个切点塌下去 10–18 dB。

## Decision

**剪辑单写法**（`SKILL.md` 只写语法，规则在 `references/still-cuts.md` 的「运镜」「环境声」两节）

- `运镜` 多一种写法 `推近 2.5%/秒`（其余五个方向同），速度 0.1–10，可带小数，`％／秒` 也认。
  `CameraMove` 多一个 `rate`；百分比写法照旧，整段缓入缓出。
- 新增 `- 环境声：[<起>] <文件>（起点；增益）` 与 `- 环境声：[<起>] 无`。一条从本段 `起` 开始循环铺到下一条
  `环境声`：到下一条所在段的开头，或它的 `起` 更晚时到它的 `起`。所以下一条写负的 `起` 时两层重叠，
  是换场时的声音过桥。环境声没有窗口写法，写成 `起-止` 在解析时报错。

**render**

- `_move_ease` 为每段定两端缓不缓：前后一段在同一场景、都写速度、方向相同，则这一端不缓；
  否则（换场、固定、换方向、百分比写法、场景追不到）缓。
- `_move_progress` 给出第 `on` 帧已走的百分比：速度写法以匀速为主，需要缓的一端用半余弦把速度从 0 提到巡航
  （`CAMERA_EASE = 0.5` 秒，不超过段长一半），已走距离是匀速距离减去两端缓冲少走的部分，都是 `on` 的闭式；
  总幅度 = 速度 ×（时长 − 两端缓冲的一半）。平移的放大量取总幅度，推拉按已走比例变焦。
- 音效、配音、环境声统一成 `Placed`，由同一个 `_sound_effect_command` 混：环境声 `-stream_loop -1` 循环，
  两头各淡 0.3 秒，切点处不做任何处理。

**check**

- 速度写法走完一段超过 30% 报错（速度 × 渲染时长）。环境声的 `起` 与配音同样限在上一段开头之后、文件须在项目内。
- `move_notices` 在同一场景的相邻两段之间给「提醒」：方向相反（推近↔拉远、左移↔右移、上移↔下移），
  或速度相差 30% 以上（百分比写法按幅度 ÷ 时长折成速度）。提醒放在 check 输出的 `提醒` 里，不影响退出码。

**创作台**：`creator_views` 同样读速度写法与环境声，对照测试覆盖；成片表里显示「推近 2.5%/秒」与环境声文件。

**验证**：`tests/test_edit_measurements.py` 覆盖速度写法的解析、拒绝与幅度上限，缓冲规划的八种相邻关系，提醒的七种情形
与经 `main` 输出，环境声的解析、铺放区间与两种越界；真实渲染同一场两段 2 秒的左移：速度写法切点两侧的逐帧位移不低于段中的 60%，
百分比写法（对照）低于 30%，1 秒的环境声循环铺过切点、切点处 10 毫秒电平不掉。8 处守卫逐条改掉，全部变红。

## Alternatives considered

- **让 `音效` 像配音一样跨切点，用来铺底噪。** 最强理由是不加新字段。不用：一个房间声文件通常只有十来秒，
  一场戏要二三十秒，创作者得自己算每一截的起点并首尾相接，接缝处仍会有淡出；一行 `环境声` 更短也不会写错。
- **所有运镜都去掉缓冲，一律匀速。** 最强理由是最简单。不用：从固定切到运镜、或运镜后接固定时，
  匀速起步和戛然而止同样显眼；只在真正起步和停下的地方缓，才同时照顾到两种切点。
- **速度差和反向当成错误。** 最强理由是规则更硬。不用：有意的变速（情绪突然收紧）是创作选择，只该提醒。
- **把百分比写法改成匀速。** 最强理由是只剩一种行为。不用：会悄悄改变已有剪辑单的成片；两种写法各自清楚，文档一句话讲明。

## Consequences

- **收益**：同一场同向的镜头穿过切点不减速，接起来像一台机器；底噪一条铺满一场，切点不再塌陷；
  换场可以用环境声提前进场来过桥；忽快忽慢与来回反向在渲染前就会被提醒。
- **代价**：`Placed` 替换了原来的五元组，`_sound_effect_command` 的调用方改用它（旧元组仍能按位置传入）；
  运镜表达式多了 `min`/`max`，依赖 filtergraph 单引号保护逗号；速度写法下同一段的最终幅度取决于两端缓不缓，
  写的人看不到具体百分比。
- **已知上限**：只有相邻两段同场同向才连续；换方向时仍会先停再起。环境声整条循环一个文件，不做交叉淡化的接缝处理，
  文件本身首尾不齐时每个循环点会有轻微接缝。
