# 单集跨上下文交接摘要

长单集受上下文限制、需要分批续写时，在**当前会话上下文**维护一份最小交接摘要。摘要只帮助恢复写作，
不落盘；`剧本.md` 仍是剧本权威。

## 只记恢复下一段真正需要的内容

- 当前集号和最后完成的场景 ID；
- 上一场结束时仍会影响下一场的地点、在场人物、知识、关系、伤势、持物与风险；
- 已建立但尚未兑现的铺垫与回报；
- 下一场已确定的功能与退出状态；若它由争取或冲突组织，再记目标、反对与转向；
- 本批仍未解决、会改变下一段写法的真实创作分叉。

只记录变化和下一步依赖，不复制整段正文、角色小传、视觉设定或全部旧节拍。任何信息都要能回到
当前 `剧本.md` 的场景 ID 核对；摘要与正文冲突时以正文为准。

## 恢复步骤

1. 重新读取当前 `剧本.md` 的最后一个已完成场景及其相邻上下文；
2. 对照摘要中的结束状态、未兑现义务和下一场目标，丢弃已经过期的信息；
3. 只读取下一场直接依赖的分集规划与连续性事实，不预加载无关 reference；
4. 写下一场前重新确认它的必要功能与退出状态；冲突场景再确认目标、反对与转向，不能把候选想法当既定剧情；
5. 场景写入正文后刷新上下文摘要；整集完成后删除摘要。

交接摘要只帮助恢复注意力，不代表创作者确认、审查通过或交付状态。
