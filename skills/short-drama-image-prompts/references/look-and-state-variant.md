# 造型、视图与道具状态变体提示词

## 1. 变体条目六要素与编写重点

针对 `视觉设定.md` 已确认的可复用造型、地点视图或道具状态变体（单镜瞬时表情、手势或机位归分镜，未决身份先退回 `$short-drama-assets`），每条变体 `IMG-...` 必须交代：

1. **派生基底（`structural_invariant`）**：指向基础身份或上一变体条目；
2. **保持锚点（`reviewed_invariant`）**：跨变体不变的人物面部/体态、固定空间地理或道具轮廓材质；
3. **当前变化**：变化发生的具体部位、覆盖范围、强度与材质/色彩反应（不用“更脏、更老、更阴森”等空泛词）；
4. **原因与来源**：触发变化的剧本场景 ID 或视觉方向决定；
5. **有效范围**：生效起止场次/镜头；
6. **下游绑定**：依赖该变体的 `SHOT-...` 或其他 `IMG-...`。

**`craft_default`**：可复制正文先简述保持的核心身份锚点，再将重心放在本次变化上，不整段照抄基底全文后把变化藏在句尾；默认单出当前变体设定板（不把变化前后两个互斥状态画进同一张图，除非明确声明为分区比较板）。

## 2. 三类变体与局部编辑的分工

- **人物造型变体（Character / Look）**：写明衣物穿法、发型整理、妆面、污湿、血迹、包扎或年龄跨度的准确位置与未变区域（如“维修员夜班造型雨后：仅外套右肩至肘部明显湿深、发梢微湿；窄长脸、断眉、左胸布贴与右袖旧焊痕保持不变”）。
- **地点视图与状态变体（Location / View-state）**：固定入口、主分区与建筑锚点保持，只改观察朝向、临时陈设、营业状态、时段、天气与光线（不得因改成夜景而搬动门窗，或把临时堆放物写成永久地理）。
- **道具状态变体（Prop / State）**：保持轮廓与材料，写明铰链开合角度、裂纹/缺口位置、内容物可见度与承载面文字呈现（单纯换手无需新建道具状态板；若道具彻底断成两截且功能改变，退回资产阶段判定是否新建资产）。
- **变体设定板 vs 局部编辑（`edit_delta`）**：变体设定板面向多镜复用的完整当前状态，可从零编写或绑定基底参考图；针对既有图片做局部涂改时使用 `edit_delta`（见 [定点修改](edit-and-revision.md)）。
