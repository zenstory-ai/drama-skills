# 运镜、现场声与跨镜连戏

## 1. 运镜写法与防冲突规则（`VID-06`、`VID-07`）

镜头动或不动承接分镜的「运镜」设定；运镜术语优先对齐目标模型写法指南，模型对专业术语不敏感时同步写出直观的画幅比例与前景遮挡变化。

- **固定机位**：简洁写明景别构图与画面内正在发生的表演/环境动态即可（如 `固定中近景，机位在轴线左侧平视，专注捕捉她扣住伞柄起身的眼神与手部动作`），无需为使用固定镜头额外编造辩护理由。
- **移动机位**：交代起幅构图、起动时机、移动方向与快慢节奏，以及符合分镜终点的落幅构图，运镜途中守住场景空间方位与既定轴线。
- **同一时段禁混冲突运镜（`VID-06`）**：同一时间区间内不得既写“固定机位”又写“推拉 / 摇移 / 环绕”，也不得无过渡地同时下达反向移动指令。先静后动拆成互不重叠的前后时段：
  ```text
  0.0–1.2s 固定机位：停在双人中景等待她抬眼；
  1.2–4.0s 缓慢推近：顺视线收至她的头肩近景，落幅保持原机位侧。
  ```

## 2. 对白、口型与现场声（`VID-14`、`VID-23`）

每条 `MOTION-...` 的对白、VO、OS 与关键音效严格对应《剧本.md》与《分镜.md》，不私改字句、不换说话人、不把现场对白擅改成画外旁白。跨镜延续同一句台词时，标明本镜承担起句、画外延续还是落音收尾：

- **画内对白（dialogue）**：画内说话人口型、呼吸与神态同步；
- **画外旁白 / 内心独白（`[VO]`）**：画内人物嘴唇不随旁白张合；若说话人正脸在画内，或同框旁观者在他人说话时易串口型，优先借侧脸/背身取景避开，确需正脸入画时在正文写明该角色嘴唇闭合不说话；
- **画外同期声（`[OS]`）**：说话人在同场画外或背对镜头，保留声源传来的空间方位感；
- **关键音效（`[SFX]`）与环境底声**：写明触发音效的具体动作与响起时机；同场相邻镜头的环境底声交代延续或起止变化，避免切镜时听感突变。
- **配乐归属后期剪辑（`VID-14`）**：除非属于画内收音机、现场弹奏、手机铃声等现场声源或创作者明确要求单镜直出配乐，单镜与多镜合生片段默认只保留人声、环境底声与动作音效；需排除模型乱加BGM时写“无背景音乐”，不写“全程静音”以免误抹同期声。逐镜配乐构想记在说明中交 `$short-drama-edit` 铺设。

## 3. 首尾帧与跨镜动作衔接

### 首尾帧模式的使用边界

同时传入起始帧与结束帧时，模型会优先对齐头尾两格构图、对中间过程做自动补间过渡：

- 拆信封、翻账本、拔刀出鞘等撑起本镜看点的复杂中间过程，不能指望只靠首尾两张图自动脑补完成；常规姿态变化优先单传起始帧并在正文写清动作与终点状态。
- 传入尾帧时，正文仍须按顺序写明中间动作过程与运镜，并与分镜「终点」一致。

### 跨镜衔接与连续动作精修

- **常规切镜默认独立送生**：换景别、换机位、正反打切换或常规动作顺接的相邻镜头，默认各自使用已定稿的首帧或参考图独立生成，只需在文字上对齐前后动作进度与持物状态（`CON-01`），**绝不把相邻镜头默认标成“待续接、不可提交”锁死投产流程**。
- **跨镜硬切接同一连续动作的末帧精修（按需选用）**：仅当相邻两镜在同一连续动作半途硬切（如上一镜推门到一半、下一镜紧接门扇继续推开，或一镜到底长调度拆成两段接力），且需要像素级咬合上一镜实际落定姿态时，才采用先生成上一镜、再用 `ffmpeg` 抽取上一镜成片**真实末帧**校准下一镜起始帧（或连同上一段真实成片走模型视频续写 `extend`）的精修做法。若上一镜实拍落点与分镜原定终点明显跑偏，先决定重抽上一镜还是交 `$short-drama-storyboard` 微调切点，不在提示词里硬圆穿帮状态。
- **切点共用静帧**：当创作者明确为构图一致的相邻两镜指定共用同一张切点图时，上一镜可将下一镜首帧兼作结束帧（首尾帧与多图参考互斥的模型改走多图参考并在正文点明首尾图分工）。

## 4. 上游设定边界与修订退回（`VID-01`）

本阶段不私改分镜已定的镜长、起止状态、机位轴线与剧本台词。若发现规定秒数装不下动作与台词，或前后镜头持物/站位衔接冲突，明确指出冲突位置与修改建议，退回 `$short-drama-storyboard`、`$short-drama-write` 或 `$short-drama-assets` 处理。
