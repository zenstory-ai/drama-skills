# 分镜文档格式规范（完整项目模式）

撰写并落盘完整项目文档 `剧集/<EP>/分镜.md`（用于跨文档自动核对、下游视频提示词对接或内置批量投产）时，按本规范组织字段与标点。若仅是轻量起草几镜草稿或单独构思镜头，可直接按 `SKILL.md` 的轻量模式输出，不必强套全套机读语法。

## 一、文档结构与编号约定

- **未拍场次**（仅在确需整场略过时填写）：写在文档开头、首个 `## SHOT-...` 之前，格式为 `- 未拍场次：<场景 ID>（理由：……）`，多个未拍场次之间用全角分号 `；` 分隔。
- **镜头二级标题**：每镜使用 `## SHOT-... · <名称>`。`SHOT-` 编号后缀及所有参考槽位编号（`REF-`、`PLAN-`）仅使用大写英文字母、数字与连字符 `A-Z0-9-`。
- **整集汇总**：全集总时长与待拍板事项可在回复中说明，或写在文档末尾独立的 `## 整集汇总` 二级标题下，切勿不加 `## ` 标题直接附在最后一镜的提示词引用块下方。

## 二、单镜字段顺序与写法

每条 `## SHOT-... · <名称>` 下依次列出以下字段：

| 字段 | 必填/可选 | 写法要求 |
|---|---|---|
| `- 来源：` | 必填 | 直接以 `<场景 ID>` 开头，如 `EP001-SC001「…」`，场景 ID 必须存在于 `剧本.md` |
| `- 时长：` | 必填 | 单镜秒数，如 `4s`（时长待定时明文标出） |
| `- 目的：` | 必填 | 本镜的戏剧或叙事作用，不写空泛套话 |
| `- 景别/机位：` | 必填 | 景别、水平角度与机位高度 |
| `- 运镜：` | 必填 | 运动镜写清动法与起止落点；固定镜直接写 `固定` |
| `- 起点：` | 必填 | 镜头开场一瞬间的画面事实 |
| `- 动作：` | 必填 | 镜内发生的核心状态变化、位移与持物交接 |
| `- 终点：` | 必填 | 镜头收尾一瞬间的画面落定状态 |
| `- 画面文字：` | 可选 | 仅含剧本 `[画面文字]` 的镜头填写 |
| `- 图片提示词项：` | 可选 | 填写《图片提示词.md》已有条目 `IMG-...《<名称>》（控制：…）`（`《…》` 内名称与标题完全一致）；尚无对应条目时写 `无` 或省略 |
| `- 输入参考图：` | 必填 | 见下文第四节槽位语法 |
| `- 出场设定：` | 必填 | 见下文第三节出场设定语法 |
| `- 声音：` | 必填 | 写明现场对白/VO/OS、关键音效与留白，免写读秒算术账 |

### 首尾帧提示词小节

- 每镜下设 `### 首帧提示词` 定格镜头 `起点` 瞬间画面；仅在后续视频生成确需锁死收尾构图时另加可选的 `### 尾帧提示词` 定格 `终点` 画面。
- 小节内**只放顶格以 `>` 开头的引用块**，不夹普通列表或 `---` 分隔线。
- 提示词正文语种跟随 `short-drama.json#/format/prompt_language`（无配置文件时按已有提示词或项目文档语种推断，未指定时使用用户当前语言）。

## 三、出场设定语法

首尾帧成稿后，对照提示词正文里**实际入画**的人物、造型、地点与道具填写 `- 出场设定：`，每项 `控制：` 只写本镜景别实际可见的部位：

```text
- 出场设定：《视觉设定.md》·<人物|造型|地点|道具>「<名称>」（控制：<范围>）；<人物|造型|地点|道具>「<名称>」（控制：<范围>）
```

- **名称一致**：`<名称>` 与《视觉设定.md》条目标题完全一致，多项用全角分号 `；` 连接。
- **造型连戏锁联动**：当入画人物身着《视觉设定.md》单独建档的 `## 造型 · <名称>` 且该套服装在本镜画面可见时，须同时列出 `造型「<名称>」`（用于触发挂在 `造型` 条目下 `镜头：入画` 的服装连戏锁）；手部或眼部特写看不到服装时不列 `造型「…」`。
- **画外提及条目**：校验仅核对首尾帧入画主体，不扫描 `- 来源：` 引文里的未入画名称。首尾帧正文因归属物或字样点到但本镜未入画的条目，在末尾追加 `；画外：<人物|造型|地点|道具>「<名称>」`（多项用 `；` 连接）。
- **远景与无条目情况**：远景需认出身份的角色照常列入；完全无设定条目入画时写 `无`；尚未建档的连戏物件先在提示词稳住描写，并在汇总中请 `short-drama-assets` 技能补建。

## 四、输入参考图语法

自动在用户提供的输入、`剧集/<EP>/制作成果/` 和文档已指向的可见媒体中核对真实图片（支持 `.png` / `.jpg` / `.jpeg` / `.webp`）后再填写：

### 1. 真实图片（`REF-...`）与外部挂图计划（`PLAN-...`）

- 已有项目内真实可读图片使用 `REF-...`；外部工具自挂图片预留 `PLAN-...`（将路径位置换为 `IMG-...` 或 `SHOT-...`，指向 `IMG-...` 时 `《…》` 内名称须与《图片提示词.md》标题一致；支持正反打等跨镜复用已有镜头首帧）。
- 两者可混排，并按挂图顺序从 `1` 连续编号：

```text
REF-<slot>（顺序：<n>）· <项目相对路径>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
PLAN-<slot>（顺序：<n>）· <IMG-...或SHOT-...>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

- **标点要求**：使用全角冒号 `：`、全角括号 `（）`、路径或编号前的中点 `·`；不得用 `/` 代替字段分隔符；多张图之间只用中文全角分号 `；` 连接。
- 只有真实 `REF-...` 可直接交由 `short-drama-produce` 技能图生投产。

### 2. 十项允许的 `用途` 及配额

每个参考槽位从以下十项中选填**唯一**主作用（一图兼顾两事时将次要作用写入 `控制：`）：

`外貌` / `主体` / `造型状态` / `空间布局` / `构图` / `尺度` / `效果` / `起始帧` / `结束帧` / `风格`

- 每镜最多一张 `起始帧` 和一张 `结束帧`；挂载 `结束帧` 时必须同时挂载 `起始帧`。
- 参考图位超出目标模型上限时，按「起始帧 → 核心动作/开口角色 → 关键道具 → 场景 → 其余角色 → 风格」或按本镜景别焦点取舍。

### 3. 待补参考图与纯文生视频

- **等待实图到位**：写 `无（待补参考图：<缺项>）`，或在已有槽位后追加 `；待补参考图：<缺项>`（多个缺项用顿号 `、` 分隔）。
- **确认不垫参考图**：写 `无（文生视频）。` 或简写 `无`。
