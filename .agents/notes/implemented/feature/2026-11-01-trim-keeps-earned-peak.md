# Agent Note: 压稿保留有铺垫的爆发与宣判句

Status: implemented

## Problem

写作技能的经济性遍要求删去「回报后多个同方向决定、解释或后果」，自写对白也要删掉不承担动作的句子。
这两条在复仇、逆袭一类靠结算取悦观众的戏里会误伤：一场戏唯一的峰值上，有铺垫的爆发、紧跟的关系宣判句
（例如「我们之间，到此为止。」）和离场动作，被读成「离场已经表明了决定」的同义收尾。

基线：一份合成的逆袭集和一份家庭集，在超时状态下按目标时长压稿，现行技能跑 3 次。空喊 3/3 被删，
跨句依赖 0 处被删断，一句话完成的情感反转 3/3 被指出；但有铺垫的爆发或宣判句在 2/3 次被删或压扁，
其中一次把宣判句列为「冗余」，按项目时长恢复时也不放回。

## Decision

`script-craft.md` 的经济性遍新增 `SCR-23`（`craft_default`）：压稿先认出这场的回报。峰值上有铺垫的爆发、
紧跟的宣判句和落地动作承重，离场动作表明了决定也不算同方向收尾；时长不够先删别处，爆发本身只压缩重复。
没有铺垫、没有新情绪阶段、与前文同义的空喊照删。

候选：同一份材料、同一份答案，只多这一段的技能副本跑 3 次。爆发与宣判句 0/3 被删，空喊仍 3/3 被删，
没有多保留别的台词；一次整场合并后有一处人物引入悬空，与这条规则无关。

## Alternatives considered

- **不改，只靠已有的「直白是 `taste_option`」和 `SCR-06`**：规则已经允许直白，再加一条会显得重复。未采用：
  基线读到了这些仍删掉宣判句，删的依据是经济性遍和自写对白遍，允许直白不等于压稿时知道它承重。
- **改宽「回报后同方向决定」的删除规则**：一处改动覆盖更多情况。未采用：这条规则在大多数场次上正确，
  宽松后基线里本该删的同义收尾会留下；问题只出在峰值上的结算，范围应收窄在那里。
- **在审查技能加一条误报保护**：审查也可能把宣判句当标语。暂不做：这次只测了写作压稿，审查侧没有观察到误报。

## Consequences

- **收益**：复仇、逆袭等靠结算的戏在压稿后仍保留观众等待的那一下。
- **代价**：一次合成测试、每臂 3 次，结论是「这一组里有效」。判断哪句是「有铺垫的爆发」仍靠写作者阅读，
  可能被拿来保护本该删的长篇宣泄；规则里写明空喊照删，候选测试里没有观察到过度保护。
