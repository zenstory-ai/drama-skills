# Creator-first 示例

《让你管账号》EP001 展示一集在默认工作流里的全部创作表面：五份 Markdown，没有创作阶段
JSON/JSONL、索引、指纹、QA、审核表或隐藏投影。
本例选择中文创作者说明、英文可复制生成提示词；其他项目按自己的提示词语言执行。

- [`剧本.md`](EP001/剧本.md)
- [`视觉设定.md`](EP001/视觉设定.md)
- [`分镜.md`](EP001/分镜.md)
- [`图片提示词.md`](EP001/图片提示词.md)
- [`视频提示词.md`](EP001/视频提示词.md)

本集是同一前提的合成改写，时代为当下，按漫剧节奏写成：22 镜、约 62 秒，平均镜长约 2.8 秒，`[VO]` 约占台词字数两成。
第一帧就是压力：视频会议里其他军团哄笑、上级点名给出下周评比的期限，周薄森把这摊空白交下来，江晨第 31 秒顶回去；
对手和压力都取自原著已有的事实，不新增具名人物。集尾停在任务落下的那一拍；系统面板只在后期叠加。
本例没有声明目标模型，镜长按叙事节奏定；换成有最短原生时长的模型时，按分镜技能「已声明原生时长」一条处理短镜。

这是创作效果样例，不是格式 schema；具体约束以各 owner skill 与 creator-first 文档契约为准。
