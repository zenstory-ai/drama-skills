# 剧本阶段职责与规则

本环节只负责维护 `剧集/<EP>/剧本.md`（场景、动作、对白、画外音、关键音效、画面文字、连戏提示与转场），不介入角色视觉设定、分镜构图、生成提示词或素材生产。项目目录内不另建节拍表、段落索引、审批单或状态文件；按需核对字数与时长时直接运行 `duration_estimate.py --script`。现有材料定好的事实、`必须/禁止` 要求、题材路数与集尾落点优先于本表；严禁凭空编造原稿没有的精确数字、记录、资源、流程或机关设定。

下表仅注册阻断级不变量（`structural_invariant` 与 `reviewed_invariant`）；场次推进、对白交锋、制作标记使用建议、动作冒号避让、倒计时/限次写法、声音叙事、节奏参考与压时长技巧等创作经验（`craft_default` / `taste_option`）见 [中文短剧剧作方法](script-craft.md)、[短剧对白写法](dialogue-craft.md) 与 [中文短剧 Markdown 剧本格式](screenplay-format.md)。

## 本阶段规则

### `SCR`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| SCR-03 | reviewed_invariant | 关键剧情转折处的人物心理变化须外化为可拍摄的动作、物证状态变化，或明确标注的 `[VO]`/`[OS]`，不拿大段无法拍摄的纯心理说明替代戏剧行动。 |
| SCR-05 | structural_invariant | 制作标记（`[画面文字]`、`[VO]`、`[OS]`、`[SFX]`、`[连续性]`、`[转场]` 等）须使用规定的固定语法且指代清晰。 |
| SCR-25 | reviewed_invariant | `[连续性]` 只记录前文动作已演出的状态变化，不能单靠一行备注断言镜头外“从未发生某事或从未接触某物”。 |
