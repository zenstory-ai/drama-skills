# Seedance提示词怎么写：起点、动作顺序、终点三步写法

Seedance提示词从可见起点写到有序动作和终点，把摄影机与声音放在相应事件上。Drama Skills 的2.5多镜头写法采用连续整数秒区间；官方也允许镜头序号。2.0写法采用动作顺序与镜头序号，官方说明精确时间支持不稳定。计划、参考图对应关系与实际视频分别核对，不用时间码、字数或“无字幕”声明保证结果。

## Seedance提示词要写哪几项？七项清单

以下按 Drama Skills 的运动配方整理成读者检查卡。它帮助把已经决定的镜头写清楚，不保证模型按文字逐项精确执行，也不代替真实画面检查。例句展示各项怎样写，不是已经完成生成的结果。

| 项目 | 记录 |
|---|---|
| 起手状态 | 要点：姿势、朝向、双手与持物。例：她坐在窗边椅上，左手握着半杯凉茶。遗漏风险：模型另选起点，接不上前镜。 |
| 有序动作 | 要点：触发、主体、方向与接触。例：听见敲门后，她先放杯，再从椅上起身。遗漏风险：动作同时发生，先后不清。 |
| 可见落点 | 要点：到达哪个接触点或地标。例：杯底接触桌面，手指松开；最后停在门前。遗漏风险：只写“向前”却不知道结束在哪里。无需为每镜编角度或厘米。 |
| 必要并行 | 要点：只有同时发生且互不冲突的通道才写“与此同时”。例：她放杯时，窗帘被风掀起一角。遗漏风险：必要同时关系丢失；没有并行动作时不为填表增添风或第二个人。 |
| 结束状态 | 要点：位置、姿态、目光、手与物。例：她站在门前，双手空着，杯子留在桌上。遗漏风险：收尾偏离已确认终点。 |
| 摄影机 | 要点：固定构图，或有动机的路径、触发和终点。例：固定中景，让观众看见杯子落桌与她起身。遗漏风险：未写明的机位由模型选择。 |
| 声音 | 要点：有台词时逐字写在声音时间线的一处，注明说话人和发生时机。例：站到门前后，{她用中文说：“那我自己去。”}。无台词镜记录需要的底声或静默。遗漏风险：台词重复、漏词或错位。 |

可按需要使用这个编辑骨架：`从［可见起点］开始；接着［有序动作与接触］；必要时与此同时［独立通道］；最终［终点］。摄影机［构图或路径与理由］。声音［来源中的逐字台词、声音顺序或静默］。`

复制前将占位换成本镜事实，删除不适用部分；这不是原生运动文档的完整格式。

## Seedance视频提示词的核心：起点、动作顺序、终点

起点和终点由分镜定好，提示词只读不改，只负责中间的变化：谁在什么触发下做了什么，最后停在哪里。分镜怎样定起止，见[已有剧本怎样直接做分镜](https://zenstory.ai/zh/drama-skills/script-to-storyboard)；起始画面的规格见[冻结关键帧](https://zenstory.ai/zh/glossary/dongjie-guanjianzhen)。

### 起点：用此刻的静态状态写

起点写成此刻定格的画面，“他正要推门”已经把后面的动作提前写了进来。只写开始运动必须知道的事：重心和朝向、目光落点、哪只手拿着什么，以及离门、桌子或旁人有多远。

真实起始帧已挂载且包含所需外观和构图时，可以省去它已经清楚说明的静态细节，仍保留动作所需的双手、持物、接触与视线。只有身份图或地点图时，图片不等于本镜起点，构图和当前状态仍须写明。文生视频没有图，人物、造型、地点、构图和光线都要写进正文。跨镜保持同一张脸见[AI 短剧角色跨镜一致](https://zenstory.ai/zh/drama-skills/character-consistency)。

### 连续动作与表演：用触发串起来

每一步写清谁、做什么、朝哪、碰到什么、到达什么状态，再用因果连起来：先听见或看见，视线转过去，手停下，最后身体才动。“缓缓、自然、电影感”说不出动作往哪走、走多远；情绪落到呼吸、注视、停顿或手上的动作，把“紧张地等”写成手指停在杯沿、呼吸变短、目光两次扫向门口。

优先围绕一个主导变化组织动作与反应，这是起步方法，不是规定的动作数量。连续表演与调度仍清楚时可以保留多个阶段；互不依赖的变化挤在一起且难以读懂时，再回分镜讨论拆开。

### 摄影机与声音：机位要有动机，声音排成一条时间线

机位要么固定，要么只走一条有动机的路径：什么时候开始动、往哪动、停在什么景别。Seedance 同一次生成画面和声音时，把本镜全部对白、画外音和音效按先后写成一条声音时间线，事件之间回到写明的底声或静默。

### 终点：写完逐项对照

把终点和分镜逐项对照：姿态、位置、目光、双手、持物。全部一致才算完成。提示词漏了哪项就补哪项；结尾确需改动，回分镜环节去改，提示词里不另写结尾。

逐字段一致说明提示词计划接住了分镜，不说明视频已经生成或到达终点。实际输出还要检查动作中段、手部接触、台词完整性与最后可见状态；只看最后一帧也不够。

## Seedance 2.5：时间轴与镜头序号怎样选

截至2026-09-30核对的[火山引擎2.5指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)，可以用镜头序号或时间轴组织情节；时间戳按秒描述，内容过多可能导致遗漏或过度剪切，内容过少可能留出自由发挥。

Drama Skills 的2.5多镜或长叙事档案选择整数秒连续区间，例如 `镜头 1 [0:00–0:05]：`。这是本项目的写法约定：固定总时长已接受时，段落不留无意空档，最后终点与总时长对应；不是所有2.5提示词都必须这样写。短单镜也可以用相对先后与触发。

- 逐段检查起止，不把“中间空一段、尾部超一段但合计一样”当成计划正确。把需要的动作、台词和反应安排在可用窗口内。
- 超出计划容量或内容过少都需要回看安排；不能断言一定只截尾巴、一定生成计划外动作，或补写定格就一定得到指定停留。
- 秒段是时间计划，生成后按真实媒体检查切点、发声、语速、尾音与终点。没有实测不称逐秒达标。
- 每次提及素材写明职责，如 `人物 @图片1`、`@视频1 的表演节奏`；编号按当次挂载顺序核对。
- 终点重要时可按分镜制作尾帧，按接口将首尾图绑定到 `first_frame` 和 `last_frame`。有两张提示词不等于已有两张帧图；中段变化仍要看结果。
- 编辑写“保留A、B，只修改C”；延长从输入视频的实际终点续写。两者按提交任务类型与实际绑定核对，未有原视频时不称已经续接。

官方指南也说明“不要字幕”不能完全保证无字幕。保留本镜所需声明，同时核对参考素材和实际画面，不把提示词约束当作成片结果。

## Seedance 2.0 视频提示词怎么写：动作顺序加镜头序号

截至2026-09-30核对的[火山引擎2.0指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)，推荐按事件顺序写“镜头1、镜头2”，并说明精确时间支持不稳定。不能把它写成完全不认时间戳，也不能凭时间码保证切点。

Drama Skills 的2.0档案据此选择动作顺序与镜头序号，秒数留作内部预算。单镜不必编号；多镜各自交代谁、在哪、做什么、镜头如何观察。正文语言按已选档案，台词语言按剧本，不从英文教程或模型名称推断。

本项目将对白写成 `{角色用中文说：“逐字台词”}`，音效写成 `<声音>`，音乐写成 `（音乐）`；它们是项目正文约定，不是官方唯一合法语法。无字幕要求直接写在正文，实际是否出现字幕仍需检查。

素材使用时重复职责绑定，例如 `人物 @图片1`。需要接着上一段实际结果时，写清延长意图并核对真实视频、真实尾帧和接口绑定；不是看到一个图片提示词条目就已经有续接素材。若要精确剪点，可评估独立生成后剪辑，仍以实际输出为准。

## Seedance提示词示例：同一组镜头的 2.5 版和 2.0 版

设定：末班公交进站，司机正要熄火，最后一排传来手机震动。分镜两镜共 8 秒：镜头 1 司机回头，5 秒；镜头 2 空座上的手机，3 秒。文生视频，不要字幕。

2.5 版的时间段首尾相接，到 0:08 正好是总时长；文生视频要写出司机的样子和穿着，台词只在声音时间线里出现一次：

> 镜头 1 [0:00–0:05]：夜里的末班公交停在终点站，车厢灯全亮。四十岁上下的男司机穿深蓝色工作服，坐在驾驶座，右手捏着插在锁孔里的钥匙，左手搭在方向盘上，视线落在前挡风玻璃。车厢后部传来震动声，他的视线先移到车内后视镜；接着右手松开钥匙，上身向他自身右后方转，直到能看向最后一排；与此同时，车外站台的灯箱熄灭；最终他侧身定住，左手仍搭在方向盘上，看向最后一排，随即开口，口型与台词同步。固定中近景，从前门一侧平视，全程不动，让观众看清他松开钥匙的那只手。
> 镜头 2 [0:05–0:08]：同一节车厢的最后一排，空座位上一部手机屏幕朝上亮着，随震动在座面中央轻微挪动，保持在座面上；随后震动停下，屏幕仍亮着。固定近景，略俯拍座面。
> 声音时间线：全程底声是发动机怠速的低鸣；司机转头前，车厢后部响起<手机震动声>；司机定住后：{司机用中文说：“谁的手机？”}；镜头 2 开头<手机震动声>再响一次，停下后回到怠速低鸣。全程无字幕、无对白文字叠加。

Seedance 2.0 版只改两处：方括号里的时间段去掉，写成 `镜头1：`、`镜头2：`；镜头1 的起点句后面加“开头保持一拍”。改完的开头是这样：

> 镜头1：夜里的末班公交停在终点站，车厢灯全亮。……视线落在前挡风玻璃。开头保持一拍。车厢后部传来震动声……

其余照 2.5 版保留。本项目2.0正文不使用时间戳，5秒、3秒只是内部预算；官方说明精确时间支持不稳定，不能说完全不认。若需要准切点，评估两镜分开生成后剪；独立任务时长按接口范围准备，不能把容器中的3秒成员直接当作合法独立任务。以上8秒及两镜分配是文字方案，未声称录音计时或实际生成达标。

## Seedance提示词常见错误与改法

- **只有形容词**：把“缓缓、电影感”落实为方向、接触落点和结果。
- **动作全挤在同一刻**：从触发开始串成链，“与此同时”只留给一条不冲突的通道。
- **正文混进文件名、版本号、锁定标记**：它们可能变成画面里的字，留在工作卡片里。
- **台词放不下就加快语速或删字**：回分镜延长或拆镜；改台词回剧本环节。
- **文生视频只写“保持原有外观”**：模型没收到图，把人物、造型、地点和光线写进正文。

## 常见问题

**Seedance提示词写多少字合适？**

没有适合所有镜头的固定字数。运动配方把短单镜约两百字作为省重复的写作建议，不是模型限制或质量门槛；多镜、文生视频和长对白可能需要更多。合并重复机位与形容词，保住必要身份、动作、逐字台词、声音和终点，不要为了压字数删掉关键剧情和动作要求。

**Seedance 2.0 能用时间戳吗？**

官方2.0指南说明精确时间支持不稳定，不能说完全不认时间戳。Drama Skills 的2.0档案因此用动作顺序与镜头序号，秒数留作内部预算；精确剪点通过实际生成素材与剪辑核对。

**Seedance 2.5 首尾帧怎么用？**

首帧、尾帧两个位置各放一张图；终点状态关键时，按分镜终点做尾帧。两张帧图也占图片序号，`@图片N` 按素材顺序连续往下数。首尾帧能否再混用其他参考图，要按接口文档核对并实测，中间的动作仍要看成片检查。
