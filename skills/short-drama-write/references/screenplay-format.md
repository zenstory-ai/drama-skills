# 中文短剧 Markdown 剧本格式

## 1. 设计目标与事实所有权

`剧本.md` 是场景边界、动作、对白和生产指令的**唯一可编辑剧本源**。规则分级与阶段所有权边界见 [stage-contract.md](stage-contract.md)；不在剧本中写人物/场景/道具资产全集、镜号景别与运镜、图片/视频提示词、生成参数或终审结论。

## 2. 文件、集与场景结构

### 2.1 集标题

```md
# EP001 【集名】
```

`EP001` 是稳定集 ID；修改集名不改 ID。

### 2.2 场景标题

```text
## <场景ID> <内|外|内外> · <地点> · <时间/天气>
```

示例：

```md
## EP001-SC003 内 · 渡口售票室 · 雨夜
```

- **场景 ID**（`structural_invariant`）：同一项目内唯一且稳定；改显示名称不改 ID，新建场景才分配新 ID；拆分/合并无法明确映射时展示映射选择，不暗中猜测。
- **空间与地点**：`内/外/内外` 标明主要行动空间；地点使用创作者可识别名称，不写资产内部编号。
- **时间/天气**：只保留对表演、光线、行动或连续性有用的事实。

## 3. 动作、对白与生产标签

### 3.1 动作段落

普通段落表示现在发生、可见或可表演的行动（单个动作段落可跨多行，空行分隔不同段落；组合示例见第 5 节）：

- **`craft_default`**：使用现在时与可执行动词；焦点行动、信息或空间关系变化时另起段落。完整动作链、氛围或推理可保留较长段落，不按统一长度切分。
- **`craft_default · SCR-18`**：动作段落**不要以「短语＋全角冒号」开头**。`第二格：一只手把杯子推过去。` 或 `屏幕上正在放的东西：一段没有声音的录像。` 与对白语法（`角色名：台词`）字面相同，索引器会报 `ambiguous_dialogue_or_action`。改用破折号、逗号或动词（如 `第二格换成一只手把杯子推过去。`、`屏幕上正在放的是一段没有声音的录像。`）；句中冒号不受影响。

### 3.2 对白

```text
角色名（可选的表演/策略提示）：台词
```

- 角色名与说话者必须明确；建索引前由写作所有者确认本集说话者清单，工具只核对清单，不从冒号前缀猜人物。
- 括注提示描述一个可与本句同步执行的策略或变化（如“把威胁说成提醒”“不让第三人听见”），不堆叠同义情绪词；前后动作已清楚时可省略。
- 现场不可见说话者用 `[OS]`，非现场主观/叙述声音用 `[VO]`，两者均可带提示：`[OS] 船员（隔着门喊）：关窗！`。只有主角听得见的系统音、心声写 `[VO] 系统：…`；现场旁人也听得见的广播、喇叭写 `[OS]`。

### 3.3 生产标签

只在事实对故事不可省略时使用（`SCR-05`、`SCR-07`）：

| 标签 | 用途 | 边界与禁用 |
|---|---|---|
| `[VO]` | 非现场主观/叙述声音 | 不隐藏普通可见行动，不复述已演出的画面 |
| `[OS]` | 同一场景中的画外对白 | 不代替明确说话者 |
| `[SFX]` | 改变注意、行动或信息的关键声音 | 不罗列无剧情职责的环境音 |
| `[画面文字]` | 观众必读的载体与精确内容 | 紧贴人物展示、翻看或视线落向载体的那一拍写出；不复制一般道具说明 |
| `[连续性]` | 前文动作已建立、易丢失且影响后续的状态变化 | 不把整套人物设定贴入每场，不用作者标签证明镜头外“从未发生某事” |
| `[转场]` | 有叙事意义的转场要求 | 不编写剪辑方案全集 |

**`taste_option`（出场名条）**：主要人物首次出场可加 `[画面文字] 名条：许棠｜社区打印店店主`，只写名字与当前所需的一个身份、不写形容词（后期叠加，不进生成提示词）。

## 4. 注释与未知内容

```md
<!-- 待确认：渡口停运年份是否影响下一集时间线。 -->
```

- Markdown 注释原样保留，临时索引将其标为非生产内容；生产关键事实不能只藏在注释中。
- 未识别的 Markdown 原样保留并发出警告，不擅自删除或修改。
- **`structural_invariant`**：规范化映射必须报告每个未映射的原文范围，不能暗中丢字节。

## 5. 完整格式示例

（前情：末班江轮迟迟未归，售票员葛晴的弟弟在船上当水手；站长咬定“末班船因大雾已停靠对岸”，机务员游森却在站长锁着的调度台翻出一张印着明晚日期 `11月6日`、背面已用站长专用双孔钳打穿两个放行圆孔的船票副联，并顺出栈桥内门黄铜钥匙赶到售票窗前，要葛晴从里侧打开栈桥内门查船。）

```md
# EP001 明天的末班票

## EP001-SC003 内 · 渡口售票室 · 雨夜

售票窗已经落锁。游森从窗口底槽塞进一张湿透的船票副联，食指死死按住票面日期。

葛晴没有去接。她先把窗口旁的木质收渡时刻牌翻了个面。

葛晴（压低声音，防着走廊里的站长）：站长刚来锁了栈桥内门，说末班船半小时前就在对岸收渡了。

游森：那你看看我刚从他调度台里翻出来的这张票。

葛晴捏住票角往里一抽——票面印着明晚的日期，背面却已经用站长专用的双孔钳打穿了两个放行圆孔。

[画面文字] 票面日期：11月6日

[SFX] 雨幕深处的江面传来一声短促的货轮汽笛。

游森回头望向已经熄灯的栈桥码头，把刚从调度室摸出来的黄铜钥匙塞进窗口底槽。

游森：栈桥内门只能从你里侧开锁。想知道你弟那班船今晚被他派去装了什么货，就替我把那道门打开。

[连续性] 栈桥内门的黄铜钥匙留在售票窗内侧底槽，由葛晴取得。
```

## 6. 稳定 ID、临时索引与修订

临时索引由 `scripts/screenplay_index.py` 生成在系统临时目录，只做场景、块、标签识别与时长统计，绝不反向覆盖 `剧本.md` 或自动润色文字。邻近文字修改且语义块映射明确时保留块 ID；段落拆分、合并或整场重写无法确定映射时，显式提出重映射选择，不暗中重用旧块 ID。

## 7. 现有文本的规范化入口

创作者提供其他格式的现成剧本时，目标是在不改原意的前提下整理成标准格式，不擅自重写剧情或台词：

1. 将原始字节保存为 `输入/original-script.<ext>`，记录原编码与来源说明；
2. 只提议场景标题、动作/对白边界、受支持生产标签与索引所需的最小结构变化；
3. 展示原文与规范化对照预览，分开报告纯格式整理、语义变化（新增/删除/改写）、未映射范围与低置信映射；
4. 经创作者确认后才写入 `剧本.md`。

- **`structural_invariant`**：创作者确认前不得覆盖 `剧本.md`，草稿中的关键信息不得暗中漏掉。
- **`reviewed_invariant`**：改变说话者、行动先后、事实、因果、人物态度或未说内容均属语义变化，必须显式标出，不得算作纯格式整理。规范化不要求补创作简报或新增节拍。
