# Agent Note: 剪辑把反应压在台词上，群戏不再一人一句地轮流

Status: implemented

## Problem

剪辑的对白默认（`EDT-19`）是开口前约 0.25 秒入、句后留约 0.4 秒反应再出。每一镜各自这样剪，台词和反应就排成队：
一个人说完，切到另一个人反应，再切到下一个人说。用一场五人年夜饭的真实生成素材（两句台词、三个人的反应）跑基线，
剪辑技能给出 6 段、15.1 秒，镜序照剧本、头尾都去掉了，但两句台词都在说话人的画面里说完才切到听者，
看起来像回合制。[配音与字幕跨切点](2026-09-28-edit-voice-across-cuts.md) 早已让 `配音` 可以说过切点，
`cut-craft.md` 也写了画面可以切在一句台词中间，但基线没有用上：这条做法只在静帧成片里写成了默认。

## Decision

`cut-craft.md` 新增「反应压在台词上」（`EDT-22`，`craft_default`）：

- 一句台词引起别人的反应时，在后半句、意思已经读到的地方切到听者，让这句话在听者的画面上说完（L-cut）；
  下一个人先开口、画面后到（J-cut）同理。这时说话那一镜的出点不按 `EDT-19` 的句后停留来定。
- 内置 render 把画面和原声一起裁，切点之后的半句用外部工具从同一素材截出，记录素材和区间，作为 `配音` 写进听者那一段、
  `起` 写 0；字幕仍写在说话那一段，止写到这句说完。`起` 必须小于本段时长，所以不写进说话那一段的末尾。
- 要让一句话先落地、静一拍再看反应时，可以保留先说后看。

验证：同一份素材观看记录交给只多了这一节的剪辑技能，给出 5 段、13.3 秒，「去年的流水」压在大伯笑僵的画面上，
大伯母拉袖、沈浩低头连着切；它自己找到了截声音放进 `配音` 的做法。两份剪辑单按原样渲染给创作者对比；
此前创作者看过按先说后看剪出的 18 秒版本，评价是「像回合制」。

## Alternatives considered

- **只靠已有的「画面可以切在一句台词中间」**：一句话已经写在 `cut-craft.md` 里，不需要新规则。未采用：基线读到了它，仍然每句都在说话人画面里说完；那句话讲的是允许，不是什么时候该这么做。
- **把 `EDT-19` 的句后停留改短或删掉**：改一个数字最省事。未采用：单人独白和需要落地的一句仍需要句后的停顿；问题不在停多久，而在反应该不该等台词说完。
- **让内置 render 支持原声跨切点延续**：创作者不用自己截声音。未采用：要新增剪辑单写法、check 与 render 的分支，现有 `配音` 跨切点已经能做到，只差一步外部截取。

## Consequences

- **收益**：多人场景的反应和台词同时发生，同一批素材剪出的成片短约 2 秒，节奏不再轮流。
- **代价**：每处 L-cut 要多一次外部截取并记录区间；听者那段原声里若有人声要先处理。只测了一场戏、一次纸面剪辑，
  节奏的好坏由创作者判断，套件不把交叠与否当缺陷（`EDT-14`）。
