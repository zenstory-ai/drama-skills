# 短剧美术设定图提示词

将 `视觉设定.md` 定好的外观设定写成可直接复制的角色设定图、场景空镜设定图、道具设定图、状态变化图、局部改图或视觉定调图（Lookdev）提示词，统一写入 `剧集/<EP>/图片提示词.md`：

- 每项使用二级标题 `## IMG-... · <名称>`（`IMG-...` 只标识提示词条目，不代表磁盘已有成图），下设 `- 参考：` 与可选 `- 用途：`。
- **参考图唯一语法**：无外部参考时写 `- 参考：无外部参考`；绑定项目内真实图片时写成 `REF-<slot>（顺序：<n>）· <项目相对路径>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）`，多张用 `；` 连接，顺序从 1 连续编号（分镜预留的 `PLAN-...` 不能写进图片提示词）。`用途` 从固定十项（`外貌`、`主体`、`造型状态`、`空间布局`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格`）中选填唯一主作用，同一张图只占一个 `REF-...` 图位。
- **语言契约**：正文标题固定为 `### 可复制提示词`，每个非空行以 `>` 开头；说明文字跟随项目语言，可复制提示词正文跟随 `short-drama.json#/format/prompt_language`（没有 `short-drama.json` 时按已有提示词或项目文档语种推断，未指定时可用用户当前语言）。

## 快速开始

```text
用 $short-drama-image-prompts 为 EP001 已确定的人物、地点和道具写可直接复制的图片提示词
```

## 工作流与提示词要求

1. **对齐设定与板式**：对照 `视觉设定.md` 确认本项属于角色设定图、换装/状态图、场景空镜图、道具设定图、分栏对照设定板、视觉定调图还是局部改图（分镜需单出尾帧图时，可将定稿「尾帧提示词」落成独立 `IMG-...` 状态图条目）。
2. **核心特征优先落笔**：按「设定图类型与主体 → 固定核心外观 → 本张造型/视角/状态 → 构图版式与尺寸参照 → 材质色彩与布光 → 背景清场与字迹排除项」组织正文（见 [美术设定图与视觉定调指南](references/sheet-prompt-guide.md)）。单图默认画单一共存状态，同板展示开合或多分区对照须明确声明分栏；多视图并排时按当前提示词语言补充无视图标签/尺寸标注约束。
3. **落实连戏锁与字迹规则**：被 `视觉设定.md` 的 `连戏锁` 点名的 `IMG-...` 条目必须把 `锁定词` 原字带入 `### 可复制提示词`（`IMG-13`）；画面字迹严格对齐设定规则，要求生成可读文字时绝不同时挂全局禁字词（`IMG-07`）。
4. **干净正文与直接改稿**：`### 可复制提示词` 内不夹条目编号、文件路径或流程备注；收到明确的改词或局部改图要求时，先读最新磁盘文件后直接更新对应 `IMG-...`（见 [换装状态图与局部改图指南](references/variants-and-edits.md)）。整集请求一次写完所有指定条目。

## 完成与投产

所有指定条目具备唯一 `IMG-...`、合规 `- 参考：` 与干净可复制的 `### 可复制提示词` 即完成（同轮连带修改分镜时同步更新对应 `- 图片提示词项：`）。完成后可转 `$short-drama` 做局部或整集格式校验；实际出图转 `$short-drama-produce` 预览确认后执行。
