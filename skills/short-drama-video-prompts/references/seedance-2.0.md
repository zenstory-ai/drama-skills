# Seedance 2.0 提示词方言

只在目标档案明确写 `target_video_model: seedance-2.0` 时使用。推荐档案：

```json
{
  "target_video_model": "seedance-2.0",
  "video_prompt_dialect": "seedance-2.0",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 4, "max": 15},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference", "extend"],
  "audio_generation": "same_pass"
}
```

## 正文组织与标记

- 按“主体 + 动作细节 + 场景 + 光色 + 运镜 + 视觉形态 + 约束”写具体可见事实。
- 单镜按动作先后写；多镜容器用 `镜头1：`、`镜头2：`（2.0 响应镜头序号、不响应时间戳，需精确切点时评估逐镜生成或生成后剪辑）。
- **声音与文字标记**：可辨对白写 `{角色用中文说：“逐字台词”}`（全文单一口语语言，专名除外，不加外语暖场）；音效写 `<声音>`，音乐写 `（音乐）`；显式开启字幕才用 `【字幕】`，默认禁字幕写“全程保持无字幕，不生成对白文字叠加”且不出现 `【】`，画内已批准文字逐字说明承载面与位置。

## 站位与视线

- 前后关系按机位写清（机位在哪、谁在前景/后景、谁背对镜头、中间隔着什么，如“机位在桌前，她走进前景、背对镜头停在桌子这一边，桌子在她和他之间”），避免只写“隔着桌子面对面”导致两人出在同侧。
- 简单的画面左右（“男人在画面左侧”“从右侧门口进来”）可直接使用；画外视线对象须明写“在画外、不入画”，防止模型把人补进画面。

## 三种互斥起点与参考续写

首帧（1 张图）、首尾帧（2 张图）与全模态参考（0–9 张图、最多 3 段视频與 3 段音频，音视频每段 2–15 秒且各自合计 ≤15 秒，音频不可单独输入）**同一次生成互斥**：
- “起始帧 + 人物图 + 地点图”统一走全模态参考，正文写明“@图片1 作为首帧”；要求开场/收尾严格锁死某张图时改用首帧或首尾帧模式（由该图自身承载人物与地点）。
- 每次提及素材均重复绑定（`人物 @图片1`、`参考 @视频1 的运镜`、`参考 @音频1 的音色`），序号取当次 job 真实绑定。
- 关键交接道具须挂图（防形制被替换）；超出 9 张上限时的取舍顺序见[目标模型能力档案](target-model-profile.md#参考条件方式)。
- **续写**：接着上一段实际结果生成时写“向后延长 @视频1”，并用 `@图片1` 指向该视频实际尾帧作为新段开场可见状态（不写成普通“参考 @视频1”）；两项真实素材缺一时不宣称连续生成。

## 长度与时长边界

- **正文长度**：官方建议中文 ≤500 字、英文 ≤1000 词（超长正文易把顺带提到的背景元素硬塞进画面或触发硬切）。超 500 字时先删不入画的环境铺陈，保留连续性锁锁面、身份锚点与逐字对白。
- **时长（4–15 秒整数或 `duration: -1`）**：短于 4 秒的动作到位后 hold，长于 15 秒回分镜拆镜；对白/VO/OS 按 [performance-action-timing.md](performance-action-timing.md) 核对发声窗口。固定镜长传已接受正整数；使用 `duration: -1` 自适应时长（仍受 15 秒上限约束）时，返回后须按实际时长复核剪辑与台词完整性。

依据（2026-09-07 核对；三种起点互斥、素材上限与正文长度建议 2026-10-20 核对）：[视频生成 API](https://docs.volcengine.com/docs/82379/1520757)、[Seedance 2.5 指南中的 2.0/2.5 时间控制差异](https://docs.volcengine.com/docs/82379/2607689)。
