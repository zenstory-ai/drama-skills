# Seedance 2.5 提示词写法

在目标模型配置明确指定 `target_video_model: seedance-2.5` 时使用。推荐配置：

```json
{
  "target_video_model": "seedance-2.5",
  "video_prompt_dialect": "seedance-2.5",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 4, "max": 30},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference", "edit", "extend"],
  "audio_generation": "same_pass"
}
```

## 时间戳分段、素材标签与首尾帧

- **时间戳分段**：单镜按因果先后连贯描写；多镜合生或长调度按 `镜头 1 [0:00–0:03]：` 写出互不重叠、首尾紧接的时间区间，末段结束时刻等于总时长（模型实际切点仍有轻微浮动，后期按画面实际切点精剪）。
- **素材标签与取舍**：`@图片N`、`@视频N`、`@音频N` 编号严格对应本镜同类参考项的 `顺序` 数字，正文中（含跨时段再次提及时）每次提及同一角色或道具保持一致标签并标明作用（如 `人物 @图片1`、`参考 @视频1 的表演节奏`），台词引号内不塞入素材标签；超过 9 张参考图上限时按本镜景别与视觉焦点取舍（见 [模型与交付配置](model-and-delivery-profiles.md)）。
- **`first_frame` 锁构图 vs `reference` 参考模式**：要求开场第一帧严丝合缝不跑偏时走 `first_frame`（`first_frame` 与 `last_frame` 各占连续 `@图片N` 编号，不跳号）；普通 `reference` 模式没有专用首帧硬锁位，把开场关键帧并入 `reference` 时将其 `用途` 改标为 `构图`（未由 `主体` / `造型状态` 图覆盖的生效 `LOCK-...` 锁定词按 `CON-07` 保留在正文），写“`@图片1` 是开场画面”仅作强参考而非像素级锁死。
- **多镜合生挂关键帧与局限**：相邻子镜头均备妥首帧实图时，可将各子镜头首帧按序排在 `@图片N` 最前，在 `输入参考图` 中统一将各关键帧改标为 `用途：构图`（单条目最多允许一张 `起始帧`，未由 `主体` / `造型状态` 参考图覆盖的生效 `LOCK-...` 锁定词按 `CON-07` 保留在正文），首行写 `@图片1、@图片2 依次是镜头 1、镜头 2 的画面`，各段写 `镜头 2 [0:03–0:06]：以 @图片2 为画面，……`。注意 `reference` 合生存在开场非像素锁死、切点略微提前、前镜台词尾音易串入下镜、纯反应镜易定格不动四项特性，重头反应镜或硬接缝镜头建议单镜生成。
- **音色参考**：挂载 `- 参考音频：` 时按音频 `顺序` 写“音色参考 `@音频1`”；模型会按本镜台词重新发声演绎而非原封不动照搬干音波形，出片后逐镜回听核对。

## `任务类型` 与视频编辑 / 续写

提示词写法须与接口参数 `omni_reference_task_type` 一致（不一致会被接口拦截）。《视频提示词.md》参考槽位仅登记图片与角色音色参考；依赖参考视频（`@视频1`）的 `edit` / `extend` 走外部平台手动提交（`relay_external`）。目标模型为 `seedance-2.5` 时，可在 `MOTION-...` 的 `生成方式` 下一行注明 `- 任务类型：reference | edit | extend | auto` 供人工与外部提交核对（`auto` 由服务端按输入自动判别，非 2.5 模型不写；交 `short-drama-produce` 投产时在任务参数 `parameters` 中显式传入 `omni_reference_task_type`）：

- `reference`：参考传入的图片与音色音频生成新镜头，点明各素材控制项。
- `edit`（外部手动提交 `relay_external`）：指定 `@视频1` 写清“保留 A、B，只把 C 改成……”（接口传 `ratio: adaptive`、`duration: -1`，成片时长跟随原片；改长台词前先核对原片留白够不够）。
- `extend`（外部手动提交 `relay_external`）：仅在创作者明确需要顺着上一段真实成片往后延长时使用，写明“在 `@视频1` 的基础上向后续写 N 秒”（接口传 `ratio: adaptive`，可搭配截取的真实尾帧 `@图片1` 稳住接缝）。若需在既有片段**前面**补拍起手戏，不可用 `extend`，改走首尾帧模式——同时将补拍起手画面绑为 `起始帧`、原片第 0 帧绑为 `结束帧`（挂载 `结束帧` 时必须同时挂载 `起始帧`，不得只绑 `结束帧`）。

## 动作句式、声音标记与屏幕文字

- **动作句式与反应镜弧线（`craft_default`）**：单句尽量短促利落，直给核心动作指令，少堆叠修饰长句；拍摄近景反应镜时保留连贯的「触发 → 停顿消化 → 神情与肢体递进 → 落定」完整弧线，不必刻意压缩成短秒硬定格。

- **声音标记**：现场对白写进声音时间线的 `{角色用中文说：“逐字台词”}`（单镜只写一次台词全文，动作段只写口型同步）；音效写 `<声音>`，音乐写 `（音乐）`；存在开头杂音风险时可按需补一句“对白直接从指定首字开始，无额外杂音或重复念词”。
- **字幕与手机弹窗防悬空**：需显示画面外花字才用 `【字幕】`，有乱码风险时按需注明无字幕叠加且不写 `【】`。2.5 拍手机来电或通知时易画成半空悬浮气泡框，提示词需写明“通知仅在手机屏幕表面亮起，半空不出现悬浮弹窗”，关键数字留给后期叠字。
- **支持时长**：支持 **4–30 秒整数**或 `duration: -1` 自适应；含对白时按 [台词时长估算](performance-action-timing.md#台词时长估算) 核算（`extend` 只算新增段），接口返回 `duration` 为向下取整近似值，验收以工具实测时长与句尾听感为准。
