# Agent Note: 模型行为实测记录入库

Status: implemented

## Problem

技能正文里有一批来自真实生成的数字：H3 自然语速约 4.1 字/秒、写空配乐 14 次全干净、起始帧三条路径 9/9、多镜切点 ±0.4 秒。读者需要知道每个数字是在什么模型、什么样本量、什么执行路径下测出来的，否则会把一次探针当成能力保证。同一轮实跑还会产出原始媒体、供应商响应和完整项目，这些体积大、带私有路径，不能进公共树。

## Decision

`evaluations/model-behavior-probes.md` 是仓库内唯一的模型行为观察摘要，随版本库一起提交。每次探针在表里追加一行，固定三列：观察、样本与结果、可用于什么判断；文首写明日期范围、调用路径与测量方法，并声明它不是可重放回归夹具、不构成能力或成功率保证。CHANGELOG 与技能正文里的实测数字 must 链接到这份摘要；结论被后续实验推翻时改这张表，不另开文件。

原始媒体、运行状态、供应商响应与完整实跑项目 never 入库：放在仓库外，或被忽略的 `evaluations/local-runs/` 与 `evaluations/让你管账号/reference-run-0.6.6/`；渲染中间产物由 `.gitignore` 排除。技能正文里的 illustration never 引用某一次实跑项目的原文，只用自足的中性例子；`examples/creator-first` 是被套件到处引用的共享样例，不受这条约束。

来源：edc62de (#109)、ec66337 (#110)、c88ae34 (#113)、a225b1d (#114)、dc9b0fa (#142)、86c2aa1 (#169)

## Alternatives considered

- **实测记录移出版本库、只在本地保留（#113 的做法）** — 最强理由：避免把某一轮实跑的具体数字和项目痕迹固化进公共仓库，也不必维护一个会过期的表。被否：`evaluations/` 早已是仓库的一部分；技能正文引用的数字失去仓库内出处，读者无法核对适用边界；CHANGELOG 的链接只能改成「维护者本地保留」的说明。该提交当天被 #114 revert，之后每一轮探针（#147–#156、#169）都继续往这张表追加。
- **把实跑的完整产物作为夹具入库** — 最强理由：可重放。被否：探针的原始媒体与供应商响应既大又含私有路径；`evaluations/README.md` 已把新的实跑产物明确放在仓库外，只有去标识摘要留在库内。

## Consequences

- **收益**：每条实测断言有出处和边界，纠错有落点——#110 把 #109「不会截断」的结论改成三段容量，改的就是这张表。
- **代价与已知上限**：摘要与技能正文两处要同步；表是探索性观察（多数每臂 3 次、单一路径），把它当成回归门禁或供应商能力承诺都会重犯。表变长后仍要一行一观察；要按项目归档就开新的评估目录，不改这张表的形状。
