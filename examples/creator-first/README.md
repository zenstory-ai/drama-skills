# 完整单集创作示例（《让你管账号》EP001）

《让你管账号》EP001 展示一集在默认工作流下产出的全部五份创作文档：纯 Markdown 交付，不夹带创作阶段的 JSON/JSONL、索引、指纹、质检表、审核表或内部中间文件。
本例采用中文创作说明、英文可复制生成提示词；其他项目按各自选定的提示词语言编写。

- [`剧本.md`](EP001/剧本.md)
- [`视觉设定.md`](EP001/视觉设定.md)
- [`分镜.md`](EP001/分镜.md)
- [`图片提示词.md`](EP001/图片提示词.md)
- [`视频提示词.md`](EP001/视频提示词.md)

本集基于同一故事背景重新编写，时代设在当下，按快节奏漫剧排布：22 镜、约 62 秒，平均镜长约 2.8 秒，`[VO]` 约占台词字数两成。
第一帧就给足压迫感：视频会议里其他军团哄笑、上级点名压下下周评比的死限，周薄森把这摊空白交下来，江晨在第 31 秒立下“下周榜首”的军令状；
外部压力和人物短板都来自原故事设定，不硬塞有名有姓的配角。集尾卡在倒计时跳秒、笑容僵住的那一拍；系统面板留在后期叠加。
本例未绑定特定视频模型，镜长按叙事节奏定；切换到有最短时长限制的模型时，按模型官方支持的最短时长合并或调整短镜。

本目录展示实际成稿样貌，具体格式要求见各阶段技能说明与五份创作文档规范。
