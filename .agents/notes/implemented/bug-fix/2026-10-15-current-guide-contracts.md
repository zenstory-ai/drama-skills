# Agent Note: 当前指南与创作台、五文档和参考输入契约对齐

Status: implemented

## Problem

产品技能已退役旧创作模板，但摘录示例 README 仍让读者发布 `screenplay.md` 与索引，未说明它只是历史回归材料。跨镜指南把提示词条目、挂图计划和真实图片混称为状态，容易让人把 `IMG` 当成已经或尚未出图的证明，或忽略 `PLAN` 可交付提示词但不可提交内置生产的范围。

DESIGN 仍要求早期单页、无视图切换和石墨/琥珀视觉，与已落地的分阶段视图、原文编辑和现有深浅主题 token 不符。源码发布说明还带有首次接线时“不创建 release”的阶段旁白。

## Decision

对限定的根、docs、评测说明、示例 README 和维护者参考共 26 份文档逐份完成五步复核，修改其中 11 份。按已接受的[创作台分视图决定](../feature/2026-09-27-dashboard-v2-stage-views.md)、[旧创作模板退役决定](../simplification/2026-10-15-retire-legacy-authoring-templates.md)及当前 `creator-documents.md` 对齐说明，不改变运行时代码、评测门槛或生产确认规则。

DESIGN 描述现有阶段视图、原文编辑、主题 token 和源码归属；三个普通设计示意围栏仅修正当前视图以及默认的输入、交付目录。指南分清 `IMG` 条目、`PLAN` 外部挂图和 `REF` 本地图片，保留连续性锁，说明图像与视频仍须生成后验收。示例 README 将历史夹具与当前五文档入口分开。发布评估说明区分旧结构化回归和按当前契约实跑，不把某台机器是否有生成后端写成固定能力边界。

真实运行、badcase、配对、模型观察表、所有引文与其他 46 个代码围栏保持原文；生成提示词、盲评提示词、量表和维护者六份文档逐字保留。产品技能、双语产品 README、历史笔记、版本、案例与项目内容均未改。

## Alternatives considered

- 只调整语言：差异更小，但读者仍会按旧入口生成退役文件，维护者也会按 DESIGN 恢复已被取代的界面限制，因此同时修正有明确源码和决定依据的事实。
- 删除历史示例及其说明：入口最少，但回归测试仍使用这些输入，且用户要求冻结真实样本；保留样本，把 README 的用途与当前入口说明准确。

## Consequences

当前指南与实际工具行为一致，历史材料不再充当创作操作指令。文档精修不证明媒体质量、外部服务状态或评测通过；本轮不发版、不执行生产或付费评测。
