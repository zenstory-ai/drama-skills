# Agent Note: 英文台词按词估时，非中文台词从场景直接写

Status: implemented

## Problem

`duration_estimate.py` 把台词的每个可发声字符当一个计时单位，再除以项目声明的每秒字数。英文等以空格分词的语言里，每个字母都被当成一个「字」：一句 4 个词、约 20 个字母的英文台词按中文语速算出的秒数约是实际的 3 倍，写作阶段会据此删戏或误判集长。项目也没有地方声明每秒词数；`project_tool.py status` 和 `set-authority` 只认每秒字数，英文项目只能编一个字速。

写作技能也没有说英文台词怎么写。把中文剧本逐句译成英文，会保留中文的信息顺序和称呼密度（几乎每句叫一次「陈总」「林小姐」、客套话照搬），英文观众听来像字幕腔，时长也更长。

此前的 [时长约束提前暴露](2026-10-20-timing-chain-constraints-surface-early.md) 引入了去标点的 `voiced_characters`，本篇沿用它的口径，只把以空格分词的文字改按词计。

## Decision

- `duration_estimate.py` 的发声计数拆成两个单位：拉丁、西里尔、希腊字母组成的词（词内数字、撇号、连字符算在词里）计入 `voiced_words`；其余可发声字符仍逐字计入 `voiced_characters`。混排的一句各按各的单位计（`OK，走吧` 是 1 词 2 字）。纯数字串跟随所在的句子：整句只有词时算 1 个词，句里有汉字时仍逐位计数，所以不含拉丁字母的台词计数与此前完全相同。
- `format.pacing` 新增可选的 `spoken_words_per_second`。字速与词速至少声明一个，加上每段动作秒数，估算即可用；秒数按各自的单位与速率相加。有某个单位的台词而项目没声明这个单位的速率时，这部分不借用另一个速率，而是列在 `untimed_speech` 里，秒数不含它。
- `short-drama` 的 `project_tool.py`：`status` 的 `profile_notes` 把字速或词速任一可用都算作有语速；`set-authority /format/pacing` 允许另一种语速保持模板里的 `null`，前提是已经有一种语速为正数，其余速率仍须为正数。
- 起点值写在 develop 的 `episode-design.md`，按 `craft_default` 给出：约 3 词/秒。依据是 Yuan、Liberman、Cieri（Interspeech 2006）对电话对话语料用相同口径量得英语约 193 词/分、汉语约 228 字/分，一个英文词约占一个汉字 1.2 倍的时长；表演台词停顿多于电话闲聊，所以略往下取。套件内没有英文的模型实测，这个数只是待创作者接受、试跑后校准的起点，不是门槛，代码里也没有默认值。
- 写作技能 `dialogue-craft.md` 新增 §6.3「非中文台词：从场景直接写，不逐句翻译」（`craft_default`），从 `SKILL.md` 按需知识链接。
- 收录 §6.3 前跑了一次基线对照：同一段合成的中文场景（6 句台词），一个新开的 agent 只读现有写作技能改成英文，另一个新开的 agent 另外读了这一节，再由一个盲评 agent 比较北美观众听来是否自然、计时是否现实、节拍是否完整。带这一节的版本胜出（中高置信）：67 词对 77 词，去掉了照搬的称谓和客套，节拍不缺；基线版在两处措辞上更贴原文。样本只有一段场景、一位评审。

## Alternatives considered

- **英文也按字母计，让项目把字速调低到适配英文**：不改代码。未采用：同一项目里中英混排时一个字速无法同时适配两种单位，而且「每秒字母数」不是任何人能凭经验给出的数。
- **按音节计**：音节和时长的相关性比词更强。未采用：英文音节需要词典或启发式切分，脚本只做确定性计数；词数是创作者和配音都能直接核对的单位。
- **没声明词速时借用字速乘一个换算系数**：英文项目开箱就有秒数。未采用：等于给语速设隐藏默认值，与 [时长约束提前暴露](2026-10-20-timing-chain-constraints-surface-early.md) 不设默认语速的决定相反；改为把没计时的部分列出来。
- **把逐句翻译的写法写成审查规则**：可以在审查里拦住字幕腔。未采用：是否直译是创作者的风格选择，只作为 `craft_default`，创作者要求直译时照做。

## Consequences

- **收益**：英文与中英混排台词的估时不再成倍偏长；英文项目可以只声明词速；漏声明的单位在输出里看得见。写英文台词时有一条从场景写起的做法，基线对照里它让台词更短、更像母语。
- **代价**：词的边界只按字母与少数连接符判断，数字串、缩写、`3-2-1` 这类读法仍要写作者另估；画面文字仍按字符计读字时间；约 3 词/秒没有模型实测支撑，需要项目自己校准；§6.3 的证据只有一次单样本对照。
