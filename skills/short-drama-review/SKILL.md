# 短剧审查

优先由未参与本轮执笔的独立审稿人执行；执笔人自检时如实标明自检。本技能只负责指出问题、说明影响、明确改稿标准并退回对应负责技能，不直接修改受审原稿，不调用生成接口。

## 快速开始

直接读取用户指定的稿件或看片反馈。需要保存审查文档时，单集联审写入 `审查/EP001-审查.md`，专项审查写入 `审查/<主题>-审查.md`；只需口头反馈时直接在对话中回复。每条问题单标题必须严格采用 `## <Blocker|Major|Minor|Note> · REV-<编号> · <标题>` 格式（如 `REV-001` 或 `REV-EP001-001`，编号至少三位数字以避免与阶段规则号混淆），并在标题下逐行写出 `- 位置：`、`- 证据：`、`- 影响：`、`- 修改要求：`、`- 规则：`，以便创作台审查卡片完整解析每条问题；出处仅引用文件名、标题编号、行号或简短原文摘录，不建隐藏 JSON、哈希值或状态副表：

```markdown
# EP001 审查

- 范围：剧本、分镜、视频提示词
- 结论：REVISE
- 复核方式：<独立审稿 或 自检（二选一填写，勿并列保留）>

## Blocker · REV-001 · 分镜漏拍剧本中的画面文字
- 位置：剧本.md / EP001-SC002；分镜.md / SHOT-EP001-004
- 证据：……
- 影响：……
- 修改要求：交 $short-drama-storyboard 补上准确的画面文字内容与景别停顿条件，保持本镜原有的人物站位与情绪反应不变。
- 规则：SHT-02 · reviewed_invariant
```

## 工作流

1. **划定受审范围，先查基础格式与连戏（`REV-01`）**：确认本次受审文档、章节或镜头范围及创作者已拍板的创作要求。先核清标题编号重漏、链接与条目引用悬空、分段与合生分组时长加总、剧本全要素落镜、跨镜连戏状态，以及是否混入私有凭据或本机绝对路径；缺某份前置材料时只跳过依赖它的判断，其余照常审。
2. **顺链条对账并凭实据开单（`REV-02`、`REV-03`）**：按 `剧本事实 → 视觉设定 → 分镜起止状态 → 首尾帧提示词 → 视频动态 → 下一镜接戏 → 《剪辑单.md》与整集成片切点接缝` 核查上下游是否走样（指认篡改或漏拍须成对列出上下游原文）。每条问题单写清位置、实据、实际影响、局部修法与不得误伤的保留内容、负责技能及严重程度，不空扣“有 AI 味”“不够电影感”帽子。
3. **局部补丁与亮点保护（`REV-14`）**：返修意见只针对病灶开最小局部补丁，不借局部毛病要求整集推倒重写。对比新旧稿时若发现润色压稿误删了抓人钩子、高潮金句或精妙包袱，单列 `## 被删的强钩子` 记下原位置与原句供执笔人取舍；复审时只核验返修点是否修通及保留内容是否完好，不翻已放行段落旧账。
4. **定级与结论分派**：
   - **规则等级与严重程度上限**：`structural_invariant` 与 `reviewed_invariant` 违背时按对应不变量规则编号视影响定为 `blocker` 或 `major`；包括 `REV-05 · craft_default` 与 `REV-15 · craft_default` 在内的所有 `craft_default` 偏离仅可记为 `minor` 或 `note`，**绝不升格为 `major`，也绝不单凭 `craft_default` 触发 `REVISE`**（唯有台词/正文或生成成片实质违背已立住的人物硬事实、剧情因果链或上下游不变量规则时，才归入对应的 `structural_invariant` / `reviewed_invariant` 编号定为 `major` 或 `blocker`）；`taste_option` 一律仅记作 `note`（`REV-06 · taste_option`）。
   - **严重程度四档**：`blocker`（阻断交付的不变量结构错误、核心事实穿帮、泄密违规或不可挽回的成片缺漏）、`major`（违背 `structural_invariant` 或 `reviewed_invariant`、伤及剧情因果理解、跨镜连戏或成片主体与台词完整度的中度硬伤）、`minor`（`craft_default` 范围内的套路重复改进建议、局部瑕疵提醒或裁切/后期可修项）、`note`（审美与风格参考建议及保留沿用备忘，`REV-06 · taste_option`）。
   - **审查结论判定**：书面审查文档 `- 结论：` 填写 `APPROVE`（无 `blocker`，且无未经创作者明确豁免的 `major`）、`APPROVE_WITH_NOTES`（无 `blocker` 且无未获豁免的 `major`，附 `minor` / `note` 建议或创作者已明确豁免的 `major` 留底）、`PROVISIONAL`（无 `blocker`，仅剩不影响核心主线推进且已写明下阶段修正方案的局部问题、待创作者看片拍板的边界项，或尚有关键材料/成片片段未查看到——未看过的音画素材如实标为未知，不凭文件名或后台状态猜测画质口型）、`REVISE`（存在 `blocker`，或存在尚未获创作者豁免的 `major` 硬伤需返工）；生成媒体看片四档判定（`PASS` / `PROVISIONAL` / `REVISE` / `REJECT`）见 [成片看片与返工分流指南](references/generated-media.md)。
   - 按负责技能归拢返修项交创作者拍板；下游返修与复审在用户明确指示时启动。
