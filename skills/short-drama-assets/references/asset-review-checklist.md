# 资产拆解审查清单

## 下游引用核对（`AST-05`）

资产设定完成前，每个已存在的下游引用都要指向明确的身份条目，且变体必须在引用的剧情范围内有效。
未解决的出现项继续保持未决；不得为了让提示词或分镜继续工作，猜一个看似合理的 ID。

按“结构核对 → 语义判断 → 创作者接受”顺序检查。资产负责人根据问题记录修订；修订本身
不构成审查结论。需要质量结论时另起审查动作，所有者自检须如实标注。

## A. 机械检查（`structural_invariant`）

- [ ] 每个结果都指向可见场景 ID，并能从当前 `剧本.md` 找到依据。
- [ ] 新变体写清基底、变化、原因、生效位置与结束位置；没有明确终点时标为持续。
- [ ] 可见标题和 ID 无重复；下游引用指向 `视觉设定.md` 的人物/造型、地点/视图或道具/状态，并注明当前有效版本。
- [ ] 未决项没有伪造成已确认身份，不能流入图片提示词或分镜。
- [ ] 每条变化有前态、后态、原因/来源、生效范围和受影响的可见 ID。
- [ ] 相连的结束/进入状态一致，或有负责人明确提出的修订。
- [ ] 可读文字政策完整；`exact_readable` 不与 `no_readable_text` 冲突。

核对结构时只判断来源、引用、范围和显式声明是否齐全或相互矛盾；引用背后的身份判断与变化因果见语义审查。
发现问题时写明具体文件、标题或 ID、负责技能和修复方向，不回显整段创作文本。

## B. 语义审查（`reviewed_invariant`）

逐条引用 `剧本.md` 与 `视觉设定.md` 的证据回答：

- [ ] 每个制作相关的剧本段都有资产处理结果，或明确说明本段没有资产变化。
- [ ] 来源位置、剧本明示事实、资产判断与连续性变化各自清楚。
- [ ] 每个出现项的复用、新变体、新身份或未决判断有足够证据。
- [ ] 含混代词、匿名人、同款多件物没有被猜成某个已有 ID。
- [ ] 人物身份锚点与服装、伤势、湿污、姿势等临时状态分离。
- [ ] 地点地理/固定锚点没有因角度、时段、天气、灯光被复制成新地点。
- [ ] 道具形制/功能身份没有因所有者、开合、破损、内容或文字状态被复制。
- [ ] 每个新资产都有不能复用的持久证据；每个变体说明基础身份中什么保持不变。
- [ ] 提取没有凭空补脸、品牌、门窗、内容物、伤势、灯光或可读文字。
- [ ] 时代不与原著事实矛盾；旧、老式、复古一类词有原著依据或创作者选择（`AST-14`）。
- [ ] 转手、伤势、换装、停电、天气/光态和知识变化都有足以支持的剧情原因。
- [ ] 出现方式与制作处理相符：提及不被误当出镜，关键操作物不被降成普通布景。

每条审查问题须包含文件与标题或 ID、证据、影响、所需修订、负责技能、严重程度和状态；不能只说
“资产不够细”或“看起来 AI”。

## C. Craft 默认（可覆盖，不单独阻断）

- [ ] 身份未变时优先复用或 variant，没有追求“一场一资产”。
- [ ] 瞬时姿势、摄影机与构图留给分镜，没有为每个瞬间新建造型、视图或状态版本。
- [ ] 视觉设定只保留识别、复用、提示词、镜头和连续性所需事实。
- [ ] Location 先有地理/入口/固定锚点，再有氛围；Prop 有尺度/形制/材料/功能；
  Character 有可观察的区分锚点。
- [ ] 项目视觉方向写了时代锚点，地点、造型、道具条目写出时代形制（`AST-15`）。
- [ ] 结束状态简洁，足以让下一场/集直接承接。

创作者可因制作需要覆盖默认做法，例如逐件审批背景陈设；在视觉设定中记录选择与原因。

## D. Taste 选项（只确认选择）

- [ ] 群演按 group 还是个体管理已选择。
- [ ] 同建筑空间拆分颗粒度能支持当前制作。
- [ ] 蒙太奇/梦境/主观断裂已声明边界。
- [ ] 临时可见状态用 delta 还是升为 variant 符合本项目复用策略。

不得仅因 reviewer 偏好另一个选项而判失败。

## E. 创作者确认

给创作者看的摘要必须列出：

1. 复用项及匹配证据；
2. 新 variant 及 base/difference/cause/validity；
3. 新 asset 及持久区分证据；
4. unresolved 的原文证据、候选和不同选择的下游影响；
5. continuity deltas 与跨集 outgoing；
6. 确认后需要同步更新的下游文件。

把创作者确认的结果直接写进 `视觉设定.md`，未确认选择保留为“未决”并说明影响。创作者确认不等于
结构检查通过、审查通过或可以投产；这些动作各自独立发生。

## 当前范围完成判据

本次范围内结构核对完成，每个出现项已有处理结果或真实未决，已确认的视觉事实与连续性可交接，
即完成当前资产整理。需要创作者选择的新增、复用、变体或变化保留为未决；依赖这些未决项的
图片提示词或分镜暂不继续。审查与交付各自独立，不自动成为这两个并列分支的前置步骤。
