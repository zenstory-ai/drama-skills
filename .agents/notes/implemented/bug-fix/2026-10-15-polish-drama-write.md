# Agent Note: 写作参考与现行阶段契约保持一致

Status: implemented

## Problem

五步精修发现写作参考中的几处表述与现有契约不一致：场景修订和完成检查把冲突场景的议程、反对与转向套到了所有场景；VO 占比被写成可发声字数，但 `duration_estimate.py` 实际去掉空白与括注、保留标点；短闪回和巧合建议夹带了通用数量限制。制作格式资料还保留了无法从公共资料核验的来稿频率。

现行边界已见 [规则四级分级](../architecture/2026-07-16-rule-tiers-and-script-boundary.md)、[项目节奏档案](../architecture/2026-09-26-payoff-first-adaptation-and-rhythm-profile.md) 与 `SCR-01`：数量不作为套件级质量门槛，非冲突场景按必要变化判断，脚本计数与实际语速换算分别说明。

## Decision

参考资料对齐上述现行边界：冲突专项检查写明启用条件；VO 占比按脚本口径说明；数量建议改成对应的戏剧职责；格式兼容清单保留写法和识别方法，移除无从核验的频率。可替代实现的合成示例明确指控者知情与公众、观众知情的区别，不能凭一次反应视为所有人已知姓名；格式反模式保留“他笑得合不拢嘴”原例并纠正其可表演性判断。现有范例、反例、代码块、稳定 ID、四级分级与审查修订边界保留；脚本、数据格式和外部生产确认流程不变。

写作默认提示、模板路径和上下文契约的事实同步记入 [五份创作者文档](../architecture/2026-08-22-creator-first-five-documents.md)。

## Alternatives considered

- **只润色句子，保留冲突表述**：改动小，既有文档差异也最少。未采用：agent 仍会因读取不同参考而得到不同检查范围，VO 比例也仍有两个口径。
- **删除整段手艺或旧格式兼容资料**：可以一次去掉冗余与来源疑点。未采用：场景、对白和旧稿识别方法仍有用，只需修正条件与事实，不应连同技法一起删除。

## Consequences

- **收益**：参考资料与现行规则、脚本事实一致，避免把创作建议误当通用数量门槛。
- **代价**：创作质量仍需结合本集意图判断；本次不以语言精修代替内容实跑或供应商能力评估。
- **验证**：写作技能 14 项 self-test 与安装/套件结构 21 项测试通过；12 份范围内文档的 26 个 fenced code blocks 与基线逐字一致，`SCR-01` 至 `SCR-22` 的 ID 与分级不变。

独立 review 补齐索引重跑的成对参数：改稿前保留旧剧本快照，复用索引时同时传 `--previous-index` 与 `--previous-source`；无快照则明确重编号。临时剧本初建及带成对参数的重跑均通过。

旧模板保留、旧根迁移与锁定旧版的部分由后续[退役旧创作模板决定](../simplification/2026-10-15-retire-legacy-authoring-templates.md)取代；本文其余精修与真值修复结论继续适用。
