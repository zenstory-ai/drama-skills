# 测量与观看

## 抽样

按本轮问题取样（多部对比时保持抽样规则一致，相邻集必须成对抽取以观察集间承接）：

- **开头全拿**（建议第 1–12 集）：覆盖首集结构、前几集加长与付费点前节奏；
- **中段隔段抽**（如每 20 集取一对相邻集）：观察是否定长、节奏是否变化；
- **结尾 2–3 集**：观察收尾做法。

若对标中含同一故事的不同制作版本（换名、换画风或重拍），归为同一个故事；报告同时写明「几部、几个故事」，机制候选按故事数统计。

## 转写从哪里来

脚本不做语音识别，按优先级使用：

1. 平台或创作者提供的字幕文件（SRT、WebVTT）；
2. 本机语音识别工具导出的带时间分段（JSON 每段含 `start`、`end`、`text`）；
3. 均无时只测画面，有声占比、语速、首句时刻留空不估（需从烧录字幕还原台词时见 [整集与多集还原](reconstruct.md)）。

## 运行测量

按 `SKILL.md`「测量与拆解流程」运行 `breakdown_tool.py` 的 `measure`、`transcript`、`profile` 与 `plan` 子命令：

- `measure`：每集输出 `*.measure.json` 及代表帧拼图（每镜取中点一帧，按镜头顺序一格一镜排列；集数多时可加 `--no-sheet`，仅对细看集出拼图）。测量结果统一写进 `输入/对标/<REF-ID>/measure`。
- `profile`：按文件名集号（识别 `E001`、`EP01`、`第1集`）排序并配对相邻集，将开头几集（`--opening`，默认 3）与后续集分开统计，同时报告后续集是否近似定长、相邻集开头重放上一集结尾的次数。
- `plan`：读取本项目 `剧集/<EP>/分镜.md` 的镜头时长与 `剧本.md` 的台词，输出同结构的 `*.measure.json` 至 `项目开发/对标拆解/plan/`。声明了 `format.pacing` 时按语速和动作秒数排时间线估算有声占比、首句与末句留白（台词超分镜总长时报错不估；仅出场一次且无表演注的长名说话人需用 `--speaker` 指定）。

拿到拼图与带时间转写后，每部至少细看第 1 集与中段一集，按 [拆解维度](breakdown-dimensions.md) 逐项记录。

## 数字的盲区

| 数字 | 盲区 | 补齐方式 |
|---|---|---|
| 转写时间 | 识别模型偶将配乐或静默识别为超出片长的长段文字 | `transcript` 挂接会提示，`profile` 只计片长以内部分；抽查原片 |
| 切点与镜长 | 帧差阈值漏掉慢溶，或将闪白、甩镜、粒子特效误判为切点 | 动作/特效集看拼图核对；必要时调 `--scene-threshold` 重测并注明阈值 |
| 有声占比、语速 | 转写不区分对白、旁白与系统音，或混入配乐歌词 | 读转写时标出旁白与系统音，单独计算 VO 份额 |
| 首句时刻 | 纯音效或纯画面开场钩子会使首句偏晚；`plan` 按剧本顺序排，分镜将 VO 压在开场画面上时计划值偏晚 | 看第一帧拼图记录第一拍；有分镜时以首句所在镜起点为准并注明口径 |
| 末句后时长 | 末句后可能是画面反转，也可能只是片尾 | 看最后一帧拼图确认 |
| 重放上一集结尾 | 脚本只比对文字，纯画面重放或换词复述测不出 | 抽 2–3 对相邻集看拼图确认 |
| 近景占比 | 脚本不区分景别 | 看拼图人工统计，无法确认的记为未知 |
