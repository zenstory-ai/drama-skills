# Agent Note: 出片实测沉淀：空间、音色与切点

Status: implemented

## Problem

[对标拆解的私有还原层](2026-11-04-breakdown-private-reconstruction.md) 落地后，拿一集 45 秒、13 镜的还原去出片
（关键帧 → H3 首帧图生视频 → 剪辑），前后改了 6 版。看片人反复指出三类问题，各技能文档都没有可照做的写法：

- **空间**：柜台时而贴瓷砖墙、时而贴落地窗，冷柜和窗来回换位置，凭空多出第二台设备；人离柜台忽远忽近。
  原因是从来没有一个“真”房间：各机位的地点图各自生成，每张关键帧又按“地点图 + 文字”重画一遍；用上一镜关键帧
  当参考带不过去距离；局部编辑换背景又重画一次；站位只写在哪一侧，没写多远；还照搬了原片本身不成立的空间。
- **声音**：另配合成配音只能整句对齐口型；改用 H3 自带的声音后口型同步，但每条重新挑声音，同一个人跨镜换嗓子。
  当时用的执行渠道收不了参考音频。
- **切点**：台词说完 0.3 秒就切到景别、站位都变了的下一镜，看片人觉得硬；想在转身动作上剪，H3 的转身方向又和下一镜相反。

## Decision

知识写进各自负责的技能，跨技能只按技能名路由，都是 `craft_default`，不新增规则编号，实测数字只当一次实测的起点：

- `short-drama-image-prompts` 的 `location-plate.md`「多个 View 从一张全视图派生」：先出全视图母版，各 View 以母版为参考
  派生，View 尽量少（一场戏通常只要正反两个观察方向，都在同一工作侧），逐张和母版核对，纯镜像且无可读文字的才翻转使用；失败征兆补一条。
- `short-drama-storyboard`：`blocking-playbooks.md` 在 SHT-30 下补“人和锚点的远近写成身体距离、不走位的人锁在锚点同一侧、
  离场朝门出画”，在「观察视角与边界」补“绑定前先看地点图前景”；`keyframe-craft.md` 补“关键帧图的空间只从一张地点图来”。
- `short-drama-video-prompts` 的 `minimax-h3.md`：首帧模式转身方向不听提示词（6/6、3/3 转反）；开口实际晚 1.3–2.4 秒；
  单喊两字人名发音不稳；`<d>` 外音色描述锁不住跨镜同一声音，收不了参考音频时交剪辑后期统一。
- `short-drama-edit`：`cut-craft.md` 补句后反应在大变化切点放长、起始帧镜头从第 0 帧起用且不整段提速、方向相反时在动作前切、
  只露眉眼的镜头可句中切；`sound-and-subtitles.md` 新增「同一个人跨镜换了声音」（人声分离 → 零样本变声 → 回混，
  用说话人相似度和逐字转写核对），并补各段对白电平先拉近再铺环境底。
- `short-drama-review` 的 `generated-media.md`：按镜序拼首尾帧查空间连续。
- `short-drama-breakdown` 的 `reconstruct.md`：消音词换可播词；新增「拿还原去出片」：不照搬原片不成立的空间与站位、
  验收对节拍不对秒数、用能听音轨的模型审片时一并给分镜。

## Alternatives considered

- **做一个三维灰盒房间，按机位渲染后当关键帧的构图参考。** 最强的理由是几何严格一致，反打不会错。没采用：
  全视图母版加正反两张地点图已经让同一方向的镜头对得上，灰盒要多一套建模和渲染工具链；看片人也明确倾向更轻的做法。
- **让模型直接从全视图派生每个机位。** 最省事。实测 4 个方向全有空间错误，所以改成只派生正反两个方向、逐张核对。
- **另配合成配音再对齐口型。** 能保证每个角色同一个声音。实测只能整句对齐，看片人觉得比自带声音更差，改为保留自带声音后期变声。
- **在 H3 里绑定参考音频。** 官方方言支持，跨镜音色最直接。当时的执行渠道收不了参考音频，渠道状态会变，不写死；
  文档写“能绑就先绑，收不了时后期统一”。
- **在转身动作上剪（动接动）。** 衔接最顺。H3 转身方向不听提示词，9 条候选都转反，强接会让人当场调头，改为在动作前切。
- **把渠道报错、远程机器跑重活、具体开源工具名写进文档。** 前两者是这次环境的临时状态，后者在仓库没有点名先例，都用通用说法。

## Consequences

- 收益：同一侧机位的空间对得上；同一角色跨镜音色相似度从 0.19–0.59 提到 0.75–0.87，口型不变；切点更顺；
  还原出片不再照搬原片的不合理处。
- 代价：多一张全视图和逐张核对的工夫，首轮关键帧仍有约三分之一要重出；后期变声要在外部另做人声分离、变声和回混，
  实测 CPU 上每段约两分钟，几段并行时会占满整台机器；成片比原片长（这一集长约 13 秒）。
- 证据只有一集 13 镜、一个执行渠道；方向不听、开口晚等数字换模型版本后要重测。变声后的音质与情绪仍要人耳确认。
