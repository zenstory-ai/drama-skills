# Wan 3.0 提示词方言

只在目标档案明确写 `target_video_model: wan-3.0` 时使用。推荐档案：

```json
{
  "target_video_model": "wan-3.0",
  "video_prompt_dialect": "wan-3.0",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 2, "max": 30},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference"],
  "audio_generation": "same_pass"
}
```

Wan 3.0 用中文自然指令，素材标记为 `图1`、`视频1`、`音频1`，不套用 Seedance 的 `@图片N`、`{…}` 或 `<声音>`。

## 模式、编号与时长

| 本镜绑定的参考图 | Wan 3.0 模式 | 正文指代 |
|---|---|---|
| 无图（创作者已明确选择文生视频） | 文生 | 写清静态视觉锚点，不含素材标记 |
| 仅 1 张 `用途：起始帧` | 首帧 | 从输入帧可见姿态写起，不另起标记 |
| 1 张 `用途：起始帧` + 1 张 `用途：结束帧` | 首尾帧 | 终点只呈现分镜已接受终点 |
| 其他任何组合 | 参考 | 用 `图N` 逐张点名职责 |

- **互斥与编号**：首/尾帧与 `reference_image`/`reference_video`/`reference_audio` 互斥，「起始帧 + 角色图 + 场景图」或连续段「上一段实际视频 + 实际尾帧」统一走参考模式（起始帧或实际尾帧标为 `图1 是本镜开场画面`，实际视频标为 `视频1`）。无起始帧时须写明具体取景边界（见[目标模型能力档案](target-model-profile.md#参考条件方式)）。
- **素材与时长上限**：`图N`、`视频N`、`音频N` 各自按同类素材 `顺序` 从 1 编号；单次最多 10 张参考图、5 段视频、5 段音频（音视频每段 1–15 秒且各自合计 ≤15 秒），首/尾帧各 1 张，正文 ≤20000 字符。`duration` 为 2–30 整数秒（带视频输入时输入加输出 ≤30 秒；`-1` 为智能时长，固定镜长显式传已接受秒数），分辨率 1080P/720P/480P。

## 多镜时间段

- 按 `(0:00 - 0:03) 镜头1，远景：…` 写首尾相接的时间段，末段终点等于总时长。
- **多镜容器挂关键帧**：按[交付形态](delivery-profile.md)记账，关键帧排在参考清单最前，首句写「图1、图2、图3 依次是三个镜头的画面，图4 是老人，图5 是年轻女子」，各段写「按图N构图」（容器切点有浮动，需精确切点时逐镜生成或生成后按实际切点剪辑）。

## 对白、声音与文字

- **对白写法与语速**：紧跟说话人可见动作写 `说道：“逐字台词”`（如「她望着镜头，声音轻而稳，用普通话说道：“……”」）。按[对白预算](performance-action-timing.md#对白预算)先估再排时（中文常速约 4.6 可发声字/秒；超载会加速赶词或无报错截断，生成后须逐字核听）。
- **参考音频**：跨镜保持角色音色写「图1 中的女子说话时，音色参考音频1」；把本句合成音挂成 `音频1` 写「口型与音频1 逐字同步」时音色最稳，但需逐镜查口型是否停顿或提前张嘴。双人镜不说话者按[对白、口型与声音](camera-audio-continuity.md#精确引用)处理。
- **声景与文字层**：写全环境底声、音效事件及配乐层（无配乐显式写「无背景音乐」）。默认禁字幕写「全程无字幕，不生成对白文字叠加」；画内已批准文字逐字说明承载面和位置，无画内可读文字义务时才加全局无文字要求。

## 智能改写、编辑与延长

- **`prompt_extend`**：官方 API 默认 `prompt_extend: true` 会用大模型改写提示词，可能改动逐字台词、声音层或切数；直连 API 时显式控制该参数，平台不暴露时生成后须对照正文逐项核对。
- **编辑与延长（不写 2.5 的 `任务类型` 行）**：均通过 `reference_video` 加正文关键词触发——编辑写「编辑视频，把视频1 中……改成……」（或用「去掉 / 替换 / 改成」点名修改处）；延长写「将视频1 向后延长 N 秒」「延续」或「向前延长」（需 `ratio: adaptive`，从实际终点写唯一动作与新终点，预算新增片段时长与对白）。

依据（2026-09-26 核对）：[Wan 3.0 视频生成 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)：输入模式与互斥、素材上限、时长、`prompt_extend`、编辑与延长；[Wan 3.0 视频生成指南](https://platform.qianwenai.com/docs/developer-guides/video-generation/wan30-video)：时间段写法、`说道` 对白、素材编号、编辑与延长关键词。
