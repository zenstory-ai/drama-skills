# 时代锚点

## 时代从原著事实来

拆资产前，先按原著与剧本中的设备（全面屏智能手机、U 盘、液晶屏）、传播方式（热搜、短视频、直播带货）、流行语、写明的年份或年龄与事件关系判断时代，在 `视觉设定.md` 顶部的项目视觉方向写一行时代锚点（年份/年代 + 设备、制服、家具、灯光的时代形制）：

```markdown
- 时代锚点：当下（2020 年代）；设备：全面屏智能手机、笔记本电脑、液晶显示器；制服：现行常服；陈设：白色工位桌、网面办公椅；光：嵌入式 LED 面板灯，冷白。
```

原著没有能定时代的事实时，标为「需创作者决定」，不默认成过去。

## 旧要有来源与条目形制（`AST-14` / `AST-15`）

- **`reviewed_invariant` AST-14**：`视觉设定.md` 与下游提示词的时代不得与原著事实矛盾。「旧」「老式」「复古」「褪色」「斑驳」及 `old`、`worn`、`dusty`、`period`、`CRT` 等词须有原著依据或创作者明确选择；无依据的一律删去，改用时代锚点写法。原著只写某件物品旧时，仅在该道具状态中记录，不把整个地点拉回过去。
- **`craft_default` AST-15**：地点、造型和道具条目在年代会改变外观处写具体时代形制（如写「全面屏智能手机」「液晶显示器」「现行常服」，不写笼统的「手机」「显示器」「军装」）。

示例（主角跑外卖，用手机抢单、看直播带货、刷热搜）：
- 错：「九十年代小饭馆门口，二八自行车，腰别 BP 机」（无原著支撑）。
- 对：时代锚点写当下；站点写电动车充电桩、智能取餐柜；手机写装有接单 App 的全面屏智能手机。
