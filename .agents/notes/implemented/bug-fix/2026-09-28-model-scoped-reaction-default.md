# Agent Note: 反应镜默认写法按模型限定

## Problem

[原决定](../feature/2026-09-28-reaction-contact-keyframe-framing.md) 把 H3 复测的
「情绪词＋两处泄露＋1.5 秒内落下」推广为通用默认，但同轮 Seedance 样片档支持完整可见反应链，
两者证据不能互换。

## Decision

H3 才使用该复测默认；Seedance 2.5 保留完整可见反应链，其他模型没有这轮证据，不照搬
两处/1.5 秒配方。同步通用参考、Seedance 方言、实测摘要的适用结论与更新日志。接触拆镜同样限定为已测的 H3 掌掴/推搡，不外推到拉住、带离或其他模型。

## Alternatives considered

- 保留通用默认、只在段末注明样本小：读起来简短，但仍会给 Seedance 相反的指令，故不用。

## Consequences

建议与证据适用范围一致；多模型项目要按目标方言选写法，不能再共用一个反应镜配方。
没有新增生成实验，不把文案检查冒充模型效果验证。
