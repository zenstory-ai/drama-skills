# Creator-first 示例

《让你管账号》EP001 展示一集在默认工作流里生成的全部五份创作者文档：纯 Markdown 交付，不夹带创作阶段 JSON/JSONL、索引、指纹、QA 表、审核表或内部中间文件。
本例选择中文创作者说明、英文可复制生成提示词；其他项目按各自的提示词语言执行。

- [`剧本.md`](EP001/剧本.md)
- [`视觉设定.md`](EP001/视觉设定.md)
- [`分镜.md`](EP001/分镜.md)
- [`图片提示词.md`](EP001/图片提示词.md)
- [`视频提示词.md`](EP001/视频提示词.md)

本集是同一故事设定的合成改写，背景设在当下，按快节奏漫剧写成：22 镜、约 62 秒，平均镜长约 2.8 秒，`[VO]` 约占台词字数两成。
第一帧就给足压迫感：视频会议里其他军团哄笑、上级点名压下下周评比的死限，周薄森把这摊空白交下来，江晨在第 31 秒立下“下周榜首”的军令状；
外部压力和人物短板都取自故事既有事实，不额外添塞具名配角。集尾卡在倒计时跳秒、笑容僵住的那一拍；系统面板留在后期叠加。
本例未绑定特定视频模型，镜长按叙事节奏定；切换到有最短原生时长限制的模型时，按分镜技能「已声明原生时长」处理短镜。

本目录是创作质感样例，不是死板的格式模板；具体约束以各负责技能与五份创作者文档契约为准。
