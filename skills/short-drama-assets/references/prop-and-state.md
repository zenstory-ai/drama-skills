# 道具与状态设计

## 持续身份与可变状态（`AST-03` / `AST-04`）

只有会被识别、操作、传递、读取、揭示或保持连续性的物体才建道具条目；普通背景物归 `set_dressing`（同款多件若流转独立则分建条目，仅作背景的便签按类别管理）。

- **持续身份（Prop）**：尺度参照、基本形制与部件关系、主要材料与表面工艺、原本功能与操作方式、永久唯一标记（序列号、缺口、纹章）。禁用“重要文件”“神秘盒子”“高级质感”替代具体形制，也不补写剧本未给的品牌或装饰。
- **可变状态（State，`craft_default` AST-03）**：同一物体的转手（所有人、持有人、左/右手、位置）、开合/启停、裂损/污湿、内容物（及是否已露面）、可读文字版本、消耗进度及变化原因与有效范围，一律记为状态变化，不拆成 `PROP-OPEN-CASE`、`PROP-EMPTY-CASE` 等假新道具。
- **持续身体—物件关系**：持续承担人物支撑、固定、负重或行动限制的物件，在状态中写明人物—物件关系与有效范围，交分镜落实起止边界；单次坐下、靠墙或伸手接触归镜头瞬态。
- **内容物 vs 人物认知**：盒内始终有号牌是道具内容状态，角色开盒后才知道号牌存在是人物认知状态；未展示内容物不等于凭空消失，装有物品也不等于角色提前知情。
- **功能性关键道具**：承担防护、开路、储能或身份证明的道具，状态须写明来源、当前持有人、触发条件、启用可见表现、剩余次数/进度与使用后果，不得无来源突然生效。

## 可读文字政策

每个带文字或标识的道具必须明确选定一项政策：

1. **`exact_readable`（精确可读）**：剧情要求观众读到；保存准确字符、语言、大小写/标点及来源，下游提示词不得同时启用全局禁字（`no_text`）。
2. **`graphic_only`（仅留图形轮廓）**：保留标签/印记形状与排版，不生成可辨文字。
3. **`no_readable_text`（无可读文字）**：表面不出现任何可读字。
4. **`pending_creator_text`（待创作者定稿文字）**：剧本要求文字但具体字句未定，阻断依赖它的可读提示词。

- **敏感屏显与真实专名（`craft_default`）**：涉及网址、号码、合同等敏感屏显须写明剧本来源与准确文字，严禁带入本地路径或内部地址。若原著带入现实品牌、商标、机构或真名，不得擅自决定去留或改名——在对应道具条目下标「文字政策未决」，列出「保留原名 / 只留形制不留标识 / 改用虚构名」三项候选及下游影响交创作者选择。

## 合成例：铁皮匣

- **道具 · 铁皮匣**：手掌至小臂长的扁长黑铁匣，铰链盖，右前角永久凹陷；盖内写 `“潮位 7”`（政策：`exact_readable`）。
- **本集状态**：初始闭合、内置白瓷号牌，放于柜台下层；SC004 顾禾开匣取牌后变为「打开、空」，盖内文字此时出镜可见（号牌另记转入顾禾右手状态）。
