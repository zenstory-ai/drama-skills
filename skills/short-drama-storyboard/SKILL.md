# 短剧分镜与首尾帧提示词

把定稿剧本和视觉设定拆成切镜有据、空间连戏、起止画面清楚的 `剧集/<EP>/分镜.md`。
每镜使用二级标题 `## SHOT-... · <名称>`（列出「来源、时长、目的、景别/机位、运镜、起点、动作、终点、图片提示词项、输入参考图、出场设定、声音」），同镜下用 `### 首帧提示词` 写起始帧画面（小节内只放以 `>` 开头的引用块，不夹普通列表或 `---` 分隔线；确需锁定收尾构图时另加 `### 尾帧提示词` 写终点画面）。

## 快速开始

```text
用 $short-drama-storyboard 完成 EP001 的正式分镜和每镜首帧提示词
```

## 入口与语言配置

- 有定稿剧本与必要视觉设定即可直接动笔（先读磁盘最新 `剧集/<EP>/剧本.md`，与早期对话草稿有出入时以文件为准）。美术设定图提示词与分镜可并行推进，仅当创作者明确要求比选重头戏拍法时才先给备选方案等拍板，常规整集或单场拆镜直接一气呵成。
- 创作者可读说明跟随项目语言；首尾帧的可复制提示词正文跟随 `short-drama.json#/format/prompt_language`（没有 `short-drama.json` 时按已有提示词或项目文档语种推断，未指定时可用用户当前语言）。
- 分配镜长前参考 `short-drama.json#/creator_authority/production_profile/choices/native_duration_seconds` 与 `rhythm_profile`：已确认模型秒数区间时对齐单镜上下限（短于下限的快切可提议多镜合生或演完稳住终点画面）；未填写秒数或未定模型时，直接按对白与动作体量给常规秒数（如 2–6s），**不因此停工追问**。`target_avg_shot_seconds` 与 `close_shot_share_min` 作为全集节奏与近景占比的参考区间弹性把握。

## 工作流

1. **排定戏剧落点与悬念时机**：顺场理清动作、对白、音效、画面文字与转折落点（若立项或剧本限定了“后半段 / 最后 N 秒首次露面”，按全集目标时长换算到具体秒数位置再排镜）。
2. **逐镜写清起止、运镜与声音**：顺着 `起点 → 动作 → 终点` 交代人物站位、姿态与持物交接，单镜动作量贴合秒数（见 [镜头设计方法](references/shot-craft.md)）：
   - `运镜`：运动镜头写清动法与起止落点（开场强钩子或高潮反转可用急推），固定镜头直接写 `固定` 即可，无需强凑不动理由；
   - `声音`：排镜时按台词与停顿估准秒数，文档「声音」行清爽写明对白/VO/OS、关键音效与留白即可，免写读秒算术账。
3. **按需标注空间站位与轴线**：三人以上群戏、复杂空间换位或跨轴调度时，按需在该场开头写一段 `场景站位` 标尺（简单双人场直接在各镜起止点写清即可），见 [场面调度手册](references/blocking-playbooks.md)；动作打斗戏拆法见 [打戏与动作分镜](references/fight-craft.md)。
4. **编写首尾帧提示词**：`### 首帧提示词` 只定格镜头 `起点` 瞬间画面（带 `连戏锁` 的条目在生效范围内原字保留 `锁定词`），需要锁收尾构图时另补 `### 尾帧提示词`。全集保持统一画风与同场主光方向——**明确标出的回忆闪回、梦境幻觉或主观视角镜头可按剧情意图切换色调质感或画风表现**。同机位切景或微调表情动作时，允许基于已确认的上一镜首帧配合指令改图模型派生下一镜首帧以锁死连戏（见 [首尾帧构图与写法](references/keyframe-craft.md)）。
5. **核对关联字段并收束整集**：首尾帧写定后，按画面实际入画主体一次填好 `出场设定`、`图片提示词项` 与 `输入参考图`（语法见下节）。剧本每个场次都须有镜头覆盖，确需整场略过时在文档开头写 `- 未拍场次：<场景 ID>（理由：……）`；末尾汇总全集总时长与待拍板事项。

## 出场设定与参考图写法

用户没有手工点名参考图，不等于选择文生视频。首尾帧成稿后，对照提示词正文里**实际入画**的人物、场景与道具核对填写三项字段（每项 `控制：` 只写本镜景别实际可见的部位，不照搬上一镜全身范围）：

- **出场设定**（必填）：写成 `《视觉设定.md》·<人物|造型|地点|道具>「<名称>」（控制：<范围>）`，多项用 `；` 连接，名称与《视觉设定.md》条目标题完全一致（仅核对首尾帧入画主体，不扫 `- 来源：` 引文里的未入画名称；远景需认出身份的角色照常列入，完全无设定条目入画时写 `无`；尚未建档的连戏物件先在提示词稳住描写并在汇总里请 `$short-drama-assets` 补建）。
- **图片提示词项**：填写《图片提示词.md》已有的对应 `IMG-...《<名称>》（控制：…）`；尚无对应条目时写 `无`。
- **输入参考图**：自动在用户提供的输入、`剧集/<EP>/制作成果/` 和文档已指向的可见媒体中核对真实图片——
  - 已有真实可读图片绑定 `REF-...`，外部工具自挂图片预留 `PLAN-...`（将路径位置换为 `IMG-...` 或 `SHOT-...`，支持正反打等跨镜复用已有镜头首帧），两者可混排并从 `1` 连续编号：`REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）`（书名号内名称同样支持外文）。注意全角冒号与路径前的中点 `·`，不得用 `/` 代替字段分隔符，多图之间只用中文分号 `；` 连接。
  - `用途` 从 `外貌`、`主体`、`造型状态`、`空间布局`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格` 十项选填唯一主作用（一图兼顾两事时次要作用写进 `控制：`；每镜最多一张 `起始帧` 和一张 `结束帧`，挂 `结束帧` 必同时挂 `起始帧`；参考图位超模型上限时按「起始帧 → 核心动作/开口角色 → 关键道具 → 场景 → 其余角色 → 风格」取舍）。
  - 创作者要求等实图到位时写 `无（待补参考图：<缺项>）` 或在已有图位后接 `；待补参考图：<缺项>`（缺项用 `、` 分隔）；确认不垫参考图时写 `无（文生视频）。` 或简写 `无`（只有真实 `REF-...` 可直接交 `$short-drama-produce` 图生投产）。

## 修订原则

返修分镜时按戏剧职责维护 `SHOT-...` 镜号稳定：
- **调顺序或同镜微调**（改景别、走位或起止细节）→ 保留原 `SHOT-...` 镜号，同步修好相邻镜衔接；
- **新插独立镜头**（补反应特写或道具插入镜）→ 新开 `SHOT-...` 镜号，后续老镜号不顺延改号；
- **一镜拆多镜** → 承接原起点与已生成首帧的主半镜可保留原 `SHOT-...` 镜号，仅给新拆出的子镜开新号；
- **多镜并一镜或整镜推翻重拍** → 停用旧号换新号，已停用废号绝不重用，并在回复中点明需同步更新的下游 `MOTION-...` / `GROUP-...`。

## 完成标准

同轮同时修改《图片提示词.md》与《分镜.md》时当场对齐引用，不另建场次核对表文件。单场试拆或上下游其余文档尚未齐备时，可用 `$short-drama` 的 `creator_markdown_check.py 剧集/<EP> --project-root . --partial` 做局部校验；整集齐备后可跑完整校验。视频提示词、生成投产与独立审查只在创作者点名时启动。
