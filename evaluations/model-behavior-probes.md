# 模型行为观察摘要

这些是 2026-09-08 至 2026-09-11 的探索性观察，用于选择下一步验证方法。
视频经中转服务调用 MiniMax H3、Seedance 2.0/2.5；图片经 imagegen 调用，
生成工具自报 gpt-image-2，编辑步骤未暴露模型名。未单独说明时为 5 秒、720P、16:9。
音频使用转写、回听或电平测量，画面使用抽帧、区域比较或盲评；各自结论限于所用方法。

原始媒体、运行状态和完整项目保存在仓库外。这份摘要不是可重放回归夹具，
也不构成接口能力、成功率或内容质量的保证。供应商参数以原生 API 文档为准。

| 观察 | 样本与结果 | 可用于什么判断 |
|---|---|---|
| H3 配乐空形式 | 写 `non_diegetic_music: N/A` 的 14 次无配乐，省略的 3 次中 2 次有配乐 | 无配乐时显式写空，仍验收结果 |
| H3 否定句与额外对白 | 含 `No dialogue` 的 8 次未出现台词；否定气球的 3 次未出现气球 | 未支持“否定会招来被排除内容”的机制 |
| 视频字幕 | 11 条片抽样 44 帧，未观察到烧录字幕 | 不能据此保证模型永不加字幕 |
| 图片文字限制 | 同一描述各 1 张，加无文字约束后可读文字减少 | 保留项目文字政策，扩大样本后再判断稳定性 |
| H3 中文对白 | 同镜头 20 次，7–108 字、5–13 秒；自然语速约 4.1 字/秒，较密输入赶词或截断 | 作为可覆盖估时参考；50 字/5 秒仍完整，不能划定“超过 9 字/秒必截断”的阈值 |
| 逐字台词语法 | Seedance 两版各 2 次，H3 1 次，观察到逐字返回 | 使用方言语法，生成后回听 |
| H3 参考构图 | 20 次比较中，明确要求保留构图的 8 次保留较好 | 点名所需控制范围，不将其视为保证 |
| H3 起始帧路径 | 专用首帧、单张参考、参考加角色板各 3 次，均观察到开场构图保留 | 验证这几种已测试输入的可用性 |
| 实际尾帧续接 | 带上一段尾帧 2 次保持开场，纯文字 2 次未保持 | 需要连续画面时优先使用真实产物作参考 |
| 多镜切点 | 要求 4 秒切：H3 3.96/4.04/4.12 秒，2.5 为 3.71/4.29/4.46 秒；2.0 未指定秒数，落在 5.21–5.54 秒 | 测实际切点；不是精度承诺，也不是同语法严格对照 |
| 图片定点修改 | 2 次，仅改目标物时其余区域变化较小 | 说明修改目标与保持范围，核对输出 |
| 角色音色 | 一组无绑定素材的角色间音高差接近角色内差；预置音色合成的另一组区分增大 | 对比试听候选；不能证明参考音频绑定到视频的效果，也不能用音高独自判定角色身份 |
| 写实角色板 | 两组各 3 张，单个盲评者区分出写实程度；同时改变光学描述、表面和不对称细节 | 支持整组写法的探索，不能归因于其中某个词或要求身份细节跨镜变化 |
| Seedance 2.5 尾帧 | 一个镜头每组 3 次，绑定尾帧的末帧更接近声明终点，仍有运动 | 可尝试尾帧约束；未验证所有动作、节奏或参考图与首尾帧混合路径 |
| Seedance 2.5 多镜容器 | 一组分开生成的基线与 3 次容器比较，亮度极差持平、蓝红极差增大 | 容器只有一张起始帧，基线逐镜有首帧；不能把差异归因于容器机制 |
| Seedance 2.5 连续长镜 | 一个对白场次 3 次，未同时满足预期发声时序与尾段静默 | 在此类任务中验收时序；未逐字核对，也不支持“所有长镜头不可控” |
| 图片光线写法 | 同画面各 4 张，光位描述 2/4、受光结果描述 4/4 落在指定一侧 | 可补充可观察结果；未测视频，不要求删除方向词 |
| 光线测量单位 | 暗部中位像素值 17.8 与 29.8，相差 12 个数值单位 | 不是曝光提升 12 档 |
| 多项同时重跑 | 九镜重跑后接镜色差下降、尾帧落位改善，未绑音频时音色指标也改善 | 多项同时变化，不能单独归因；台词完整性未测，不能据此证明全链路质量 |

## 执行路径限制

中转服务的 `duration: -1`、reference_video 接入和首尾帧/参考组合受当时账号与中转接口限制。
这些失败或接受结果不能直接推断原生供应商的支持范围；同一 content 数组也不足以证明所有 role 可组合。

## 后续使用

技能保留可迁移的做法，测试数据留在这里；更新时注明模型、执行路径、样本与混杂因素。
需要做新的能力断言时先验证具体路径。未观察到失败不等于不会失败，单次改善也不等于稳定因果。
