# 视频提示词格式规范（完整项目模式）

撰写并落盘完整项目文档 `剧集/<EP>/视频提示词.md`（用于跨文档自动校验或衔接内置投产）时，按本规范组织字段与标点。若仅是轻量起草单镜或几条独立提示词，可直接按 `SKILL.md` 的轻量模式输出。

## 一、单镜条目结构（`MOTION-...`）

- **标题与编号字符集**：每镜使用二级标题 `## MOTION-... · <名称>`。所有条目编号与参考槽位 ID（`MOTION-...`、`GROUP-...`、`REF-...`、`PLAN-...`、`REF-VOICE-...`）仅使用大写英文字母、数字与连字符 `A-Z0-9-`。
- **必填字段顺序**：依次列出以下字段——

| 字段 | 写法要求 |
|---|---|
| `- 分镜：` | 对应《分镜.md》的 `SHOT-...` 编号 |
| `- 时长：` | 必须与对应 `SHOT-...` 的时长完全相等，且落在目标模型单次支持区间内 |
| `- 生成方式：` | **只写两个精确值之一**：`图生视频`（绑定 `REF-...` 或 `PLAN-...` 时）或 `文生视频`（未绑定参考图时） |
| `- 输入参考图：` | 承接或按模型需要增减 `REF-...` / `PLAN-...` 槽位；确认不垫图时写 `无（文生视频）` 或 `无` |
| `- 参考音频：` | 可选，见下文第三节（仅在音画同出且挂载角色音色参考时紧跟 `输入参考图` 下一行） |
| `- 开场画面：` | 文生视频时必填非空，点名设定条目须与对应分镜 `出场设定` 一致；图生视频可按需简写或留空 |
| `- 起始帧：` | 本镜开场定格状态说明 |
| `- 动作过程：` | 本镜核心动作、表演与运镜先后概要 |
| `- 终点：` | 与对应 `SHOT-...` 一致的收尾状态 |

- **可复制正文小节**：固定使用三级标题 `### 可复制提示词`，小节内**只放顶格以 `>` 开头的引用块**，不夹普通列表或 `---` 分隔线。

## 二、参考图槽位与连戏锁豁免（`CON-07`）

参考图槽位语法与《分镜.md》保持一致（全角冒号、全角括号、中点 `·`、多项用中文分号 `；` 分隔，从 `1` 连续编号）：

```text
REF-<slot>（顺序：<n>）· <项目相对路径>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
PLAN-<slot>（顺序：<n>）· <IMG-...或SHOT-...>《<名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

- **连戏锁（`LOCK-...`）豁免判定**：
  - 已挂载本镜 `起始帧`（含首帧已带该锁定词的跨镜复用 `PLAN`），或已挂载对应设定条目的 `主体` / `造型状态` 参考图时，本镜自动豁免重抄该条静态 `LOCK-...` 锁定词（专注描写动态演变）。
  - 触发豁免的槽位需满足：`REF-...` 在 `《<名称>》` 或 `控制：` 中点明该《视觉设定.md》条目名称，或指向该条目已登记的参考图路径；`PLAN-...` 指向该锁 `图片提示词项：` 列出的 `IMG-...`。
  - 文生视频，以及仅挂 `空间布局` / `风格` 等未锁住该外观的图生视频（含合生分组），均须在生效范围内原字保留 `LOCK-...` 锁定词。
- **消除 `待补参考图`**：图生视频找到真实图片改绑 `REF-...` 或将剩余缺口转为 `PLAN-...` 后，须请 `short-drama-storyboard` 技能同步更新《分镜.md》对应镜头的 `输入参考图`。

## 三、可选角色参考音频（`VID-27`）

仅当项目走音画同出路线、目标模型支持音色参考，且本镜（或本组）`### 可复制提示词` 显式引述了该角色本场剧本台词时，在 `输入参考图` 下一行单列：

```text
- 参考音频：REF-VOICE-<slot>（顺序：<n>）· <音频路径>《<名称>》（用途：音色；角色：<人物名>；控制：<范围>；不得控制：<范围>）
```

- 路径必须对应《视觉设定.md》中该人物登记的 `- 声音参考：<项目内路径>（用途：音色；控制：…；不得控制：…；状态：…）`。
- 槽位名不得与本条目 `输入参考图` 重名；音频 `顺序` 与图片分开从 `1` 连续编号。
- 同一角色单条至多绑定一条参考音频；`控制` 与 `不得控制` 互不重叠（样音情绪、空间混响与背景杂音一律归入 `不得控制`）。

## 四、多镜合生分组（`GROUP-...`，`VID-13` / `VID-15`）

启用多镜合生时，完整保留全集逐镜 `MOTION-...` 条目，并在其后增补分组条目：

```markdown
## GROUP-EP001-01 · <分组名称>
- 成员：MOTION-EP001-001、MOTION-EP001-002
- 时长：8s
- 输入参考图：REF-OPEN（顺序：1）· <项目相对路径>《<名称>》（用途：构图；控制：<范围>；不得控制：<范围>）
- 参考音频：REF-VOICE-01（顺序：1）· <音频路径>《<名称>》（用途：音色；角色：<人物名>；控制：<范围>；不得控制：<范围>）
- 理由：<同场紧邻合生理由>

### 可复制提示词
> ...
```

- `成员` 须为同一场次内按分镜顺序紧邻的已有 `MOTION-...` ID；同一集内每个 `MOTION-...` 至多归入一个 `GROUP-...`，组内成员不得重复。
- 分组 `时长` 等于各成员时长之和；分组级 `- 输入参考图：` 与 `- 参考音频：` 均为可选，绑定真实 `REF-...` 时可直接交由 `short-drama-produce` 技能按组投产。

## 五、成片配乐与主题曲章节

需要编写成片配乐或主题曲提示词时，在《视频提示词.md》末尾以独立的二级标题 `## ` 开启新章节（如 `## 成片配乐与主题曲`），以便文档解析与自动校验正常收束前一条 `MOTION-...` / `GROUP-...` 小节。章节内写明铺乐区间、剧情作用、淡入淡出时机、情绪起伏与禁用元素（歌词仅取自用户来稿或定稿剧本，严禁自行编造）。
