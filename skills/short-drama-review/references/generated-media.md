# 成片看片与返工分流指南

适用于审查单镜生成素材、《剪辑单.md》与整集成片切点接缝，以及根据试拍样片或创作者看片反馈做问题归因与提示词调优。创作者在对话里随口给出的看片反馈（如“第 3 镜手穿模了”“第 5 镜后半句吞字了”）可直接接手定位病灶并给出修法，无需强求补填看片人、查看工具或查看局限等繁琐表格。

## 一、单镜与成片瑕疵六档分流

对照《分镜.md》本镜目的、起止画面与声音要求，先看核心剧情信息、台词、关键道具变化与人物反应是否拍出，再将画面或声音瑕疵归入以下六类处置。其中保留沿用、裁切避让与后期修补属 `craft_default` 处置建议（`note` / `minor`）；凡定为 `major` 或 `blocker` 的实质媒体缺陷，其 `- 规则：` 字段必须挂靠所违背的 `structural_invariant` 或 `reviewed_invariant` 规则编号：

| 处置分类 | 判定标准 | 严重程度与归属规则 | 后续动作与负责技能 |
|---|---|---|---|
| **保留沿用** | 正常倍速播放不显眼，不影响剧情理解与前后连戏（如单帧边缘微闪、远处路人轻晃） | `note`（`craft_default`） | 留底告知剪辑，不改提示词、不重抽 → `short-drama-edit` 技能 |
| **裁切避让** | 瑕疵落在有效动作起止点之外（如片头发呆等待、片尾多余变形），掐头去尾后本镜信息完整 | `minor`（`craft_default`） | 写明剪辑入出点避开问题区间 → `short-drama-edit` 技能 |
| **后期修补** | 挪几帧音频对口型、调色、后期叠字或局部擦除背景穿帮小物即可解决 | `minor`（`craft_default`） | 写明后期修补做法 → `short-drama-edit` 技能 |
| **建议重抽（创作者可豁免）** | 核心剧情能看懂，但存在较明显的外观造型偏移、连戏锁细节走样、动作容量紧促或口型听感瑕疵，后期难彻底修净 | `major`（归入对应不变量，如 `AST-01 · reviewed_invariant`、`AST-03 · reviewed_invariant`、`CON-01 · reviewed_invariant`、`CON-07 · reviewed_invariant`、`VID-05 · reviewed_invariant`、`EDT-04 · reviewed_invariant`） | 给出局部调优重抽方案，同时允许创作者结合工期与预算显式豁免留用或靠切镜遮掩 → 对应负责技能 / `short-drama-edit` 技能 |
| **必须重新生成** | 漏掉关键剧情动作、核心台词或必看物证，私编发声台词，或人物换脸脱绑、空间轴线全反、关键真字乱码扭曲事实，裁切与后期均无法挽回 | `blocker`（归入对应不变量，如 `AST-05 · structural_invariant`、`CON-07 · reviewed_invariant`、`SHT-02 · reviewed_invariant`、`SHT-09 · reviewed_invariant`、`VID-17 · reviewed_invariant`、`VID-22 · reviewed_invariant`、`VID-25 · reviewed_invariant`） | 定位提示词、垫图或拆镜症结，退回对应负责技能修改后交 `short-drama-produce` 技能重生 |
| **剪辑补回**（仅成片） | 原始生成素材已拍到关键内容，但成片切点下刀太狠、字幕错漏或混音叠字把关键信息与台词弄丢 | `blocker`（归入对应不变量，如 `EDT-04 · reviewed_invariant`、`EDT-05 · structural_invariant`、`EDT-07 · reviewed_invariant`、`EDT-10 · reviewed_invariant`） | 指明需调整入出点、字幕或音轨的 `CUT-...` 条目 → `short-drama-edit` 技能 |

### 审查结论判定

- `PASS`：无 `blocker`，且无未获创作者显式豁免的 `major`（落入 `审查/*.md` 的 `- 结论：` 字段时，无建议写 `APPROVE`，附 `minor` / `note` 或已豁免 `major` 留底写 `APPROVE_WITH_NOTES`）；
- `PROVISIONAL`：无 `blocker`，仅剩不影响核心主线推进、已写明下阶段修正方案的局部问题（或待创作者在看片时拍板的边界项，以及尚有关键片段未查看到的情形）；
- `REVISE`：存在 `blocker`，或存在尚未获创作者豁免的 `major` 缺陷需返修重出（已过关片段照常交剪辑推进，复审只核验返工片段，不翻已放行片段旧账）；
- `REJECT`：整批生成方向、主体一致性或关键戏份严重失控，局部补救无效，需回退重设提示词或参考资产（在 `审查/*.md` 中记 `- 结论：REVISE` 并标明整批回退重设范围）。

## 二、问题归因与返修尺度（`craft_default`）

1. **先分清垫图毛病还是出片毛病**：
   - **参考素材本身的问题**：输入参考图底图自带旧水印、杂字、五官模糊、服装画错或空间透视歪斜——写再多防崩提示词也救不回来，直接退回 `short-drama-assets` / `short-drama-image-prompts` 技能换图、裁修或重出设定图。
   - **生成阶段的问题**：垫图干净合规，但在当前提示词、挂图顺序或模型参数下出现残留杂字、意外混入配乐、人物串衣换脸、180° 越轴、动作超载或口型错位——顺藤摸瓜定位到具体条目与字句（结论仅限当前项目与模型配置，不跨项目当成死规矩硬套）。
2. **区分“探索试拍单改一项”与“明确错漏一并修完”**：
   - **探索性试拍归因**：试拍重难点镜头（多人调度、复杂走位、手部交接、高反差夜景）出现原因不明的抽风时，优先每次只调整一个变量（如拆短动作、换挂图组合或精简背景词）以便看清哪一处生效。
   - **明确错漏返修**：已经一眼看清的多处确定性错漏（如漏绑角色参考图、台词抄漏半句、运镜前后矛盾、道具拿错左右手），在**同一轮返修中一次性全部修完**，写明修改点与不得误伤的保留内容，绝不机械拆成多轮折腾。
3. **原样重抽与结构重拆的取舍**：
   - 垫图与提示词查无明显问题、属模型偶发抽风时可先原样重抽；同一输入连续重抽一两次仍反复冒出同一硬伤时，及时转为**局部改词**或退回分镜**拆镜重排**，不要往提示词末尾硬塞“高质量、保持一致”等空话盲抽。
   - 仍迟迟难以生成时停下试错，列出三条出路请创作者拍板：① 留用现有素材并靠剪辑切点藏拙；② 将该镜信息挪给相邻镜头交代；③ 删减该镜——涉及关键剧情或台词须先转移信息或退回 `short-drama-write` 技能调剧本；确认删减单镜后按 `EDT-11` 在《剪辑单.md》登记未入片原因，或退回上游成对移除 `SHOT-...` 与 `MOTION-...`（仅整场不拍时才在《分镜.md》写 `- 未拍场次：`）。

## 三、要求优先级与改稿防漏把关（`REV-09`）

压缩提示词字数、局部返修或重排 `GROUP-...` 多镜合生分组时，按由高到低的优先级守住底线：

1. **剧本已定的核心事实、逐字台词与必读画面文字**
2. **分镜已定的本镜目的、起止状态与镜头时长**
3. **视觉设定版本与跨镜连戏状态**
4. **创作者拍板的画风方向与模型模式配置**
5. **目标模型的提示词语法与能力边界**（模型做不到上层要求时挑明汇报并提替代拍法，不悄悄删戏糊弄）
6. **次要环境点缀与画质修饰词**

每次改词或重拆合生分组后快速复核四件事：① 剧本动作、反应与分镜总时长/合生分组覆盖（`SHT-16`、`VID-15`）是否仍严丝合缝；② 首尾帧小节结构干净（`SHT-17`）且各自守住静态瞬间（`SHT-06`、`SHT-10`），中段复杂核心动作少靠首尾双帧自动插值硬猜；③ 本镜原本立住的构图、光影与表演亮点未被改稿误伤；④ 局部补拍或备选版是否标清了与主镜头的关系（`VID-12`）。遇到缺前置材料（如某镜印字尚未定稿）时，只拦下依赖该字样的直出真字镜头，其余环节照常审理。

## 四、《剪辑单.md》与整集成片切点接缝核查

审查 `剧集/<EP>/剪辑单.md` 与整集渲染成片时，对照 `short-drama-edit` 阻断级不变量定级并退回对应负责技能（仅加工剪辑退 `short-drama-edit`，需改剧情、台词或重出素材时路由对应上游）：

- **结构硬账（`structural_invariant` → `blocker` / `major`）**：
  - `EDT-01`（上游条目与可读媒体文件真实绑定）、`EDT-02`（`入点`/`出点`/`时长` 算术自洽与边界；短于 `0.50s` 快闪静帧归提醒不阻断）、`EDT-05`（开启字幕时逐字照抄《剧本.md》）、`EDT-06`（同源视频重叠须声明 `- 重放：<叙事理由>`）。
- **内容与切点接缝（`reviewed_invariant` → `blocker` / `major`）**：
  - `EDT-03`（不得反向篡改上游定稿）、`EDT-04`（保留台词听感完整可辨）、`EDT-07`（入出点在可用区间且 `取舍` 写清可见变化）、`EDT-10`（回听并修平环境声与配乐切点跳变，不靠渲染器不执行的自然语言备注）、`EDT-11`（全集未入片镜头逐一登记原因；`--partial` 试剪不阻断）、`EDT-16`（同场同光相邻镜头色差核查，剧情光色突变无需强拉）、`EDT-17`（素材重出后重测发声并更新字幕/画面文字时间窗）。
- **批量缩略图排错与误杀防线（`craft_default` / `taste_option`，不触发 `REVISE`）**：
  - 审批量首帧图、生成素材或成片切片时，可按镜序拼缩略图并排对照《分镜.md》站位与《视觉设定.md》，排查背景镜像翻反、陈设远近跳变与身高比例失真；尾段跳变优先走「裁切避让」（`minor`），首帧即错或全程穿帮则挂靠所违背的上游不变量定为 `major` / `blocker`（`SHT-09`、`AST-03`、`AST-05`、`CON-01`、`CON-07`）。
  - **放行项**：对白留白、L/J-cut 叠音提醒、自动接镜覆盖、响度一次外修仍超容差后转创作者拍板、服务于叙事意图的相似景别/有意重放/跳切、切点音量跳变「请回听」提示均属 `craft_default`（最高记 `minor` / `note`）；剪切节奏快慢、留拍早切与可选全片颗粒属 `taste_option`（仅记 `note`），绝不判回。
