# 分镜、首尾帧与视频动态核查清单

按归属分别路由：分镜、站位调度与首尾帧问题退回 `short-drama-storyboard`；视频动态、合生分组与音频参考问题退回 `short-drama-video-prompts`；跨场设定缺失退回 `short-drama-assets`。

## 1. 分镜与跨镜连戏核查（路由 → `short-drama-storyboard`）

- **场次覆盖与结构硬账（`structural_invariant`）**：
  - `SHT-01`（每场由 `SHOT-...` 覆盖或在文首写明 `- 未拍场次：` 理由，`- 来源：` 场景 ID 存在）、`SHT-17`（`### 首帧提示词` 与选配 `### 尾帧提示词` 仅保留顶格 `>` 引用行）、`SHT-05`（可选 `- 图片提示词项：` 指向《图片提示词.md》已有条目且名称一致）、`SHT-22`（首尾帧实际入画的设定条目列入 `- 出场设定：` 并指向《视觉设定.md》已有条目，穿戴独立 `## 造型 · <名称>` 且可见时列出 `造型「…」`）、`SHT-23` / `SHT-25`（实查可用图片后规范绑定 `REF-...` / `PLAN-...` / `无`，十项标准 `用途`、`顺序` 连续、`控制`/`不得控制` 不重叠，单条至多一张 `起始帧` 和一张 `结束帧` 且挂 `结束帧` 必挂 `起始帧`）。
- **内容保真、时长汇总、调度空间与单帧纯净度（`reviewed_invariant`）**：
  - `SHT-02`（镜头目的明确且忠实剧本原意、不漏拍关键动作/对白/音效/`[画面文字]`）、`SHT-08`（关键状态转变由主力镜头交代，不无故重演已完成动作；放行动作顺接微重叠与标明 `高潮重播镜` 的多角度重放）、`SHT-06` / `SHT-10`（首尾帧各自只定格 `起点`/`终点` 单一静态瞬间且与 `出场设定` 一致，不写连续动作链、不互借戏抢跑）、`SHT-09`（场景观看朝向与同框 `固定陈设` 匹配机位侧）、`SHT-12`（悬念揭晓边界不漏底不挡死）、`SHT-13`（多人站位朝向视线体现剧本关系）、`SHT-14`（跨镜运动物件轨迹方向连贯）、`SHT-15`（仅在项目声明 UI 遮挡区时核查避让）、`SHT-16`（单集总时长等于各镜可见时长算术加总，待定镜明标不漏算）、`SHT-19` / `SHT-20`（仅创作者要求比选时才出多套拍法；改分镜保持 `SHOT-...` 镜号稳定不重用废号）、`SHT-21`（提示词正文无编号/路径/分镜黑话）、`SHT-24`（`出场设定` 与 `控制` 范围不超出当前景别可见部位）、`SHT-26`（首尾帧提示词正文实际入画的设定条目与 `- 出场设定：` 核对一致，未入画提及项按需标入 `；画外：`）。
- **跨镜连戏与连戏锁（`CON-01`、`CON-02`、`CON-07`）**：
  - 顺镜序核查站位、朝向、伤污、持物、光线与知情状态衔接（`CON-01`、`CON-02` · `reviewed_invariant`），**放行明确标出的蒙太奇、闪回、梦境、时间省略或主观画面**（`taste_option`）。
  - **连戏锁覆盖边界（`CON-07 · reviewed_invariant`）**：脚本确定性核对 `LOCK-...` 声明语法与目标 ID；审稿核查生效范围内静态图、首帧、文生视频及未由 `起始帧`（`PLAN-...` 复用他镜首帧时该首帧须含该词）或对应条目 `主体`/`造型状态` 参考图锁住外观的图生视频（含 `GROUP-...`）是否原字保留 `锁定词`；已由上述参考图覆盖该锁的图生视频自动豁免，**绝不因省略静态锁定词报错**。
- **防误杀护栏（稳机位与单首帧取舍）**：
  - 固定机位是对白交锋、特写反应与防 AI 背景畸变的成熟拍法——简写 `运镜：固定` 或整场/整集采用克制稳机位风格均属合规选择，**绝不因未写固定机位理由或固定镜占比高而判不过**（仅当固定机位确实遮挡或漏掉关键戏眼时才提 `note` 建议）。
  - 镜头中段含复杂动作时少靠首尾双帧自动插值、多招打戏按回合拆切等均属 `craft_default`，偏离最高记 `minor` / `note`，不作阻断硬伤。

## 2. 镜头节奏指标核对

在满足 [故事大纲与剧本核查清单](rubric-story-script.md#4-节奏设定核对) 的启用条件（`rhythm_profile.status == "accepted"`）时，核对分镜两项确认指标：全集平均镜长是否落在 `target_avg_shot_seconds` 区间，全集近距离镜头占比是否达到 `close_shot_share_min`（超标仅记 `craft_default` 提醒，不阻断交付）；同时留意是否按剧本字数机械折算镜长而忽略对白真实发声耗时。

## 3. 视频动态与生成风险核查（路由 → `short-drama-video-prompts`）

- **结构与算术硬账（`structural_invariant`）**：
  - `VID-01`（`MOTION-...` 指向已有 `SHOT-...` 且时长完全相等）、`VID-03`（`输入参考图` 绑定 `REF`/`PLAN` 时写 `生成方式：图生视频` 且槽位语法、十项 `用途` 与首尾帧配额合法；无参考图写 `生成方式：文生视频` 并提供非空 `开场画面`）、`VID-13` / `VID-15`（保留全部逐镜 `MOTION-...`，`GROUP-...` 成员同场紧邻、分组时长等于成员之和、各分组与单拍不重不漏覆盖全集）、`VID-27`（`- 参考音频：` 槽位语法合法、`用途：音色`、路径指向《视觉设定.md》登记项、槽位不与参考图重名、音频 `顺序` 单独从 1 编号、同角色单条至多一条、`控制` 与 `不得控制` 互不重叠）。
- **语义保真、分段算术与动态合理性（`reviewed_invariant`）**：
  - `VID-04`（精确标秒分段之和含重叠合并覆盖等于分镜时长）、`VID-25`（显式人物发声引文须出自上游定稿，严禁私编台词；且 `- 参考音频：` 仅绑本镜/本组实际说出本场剧本台词的角色，不给沉默角色挂音色）、`VID-29`（忠实沿用分镜起点、终点、台词与下一镜衔接状态，不私改上游）、`VID-05`（未标秒动作量在镜长内可从容演完）、`VID-06`（同一时段严禁固定与移动运镜自相矛盾）、`VID-11`（局部变形/碎裂写清触发、变化部位与同框不变参照物）、`VID-12`（补拍或备选版沿用固定 `MOTION-...` 并标清与主版关系）、`VID-17`（多图参考固定编号顺序防串图换脸）、`VID-19`（项目要求的固定触发词在台词定界外原字保留）、`VID-20`（合生组内成员共用空间与设定且不改子镜起止；跨镜硬切连续动作续接基于实看上段成片或真实末帧并以分镜起点为准）、`VID-22`（可复制正文纯净无内部编号/路径；防字幕负面词按模型与文字风险按需添加，**不因无文字风险镜头未写禁字幕套话扣分**）、`VID-24`（允许图生视频在分镜基础上按目标模型合理增减静态设定板或承接帧，并按 `用途` 组合准确转换输入模式）。
- **纸面风险提示与实看归因**：已挂参考图却大段复述静态外貌、底图带杂字未清理、对口型与 `[VO]` 闭嘴打架、单镜无故混入背景音乐或打戏同段多人齐出招等提示走样风险（属 `craft_default` 建议，不单独触发 `REVISE`）；已有看片反馈印证时按 [成片看片与返工分流指南](generated-media.md) 定级分流。
