# 整集与多集还原

## 产物放哪、能交给谁

- 按 [阶段契约](stage-contract.md) 核对 `BRK-01`（未登记允许外传时只做本机测量，不调用外部看片模型）与 `BRK-02` / `BRK-11`（`study` 仅供本技能提炼机制与同尺对照；`owned` / `licensed` 可复制为独立新项目，不得合并进外层项目剧集）。
- 先建好 `输入/对标/<REF-ID>/还原/`，再用 `$short-drama` 在该目录下单独初始化项目（项目编号与外层项目不同，标题写 `<REF-ID> 还原`，不写对标剧名），再写入 `项目开发/`、`设定集/`、`剧集/EP001/` 五份文件。

## 看片通道

使用支持同时读取视频画面与音轨的多模态看片工具（仅在登记允许外传或本机离线模型下使用）：

- **目录隔离**：每次调用放入独立的新空目录（只放当前集 `ep.mp4`），防止前次上下文串入。
- **音轨实测**：先裁掉字幕区剪十几秒片段让模型逐字转写并给时间，验证模型确实能接收音轨（部分多模态模型只收画面不收音频；模型自述是否收到音轨不可信，以实测为准）。
- **输出约束**：提示中要求只根据该视频回答、不运行终端命令、只输出单个 JSON 代码块；收到后只修 JSON 语法，不改内容。失败或限流时换新目录重试（最多 3 次）。

## 每集流程

### 1. 测量

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure <各集.mp4> --out 输入/对标/<REF-ID>/measure
python3 {技能目录}/scripts/breakdown_tool.py audio <各集.mp4> --out 输入/对标/<REF-ID>/audio
python3 {技能目录}/scripts/breakdown_tool.py subtitle-sheet <两三集.mp4> --out 输入/对标/<REF-ID>/subtitles
python3 {技能目录}/scripts/breakdown_tool.py subtitles <各集.mp4> --out 输入/对标/<REF-ID>/subtitles \
  --band <左,上,右,下> [--color <字色>] --audio 输入/对标/<REF-ID>/audio
python3 {技能目录}/scripts/breakdown_tool.py shots <某集.mp4> <某集.measure.json>
```

- **校准字幕区与字色**：先用 `subtitle-sheet` 生成带比例刻度的 `subtitle-sheet.jpg` 与 `subtitle-rows.json`（记录各高度带描边字出现率 `shown` 与变化率 `changed`）。框定 `changed` 明显大于 0 的对白字幕区（上下留约 0.02 余量，避开 `shown` 高但 `changed` 近 0 的水印台标及名条/系统面板）；黄字或彩字用 `--color` 指定六位十六进制色值（如 `FFD400`）。首集样式不同时单独指定。
- **扫描字幕与自检**：`subtitles` 按集运行（勿跑拼接长母版），输出每句起止时间（精度约 0.1 秒）与裁图。检查结果中的 `voiced_shown_share`（有声时间字幕覆盖率，烧录字幕剧通常为 0.5–0.8）：若低于 0.3，检查区域框或字色是否偏离，或是否为细描边字幕（细描边易将一句拆成多段，读裁图时合并文字相同的相邻段）。
- **音轨与逐镜切片**：`audio` 输出有声区间与响度（用于判断监控时间、文件特写等画面文字是否有人念）；`shots` 按测量切点切出每镜小段与首/中/尾三帧，并列出镜内低阈值候选切点（`frames > 1` 多为闪光/粒子/快摇，单帧候选多为漏检硬切）。

### 2. 整集听看一遍

整集交模型提取：
- `lines`：每句台词（含系统音、旁白、群声）的起止时间、说话人、发声方式（画内/OS/VO/系统音/电话）、逐字台词、情绪及置信档位（字幕实录 / 音轨与字幕互校 / 推断）；
- `characters`：编号、名字与证据来源（名条/台词称呼/字幕/系统面板/推断）、外形、服装、随身道具、声音特征、首次出现时刻；
- `scenes`、`props`、`on_screen_text`、`sfx_music`、`beats`、`opening`、`ending`（是否断在半句或半个动作）与 `style`。

### 3. 逐镜看一遍

另开新空目录，将实测镜头编号与起止时间（到 0.01 秒）、镜内候选切点及上一遍的人物编号交模型，提取每镜的景别、角度、运镜、主体、站位与视线、动作（起始→过程→结束）、表情、对应台词、画面文字、光效、转场、镜内切及具体首尾帧描述（作为关键帧提示词底稿）。

### 4. 对齐与自查

- **台词时间以字幕为准**：有字幕的句子改用 `subtitles` 起止时间（模型时间常早 0.3–0.6 秒），无字幕或仅在面板出现的句子保留模型时间并标为推断（`BRK-12`）。
- **台词文字与归属**：读字幕裁图与音轨逐句核对（剧本按音轨纠正同音错字，字幕原文另存并注明；每集至少抽 5 处台词中点核对裁图）；台词归属按台词起止与镜头区间求交重算。
- **切点与人名核实**：模型报的镜内切点与候选切点吻合的抽帧确认后记为镜内切，不吻合的列出交人判断，不自动增删；不足 0.2 秒的碎镜单独标出。无名条、称呼或字幕证据的名字一律不用，改用身份称呼并注明（`BRK-12`）。

## 跨集衔接

1. **统一身份**：全系列每个真实人物唯一编号，记录各集局部编号映射依据（台词/造型/推断/未决）及名字首次确认的集与时刻。
2. **接缝表**：记录每对相邻集的上一集末句与末帧、下一集首句与首帧、是否断在半句/半动作、是否重放结尾及跨集延续状态。若后续各集时长完全相同（长母版定长切分），先按连续母版还原再按集界切回。
3. **连续性漏洞**：原片道具形态不一、数值矛盾或交代缺失处如实列出并原样还原，不擅自修补。

## 写成套件文件

按各阶段负责技能的格式写入 `还原/` 下的 `项目开发/`（分集地图、系列大纲）、`设定集/`（风格圣经、声音说明）与每集五份文件，并遵守：

- 剧本台词逐字按序，标明 VO/OS/系统音与 `[画面文字]`；原片消音（哔声）或符号遮蔽词在对齐记录中注明，写入《剧本.md》与下游提示词时替换为字数、语气相近的可播词。
- 每条实测镜头对应一条分镜（时长取实测值，镜内确认切点写入说明）；从上一集半句承接开场的如实注明来自接缝表。
- 关键帧提示词复用 `设定集/` 造型锚点；三维国漫等风格化画面视频提示词统一写为挂起始帧的图生视频。

### 拿还原去出片（`owned` / `licensed`）

将还原项目交下游技能生成关键帧、视频与剪辑成片（产物仍放 `输入/对标/<REF-ID>/` 下）时：

- **修正原片不成立的空间与滞留人物**：原片空间缺失功能区、门窗柜台前后跳位或戏完未退场人物不带入生成；保留节拍、镜头职责与台词，交 `$short-drama-assets` 与 `$short-drama-storyboard` 重设合理空间与退场动线，改动单列于 `审查/`。
- **镜内切拆成单镜**：出片时按分镜说明里的镜内切点拆成单镜，否则生成出来只剩一个连续镜头；一秒上下的眼、嘴、手或道具特写是情绪重音，单独成镜，不并入相邻镜。
- **对齐节拍而非硬凑秒数**：生成模型开口晚、语速慢且需留反应，验收看节拍、台词与镜头职责，不为凑原片时长硬切反应或整段提速。
- **审片附带分镜**：用模型辅助审成片时一并提供还原项目的《分镜.md》，区分生成偏差与原片固有拍法（如内心独白嘴不动、背对镜头喊人）。

## 保真度核对

还原完成后用原片回测，结果写入还原项目的 `审查/`：

| 核对项 | 做法 | 口径说明 |
|---|---|---|
| 台词字错率 | 抽约 40 句读台词中点字幕裁图，与剧本逐字比对 | 按音轨纠正字幕错字、替换消音/遮蔽词单列为有意差异 |
| 漏句 | 抽 2 集以上，比对 `subtitles` 事件数与剧本台词数 | 无字幕群声与面板系统音单列统计 |
| 节奏 | 按实测语速设节奏档案（含拉丁字母如“c级”时需同时声明字速与词速），用 `plan` 与原片 `measure` 比首句时刻与有声占比 | 分镜照搬测量切点时，镜数与镜长必然一致，不作证据 |
| 画面幻觉 | 抽约 15 镜核对首/中/尾三帧的景别、身份、动作方向与画面文字 | 重点核查集界第一镜（易将上一集尾镜延续误认为反打人物） |
| 接缝与人名 | 逐对核对相邻集开头是否接上接缝表；列出所有名字的证据来源 | |
