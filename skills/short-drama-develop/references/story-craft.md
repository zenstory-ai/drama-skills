## 1. 使用方式与规则分级

在制作 `creative-brief.md` 与 `story-engine.md` 时使用本文件。它提供决策问题，不替创作者选择题材、结局或风格。

四类规则的权限不同：

| 分类 | 适用内容 | 谁可以执行 |
|---|---|---|
| `structural_invariant` | ID、引用、已声明事实、显式矛盾 | 本地校验器可以阻断 |
| `reviewed_invariant` | 承诺是否成立、升级是否真实、行动是否可信 | 审查者引用证据判断 |
| `craft_default` | 通常能减少空转的创作做法 | 创作者可说明理由覆盖 |
| `taste_option` | 题材、弧线、钩子、叙事气质 | 只呈现选择，不阻断 |

规则标签只约束如何判断，不把审美变成机械评分。

## 2. 从题材词到戏剧承诺

“复仇”“甜宠”“悬疑”“家庭冲突”只说明货架位置，没有说明观众每次回来会得到什么。

先回答五个问题：

1. **主体**：观众跟随谁承受压力、作出选择？
2. **追求**：这个人现在想得到、守住、查明或摆脱什么？
3. **昂贵阻力**：谁或什么能让追求持续付出代价？
4. **独特矛盾**：主角最有效的策略为什么同时会伤害自己珍视的东西？
5. **反复回报**：每一集观众期待看到哪类局面变化——夺回主动、识破谎言、关系靠近、身份暴露、道德抉择，还是别的？

把答案压成一句可检验的工作陈述：

> 当【主角】用【惯常策略】追求【当前目标】时，【对抗机制】迫使其付出【核心代价】；系列反复兑现【观众回报】，直到【终止性转变】发生。

这是一张检查表，不是文案格式。自然语言可以完全不同。

**`craft_default · STY-01`**：戏剧承诺同时包含主体、追求、昂贵阻力和反复回报。缺一项时，后续常退化成题材标签或事件清单。

**`reviewed_invariant`**：实际分集必须能提供承诺过的体验。审查者应引用分集或剧本证据说明兑现/背离，不能只说“不够抓人”。

**`taste_option · STY-06`**：回报可以外放、克制、温暖、残酷或含混；主角也可以胜、败、误判或拒绝行动。

### 回报词本身不构成承诺：要写清它落在哪里

"后悔""复仇""守护""翻身"都只是回报的**名字**。同一个名字在不同观众承诺下，落点可以
完全不同，而落点决定了哪些事件算数、哪些事件白写。

以"让对方后悔"为例，至少有两种互不通用的落点：

- **落在关系上**：观众要看的是那个人意识到自己弄丢了什么，痛苦本身就是兑现，收束常常
  发生在一次无法挽回的告别或一句迟到的承认上；
- **落在地位上**：观众要看的是"没有我，你什么都不是"被当众证实，兑现必须是可核对的
  位置变化，仅有内心痛苦不够。

两种落点会挑走完全不同的事件。按第一种写却用第二种兑现，观众会觉得"赢了但不解气"；
反过来则是"解气了但不动人"。承诺阶段不写清落点，这个偏差要到中段才暴露，而那时纠正
的成本已经落在整条分集线上。

**`craft_default`**：写下回报的名字之后，再写一句它的落点——观众最后要看到的是关系
变化、位置变化、认知变化，还是别的什么。

### 回报要先有舞台，再有能力

观众期待的不是"主角获得了什么"，而是"获得之后，那些人会怎样"。在关系、家庭、复仇这类
靠积累兑现的题材里，这决定了铺垫顺序：**先建立回报会被花掉的场合，再让主角拿到能力**。

顺序颠倒的典型症状是能力先到位，然后临时找一个人来被打脸——这一段无论写得多热闹，
观众都没有攒下期待，因为在能力出现之前，他们并不知道该盼什么。

可用的检查：在主角取得关键优势之前，观众是否已经认得**具体的人、具体的场合、具体的
那句话**？三样里至少要有一样是先立起来的。

系统流、重生穿越、逆袭这类爽文不同：观众为奖励本身而来，奖励可以先到，被打脸的人和场合
可以在同一场里立起来。这时要保的不是先后顺序，而是对手的压迫到位，写法见对应的
[题材卡](genre-cards.md)。

**`craft_default`**：让能力、证据或身份的兑现落在此前已经建立的对象与场合上；确实需要
新对象时，先给它一段独立的建立，不与兑现同场发生。爽文题材的建立与兑现可以同场。

### 承诺的压力测试

- 如果换掉人物姓名和职业，概念仍与大量故事没有区别，独特矛盾还不够具体。
- 如果对抗者只需解释一句话就会停止阻碍，阻力没有结构性。
- 如果主角不行动也能得到结果，追求没有戏剧主动性。
- 如果只有最终结局有回报，中间各集没有可兑现的体验。
- 如果每次回报都完全同形，系列缺少变化空间。

## 3. 设计能持续运转的冲突引擎

故事引擎不是“大反派不断使坏”，而是一个会对人物选择作出反应的压力回路。

### 3.1 写出一轮回路

按顺序描述：

```text
触发压力
→ 主角依据自己的信念选择策略
→ 对手/制度/关系作出有能力的反制
→ 主角得到局部结果并承担新代价
→ 权力、信息、关系、暴露、资源、时间或身体状态改变
→ 新状态制造下一轮更难的选择
```

如果删掉“选择”与“代价”仍能发生相同剧情，这一轮主要靠作者搬运事件，不是人物驱动。

### 3.2 检查引擎的六个部件

| 部件 | 开发问题 |
|---|---|
| 压力来源 | 哪个角色、规则、秘密、资源限制或关系义务会反复施压？ |
| 对抗能力 | 它为什么真的能阻挡主角，而不只是态度恶劣？ |
| 主角策略 | 主角通常怎样解决问题？该策略的优点和盲区是什么？ |
| 退出成本 | 主角为何不能离开、报警、坦白或轻易换目标？ |
| 变化空间 | 压力能在哪些状态维度改变，而不只是声量增加？ |
| 终止条件 | 什么事实、选择、关系或能力变化会让旧回路无法继续？ |

**`craft_default · STY-02`**：让压力来自多种相互作用的来源，例如人物意志、关系义务和现实约束。单一坏人若没有筹码，往往只能重复阻挠。

**`reviewed_invariant · STY-03`**：升级需要改变故事状态或后果。审查者要指出升级前后哪项状态发生变化；“更生气、更吵、更危险”若没有新的能力、知识、代价或决定，不足以证明升级。

**`taste_option · STY-06`**：引擎可以是追逐、谈判、秘密维持、关系拉扯、任务解决、身份错位或日常困境；不要求同一种商业套路。

### 3.3 给引擎留出变化

同一承诺可通过改变以下变量产生新局面：

- **权力**：谁能决定规则、分配资源、定义事实；
- **知识**：谁知道什么，谁只知道一半，谁掌握可验证证据；
- **关系**：信任、债务、依赖、联盟和边界如何移动；
- **暴露**：秘密被谁看见，公开范围和被利用方式如何变化；
- **资源**：时间、场地、证件、金钱、工具或帮助者是否可用；
- **物理状态**：距离、伤势、持物、封闭空间、天气等怎样改变行动能力；
- **道德成本**：要赢这一轮，主角必须变成怎样的人或伤害谁。

变量不是待填满的清单。每一轮只选对当前选择真正有影响的维度。

## 4. 让人物成为压力的制造者

角色小传不应只列年龄、性格与外貌。开发阶段更需要能预测选择的“行动模型”。

为主要人物写：

- **表层目标**：此刻想让什么发生；
- **保护对象**：即使失败也不愿失去什么；
- **自我解释**：他怎样证明自己的行为合理；
- **惯常策略**：控制、讨好、试探、撤退、公开、交易、冒险等；
- **筹码**：能提供或剥夺什么；
- **盲区**：对自己、他人或局势持续看错什么；
- **底线与越线条件**：什么不会做，什么压力可能迫使他做；
- **可变事实**：哪项认识或关系变化可能改变其策略。

### 4.0 观众为什么站在他这边

上面八项回答的是"他会怎么选"，全部服务因果预测。它们答不出另一个问题：**观众第一次
看见这个人时，凭什么替他着急**。一个只有压力、策略与代价的人物是**可分析的**，不是
**可跟随的**——这是"结构正确但没人看"最常见的产地：第一集看完，观众知道发生了什么，
却不知道该替谁紧张。

为焦点人物再答四问，答案要能落到第一集的可见画面上，不是形容词：

- **他正在承受什么不该由他承受的东西**？ 不公要具体、要可见——被顶掉的署名、被改的
  排班、当众被拿走的东西。观众的立场来自看见不公，不来自被告知他是好人。
- **他正在替谁扛**？ 替自己扛容易变成执拗，替一个具体的人扛才有牵引。那个人最好在
  第一集出现过，哪怕只有一个照面。
- **他想要的那样东西，观众自己是不是也想要**？ 尊严、被认出来、把一件事做完、护住
  一个人——观众能代入的欲望，比"复仇"这类抽象目标更早生效。
- **他有什么本事是观众想借来用一次的**？ 不必是金手指。看穿谎言、修好别人修不好的
  东西、在难堪的场合仍然体面，都算。这决定观众是**同情**他还是**想成为**他。

四问不必全答，但**至少要答出一条，并且它要在第一集就能被看见**。答不出来时，人物仍
可以是精确的，只是没人会跟着他走完六十集。

反面提醒：这四问不是"把人物写讨喜"。让人物一直正确、一直被善待、或者一上来就赢，
反而会同时取消不公与欲望，观众没有可替他争取的东西。可跟随来自**他想要而尚未得到**，
不来自他可爱。

### 4.1 关系不是标签，而是双向压力

不要只写“母女”“上司下属”“旧恋人”。写成两个方向：

```text
A 需要 B 提供什么 / 害怕 B 看见什么 / 用什么约束 B
B 需要 A 提供什么 / 害怕 A 拿走什么 / 用什么反制 A
```

同一个关系中的爱、债、羞耻、利益和身份可以同时存在。场景冲突来自这些力量当下无法兼得。

**`craft_default`**：让关键人物拥有独立目标和可用筹码，而不是只负责给主角递线索或制造障碍。

**`reviewed_invariant`**：关键选择应当能从人物当时掌握的事实、目标与压力中解释。审查者引用选择前的证据，不以“正常人不会这样”替代分析。

**`taste_option`**：人物可以稳定、成长、倒退、自欺或拒绝改变；变化方向由创作者决定。

## 5. 用状态变化判断升级

### 5.1 先写前后状态

对计划中的主要事件，不先问“够不够炸”，先问：

- 事件前谁占主动，事件后谁占主动？
- 新获得或失去的事实、证据、盟友、资源是什么？
- 哪段关系变得更近、更远或更不平等？
- 哪个选择现在不可撤回？
- 下一步为什么比上一步更难、更贵或更暴露？

### 5.2 区分四种常见运动

- **扩张**：同一矛盾影响到新的关系、场域或责任；
- **反制**：对手学习主角策略并封住原有路径；
- **代价落地**：先前选择的损失现在真正发生；
- **意义改变**：新证据让旧事件获得不同解释，但不抹去已发生事实。

转折不是必然等于秘密揭晓。一次拒绝、联盟变化、证据失效、承诺兑现或人物主动改策，都能改变方向。

**`craft_default`**：主要转折优先来自角色选择与此前压力的后果，偶然事件适合开启问题，不适合替人物解决核心困境。

**`taste_option`**：有的系列依靠剧烈位移，有的依靠微小但不可逆的关系变化；变化幅度服从作品气质。

## 6. 管理信息、证据与兑现

### 6.1 分开事实与认知

维护四个问题：

1. 世界中实际发生了什么？
2. 每个角色相信什么，依据是什么？
3. 观众知道什么，何时知道？
4. 哪个可见证据能改变某人的判断？

这样能避免“作者知道，所以角色也知道”或“说出秘密就自动可信”。

### 6.2 铺垫记录的是义务

一条铺垫至少记：

- `setup_id` 与首次出现位置；
- 观众当时自然会怎样理解；
- 它承诺回答的问题或造成的期待；
- 计划兑现方式；
- 若不兑现，是有意悬置、改义还是遗漏；
- 改写后哪些分集会受影响。

**`structural_invariant · STY-05`**：被引用的进入状态、铺垫、兑现与分集 ID 必须存在，或明确标为未解决。校验器只判断引用关系，不判断揭示是否精彩。

**`reviewed_invariant`**：揭示不能凭空发明先前不存在的决定性事实；若改变旧事件意义，审查者应引用旧证据与新解释，判断二者是否相容。

**`craft_default`**：兑现不仅回答问题，还让人物当下作出新选择或承担后果。纯解释会停止运动。

**`taste_option`**：观众可以早于、晚于或同步于角色知道真相；悬念、惊讶和共谋感是不同体验。

## 7. 让主题进入选择

主题不是角色替作者宣读的结论。把主题写成无法同时满足的价值：

- 诚实与保护是否能兼得？
- 被看见与保持自主是否冲突？
- 规则公平与个体补偿谁先？

然后把价值放进有代价的选择。不同人物用行动给出不同答案，剧情后果继续追问，而不是立即宣布谁正确。

**`craft_default`**：至少让核心冲突同时触碰外部目标与人物珍视的价值，胜负才不会只剩流程。

**`taste_option`**：作品可以给出明确立场、矛盾结论或开放余味。

## 8. 生成真正不同的方案

方向探索时，用“机制差异表”比较，而不是写几段同义文案：

| 维度 | 方案甲 | 方案乙 | 为什么会产生不同剧情 |
|---|---|---|---|
| 主角惯常策略 |  |  |  |
| 主要对抗机制 |  |  |  |
| 退出成本 |  |  |  |
| 反复回报 |  |  |  |
| 核心道德代价 |  |  |  |
| 引擎终止条件 |  |  |  |
| 制作负担 |  |  |  |

若各列只更换职业、地点或秘密名称，重新设计。创作者方向已明确时，不需要强行产出多个方案。

**`craft_default`**：比较方案时同时写“它擅长提供什么”和“它会牺牲什么”，避免所有选项都被包装成最优。

**`taste_option`**：创作者可以选一个、组合兼容部分，或拒绝全部方案；记录其理由以保护后续修订。

## 9. 从引擎走向分集

故事引擎准备好进入分集规划时，应能回答：

- 第一集开始前，压力为什么已经活跃？
- 主角第一次选择如何暴露其策略与盲区？
- 哪些状态维度有足够变化空间？
- 哪些铺垫有明确的兑现责任？
- 系列终止条件与当前人物距离多远？
- 视觉、场景、角色规模是否符合创作者边界？

然后转到 [episode-design.md](episode-design.md)。不要从“要多少集”倒推出重复事件；先设计必要的状态台阶，再由创作者的形式约束决定如何分集。

## 10. 合成示例

以下例子只演示机制，不是答案模板。

> **起点**：老城区一家共享厨房即将关闭。负责排班的年轻厨师想保住所有摊主的位置，却一直靠私下调换时段解决冲突。

题材词只是“职场/群像”。更可用的承诺是：

> 她每次用隐瞒和临时协调替弱势摊主争到喘息，都让公开规则更不可信；观众反复看到她用现场解决能力夺回局部主动，也看到被保护者开始要求发言权，直到她必须选择由自己控制还是让众人承担真实决定。

引擎部件：

- 压力来源：有限灶位、互相冲突的生计、即将到来的物业审查；
- 主角策略：暗中调整、先解决再解释；
- 反制：摊主根据不透明排班争夺关系，管理方以混乱为由收权；
- 退出成本：她的家人也依赖厨房收入，且过去承诺会保住团队；
- 变化空间：谁知道排班真相、谁能定义公平、联盟如何移动；
- 终止条件：排班权从个人保护转成可承担后果的共同规则，或厨房彻底失去自治。

一个**重复而不升级**的事件是：又有摊主因排班迟到，大家再次争吵，主角再次调开时段。

一个**产生状态变化**的事件是：她为保护新摊主删掉一条换班记录；被挤掉的老摊主拿着自己的订单证明公开质问。此后问题从“如何排开”变成“谁有权改记录”，主角的可信度与管理方筹码同时变化。

例子没有规定必须如何结局，也没有要求秘密揭晓或固定位置的转折。

## 11. 失败征兆与审查问题

### 失败征兆

- 概念只有题材标签、身份噱头或结局愿望；
- 对手没有筹码，只能不断升级恶意；
- 主角靠等待他人救援获得核心结果；
- 所有事件都能互换顺序，选择没有后果；
- 每一轮只是同一种羞辱、误会、争吵或营救；
- 铺垫只用于延迟说明，不改变人物选择；
- 人物关系只有标签，没有双向需要与制约；
- 未选方案被悄悄当成既定事实；
- 形式配方取代了作品自己的因果与气质。

### 审查问题

审查者应引用具体字段或分集记录回答：

1. 承诺的回报在计划中哪里被实际兑现？
2. 主角的策略怎样同时产生能力与代价？
3. 对抗者在哪些地方根据新状态作出有效反制？
4. 相邻升级改变了哪项状态，为什么不可简单复位？
5. 揭示使用了哪些已有证据，是否改义而非改写事实？
6. 主题如何通过选择与后果出现，而不是口号？
7. 哪些是创作者选择，修订有没有擅自替换？

审查结论属于单独的审查动作；开发者只能据证据修订自己的文件，不能把修订本身冒充 verdict。
