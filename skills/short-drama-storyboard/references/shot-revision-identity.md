# 镜头修订与稳定身份

`SHOT-...` ID 代表同一个导演决定的连续身份，不等于列表位置或外部任务编号（`SHT-20`）。修订时按叙事职责是否仍是同一个来决定：

- **重排**：顺序改变但镜头目的与边界职责不变时保留原 ID，刷新相邻边界。
- **插入**：新增独立注意或戏剧职责时创建新 ID，不重排后续镜头编号。
- **内容修订**：同一镜头目的下调整构图、走位或边界，保留原 ID。
- **拆分 / 合并**：原镜头被多个独立职责取代，或多个旧镜头合并为一个新决定时，停用全部旧 ID、创建新 ID，并在 `分镜.md` 修订说明中列出前身与后继（不把旧 ID 偷给其中一个子镜）。
- **恢复**：已停用的 ID 不复用于无关镜头。

拆分、合并或重排后，同步核对原文落实、场景站位、相邻起止边界、单集总时长及下游 `MOTION-...` / 多镜分组引用；旧 ID 仅保留在修订说明中。
