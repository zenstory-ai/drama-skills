# 通用资产图片提示词配方

## 1. 八段式编写顺序（`IMG-01` / `IMG-02`）

每条 `IMG-...` 先指向 `视觉设定.md` 中已确认的条目与当前变体（未决身份不写提示词），按信息保真优先级组织正文（省略不适用项，不写段落小标题或内部字段名）：

1. **用途与主体**：指明人物设定板、场景空镜、道具参考板、状态变体或局部修改，以及主体是谁。
2. **稳定锚点**：跨造型/跨视角不变的可见形状、比例、相对位置与材质特征（不用“漂亮、奢华、高清、电影感”代替识别证据）。
3. **版本差异**：仅写本次造型、视角或状态相对基准版本的可见变化。
4. **构图与尺度**：视角、画幅占比、方位关系与中性尺度参照（不引入无关剧情角色作尺度参照，也不为了好看搬动门窗）。
5. **材质、色彩与光线**：表面质感、主次色关系、主光方向与明暗逻辑（参考板默认优先清楚可比较的均匀光，风格可覆盖）。
6. **背景/舞台政策**：干净中性背景、环境内展示或 `empty_stage`（说明是否允许人群、手或支架）。
7. **文字与功能**：按下方两层文字映射写明呈现方法与功能结构可见方式。
8. **排除与保留**：针对高风险误读的负面约束（如“不要混入第二套制服”“空场无演员”），不用“不要模糊、大师杰作”套话，且排除项不得否定必需项（如要求旧铜锈又排除一切磨损）。

## 2. 文字政策两层映射（`IMG-07`）

文字分两层管理：上游 `视觉设定.md` 决定**资产来源政策**，本阶段选择**提示词呈现方法**，不得越权放宽映射，也不得让 `readable` 与全局禁字（`no_text`）并存：

| 资产来源政策（`视觉设定.md`） | 允许的提示词呈现方法 | 正文编写要求 |
|---|---|---|
| `exact_readable` | `readable` 或 `postproduction` | `readable` 逐字引用已确认字符、位置与承载面；`postproduction` 预留无遮挡、透视清楚的承载区，正文不要求生成字（无正式字形资产的签名等同样走 `postproduction` 或阻断 `readable`，不伪造笔画） |
| `graphic_only` | `symbolic` | 保留标签/印记的版式与图形轮廓，明确不出现可辨文字、姓名、号码或网址 |
| `no_readable_text` | `blank` 或不可读的 `symbolic` | 承载面保持空白或纯图形，严禁生成任何可读字符 |
| `pending_creator_text` | `postproduction` 暂存，或阻断 `readable` | 不猜文字；保留未决说明与受影响的 `IMG-...` / `SHOT-...` |

## 3. 参考图槽位与像素准入（`IMG-08` / `IMG-09` / `IMG-12` / `IMG-14`）

- **单图单槽与槽位稳定（`IMG-12`、`IMG-14`）**：`- 参考：` 语法与九项封闭 `用途` 词表见 `SKILL.md`（资产板通常用前六项与 `风格`，`起始帧` / `结束帧` 归镜头；严禁写“全参考”）。同一张图在一项条目中只占一个槽位：兼顾两件事时，`用途` 填主要职责，次要职责写入 `控制`；换图时在原槽位更新路径，重排顺序不改槽位 ID。
- **控制边界（`IMG-09`）**：
  - `身份` 参考不自动决定姿势、构图或临时造型；
  - `构图` / `尺度` 参考只借占比、机位侧、留白或相对尺度，不得带入参考图内的人物、文字或事件；
  - `效果` 参考只控制目标区域的形态与范围，不使非目标对象变形或消失。
- **像素准入与文字风险检查（`IMG-08`）**：
  - 仅在创作者提供可核对画面说明（`creator_described`）或运行环境获授权检查图片像素（`visually_inspected`）时，才能声称参考图无文字/水印残留；未获授权或仅见文件名时保持 `unverified`。
  - **负面提示词（“不要文字”）不能清除参考图已有的标牌、界面、水印或字幕残留**：若参考图与文字政策冲突，必须先裁切、清理、遮罩、替换或改走 `postproduction`。
