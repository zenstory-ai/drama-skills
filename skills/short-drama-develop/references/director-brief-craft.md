# 导演阐述工艺：拆分/分镜前的项目级指令

导演阐述由创作者在拆分/分镜之前确认，明确全剧后续工作的分镜格式、摄影职责、节奏方向和已知能力条件。本技能在 `项目开发/director-brief.md` 中起草候选并展示 `visual_direction` 与 `production_profile` 的语义差异，经创作者接受后由 `$short-drama` 写入 `short-drama.json#/creator_authority`。

## 基础写法

```text
你负责把《剧名》已确认的剧本和设定编成可审查分镜。先读取创作者已接受的题材承诺、
人物视角和 `production_profile`；保留行动顺序、信息权限和逐字对白。若视觉实现需要
改变上游事实，提出带证据引用的修订请求，不在下游私自改写。
```

## 可选写法（按场景选用，可组合）

### 可验收约束型（项目需要稳定规格时）

每条规则须说明保护哪项上游必保内容、什么证据允许例外，并在交付文本和制作结果中可验证：

```text
【本项目接受的约束】
- 空间：当观众尚不能定位入口、人物或冲突区域时，先建立完成当前理解所需的地理；
  上游材料有意延迟识别或前镜已经建立时，不补仪式化全景。
- 身份与状态：同一人物绑定已接受的固定身份特征（`identity`）与本段有效造型（`Look`）；有来源的换装、伤损
  或伪装走状态变体（`variant`），无来源漂移不得进入。
- 连续性：相邻镜逐字段比较手、朝向、持物、位置与可见状态；跳时、蒙太奇或有意
  断裂按上游授权记录，不用“必须补过渡”抹掉剪辑意图。
- 对白与反应：切镜由意图、权力、信息或选择的变化决定；只有听者要承担后果时，才要
  给他的外显反应留出画面空间，景别和停留由表演与节奏决定。
- 结尾：先完成本集结果，再保留由结果启动的压力；特写、定格、切黑或不断镜
  都是候选拍法，不预设一种收尾动作。
```

色温/光比、留白、节奏停顿、同场动作、反应安排和台词量等具体数值只能来自本项目试跑与创作者选择（台词量从镜头时长、语速与动作反推；多人同镜要求指代可唯一解析）。

**服装、光影、构图分别决定参考权限**：参考图只负责已声明的参考用途（`role`），提示词只补当前容易漂移的局部事实（如同一镜用身份参考控脸型、用 `Look` 参考控服装、用文字说明本镜光向）。

### 单集导演阐述型

适合首集、大结局或转折集单独加写：说明本集在全剧的位置、必须改变的状态、分场注意力或节奏转折依据，不必凑齐固定栏目。

### 风格速记型（多项目复用）

用简短文字记录已选方向及适用条件：

- `追逐段以方向清楚和呼吸受压为主；只有行动转向或风险位置变化时切镜。`
- `审讯段保持冷硬侧光；若证据需要可读或人物选择需要停留，优先保证信息承载。`

### 按已知制作能力写表演（项目已有证据时）

只将创作者已提供并接受的测试记录写进 `production_profile`（无测试记录时保留供应商无关的通用表达，不跨项目移植或猜测参数）：

- **可观察表演**：情绪词至少用与人物和触发相符的准备动作、面部微动作、肢体联动或重心变化承载；
- **记录失败条件与替代方式**：写清哪种表达在什么镜头、参考条件和制作方案下不可执行及可观察替代（不汇成跨题材禁词清单）；
- **权力反转**：先确认旧权力如何成立、什么证据使其失效、谁接收后果，再选同镜、反应镜或群体状态变化。

### 跨集人物弧线（长篇项目可选）

阶段数与边界来自人物选择、关系或信息权限的实际门槛；每阶段绑定有效范围、镜头语言职责与节奏目的（手持、平行蒙太奇、升格或首尾呼应仅在承担该节点职责时进入，不按固定集区间切块）：

```text
阶段：公开同盟开始破裂后，直到主角主动承担代价
镜头语言职责：把多线压力汇到同一选择；只有注意力或风险位置改变时加速切换。
节奏目的：从被动防守收紧到不可撤回的决定，并保留决定后的反应时间。
```

## 反模式

1. **把剧本塞进导演阐述**（整集原文塞进指令字段）——指令与内容混流。
2. **空泛形容词**（“画面高级有电影感”）——无法拿着成片判定是否遵守。
3. **无证据的能力规则**——从其他项目复制禁词、并发量或镜头配方，覆盖当前人物和已确认内容。

## 拆分参数配套

- **按集拆分**：明确本集戏剧结果、代价与后续压力；文字量从目标时长、语速、动作和停留空间反推。
- **按字数拆分**：容易切断场景目标、行动转向或反应职责；若采用须在切点复核场景与交接内容。
