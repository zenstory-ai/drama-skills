# 题材条件与钩子手册

本手册负责**跨题材的比较**：同一条轴线上，不同题材怎样分岔。单个题材的执行细节（具体场面细节、集尾钩子取向、前中后期推进方式、特有制作成本）拆在 [genre-cards.md](genre-cards.md) 索引下的题材卡里（一次只读一张）。先用本手册比较压力机制，再用题材卡校准场面与情绪落点。

## 使用方式：先看故事怎么运转，不先认标签

按六个问题确定故事推进方式（不相符时回到 [story-craft.md](story-craft.md)）：

1. **压力从哪里来**：规则、关系、证据、制度、空间、资源还是身体限制；
2. **人物怎么应对**：靠隐藏、照料、专业能力、权威、交易、逃避还是冒险解决问题；
3. **观众每集看到什么结果**：真相、关系、权力、路线、身份或生存条件怎样变化；
4. **谁知道什么**：谁知道、误信、怀疑，谁能把事情说出来或公开；
5. **观众具体看到什么**：哪个行为、物件、空间变化或群体动作能证明结果成立；
6. **制作难点**：哪些造型/状态、场景/方位、道具/状态、群体区域、必抄文字或镜头起止状态需持续追踪。

## 不同题材怎么推进

| 题材方向 | 压力怎样持续 | 每段先给什么结果 | 制作时必须拍清什么 | 常见问题 | 题材卡 |
|---|---|---|---|---|---|
| 悬疑 / 规则恐怖 / 生存 | 安全规则逐步失效，可走的路、可用的时间和保护手段越来越少 | 查明一条能决定下一步的新事实，同时失去一条退路 | 门槛、路线、计时、有明确用途的关键道具、感官异常与受限身体状态 | 只把黑暗、噪声和形容词变强；旁白替代可见验证 | [悬疑规则](genre-cards/悬疑规则.md) |
| 家庭 / 照料 / 关系伦理 | 私人义务与自我保护互相冲突，经济/照料/名誉筹码可执行 | 关系边界、证据归属或公开地位改变 | 往复照料动作、便携证据、见证人分区、退出路径 | 群体重复谴责，人物没有新选择或执行能力 | [家庭关系](genre-cards/家庭关系.md) |
| 亲子 / 血缘揭示 / 认亲 | 关系尚未被承认，监护、抚养与就学就医的硬期限持续逼近答案 | 名分或责任真的落地：签字、称呼、接送、监护归属改变 | 签字与关系栏、接送与等待、可验证的检验流程、孩子自己带来的物件 | 孩子只负责卖萌撮合，没有自己的目标；血缘结果自动等于情感结果 | [亲子隐秘](genre-cards/亲子隐秘.md) |
| 古装 / 奇幻 / 婚恋 / 隐藏身份 | 礼制、阶序、阵营与公开选择限制关系 | 行为让隐藏地位或联盟获得新的公开解释 | 造型、随行层级、身份道具、入场方式、空间区域与知情者反应 | 奢华/寒酸形容词堆叠；突然报身份代替此前证据 | [古装权谋](genre-cards/古装权谋.md) / [仙侠修真](genre-cards/仙侠修真.md) / [豪门婚恋](genre-cards/豪门婚恋.md) / [破镜重圆](genre-cards/破镜重圆.md) |
| 职场 / 技术 / 轻喜剧 | 一个日常工作疏漏造成越来越具体的后果 | 别人能当场核对的修复结果，随后角色地位改变 | 必须照抄的技术名称、操作顺序、核对点、屏幕/设备状态与见证更新 | 同事先夸“天才”；通用屏幕特写；人人同一惊讶反应 | [职场喜剧](genre-cards/职场喜剧.md) |
| 复仇 / 权力反转 | 对手拥有真实手段，主角以证据、联盟或能力改变实际权力 | 一项旧权力失效并产生后果，而非只获得口头认可 | 证据链、公开场合、对手反制、受影响者的反应与代价 | 重复受辱—亮牌；身份揭示不改变任何人的行动空间 | [复仇打脸](genre-cards/复仇打脸.md) |
| 逆袭 / 系统流 / 重生穿越（爽文） | 对手的轻视或压迫当众落地，主角手里有对手看不见的底牌 | 奖励兑现或当众打脸，旁观者改口也算 | 对手当众做过的事、见证者分区、奖励的可见数值（屏显交给后期） | 奖励换成焦虑；删掉喜剧反应；第一次打脸拖到很多集后 | [逆袭](genre-cards/逆袭.md) / [系统流](genre-cards/系统流.md) / [重生穿越](genre-cards/重生穿越.md) |
| 动作 / 任务 / 冒险 | 地理、资源、时间与对手学习共同收窄可行路径 | 完成一个阶段目标并留下伤势、损耗、暴露或路线变化 | 轴线、出入口、距离、持物、能力边界、伤势与交接 | 动作更大但任务状态不变；同一镜承担过多力学阶段 | [动作任务](genre-cards/动作任务.md) |
| 身份错位 / 身体互换喜剧 | 外部任务迫使人物用不合身的身份、身体或权限解决现实问题 | 任务状态先改变，再让身份误读带来关系或地位余波 | 当前身份占用、别人如何识别、身体能力边界与多主体位置 | 设定梗不断重复，任务和人物策略没有进展 | [身份错位](genre-cards/身份错位.md) |
| 生活流 / 小人物 / 都市温情 | 一个具体小目标被来客、误会、匮乏或照料义务打断 | 小事被实际完成、放弃或重新理解，关系留下轻微但可见变化 | 日常物件、距离、手部选择、环境节奏与留白 | 套用真人爽剧的密集大特写和公开翻盘，压扁生活质地 | [生活流](genre-cards/生活流.md) |

混合题材须声明主要矛盾归属，并核对两套制作要求（如公开群戏 vs 封闭空间状态连续）是否冲突。召回规范与冲突优先级见 [genre-cards.md](genre-cards.md)；首集入口与集尾钩子设计见 [episode-design.md](episode-design.md)。

## 提前写清制作难点

候选方案旁同步标明制作负担：**状态数量**（跨镜/跨集复用的道具、伤势、造型、证据版本）、**空间**（需区分方位的场域）、**群体**（常驻角色、代表性见证者与背景人群）、**文字/声音**（可读、图形化、`[VO]`/`[OS]` 或后期叠加）、**动作**（需拆清起止状态的力学或操作段落）。
