# 短剧分集架构、反转留钩与节奏设计

编制多集连载大纲（`episode-map.jsonl`）、拆单集节拍、设计揭秘反转与集尾悬念，或拟定项目节奏目标时使用本文件。故事核、矛盾引擎与人物弧光见 [故事核与人物开发](story-and-character-craft.md)；规则分级与 `STY-*` 规则表见 [开发阶段职责与规则](stage-contract.md#本阶段规则)。

## 1. 单集结构与精简状态账（`episode-map.jsonl`）

每一集既要给观众一眼认得出的阶段结果，又要把全剧主线实打实往前拱一步：

```text
清楚的开集处境（承接上集 handoff_state）
→ 眼前危机逼着人物出手争取本集目标 → 出招撞上对手反扑并付出代价
→ 兑现本集阶段结果 → 具体的新决定、新险境或新疑点推向下一集 → 清楚的集尾落点
```

`episode-map.jsonl` 定位为**多集连载项目的按需轻量分集状态账**（轻量单集或迷你短篇直接在 `creative-brief.md` 写合一简纲即可）。每集一条扁平记录，只保留核心推进与单向交接给下一集的 `handoff_state`，不重复抄写上一集状态、不塞全剧人物弧光表或向审稿人自夸的小作文：

- **核心扁平字段**：`episode_id`、`title`、`goal`（本集主角想促成的具体变化）、`hook`（开场钩子）、`conflict`（当场对手筹码与反扑阻力）、`turn`（局势转折的具体可见动作）、`climax`（本集高潮与阶段兑现结果）、`ending_hook`（集尾悬念或舒缓收束落点）、`handoff_state`（交接给下一集开场的现场事实：知情/实权/关系/物理位置与正悬着的半截动作）、`setup_payoff`（本集埋下或回收的伏笔编号与说明，满足 `STY-05`）、`locations`、`characters`。
- 首集目标时长或高概念揭晓进度等特殊信息，仅在有需要时随集补充简短字段，无则不加。

## 2. 首集开篇切入与开场钩子

### 2.1 找准首集开篇切入点（`craft_default`）

优先切在同时满足以下条件最多的一刻：危机已烧到眉毛；主角惯用招数马上要露馅闯祸；单看动作、物件与对峙就能倒推前因；第 1 集能干脆打完一轮交锋见分晓；再往前是流水账、再往后会漏关键抉择。

原著开场已抓人时直接采用；拿不准时在三种切法中比选（冷开与前移重排的因果修补见 [改编重排](adaptation-craft.md#重排也要登记)）：

- **顺叙开场**：按事件先后最早能立住矛盾与关系处；
- **高光直入**：直接从冲突爆发或看点最强处切入，顺带亮明身份、处境与目标；
- **冷开切入**：先切后文重头高潮最抓人的一拍或揭晓前一秒，再回溯起因，前后靠同一人物、道具或场所咬合；中段在观众急问“凭什么”时切两秒极短闪回往往比片头长铺垫更利落。

### 2.2 开场钩子路数

钩子须顺应题材气质（详见 [多元开场与留钩语法](genre-and-hook-playbook.md#多元开场与留钩语法)）并直通本集戏眼，允许相邻集顺着同一危机链沿用同类钩子，不搞排班机械轮换：

- **行动钩**（正在干一失手即完蛋的险事）、**恶果钩**（上集决定转头反噬）、**穿帮钩**（嘴上话与露出铁证撞车）、**变脸钩**（熟人翻脸或强弱易位）、**逼宫钩**（当场二选一）、**漏底钩**（观众先瞥见颠覆认知的细节）。

开场调性、钩子形态、总集数与高潮位置服从创作者选定的体裁规格（`taste_option`）。

## 3. 揭秘、反转、兑现与集尾留钩

### 3.1 分清四种容易混淆的戏剧动作

- **信息揭秘**：得知早就存在的隐情（光把秘密嚷出来却无人改主意吃瘪，不算反转）；
- **局势反转**：砸下来的实情让原有算盘、借口或强弱站位当场报废；
- **情绪与爽点兑现**：观众盼着的打脸、甜虐、惊悚或暖心落到看得见的结果上；
- **集尾钩子**：冒出新决断、新险情或致命疑问推着局面往下走（故意把半句话吞回去硬切黑屏不算好钩子）。

以“追查亡母老宅拆迁款”为例：私下亮银行流水被继母冷笑敷衍只算**揭秘**；改为在祠堂宗亲大会上等继母发毒誓后当众投屏流水单揭穿其给弟弟付赌债首付，令族老变脸围逼继母，才打出**反转**；糊涂父亲哑口无言、族老押着继母交出房契与亡母木匣，砸实**爽点兑现**；当众掀开木匣却见里面空空如也、只压着离进炉熔毁仅剩两小时的当铺通知单，顺势甩出**集尾钩子**。

### 3.2 揭秘五筛与六种因果反转（`STY-09 · reviewed_invariant`）

**重磅揭秘先过五筛**：前文有无足够蛛丝马迹（如先提过巡检册装订细节，后文瞥见订书针孔反了才知中间责任页被抽）？此前谁能接触真相？为何偏偏此刻翻出铁证？堵死了哪句旧借口？谁因此再也无法按原计划行事？

**因果反转（`STY-09`）**：揭秘与反转必须从前文埋好的事实顺理成章推出，且至少推翻原有盘算、改写旧认知、扭转关系或逼出高代价抉择之一。六种耐看路数：

1. **赢局撞上合规后手**（亮旧账逼退对手，对方反拿“私泄内部台账”走规章冻权）；
2. **铁证坐实更痛真相**（查出刹车线动手脚，签字单却指向替弟顶罪的已故父亲）；
3. **护着的人当众不领情**（暗中兜底的老师傅不愿背走后门黑锅，当众站出反质问）；
4. **绝活撞上新盲区**（弃赛躲过台上抄袭套，对手转头在后台假摔拍错位视频）；
5. **盟友刚帮完就上门讨债**（请二叔压下堂兄，二叔转身拍出老宅过户字据）；
6. **钻死规矩漏洞反将一军**（对手锁婚书库房，主角亮旧宗规当场招婿破局）。

### 3.3 先兑现再留钩与付费卡点集（`craft_default`）

- **先喂肉再留钩**：常规连载集切黑留钩前，先砸实本集看得见的阶段兑现（救下谁、赢回哪口气、捅破哪层纸或关系挪位），再从刚砸出的结果里长出留给下一集的危机——“断了谁财路、露了谁马脚、新欠哪笔债”（单元温情剧可在完整情绪落点舒缓收束）。
- **付费卡点集（仅创作者指定时）**：设不设卡点、定在第几集全由创作者拍板（若主动问参考，首道常见约第 8–16 集、次道约第 25–30 集，随大爽点浮动）。卡点集捏紧三条：先兑现本集结果再把下波大爆发劈成两半卡在揭晓前一秒（台词钩或画面钩）；悬念全扣在观众熟知的人与赌注上（`STY-09`）；卡点前每集都有扎实兑现防劝退。

## 4. 前因后果节拍与画面落地

- **一拍戏答清六件事**：起因（接哪条事实）→ 人物诉求 → 当场阻力（对方筹码与反扑）→ 看得见的动作/物证/台词 → 处境变化（对比上一拍改了哪一项，`STY-03`）→ 推向下一拍的紧迫感。
- **“所以 / 但是”串读检验**：上下拍应能用“因为 A → **所以**出招 B → **但是**遭反扑 C → **所以**付代价换打法 D”顺畅串读；只能用干瘪的“然后”硬连时，立刻补回缺失的抉择、反扑或后果。
- **写看得见的那一下动作，别写抽象总结（`craft_default`）**：

| 抽象总结（不及格） | 看得见的那一下动作（合格） |
|---|---|
| 他不再讲道理，用信用担保 | 债主当众催债，他不再求情，把自家祖屋房契拍在桌上 |
| 众人从偏帮转为信服证据 | 刚才嚷着报警的村长俯身看清房契上的亡父私章，当场收回了手 |
| 亲戚人多势众口径一致 | 二叔已带着村长堵在院门口逼签抵债字据 |

- **外部危机 × 人物情绪四象限张弛搭配（`craft_default`）**：
  - **外紧内绷（双高）**：刺刀见红的公开摊牌决裂；
  - **外紧内稳（外高内低）**：死心后冷静收网清产反杀；
  - **外缓内痛（外低内高）**：大战前夜独处或真相大白后的心里余震；
  - **外缓内平（双低）**：短平快换场过渡，角落顺手露一点山雨欲来的反常苗头。

## 5. 全剧弧光、单向交接与扩缩调序

- **全剧四阶收紧（不绑死集数）**：① 老办法管用但埋隐患 → ② 对手摸透反制、再用老招开始伤及在乎之人 → ③ 两难代价摆上台面必须割舍一头 → ④ 彻底破局或转向。排完每集必问：“删掉这一集，全剧会断哪一步推进台阶？”
- **写清现场交接（`handoff_state`），拒绝空泛气氛词**：别写“双方剑拔弩张、危机升级”；写“叶澄把大门与排班柜钥匙拍给齐曼，隐瞒冷柜夹缝真实替班底账；齐曼已定明早八点放物业进场核账”。对不上号时须调归属或补明时间过渡。
- **扩写、精简、调序与防机械轮换**：
  - *该扩写*：补回跳步漏掉的关键抉择、铁证怎么抢到手、代价落到哪儿及在场利害人反应（绝不注水）；
  - *该合并砍掉*：重复讲观众已知信息、同招撞同挡处境零变化、纯走路换场无抉择过场戏；
  - *调序前五查*：有无提前用未到手的情报道具、翻脸跑在导火索前、伏笔落在揭晓后、伤势钟点站位断戏、观众知情先后变了悬念是否仍成立；调完重顺全部 `setup_payoff` 与 `handoff_state`；
  - *防机械轮换*：不按“一集打脸、一集掉马、一集误会”排班硬凑，看对手是否长记性变招、主角打法与代价落点是否升级。
- **自校准篇幅与镜头量估算（`craft_default`）**：仅在已有本项目定稿集时，用本项目的平均每镜字数与秒数估算待写集量级（绝不硬套外部项目数字），只抓翻倍级严重超标并在大纲阶段拆合消化，不卡死交付。

## 6. 节奏参考标准

本阶段按项目制作形态提出节奏参考初稿（写入立项简报，状态 `proposed`）；经创作者确认或手改后，由 `short-drama` 技能写入 `short-drama.json#/creator_authority/rhythm_profile`（状态 `accepted`，`craft_default`）。未设定或未确认时一律不核对。

| 节奏指标（配置键名） | 说明 | AI 真人短剧参考起点 | 漫剧参考起点 |
|---|---|---|---|
| 制作形态（`form`） | 支持 `ai_live_action`、`motion_comic` 及 `实拍`、`二维动态漫`、`风格化三维`、`水墨笔触`、`Q 版表达`、`国漫二次元` 等形态名；支持按需只填已确认项 | `ai_live_action` | `motion_comic` |
| 首钩出现时限（`first_hook_seconds`） | 开场第一个钩子最迟第几秒亮出 | 5 | 5 |
| 情绪触点最大间隔（`beat_interval_seconds_max`） | 相邻两次冲突台词、关键动作或新信息揭晓最长隔几秒 | 30 | 30 |
| 单集最少对手反转数（`opposed_reversals_per_episode_min`） | 每集至少打出几次有具体对手交锋的局势反转 | 1 | 1 |
| 集尾卡在最高点（`end_on_peak`） | 集尾直接在冲突爆点或悬念落槌处掐断，不拖泥带水接平缓收尾 | `true` | `true` |
| 集首回放上集末拍（`reprise_previous_last_beat`） | 下一集开头先顺接回放上一集最后那一拍 | `true` | `false`（App 自动连播） |
| 旁白占比上限（`vo_share_max`） | `[VO]` 占全集口播字数比例上限（去空白与括注、留标点；`[OS]` 计入分母不计分子） | 0.3（待实测） | 0.3（待实测） |
| 目标平均镜长（`target_avg_shot_seconds`） | 单镜平均时长参考值（秒） | 2.5 | 2.6 |
| 近景特写占比下限（`close_shot_share_min`） | 近景、特写、大特写与细节特写占总镜数比例下限 | 0.45 | 0.45 |
| 首个大爽点最晚集数（`first_major_payoff_by_episode`） | 全剧头一回重头爽点兑现最迟落在第几集 | 1 | 1 |

静态漫、解说漫或投流素材可先用 `short-drama-breakdown` 技能实测同赛道对标剧再定起点；解说漫可放宽 `vo_share_max`，温情生活流可适当放宽触点间隔与单镜秒数。配套核对两项：

- **视频模型最短秒数**：当 `target_avg_shot_seconds` 短于目标模型单条最短输出时长（如均镜 2.5s 而模型最短 4s）时，在简报写明走**多镜合生**还是调高平均镜长请创作者拍板。
- **语速与动作估时（`format.pacing`）**：随节奏标准给出可手改起点——如中文快节奏约 `4.1` 字/秒、英文按词约 `3` 词/秒与常规动作段落耗时，跑出样片后再微调。
- **`end_on_peak: true` 切黑做法**：挑既给本集交锋砸出结果、又当场捅出下集新篓子的那一拍干脆切黑（若情绪爆点与新危机分属两件事，让它们同秒撞车），`handoff_state` 如实记下定格现场。

## 7. 合成示例（共享厨房单集大纲与因果诊断）

沿用 [故事核与人物开发](story-and-character-craft.md#6-合成示例共享厨房) 情境：

- **开场钩子与目标**：齐曼手攥凌晨三点叶澄代签的黄色鲜肉送货底联，当着十几个摊主堵桌逼亮原始排班册；叶澄想在不捅破“老周旷工、自己私改表”的前提下稳住众人、别惊动门外巡街物业。
- **交锋升级与转折**：叶澄亮重抄排班表息事宁人 → 齐曼拍出黄色底联拆穿造假 → 叶澄咬牙独自认改表却死守不提老周 → 人群后老周不愿背“走后门抢灶位”黑锅，当众站出认下带娃急诊迟到，反质问叶澄为何不按明规罚押金反害全厨房被抓违约把柄——争执从“争灶位”转成“叶澄私改台账连累全员停业”。
- **本集兑现与集尾悬念**：送货单真相在摊主内部挑明，叶澄护短本事与失信代价同登台面；她当众拍出大门与排班柜钥匙向齐曼交权平息众怒，齐曼答应明早八点放物业进场核账，却不知冷柜夹缝里藏着记满半年违规替班（连齐曼去年冬天那三次也在内）的真实底账，叶澄必须在明早八点开门前取走它。
- **因果诊断**：断节拍写法是“众人争吵，物业提前审查，叶澄紧张”；咬合紧实写法用“因为底联砸实造假 → 所以物业要求明早八点封账 → 但是连底账交出半数摊主会被清退 → 所以她交权稳住众人、独瞒底账并定下明早八点前取走的死线”。
