# Agent Note: 不另建画风候选目录

Status: rejected

## Problem

有一种常见做法是给创作者一份现成的画风菜单（按导演、影片或流派列几十张风格卡），选一张就得到一整套光色、质感与表演参数。设想是：创作者没想好画风或只说得出「某导演那种感觉」时，套件能更快给出有味道的方向。

## Proposal

在 `$short-drama` 下新增一份画风候选目录：若干个按情绪命名、不出人名的方向原型，每个写好稳定项、可变量、叙事职责和失效信号，项目初始化时供创作者挑选；创作者点名导演或影片时，先把名字翻成可观察的选择。

## Alternatives considered

- **新建目录（本提案）**：最强的理由是体验可预期，每次给出的候选口径一致，新手一眼能挑。未采用：先跑了基线臂，不加目录、只用现有 `look-development.md` 与 `production-form-profiles.md`。对「都市复仇、竖屏、实拍，画风没想好」，基线给出四个可逐镜比较的方向，每个都有稳定项、可变量、叙事职责和失效信号，删掉方向名后写法仍各不相同。对「要某导演那种感觉」，基线把名字拆成光源、色彩、材质、构图、景深和失效信号，把影响剧本与剪辑的选择（抽帧拖影、内心独白、全剧统一还是分段）交给创作者，并说明提示词里不写导演名。基线已经到顶，目录只会多出一层要维护的固定词汇，还和「风格名不是生产决策」这条既有规则相冲突：卡片会被当成套餐整套照抄。
- **只在 `look-development.md` 补一句「点名导演或影片时先拆成可观察选择」**：成本最低。暂不做：基线没有它也做对了，加了也测不出差别；以后若实跑中出现把人名写进提示词或整套照抄的产出，再补这一句。

## Consequences

- **收益**：不新增需要维护的风格词汇，候选方向继续按项目题材与制作形态现场提出。
- **代价**：候选方向的口径取决于当次推理，不同会话给出的方向数量和命名会不同。基线只有一次实跑，结论是「未观察到缺口」，不是保证。
