# 可替换拍法：更换呈现时保住戏剧功能

## 适用边界

本规则（`SCR-10`）仅在创作者主动标注某个关键节点需要备选呈现时启用；未标注节拍不启用，本套件不内置平台审核标准、不预测审批结果。在进入资产、关键帧与运动规格前记下备选拍法，可避免后续更换呈现时因下游链条锁死而被迫整场硬删。先按创作者选定的当前拍法正常写作，不要提前磨平冲突。

## 功能与拍法分开写

标注节拍时拆开三项：

| 字段 | 回答什么 | 常见错误 |
|---|---|---|
| 功能 | 这个节拍在故事里**兑现了什么**：谁的什么被证明、谁的处境如何改变 | 写成情绪词（“高潮”“爽点”），无法判断备选是否等价 |
| 当前拍法 | 现在**用什么具体呈现**来兑现它 | 与功能混写成一句，导致换拍法就得换功能 |
| 备选拍法 | 换一种具体到可直接拍成动作的呈现，**同样兑现该功能** | 写成“改温和些”“酌情处理”等无法拍成动作的套话 |

## 备选成立的四条判据

1. **同一个人被证明或被改变**：换了受影响的人，就是另一个节拍。
2. **后续依赖仍然成立**：后续回报与下一集进入状态仍被满足；若上游呈现是后续多拍的依据，备选须连带说明下游如何衔接。
3. **代价没有消失**：暴露、失去、欠下等代价仍在，不因换拍法而抹平后续压力来源。
4. **不需要新的铺垫**：不依赖前文未建立的事实。

**「删掉这场」永远不是备选**。若要移交功能，必须指明移交给哪个已存在的节拍，并写清该节拍新增的承担内容。

## 合成示例

（虚构情境：社区食堂排班员被副店长当众指控“私改夜班排班表吃空饷”；实际昨晚旷工、被排班员暗中涂改排班本替下的人，正是副店长偷偷塞进后厨打杂的亲外甥，而副店长发难时还不知道旷工的是自己外甥。）

- **功能**：坐实排班员确实动过排班表，且是为了护住副店长自己也不敢曝光的人；排班员私改台账的代价与副店长被堵回嘴的反转当场同时落地。
- **当前拍法**：排班员当众把纸质排班本拍在桌上摊开，指着涂改液底下透出的原签字行，亲口念出副店长外甥的名字。
- **备选拍法**：排班员把排班本直接塞进副店长手里让他自己对着灯光看底下的原名，副店长看清字迹时脸色骤变、猛地合上本子不再往下念——被护者身份靠**指控者当场掐断追查的反应**坐实，不靠台词点名。功能与代价一致（仅适用于后续只需副店长知情退缩、不要求在场众员工当场听见名字的情形；若后续要求全场或观众知晓名字，需配合前文线索或一眼原签字特写）。
- **不算备选**：改成私下找副店长解释（失去当众对峙与公信力受损代价）；直接删掉这场（戏剧功能落空）。
