# Agent Note: 混剪分段统一音频格式

## Problem

PR #184 的静音段匹配第一个有声视频，但后续有声视频仍保留不同的采样率与声道布局，流拷贝拼接后
会按第一段错误解码，出现音高与时长失真。本决定修正
[静帧剪辑笔记](../feature/2026-09-28-edit-still-cuts.md) 中「不转换原声」的选择。

v0.9.2 发布前的实跑又发现：即使格式统一，逐段编码 AAC 再流拷贝拼接，每个切点仍有约 32 毫秒掉音
（每段开头的编码预热帧与末帧补零），跨切点的台词和唱段听得出来；verify 不测这一项。

## Decision

所有分段编码为首个有声视频的采样率和声道布局；全静帧仍用 48 kHz stereo。
真实渲染回归在修正前得到音频 3.265306 秒而非 3 秒，修正后通过；用 44.1 kHz mono 与 48 kHz stereo 视频夹静帧的真实渲染验证音视频时长和后段音高。

拼接时画面仍流拷贝；声音把每段解码为 PCM，按该段画面在成片里的长度补齐或截断，首尾相接后只编码一次 AAC。
真实渲染回归：两段连续正弦音拼接，修正前切点处电平跌到峰值的 1% 以下，修正后连续。

## Alternatives considered

- 检查时拒绝不同格式：不需要转换原声，边界简单；但创作者无法正常混剪来自不同工具的素材，故不用。

## Consequences

修正流拷贝拼接的格式契约；不同声道素材可能按首段布局下混，采样率会转换，不再声称所有原声参数原样保留。
