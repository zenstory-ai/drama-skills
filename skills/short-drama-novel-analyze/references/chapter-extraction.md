# 逐章提取与人物设定整理

## S2 单章提取（`chapters/ch-<N>-extract.md`）

目标范围内的每一章单独产出一份 `chapters/ch-<N>-extract.md`，`<N>` 使用章节索引里的 `sequence` 序号。第一行写 `# ch-<N> <原文章节标题>`（原文无标题则只写 `# ch-<N>`），开头注明原著文件路径及本章在索引中的起止行号，标题下写五段：

1. **概要**：3–5 句，写清读完本章后谁的处境、所知秘密或手里筹码发生了实质变化，不记流水账。
2. **情节点**：每条一行，四段用半角竖线 `|` 分隔：
   ```text
   P1 类型 | 白描（附行号范围） | 涉及：称谓、物件、地点 | 功能：这一步改变了什么
   ```
   - `P<n>` 从 `P1` 起顺排，`P<n>` 与类型、类型与第一个 `|` 之间各留一个半角空格；
   - **类型**取自七项：`行动`、`对话`、`信息`、`转折`、`铺垫`、`兑现`、`状态`；
   - **白描**只记可观察的具体言行（如「吴志斌告诉郑松张子豪在韩国训练」「管家把旧钥匙放进抽屉最里层」），不拿主观评价或空泛总结（「展现了实力」「陷入绝望」「埋下伏笔」）充当事实；遇到内心独白时直接摘记角色所想的关键意思；
   - **功能**点明强弱易位、揭开秘密、关系转折、底牌败露、筹码得失或倒计时逼近中的具体变化（`功能：` 仅用于情节点第四段，其余段落写「作用」以便行格式自检）。
3. **载体记录**：格式见下节。
4. **出场人物**：照录本章实际出现的称谓及行动作用，不在单章提取阶段跨章合并。
5. **未决项**：本章拿不准的人物指代、时间先后或前后出入。

## 载体记录

每章至少记 1 条，拆开记录「必须传达给观众的关键信息」与「原文所用的叙述通道」，供后续按目标制作形态判断转化做法：

| 字段 | 写什么 |
|---|---|
| 关键信息 | 本章必须让观众知道、误信、悬心期待或印证的事 |
| 原文载体 | 作者用了哪些事件、对话、人物反应、物证细节或前后呼应写出来 |
| 通道 | `可见行动` / `对白` / `心理叙述` / `叙述者旁白` / `信息密度` |
| 观众效果 | 勾起好奇、拉满期待、憋屈施压、解气爽感、心疼、紧张揪心、甜宠、热血等 |

通道对后续改编的提示需**结合目标制作形态判断**：
- `可见行动`：各制作形态下通常均可直接入镜（`screen_ready`）。
- `对白`、`心理叙述`、`叙述者旁白`：真人实拍里大段站桩对话与纯内心盘算容易拖慢画面，往往需改成当场动作、物证交锋或反应切镜（`needs_carrier`）；而在二维动态漫、Q 版表达或强风格化漫剧中，短促内心吐槽、分格对峙与画外音（`[VO]` / `[OS]`）本就是高频表现手段，只要配得上具体表情动作支点即可直接成戏，仅在纯抽象背景百科或文字障眼法时才需重写或舍弃（`prose_only`）。
- `信息密度`：表面像家常过场，实则交代了后续冲突必需的规矩、家底、人物关系底色或生死时限，专门标出以防排集时误当水戏一刀砍掉。

## 格式自检与分批执行

单章写完后核对格式再落盘（情节点四段齐全、类型在七项内、`## 载体记录` 至少含 1 条数据行）：

```bash
F=项目开发/source-analysis/chapters/ch-${N}-extract.md
P=$(grep -cE '^P[0-9]+ ' "$F")
grep -cE '^P[0-9]+ [^|]+\|[^|]*[^|[:space:]][^|]*\|[^|]*涉及' "$F"   # == $P
grep -cE '^P[0-9]+ .*\|.*\|.*\|[^|]*功能：' "$F"                     # == $P
```

- **并行与分批**：支持并行子任务时每批同时拆 5–8 章（子任务提示词开头注明材料系合法持有的虚构作品、仅做结构拆解、通俗冲突照常提取）；创作者指定分批范围（如前 100 章或第一季）时，完整拆完该目标区间并在 `_progress.md` 记明起止章号即可进入汇总。
- **失败处理**：单章中断或格式不过时重试 1 次；仍失败先记入 `_progress.md` 继续拆其余章，S2 收尾前集中补跑，目标区间内仍有缺章时停在 S2 汇报缺失章号。

## 人物合并与设定质变记录

S4 基于已提取章节汇总 `characters.md` 与 `world.md`（仅作供 `$short-drama-develop` 取舍的候选名单，正式设定待剧本定稿后由 `$short-drama-assets` 建立）：

### 同人异名合并（`NVA-08`）

一人只建一条，拿不准时分开列并记入 `unresolved`，严禁凭主观臆测硬并：
- **可合并（须有原文同人实据）**：专名与小名（「顾禾」「顾小禾」）、原文点明指向的绰号、带明确姓名的职务称呼（「李队」「陈记者」）。
- **不合并**：纯外貌或临时身份泛称（「红衣女子」「随从」）、不带姓名的泛指职务（「护卫队长」「家主」，前后可能换人担任）。

### 人物与设定跨卷质变记录（`NVA-07`）

长篇连载跨卷、换地图或分季推进时，不能只记静态初始设定，须按章号顺序记清**跨卷质变节点**：
- **人物跨阶段质变**：记录首次出场章号，以及关键立场倒戈、马甲揭晓、实力阶位跃迁、核心关系决裂或结盟所落在的具体章号与行号依据，方便分季改编时准确切取对应阶段的人物状态。
- **世界观与设定演进**：整理核心规则、战力等级体系、势力版图与绑定道具（如「古戒 + 戒中残魂」合记一条），逐条标明出场章号与跨卷规则升级点（如新地图战力体系换算、旧压制规则失效）；原文语焉不详处直接写「原文未明确」，绝不按网文套路脑补。
