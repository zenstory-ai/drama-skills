# 角色声线与配音设定

项目需要跨集保持角色配音一致时，在 `视觉设定.md` 对应人物条目下记录声线与配音设定。**无对白角色（纯动作出镜、背景人物或未开口角色）免填声线**；有对白角色按戏份轻重分层填写：

- **主要发声角色（推荐完整写法）**：写清年龄音域、嗓音质地、日常语速停顿、情绪失控或紧绷时的发声特征，可附跑偏反例，并在同剧存在声线相近对手角色时点名听感区分点；已选定样音时登记 `- 声音参考：` 与专名读音。
- **次要配角与功能性开口角色（简写即可）**：一行简写音色底子与说话语气（如 `- 角色声线：中年男声偏沙哑，说话简短催促`），无需硬凑多条选音标准、跑偏反例或全员两两找对手角色比对。

## 固定本嗓声线与单场表演的界线（`AST-07`）

**`reviewed_invariant` AST-07**：跨场不变的角色本嗓设定与单场戏的台词演法严格分开：

| 固定本嗓设定（写进人物条目） | 单场台词演法（留给剧本、分镜与视频提示词） |
|---|---|
| 音区高低、音色质地、听感年龄与声音厚薄 | 本场因狂奔或受伤造成的气息急促 |
| 平时语速快慢、停顿习惯、尾音收放特点 | 某句台词的刻意重音或压低嗓门耳语 |
| 口音与方言底子、确认好的专名读音 | 情绪爆发时的临时拔高音量 |

角色压嗓伪装、跨越十年变老或长期失声沙哑等跨多场持续变化，按 [视觉设定拆解指南](asset-design-guide.md) 记清变化原因、起止场次与相比本嗓的差异，不改写基础声线设定；单场几句话的语气起伏归现场表演。

## 参考音频绑定与核验状态（`AST-08` / `AST-09`）

需要绑定参考音频（配音小样、获授权的克隆干声，或用 `$short-drama-produce` 试出的样音）时，音频统一放在项目 `输入/` 目录下，在对应人物条目写一行 `- 声音参考：<项目相对路径>（用途：…；控制：…；不得控制：…；状态：<核验状态>）`（暂未选定时可写 `- 声音参考：待选型`），下游《视频提示词.md》的 `- 参考音频：` 行原样引用该路径。

**`reviewed_invariant` AST-08（控制范围边界）**：写明借用参考音的哪一面、禁止带入哪一面。**参考录音当条的情绪、录音房间混响/话筒远近，以及底噪、伴奏、旁人搭话等背景声，一律写进 `不得控制`**：

| 用途 | 允许控制 | 默认不得控制 |
|---|---|---|
| 音色 | 嗓音质地、共鸣位置、听感年龄与声音厚薄 | 该条录音里的情绪、语速快慢、录音空间混响、背景杂音 |
| 口音 | 口音轻重与用词腔调范围 | 音色、音区高低、说话人本嗓辨识度 |
| 语速节奏 | 平时语速快慢与断句停顿习惯 | 音色、口音、该条录音里的情绪 |
| 听感年龄 | 听感年龄段 | 具体音色质地与口音 |

同一段参考音频兼作多项用途时，在同一行 `- 声音参考：` 里合并写清控制范围，不拆成多行重复登记。

**`reviewed_invariant` AST-09（参考音核验状态）**：
- `creator_described`（创作者已说明）：创作者或音源权利人给出了可核对的听感说明；
- `audibly_inspected`（已试听核验）：当前环境已获授权实际试听并核对过音频内容；
- `unverified`（未试听核验）：只看到文件名、尚未实际试听——不得凭文件名断言音色、口音、干净无底噪或只有单人说话，也不得指望负面提示词抹掉参考音自带底噪。

## 主要角色选音推荐写法、相近声线区分与专名读音（`AST-10` / `AST-11` / `AST-12`）

- **主要发声角色推荐写法（`craft_default` AST-12）**：挑试音小样或验收克隆/预置音色时，可从听感年龄与音区高低（写同剧对比，不写生硬赫兹数）、嗓音颗粒感与厚薄、平时语速与断句习惯、情绪紧绷/失控时的声音变化里提炼核心特征，按需附“演过头/跑偏”反例（如“克制冷感，忌播音腔朗诵感”），不拿「愤怒」「悲伤」等单场情绪词当本嗓标准，也不拿文字描述顶替真实参考音频。
- **相近声线按需比对（`craft_default` AST-11）**：同剧主要发声角色定音时拉开音区与节奏层次；当两位常同场交锋的角色音区接近（如两位中年沉稳男角）时，建议点名对方写出好认的听感差别（如：`周薄森句尾收得干脆利落；老林句尾常带一点往下叹气的余音`）。
- **专名读音全剧统一（`structural_invariant` AST-10）**：同一个专有名词确认读音后，在整份 `视觉设定.md` 里只保留唯一一种注音拼法，防止前后集配音改口。
