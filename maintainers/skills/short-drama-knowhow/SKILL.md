# 短剧创作经验提炼与规则维护

通过定性研读理解编剧、漫剧团队与导演怎样把剧情构想落成可拍可用的制作文稿与成片，将可复用的创作经验整理成脱敏的公开指南，并及时清理过严或失效的旧教条。

## 授权与范围边界

- 仅在维护者主动调用本技能、且当前会话已提供明确授权的只读访问时，才读取非公开材料；连接方式、凭据、来源名称与内部研究记录只留在维护者指定的隔离工作区，严禁写入本技能目录、公开技能库、待公开草稿或测试样例。未获授权或无法确认只读时立即停止读取，仅用虚构样例演练。
- 在维护者明确授权的只读隔离会话内，除研读立项设定、大纲、剧本、视觉设定、提示词、分镜、剪辑与改稿等文字稿外，允许查看图像、音频、视频媒体以核对真实视听事实；本流程内不发起外部媒体生成任务，公开使用环境下绝不连接任何非公开来源，严禁将任何非公开媒体、原始文件名、项目专有词或原文词句抄出隔离区。

## 核心原则与分级验证

- **定性判断优先**：题材语境、人物动机、信息差、表演细节、镜头意图与模型视听表现由 Agent 结合上下文与成片事实判断；脚本只做格式校验、文件比对、查重与隐私扫描，不拿出现频次或相关性统计当创作铁律。
- **按规则等级分级验证**：不再把所有经验整理死绑在双盲评测上，按改动性质与规则等级分别把关：
  - **新增或收紧阻断级规则**（`structural_invariant` / `reviewed_invariant`）：必须完成脱敏核查、界定正反例边界，并按 [blind-forward-eval.md](references/blind-forward-eval.md) 跑匿名对照样本与独立盲评；重大门禁增删同步记入仓库 `.agents/notes/` 决策笔记。
  - **新增或修订经验建议与风格选项**（`craft_default` / `taste_option`）：完成脱敏核查、写清适用条件与反例边界说明，并通过仓库回归测试即可合入对应阶段参考指南，默认不新增审稿扣分门禁。
  - **降级、收窄或废止过严/失效旧规则**：凭明确反例、真实成片反证或下游模型演进事实即可直接修改落地并通过现有测试，免跑双盲评测。

## 工作流

1. **确认只读授权与隔离区**：记清本轮目标（提炼新做法或清理旧规则）、可读范围与输出位置；涉及非公开项目时先确认只读隔离边界。
2. **研读项目材料与核对视听事实**：顺着立项设定 → 分集大纲 → 剧本 → 视觉设定与连戏记录 → 图片提示词 → 分镜 → 视频提示词 → 剪辑与改稿记录对照梳理，并在授权隔离区内按需核对参考图、音频或成片画面，按 [cards-and-coverage.md](references/cards-and-coverage.md) 记录五项轻量研究要素。
3. **收紧边界与脱敏改写**：主动排查同题材例外、失灵反例与模型能力变化，按 [synthesis-and-promotion.md](references/synthesis-and-promotion.md) 抹除来源特征、换全新题材与人物重编虚构示例，写成带适用前提与失效边界的草稿。
4. **按等级验证与合入维护**：仅在新增或收紧阻断级门禁时按 [blind-forward-eval.md](references/blind-forward-eval.md) 执行匿名盲评；`craft_default` / `taste_option` 更新以及过严、失效旧规则的降级、收窄或废止，核对脱敏合规并跑通仓库回归测试后直接落地，重大门禁与契约变更同步记录至 `.agents/notes/`。
