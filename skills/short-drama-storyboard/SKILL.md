# 短剧分镜与首尾帧提示词

把定稿剧本和视觉设定拆成切镜有据、空间连戏、起止画面清楚的 `剧集/<EP>/分镜.md`，并逐镜编写首帧（按需含尾帧）提示词。

## 快速开始

```text
用 short-drama-storyboard 技能完成 EP001 的正式分镜和每镜首帧提示词
```

## 模式选择（正式项目 vs 轻量起草）

- **轻量 / 草稿模式**：用户仅要求试拆几镜、构思某场调度或单独起草几条首尾帧提示词（无完整短剧项目目录）时，直接输出清晰易读的镜头表（镜号、景别/机位、运镜、画面起止、声音）与可直接复制的首尾帧提示词，**不强制套用完整项目全部 13 个机读字段与 `REF-`/`PLAN-` 槽位语法**。
- **正式项目模式**：落盘 `剧集/<EP>/分镜.md` 或衔接跨文档校验、下游视频提示词与投产时，完整遵循 [分镜文档格式规范](references/format-spec.md)（包含 `SHOT-...` 标题、字段顺序、出场设定与参考图槽位语法）。

## 入口与语言配置

- **直接动笔**：有定稿剧本与必要视觉设定即可直接开拆（正式项目先读磁盘最新 `剧集/<EP>/剧本.md`，与早期对话草稿有出入时以文件为准）。美术设定图提示词与分镜可并行推进；仅当创作者明确要求比选重头戏拍法时才先给备选方案等拍板，常规拆镜一气呵成。
- **双语分工**：创作者可读说明跟随项目语言；首尾帧可复制提示词正文跟随 `short-drama.json#/format/prompt_language`（无配置文件时按已有提示词或项目文档语种推断，未指定时使用用户当前语言）。
- **镜长与节奏**：参考 `short-drama.json` 中的 `native_duration_seconds` 与 `rhythm_profile`（如已确认模型秒数区间，贴合单镜上下限；短于下限的快切可提议多镜合生或演完稳住终点）。未定模型或未填秒数时按对白与动作体量给常规秒数（如 2–6s），**不因此停工追问**。

## 工作流

1. **排定戏剧落点与悬念时机**：顺场理清动作、对白、音效、画面文字与转折落点（若立项或剧本限定了“后半段 / 最后 N 秒首次露面”，按全集目标时长换算到具体秒数位置再排镜）。
2. **逐镜写清起止、运镜与声音**：顺着 `起点 → 动作 → 终点` 交代人物站位、姿态与持物交接，单镜动作量贴合秒数（见 [镜头设计方法](references/shot-craft.md)）：
   - `运镜`：运动镜头写清动法与起止落点（开场强钩子或高潮反转可用急推）；固定镜头直接写 `固定`，无需强凑不动理由。
   - `声音`：排镜时按台词与停顿估准秒数，文档「声音」行清爽写明对白/VO/OS、关键音效与留白即可，免写读秒算术账。
3. **按需标注空间站位与轴线**：三人以上群戏、复杂空间换位或跨轴调度时，在场头写一段 `场景站位` 标尺；简单双人场直接在各镜起止点写清即可（见 [场面调度手册](references/blocking-playbooks.md)）。动作打斗戏拆法见 [打戏与动作分镜](references/fight-craft.md)。
4. **编写首尾帧提示词**：`### 首帧提示词` 只定格镜头 `起点` 瞬间画面（带 `连戏锁` 的条目在生效范围内原字保留 `锁定词`），确需锁定收尾构图时另加 `### 尾帧提示词`。全集保持统一画风与同场主光方向，明确标出的闪回、梦境或主观镜头可按剧情意图切换质感或画风；同机位切景或微调表情动作时，允许基于已确认的上一镜首帧配合指令改图派生下一镜首帧（见 [首尾帧构图与写法](references/keyframe-craft.md)）。
5. **核对关联字段并收束整集**：正式项目按 [分镜文档格式规范](references/format-spec.md) 补齐 `来源`、`出场设定`、`输入参考图` 及可选的 `画面文字` / `图片提示词项`。剧本每个场次均须有镜头覆盖（确需整场略过时在首个 `SHOT-...` 前注明 `- 未拍场次：`）；全集总时长与待拍板事项放在回复或文末独立 `## 整集汇总` 下。

## 出场设定与参考图原则

用户没有手工点名参考图，不等于选择文生视频。正式项目在首尾帧成稿后，对照正文**实际入画**内容核对关联字段（精确标点与完整语法见 [分镜文档格式规范](references/format-spec.md)）：

- **出场设定**：只列本镜画面实际可见的人物、造型、地点与道具，`控制：` 不超出本镜景别可见范围；入画人物身着独立建档的 `造型` 且服装入画可见时须一并列出。正文提及但未入画的条目列在 `画外`，尚未建档的连戏物件在汇总中请 `short-drama-assets` 技能补建。
- **输入参考图**：先在用户输入、`剧集/<EP>/制作成果/` 与文档已指向的可见媒体中核对真实图片——已有真实图片绑定 `REF-...`，外部工具自挂图片预留 `PLAN-...`，需等实图到位标明 `待补参考图`，确认不垫参考图再写 `无（文生视频）` 或 `无`（只有真实 `REF-...` 可直接交由 `short-drama-produce` 技能图生投产）。
- **用途配额**：每张参考图只选一项主 `用途`，每镜最多一张 `起始帧` 与一张 `结束帧`，挂 `结束帧` 时必须同时挂 `起始帧`。

## 修订原则

返修分镜时按戏剧职责维护 `SHOT-...` 镜号稳定：

- **调顺序或同镜微调**（改景别、走位或起止细节）→ 保留原 `SHOT-...` 镜号，同步修好相邻镜衔接。
- **新插独立镜头**（补反应特写或道具插入镜）→ 新开 `SHOT-...` 镜号，后续老镜号不顺延改号。
- **一镜拆多镜** → 承接原起点与已生成首帧的主半镜可保留原 `SHOT-...` 镜号，仅给新拆出的子镜开新号。
- **多镜并一镜或整镜推翻重拍** → 停用旧号换新号，已停用废号绝不重用，并在回复中点明需同步更新的下游 `MOTION-...` / `GROUP-...`。

## 完成标准

同轮同时修改《图片提示词.md》与《分镜.md》时当场同步引用，不另建场次核对表文件。需要跨文档结构与连戏自动校验时，如已安装 `short-drama` 技能可交由其按局部或整集模式核对；独立使用本技能时，对照 [分镜文档格式规范](references/format-spec.md) 与 [阶段规则](references/stage-contract.md) 人工自检即可。视频提示词、生成投产与独立连戏审查只在创作者点名时启动。
