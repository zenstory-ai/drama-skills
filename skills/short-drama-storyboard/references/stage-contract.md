# 分镜阶段规则

本阶段负责维护 `剧集/<EP>/分镜.md` 中的 `SHOT-...` 镜头条目、镜头目的、剧本来源、时长、起止画面、声音、出场设定与输入参考图（及可选的图片提示词项）以及首尾帧提示词。分镜以定稿剧本和 `视觉设定.md` 为准，不越界擅改剧情走向或角色场景设定，不另建隐藏草稿或 JSON 台账文件。

下表仅注册阻断级不变量（`structural_invariant` 与 `reviewed_invariant`）；拆镜粒度、运镜与焦段风格、反应镜节奏、场面站位、打戏拆招与非线性连戏例外等创作经验（`craft_default` / `taste_option`）见 [镜头设计方法](shot-craft.md)、[首尾帧构图、受光与漫剧定格写法](keyframe-craft.md)、[场面调度手册](blocking-playbooks.md) 与 [打戏与动作场面分镜](fight-craft.md)。

## 本阶段规则表

### `SHT`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| SHT-01 | structural_invariant | `剧本.md` 每个场次都须有至少一个 `SHOT-...` 镜头覆盖，或在文档开头 `- 未拍场次：` 写明略过理由；每镜 `- 来源：` 填写的场景 ID 必须真实存在于 `剧本.md`。 |
| SHT-02 | reviewed_invariant | 每个镜头都有明确的戏剧或叙事目的，且忠实传达所引剧本段落的原意。 |
| SHT-05 | structural_invariant | 可选的 `- 图片提示词项：` 填写时须指向《图片提示词.md》中已存在的条目且 `《…》` 名称与标题一致；尚无对应条目时写 `无` 或省略该行。 |
| SHT-06 | reviewed_invariant | 首帧或尾帧提示词只画快门按下那一瞬间的静态画面，绝不写成一串有先后顺序的连续动作。 |
| SHT-08 | reviewed_invariant | 剧本每个关键状态转变由主力镜头交代清楚，禁止无意图地把已演完的同一动作从头重演一遍；跨镜切点处的常规动作顺接微重叠（出画接进画、抬手接落手），以及标明 `高潮重播镜：SHOT-...` 的高潮多角度分段重放除外。 |
| SHT-09 | reviewed_invariant | 本镜绑定的地点与场景视角，其观看朝向和同框 `固定陈设` 必须与本镜机位侧一致。 |
| SHT-10 | reviewed_invariant | 首帧提示词只定格镜头 `起点` 已成立的画面事实，尾帧提示词只定格镜头 `终点` 落定的画面事实，并与本镜 `出场设定` 保持一致；首尾两帧严禁互相借戏抢跑或残留已消失状态。 |
| SHT-12 | reviewed_invariant | 需控制揭晓时机的悬念或底牌须对准剧本知情进度；构图既不能提前漏底，也不能把本镜该亮出的关键证物或脸色挡死。 |
| SHT-13 | reviewed_invariant | 多人同场调度须把剧本里有据可查的护短、联手、逼压与旁观关系，落成站得住脚的远近站位、身体朝向、眼神落点与走位路线。 |
| SHT-14 | reviewed_invariant | 跨镜传递或争抢中的运动物件（球、车辆、兵器、证物），在未标明时间跳切或省略时，保持归属、运动轨迹、方向与落点前后连贯。 |
| SHT-15 | reviewed_invariant | 当项目声明了播放界面 UI 遮挡区时，构图将关键人脸眼神、必读证物字样与核心手部动作安排在干净可见区；未声明时不凭空猜安全框。 |
| SHT-16 | reviewed_invariant | 单集总时长等于《分镜.md》各镜头可见时长的算术加总，时长待定的镜头须明文标出不得漏算；与目标集长的差值如实汇总报告，不把固定秒数当硬门槛卡死质量。 |
| SHT-17 | structural_invariant | 每个镜头须使用 `### 首帧提示词` 小节对应镜头 `起点`（仅在需锁定收尾构图时另加可选的 `### 尾帧提示词` 小节对应镜头 `终点`）；首尾帧小节内只保留顶格以 `>` 开头的引用行，不混入普通列表或分隔线。 |
| SHT-19 | reviewed_invariant | 仅当创作者明确要求比选分镜方案或多机位试排时，先给出在知情时机、代入视角、空间控制、核心画面或场尾落点上真正拉开差距的备选拍法等拍板；常规拆镜请求直接一气呵成落稿。 |
| SHT-20 | reviewed_invariant | 改分镜时保持 `SHOT-...` 镜号稳定：调顺序或同镜微调保留原号；一镜拆多镜时，承接原起点与已生成首帧的主半镜可保留原号，仅给新拆出的子镜开新号；多镜合并或整镜重拍换新号，停用旧号不重用，并同步更新下游引用。 |
| SHT-21 | reviewed_invariant | 首尾帧可复制提示词正文只写画面看得见的内容；条目编号、流程备注、文件路径与「轴线左侧」等分镜黑话一律留在提示词外面。 |
| SHT-22 | structural_invariant | 每个镜头都必须在首帧成稿后填写 `- 出场设定：`，把首尾帧实际入画的人物、造型（入画人物身着单独建档的 `## 造型 · <名称>` 且衣服可见时列出 `造型「<名称>」`）、地点、道具对应到 `视觉设定.md` 现有条目。 |
| SHT-23 | structural_invariant | 用户没有手工点名参考图，不等于选择文生视频；自动查完项目图片后，每镜将核对无误的真实图片绑成 `REF-...`，或将外部自挂图写成 `PLAN-...`（指向 `IMG-...` 或 `SHOT-...`），或按需标明 `无（待补参考图：…）`，确认不垫参考图时写 `无（文生视频）` 或简写 `无`。 |
| SHT-24 | reviewed_invariant | `出场设定` 只记当前画框里实际看得到的主体，每项 `控制：` 范围不超出本镜景别可见部位，不把上一镜的全身绑定原样照搬到局部特写。 |
| SHT-25 | structural_invariant | 每个参考图位都必须从 `外貌/主体/造型状态/空间布局/构图/尺度/效果/起始帧/结束帧/风格` 十项中选填唯一 `用途`；每镜最多一张 `起始帧` 和一张 `结束帧`，挂 `结束帧` 时必须同时挂 `起始帧`。 |
| SHT-26 | reviewed_invariant | 凡在首帧或尾帧提示词正文里实际入画的 `视觉设定.md` 条目，须完整纳入本镜 `- 出场设定：`；仅因归属物或字样在正文提及但本镜未入画者，可在末尾加 `；画外：<人物|造型|地点|道具>「<名称>」` 注明边界（由审稿结合画面语义核对，不靠机械字面扫描阻断）。 |

### `CON`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| CON-01 | reviewed_invariant | 相连镜头或场次的前一收尾状态（`终点`）与下一开场状态（`起点`）在站位、朝向、持物与环境状态上必须衔接一致；若有跳变或刻意跳切须写明说明，对不上时退回负责技能修订。 |
| CON-02 | reviewed_invariant | 人物知情范围、伤势污渍、道具归属与开合、天气、光线或空间状态不得在切镜或转场间无剧本依据凭空跳变或自行复原。 |
| CON-07 | reviewed_invariant | `视觉设定.md` 声明的 `- 连戏锁：` 固定唯一 `LOCK-...` 编号、生效目标引用（脚本确定性核对声明语法及指向的 `SHOT-...`/`IMG-...` ID 存在性）与 `锁定词`；点名的静态图片提示词、范围内镜头的首帧提示词，以及无参考图的文生视频和仅挂 `空间布局` / `风格` 等未锁住该外观的图生视频（含合生分组）在正文里原字保留该锁定词，已挂载本镜 `起始帧`（含首帧已带该锁定词的跨镜复用 `PLAN`）或对应设定条目 `主体` / `造型状态` 参考图时自动豁免（正文锁词保留与豁免由审稿按上下文核实）。 |
