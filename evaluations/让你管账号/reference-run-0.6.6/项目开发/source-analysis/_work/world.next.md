## 世界规则：一个新媒体整体落后的平行世界

出现章：1、2。

- 与原世界「几乎一模一样的平行世界」，江晨带着上一世的记忆与方法论穿越而来（ch-1 P2）。
- **民间新媒体同样贫瘠**：粉丝过万的博主屈指可数，整个行业人气不如江晨上一世刚起步时
  的水平（ch-1 P10）。这一条是全书所有「爽」的地基——它把主角的专业能力从「有优势」
  放大成「无人竞争」。
- 军队新媒体几乎为零：十几个账号粉丝总数不足两位数（ch-1 P9）。

`unresolved`：这个世界与原世界在其他方面的差异，原文未展开；穿越机制原文未解释。

## 势力

### 火箭军 / 西南军区火箭军文工团

出现章：1、2、6、7、9、10、11、13、15、17。

- 层级（按原文出现的称呼）：齐首长／齐军长 → 团长张耀祖 → 副团长周薄森 → 宣传兵江晨。
- **建制关系原文自相矛盾**：ch-15 中周薄森称张耀祖「团长」，团内众人却称周薄森「周团」。
  谁是正职，原文未明确。
- 处境：文宣常年排名垫底，年中军宣会上被其他军团调侃，内部会上被点名批评，
  年中总结评比关系单位荣誉与个人晋升（ch-2 P10、ch-6 P1）。这是江晨得到试错授权的原因。
- 「西南军区的文工团」与「火箭军文工团」是同一单位还是隶属关系，原文未明确（ch-1 未决项）。

出现章：6、7、8、9、10、11。

短文与军事开放日公告、刊登署名「钟嘉嘉」的《华国军魂，且听龙吟》。

出现章：1、2、3、5、9、10、13、14、17、18。
