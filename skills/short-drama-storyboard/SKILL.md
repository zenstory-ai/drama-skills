# 短剧分镜与冻结关键帧

把剧本和视觉事实转成有镜头职责、空间连续性和可冻结起点的 `剧集/<EP>/分镜.md`。
每镜使用二级标题 `## SHOT-... · <中文名称>`（列出「职责、来源、时长、景别、机位、运镜、起点、唯一动作、终点、声音、视觉依据、图片提示词项、输入参考图」），同镜下用 `### 冻结关键帧提示词` 写起始帧正文（小节内只放以 `>` 开头的引用块，不夹杂普通列表或 `---` 分隔线；需要时另加 `### 收尾关键帧提示词` 写终点正文）。

## Quick Start

```text
用 $short-drama-storyboard 完成 EP001 的正式分镜和每镜冻结关键帧
```

## 入口

当前剧本加必要视觉事实即可直接进入。资产图片提示词与分镜是兄弟分支，不互相等待。只有关键场次
真的存在多个成立导演方案时，才在上下文比较覆盖方案；普通场次直接设计。

创作者可读说明跟随项目语言；冻结关键帧的可复制正文跟随
`short-drama.json#/format/prompt_language`。没有 `short-drama.json` 时正文默认使用 `en`。
分配镜头时长前读取
`short-drama.json#/creator_authority/production_profile/choices/native_duration_seconds`。已声明目标模型但
没有原生时长时先补这一个选择；目标模型也未声明时照常按叙事节奏设计，不猜供应商限制。
同时读取 `short-drama.json#/creator_authority/rhythm_profile`：`status` 为 `accepted` 时，镜长按
[镜长从哪来](references/shot-craft.md#镜长从哪来-sht-28) 由声音事件与 `target_avg_shot_seconds` 推出，
全集近景类镜头占比不低于 `close_shot_share_min`；档案缺失或未接受时不核对这些数值。

用户没有手工点名参考图，不等于选择文生视频。冻结关键帧成稿后，再按画面中的可见内容核对项目中已有的可读真实图片（文件名相近但内容未核对的不算），填写视觉依据、图片提示词项和输入参考图。

开始分镜前读 `剧集/<EP>/剧本.md` 的当前内容；与对话早期草稿不一致时以文件为准并点明差异。

## 工作流

1. 读取已接受的目标模型原生时长区间，确认每个场景动作、对白、声音、画面文字和转折由哪些镜头承载。
2. 确定观众知情时机、对齐对象、空间揭示顺序与转折落点。剧本或 Brief 用“前半段 / 后半段 / 前三分之一 / 最后 N 秒”等相对时间限定首次出现、释放或禁止时，先按已接受集长换算成明确秒数边界再分镜（如 60 秒作品的“后半段首次出现”不得早于 30 秒），不拿“稍后”“交接后”替代数值时间。
3. 每镜写清唯一职责、来源、时长、景别/机位、运镜、起点、唯一主要动作、终点和声音；用 `起点 → 唯一动作 → 终点` 说明人物、双手与持物的状态转换（涉及交接、换手、放置或取回时写清接触者、接触方式和物件落点，不靠镜外瞬移衔接）。
   - 按镜长核对本镜要看清的事项数量，超载时先删、合并或拆镜，见 [短镜头的动作量](references/shot-craft.md#短镜头的动作量-sht-03)。
   - 「运镜」按本镜目的逐镜选，写出行为、起止与理由，固定也写理由，见 [运镜逐镜选](references/shot-craft.md#运镜逐镜选-sht-04)。
   - 有对白、VO 或 OS 时，先按原文和说话方式估算完整发声时间，再排不能重叠的动作、停顿与末尾反应，把估时依据简写在本镜「声音」里，见 [对白估时](references/shot-craft.md#对白估时)。对白场切点默认按 [对白覆盖默认](references/shot-craft.md#对白场怎么切-sht-29) 安排；镜长不按剧本字数折算。
4. 一场戏拍成多镜时，先在《分镜.md》开头写这场的「场景站位」（固定锚点、各人相对锚点与彼此的位置、轴线与摄影机工作侧、哪一镜改变站位），再逐镜锁定朝向、位置、视线、持物、出入口和限制动作空间的持续关系；冻结关键帧再把它翻成本镜机位下的前后景、朝向、隔挡物和画面左右，见 [站位先写锚点和关系](references/blocking-playbooks.md#站位先写锚点和关系)。
5. 冻结关键帧只呈现镜头起点，删除终点才出现的文字、动作、姿态或道具状态。需要锁定收尾构图时，另写可选的 `### 收尾关键帧提示词` 呈现终点（删除起点才有、终点已消失的状态），取舍见 [首尾成对](references/shot-craft.md#首尾成对)。
6. 关键帧成稿后，从成稿正文提取需保持身份、造型或地理的可见人物、地点和道具，一次填满三条依据（语法见下节）：
   - **视觉依据**：必写字段，逐项引用《视觉设定.md》条目；
   - **图片提示词项**：已有合适 `IMG-...` 条目的写上，没有的写「无」；
   - **输入参考图**：在用户提供的输入、`剧集/<EP>/制作成果/` 和文档已指向的可见媒体中查找匹配图片，命中写 `REF-...`。未命中的默认写成 `PLAN-...` 挂图槽位（起始帧指本镜 `SHOT-...`，人物/地点/道具指《图片提示词.md》的 `IMG-...`；尚无 `IMG-...` 板子的在报告里点名并建议 `$short-drama-image-prompts` 补板），本镜照常就绪。报告里一并说明另外两条路：把真实图片放进项目绑成 `REF-...`（只有 `REF-...` 能转 `$short-drama-produce` 投产），或明确改走文生视频。只有创作者要求先等图进项目时，才写「无（待补参考图：<本镜缺失的起始帧、人物、地点、道具>）」或在已有槽位后追加「；待补参考图：<仍缺的图片>」（缺口之间只用 `、` 分隔）；只有创作者明确不用图时，才写「无（创作者已明确选择文生视频）」。
   - 目标模型参考槽位有上限（如 Seedance 2.0 最多 9 张图）时，按失去代价从高到低保留：起始帧 → 说话或主要动作人物 → 必认道具 → 地点 → 其余入画人物 → 定调图；放弃项写明，必要事实写进关键帧正文。
7. 整集请求完成整集，末端一次报告覆盖、节奏和未决选择。

## 镜头要求

- 「来源」以《剧本.md》真实存在的场景 ID 开头，可跟对应本镜动作或声音的短引文，跨场次用 `、` 连接（`creator_markdown_check.py` 机械核对）。剧本每个场景都要有镜头承载；确需省略某场时，在《分镜.md》正文开头写 `- 未拍场次：<场景 ID>（理由：……）`，多项用 `；` 连接（SHT-01）。
- 已声明原生时长时，短于下限的镜头可向创作者提议将同场相邻镜头装进多镜容器（同意后由 `$short-drama` 写入 `multi_shot_containers: true`，能否装及是否需逐切关键帧由 `$short-drama-video-prompts` 方言决定）；未启用容器时落在最短秒数内并在动作完成后保持终点。长于上限的动作按可见状态闭合点拆镜。目标模型只收整数秒时，单镜写整数秒；同一多镜容器内的短镜可写半秒，但容器总和须在分镜阶段凑成整数秒。
- 切镜必须带来信息、权力、情绪、空间或节奏变化，删掉同义重复镜头。同一动作不跨镜重复发生，峰值处声明过的[冲击重复](references/shot-craft.md#动作落实表)除外；终点应能成为下一镜可信起点。
- 冻结关键帧只写该瞬间能看见的内容；《视觉设定.md》的连续性锁在生效镜头上原样写进关键帧正文。
- 同集关键帧每条正文用同一句画风（写实不混用「漫剧」「插画」等词），同场景用同一句光与色温；生成时可先出一张场景中远景作定调图并作为其余镜头的最后一张参考（只取色调、光线与质感，不取构图）。

## 视觉依据与图片

- **视觉依据**（必写）：按关键帧实际画面写成 `《视觉设定.md》·<人物|造型|地点|道具>「<名称>」（控制：<范围>）`，多项用 `；` 连接，名称须匹配《视觉设定.md》标题；确无此类条目写「视觉依据：无」。需认出身份的小比例或背景人物也在范围内，画外人声和不可识别局部不算。
- 关键帧正文或「来源」引文点名了某条目名称（或其声明的「画面代称」），但该人/物本镜不在画面里时，在「视觉依据」末尾追加 `；画外：<类别>「<名称>」`（不代替必要动作的镜头落实）。若条目名在正文里易与普通词误撞（如 `道具「手机」` 撞「手机店」），请 `$short-drama-assets` 在该条目写 `画面代称：无`。
- 本镜需跨镜保持一致、但《视觉设定.md》尚无条目的可见物件：正文逐镜用完全相同的描述钉住，并在末尾报告点名建议 `$short-drama-assets` 补条目，不自行新增条目或塞进「视觉依据」。
- **图片提示词项**：`IMG-...` 只是《图片提示词.md》的条目 ID，不代表图片已生成。命中时写匹配该文档二级标题的 ID、中文名称和控制范围；无该文档或无合适条目时写「图片提示词项：无」。
- 三条依据的「控制」只写当前这一格承担得起的范围（如手背特写不写「本集造型」），不因角色仍在场就顺延上一镜绑定。
- **输入参考图**：真实可读图片用 `REF-...`，创作者生成时自挂的图片用 `PLAN-...`（把路径换成 `IMG-...` 或 `SHOT-...` 条目 ID），两者可混用并按 `顺序` 连续编号。每个槽位必须逐字遵循唯一格式：`REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）`。注意「顺序：」后的全角冒号和路径前的中点 `·`；不得用 `/` 代替字段分隔符。多图只用中文分号 `；` 连接，部分缺图在末尾接 `；待补参考图：<缺口>`（缺口之间用 `、` 分隔）。
- `用途` 只能取 `身份`、`造型状态`、`地理`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格` 之一（详见 `$short-drama` 的《参考角色》）。同一路径只能占一个槽位：一图承担两件事时，`用途` 写主项，副项写进「控制」（如 `用途：起始帧；控制：起始构图、本集造型`）。一镜最多一张 `起始帧` 和一张 `结束帧`，有 `结束帧` 必须同时有 `起始帧`。
- 近景或说话镜里脸占大块、无 `起始帧` 锚住脸、只有全身身份板且目标方言仍有槽位时，可为该角色加挂一张同 Look 面部识别板作第二个 `身份` 槽（`craft_default`）。
- 本镜尚无起始帧文件时：用 `$short-drama-produce` 生产则以 `剧集/<EP>/分镜.md` 的 `SHOT-...` 生成到 `剧集/<EP>/制作成果/images/` 后绑成 `REF-...`；创作者在外部工具出图则默认先写 `PLAN-SHOT-START（顺序：<n>）· <本镜 SHOT-...>《本镜冻结关键帧》（用途：起始帧；……）`。

## 修订

保留未受影响的镜头 ID。拆镜、并镜或改变镜头职责时，说明哪些下游视频提示词需要刷新，但不自动
重写用户没点名的文件。

## 完成

本次请求同时修改《图片提示词.md》与《分镜.md》时，当轮刷新受影响镜头的引用；不另建覆盖表。视频提示词、生产和审查仅在用户点名时开始。写完后可转 `$short-drama` 做局部或完整机械核对。
