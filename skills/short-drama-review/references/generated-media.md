# 成片看片与返工分流指南

适用于审查单镜生成素材、《剪辑单.md》与整集成片切点接缝（`EDT-01`–`EDT-14`、`EDT-16`–`EDT-23`），以及根据试拍样片或创作者看片反馈做问题归因与提示词调优（`REV-08`–`REV-10`、`REV-15`）。创作者在对话里随口给出的看片反馈（如“第 3 镜手穿模了”“第 5 镜后半句吞字了”）可直接接手定位病灶并给出修法，无需强求补填看片人、查看工具或查看局限等繁琐表格。

## 一、单镜与成片瑕疵六档分流（工作流与轻度修补遵循 `REV-15 · craft_default`，实质缺陷按不变量定级）

对照《分镜.md》本镜目的、起止画面与声音要求，先看核心剧情信息、台词、关键道具变化与人物反应是否拍出，再将画面或声音瑕疵归入以下六类处置。其中 `REV-15 · craft_default` 负责看片分流流程、追溯记录及 `note` / `minor` 级处置建议；凡定为 `major` 或 `blocker` 的实质媒体缺陷，其 `- 规则：` 字段必须挂靠所违背的 `structural_invariant` 或 `reviewed_invariant` 规则编号：

| 处置分类 | 判定标准 | 严重程度与归属规则 | 后续动作与负责技能 |
|---|---|---|---|
| **保留沿用** | 正常倍速播放不显眼，不影响剧情理解与前后连戏（如单帧边缘微闪、远处路人轻晃） | `note`（`REV-15 · craft_default`） | 留底告知剪辑，不改提示词、不重抽 → `$short-drama-edit` |
| **裁切避让** | 瑕疵落在有效动作起止点之外（如片头发呆等待、片尾多余变形），掐头去尾后本镜信息完整 | `minor`（`REV-15 · craft_default`） | 写明剪辑入出点避开问题区间 → `$short-drama-edit` |
| **后期修补** | 挪几帧音频对口型、调色、后期叠字或局部擦除背景穿帮小物即可解决 | `minor`（`REV-15 · craft_default`） | 写明后期修补做法 → `$short-drama-edit` |
| **建议重抽（创作者可豁免）** | 核心剧情能看懂，但存在较明显的外观造型偏移、连戏锁细节走样、动作容量紧促或口型听感瑕疵，后期难彻底修净 | `major`（归入对应不变量，如 `AST-01 · reviewed_invariant`、`AST-03 · reviewed_invariant`、`CON-01 · reviewed_invariant`、`CON-07 · structural_invariant`、`VID-05 · reviewed_invariant`、`EDT-04 · reviewed_invariant`） | 给出局部调优重抽方案，同时允许创作者结合工期与预算显式豁免留用或靠切镜遮掩 → 对应负责技能 / `$short-drama-edit` |
| **必须重新生成** | 漏掉关键剧情动作、核心台词或必看物证，私编发声台词，或人物换脸脱绑、空间轴线全反、关键真字乱码扭曲事实，裁切与后期均无法挽回 | `blocker`（归入对应不变量，如 `AST-05 · structural_invariant`、`CON-07 · structural_invariant`、`SHT-02 · reviewed_invariant`、`SHT-09 · reviewed_invariant`、`VID-17 · reviewed_invariant`、`VID-22 · reviewed_invariant`、`VID-25 · structural_invariant`） | 定位提示词、垫图或拆镜症结，退回对应负责技能修改后交 `$short-drama-produce` 重生 |
| **剪辑补回**（仅成片） | 原始生成素材已拍到关键内容，但成片切点下刀太狠、字幕错漏或混音叠字把关键信息与台词弄丢 | `blocker`（归入对应不变量，如 `EDT-04 · reviewed_invariant`、`EDT-05 · structural_invariant`、`EDT-07 · reviewed_invariant`、`EDT-10 · reviewed_invariant`） | 指明需调整入出点、字幕或音轨的 `CUT-...` 条目 → `$short-drama-edit` |

### 审查结论判定

- `PASS`：无 `blocker`，且无未获创作者显式豁免的 `major`（落入 `审查/*.md` 的 `- 结论：` 字段时，无建议写 `APPROVE`，附 `minor` / `note` 或已豁免 `major` 留底写 `APPROVE_WITH_NOTES`）；
- `PROVISIONAL`：无 `blocker`，仅剩不影响核心主线推进、已写明下阶段修正方案的局部问题（或待创作者在看片时拍板的边界项，以及尚有关键片段未查看到的情形）；
- `REVISE`：存在 `blocker`，或存在尚未获创作者豁免的 `major` 缺陷需返修重出（已过关片段照常交剪辑推进，复审只核验返工片段，不翻已放行片段旧账）；
- `REJECT`：整批生成方向、主体一致性或关键戏份严重失控，局部补救无效，需回退重设提示词或参考资产（在 `审查/*.md` 中记 `- 结论：REVISE` 并标明整批回退重设范围）。

## 二、问题归因与返修尺度（`REV-08`、`REV-10`）

1. **先分清垫图毛病还是出片毛病**：
   - **参考素材本身的问题**：输入参考图底图自带旧水印、杂字、五官模糊、服装画错或空间透视歪斜——写再多防崩提示词也救不回来，直接退回 `$short-drama-assets` / `$short-drama-image-prompts` 换图、裁修或重出设定图。
   - **生成阶段的问题**：垫图干净合规，但在当前提示词、挂图顺序或模型参数下出现动作超载、参考脱绑换脸、运镜冲突或吞台词——针对当前项目与模型配置定位具体字句（结论不跨项目当成死规矩硬套）。
2. **区分“探索试拍单改一项”与“明确错漏一并修完”**：
   - **探索性试拍归因**：试拍重难点镜头（多人调度、复杂走位、手部交接、高反差夜景）出现原因不明的抽风时，优先每次只调整一个变量（如拆短动作、换挂图组合或精简背景词）以便看清哪一处生效。
   - **明确错漏返修**：已经一眼看清的多处确定性错漏（如漏绑角色参考图、台词抄漏半句、运镜前后矛盾、道具拿错左右手），在**同一轮返修中一次性全部修完**，写明修改点与不得误伤的保留内容，绝不机械拆成多轮折腾。
3. **原样重抽与结构重拆的取舍（`craft_default`）**：
   - 垫图与提示词查无明显问题、属模型偶发抽风时可先原样重抽；经验上同一输入连续原样重抽一两次仍反复冒出同一个硬伤，往往说明单镜动作容量超载或写法撞上模型短板，宜及时转为**局部改词**或退回分镜**拆镜重排**，不要往提示词末尾硬塞“高质量、保持一致”等空话盲抽。
   - 若改词与重抽后某个镜头仍迟迟难以生成，立即停下反复试错，列出三条出路请创作者拍板：① 勉强留用现有素材并靠剪辑切点藏拙；② 将该镜承载的信息挪给前后相邻镜头交代；③ 删减这一镜——**若涉及关键剧情信息或台词，须先将信息转移到相邻镜头或退回 `$short-drama-write` 调整剧本，严禁一删了事留下剧情断层；确认删减单镜后，按 `EDT-11` 在《剪辑单.md》登记未入片原因，或退回上游成对移除对应的 `SHOT-...` 与 `MOTION-...`（仅整场不再拍摄时才写《分镜.md》开头的 `- 未拍场次：<场景 ID>（理由：……）`）**。

## 三、要求优先级与改稿防漏把关（`REV-09`）

压缩提示词字数、局部返修或重排 `GROUP-...` 多镜合生分组时，按由高到低的优先级守住底线：

1. **剧本已定的核心事实、逐字台词与必读画面文字**
2. **分镜已定的本镜目的、起止状态与镜头时长**
3. **视觉设定版本与跨镜连戏状态**
4. **创作者拍板的画风方向与模型模式配置**
5. **目标模型的提示词语法与能力边界**（模型做不到上层要求时挑明汇报并提替代拍法，不悄悄删戏糊弄）
6. **次要环境点缀与画质修饰词**

每次改词或重拆合生分组后快速复核四件事：① 剧本动作、反应与分镜总时长/合生分组覆盖（`SHT-16`、`VID-15`）是否仍严丝合缝；② 首尾帧小节结构干净（`SHT-17`）且各自守住静态瞬间（`SHT-06`、`SHT-10`），中段复杂核心动作尽量少靠首尾两帧自动插值硬猜（`SHT-03 · craft_default`）；③ 本镜原本立住的构图、光影与表演亮点未被改稿误伤；④ 局部补拍或备选版是否标清了与主镜头的关系（`VID-12`）。遇到缺前置材料（如某镜印字尚未定稿）时，只拦下依赖该字样的直出真字镜头，其余环节照常审理。

## 四、《剪辑单.md》与整集成片切点接缝核查（`EDT-01`–`EDT-14`、`EDT-16`–`EDT-23`）

审查 `剧集/<EP>/剪辑单.md` 与整集渲染成片时，严格按剪辑阶段规则等级定级并退回 `$short-drama-edit`（涉及改剧情设定、改台词或重出素材时再路由对应上游）：

- **结构硬账核验（`structural_invariant`，违背定 `blocker` / `major`）**：
  - 每条 `CUT-...` 均绑定真实存在的上游条目（视频段对应 `MOTION-...`，静帧段对应 `SHOT-...` 或 `IMG-...`）与当前可读的媒体文件，无对应素材文件的剪辑段不得写入剪辑单（`EDT-01`）。
  - `入点`、`出点` 与 `时长` 算术自洽（`出点 - 入点 == 时长`）且非负；视频段 `出点` 不超过素材实测总时长；静帧段从 `0` 起算、`出点` 等于 `时长` 且硬下限为 `2` 帧（约 `0.08s`，短于 `0.50s` 的快闪静帧仅作提醒复核，`EDT-02`）。
  - 开启字幕时，成片保留的每句有声台词连同标点与《剧本.md》逐字一致；语音转写仅用于定位发声起止时刻，不得改动剧本原字（渲染阶段可按屏幕显示惯例转换标点，`EDT-05`）。
  - 引用同一条视频素材的两个剪辑段源时间区间默认不重叠；闪回或强调重放须显式写明 `- 重放：<叙事理由>`（静帧图片可跨多段复用，`EDT-06`）。
- **内容与切点接缝核查（`reviewed_invariant`，违背定 `blocker` / `major`）**：
  - 剪辑只对既有素材做裁短、调序、局部试剪或后期换配音等加工，不得反向篡改《剧本.md》《分镜.md》《视频提示词.md》等上游定稿（`EDT-03`）。
  - 成片保留的每句台词听感完整可辨；允许画面在台词中途切镜或独立 `配音` 跨切点延续，视频原声跨镜铺底或清除人声须先交外部工具处理（`EDT-04`）。
  - 入出点落在源素材可用区间内，`取舍` 具体写明入出点可见的动作、表情或画面变化，不拿“为了节奏”等空话敷衍（`EDT-07`）。
  - 逐处回听切点前后环境声与配乐是否出现突兀跳变并按需修平接缝，不把混音指望寄托在内置渲染器不会执行的自然语言备注上（`EDT-10`）。
  - 全集交付时，未剪进成片的镜头须逐一登记原因（`--partial` 局部试剪未入片镜头仅归入提醒，不阻断渲染，`EDT-11`）。
  - 同场景、同一光线条件下的相邻镜头核对人物肤色、同款衣物或灰白墙面色差，记录调色参数后再看片复核；符合剧情的开关灯或冷暖突变无需强拉一致（`EDT-16`）。
  - 素材重新生成后须在交付前重测发声区间并更新字幕与画面文字时间窗（素材修改时间晚于剪辑单作为提醒输出，不直接阻断渲染，`EDT-17`）。
- **剪辑工艺建议（`craft_default`，偏离最高记 `minor` / `note`，不触发 `REVISE`）**：
  - 排查相邻切点意外跳帧或无意义信息重复，放行服务于叙事意图的相似景别、有意重放与跳切（`EDT-08`）；裁短某段后不机械把省下的秒数平摊给其他镜头（`EDT-09`）。
  - 默认烧录字幕并按声明响度标准化，如实核对实测综合响度与真峰，经一次外部音频处理仍超容差时交创作者拍板而非死循环重渲（`EDT-12`）；区分硬性交付时长与参考目标时长（`EDT-13`）。
  - 常规对白镜按字音起止留出自然入画提前量与句尾反应余量（`EDT-19`）；同场景默认向同场曝光与色彩中位数适度拉近，支持单段手动校正、`不校` 或整集关闭（`EDT-20`）；多镜合生打戏先按画面切点拆段并裁净头尾呆立（`EDT-21`）；多人交锋或强反应处善用 L-cut / J-cut 跨切点过渡，短尾音抢话或标注 `（叠音）` 列入提醒复核（`EDT-22`）；切点前后音量跳变显著时按 `EDT-10` 列入「请回听」提醒人工核查而非直接拦截（`EDT-23`）。
  - 审批量首帧图、生成素材或成片切片时，可按镜序拼成缩略图一览表（排查方法遵循 `REV-15 · craft_default`），并排对照《分镜.md》站位、地点图与《视觉设定.md》，逐镜排查背景左右镜像翻反、固定陈设忽近忽远、固定物相对人物高度跳变或身高比例失真；尾段跳变优先走「裁切避让」（`REV-15 · craft_default`，记 `minor`），首帧即错或全程穿帮归入「建议重抽」或「必须重新生成」并挂靠所违背的不变量规则定为 `major` / `blocker`（如场景朝向与固定陈设穿帮 `SHT-09 · reviewed_invariant`、设定分层与状态失配 `AST-03 · reviewed_invariant` / `AST-05 · structural_invariant`、跨镜连戏跳变 `CON-01 · reviewed_invariant`、连戏锁丢失 `CON-07 · structural_invariant`）。
- **风格取舍（`taste_option`，仅记 `note`）**：剪切节奏快慢、某一拍多留还是早切、某瞬间是否重放（`EDT-14`），以及交付规格中可选声明的全片颗粒叠加或外部胶片质感调色（`EDT-18`），均属创作者风格选择，不判为问题。
