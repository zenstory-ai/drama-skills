# 短剧视觉设定拆解

顺着剧本提炼跨场沿用的外观设定，统一写入 `剧集/<EP>/视觉设定.md`（每个条目使用二级标题 `## <人物|造型|地点|道具> · <名称>`）；分清固定本体与阶段状态，单镜姿势、左右手拿握、机位走位与生图/视频提示词交由下游对应环节负责。

## 快速开始

```text
使用 short-drama-assets 技能，从 EP001 剧本拆完人物、造型、地点、道具和本集状态
```

## 工作流

1. **定年代与读视觉方向**：读取当前剧本与项目视觉方向；在 `《视觉设定.md》` 顶部写明 `- 制作形态：<画风形态与画幅>` 与 `- 时代背景：`（尚未写明年代时按剧本里的设备、传播渠道、制服或年份提炼，依据不足标待创作者拍板），器物制式不与年代设定冲突，合理的日常物理旧化质感正常保留（见 [视觉设定拆解指南](references/asset-design-guide.md)）。
2. **顺场盘点与归属定性**：逐场盘点出镜人物、场景与戏用道具，归为沿用旧设定、新增造型/状态、新建条目或待创作者拍板（指代含糊处列候选待拍板，不硬猜；普通环境陈设与仅台词提及项不建档）。
3. **分层写清外观与状态**：每个条目先写跨场不变的 `- 外观特征：`，再在 `- 本集状态：` 记清阶段变化、原因与起止场次（跨多场持续或需单出参考图的换装单立 `造型` 条目；拄拐、手铐等持续限制行动的随身绑定写明起止场次；带字道具明确字迹处理方式）。不在 `视觉设定.md` 里回头抄录分镜 `SHOT-...` 或生图 `IMG-...` 编号列表。
4. **按需填写声线、跨语言名称与连戏锁**：
   - `- 角色声线：` / `- 声音参考：`：无发声台词角色免填；**一旦本集启用 `- 角色声线：`，《视觉设定.md》中所有在《剧本.md》有发声台词（含对白、`[VO]`、`[OS]`）的 `人物` 条目均须填写非空且不为 `无` 的 `- 角色声线：`**（主要发声角色细写音域质地与发声特征，次要配角简写音色语气即可，见 [角色声线与配音设定](references/voice-direction.md)）。
   - `- 提示词名称：`：提示词与条目标题同语种时免填（仅易与普通环境词重名误判的条目填 `无`）；存在跨语种差异（如中文标题配外文提示词）时，建议为正文实际点名的 `人物`（及按需 `造型` / `地点` / `道具`）写一致拼写（从不点名写 `无`；跨语种人物缺项时脚本仅输出软 `WARNING` 提醒复核，不作硬阻断）。
   - `- 连戏锁：`：对跨镜反复出现、画偏即穿帮的不变外观按需加锁（服装锁挂在 `造型` 条目下写 `镜头：入画`），`锁定词` 用于静态设定图、首帧与未由参考图锁住该外观的视频提示词（见 [跨场连戏与连戏锁指南](references/continuity-and-locks.md)）。
5. **整集一次拆完**：整集拆解请求一次写完整集，在回复末尾集中汇总新建/换装拆分决定、跨集结束状态与待创作者拍板的含混指代，不在《视觉设定.md》文末追加汇总小节。

## 完成标准

所有明确出场均已定性并写入 `剧集/<EP>/视觉设定.md`，固定 `外观特征` 与可变 `本集状态` 边界清晰。完成后可移交 `short-drama` 技能做局部或整集格式校验；图片提示词、分镜、审查和生产不自动启动。
