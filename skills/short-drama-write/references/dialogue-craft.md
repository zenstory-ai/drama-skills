## 1. 对白的工作定义与规则分级

对白发生在具体关系中：说话者试图改变对方的行动、判断、当下心境或公开体面，对方用自己的目标回应。

四类规则：

- **`structural_invariant`**：说话者、场景、画外/画内边界与精确文字要求；校验器可检查。
- **`reviewed_invariant`**：对白是否有明确目的、是否回应上一动作、是否改变局面、人物腔调是否可信；审查者引用文本判断。
- **`craft_default`**：让信息通过争取、回避、交换和后果出现；创作者可说明理由覆盖。
- **`taste_option`**：口语程度、方言、停顿、沉默、直白、诗性、打断和句式长短；遵从人物与作品风格。

对白比例、金句数量、句长和口癖数量不能证明质量。项目接受节奏档案后，按其中的 VO 占比上限核对，见[剧作手艺](script-craft.md#44-能演的不说vo内心独白与痛点)；不另设通用比例。

## 2. 先定说话目的，再写句子

冲突或博弈场景写对话前，可为每个主要说话者回答：

| 问题 | 主动方 | 对手方 |
|---|---|---|
| 此刻想让对方做什么？ |  |  |
| 最怕对方看见/说出什么？ |  |  |
| 手里有什么筹码？ |  |  |
| 哪件事不能公开说？为什么？ |  |  |
| 认为对方想要什么？ |  |  |
| 先用什么策略？失败后怎样换？ |  |  |
| 哪条底线受到压力才会越过？ |  |  |

两人可以表面谈同一件事，实际争不同结果。例如都在谈“交钥匙”：一人要结束控制，一人要迫使对方承认责任。

温情、喜剧或生活流场景不必强套“对手与筹码”：说话目的可以是报喜不报忧、嘴硬护短、递台阶、借日常小事确认关系，或因认知错位鸡同鸭讲，不要把亲友关心与市井闲聊全写成互相套话的审讯室。

**`craft_default · SCR-04`**：重要对白应能识别说话者的目的、关系位置、潜在风险或分寸，以及台词造成的变化。审查者引用前后动作，而不是给“自然度”打空泛分数。

**`craft_default`**：先想清楚“这句话想对对方做什么”，再决定字面怎么说。只替观众做背景说明或复述刚演完动作的句子，通常可以压缩或转为动作。

## 3. 台词是一种行动

同一句事实可以执行不同动作：

事实：“门在九点锁。”

- **催促**：“你还有三分钟。”
- **推责**：“九点以后，钥匙不归我管。”
- **试探**：“你是不是以为九点以后没人进得来？”
- **威胁**：“九点一到，里面是谁都不重要了。”
- **保护**：“九点前走，我就当没见过你。”

字面信息相近，对彼此关系起到的作用完全不同。

### 3.1 常用策略库

按人物目标选择策略：

- 要求、命令、请求、交换；
- 试探、诱导、套话、验证；
- 重新命名问题、缩小/扩大责任；
- 先承认一部分以保护更大秘密；
- 借第三人或公共规则施压；
- 假装无所谓、拖延、转移；
- 把选择交还给对方；
- 暴露自己愿付的代价；
- 拒绝旧称呼或旧关系位置；
- 用沉默迫使对方继续说；
- 报喜不报忧、嘴硬心软、递台阶、借日常小事打岔圆场（温情、喜剧与生活流常用）。

### 3.2 策略必须会受阻

若一方每句话都成功，对话会变成演讲。让另一方：

- 看穿并点破策略；
- 接受字面条件却拒绝隐含关系；
- 提供反证；
- 改变公开范围；
- 把对方的词反过来使用；
- 拿走说话所依赖的时间、物件或身份；
- 不给预期反应。

例如家族餐饮店老板突发脑溢血住院，二叔趁机拿着空白采购授权书到后厨逼少东家女主交出公章：

- **原地顶牛（双方只重复各自立场，无策略变化）**：
  - 二叔：“你爸在医院昏迷，后厨进货不能停，赶紧把公章交出来！”
  - 女主：“我不交！你就是想趁我爸病了夺权！”
  - 二叔：“我是你二叔，还能害你？快交出来！”（连吵三轮，关系与筹码一步没动。）
- **出招受阻与换招反制（把抽象策略落成回合交锋）**：
  - **第一回合（假意体恤 vs 接受字面条件却改写规则）**：二叔把授权书推上案台，打长辈体恤牌：“小禾，你爸还在重症室，你一个姑娘家哪熬得住天天凌晨四点验货？二叔替你分担。”女主不吵“我不累”，而是顺着他的话头接招：“二叔心疼我，那先把上个月欠冷鲜肉供货商的四十万尾款结了，结清这笔账，我立刻交印。”
  - **第二回合（借第三人施压 vs 把对方的词反过来用）**：二叔第一招受阻，立刻沉下脸拿股东压人：“那是你爸住院前签的账！今天不交印，下午几位合伙股东过来查账，我看你怎么交差！”女主直接把他的词反过来用，从手边进货夹板底下抽出一张回扣收据，反手拍在他的授权书上：“正好，几位股东刚进前厅包间，二叔现在跟我一块儿过去交差？”二叔脸色骤变，伸手去按那张收据。
  - **作者具体改哪里 → 观众因此多看到什么**：把“我不交公章”的口头顶撞，改成“顺着二叔‘替你分担’的话头把四十万欠款推给他，再借他搬出的‘股东查账’亮出回扣收据”；观众因此看到二叔从假装慈爱、搬股东压人到做贼心虚伸手抢收据的完整破防过程。

**`craft_default`**：一轮对话中，策略受阻后应当换策略、付代价或退出；重复同一句要求只会延长时长。

**`taste_option`**：有意的重复可以表现仪式、创伤、压迫或喜剧，只要重复本身改变效果或关系。

### 3.3 每种方法的反向条件

方法有各自的适用条件。修订时若发现对白别扭，可对照下表检查是否误用了某种方法：

| 方法 | 它失效的条件 | 失效后读起来是什么样 |
|---|---|---|
| 写潜台词 | 人物没有理由隐瞒 | 该说的话被作者按住不说，人物显得莫名其妙地躲闪 |
| 把说明改成有利益的传递 | 这条信息本来就中立 | 为了制造冲突而硬派立场，观众看得出争的是假的 |
| 打断 | 被打断的那句带着观众此后拿不到的信息 | 信息断供，后面的推断失去依据 |
| 停顿与沉默 | 沉默没有可见对象 | 观众读不出在权衡什么，只读到空档 |
| 把选择交还给对方 | 交出者本来就无权扣住它 | 不是让步，是虚张声势 |
| 借第三人或公共规则施压 | 这条规则观众此前不知道 | 像临时发明的挡箭牌 |
| 先承认一部分 | 观众还不知道有更大的秘密 | 部分承认被当成全部真相，后面揭露时观众觉得被耍 |
| 区分人物腔调 | 差异只落在口头禅上 | 标签化：换掉那个词人物就没了区别 |
| 用动作断开长发言 | 这段发言本来就没有内部转折 | 插入的动作是填充，该做的是缩短（`SCR-09`） |
| 让每轮承担不同工作 | 场景本来只有一件事要办 | 为了不重复而制造支线，冲淡了唯一的目标 |
| 套用筹码与试探模板 | 温情、喜剧或生活流场景本无利害博弈 | 把亲友关心、搭档拌嘴写成全员审讯与互相拿捏，烟火气变成算计 |

## 4. 潜台词来自已知差与风险

潜台词来自“真正想做的事不能或不愿直接说”。先找出不能直说的原因：

- 说出会暴露秘密；
- 说出会失去体面或关系；
- 替对方省心、留面子或嘴硬护短；
- 现场有第三人；
- 说话者尚未确认对方知道多少；
- 直接要求会显得自己没有筹码；
- 角色连自己都不愿承认真实需要。

### 4.1 三层写法

可用三层检查，不要求每句都复杂：

1. **字面层**：角色实际上说了什么；
2. **行动层**：想让对方做什么；
3. **风险层**：为什么不能直接说。

例（刚被撤掉项目署名权的工程师，在茶水间撞见抢走他署名的部门主管正在泡咖啡；走廊几步外就是来巡查的总部副总）：

> “张总，三楼会议室的投影仪刚才又闪屏了，您待会儿汇报那页核心架构图，要不要我进去帮您切一下底稿？”

- **字面**：提醒设备故障、主动提出帮主管切换演示底稿；
- **行动**：当面敲山震虎，让主管知道带原始时间戳的工程底稿还在自己手里；
- **风险**：走廊外总部副总就在几步远，两人谁都不能当众撕破脸喊出“署名是你抢的”；主管只要心虚接茬或阻拦，就等于认账。

温情与情感戏里，潜台词同样可以来自体谅与体面：女儿对着满桌没动过的纪念日冷菜接起母亲电话，笑着说“刚吃完，妈，他挑的项链挺衬我”——字面是报喜，行动是安母亲的心并保住自己最后一点体面，观众凭桌上的冷菜与空首饰盒一眼读懂潜台词，无需靠盘问或亮筹码。

若现场没有外人、秘密、关系分寸或权力差，句子就只是日常指令或寒暄，不自动具有潜台词。

### 4.2 让观众有推断依据

潜台词需要可观察线索：

- 角色避开一个具体词；
- 对方触碰/藏起相关物件；
- 称呼改变；
- 先回答旁枝，拒绝核心问题；
- 台词与可见证据矛盾；
- 第三人进入后语言突然改变。

例如同样写“角色心里有鬼或有事瞒着对方”，对比直白应付和带推断线索的写法：

- **线索一：先回答旁枝 + 顺手藏起物件**（丈夫问刚进门的妻子：“妈说下午在妇幼医院门口看见你了，你去医院干什么？”）
  - *无推断依据（平白应付）*：“我没去干什么，就是顺路去开了点胃药。”
  - *给观众推断线索*：妻子正把风衣挂上玄关衣架，听见这话手指一顿，顺手把风衣口袋里露出一角的孕检B超单往里塞了塞，头也不回地答：“三环那段路今天堵了一个钟头，回来时连物业快递站都关门了。”
  - *作者具体改哪里 → 观众因此多看到什么*：删掉正面回答，改成“把口袋里的B超单往里塞 + 只抱怨路上堵车”；观众不用听一句内心独白，单凭塞口袋的动作和答非所问的回避，就同时看懂“她怀孕了”和“她现在不打算告诉丈夫”。
- **线索二：第三人进门后称呼与话风突变**（实习生在档案室追问带教师傅为什么要替科室主任背黑锅）
  - *无推断依据（硬按住不说）*：“这件事你别问了，我不能说。”
  - *给观众推断线索*：实习生压低声音急道：“陈哥，那份违规批条明明不是你签的——”档案室门被推开，科室主任端着保温杯走进来；带教师傅没有抬头，只把压在手底下的批条复印件滑进文件夹合上，语气平淡地接话：“小周，上季度的归档目录核对完了就放这儿，先回工位吧。”实习生怔了一下，改口道：“好的，陈老师。”
  - *作者具体改哪里 → 观众因此多看到什么*：在主任进门的瞬间，把师傅的动作写成“合上文件夹下逐客令”，把实习生的称呼从“陈哥”切成“陈老师”；观众当场看懂两人防的是谁，以及这间办公室里的上下级高压。

**`reviewed_invariant`**：潜台词不能完全依赖作者事后解释。审查者要指出观众能依据哪些台词、动作与已知事实推断。

**`taste_option · SCR-06`**：有些场景需要直白承认，有些需要高度含蓄；潜台词不是每句必备装饰。

## 5. 信息如何进入冲突

### 5.1 把说明改成有利益的传递

信息更有戏时，至少一方对它有态度或利益：

- **争夺**：谁有权读、说、保存或解释；
- **验证**：证据是否可信，来源是否暴露；
- **交换**：信息换取行动、沉默、时间或关系承诺；
- **指控**：说出事实会把责任落到某人身上；
- **纠正**：新事实迫使对方重新选择；
- **回避**：不回答本身暴露风险；
- **公开**：同一句话在私下与众人面前代价不同。

例如母亲生前留下老街打印店和一份盖有红章的《五年免租补充协议》原件，弟弟背着姐姐答应帮急着收铺拆迁的房东偷出原件抵赌债，姐姐赶回店里拦阻：

弱：

> “我们这家店是母亲二十年前开的，她把免租协议原件放在铁皮柜里。”

带当下诉求：

> “你要真觉得这只是家随时能卖的店，就别攥着妈留的那把铁皮柜钥匙不撒手。”

后者不必一次交代所有背景，却把历史、所有权和当下动作绑在一起。

### 5.2 说明量由现场认知决定

人物不会为了观众重复彼此都熟知的事实。可以通过：

- 对事实的不同解释；
- 对过去承诺的选择性引用；
- 第三人不知道而必须被说服；
- 某人故意把私事说成公开规则；
- 物证迫使人物说出最少必要部分。

**`craft_default`**：让说明带着争取目标进入；能由动作或证据表达的部分，不再由两人完整复述。

动作已经让观众看懂机制时，台词优先承担新的工作：改变关系、收窄结论、隐藏态度或迫使下一步。若一句话只复述观众刚看到的因果或角色刚做完的动作（例如动作行刚写“她把热药碗推到桌沿”，台词又写“我把药给你端过来了，你快喝吧”），删掉复述，让动作交代物理事实、台词交代关系态度（如只说“凉了别怪我不再热第二回”）。

过去事件只说当前动作需要的最小片段。若一名角色能不受阻地一口气交代时间、关系与结果，先检查这些
信息能否被对方打断、质疑、回避或拿来交换；让背景参与当下争取，而不是暂停剧情播放资料。需要完整
宣读、证词或仪式性讲述时可以保留长段，但其现场作用要清楚。

**`taste_option`**：仪式宣读、审讯、教学、公开声明等场景可以容纳长信息，但仍要有听者反应和权力后果。

## 6. 人物腔调如何区分

“一个总说成语，一个总说网络词”只是表面。更稳定的说话腔调来自人物看世界和处理关系的方式。

### 6.1 五个腔调维度

1. **盯什么**：流程、感受、风险、体面、具体物件、长远后果；
2. **拿什么说服或施压**：摆事实、搬规矩、讲情分、拿资历说话、逼对方当场表态；
3. **怎样拿捏距离**：直呼其名、叫头衔、一口一个“咱们”、故意省掉主语、当众说还是私下说；
4. **怎样藏话**：顾左右而言他、反问顶回、打哈哈、闷不吭声、岔开话头、报细节搪塞；
5. **被逼急了怎样变形**：突然公事公办、字数变短、客气得发冷、直接掀桌、车轱辘话反复说或干脆摊牌。

再加入关系分寸：同一个人面对上司、家里人、外人和自己护着的人，绝不会是一个腔调。

### 6.2 建立轻量腔调卡

需要区分人物说话腔调时，只在上下文中记录当前写作所需的信息，不另建角色文档：

```text
角色：
惯常说话方式：
说话依仗什么（规矩/情分/资历/实据）：
最忌讳被提起的痛处：
拉近关系或拿捏分寸的方式：
被逼急后的口气变化：
对关键对戏人物的称呼与雷区：
这辈子绝不会说出口的句式：
```

不要把腔调卡变成强制口癖表。成片里偶尔破功、失态，恰恰能体现关系或处境变了。

**`craft_default`**：先用处世逻辑、关系分寸和受压反应拉开人物腔调，再用用词与句式节奏微调。

**`reviewed_invariant`**：如果把两个人的台词对调后依然完全成立，审查者应引用具体片段，指出缺了哪一方的说话目的、关系分寸或信息差；不能光凭常用词判定“千人一面”。

**`taste_option`**：人物可以极简、健谈、书面、地方化、诗性或笨拙；不要用统一“自然口语”抹平风格。

**`craft_default`**：中文对白默认贴合人物身份与人情分寸，可用称呼变化、半截话或反问，少写“我为你的行为感到羞耻”“这不在我的计划之内”这类译制片腔，也不要把人物写成背诵设定表的播音员。人物或作品选择书面、诗性等风格时，以该选择为准。

### 6.3 非中文台词：从场景直接写，不逐句翻译

**`craft_default`**：台词语言不是中文时，从场景本身直接用目标语言写——这一拍谁要什么、挡在哪、
这一句让局面变成什么——不先写中文再逐句翻译。逐句翻译会把中文的信息顺序和称呼密度一起带过去：
先铺原因再给结论，几乎每句都点名或叫头衔，客套话照搬，演出来像字幕腔，时长也跟着变长。

- 中文草稿或原著对白只当场景事实的来源：信息、压力、转折一条不少，句子重新写。
- 先给要害，原因能省就省或后置；靠代词和省略衔接，名字和头衔只在换对象、施压或示好的那一刻用。
- 称谓按目标观众熟悉的关系重设（「王总」「嫂子」没有固定对译，按关系写成名字、姓氏加称呼或不叫）。
- 一句的分量落在句尾的实词上，给演员落点；客套和寒暄按目标文化里这个人在这种场合真会说的话写。
- 台词长度按目标语言估时（英文按词数），不拿中文句子的长度当预算。

创作者要求直译或保留原文腔调时，按创作者的要求。

## 7. 让对话改变权力与关系

### 7.1 权力不是音量

现场权力可能来自：

- 谁能结束谈话或打开门；
- 谁持有可验证证据；
- 谁能让话语公开；
- 谁承担更少退出成本；
- 谁能定义问题与可接受答案；
- 谁愿意付更高代价；
- 谁掌握第三人的信任。

台词改变权力时，应有后续动作证明：对方交出物件、改称呼、停止解释、转向第三人、撤回条件或离开原位置。没有筹码、具体利害与身份支撑的空洞狠话（如动辄“我要让你在这个行业彻底消失”“你连给我提鞋都不配”），既拉不开人物身份，又只会加重演员咆哮负担。

### 7.2 关系分寸与位移

关系变化不必由“我不再信任你”宣布。可通过：

- 从私名称呼改为正式称谓；
- 把共同物品变成个人物品；
- 不再替对方撒谎；
- 首次在第三人面前支持/反对；
- 接受条件但拒绝情感解释；
- 把选择权还给一直被保护的人。

**`craft_default · SCR-04`**：关键对白结束后，至少能指出信息、权力、关系、带情绪的动作或物理状态的一项变化；否则审查者应说明该轮是否只是重复。

**`taste_option`**：关系也可以有意维持僵局；僵局要增加成本、暴露策略或改变观众理解，而不是静止。

## 8. 动作、停顿、打断与沉默

### 8.1 动作不要成为填充物

避免在每句间插入“看了看、笑了笑、皱眉”。对话间动作应完成：

- 操作筹码或证据；
- 改变距离和公开范围；
- 显示话语与行为不一致；
- 给对方一个必须回应的新事实；
- 记录连续性变化。

### 8.2 停顿要有对象

不要只写“沉默片刻”。写清停顿期间人物在避免、等待或判断什么（例如姐姐逼问弟弟有没有把亡母留下的免租协议原件偷交给房东）：

> 岑放没有回答。他把铁皮柜钥匙从钥匙圈上拆下来攥进手心，却没有递过去。

这段沉默包含选择，下一句会因此不同。

### 8.3 打断的权力

打断可以：

- 阻止一个危险词被说完；
- 抢走问题定义权；
- 保护第三人；
- 暴露说话者已经知道答案；
- 让本来私密的内容进入公开空间。

打断后要处理未说完内容的后果；否则只是制造表面节奏。

### 8.4 在长发言的策略转折处加入动作 (`SCR-09`)

长发言可以连续保留、缩短，或在内部策略转折处插入可见动作。第三种适用于发言本就有转折的场景，
可以同时帮助分镜与表演：

- **给分镜一个有依据的切点**：断开处是一次看得见的动作变化，分镜可以在这里换景别或换画面焦点，
  切点可以回到剧本中的动作核对。
- **给表演和配音一个换气口**：说话者在断开处做了一件事，这个停顿有对象（见 8.2），
  不是为了凑节奏的空拍。

**`craft_default`**：**只有当发言内部存在意图或策略转折时**，才用一条改变策略的动作行把它断开；
内部没有转折的长发言应当**缩短**，不是拆开。插入的动作必须满足 8.1 的标准（操作证据、
改变距离、暴露言行不一、给出必须回应的新事实、或记录连续性变化），不能是“看了看、
顿了顿”这类填充。断不开就说明这段话本身在替人物做说明，回到第 5 节重写信息的进入方式。
判据是转折，不是字数——多长算长由说话目的决定。

反例与修法——例如矿区事故后，安监科林深来查当晚下井值班名册，周主任为了包庇违规代班的妻弟，前半句先拿规章制度当挡箭牌敷衍推责，见林深目光落向桌上名册，才在后半句改用压住名册、点破证人不会到场来施压；原稿把关键策略动作塞进台词括号里，动作和台词都被削弱：

```text
周主任：夜班交接向来按班组长报上来的底单走，这事归不到我头上。（看了林深一眼，把名册翻页按住）再说，你要找的那个代班工今晚也不会来。
```

独立动作藏在台词括号里，分镜难以单独引用，台词语气也被打断。在策略从“官腔推责”转向“盖住证据当面施压”的转折处断开，改成三行，让动作独立成段、台词各自完整：

```text
周主任（公事公办）：夜班交接向来按班组长报上来的底单走，这事归不到我头上。

周主任迎着林深看名册的目光，不动声色把手里的下井值班名册翻过一页，手掌稳稳压住了妻弟代签的那一行。

周主任（压低声音）：再说，你要找的那个代班工今晚也不会来。
```

改稿的括注只保留说话方式（`公事公办`、`压低声音`），翻名册、压住签名行等改变现场筹码的独立动作单独成段，便于分镜与表演追踪策略切换。
能与本句同时完成的简短表演提示仍可放在括注中。

断开点的选择服从策略转折，不服从字数：上例断在“推开话题”转向“反过来施压”的位置。
连续两条同角色台词在人物抢话、自我修正或对方拒绝回应时都成立。单条台词长度与断开频率
同样属于 SCR-06 的风格范围，不设统一字数或比例门槛。

**`craft_default`**：只在动作、停顿或打断改变当前策略时写出它们。

**`taste_option · SCR-06`**：留白长度、标点、重叠对白和沉默密度属于表演与风格选择，不设统一比例。

## 9. 高密度对白场景

一室对谈可以有强烈运动，关键是让对话不断改变“谁能做什么”。

### 9.1 设计可见锚点

- 一份可逐步露出内容的文件；
- 一个会改变公开范围的门/电话/录音；
- 一件所有权正在争夺的物品；
- 一个有时间限制的现场任务；
- 第三人的进入、离开或保持沉默；
- 人物位置变化影响谁能读、听、拿到。

锚点服务权力变化，不是为了强行“画面丰富”。

### 9.2 让每轮承担不同工作

可在修订时标记每轮主要功能：

- 定义问题；
- 试探知识边界；
- 提出条件；
- 交出/拒绝证据；
- 重新定义关系；
- 迫使选择；
- 承担后果。

如果连续多轮功能相同，压缩或让反对方换策略。无需追求固定轮数。

### 9.3 给听者行动

听不是空白。听者可以验证、隐藏、拖延、记录、改变站位、让第三人看见或不给预期反应。这样对白不会变成单人独白加人名。

### 9.4 抓手、轮次与听者反应合在一起怎么写

以一场“酒楼包间家宴逼签学区房抵押协议”的高密度对白戏为例，看实物锚点、轮次分工与听者行动如何配合，避免拍成“几个人围着圆桌干坐吵架”：

- **可见锚点**：圆桌玻璃转盘上的**那份抵押协议、一盒红印泥、一支签字笔**，以及女主脚边拉链半开的**手提包**。
- **第一轮（诱敌把话说满）**：未婚夫把协议和红印泥推到女主面前，柔声逼她签字替婆婆“安心”；女主拿起签字笔，笔尖悬在签名栏上方一寸停住，抬头问：“这字一签、房子押过去，那八十八万的债是不是就真的一笔勾销？”听者未婚夫嘴角微挑连连点头，婆婆更是迫不及待把印泥又往她手边推了半寸，当着满桌亲戚拍胸脯发誓“签了字谁再提谁不是人”。
- **第二轮（掀开第一层底牌，分化听众）**：女主手腕一翻，“啪”地把签字笔拍在玻璃转盘上，笔杆弹滚到未婚夫面前；她拉开手提包，掏出的不是房产证，而是一沓工商股权穿透图砸在转盘中央：“那八十八万在我卡里只待了一分钟，就被‘融惠通达’自动代扣划走——陈玉兰，这家公司占股百分之九十的法人陈建军，是你什么人？”听者婆婆脸色煞白往后退半步结巴否认，旁边刚才还在帮腔的二姑却探头看清纸上的名字，失声插嘴：“那不是你娘家侄子吗？！”
- **第三轮（对手垂死反扑，亮出终极铁证）**：未婚夫猛地站起、绕过圆桌一把按住女主手腕，压低声音威胁：“协议是你自己刷脸签的，没证据证明是我干的，不签字明天就送你去坐牢！”女主甩开他的手，从包里掏出手机按下免提播放——未婚夫前一天在车里得意的原声传遍包间：“办卡那天我拿她手机谎称激活网银，哄她对着镜头刷的脸……她爸妈那套学区房早晚落在咱们手里。”未婚夫脸色惨白扑上来抢手机，包间大门同时被接警赶到的警察推开。

三轮交锋里，签字笔与手提包每一次状态变化都对应着说话策略的切换，桌旁的婆婆、二姑、未婚夫每一轮都有即时身体反应与立场松动，整场室内文戏因此比追打更有张力。多轮交锋也不必每轮都从包里掏一件新道具——围绕桌上已有的同一件核心物件（如一份被折起附页的补签单、一张贴过胶带的复印件或一只摔碎的玉镯）逐层掀开新事实或利用双方认知差换招，同样能撑起层层递进的回合。

**`reviewed_invariant`**：以争取或对抗组织的对白密集场景，仍需可追踪的目标、反制、转向与退出状态；
仪式、氛围或后果消化场景则检查其必要变化，不能只以“台词好听”证明场景成立。

## 10. 对白修订流程

### 10.1 标注行动

在每句旁用动词标记它正在做什么：逼问、遮掩、交换、缓和、划界、验证、转移……无法标注且不承担必要信息的句子，考虑删除或改成动作。

### 10.2 检查回应关系

每句是否：

- 回答字面问题；
- 拒绝回答但暴露风险；
- 改写问题；
- 利用对方刚说的词；
- 用行动造成更强回应。

角色可以答非所问，但必须有躲闪或反制的意图，而非作者忘了上一句。

### 10.3 删除共同已知说明

标出人物彼此都知道的背景。保留有争议的解释、责任与关系含义，删除只为观众复述的百科句。

### 10.4 检查策略变化

给每个角色画策略序列：

```text
试探 → 证据受阻 → 借第三人施压 → 暴露自己代价 → 退出/决定
```

这只是记录实际序列，不是预设模板。若一人从头到尾只重复一种策略，检查是否需要压缩。

### 10.5 交换说话者测试

暂时交换两人的台词：

- 若情节和关系几乎不变，补入各自的目标、证据观和关系风险；
- 若只是词汇不合但行动完全通用，表面口癖过多、人物策略过少；
- 若交换后明显违背谁愿意付代价、谁能公开、谁回避什么，人物腔调就立住了。

### 10.6 朗读与可表演性

朗读检查：

- 句子是否能在当前动作中说出；
- 表演提示是否与台词/动作重复；
- 呼吸、打断和沉默是否有行动原因；
- 长说明是否可以被对方打断、质疑或要求证明；
- 重要话语之后是否有行为后果。

### 10.7 保护风格

修订只解决已指出的问题。不要把方言、笨拙表达、重复、长句或含混一律“润色”为同一种利落金句。

## 11. 合成示例

情境：亡母留下老街社区打印店和一份盖有红印泥公章的《五年免租及拆迁补偿归承租方补充协议》原件，一直锁在店里的铁皮文件柜里。弟弟岑放在外欠了八万赌债，私下答应帮急着收铺拆迁的房东偷出原件销毁；但房东只先付了两万定金，岑放怕交出真原件后房东赖掉六万尾款，只拿遮掉红章底栏的复印件糊弄了房东，真原件仍锁在铁皮柜里。姐姐岑予赶在闭店前冲回店里，要从弟弟手里拿回铁皮柜钥匙、保住原件。

### 11.1 信息朗读版

```text
岑予：妈妈把五年免租协议原件放在铁皮柜里，你把钥匙给我。
岑放：我不能给你，因为我欠了八万赌债，已经答应房东把原件交给他换钱了。
岑予：可是我是你的姐姐，这家店是我们俩的，我有权看协议。
岑放：我们关系不好，而且房东还没给齐尾款，所以我只给了他复印件。
```

问题：双方像念说明书一样直接讲完背景和底牌，既没有利用现场筹码施压，也没有试探对方到底知道多少。

### 11.2 让台词行动

```md
岑予按下门口卷帘门遥控器将店门落锁，把遥控器揣进外套兜里。

岑予：铁皮柜钥匙拿来。

岑放：你先把卷帘门升上去。原件我已经交出去了，开柜子也是空的。

岑予：真交出去了你慌什么？让我看一眼空柜子，我立刻开门放你走。

岑放一把捂住右侧裤兜，不让那串黄铜钥匙隔着布料响出声。

岑放：房东赶着拿去办拆迁手续，只要手里有份协议交差就行，谁还管柜子空不空。

岑予：他费尽心思要赶咱们净身出户，会不验妈按了红手印的那页补充条款？

岑放（被激得脱口顶回去）：他连六万尾款都没结清，难不成我傻到把带红章的那页白送他？

岑予放在兜里的手慢慢松开遥控器，目光钉在他捂住的裤兜上。

岑予：也就是说，带红章的原件还在柜子里。
```

对白动作：

- **第一轮（拿门锁逼交钥匙）**：岑予先落锁卷帘门断弟弟退路，逼他交出铁皮柜钥匙；岑放拿“原件已交、先开门”挡回去；
- **第二轮（抓反常反应逼问）**：岑予抓住他“既然交了为什么不敢开空柜子”的破绽紧逼；岑放捂紧裤兜钥匙，用“房东只要份协议交差”搪塞；
- **第三轮（激将逼出底牌）**：岑予点破房东绝不会收一份没红手印的废纸；岑放怕被姐姐看扁，脱口说出“他尾款没结清我怎么可能把带红章那页白送他”；
- **场景结果**：岑予从弟弟的自我辩解里当场坐实“真原件还在铁皮柜里”，立即松开遥控器准备夺钥，把口头试探推向正面争夺。

关系与信息通过每轮筹码与策略变化自然显现，不用把句子缩成没头没尾的谜语，也不用靠人物自白“我们互不信任”。

### 11.3 同一事实的不同人物腔调

事实：带红章的协议原件仍在店里铁皮柜中。

- 盯死证据的岑予：“房东拍过来的那页连妈的红手印都没有——真原件根本没出这道门。”
- 拿尾款当算盘的岑放：“我是答应过给他，可他六万尾款没到账，我凭什么先把真家伙交出去？”
- 先礼后兵的房东：“我只管收没收到带红章的原件，至于你们姐弟俩谁开的柜子，你们关起门自己掰扯。”

区别来自人物如何拿证据说话、如何护住自己，不只来自句尾语气词。

### 11.4 温情与生活流：不靠筹码博弈的潜台词与动作分工

情境：老街修表铺拆迁前夜，父亲林建国死死护着一只后盖螺丝松脱的旧座钟（里面藏着给女儿林晚攒了三年的嫁妆存单），不让女儿装箱。

说明书式 + 复述动作版（弱）：

```text
林晚：爸，明天拆迁办就要来收钥匙了，我现在撕下一截气泡膜，把这只旧座钟包起来装箱。
林建国：你别碰这只钟，里面藏着我给你攒的嫁妆存单，我怕你现在看见心里难受。
```

借修表行当说话 + 动作与台词分工版（可演）：

```md
林晚撕断一截气泡膜，伸手去拿工作台上的黄铜座钟。

林建国右手一揽，把座钟往怀里带了半寸，低头拿袖口蹭了蹭钟面玻璃。

林晚：爸，明早拆迁办就来收钥匙了，这旧钟我替你裹好装箱。

林建国（嘴硬）：里头游丝是老瑞士货，磕坏了你赔？

林晚看着他死死按住座钟后盖翘起一角的大拇指，从工具盒里拈起一把细柄一字螺丝刀，递到他手边。

林晚：后盖那颗螺丝松得翘起来了，先拧紧再搬。
```

这里没有对手博弈或审讯套话：父亲拿老手艺人的行话（“里头游丝是老瑞士货，磕坏了你赔？”）掩饰心虚，女儿用递螺丝刀给父亲台阶下，动作做完的事（撕气泡膜、递螺丝刀）台词不再重复一遍。

## 12. 失败征兆与审查问题

### 失败征兆

- 人物轮流复述彼此都知道的背景，或用台词把刚演完的动作再说一遍；
- 每句都直接说出真实意图，且没有这样做的关系理由；或反过来，把温情、喜剧与日常关心强行写成全员试探与筹码算计；
- 所有人用同一种证据观、句式和价值判断；
- 一方持续发问，另一方持续完整回答；
- 对方已经反制，角色却重复原要求；
- 台词很“狠”或很“金”，却没有身份与筹码支撑，也没有让任何人改变行动；
- 每句后都配无功能的表情动作，或把独立动作塞进台词括注加重表演负担；
- 沉默、打断只用于制造节奏，不留下后果；
- 为了含蓄而让观众没有任何推断依据；
- 为了利落而抹掉角色的笨拙、地方性或关系差异；
- 用对白长度或比例判断好坏；
- 写作所有者把自己的偏好当成终审结论。

### 审查问题

审查者引用具体台词与相邻动作回答：

1. 每个主要人物此刻对谁说、想达成什么（争取、施压、护短、留体面或递台阶）？
2. 冲突戏里说话者使用了什么策略、对方怎样反制？温情、喜剧或生活流段落是否贴合人物关系分寸而非强套博弈？
3. 哪句话改变了信息、权力、关系、情绪或下一动作，且没有复述刚演完的动作？
4. 潜台词的风险或分寸是什么，观众有什么推断依据？
5. 必要信息为何必须在此刻、借这种关系互动说出？
6. 交换说话者后，哪些台词会失去人物身份与逻辑？
7. 动作、停顿与打断是否改变了现场关系、持物或公开范围，而非充当逐句填充物？
8. 修订建议是在解决证据明确的问题，还是把个人口味冒充规则？

所有者根据证据修改对白；需要 verdict 时另起审查动作并记录证据。审查可以由未参与写作的
reviewer 完成，也可以诚实标注为自检；所有者修改本身不自动等于通过。
