# 聚合与实体

聚合以 S2 的逐章提取为输入。核对硬事实时先回查对应白描，证据不足再按定位回读原文片段，不重新通读全书。

## 先识别故事框架

先识别故事框架，再按相应的目标与冲突切分剧情单元。

| 框架 | 特征 | 切单元的依据 | 改编提示 |
|---|---|---|---|
| 升级流 | 等级/境界体系清晰，按阶段推进 | 按等级阶段 | 阶段边界天然是集边界 |
| 复仇线 | 核心矛盾明确，目标驱动 | 按复仇对象或阶段 | 每个对象一个小高潮，适配短剧 |
| 单元剧 | 每卷独立故事，弱连续性 | 按单元 | 与短剧的集结构最贴合 |
| 多线交织 | 多视角/多时间线 | 按线索切，交叉点单独标记 | 竖屏里最贵：观众要记住的人最多 |
| 蜕变成长 | 主角内在变化为主线 | 按成长阶段 | 内在变化要找到外部载体才成立 |

判定方法：扫全部章节概要 + 首尾各三章的提取。判不出来时写「框架不明确」并说明原因，
不硬套——套错框架会让后面每一个单元都切在错的地方。

框架识别的结论写进 `story-units.md` 开头，并与 S1 `triage.md` 里的框架判断对照：
不一致时写清哪一个错了、为什么。

## 剧情单元

一个单元记录六项：

| 字段 | 写什么 |
|---|---|
| 标题 | 15 字以内 |
| 章节范围 | 用索引的 `sequence` 起止 |
| 进入状态 | 单元开始时，谁知道什么、谁有什么筹码 |
| 核心冲突 | 具体的对抗对象 + 具体的冲突事件 |
| 代价 | 这个单元里谁付出了什么，不写「无」 |
| 出去状态 | 单元结束时改变了什么，下一个单元必须继承哪些事实 |

进入状态与出去状态必须能对接：上一个单元的出去状态就是下一个的进入状态。
对不上说明中间漏了一个单元，或者边界切错了。

## 单元粒度

| 粒度 | 例子 | 问题 |
|---|---|---|
| 过细 | 「获得神器」（1–2 章） | 只是一次事件，还成不了一个单元 |
| 过粗 | 「主角的成长之路」（1–100 章） | 只是全书主题，大而无当 |
| 合适 | 「识破假账与夺回老铺」（1–6 章） | 有明确目标、具体对手、核心人物和完整起落 |

一个单元必须同时满足四条：有独立且可衡量的戏剧目标；有具体的对抗力量；有本单元特有的
核心角色（可与其他单元共享部分角色）；有自己的紧张—缓和节奏。

四条里缺一条，它多半是另一个单元的**阶段**，降级处理即可，不必单独建条。

## 阈值自检

聚合后跑三条边界复核信号：

| 指标 | 参考值 | 算法 | 不达标怎么办 |
|---|---|---|---|
| 归属置信 | ≥ 0.85 | 确实推动本单元冲突的情节点 / 已被划入该单元的情节点总数 | 低于线的单元标「待复核」，不删 |
| 覆盖率 | 85%–95% | 已归类情节点 / 总情节点数 | < 85% 走散落兜底；> 95% 复核是否过度归并 |
| 重叠率 | ≤ 35% | 跨单元共享的情节点 / 总情节点数 | > 35% 复核是多线交叉还是边界重叠，再判断是否合并 |

计算「归属置信」时，将顺手划入本单元但只服务其他支线或过场闲聊的情节点从分子中剔除；真正同时推动两个单元的多线交叉情节点，在两个单元里均计入分子（同时计入「重叠率」）。

**小体量素材例外**：不足 30 章、单主线连续叙事的材料按时序切分时，覆盖率天然接近 100%，复核重点是「是否把两条剧情硬并进同一单元」，不必强行压低到 95% 以下。不要为凑阈值人为拆分或合并单元。

## 散落情节兜底

覆盖率不足时执行，目的是**不丢情节点**，不是强行塞入单元：

1. 孤立比例 `< 5%` 直接标「少量散落」，不再处理。
2. 收集未归类情节点，按角色重叠、地点重叠、因果关系判相关性：强相关归入并标 `[孤立归入]`；中等相关归入并标 `[低置信归入]` 待复核；弱相关**不强行归入**。
3. 弱相关按主题聚类，聚出 5 个以上情节点才形成候选单元并标 `[聚类生成]`。
4. 仍无法归类的按章列入 `story-units.md` 末尾散落清单并注明原因，**宁可留在散落清单也不要塞进不相关单元污染进出状态**。

## 节奏与情绪

`rhythm-and-emotion.md` 写四件事，每条均须回指到章或情节点（无源断言直接删去）：

- **关键信息推进**：某条信息何时进入读者视野 → 如何被延迟、误导或验证 → 何时爆发 → 余波与新钩子。
- **情绪触动点索引**：每个触动点落在哪一章、由哪条情节点承担。
- **长间隔说明**：连续 3 章以上无触动点时，写清作者用什么维持期待（改编时作为合并或删减对象）。
- **爽点表**：见下一节。

### 爽点表

选段和切候选集前，先按**观众收益**给全书情节点从高到低排名（`craft_default · NVA-13`；本书内部相对排，不打分）：

| 列 | 写什么 |
|---|---|
| `PAY-<N>` | 稳定编号，供候选集引用 |
| 位置 | 章（`sequence`）与情节点 |
| 类型 | 打脸、奇观、反转、身份揭露、奖励兑现、危机、关系破冰、情感兑现、喜剧反差，可多选 |
| 谁兑现 | 主角、对手、旁观者或群体；**旁观者完成的兑现同样入表**（群里改口、围观者集体道歉、老前辈当众表态） |
| 收益落在谁身上 | 被反制的压迫者（此前压迫越具体，落差越大），或被护住、被认出、关系破冰的当事人 |
| 首集能力 | 能否同时交代主角身份、眼前危机与目标（能则标为开篇替换点候选） |
| 依赖 | 观众要先知道什么才看得懂，可怎样在开场后补 |

喜剧反应、奖励清单等局部爽点同样入表。

## 人物归并

跨章去重遵循**一人一实体**：无法确定是否同指时分开建条，不强行合并。称谓分五类：

| 类型 | 定义 | 可合并 | 例 |
|---|---|---|---|
| 专名 | 全名、常用名 | 是 | 「顾禾」「顾小禾」 |
| 绰号 | 外号，须有同指证据 | 是（证据充分时） | 「城东那位」经文中点明即为某人 |
| 描述性称谓 | 按外形或角色描述 | **否** | 「红衣女子」「随从」 |
| 头衔职务 | 泛指某个职位的称呼 | **否** | 「护卫队长」「家主」 |
| 姓氏＋头衔 | 带姓氏或名的称呼 | 是（证据充分时） | 「李队」「陈记者」「王厂长」 |

**判据**：去掉头衔后仍剩姓或名（如「李队」「陈记者」），有同位说明、括号别名、上下文指代或改名证据即可合并（「读起来像同一个人」不算证据）；不带姓名的泛指头衔（如「护卫队长」「家主」）可由不同人先后担任，一律不合并。

按出场章数占比、是否推动主线、是否有独立动机与变化分级。每条人物记录 `unresolved` 与来源引用（仅为候选，正式资产由 `$short-drama-assets` 从已接受剧本建立）。

## 设定归纳

从提及数据归纳世界规则、力量体系、地理、势力与特殊设定，每条标注出场章号；标不出章号或原文未写清的写「原文未明确」，不从题材惯例脑补。相互依赖、共同起作用的设定合并为一条（如「戒指 + 里面的残魂」），独立设定分开列。
