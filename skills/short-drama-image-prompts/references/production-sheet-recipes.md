# 生产参考板决策：版式与布光词汇

通用八段式写法见 [common-recipe.md](common-recipe.md)；本文档规定多视图/生产参考板的版式约束与识别布光选择（`IMG-02` ~ `IMG-05`）。

## 1. 三类生产参考板版式要点

纯白底、无情绪、三视图仅是可选版式之一；只要服务下游识别且不混淆身份与临时状态，均可按需选用单视图、多视图并排或带受控上下文的参考板：

- **角色参考板**：按复用职责选择头肩、全身或正/侧/背并排视图。**多视图并排时必须在正文中写明「画面内无视图标签、无引线箭头、无尺寸标注、无图注」**。社会处境（磨损、整洁、改制、借穿不合身制服）须引自已确认设定，不从性别、贫富或反派标签自动推导阴影脸或可疑眼神。
- **场景方位板**：仅在摄影方向改变入口、可见地理、光源或遮挡时单立视角（不为凑齐四面八方建板）。正文按当前空间最易混淆的锚点关系起笔，写明观察侧、朝向、固定地理、本版本光态与空场/文字政策。
- **道具参考板**：优先让轮廓、可操作部位（如钥匙齿形、药瓶封口、箱扣）、尺度参照、当前状态与文字承载面清晰可比；依赖佩戴或安装尺度的道具可选用受控环境背景。

## 2. 识别布光词汇表（按“要比较什么”选）

根据本张参考板必须让下游看清的结构选择光型，**严禁按性别、年龄、贫富或善恶标签套用默认光型**（如“女性一律柔光、男性一律侧光”）；绘制形态下同样按此表决定阴影形状与边缘硬软：

| 光型 | 突出并便于比较的视觉特征 | 压制或损失的信息（及禁用情形） |
|---|---|---|
| 均匀正面光（平光） | 五官相对位置、妆面、服装固有色与图案 | 颧骨、鼻梁、下颌等骨骼体积起伏 |
| 侧光 / 高位斜侧光 | 明暗交界线两侧的骨骼体积、轮廓起伏与不对称特征 | 暗侧细节 |
| 顶光 | 眼窝、鼻下、颌下的纵向结构关系 | 暗区识别细节与服装层次 |
| 底光 | 反转日常明暗方向的非常规体积 | 破坏常规面部结构读法，**识别板禁用** |
| 大面积柔光 | 材质纹理、肤质、布料表面状态 | 形状边界与轮廓锐度 |
| 小面积硬光 | 金属/玻璃反射差异、磨损、高光与工艺痕迹 | 明暗过渡信息；易放大局部形变 |
| 轮廓光 / 逆光边缘光 | 外轮廓、发型剪影、服装廓形与前后分离 | 面部五官识别信息，**不得单独用于身份板** |
| 场景内实际光源 | 状态板与环境参考板的光向可核对性 | 中性比色条件（须与场景已确认光向一致） |

## 3. 合成示例：伪装期双视图角色板

- **身份锚点（跨造型保持）**：窄长脸、左眉旧缺口、略前倾的站立重心。
- **当前造型（伪装期有效）**：借穿深蓝制服（袖长略短不合身），左胸牌为无字图形轮廓（`symbolic`）。
- **版式与布光**：头肩正面（看清眉缺口）与全身侧面（看清重心与袖长）两视图等高并排；浅灰中性背景，高位柔侧光兼顾面部骨骼与制服布料层次；画面内无视图标签、无引线箭头、无尺寸标注、无图注。
