# 题材、画风、场景与提示词 Know-how 学习

沿完整项目文本链研究：在特定题材承诺、制作形态、视觉方向和场景职责下，哪种提示词机制能解决哪类具体问题。

## 五轴选样矩阵

目的性选样同时记录以下五个轴（缺失项记 `unknown`）：

1. **题材/观众承诺**：爽感、悬念、亲密、喜剧、生活观察、评论讲述等；
2. **制作形态/视觉语言**：实拍、二维、三维、水墨、Q 版、国漫等项目自述，以及可观察的形、材质、光色、边缘、密度和运动预算（不以风格代码或供应商名代结论）；
3. **场景功能**：亮相、谈判、证据揭示、亲密冲突、动作任务、群像、过渡、结尾落点等；
4. **提示词职责**：身份、地点地理、构图、风格、状态、手物接触、动作、表演、摄影、声音；
5. **版本角色**：创作来源、派生投影、修订请求、外部执行文本、授权观察或运营状态。

## 沿完整链追踪提示词变化

按同一项目与版本追踪：故事/场次意图 → 剧本事实 → 资产身份/地理/状态 → 场次导演选择 → 关键帧/图片规格 → 动作/表演/摄影/声音提示词 → 创作者修订请求 → 授权文字观察（若有）。重点比对：

- 上游必须保持哪些事实，提示词新增了哪些执行选择；
- 描述是在保护身份、地理与边界，还是在堆砌泛化画质词；
- 修订改动的是观看节奏、空间、动作量、表演信号、光线还是参考策略；
- 同一机制换到其他题材、画风或场景功能下为何失效。

媒体观察证据的准入与字段约束按 [cards-and-coverage.md](cards-and-coverage.md) 的 `input_reference` / `generated_result` 规则执行。

## 压缩为可迁移机制

把表层词句压缩为：`观众状态 → 场景问题 → 提示词/导演机制 → 可观察信号 → preserve_set → 失效边界`。

例如提示词表演描述中，`receive / mask / choice` 指接收信号、掩饰反应或作出选择，`attention handoff` 指注意力从一个人物或动作移交到另一个的时点。“多人同框杂乱”应压缩为注意竞争问题：候选机制是保留单一主要动作、给其余角色分配不同的 `receive / mask / choice` 并声明 `attention handoff`，而不是机械规定“所有群像只能有一个动作”。不要迁移供应商参数、编号、原句、罕见组合或把单项目的“多空镜、无 BGM”升为通用规则。
