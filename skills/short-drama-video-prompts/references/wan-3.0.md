# Wan 3.0 提示词写法

在目标模型配置明确指定 `target_video_model: wan-3.0` 时使用。推荐配置：

```json
{
  "target_video_model": "wan-3.0",
  "video_prompt_dialect": "wan-3.0",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 2, "max": 30},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference"],
  "audio_generation": "same_pass"
}
```

Wan 3.0 直接采用连贯自然的指令叙述，素材编号使用 `图1`、`视频1`、`音频1`，不混用 `@图片N`、`{…}` 或 `<声音>` 等其他模型符号。

## 模式互斥、素材上限与时间段语法

| 本镜传入素材组合 | Wan 3.0 模式 | 正文指代方式 |
|---|---|---|
| 无参考素材（`无（文生视频）` 或 `无`） | 文生 | 完整写出开场画面，不出现素材编号 |
| 仅 1 张 `用途：起始帧` | 首帧 | 顺着首帧起手姿态直接写动作演变，不另标 `图1` |
| 1 张 `起始帧` + 1 张 `结束帧` | 首尾帧 | 终点保持在分镜既定结束状态 |
| 含多张参考图、参考视频或参考音频 | 参考 | 用 `图N`、`视频N`、`音频N` 逐一点名各自职责 |

- **模式互斥与按焦取舍**：首尾帧模式与 `reference_image` / `reference_video` / `reference_audio` 互斥；「起始帧 + 角色/场景图」走参考模式并写明 `图1 是本镜开场画面`（未传起始帧时写清景别切线防拉远）。单次最多传 10 张参考图、5 段参考视频、5 段参考音频（音视频单段 1–15 秒且同类总长 ≤15 秒），首尾帧各最多 1 张，提示词上限 20000 字符；超过 10 张图上限时按本镜景别与视觉焦点取舍（见 [模型与交付配置](model-and-delivery-profiles.md)）。
- **支持时长与多镜时间段**：`duration` 支持 **2–30 秒整数**（传参考视频时输入加输出总长 ≤30 秒；传 `-1` 为智能时长，定长分镜直接传正整数秒），分辨率支持 1080P / 720P / 480P。多镜合生按 `(0:00 - 0:03) 镜头1，近景：…` 写出首尾紧接的时间段；多镜挂关键帧时首句写明「图1、图2 依次是两个镜头的画面，图3 是老者」，各段写「按图N构图」。

## 对白、参考音频与智能改写开关

- **对白写法与语速**：紧跟说话人开口动作写 `说道：“逐字台词”`（如「她望着对面，声音轻稳，用普通话说道：“……”」）。Wan 3.0 中文常速约 4.6 实读字/秒，动笔前按 [台词时长估算](performance-action-timing.md#台词时长估算) 留出余量防句尾吞字；同框不说话角色的闭嘴与取景配合见 [运镜、现场声与跨镜连戏](camera-audio-continuity.md)。
- **参考音频与文字边界**：跨镜稳音色写「图1 中的女子说话时，音色参考音频1」；挂本句干音做逐字对口型时写「口型与音频1 逐字同步」并出片复查嘴型起止。不需要配乐时写「无背景音乐」；存在乱码或伪字幕风险的场景按需补充无字幕叠加要求，并写清画内必读文字的所在表面与位置。
- **`prompt_extend` 与视频编辑 / 延长**：官方 API 默认开启 `prompt_extend: true` 自动扩写提示词，易改乱逐字台词、切镜数或无配乐要求，直连 API 时建议显式关闭或出片后逐项核听核看。局部改片与续写均通过传 `reference_video` 加正文触发词触发（不写 `任务类型` 字段）：改片写「编辑视频，把视频1 中……改成……」；按需向后续写时传 `ratio: adaptive` 并写「将视频1 向后延长 N 秒」。

依据（2026-09-26 核对）：[Wan 3.0 视频生成 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)：输入模式与互斥、素材上限、时长、`prompt_extend`、编辑与延长；[Wan 3.0 视频生成指南](https://platform.qianwenai.com/docs/developer-guides/video-generation/wan30-video)：时间段写法、`说道` 对白、素材编号、编辑与延长关键词。
