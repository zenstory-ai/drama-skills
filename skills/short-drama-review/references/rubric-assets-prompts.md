# 视觉设定与生图提示词核查清单

对照 `short-drama-assets` 与 `short-drama-image-prompts` 的阻断级不变量核查《视觉设定.md》与《图片提示词.md》；发现问题按条目归属分别退回 `short-drama-assets` 或 `short-drama-image-prompts` 技能。

## 1. 视觉设定阻断级核查（路由 → `short-drama-assets`）

- **出场依据、归类与下游引用**：核对设定条目是否有《剧本.md》场景 ID 与可见依据（`AST-01 · reviewed_invariant`）、每次出场是否明确归类且指代含糊处未硬猜（`AST-02 · reviewed_invariant`），以及下游引用的每一项设定与状态都能在《视觉设定.md》落到实处（`AST-05 · structural_invariant`）。
- **固定本体 vs 阶段变体（`AST-03 · reviewed_invariant`）**：严查一票否决硬伤——换套衣服就拆成新角色、把互斥妆造揉进同一状态、跨场道具无故瞬移或丢字，或仅凭“主角/反派”脑补刻板脸谱。
- **跨语种 `- 提示词名称：`（`AST-13 · reviewed_invariant`）**：提示词与条目标题跨语种时，核查正文实际点名的 `人物`（及按需 `造型`/`地点`/`道具`）是否填写大小写一致的拼写（不点名或需防重名误判时写 `无`；脚本仅输出软 `WARNING` 提醒复核）。
- **角色声线（按集选配，不强制启用）**：未启用 `- 角色声线：` 的剧集整集省略即可，绝不因未填报错；一旦本集启用，则《剧本.md》所有发声角色（含对白、`[VO]`、`[OS]`）均须填写非空且不为 `无` 的 `- 角色声线：`，并核对本嗓与单场演法分离（`AST-07 · reviewed_invariant`）、参考音频控制与 `不得控制` 边界（`AST-08 · reviewed_invariant`）、听感核验依据（`AST-09 · reviewed_invariant`）及同一专名全篇唯一读音拼法（`AST-10 · reviewed_invariant`）。

## 2. 时代背景考据与误杀防线

- **只拦截跨时代穿帮硬伤（`AST-14 · reviewed_invariant`）**：如古装混入玻璃幕墙/塑料、九十年代掏出全面屏手机，或无剧情依据把现代场景写成淘汰年代器物。
- **放行日常物理旧化与款式提醒**：旧夹克、桌面磨损、墙皮斑驳、褪色布料、`worn`、`dusty` 等正常生活旧化质感**绝不因原著未逐字点名“旧/斑驳”就判违规**；漏写 `- 时代背景：` 或款式偏简仅作 `note` / `craft_default` 提醒；仅台词随口提及不入画的名词不建档、声线区分或选音细节偏简亦不触发 `REVISE`。

## 3. 生图提示词阻断级核查与误杀防线（路由 → `short-drama-image-prompts`）

- **阻断级硬账**：
  - `IMG-...` 指向的《视觉设定.md》条目名称或造型/视角/状态悬空（`IMG-01 · reviewed_invariant`）；
  - 被生效 `- 连戏锁：`（`图片提示词项`）点名的 `IMG-...` 在 `### 可复制提示词` 中漏写或改动了原字 `锁定词`（`IMG-13 · reviewed_invariant`）；
  - 角色/场景空镜/道具/Lookdev 违背身份一致、布局朝向清场、尺寸字迹或同场同光多视角主光统一（`IMG-03`、`IMG-04`、`IMG-05`、`IMG-10`、`IMG-11`，均为 `reviewed_invariant`）；
  - 要求直出清晰可读文字却挂全局禁字约束（`IMG-07 · reviewed_invariant`），或未实看/无说明就断言参考图无杂字水印（`IMG-08 · reviewed_invariant`）；
  - `- 参考：` 绑定非法路径、`PLAN-...`（生图阶段只收 `无` 或真实 `REF-...`）、十项标准 `用途` 越界或控制边界串扰（`IMG-09 · reviewed_invariant`）；
  - 可复制提示词混入私有路径、网址、内部编号或人工返工吐槽。
- **防误杀护栏**：
  - **明确支持分栏设定对照板**：只要提示词写明了分栏/并列版式且同板属于同一角色造型或明确标注的开合/多视角对照，即属合规工业设定图，不得误判为“多动作混杂”或“状态互斥”（仅拦截非分栏单幅画面里的姿态/持物互斥）。
  - **画风词位置与局部改图细节不作阻断**：提示词开头写明画风媒介（如二维手绘国漫、风格化三维）是稳住非实拍画风的常见做法；空泛画质套话或局部改图不变特征漏写仅作 `note` / `craft_default` 建议，绝不判 `REVISE`。
