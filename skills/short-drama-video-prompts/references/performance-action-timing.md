# 表演弧线与动作计时

## 1. 单镜动作容量与同步边界（`VID-05`）

在分镜给定的秒数内，优先保住推进剧情、改变人物强弱势并落到分镜「终点」的核心动作与关键反应，砍掉纯粹为了凑热闹而硬塞的琐碎杂活（结合走位距离、动作幅度与台词停顿综合拿捏，不设“每镜最多几个动词”的机械公式）。

- **接触发力层次**：手部与关键道具互动时，按“靠近 → 触碰参照物 → 发力位移 → 落定停稳”交代清楚；涉及递物换手时点明谁递谁接与松手时机。
- **并行与先后的界限**：“同时 / 与此同时”只用于真正互不干扰的并行变化（如一边压低声音开口一边缓慢抬眼、窗外雨丝持续飘落、摄影机平稳微推），不把互为因果前提的前后动作硬揉成一团。

## 2. 微表情发力先后与同框层次（`VID-16`、`VID-26`）

人物受刺激后的真实反应存在生理与心理先后顺序，避免写“平静 30% → 震惊 100%”之类的数值标签或干瘪情绪副词：

- **微表情与肢体发力先后**：通常按「**感官截获（眼神骤定 / 手头动作顿住 / 呼吸屏住半拍）→ 情绪渗出（眉心微蹙 / 笑意僵在嘴角 / 下颌绷紧）→ 身体重心与决断动作（上身离开椅背 / 把文件推回 / 转身迈步）→ 落定保持**」展开。先定住眼神或停下手上动作半秒再变脸发力，比所有部位一齐乱动更有戏剧张力。
- **说话口气与身体配合**：剧本里的 `（情绪）` 括注同时锚定面部神态与念词节奏（如话到嘴边咽回半截、突然压低嗓音连名带姓点破、语速放慢一字一顿），确需改动情绪走向时退回 `$short-drama-write`。
- **多人同框反应分工（`VID-16`）**：只给本镜真正发生状态变化的角色写表演过程；纯过场镜或神色不变的旁观者不必硬凑戏份。多人同受冲击时写出处境与反应时差（如知情者目光微沉不动声色，蒙在鼓里的人慢半拍转头追看），绝不给满屋子人复制同款“全场震惊”。视线或戏眼转移时，顺手写清焦点从谁/哪件物移向谁/哪件物。

### 不同模型与制作形态的反应镜调校（`craft_default`）

- **MiniMax H3 反应镜**：拍听闻消息后的近景反应时，按「**触发动静 → 用一个准确情绪词点名（如“他瞬间怔住”）→ 给两处在当前景别清晰可见的外露破绽（如眼神定死、拇指悬停半空；嘴角笑意凝固、小臂收紧）→ 1.5 秒内落定保持**」组织。光写抽象情绪词容易五官乱飞，只列零碎动作不点情绪词又容易力度发软。
- **Seedance 2.5 反应镜**：保留连贯的「触发 → 停顿消化 → 神情与肢体递进 → 落定」完整弧线，不必套用 H3 的 1.5 秒定格写法（见 [Seedance 2.5 写法指南](seedance-2.5.md)）。
- **形态幅度差（`VID-26`）**：动态漫与强冲突爽剧在情绪爆点用整脸神情与带手臂/上身的大幅度动作把张力打透；AI 真人剧日常戏收在克制的眼神与微动作里，到情绪顶点再给出一记干净利落的重拍（如猛然抬眼盯死、动作急停或干脆拂袖转身）。

## 3. 动作节奏锚点与台词发声窗口（`VID-04`）

### 顺序锚点与标秒卡点

- **常规节奏锚点**：无需卡死时间码的镜头，用动作与声音互为锚点排定节奏（如“门锁咔哒落定后她停半拍再抬眼”“趁对方伸手去接的半途开口”），可顺带点明“起手定住约半秒”等局部停顿。
- **精确标秒分段（`VID-04`）**：需要精确卡准切点或配合多段动作时，列出互不重叠的起止秒数（有重叠动作时注明重叠区间），覆盖总长必须分毫不差等于本镜分镜时长——超时会截断句尾或落幅，留出空白余秒则会让模型把动作慢放拖长：
  ```text
  0.0–0.8s：保持起手坐姿，听见门闩响动后笔尖顿住、视线射向木门
  0.8–2.6s：左手按紧账册页角，上身微前倾（1.1s 起压低嗓音开口说话，与前倾同步）
  2.6–4.0s：话音落定后保持按册握笔姿态，目光锁住门口直至镜头结束
  ```

### 台词时长估算

含对白、VO 或 OS 的音画同出镜头，动笔前核对分镜留给说话的有效发声窗口：扣除起手反应停顿、无法边说边做的大动作以及同镜他人轮流接话的耗时后，剩余秒数须从容装下本句台词（已有实录配音时按实测秒数核对；未录音时按目标模型常速留足气口余量，防止字数超载导致模型赶词或吞掉句尾）。

若动作与台词在规定秒数内挤不下，按以下顺序化解：（1）砍掉无关环境动静与次要手势；（2）把能边说边做的姿态变化叠入念词时段；（3）仍装不下时退回 `$short-drama-storyboard` 加长镜长/拆镜，或退回 `$short-drama-write` 精简台词——不在本阶段私删台词、擅改旁白或硬写“极速念完”。
