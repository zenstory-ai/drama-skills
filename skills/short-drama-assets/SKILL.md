# 短剧资产拆解

从剧本提取可复用、可持续的视觉事实，统一写入 `剧集/<EP>/视觉设定.md`（每个条目使用二级标题 `## <人物|造型|地点|道具> · <中文名称>`）；每次出场先判断身份
与状态，剧本语义、镜头走位和生成提示词由各负责技能处理。

## Quick Start

```text
用 $short-drama-assets 从 EP001 剧本拆完人物、造型、地点、道具和本集状态
```

## 入口与边界

现成剧本可以直接拆资产。先区分：

- **身份**：换一个就不再是同一个人、地或物；
- **变体**：身份不变，但服装、伤势、时段、天气、开合或持有状态改变；
- **镜头瞬态**：姿势、视线、左右手、站位和相机角度，由分镜拥有；
- **故事语义**：知识、目标、关系和情绪由写作/开发拥有，只引用可见后果。

## 工作流

1. 读取当前范围剧本与已确定的项目视觉方向；尚未确定时代锚点时，按原著或剧本事实提炼（见 [时代锚点](references/era-anchors.md)），证据不足标为待决定。
2. 逐场提取实体、可见描述、状态变化与含混指代（见 [出现提取](references/occurrence-extraction.md)），对每次出场判定复用、新变体、新身份或未决（见 [身份与变体](references/identity-vs-variant.md)）；含混指代不猜。
3. 编写最小可识别设定：先写跨场不变的 `识别锚点`，再写 `本集状态`、变化原因与生效范围；不复制剧情摘要，不擅自补造品牌、文字或私密信息。
4. 持续限制后续动作空间的身体—物件—空间关系写进有生效范围的状态，可独立识别的物件单建道具资产，交分镜逐镜落实（见 [道具与状态](references/prop-and-state.md)）。
5. 核对造型/伤势、持物/所有权、道具状态、地点时段/天气/光态与跨集结束状态（见 [连续性变化](references/continuity-delta.md)）。
6. 对跨镜出现且不一致会被看出的不变可见事实声明 `连续性锁`：锁面用提示词语言写成最小名词短语，写在所属条目下（服装锁写在 `造型` 条目下），分镜未出时镜头范围写 `入画`（见 [跨镜一致性锁](references/continuity-lock.md)）。
7. 提示词正文语言不是中文或条目名易与普通词同形时，按 [人物与造型](references/character-and-look.md) 填写 `画面代称`（`AST-13`）。
8. 整集请求一次处理完整集，末尾集中汇报关键身份决定与未决指代。

## 按需知识

默认只读本 SKILL、当前剧本和视觉方向。按需查阅：

- 阶段边界与规则分级：[阶段契约](references/stage-contract.md)
- 定时代、写时代锚点，或避免把场所/设备/服装无依据写旧：[时代锚点](references/era-anchors.md)
- 从剧本提取资产出现证据：[出现提取](references/occurrence-extraction.md)
- 新身份、复用、变体或未决判定：[身份与变体](references/identity-vs-variant.md)
- 人物识别与造型层次：[人物与造型](references/character-and-look.md)
- 地点地理、视图与固定锚点：[地点与视图](references/location-and-view.md)
- 功能道具、所有权、状态变化与可读文字政策：[道具与状态](references/prop-and-state.md)
- 声音参考的身份与授权边界：[声音方向](references/voice-direction.md)
- 跨场、跨镜、跨集状态交接：[连续性变化](references/continuity-delta.md)
- 跨镜服装/道具颜色、材质锁面：[跨镜一致性锁](references/continuity-lock.md)
- 完成前漏项与一致性核对：[资产审查清单](references/asset-review-checklist.md)

## 完成

所有明确出场均已复用、新建、变体化或标为真实未决，且识别锚点、状态变化与连续性锁已写入 `剧集/<EP>/视觉设定.md`。完成后可转 `$short-drama` 做局部或完整机械核对；图片提示词、分镜、审查和生产不自动开始。
