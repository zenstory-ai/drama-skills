# 短剧剪辑与成片

把 `剧集/<EP>/制作成果/` 里的逐镜素材剪辑合成一条成片，取舍依据写进 `剧集/<EP>/剪辑单.md`。
每段使用二级标题 `## CUT-...`，各自绑定一个来源编号和一个真实媒体文件：视频段对应 `MOTION-...`，
关键帧或插片静帧段对应 `SHOT-...` 或 `IMG-...`。

## 快速开始

```text
用 $short-drama-edit 把 EP001 已生产的镜头剪成成片
```

## 入口与边界

- **前置条件**：`剧集/<EP>/制作成果/` 中已有可读的视频文件（或关键帧图片与配音文件），且本机 `PATH` 中装有 `ffmpeg` 与 `ffprobe`（缺失时 `edit_tool.py` 直接报错退出）。同宽高比但分辨率或帧率不同的视频素材，`check` 列入提醒并由 `render` 自动缩放及转换帧率至交付规格；宽高比明显不同（如横屏混入竖屏）时报错拦截，需先用外部工具裁切或留边统一画幅。
- **不反向篡改上游定稿文档**：镜序与镜头作用对照 `分镜.md` 与 `视频提示词.md`，对白、VO、OS、场头时空与 `[画面文字]` 对照 `剧本.md`。剪辑阶段可裁短、删减、调序或用 `--partial` 局部试剪，但不回写篡改上游定稿文档，也不擅自加塞无剧本依据的台词。
- **跨阶段分工**：需要补拍、重出或更换参考图转 `$short-drama-produce`；修改提示词转 `$short-drama-video-prompts` 或 `$short-drama-image-prompts`；修改台词或剧情转 `$short-drama-write`；成片审片交 `$short-drama-review` 或创作者把关。

## 工作流

1. **标定可用区间**：从头到尾播放每条素材，记下画面可用的起止秒数及区间外的毛病（开头呆立、结尾走样、画面发白、动作回弹、重复动作），见 [素材检视与入出点](references/editing-guide.md#素材检视与入出点)。
2. **定位台词起止与入出点**：带台词的镜头先听准整句字音起止与句间停顿；在可用区间内按起手动作、表情反应或气口定入点，在画面信息交代完毕且穿帮露头前定出点，逐段写清取舍理由，见 [镜序与打戏切法](references/editing-guide.md#镜序与打戏切法)。
3. **排定镜序与接镜调色**：核对相邻镜头的动作衔接、空间方位与揭晓顺序；`render` 默认在同场次内执行自动接镜，需要手动微调或关闭校正的段落单独填写 `画面` 行，见 [接镜调色与颗粒](references/editing-guide.md#接镜调色与颗粒)。
4. **处理声音、字幕与画面图文层**：按需配置 `音效`、`配音`、`环境声`、`字幕` 与 `画面文字`（见 [声音字幕与响度](references/editing-guide.md#声音字幕与响度) 与 [静帧段与运镜](references/editing-guide.md#静帧段与运镜)）。
5. **保存、渲染与看片验收**：写出或更新 `剧集/<EP>/剪辑单.md`（未改动段落保留原 `CUT-...` 编号），依次运行 `check`、`render`、`verify`（试剪单场或前几镜时传 `--partial`），按 [交付验收口径](references/editing-guide.md#交付验收口径) 抽帧看画面、回听切点后再交付。

## 剪辑单要求

- **开头交付规格**：写明 `成片目标时长`、`画幅与帧率`、`交付响度`、`字幕`（可按需加写 `接镜匹配：无`、`颗粒：<0–20|无>`）。全集交付时未剪进成片的镜头写 `- 未采用镜头：<MOTION-...或SHOT-...>（理由：文件缺失｜质量不可用｜叙事取舍——说明）`，多条用 `；` 分隔（`--partial` 局部试剪时未入片镜头自动归为提醒，见 [静帧段与运镜](references/editing-guide.md#静帧段与运镜)）。
- **分段条目**：每段使用 `## CUT-<EP>-<序号> · <名称>`。同一条 `MOTION-...` 拆成多段使用时，源视频截取区间默认不得重叠（确需闪回或重放强调时，在第二次及后续重叠分段写 `- 重放：<叙事理由>` 显式豁免；同一张静帧图片可跨多段复用）：
  - `- 来源：<MOTION-...> · <项目相对路径>`（对应 `视频提示词.md`），或静帧段 `- 来源：<SHOT-...或IMG-...> · <图片路径>`（支持 png/jpg/jpeg/webp，入点固定 `0.00`，出点等于时长；硬下限为 `2` 帧即 24fps 下 `0.08` 秒，短于 `0.50` 秒列入提醒）。
  - `- 入点：<秒>` / `- 出点：<秒>` / `- 时长：<秒>`：保留两位小数秒数（不写时码或帧号），满足 `出点 - 入点 == 时长`。
  - `- 取舍：入点=<理由>；出点=<理由>`：写清入出点那一帧的具体画面动作与切镜理由，不写空泛的「节奏需要」。
  - `- 重放：<叙事理由>`（可选）：当本段与前序剪辑段截取了同一源视频的重叠时间区间（如高潮动作重放、悬念闪回）时填写，显式豁免同源重叠报错。
  - `- 声音：<处理说明>`：记录保留原声或外部混音做法（仅作文字记录，`render` 不会按此行文字自动混音）。
  - `- 画面：<接镜校正|无|不校>`：`无` 采用默认同场自动接镜，`不校` 跳过自动接镜，也可填写手动调色参数（取值范围见 [接镜调色与颗粒](references/editing-guide.md#接镜调色与颗粒)）。
  - `- 字幕：<逐字台词原文|无>`：逐字照抄 `剧本.md` 台词与标点（语音转写只用来找时间点，不替代剧本原文）。一段内有多句台词时按顺序连续编号，并写明相对本段入点的起止秒数（各句互不重叠，结束时间可跨入下一镜）：`- 字幕 1：0.20-1.50 请进`。句末可加 `（重点：<词>｜<词>）` 高亮标黄；字幕颜色由工具按剧本角色自动区分（普通对白白色、`[VO] 系统：` 青色、其余 `[VO]` 浅青色）。
  - `- 画面文字 N：<起>-<止> <样式> <项>｜<项>…`：文字内容须在 `剧本.md` 的 `[画面文字]` 行有原文出处（`字卡` 样式还可直接匹配剧本场头 `## EP...-SC...` 中的时间、地点或场景词；组件自带的 `【系统提示】` `【新任务】` `进度` 字样自动绘制，不写进剪辑单；单条可省编号；同屏位置时间段不得重叠）：

    | 样式 | 各项结构 |
    |---|---|
    | `字卡` | 干净无游戏外框的通用字幕卡（适合现代都市、古风悬疑等时空地名、人物头衔或关键信息条，支持 1 至多行） |
    | `卡片` | 每项一行数据卡：首词为名称、末词为数值、中间为单位（如 `本月 订单 128｜退货 3`） |
    | `系统面板` | 首项为打字机逐字浮现的状态行，其余各项为奖励行 |
    | `任务面板` | 依次为标题、目标（打字机效果）；形如 `<数> / <数>` 的项识别为进度条，其余为奖励标签 |
    | `角标` | 右上角单行标签（相邻两段写同一角标且首尾紧接时保持常驻，不重复播入场动画） |

    奖励项末尾可标 `（传说）` `（史诗）` `（稀有）`（不标默认稀有，该后缀不参与剧本原文核对）。`任务面板` 与 `角标` 末尾可加 `（倒计时：<秒>）` 或 `（倒计时：接续）`。
  - `- 音效 N：<起>-<止> <项目相对路径>（起点：<秒>；增益：<dB>）`：时间范围须落在本段之内，增益范围 `-40` 到 `+6`，括号参数可省。
  - `- 运镜：<固定|推近 n%|推近 r%/秒|…>`：仅用于静帧段，方向支持推近、拉远、左移、右移、上移、下移（幅度 `n` 取 `1–30`，速度 `r` 取 `0.1–10`），见 [静帧段与运镜](references/editing-guide.md#静帧段与运镜)。
  - `- 配音 N：<起> <项目相对路径>（起点：<秒>；增益：<dB>；叠音）`：`起` 可填负数提前入声，配音尾音可跨切点延续；短于 `0.50` 秒的自然抢话尾音交叠或括号内注明 `叠音` 时归入提醒而不报错，见 [声音字幕与响度](references/editing-guide.md#声音字幕与响度)。
  - `- 环境声：[<起>] <项目相对路径>（起点：<秒>；增益：<dB>）` 或 `- 环境声：[<起>] 无`：循环铺底直至遇到下一条 `环境声`。

## 命令

命令行工具由 [edit_tool.py](scripts/edit_tool.py) 提供：

```text
python3 <本技能目录>/scripts/edit_tool.py check <剧集/EP001> --project-root <project> [--partial]
python3 <本技能目录>/scripts/edit_tool.py render <剧集/EP001> --project-root <project> [--partial] [--no-subtitles] [--subtitles ffmpeg|remotion] [--remotion-concurrency N]
python3 <本技能目录>/scripts/edit_tool.py verify <剧集/EP001> --project-root <project>
```

- `check`：检查入出点与时长算术自洽、来源编号与全集镜头下落（`--partial` 时未采用镜头转入提醒）、媒体可读与源片时长边界、同源视频区间不无故重叠（写明 `- 重放` 可豁免）、画幅宽高比一致（同比例异分辨率/帧率归入提醒）、字幕与画面文字匹配剧本原文、倒计时接续合法、音效落在本段内、字幕与配音不越界；素材修改时间晚于剪辑单、短于 `0.50` 秒的快闪静帧及短尾音/显式叠音列入提醒，不阻断试剪渲染。
- `render`：裁切分段、自动缩放并统一同比例素材帧率、生成静帧运镜、同场自动接镜、拼接画面、混入音效/配音/环境声、烧录字幕与画面文字、统一整片响度，输出至 `剧集/<EP>/制作成果/成片/` 并保留分段中间文件。烧录字幕默认走 `ffmpeg`（`libass`）；指定 `--subtitles remotion` 或含有 `画面文字` 时调用 [Remotion 图文叠加层](assets/remotion/README.md)（默认并发数为 2）。
- `verify`：实测成片总时长、综合响度与真峰值，列出画面文字、音效与配音在成片中的起止秒数，并标出切点亮度跳变、切点音量跳变与疑似坏帧位置供人工抽帧与回听。
