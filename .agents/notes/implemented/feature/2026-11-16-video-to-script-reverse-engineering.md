# Agent Note: 视频反推剧本流程、烧录字幕拼版与台词画面校对

Status: implemented

补充并调整 [对标拆解增加还原层](2026-11-04-breakdown-private-reconstruction.md) 中“单集还原默认走逐镜五份文档并写入旧版 `设定集/` 目录”的做法；测量、外传与授权隔离边界（`BRK-01`、`BRK-02`、`BRK-11`、`BRK-12`）保持不变。

## Problem

创作者常提出“先把这几集视频反推成《剧本.md》，暂不写分镜和生图视频提示词”。对 23 部真实短剧与漫剧成片做字幕区与画幅扫描，并在隔离的干净子会话中按现行公开技能实跑多集基线反推后，暴露出脚本与工作流两方面缺口：

1. **测量与字幕脚本存在五处缺口**：
   - **字幕框与单字阈值漏截**：22 部带硬字幕的成片里，有 8 部字幕落在纵向 `0.80–0.86`、另有贴底排版的成片字幕下沿到 `0.94–0.985`、长句横向铺到 `0.06–0.94`，原默认 `--band 0.15,0.86,0.85,0.96` 既会截断偏高字幕上半截或长句首尾字，也会削掉贴底字幕下半截；`subtitle-sheet` 只统计纵向行高，不给左右跨度与候选框；`subtitles` 固定 `min_share=0.002` 且不开放参数，独立成句的单字硬字幕（如“是”“嗯”）因描边像素占比偏低被漏掉；同时 `blind_spot` 写着“同一句字幕跨镜头不断开”，实际遇到跨切镜背景明暗突变就会拆成相邻两条。
   - **散装字幕裁图无总览图，且无法挂回 `measure`**：一集常规对白常扫出 70–100 张独立 `Txxx.png`，逐张读取耗费大量工具调用；校完台词后，`breakdown_tool.py transcript` 只认 `segments` 列表而不认 `*.subtitles.json` 的 `events` 结构，导致 `reconstruct.md` 写的“`plan` 对比 `measure` 有声占比与首句时间”走不通。
   - **代表帧拼图漏掉首尾拍**：`measure` 的 `*.sheet.jpg` 只抽每个检测镜头的中点帧且不标镜号时间；遇到集尾最后 1–2 秒低帧差切出的新场次或首拍无声字卡，中点抽帧与默认切镜阈值一起漏掉。
   - **`plan` 缺参数不提示与跨集重放误报**：`reconstruct.md` 只让填语速，没写 `project_pacing()` 还要求填 `seconds_per_action_paragraph`，只填语速时 `plan` 不报 `plan_problem` 却输出空时间轴；`profile` 的 `reprise()` 在 `plan` 模式下把首尾动作描写和台词混做 6 字公共子串匹配，上下集同场景连戏只要共用一件道具或动作词就被误报为“开头重放上集结尾”，与 `measure` 只比对台词的口径不一致。
   - **非登录子会话 `PATH` 漏找本机 `ffmpeg`**：部分子会话环境未加载用户常用二进制目录，本机已安装 `ffmpeg` 与 `ffprobe` 仍直接报错退出。

2. **还原流程绑死全套逐镜五份文档，且缺少成片瑕疵校对说明**：
   - `reconstruct.md` 只有全量逐镜还原一条路（跑 `shots` 切出整集几十段视频和上百张静帧、逐镜提取生图细节，还要求生成已退役的 `设定集/` 目录），没有“只反推《剧本.md》”的做法，也没约定外层未立项时对标登记与跨集核对记录的文件名。
   - 真实成片普遍带有几类偏差：硬字幕用避敏字而配音读正常字、音画同时打码消音、硬字幕完整而合成配音漏字、自动字幕把吸气叹息误标成语气单字或把同名写成不同同音字、网文漫剧把未删净的第三人称动作描写直接录进配音、垫底配乐带人声采样或音频水印、手机和系统面板局部错字或数字与紧邻台词冲突、以及同场切向反应特写时的画外声被机械标成 `[OS]`。现行文档缺少对应的处理说明。

## Decision

### 1. `breakdown_tool.py` 确定性脚本调整（保持 Python 3.9 标准库与纯测量边界）

- **本机媒体工具查找回退**：`shutil.which` 未命中且当前 `PATH` 非显式清空时，按序检查用户主目录 `.local/bin`、`/opt/homebrew/bin` 与 `/usr/local/bin`。
- **字幕校准、扫描阈值与带标号字幕拼版**：
  - 默认字幕框改为 `0.08,0.78,0.92,0.99`，默认最小字形占比由 `0.002` 下调至 `0.0007`，覆盖偏高、贴底与单字硬字幕，并在 `subtitles` 公开 `--min-share` 与 `--change-share`；修正 `blind_spot` 如实说明跨切镜明暗变化拆条与连句合并。
  - `subtitle-sheet` 输出的 `subtitle-rows.json` 增加下半屏活跃字幕行的左右跨度（过滤偶发单帧边缘亮斑）与 `suggested_band` 候选框，跑 `subtitles` 前仍对照 `subtitle-sheet.jpg` 确认。
  - `subtitles` 在保存单条 `Txxx.png` 的同时，用标准库 5×7 位图字模加 `ffmpeg` 自动拼出分页字幕总览图（单页 `*.subtitles.sheet.jpg` 或多页 `*.subtitles.sheet-01.jpg` 等，每页最多 40 条，左侧带 `T001` 与起止秒数），不依赖外部字体或 `drawtext` 滤镜。
- **烧录字幕时间轴挂回 `measure`**：`transcript` 新增 `--subtitles <*.subtitles.json>`，支持读取 `T001 台词` 或 `T005-T010 合并台词` 的文本映射（自动取首条起点至末条终点合并跨屏/跨镜拆条）；`parse_transcript()` 同时兼容填好 `text` 字段的 `*.subtitles.json`（整份非空 `events` 未填任何 `text` 时报错提示）。
- **代表帧拼图补齐首尾拍与时间标号**：`measure` 生成的 `*.sheet.jpg` 为每格叠印位图镜号与起止秒数（`S01 0.0-2.0s`），首镜或末镜不短于 2 秒时补抽 `OPEN` 与 `END` 帧，并在 `*.measure.json` 记录末镜低阈值候选切点 `tail_candidate_cuts`。
- **`plan` 缺项提示与 `reprise` 口径对齐**：`short-drama.json` 已填字/词速却漏填 `seconds_per_action_paragraph` 时，`plan_episode()` 在 `plan_problem` 明确提示；`plan` 模式的 `reprise()` 将台词匹配（维持 6 个发音单位阈值，与成片转写一致）与单条动作段整拍重演（按字/词加权不低于 14 且覆盖较短拍 75% 以上）分开判定，避免同场景连戏共用道具或动作词触发假重放。

### 2. 拆解还原文档与路由、审查对齐

- **区分只反推剧本与全套还原**：在 `SKILL.md` 与 `references/reconstruct.md` 区分「只反推《剧本.md》」（跑 `measure` + `subtitle-sheet` + `subtitles` 并通看全片音画，不切单镜视频）与「还原全套五份文档」；明确「登记权限 → `measure` 测画幅片长 → 按实测画幅 `init` 还原项目」顺序，去掉旧版 `设定集/` 要求，统一 `输入/对标/<REF-ID>/对标登记.md` 与 `还原/审查/还原核对.md` 两个落点，并用 `duration_estimate.py --script` 做纯内存估时自检。
- **新增四条 `craft_default` 规则（`BRK-13`–`BRK-16`）**：
  - `BRK-13`（对白与硬字幕校对）：处理避敏字还原、音画打码替换、硬字幕错字/同音异写与配音漏字校对、残留小说第三人称旁白改动作、自动字幕误识吸气单字剔除、以及配乐采样与水印剔除。
  - `BRK-14`（按场次内外标 `[OS]` 与 `[VO]`）：同场交谈切反应特写写普通现场对白，隔断空间或电话连麦外放标 `[OS]`，闭口心声与独享系统音标 `[VO]`，跨镜声桥按声线与立场定说话人。
  - `BRK-15`（画面文字与原片穿帮处理）：分类处理关键物证与界面字（小字画面抽原分辨率静帧核对）、角色名条（篇首补齐含零台词关键在场人物的 `人物：` 行；看片按单集隔离，写稿对已确认同人跨集统一真名）、地点时间字卡、漫剧气氛拟声字、常驻水印与无意穿帮；正文写可拍连戏状态，原片错字与穿帮记入 `还原核对.md`。
  - `BRK-16`（场次切分与跨集接缝）：归并室内外或连麦高频正反切与几秒短闪回，核对 `END` 帧、`tail_candidate_cuts` 与超过 4 秒长镜防漏切，定长硬切集先拼回连续对话理顺因果再按分集点切回。
- **路由与审查同步**：在 `$short-drama` 的路由表与 `knowhow-index.md` 增加“视频反推剧本”入口，并在 `$short-drama-review` 的 `rubric-source-analysis.md` 补充 `BRK-13`–`BRK-16` 的 `craft_default` 核对项。

### 3. 前后对照实测

在多集漫剧样本与未参与基线调优的样本上，用无历史记忆的干净子会话重跑修改后的公开技能：
- 基线中误把生成界面粘连错字当作女主真名、把截断的小说第三人称旁白原样留作角色 `[VO]`、把二十余秒闪回切成 7 个碎场、手写临时拼图脚本以及 `reprise` 误报 `1/2` 的问题全部消除；
- 留出样本在无额外环境提示下跑通反推流程，准确检出不足 1 秒的大屏闪切账单、集尾关键同音错字、手机通知局部错字及自动字幕误识的吸气单字，通过 `creator_markdown_check.py --partial`、`duration_estimate.py --script` 与 `$short-drama-review` 核查。

## Alternatives considered

1. **在 `breakdown_tool.py` 引入本地语音识别或 OCR 依赖，直接从视频导出《剧本.md》**。
   - 最强理由：省去看片与填写字幕映射步骤。
   - 为何不用：违背套件脚本只用 Python 3.9 标准库加 `ffmpeg` 的约束；且纯语音识别或字幕 OCR 分不清说话人嘴型、同场切镜与场外 `[OS]`、AI 界面错字和配乐水印，会把避敏字与配音漏字直接写进剧本。脚本管时间轴与拼版图、模型结合音画定词，边界更稳。
2. **用 `ffmpeg drawtext` 滤镜给代表帧拼图和字幕裁图叠印编号与时间戳**。
   - 最强理由：滤镜参数短，不必在 Python 里带像素字模。
   - 为何不用：`drawtext` 依赖编译期可选的 `libfreetype`/`libfontconfig` 及系统字体路径，精简版或跨平台环境常因缺滤镜报错（`subtitle-sheet` 的比例刻度尺此前已因此改用 `drawbox`）。用标准库 5×7 位图字模生成 PPM 流交 `ffmpeg` 编码，不挑机器字体。
3. **把新增的四条反推校对规则定为阻断级的 `reviewed_invariant`**。
   - 最强理由：审稿时能对未改净的旁白或错标 `[OS]` 直接判 `REVISE`。
   - 为何不用：部分短剧可能有意保留荒诞旁白或特殊字卡，升为阻断级容易误伤刻意设计；`BRK-12` 已守住实测时间与不编人名的底线，具体校对做法定为 `craft_default` 即可。

## Consequences

- **收益**：
  - 只需反推《剧本.md》时不必切出上百个单镜视频文件；分页字幕总览图把近百次单图读取降为 1–3 张拼版图读取，单字硬字幕、贴底字幕与集尾 1–2 秒短场次不再漏掉。
  - `T001-T00N` 文本映射或填好 `text` 的 `*.subtitles.json` 可直接挂回 `measure.json` 跑 `profile`；`plan` 缺动作秒数会明确提示，同场景跨集连戏不再误报重放。
  - 避敏字、配音漏字、残留小说旁白、配乐水印、AI 界面错字和 `[OS]`/`[VO]` 划分有了清晰的落盘做法。
- **代价**：
  - `breakdown_tool.py` 增加了位图字模拼版、字幕横向跨度统计、文本映射挂接与尾切检测代码，需在 Python 3.9 下维护对应测试；未建《分镜.md》时 `plan` 与 `duration_estimate.py` 仍将动作段与台词串行相加，精确时间线待进入分镜阶段后由镜头时长确定。
