# 生产质量门：跨环节返工、改写回归与生产纪律

配合 [review-method.md](review-method.md) 与 [rubric-visual-motion.md](rubric-visual-motion.md) 使用，重点核对提示词压缩、容器重编或生产失败重投时的跨阶段回归（`REV-08`、`REV-09`）。

## 一、指令优先级与改写回归（`REV-09`）

同一提示词同时接收多层约束时，优先级由高到低为：

1. **已确认的故事事实与对白/文字内容**
2. **已确认的镜头覆盖、职责、起止边界与时长**
3. **已确认的资产身份/版本与连续性变化**
4. **创作者已确认的视觉方向与制作配置**
5. **目标模型表达与能力边界**（无法实现上层要求时须报告缺口，不得暗删）
6. **装饰性镜头与泛质量词**

同级已确认规则冲突时直接阻断并交回负责技能或创作者。每次重写、压缩提示词或重新编组容器后，逐项核对回归表（单镜专项规则见 [rubric-visual-motion.md](rubric-visual-motion.md) 與 [rubric-assets-prompts.md](rubric-assets-prompts.md)）：

| 义务 | 核对内容 |
|---|---|
| 原文覆盖与镜头职责 | 剧本段落、反应、镜头目的是否保留，重拆后总时长与容器成员并集（`SHT-16`、`VID-15`）是否自洽 |
| 起止边界与时长 | 首帧只写 start、尾帧只写 end（`SHT-17`），首尾帧之间未靠插值兑现必看动作；选择性环境变换（`VID-11`）是否保留 `preserve_set` |
| 资产、参考与文字 | 角色/造型/地点/道具状态、参考图像素清理（无未批准水印/字幕回流）、文字政策与逐字台词是否未无故变更 |
| 补拍与替代候选 | 同一 `SHOT-...` 只保留一个正式 `MOTION-...`；补拍说明是否标明母版与原文去向（`VID-12`）；独立补拍是否已先在分镜建 `SHOT-...` |

## 二、缺制作输入时的隔离阻断

- **缺逐字台词**：只阻断具体时长、台词表演与口型可行性，不得自编台词；
- **有签名职责但无正式字形**：只阻断 `readable` 投产（若政策允许 `postproduction` 可预留空白承载区，但若画面留白却让角色当场认出字迹则报语义矛盾）。

## 三、生产与重试纪律

1. **先覆盖后定密度，从动作量反推时长**：不按固定拍镜比倒推镜数，放不下动作与对白时拆镜、删减或退回上游，不靠全镜加速硬塞。
2. **定点修改单次单意图**：每次只改一项诊断目标并显式列出 `preserve_set` 及受影响下游。
3. **重试按被拒输入精准路由**：拒绝原因指向台词交 `$short-drama-write`，指向提示词交对应 prompt 技能，指向参考图或音频交对应资产/生产负责人。只有原因不落在任何具体输入上时才允许原样重投，且**同一输入连续原样重投不超过两次**；超限后必须改内容或退回负责环节。
