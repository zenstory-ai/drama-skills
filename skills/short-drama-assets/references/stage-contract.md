# 视觉设定阶段规则

本阶段负责维护 `剧集/<EP>/视觉设定.md` 中的人物与造型、地点与视角、道具与状态、角色声线与配音设定及跨场连戏记录；以定稿剧本为准，不越界决定单镜临时动作、左右手拿握、构图景别、动作终点或生图/视频提示词。剧本里的每次出场在同一份文档内定性为沿用旧设定、新建条目、新增造型/状态或待创作者拍板，不另建隐藏 JSON 或反向台账文件。

下表仅注册阻断级不变量（`structural_invariant` 与 `reviewed_invariant`）；常规建档筛选、时代款式写法、角色选音建议与非线性连戏例外等创作经验（`craft_default` / `taste_option`）见 [视觉设定拆解指南](asset-design-guide.md)、[角色声线与配音设定](voice-direction.md) 与 [跨场连戏与连戏锁指南](continuity-and-locks.md)。

## 本阶段规则表

### `AST`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| AST-01 | reviewed_invariant | 新建或沿用设定条目须对应 `剧本.md` 的场景 ID 及画面可见描写依据。 |
| AST-02 | reviewed_invariant | 每次出场明确归为沿用旧设定、新建条目、新增造型/状态或待创作者拍板；称呼或代词指代含糊时列清候选待拍板，不硬猜。 |
| AST-03 | reviewed_invariant | 人物与阶段造型、场景与分视角状态、道具固定形制与可变状态分层记录；跨场不变的 `外观特征` 与随戏变化的临时状态（伤污、淋湿、开合、昼夜停电等）严格分开，互不混写。 |
| AST-05 | structural_invariant | 下游分镜与提示词引用的每一项设定，都必须能对应到 `视觉设定.md` 里的具体条目与当前有效造型/状态。 |
| AST-07 | reviewed_invariant | 跨集固定的角色本嗓声线、专名读音与单场戏里的喘息、情绪、音量及台词演法严格分开。 |
| AST-08 | reviewed_invariant | 绑定参考音频时必须写清允许控制与不得控制的范围；参考录音里的情绪、混响空间与背景杂音一律归入 `不得控制`。 |
| AST-09 | reviewed_invariant | 描述参考音频的听感特征须有创作者/权利人说明或实际试听核验依据；未核验时标明未核验，不得空口保证音色、口音或无底噪。 |
| AST-10 | reviewed_invariant | 同一个专有名词确认读法后，在整份 `视觉设定.md` 中只用唯一拼法标注，防止跨集改口。 |
| AST-13 | reviewed_invariant | 提示词与条目标题同语种时免填 `- 提示词名称：`（仅易与普通词重名误判的条目填 `无`）；存在跨语种差异时，建议为正文实际点名的 `人物`（及按需 `造型` / `地点` / `道具`）填写大小写一致的拼写（混合语言用 `、` 并列，从不点名写 `无`）；脚本仅在跨语种人物缺项时输出软 `WARNING` 提醒复核，不作硬阻断。 |
| AST-14 | reviewed_invariant | `视觉设定.md` 与下游提示词展现的建筑、设备、制服、传播渠道等器物制式不得与原著或项目已定年代背景冲突；符合角色境遇与场所设定的日常物理旧化质感（磨损、水渍、斑驳、褪色等）正常使用，禁止无依据把现代场景写成旧时代老宅与淘汰设备。 |

### `CON`

| 编号 | 等级 | 规则内容 |
|---|---|---|
| CON-01 | reviewed_invariant | 相连镜头或场次的前一收尾状态（`终点`）与下一开场状态（`起点`）在站位、朝向、持物与环境状态上必须衔接一致；若有跳变或刻意跳切须写明说明，对不上时退回负责技能修订。 |
| CON-02 | reviewed_invariant | 人物知情范围、伤势污渍、道具归属与开合、天气、光线或空间状态不得在切镜或转场间无剧本依据凭空跳变或自行复原。 |
| CON-07 | reviewed_invariant | `视觉设定.md` 声明的 `- 连戏锁：` 固定唯一 `LOCK-...` 编号、生效目标引用（脚本确定性核对声明语法及指向的 `SHOT-...`/`IMG-...` ID 存在性）与 `锁定词`；点名的静态图片提示词、范围内镜头的首帧提示词，以及无参考图的文生视频和仅挂 `空间布局` / `风格` 等未锁住该外观的图生视频（含合生分组）在正文里原字保留该锁定词，已挂载本镜 `起始帧`（含首帧已带该锁定词的跨镜复用 `PLAN`）或对应设定条目 `主体` / `造型状态` 参考图时自动豁免（正文锁词保留与豁免由审稿按上下文核实）。 |
