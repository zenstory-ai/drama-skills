# 改编价值快评

## 何时跑、何时不暂停

`triage.md` 用于帮创作者快速判断一部未划定范围的长篇原著值不值得全本拆解、建议优先拆哪一卷或前多少章：

- **长篇未定范围**：用 `novel_index.py sample --count 12` 等距抽样（首尾必取，遇到字数极少的卷首语顺延一章并记明），写完 `triage.md` 后汇报建议拆解区间并请创作者确认。
- **短篇小说或已定范围**：短篇作品（如总章数不超过 30 章，抽样已近乎覆盖全篇）或创作者已指定拆解范围（如「拆前 100 章」「拆第一季」）、明确要求一次跑完时，**不在 S1 暂停等拍板**，直接进入 S2 逐章提取（短篇可直接合并进正式拆解，无需先停工交快评）。

```bash
python3 {技能目录}/scripts/novel_index.py sample \
  项目开发/source-analysis/_index.json --count 12
```

快评只评估剧情看点与视听转化条件，不提前生成 `chapters/` 单章文件或 `episode-candidates.jsonl`。后续 S3/S5 按完整拆解出的实据独立成文，无需回头强行对齐 S1 的初判比例或打分。

## `triage.md` 写清五件事

第一行用脚本返回的 `coverage_ratio` 与 `total_chapters` 标明抽样边界（所有结论严格限定在已读抽样章内，未抽到部分写「抽样未覆盖」）：

```markdown
> 本快评基于抽样：读了 340 章中的 12 章（3.5%），章号见下表。以下判断仅限已读抽样章。
```

1. **故事框架与主线看点**：对照 [故事框架与剧情单元](adaptation-value.md#故事框架与剧情单元) 判断属于升级流、复仇线、单元剧、多线交织还是蜕变成长（抽样不足以判断时直说原因）。
2. **结合目标制作形态的载体分布**：按 [三类判定](adaptation-value.md#三类判定)（`screen_ready`、`needs_carrier`、`prose_only`）统计已读抽样章的表现方式，并**结合目标制作形态做条件判断**——真人实拍对纯心理独白和站桩长对话改写负担重；而二维动态漫、Q 版表达或风格化漫剧天然可用内心弹幕吐槽、夸张表情符号与快切 `[VO]` 承载高频心声与密集交锋，只要有明确情绪画面支点就不应一刀切判为高风险（制作形态未定时按实拍与漫剧分别点明差异）。
3. **首集开场切入点备选**：找出抽样章里最能一并立住主角身份、眼前危机与行动目标的强看点场面（标明索引 `sequence`、爽点类型、需顺手补交代的前情；若后文另有更炸裂的名场面，一并列为倒叙冷开场备选）。
4. **场面规模与三处具体改编风险**：统计同框人数、场景跨度、动作特效与可读文字负担；具体指出落在哪一抽样章、哪段戏剧结构上的改编难点，不写空泛套话。
5. **建议拆解策略与预计集数**：按抽样剧情密度估算可改集数区间，并给出明确建议（全本拆解 / 先按前 N 章或第一季分批拆解 / 不建议改编）。
