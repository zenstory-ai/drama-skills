# 参考图用途与控制范围

挂接参考图时写明它管什么、不管什么，防止用来锚定角色或场景的参考图把本镜动作、构图或道具文字带偏。

## 图位要素与十种用途

每个参考图位写明五项：**图位编号与顺序**（项目内真实图片用 `REF-...`，外部工具手动挂图用 `PLAN-...`）、**路径或对应条目编号与名称**、**用途**、**控制**、**不得控制**。图片提示词的「参考」只用真实图片 `REF-...`（不挂图时写 `无外部参考`）；分镜与视频提示词可用 `REF-...` 或 `PLAN-...`。

当目标视频模型支持原生多模态主体参考（如 `full-reference` 多主体模式，同时传入角色图、场景图与参考音频）时，角色或核心物件图位可填 `用途：主体`，并在 `控制` 与 `不得控制` 中划分固定的主体特征与本镜自由发挥的动作构图。一张图兼顾两项作用时，`用途` 填主要项，次要作用写进 `控制`；除首尾同帧循环镜允许同一张图或同一 `PLAN-...` 定位符同时占 `起始帧` 与 `结束帧` 两个槽位外，同一路径在同一条目内只占一个图位。关键帧参考默认挂 `起始帧`；同时挂 `结束帧` 时，结束帧须对应 `SHOT-...` 已写明的「终点」。

| 用途 | 可以控制 | 默认不能控制 |
|---|---|---|
| 外貌 | 固定脸型五官、身形体态、辨识特征 | 临时服装、动作姿势、所处场景、画面文字 |
| 主体 | 多模态主体参考模式下角色的整体外貌与常服特征 | 本镜动作过程、镜头构图、场景切换 |
| 造型状态 | 本集特定服装款式、伤痕破损、雨水血污 | 人物五官长相、额外道具、背景陈设方位 |
| 空间布局 | 出入口、功能分区、固定陈设、朝向关系 | 临时出场人物、剧情变化状态 |
| 构图 | 主体占画比例、视线落点、机位侧、画面留白 | 人物外貌、服装款式、道具上的文字 |
| 尺度 | 人物之间或人物与环境的相对大小比例 | 画风、人物外貌、人数增减、动作结果 |
| 效果 | 光效或特效形态、覆盖范围与质感 | 无关人物或道具消失、角色走形 |
| 起始帧 | 本镜开场时的构图、站位与初始状态 | 尚未发生的动作过程与结尾画面 |
| 结束帧 | 本镜明确写出的收尾画面 | 本镜未交代的额外变化 |
| 风格 | 色彩搭配、材质笔触、阴影边缘、景深与细节密度 | 人物外貌、固定空间布局、剧情动作、道具文字 |

## `外貌`、`主体` 与 `造型状态` 怎么选

- **本集全程不换装的人物**：单挂一个 `外貌`（首尾帧/常规图生）或 `主体`（多模态主体参考模式），把 `本集造型` 一并写进 `控制`；只有本集内发生换装、淋湿、破损、沾血等变化时，才为变化状态单挂 `造型状态`。
- **道具**：固定器型、配色与原有旧痕归 `外貌`；亮屏熄屏、开合状态或新添污损归 `造型状态`。
- 参考图自带的水印、错字或裁切残缺无法靠反向提示词擦除，挂图前先确认原图干净。遮挡设计见 [信息揭晓时机](audience-reveal.md)，补拍路由见 [母版、补拍与替代版](pickup-and-alternate.md)。
