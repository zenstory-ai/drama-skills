# 漫剧关键帧视觉词表

项目视觉方向接受为漫剧 / 二维漫画形态后，按「**场景与主体事实**（见 [关键帧手艺](keyframe-craft.md)）→ **视觉语言投影**（项目级共享画风基底 + 当前镜头光色/构图词）→ **当前帧可读性约束**」组织关键帧提示词，并译为 `prompt_language`（画面内可读文字仍服从文字政策）。本词表词汇属于 `taste_option`；正文不写“叙事关键帧/对话镜头”等分类名或规则 ID（`SHT-21`）。

## 项目级共享画风基底

从 `视觉设定.md` 的“项目视觉方向”读取已接受的稳定项（未决时先交 Look Development 确定，不在单镜临时换画风）：

| 选择入口 | 写进可观察视觉方向的投影 |
|---|---|
| 赛璐璐动画帧 | 清晰轮廓线、平整色块、层数克制的硬边阴影 |
| 厚涂漫画 | 可见笔触、以明暗塑造体积、软硬边随材质变化 |
| 平涂漫画 | 形体概括、有限色阶、弱化表面纹理 |
| 国风条漫 | 墨线粗细变化、分层设色、留白参与空间组织 |
| 日系二次元漫剧 | 简化面部体块、干净线稿、赛璐璐式表面分区 |
| 复古港漫 | 密集轮廓与排线、高反差色块、印刷颗粒 |
| 水彩叙事 | 纸面纹理、透明色层、轮廓局部晕开 |
| 极简叙事漫画 | 克制线条、大面积留白、低数量色层 |

## 镜头类型选词

只挑能服务本镜叙事职责或防范本帧具体可见风险的词，不跨题材混用特效体系，也不堆砌通用防畸变负面词表（见 [production-shot-grammar.md](production-shot-grammar.md)）：

### 1. 叙事关键帧（剧情转向、揭示或场尾落点）

| 分组 | 可选词根 | 何时使用 |
|---|---|---|
| 构图表现 | 强透视、前景遮挡、特写叙事、画面重心偏置 | 透视、遮挡或失衡构图确实承担压力或揭示时 |
| 光影与色调 | 暗调叙事、冷暖分区、轮廓逆光、局部高反差、低饱和色层 | 已接受方向允许该变量且能凸显叙事重点时 |
| 可读性约束 | 视觉重点不被氛围层遮住、身份锚点可辨、前中后景层级分明 | 当前帧有雨雾、群像、暗部或复杂景深遮挡风险时 |

### 2. 对话镜头（中近景台词与神态）

| 分组 | 可选词根 | 何时使用 |
|---|---|---|
| 构图表现 | 人物半身构图、肩后前景、反应特写、对话框留白 | 构图需交代关系，或交付面确需叠加对话框时 |
| 光影与情绪 | 柔和侧光、单侧硬光、低饱和色层、冷暖肤色分离、背景降对比 | 光线/色层能让表情或权力差可见时 |
| 可读性约束 | 面部识别点与目光可辨、关键手势/持物不被裁掉、背景不夺焦点 | 台词落点依赖对应面部或手部信息时 |

### 3. 动作 / 特效帧（凝固在单一边界瞬间的爆发痕迹）

| 分组 | 可选词根 | 何时使用 |
|---|---|---|
| 冻结动态表现 | 方向性拖影、张力透视、流光残迹、碎片定格、冲击点形变 | 可见痕迹能说明当前边界定格瞬间（非动作过程）时 |
| 特效体系（按题材单选） | 仙侠剑气/水墨飞白；赛博能量束/霓虹光刃；魔法辉光/冰晶；火焰/金属火花/电弧/沙尘 | 已接受题材与视觉方向允许该体系时 |
| 层次与可读性 | 特效起点和受力点可辨、武器与肢体轮廓分离、粒子不遮身份锚点、前后层特效遮挡明确 | 存在特效遮挡或轮廓粘连风险时 |

## 完整示例（合成改写）

竖屏 9:16 漫剧，已接受方向为“国风条漫：墨线粗细变化、分层设色、留白参与空间组织；暗调场景允许局部冷暖分区”。场：雨夜天台对峙（科室主任陈默把实习医生林舒堵在顶楼露天连廊栏杆边逼问录音下落）：

```text
竖屏 9:16 中近景。机位在轴线左侧、平视略低约五度，标准焦段。前景是湿透的栏杆扶手
（占下缘约六分之一）；中景两人对峙；背景是虚焦的城市灯斑与雨幕。三分构图，林舒落右三分线。
林舒在栏杆内侧，双手握栏杆，身体朝向正前，视线落在对方胸口，无持物。陈默站在她正前方
约两步、略偏画面左，一手插袋，身体朝向她。光自画面右上高杆灯斜下为硬主光，左侧留暗。
视觉重点在林舒握栏杆的双手。
视觉语言：国风条漫，墨线粗细分明，前中后景分层设色；暗调叙事，右上硬光形成局部冷暖分区。
可读性约束：雨幕不遮住两人的面部识别点与林舒握栏杆的双手；栏杆、人物和城市背景层级分明。
排除：不出现动作过程；不新增道具或可读文字。
```
