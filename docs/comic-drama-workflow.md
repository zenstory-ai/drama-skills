# 漫剧创作全流程指引

核心创作按需维护五份 Markdown 文档，分别记录剧本、视觉设定、分镜和提示词；进入剪辑合成或需要全集体检时，再补写对应的剪辑单或审查报告。

## 一眼看懂

```text
点子 / 原著 / 现成剧本
        │
        ├─ 原著分析、对标拆解、故事开发（都可选）
        ▼
      剧本.md
        ▼
    视觉设定.md
      ├──────────────┐
      ▼              ▼
图片提示词.md       分镜.md
                      ▼
                 视频提示词.md（动态漫剧）
                      │
                      └─ 静态漫剧：首帧画面切换 + 配音，可跳过
      └──────────────┬──────────────┘
                     ▼
              预览 → 明确确认 → 生产
                     ▼
        剪辑单.md → 渲染导出成片（视频段 / 首帧静帧 + 配音）
```

五份核心创作文档默认存放在 `剧集/<EP>/` 目录下：

1. `剧本.md`
2. `视觉设定.md`
3. `分镜.md`
4. `图片提示词.md`
5. `视频提示词.md`

每次只按当前要做的环节创建对应文档，不会预先建一堆空文件。拆分场次、设定条目和镜头时，Agent 会自动分批写完一整集，中途不需要你反复回复“继续”，也不会往项目目录里塞多余的 JSON 索引、覆盖表、审核表或交接摘要。

## 0. 原著分析、对标拆解与故事开发（可选）

手头是长篇原著、需要先评估怎么改才用 `$short-drama-novel-analyze`；需要梳理全剧核心看点、原著必保设定表或分集大纲时才用 `$short-drama-develop`。如果手头已经有单集点子、故事梗概或现成剧本，直接从写剧本开始即可，不必为了凑齐流程回头补这两步。

手上有想学的标杆剧时，先用 `$short-drama-breakdown` 把客观节奏数据量出来（单集时长、平均镜长、有声占比、首集多长、集尾怎么留钩），再交给故事开发环节定本剧的节奏参考标准：

```text
用 $short-drama-breakdown 拆一下 输入/对标/ 里的 9 部标杆漫剧，看我该学什么
```

参考原片和台词转写只放在本地 `输入/对标/` 目录里；本地私有的 `项目开发/对标拆解.md` 可记下参考剧名供创作者自己核查，但不能照抄原片台词，交接到原创项目剧本、提示词以及任何公开材料里的内容更绝不带原片剧名、人名、原句台词与独有桥段。写完剧本或分镜、剪出成片后，还可以再用它按同一口径测一遍自己的稿子或成片，看看节奏差距补上了没有。

## 1. 初始化（按需）

需要统一配置项目语言、画幅比例、单集目标时长或生成模型时：

```text
用 $short-drama 初始化一个都市逆袭竖屏漫剧项目，9:16
```

初始化只定项目配置，不直接写故事。制作形态（动态或静态漫剧）与视觉定调（Lookdev）按需选用，不做视觉定调也能直接写提示词和拆分镜。

## 2. 写 `剧本.md`

```text
用 $short-drama-write 写完 EP001：外卖员在高档餐厅被经理羞辱，亮出集团董事身份
```

写一整集时一次成稿：先理顺前因后果与戏剧冲突，再把场头、动作、对白、画外音和关键音效写进唯一的 `剧本.md`，不另外拆分场卡、节拍表或台词录音表。剧本每一场都要让信息差、人物地位、关系、情绪或处境发生看得见的变化，方便直接拍成画面。

## 3. 写 `视觉设定.md`

```text
用 $short-drama-assets 从 EP001 拆完人物、造型、地点、道具和本集状态
```

重点记录跨镜头需要保持一致的外观设定。先分清是不是同一个人、同一个地方或同一件东西，再决定直接复用、新建条目还是记作换装/状态变化：换衣服、受伤、天气时段变化、门窗开合或手持状态改变记为同一条目的新造型或新状态；单镜里的临时站姿、眼神和走位留给分镜，不写进视觉设定，也不额外建出场流水账。需要跨镜锁死的外观细节，加上「连戏锁」和可直接贴进提示词的「锁定词」。

## 4. 写 `图片提示词.md`

```text
用 $short-drama-image-prompts 为 EP001 的角色、地点和关键道具写可直接复制的图片提示词
```

每条写清用途、固定外观特征、当前造型或状态、构图视角、光线材质和画面排除项，再给出一段可直接复制的提示词正文。图片提示词和分镜互不卡进度：只要 `视觉设定.md` 定好了，这两个环节可以同步推进。

## 5. 写 `分镜.md`

```text
用 $short-drama-storyboard 完成 EP001 的正式分镜和每镜首帧提示词
```

先核对剧本每段内容由哪几个镜头拍出来，再逐镜写清镜头目的、来源场次、景别与机位、时长、场景空间与出场设定、「起点 → 动作 → 终点」以及对白音效安排，并在同一镜下写出「首帧提示词」（需要锁收尾画面时再补「尾帧提示词」）。只有重头戏确实存在几种各有千秋的拍法时，才会列出多套调度方案供挑选，普通场次直接出分镜成稿。

首帧提示词定稿后，再对照画面回填三项引用记录：必写的「出场设定」列出这一格画面里需要认出外貌、造型状态或空间布局的人物、场景和道具；「图片提示词项」填对应的 `IMG-...` 编号；「输入参考图」用 `REF-...` 绑定项目里已有的真实图片，或用 `PLAN-...` 记下准备在外部生图/生视频工具里手动挂载的参考图，每张图都注明 `用途`（如外貌、造型状态、空间布局、起始帧等）。

## 6. 写 `视频提示词.md`

```text
用 $short-drama-video-prompts 把 EP001 的分镜逐镜写成可直接复制的视频提示词
```

每条从本镜起始画面出发，把分镜里的「起点 → 动作 → 终点」写成具体的动态过程：动作起因、肢体接触、落点位置、人物反应、运镜轨迹、声音节点和清楚的收尾画面。真实参考图已经交代清楚的静态长相可适当精简；已绑定「起始帧」或「主体」参考图的视频提示词免于重复粘贴静态 `LOCK-...` 锁定词（未挂起始帧或主体图的文生视频提示词仍原样保留锁定词），动作收在本镜终点内不抢拍下一镜。相邻镜头如果要接着上一段成片往下续生，按目标模型接口挂上一段实际生成的视频或截取的尾帧图。需要跨镜头铺配乐时，可在同一份文档里单列配乐章节（歌词只用创作者提供或确认过的文本）。如果做的是“首帧画面切换 + 配音”的静态漫剧，这一步直接跳过，拿着分镜首帧和图片提示词去预览出图，再按第 8 步合成成片即可。

## 7. 生产：预览后明确确认

```text
用 $short-drama-produce 预览 EP001 的这批图片/视频任务；等我确认后再执行
```

每次调用接口生成图片、视频、配音或配乐，都按四步走：

1. 根据当前提示词文档生成范围明确的待执行任务，产物默认存进 `剧集/<EP>/制作成果/`；
2. 先运行 `prepare` 列出本次准确数量、提示词正文、参考图、参数、输出路径与生成接口；
3. 你核对预览清单无误后明确确认；
4. 运行 `run` 正式调用外部生成接口。

只要改过提示词、参考图、参数或输出路径，或者失败后准备重跑，都会重新展示预览请你确认。后台保存的任务状态与核验记录只用来防重复扣费和查账，不会混进你的创作文档。

## 8. 剪辑成片

```text
用 $short-drama-edit 把 EP001 已生产的镜头剪成成片
```

动态漫剧从生成的视频片段里挑好入出点剪接。静态漫剧按四步合成：

1. 生成各镜头的首帧图片，逐张看片挑定；
2. 用 `$short-drama-produce` 的配音（TTS）功能按《剧本.md》逐句生成台词音频，同样先预览、确认再生成；
3. 写《剪辑单.md》：每镜一段，`来源` 填 `SHOT-...` 及其首帧图片，按配音实际有声长度排定 `时长`，写清 `运镜`、`配音` 与同步 `字幕`，需要时加上 `画面文字` 和 `音效`；
4. 先跑 `check` 校验剪辑单，通过后用 `render` 渲染导出成片，最后跑 `verify` 核验成片音画参数。

具体写法、音画对齐与动静混剪见[剪辑与静帧合成指南](../skills/short-drama-edit/references/editing-guide.md)（视频片段与静帧画面按需混剪时，在剪辑单里标明所选静帧来源即可）。

## 9. 审查与交付（按需）

需要做全集体检时再调用 `$short-drama-review`。审查意见写入 `审查/<EP>-审查.md`，直接按场次、镜头和提示词编号标出问题位置；已经看准的小毛病直接改原稿就行，日常创作不必每步都多绕一轮审查。整理交付包时，只打包你指定的创作文档和成片素材，自动剔除本地私有输入、密钥和后台任务记录。

## 常见卡点

| 卡点 | 处理方式 |
|---|---|
| 漫剧人物单张好看，但每镜不像同一个人 | 回到 `视觉设定.md` 把人物「外观特征」写具体，必要时加上「连戏锁」；分镜里虽然可以引用同一个 `IMG-...` 提示词编号对齐写法，但只有生成任务真正把对应的参考实图（如人物设定图或已核验角度一致的参考帧）传进参考图列表时，模型才会照着同一张脸画 |
| 二维画面有画风、没叙事重点 | 参考[关键帧构图与漫剧视觉指南](../skills/short-drama-storyboard/references/keyframe-craft.md)，先定准画面主体和观众第一眼该看哪儿，再加画风描述 |
| 分镜漏拍剧情或把同一动作连拍两遍 | 按场次逐句核对对白、动作、音效和画面文字落到了哪一镜，直接拆镜、并镜或修改分镜稿 |
| 首帧提示词写了某个角色，出场设定里却漏了他 | 对照定稿的首帧提示词补齐「出场设定」；如果提示词正文用英文拼音点名，给《视觉设定.md》对应人物补上 `提示词名称`，`creator_markdown_check.py` 就能自动抓出漏写项。只写外貌不写名字的角色靠校验脚本抓不到，由必写字段要求和审查细则把关 |
| 指定了目标视频模型，却拿到文生视频提示词 | 指定模型不代表要做文生视频。先把模型写进项目的 `production_profile`，分镜就会按画面里的人物、场景、道具和起始帧查找项目实图，挂成带 `用途` 的 `REF-...`；暂时还没生成的图默认记成 `PLAN-...` 挂图计划，照样出图生视频提示词，不会擅自改成文生视频 |
| 打算在外部网页工具里自己生图，却被要求先在本地生成参考图 | 图片不放进本地项目也能出图生视频提示词：分镜会把每镜要挂的参考图记成 `PLAN-...`（标明对应哪条 `IMG-...` 设定图或哪一镜 `SHOT-...` 首帧，`顺序` 就是上传挂图的先后次序）。视频提示词照常生成，只是这类未落地实图的镜头不能直接交给本地 `$short-drama-produce` 调接口跑 |
| 分镜擅自改了已定稿的剧本 | 每镜「来源」必须对应《剧本.md》里的真实场次，剧本每场戏要么有对应镜头，要么列进《分镜.md》的「未拍场次」说明原因；提示词里由发声动词或 `<d>` 引出的显式开口台词必须在《剧本.md》《视觉设定.md》或《分镜.md》里对得上（不误拦普通招牌或成语引号）。`creator_markdown_check.py` 会自动核对这三项 |
| 首帧画面提前画出了动作结束后的结果 | 「首帧提示词」只画镜头开场那一刻的状态，中间的动作过程和收尾画面留给视频提示词 |
| 中英文提示词混用 | 图片与分镜首帧提示词跟随项目配置的 `format.prompt_language`；视频提示词优先跟随目标模型配置的 `video_prompt_language`，人物开口说的台词语言仍以剧本为准 |
| 做静态漫剧却多写了一份视频提示词 | 静态漫剧靠首帧画面切换加配音就能直接预览出图并剪辑合成，不用为了凑齐五份文件硬写视频提示词 |
| 准备调用接口生成，心里没底怕跑错扣费 | 先用 `$short-drama-produce` 跑预览，看清本次生成的准确数量、提示词正文、参考图、参数、输出路径和生成接口后，再拍板确认 |

## 什么时候停

日常配合创作时，Agent 只在三种情况下停下来等你回复：你交代的这一步已经写完；遇到缺少关键设定、不同选法会大幅改变剧情或画面走向的问题需要你拍板；即将调用外部付费接口生成素材前需要你确认预览。其余分场、分镜批次都会一气呵成写完，最后向你汇总已完成内容、关键创作决定、待拍板事项以及下一步建议。
