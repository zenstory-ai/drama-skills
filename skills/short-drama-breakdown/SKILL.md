# 短剧拆解学习

## Quick Start

测量用 [breakdown_tool.py](scripts/breakdown_tool.py)，命令见[第 2 步](#2-测量)。安装、升级或排障时运行：

```bash
python3 {技能目录}/scripts/selftest.py
```

## 边界与所有权

- 只读当前会话提供或授权的材料。原片、转写、拼图与还原结果只放 `输入/对标/<REF-ID>/`，不进交付或公开文件；报告与移交内容不写对标的剧名、人名、台词和独特桥段。
- 还原结果仅在登记为 `owned` 或 `licensed` 且记了依据时可离开对标目录。
- 本技能只负责量、拆、比及对标还原；本项目各阶段产物由各自负责技能修改，节奏数值经 `$short-drama-develop` 提出并由创作者接受后才进项目节奏档案。阶段规则见 [阶段契约](references/stage-contract.md)。

## 工作流

### 1. 登记对标与本轮问题

为每部对标分配 `REF-ID`，记录来源位置、允许用途（`study` / `owned` / `licensed`，后两种记依据）、是否允许上传外部模型服务、播放面（平台、横竖屏）与制作形态，并明确本轮要回答的问题（决定抽样集数与拆解维度；无明确问题时先向创作者确认）。

### 2. 测量

按 [测量与观看](references/measure-and-read.md) 抽样，用脚本测时长、切点与镜长并生成代表帧拼图，挂接字幕或转写后按系列汇总（需 PATH 含 `ffmpeg` 与 `ffprobe`）：

```bash
python3 {技能目录}/scripts/breakdown_tool.py measure <视频...> --out 输入/对标/<REF-ID>/measure
python3 {技能目录}/scripts/breakdown_tool.py transcript <某集.measure.json> <同集字幕.srt>
python3 {技能目录}/scripts/breakdown_tool.py profile <REF-ID>=输入/对标/<REF-ID>/measure --opening 3
```

### 3. 看与读

结合拼图与带时间转写，按 [拆解维度](references/breakdown-dimensions.md) 逐项记录系列与集长结构、开场、信息载体、对白密度、镜头语法、集尾承接、画幅与形态，每项分列**直接观察**、**解释**与**未知**。

### 3a. 还原（按需）

需查看对标剧本/物料/提示词或拿自有作品做续作重制时，按 [整集与多集还原](references/reconstruct.md) 在 `输入/对标/<REF-ID>/还原/` 下还原为独立套件项目，并用原片核对字错率、漏句、节奏与画面幻觉。

### 4. 提炼机制

多部对标共现且能说明解决观众什么问题的做法，提炼为机制候选（观众状态、戏剧问题、可选机制、可见效果、适用条件、失效边界、不得复制的部分）；仅单部出现的标为单一来源。机制候选交 `$short-drama-develop` 整理，经创作者接受后进入写作上下文。

### 5. 对照与移交

用 `plan` 量本项目计划（输出至 `项目开发/对标拆解/plan/`）或用 `measure` 量自家成片，按 [差距对照与出片验证](references/gap-and-learning-loop.md) 与对标同尺并排生成差距表。每条差距由创作者确认是否有意为之；非有意的移交对应负责技能（新项目未启动时将实测值交 `$short-drama-develop` 作为节奏档案提出依据）。

### 6. 出片验证与记录

改动落盘后，挑代表段落按 [差距对照与出片验证](references/gap-and-learning-loop.md) 用同一模型生成前后两版（每版至少 2 次，盲测判画面、同尺复测）。将对标清单（仅写 `REF-ID`、播放面与形态）、实测汇总、机制候选、差距表与验证结果写入 `项目开发/对标拆解.md`。
