# 表演弧、动作预算与节奏

## 1. 可演动作链与并行通道（`VID-05`）

在已接受镜长内，优先保留造成信息/权力/情绪变化并到达分镜「终点」的主动作与必要反应，删去只为“让画面忙起来”的装饰动作（`VID-05 · reviewed_invariant`，按距离、接触复杂度、语速和停顿判断，不套“每镜几个动词”公式）。

- **接触因果**：按“靠近 → 触碰 → 施力 → 物体变化”顺序写；持物转手写明哪只手、何时释放与接住，同一只手不同时执行互斥任务。
- **合理并行**：“同时 / 与此同时”只用于互不冲突的通道（如边说话边缓慢抬眼、雨声持续、机位平稳跟随），不用它压缩互为前提的串行动作。

## 2. 构造可见的表演变化（`VID-16`）

从角色目标和触发选择当前景别读得出的外显通道，不写“平静 30% → 紧张 70% → 震惊 100%”式的百分比滑块：

- **目光**：寻找、回避、锁定、短暂失焦；
- **呼吸与声音**：吸气截断、语速变化、音量反常压低、停顿、吞字、改称呼或打断；
- **身体与决断动作**：重心后撤、肩线绷紧、手指停住、收回手、让路、把物件推回、关门。

剧本的 `（情绪）` 括注同时约束表演状态和说话方式，需要改动时回剧本修订。若创作者已声明表演标尺，标尺值仅用于校准形容词在当前场合对应的可见动作（相邻段保持不变最常见，变化按最小可见增量并带明确触发，只标真正变化的角色，数字旁仍须写可见通道）。

### 单人或多人表演弧

只为真正承担本镜可见变化的角色写表演弧（空镜、纯物理动作镜或状态未变的旁观者不写；多人镜按各自立场区分早认出继续说、晚半拍让路或掩饰，不给全员复制同一“震惊”）。按需选用以下维度（不必凑满六项）：

1. **当前诉求** → 2. **接收触发** → 3. **表面掩饰** → 4. **可见破绽**（当前景别可读）→ 5. **动作选择** → 6. **终点落定**。

存在注意力交接时，简写「谁/什么拥有注意 → 可见/可听触发 → 注意转给谁/什么」（使用 `视觉设定.md` / `分镜.md` 可见 ID）。

### H3 反应镜配方：先点名，再给两处可见泄露（`craft_default`）

- **MiniMax H3**：当镜头职责是接收消息（震惊、被打脸、得意、压怒）时，按「**触发 → 一个情绪词点名（如“他立刻震惊”）→ 两处当前景别可读的泄露（如目光停住、拇指悬住；笑容停住、手臂收紧）→ 1.5 秒内落点并定住**」编写（只写情绪词易演过头，逐段写满可见反应则强度偏弱）。
- **Seedance 2.5**：保留完整的「触发 → 处理 → 可见反应 → 落点」，不套用 H3 的两处泄露与 1.5 秒默认（见 [Seedance 2.5 方言](seedance-2.5.md)）。

## 3. 时间与对白共同预算

不需要按秒卡点时用相对时序（“开头保留一拍”“话音落下后”）；需要显式计时时列出各阶段及重叠关系，时间并集必须正好覆盖已接受镜长（`VID-04`，见 [motion-recipe.md](motion-recipe.md)）：

```text
0.0–0.8s：保持起点姿态，听见门闩声后目光转向门
0.8–2.6s：左手压住册页，身体慢慢前倾（对白从 1.1s 开始，与动作重叠）
2.6–4.0s：说完后停住，右手仍握笔，落到已确认的终点状态
```

### 对白预算

**`craft_default`**：先读取分镜「声音」的估时依据。有同句同表演录音时用实测发声区间；无录音时按完整原文、语言和表演方式以较慢一端估算（如 H3 中文常速约 **4.1 个可发声字/秒**，不含标点；超载时会先赶词、随后无报错截断）。

- **可用发声窗口** = 已接受镜长 − 开口前等待 − 不能并行的顺序动作 − 轮流说话的其他发声 − 末尾反应（句内停顿已计入时不重复扣）。例如 7 秒镜头扣除首尾各 0.5 秒只剩 6 秒窗口，装不下需 8–10 秒的台词。
- **超载处理优先级**：（1）删无故事功能的环境/手势活动；（2）把可并行动作与对白重叠，合并连贯动作；（3）只留一个主要注意中心；（4）仍放不下时，向 `$short-drama-storyboard` 请求延长或拆镜，或向 `$short-drama-write` 请求精简台词——严禁在本阶段擅自删改台词、把对白改成 VO 或要求加快语速硬塞。
