# 分镜脚本怎么写：短剧分镜表模板，把剧本逐镜拆开

分镜先把定稿剧本里的动作、对白、音效和必读画面字逐句落到具体镜头上，再定好每一镜要让观众看懂什么、从谁的视角看、开头和结尾各是什么画面、用什么景别机位，以及声音怎么排。切镜之后，人物是谁、谁知道什么、手里拿着什么、站在哪一侧都要前后连贯，但不要求两镜画成同一幅构图。有对白的镜头先把整句声音和必要动作排够，再定容得下它的镜长；两列简表方便前期顺思路，本套件的 skill 实际输出一镜一小节的 Markdown 格式。

## 分镜脚本模板：先记事实与镜头作用

下面是手头规划时好用的两列简表，把尖括号换成这一镜的具体内容即可。本套件的正式分镜技能采用一镜一小节的 Markdown 格式，不拿这张简表当正式文档格式。

| 镜头 | 一镜的记录 |
|---|---|
| SHOT-001 | **来源**：<真实场景ID、必要短引文>。**目的**：<本镜让观众看懂什么>。**画面**：<景别、水平角度、高度、机位侧、运镜起止与理由>。**起点**：<影响动作的站位、朝向、持物和空间关系>。**动作与终点**：<连续动作怎样走到收尾画面>。**声音**：<原句、说话人、画内/画外/VO、声音先后次序>。**估时**：<实际录音时长，或标明文本估计的依据与反应留白>。 |
| SHOT-002 | 按同一结构写下一镜；接住 SHOT-001 结尾留下的人物站位与道具位置，有时间跳越、倒叙或刻意重放同一动作时写清楚——切机位时，别让上一镜已经脱手的东西莫名其妙又回到人物手里。 |

核对五件事：来源场次是否对得上剧本、关键剧情有没有漏拍、这一镜的目的是否清楚、动作先后与手里拿的东西是否前后连贯、台词音效有没有排全。一镜里的「动作」可以是一串连贯动作，不必按动词个数硬拆；高潮处刻意重放同一动作时，要标明重播哪一镜，别把动作写成发生了两次。

正式的 `short-drama-storyboard` 按每镜小节写出目的、来源、起点、动作、终点、声音、时长和「首帧提示词」（镜头开场那一瞬间的定格画面），再对照画面填上「出场设定」与参考图。注意只有提示词条目不代表图片已经生成；挂已有实图时也要先看清图里画了什么、核对好用途。

## 短剧分镜表每一栏怎么填

- **镜号**：按顺序编 `SHOT-001`、`SHOT-002`，改稿时没动到的镜头保留原号。
- **来源**：场次编号加一句剧本短引文。剧本一改，顺着这一栏就能立刻定位要跟着改的镜头。
- **镜头目的**：一句话写清谁做了什么、为什么要拍这一镜，比如亮出证据、按下悬念、攻守易位、接住对方反应。只写“开场”两个字，改稿时根本看不出这一镜有什么用。
- **景别·机位**：景别看观众要看清的重点落在什么尺度——看两人僵持的距离用中景，看攥白的手指节才给大特写。水平角度（正面、斜侧、正侧、背面）和机位高度（仰拍、平视、俯拍）分开写，再注明架在轴线哪一侧（机位侧）。
- **运镜**：固定机位适合冷静观察和蓄压；推近、拉远用来改变压迫感或交代处境，摇镜和俯仰用来带视线，跟拍留给走动本身有戏的人物。同一段时间里别既写固定又写移动。
- **起点、动作→终点**：起点写站位、朝向、双手和道具在哪儿；动作写一条走到终点的具体过程，放下、递交、拿回都要写清谁碰了什么、最后停在哪儿。下一镜直接顺着这些结果往下接，机位角度和取景范围可以变；有时间省略或刻意重放时单独注明。
- **对白/声音**：台词原句照抄剧本，标明说话人和画内、画外。
- **时长估计**：有配音录音就直接按实际发声区间算；还没录音就按台词字数、说话人语速、情绪停顿和换气估一个秒数，注明“文本估计”及估算理由。

## 从剧本到镜头的五个判断

1. **剧本内容先落镜**：动作、对白、关键音效和必读画面字都要落到具体镜头上，确定不拍的场次写明原因。几句简短动作可合成一镜，一段重头戏也可拆成几镜，不按自然段机械一对一拆镜。
2. **先定目的，再选景别**：先想清楚这一镜拍什么关键动作、观众要看懂什么、从谁的视角看、开头和结尾必须看清什么细节，再挑景别和机位。交代环境、留白等待或情绪余波本身也可以是一镜的目的，不必逼着每一镜都塞新反转。
3. **有变化才切镜**：信息、视线焦点、人物关系、空间位置或节奏发生变化时，才适合切镜。同景别同角度硬切一刀前先问问有什么作用；刻意跳切或风格化停顿按创作者意图来，别为了求变随便越轴。
4. **同一状态变化只演一次**：放钥匙、推门或递东西，各自定好由哪一镜拍完动作；前后的特写和反应镜顺着结果往下接，别换个机位又把动作重做一遍。高潮处如果要多角度重放同一瞬间，标明是重放哪一镜，别拍成人物拿了两回东西。
5. **先把声音时长排够**：先后开口的对白时长要累加，能边说边做的动作共用时间，必须等话音落定才做的动作另算时间。排不下时拉长镜长、切走画面但不断台词（声画错位），或者请作者微调剧本词句，不擅自删减台词。

**景别收放**可以从交代环境的镜头切入正常对话距离，再在需要看清细节或人物反应时推近或切特写；不要求每一刀固定跳一档景别，也不强求所有场次都一律先大全景后近景。

**首帧提示词**只描写镜头开场那一刻看得见的画面：如果要在这一镜里伸手拿钥匙，首帧里钥匙就必须还摆在原处。可选的「尾帧提示词」用来锁收尾画面，但锁住首尾不代表中间动作一定顺畅。项目里已经定好模型支持时长或节奏参考标准时，照定好的来；还没定时就按这场戏的实际表演需要排时长，别硬猜统一的平台秒数。

## 分镜脚本范例：一场排练室的戏拆成四镜

下面保留同一场排练室戏的四镜拆法。秒数都是按台词字数与动作节奏估算的文字排期，还没进棚录音，也不绑定某个视频模型的固定档位。定下生成模型后再对齐模型支持时长；如果 `SHOT-004` 觉得太长要拆开，可以在拿回钥匙、动作告一段落的地方拆成两镜。

> SC01　内景·排练室门口·夜
> 窄桌横在中间。岑夏站在桌子左侧，右手捏着一把系绿布环的黄铜钥匙；周屿坐在右侧。岑夏身后有一把空椅。
> 岑夏说话间把钥匙搁到桌子正中间，收回右手。
> 岑夏：我先走了。这把钥匙你收着。
> 周屿抬眼看着她，双手搭在膝上没动。
> 周屿：（克制）门我可以替你锁，但散伙这话，我没法替你跟他们张嘴。
> 岑夏伸手去拿钥匙，指尖停在钥匙上方，抬眼看向周屿。
> 岑夏：行，那我等他们过来当面说。
> 她用右手拿回钥匙，左手把身后的椅子拉近，坐下。

| 镜头 | 记录 |
|---|---|
| SHOT-001 | **来源**: SC01「这把钥匙你收着」; **目的**: 立起她要走、他不接茬; **画面**: 中景双人·平视·固定（机位在桌子一侧，岑夏画左、周屿画右）; **起点**: 钥匙在岑夏右手，桌面中间空着，周屿双手搭在膝上; **动作与终点**: 她把钥匙搁到桌子中间，松手收回→钥匙留在桌上，周屿没接; **声音**: 岑夏（画内）：“我先走了。这把钥匙你收着。”与放钥匙重叠; **估时**: 6 秒：短句 2–3 秒，余下给放钥匙和他不接 |
| SHOT-002 | **来源**: SC01「门我可以替你锁」; **目的**: 他拒绝替她宣布散伙; **画面**: 周屿中近景·平视·固定（同一机位侧，视线朝画左）; **起点**: 钥匙在桌子中间，周屿没伸手; **动作与终点**: 他说完整句，手始终不碰钥匙→岑夏还没再伸手; **声音**: 周屿（画内，按括注克制）：“门我可以替你锁，但散伙这话，我没法替你跟他们张嘴。”; **估时**: 10 秒：整句 6–8 秒含停顿，说完留约 2 秒 |
| SHOT-003 | **来源**: SC01「指尖停在钥匙上方」; **目的**: 把“掉头就走”变成没做完的动作; **画面**: 岑夏中近景·平视·固定（同一机位侧，视线朝画右，右手和钥匙在画面下缘）; **起点**: 岑夏右手已收回，钥匙在桌子中间; **动作与终点**: 她右手伸向钥匙，碰到前停住，抬眼看周屿→手悬在钥匙上方; **声音**: 无对白，留住停顿; **估时**: 6 秒：伸手到停住约 2 秒，悬停对视约 4 秒 |
| SHOT-004 | **来源**: SC01「行，那我等他们过来当面说」及取钥匙、拉椅、坐下; **目的**: 她决定留下来当面说清，留下来当面说的局面就此定住; **画面**: 中景双人·平视·固定（同一机位侧，身后椅子入画）; **起点**: 右手悬在钥匙上方，左手空着; **动作与终点**: 先说完短句，再右手拿回钥匙，左手拉椅坐下→岑夏坐在桌子左侧，钥匙在她右手，其他成员还没来; **声音**: 岑夏（画内）：“行，那我等他们过来当面说。”; **估时**: 10 秒：短句 2–3 秒，取钥匙和坐下 4–5 秒，坐定再停一下 |

- **景别跟着要看清的重点走**。SHOT-001 用双人中景交代窄桌、钥匙和两人距离，借放钥匙的动作顺带交代室内环境，省掉单拍一张空景全景；SHOT-002 切近到周屿，看清他的拒绝；SHOT-003 反打岑夏，中近景框住她悬在半空的手；SHOT-004 退回双人中景，把她身后的空椅子带进画面。
- **轴线不动**。四镜机位都架在桌子同一侧；双人镜里岑夏在画左、周屿在画右，单人反打分别保持朝右与朝左的视线方向。人物不在画面里时，不必硬写她仍占着画左。
- **钥匙只动两次**。放下归 SHOT-001，拿回归 SHOT-004；SHOT-002、SHOT-003 里钥匙一直静静躺在桌子中间，谁也没碰。

按上表估算，后三镜连贯演下来塞不进一个 8 秒单镜里；实际要演多久还得以真声试读或配音实测为准。别为了硬压秒数把周屿整句台词砍成“你自己说”，也别让岑夏不等他说完就提前伸手。时长不够时，可以调整切镜点、做成画面切走但台词不断的声画错位（L-cut / J-cut），或者由作者调整停顿和台词节奏。

## 分镜常见问题与修法

| 问题 | 修法 |
|---|---|
| 表格只是把剧本抄了一遍 | 补上观众从哪个角度看、这一镜必须看懂什么；一个镜头能交代清楚的就合并，但也别把必要的环境交代和沉默停顿一刀切删光 |
| 看不出为什么要切这一镜 | 先看视线焦点、人物关系、空间位置或节奏有没有变化；除非有明确的风格化跳切设计，否则别为了求变随便越轴乱切 |
| 同一动作重演了一遍 | 标清动作在哪一镜完成、前后镜头各拍什么反应；刻意做高潮重放时单独注明，别拍成人物手里拿的东西越变越多 |
| 切镜后道具莫名换了位置 | 对照上一镜结尾的空间方位与手持状态；不在画面里不等于东西凭空消失，要么补上拿放动作，要么写明时间跳越 |
| 台词说完了，却看不出对方什么反应 | 补上听者神情反应、同框肢体调度、音效或道具变化；如果同框画面已经把反应拍清楚了，就不必硬凑单人反应镜 |
| 以为写好首帧就能保住整段动作 | 首帧提示词只管开场画面，就算补了尾帧也管不住中间怎么动，视频生成后仍要逐段看片检查 |
| 拿固定秒数硬塞长台词 | 先按台词和动作的实际耗时排镜，再结合项目定好的节奏标准与模型时长档位拆合镜头 |

本文里的两列简表适合前期顺思路；交给正式 skill 出稿时，传入定稿剧本和视觉设定，它会按一镜一小节的 Markdown 格式输出完整分镜，别拿文章里的两列简表反过来当工具格式。

## 用 Drama Skills 怎么做

装好本仓库的 skill 后（对应 [short-drama-storyboard](../skills/short-drama-storyboard/SKILL.md)）：在 Claude Code 里说：“用 /short-drama-storyboard 给 EP001 拆分镜，每镜写首帧提示词”（Codex 里写作 `$short-drama-storyboard`）。它会读取当前的 `剧集/EP001/剧本.md` 和 `视觉设定.md`，输出 `剧集/EP001/分镜.md`；这一步只出文字稿，不会自动生图或生视频，后续写视频提示词、调用接口出片或全集审查按需另外点名即可。

## 常见问题

**分镜脚本一个镜头多少秒？**

没有统一固定秒数。先把整句对白、关键音效、动作和必要反应排完整；有配音录音就按实测发声区间算，没有就标明文本估计。后续按项目定好的节奏标准和目标模型支持的秒数档位去拆合；单镜塞不下时可以拉长镜长、做成声画错位，或者微调剧本词句。光有一张首帧图，并不能保证所有模型都能稳稳撑满 5–8 秒。

**分镜脚本和剧本有什么区别？**

剧本定好谁做什么、说什么、这场戏改变了什么；分镜脚本接过这些定稿剧情，决定观众从多远距离、什么角度、在哪一秒看到和听到。真要改台词、调动作先后或改结局，先回剧本改定，再更新分镜。从长篇小说起步的创作者，可先看[小说改编短剧](https://zenstory.ai/zh/drama-skills/novel-to-short-drama)。

**不会画画怎么写分镜脚本？**

直接写文字分镜就行。每镜写清起点、动作、终点和声音安排，再配一段「首帧提示词」把开场那一格画面描述清楚，交给出图工具生成起始帧参考图即可。Drama Skills 的分镜技能本身只输出文字分镜与首帧提示词，出图和出视频都在后面的生产环节确认后执行。
