# 片场制作稿格式（三角符号稿）

本套件默认标准格式见 [screenplay-format.md](screenplay-format.md)，剧作与对白方法见 [script-craft.md](script-craft.md) 和 [dialogue-craft.md](dialogue-craft.md)。本文用于将行业常见的三角符号片场制作稿[整理成标准格式](screenplay-format.md#7-现成剧本整理成标准格式)，或在创作者明确要求以三角符号排版交稿时使用（`taste_option`）。

## 语法与转换要点

```text
【场景 1：地点 - 内/外（日/夜）】
【人物：甲、乙、丙】
△ 环境描写或空镜
▲ 人物动作与状态变化
【角色名】(表演括注)：台词
```

- **场头与人物行**：旧稿场头常见 `11-1 边关大帐 夜/内`、`【场次】+【场景】` 等语序变体，整理时按词义提取场号、内外景、地点与时段（漏写时段或内外景时留空请创作者确认，不瞎猜日夜）；无台词且不返场的背景群演（`村民甲/乙`、`员工A/B`）不单独拆角色设定。
- **三角符号与动作拍**：标准片场稿中 `△` 写环境空镜、`▲` 写人物动作（旧稿常混用单一符号或标 `1▲…15▲` 拍号，按内容归为动作段落即可）；括注塞入独立大动作或道具易手时拆成独立动作段。PDF 粘贴断行与字间异常空格一并清理，台词原字保留。
- **画外音、心声与内嵌标记**：无论实拍短剧还是漫剧，均可按剧情需要使用内心独白与画外音——旧稿的 `角色（OS）`、`角色 VO`、`V.O.`、`（内心）` 按角色是否在同场分别转为 `[VO]`（主观心声/旁白/规则播报）或 `[OS]`（同场画外对白），保留精炼有效的内心独白而不一刀切删禁，同时避免把整段小说心理描写机械全塞进 `OS`。`【特写】`、`【音效：…】`、`【字幕：…】`、`【闪回】`、`【转场】` 等全角方括号标记在规范化时对应转为动作描写、`[SFX]`、`[画面文字]` 或 `[转场]`。
