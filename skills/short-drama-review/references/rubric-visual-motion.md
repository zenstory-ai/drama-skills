# 分镜、首尾帧与视频动态核查清单

## 1. 剧本落镜完整度、机位运镜与跨镜连戏（`SHT-01`–`SHT-26`、`SHT-28`–`SHT-31`）

- **剧本全要素落镜与原意守真（`SHT-01`、`SHT-02`、`SHT-08`）**：《剧本.md》每个场次均由具体 `SHOT-...` 覆盖，或在开头 `- 未拍场次：<场景 ID>（理由：……）` 说明略过依据（`SHT-01 · structural_invariant`）；各镜具备明确叙事目的，忠实承接所引剧本段落的关键动作、对白、关键音效与 `[画面文字]`，无漏拍关键要素与擅改剧情原意（`SHT-02 · reviewed_invariant`），关键状态转变由主力镜头交代清楚而不无故从头重演已完成动作（`SHT-08 · reviewed_invariant`）。
- **重头戏方案比选与镜号稳定（`SHT-19`、`SHT-20`）**：创作者明确要求做拍法比选的场次，核对候选方案是否真正拉开叙事或调度差距且正式镜头已落实拍板方案（`SHT-19 · reviewed_invariant`）；返修分镜时核查 `SHOT-...` 镜号是否按职责保持稳定、未重用废号（`SHT-20 · reviewed_invariant`）。
- **镜头目的、稳机位原则与空间轴线（`SHT-04`、`SHT-07`、`SHT-09`、`SHT-12`–`SHT-15`）**：
  - 每镜有清晰的叙事或情绪作用，守住悬念揭晓边界（既不提前漏底，也不把当镜必看物证或反应挡死，`SHT-12 · reviewed_invariant`）；声明了播放界面 UI 遮挡区时将关键人脸、字样与手部动作排在干净可见区（`SHT-15 · reviewed_invariant`）。
  - **尊重固定机位与克制运镜选择**：固定机位是对白交锋、特写反应、冷峻审视及降低 AI 视频背景畸变的成熟常用拍法（对应上游 `SHT-04 · craft_default` 与 `SHT-07 · taste_option`）。简写 `运镜：固定` 或整场、整集采用克制稳机位风格均属合规创作选择，**绝不因未写固定机位理由或固定镜头占比高而判不过**；仅当某处关键揭示因机位固定确实遮挡或漏掉戏眼时，才作 `note` / `craft_default` 建议。
  - 轴线与空间核查确认场景观看朝向和同框 `固定陈设` 与本镜机位侧一致（`SHT-09 · reviewed_invariant`），多人同场站位、朝向与视线体现有据可查的人物关系（`SHT-13 · reviewed_invariant`），跨镜传递或运动中的物件保持轨迹与方向连贯（`SHT-14 · reviewed_invariant`），正反打视线互补不越轴；不带主语直写“左/右”指画面左右，角色自身手脚须点名主语。
- **跨镜连戏核查（`CON-01`、`CON-02`）**：顺切镜顺序核查人物妆造、伤污湿痕、知情状态、站位朝向、双手占空与持物交接、道具开合损毁及光线天气衔接（区分真实穿帮与剧本标明的蒙太奇、闪回或主观幻觉 `CON-05`）。

## 2. 镜头节奏指标核对

在满足 [故事大纲与剧本核查清单](rubric-story-script.md#4-节奏设定核对rev-12) 中 `REV-12` 启用条件时，核对分镜两项确认指标：全集平均镜长是否落在 `target_avg_shot_seconds` 区间，全集近距离镜头占比是否达到 `close_shot_share_min`（超标仅记提醒，不阻断交付）；同时排查按剧本字数机械折算镜长而未核算对白真实发声耗时的毛病（`SHT-28`）。

## 3. 首帧与尾帧提示词核查（`SHT-03`、`SHT-05`、`SHT-06`、`SHT-10`、`SHT-17`）

- **子标题结构与单一定格瞬间**：`### 首帧提示词` 与选配 `### 尾帧提示词` 小节须结构干净、仅包含 `>` 引用行（`SHT-17 · structural_invariant`），且正文只写画面可见内容、不夹带条目编号、路径或分镜术语（`SHT-21 · reviewed_invariant`）。首帧只画开场瞬间的静止画面，选配尾帧只画终点瞬间的静止画面；若塞入“先……再……最后……”的连续动作链、情绪演变过程或推拉摇移运镜，按静帧违规打回（`SHT-06`、`SHT-10 · reviewed_invariant`）。当拆信、翻账等复杂核心动作发生在镜头中段时，优先采用单首帧配视频动作描述或拆镜，少靠首尾两帧自动插值硬猜中间过程（`SHT-03 · craft_default`，偏离仅作 `minor` / `note` 提醒，不作阻断硬伤）。
- **`出场设定`、参考图与连戏锁边界**：
  - 首尾帧提示词正文点名需要认准外观或布局的人物、地点与关键道具，以及入画人物身着单独建档的 `## 造型 · <名称>` 时对应的 `造型「<名称>」`，均列入本镜 `出场设定`（`SHT-22 · structural_invariant`，确保 `镜头：入画` 的造型连戏锁按帧触发），`控制` 范围与当前景别实际可见部位一致（`SHT-24 · reviewed_invariant`）。
  - 自动核查可用图片后绑定真实参考图 `REF-...` 或外部挂图计划 `PLAN-...`（`SHT-23 · structural_invariant`，`PLAN-...` 指向已有 `IMG-...` 设定板或 `SHOT-...` 首帧，支持正反打切回镜复用前序 `SHOT-...` 首帧），每槽位均须选用十项合法 `用途`（`外貌`、`主体`、`造型状态`、`空间布局`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格`）之一，`顺序` 从 1 连续编号且 `控制` 与 `不得控制` 互不重叠；单条最多一张 `起始帧` 与一张 `结束帧`，**绑定 `结束帧` 时必须同时绑定 `起始帧`**（同一张图或同一条目仅在循环镜同时充当 `起始帧` 与 `结束帧` 两槽时允许复现，`SHT-25 · structural_invariant`）；未垫参考图走文生路线时写 `无（文生视频）` 或简写 `无`，成稿《视频提示词.md》不得残留 `待补参考图`。
  - **连戏锁按单条锁覆盖情况核查（`CON-07 · structural_invariant`）**：核查生效范围内的静态图片提示词、首帧提示词，以及**文生视频提示词和尚未由 `起始帧`（`PLAN-...` 复用他镜首帧时该首帧须含此锁定词）或对应设定条目 `主体` / `造型状态` 参考图覆盖该锁的图生视频提示词（含 `GROUP-...` 合生分组）**是否原字保留了 `锁定词`；其中 `用途：主体` 或 `用途：造型状态` 的 `REF-...` 槽位仅在其 `《<名称>》` 或 `控制：` 点明该《视觉设定.md》条目名称（或路径指向该条目已登记的参考图路径；`PLAN-...` 槽位指向该锁 `图片提示词项：` 列出的 `IMG-...`）时豁免该条静态锁定词，已覆盖的图生视频专注动态变化，**不因省略该条静态锁定词报错**。

## 4. 视频动态与生成风险核查（`VID-01`–`VID-08`、`VID-10`–`VID-17`、`VID-19`–`VID-28`、`REV-08`）

- **起手、动作容量与终点衔接**：`MOTION-...` 时长与 `SHOT-...` 完全相等（`VID-01`）；标秒分段之和等于本镜时长（`VID-04`），未标秒动作量在镜长内可从容演完（`VID-05`），局部变形或破碎写清触发与同框不变参照物（`VID-11 · reviewed_invariant`）；`输入参考图` 绑定 `REF-...` 或 `PLAN-...` 时须写 `生成方式：图生视频` 且多图按固定编号顺序准确指代防串图（`VID-17 · reviewed_invariant`），未绑定参考图（`无（文生视频）` 或 `无`）时须写 `生成方式：文生视频`、填写非空 `开场画面`，且 **`开场画面` 字段**点名的设定条目与本镜 `出场设定` 一致（不扫描 `### 可复制提示词` 正文中的对白引文，以免与 `SHT-26` 冲突；也不苛求正文逐字照抄 `开场画面` 子串，`VID-03 · structural_invariant`）；图生视频允许在分镜参考项基础上按目标模型合理增减静态设定板或承接帧（`VID-24`），跨镜连续动作续接以实看上段成片或真实末帧及分镜起点为准（`VID-20 · reviewed_invariant`）；终点姿态与持物严丝合缝衔接分镜终点。
- **声音时间线、文字边界与多镜合生**：
  - 由说话引导词或目标模型专用对白标记引出的显式人物发声引文须出自《剧本.md》《视觉设定.md》或《分镜.md》定稿，不私编发声台词（`VID-25 · structural_invariant`）；项目配置规定了必需固定触发字样时在台词定界外原字保留（`VID-19 · reviewed_invariant`）；挂 `- 参考音频：` 时核查是否仅绑定本镜（或 `GROUP-...` 本组）可复制提示词中显式说出本场剧本台词的角色、槽位不与本条目 `输入参考图` 重名、同一角色单条至多一条且音频 `顺序` 单独从 1 编号（`VID-27 · structural_invariant`）；音画同出路线交代清楚声源、说话人与环境底声（`VID-23`），单镜默认不混入画外背景音乐（`VID-14`）。
  - 防字幕负面词按模型特性与屏幕/纸页/招牌等文字风险按需审视，不因无文字风险镜头未写禁字幕套话扣分（`VID-22`）。
  - `GROUP-...` 多镜合生分组总时长等于成员分镜时长之和（`VID-13`），组内同场紧邻、不重不漏覆盖全集镜头（`VID-15`），单个计时段内不暗藏硬切跳镜。
- **纸面风险提醒与实看归因（`REV-08`）**：审纸面提示词时，对同一时段固定与移动运镜指令自相矛盾（`VID-06`）判阻断打回；对已挂参考图却做大段静态外貌复述、带杂字底图未清理或对口型与 `[VO]` 闭嘴打架等情况提示走样风险；已有看片反馈印证时按 [成片看片与返工分流指南](generated-media.md) 定级分流。
