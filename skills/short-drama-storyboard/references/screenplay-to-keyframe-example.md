# 合成正例：从剧本段到冻结关键帧

前情：沈禾的弟弟穿深蓝汽修工装去社区洗衣房送洗后失联；老板蒋姨咬定他放下衣服就走出前门，但沈禾刚在后巷排水沟旁捡到那枚 17 号塑料取衣牌，牌背防滑胶槽里粘着带干涸血迹的深蓝工装线头。

## 剧本段与原文落实

~~~md
## EP004-SC002 内 · 社区洗衣房 · 清晨

烘干机还在嗡嗡转动。沈禾把写着“17”的塑料取衣牌攥在手心，隔着柜台盯住蒋姨，迟迟没递过去。

蒋姨：衣服昨晚就烘干了，你今天来，不是取衣服的吧。

[SFX] 烘干机咔哒一声停转。

沈禾当着她的面摊开右掌。取衣牌背面粘着一小片带干涸血迹的蓝线头。
~~~

| 剧本段 | 落实镜头 | 理由 |
|---|---|---|
| 场景标题（空间建立） | SHOT-01 | 建立门、柜台、烘干机和双方位置 |
| 握牌动作 + 蒋姨台词 | SHOT-01 | 握牌不递与台词点破属于同一拍正面对峙 |
| `[SFX]` 停机声 | SHOT-02 | 机器骤停打破背景音，把注意推向手部动作 |
| 摊掌亮出蓝线头 | SHOT-02、SHOT-03 | SHOT-02 交代谁摊掌与双方视线，SHOT-03 给特写看清牌背血迹与蓝线头 |

## 镜头分解

### SHOT-01：握牌对峙

- **镜头目的**：建立蒋姨守住柜台、沈禾捏住证物的对峙关系，台词直接点破来意。
- **来源**：`EP004-SC002`「沈禾把写着“17”的塑料取衣牌攥在手心，隔着柜台盯住蒋姨，迟迟没递过去。」及蒋姨对应对白。
- **起点 → 唯一动作 → 终点**：沈禾站柜台外右拳攥牌、蒋姨站柜台内、背景烘干机转动 → 沈禾把拳头按在柜台沿上不前推，蒋姨不伸手接 → 手位不变，蒋姨点破她不是来取衣服的。
- **构图与运镜**：竖屏双人中景，柜台横沿分隔上下；固定机位；把双方僵持距离感钉住。

### SHOT-02：声音引导注意

- **镜头目的**：停机声显出沉默，把注意从两人脸上引向沈禾右手。
- **起点 → 唯一动作 → 终点**：继承 SHOT-01 终点 → `[SFX]` 烘干机停转，沈禾不看机器，直接摊开右掌 → 右掌摊平，牌正面贴掌、背面朝向蒋姨和观众（蓝线头存在但本镜不要求读清）。
- **运镜**：从双人中景下移，终点仍保留蒋姨落在手上的视线；跟随注意力转向证物。

### SHOT-03：证据细节

- **镜头目的**：让观众确认牌背粘着带血蓝线头，同时保留蒋姨已看见的关系。
- **起点 → 唯一动作 → 终点**：继承 SHOT-02 终点 → 物理状态保持静止，观众读清牌背血迹与蓝线头 → 与起点相同（牌正面“17”朝下不可见，不得翻牌造字）。
- **运镜**：固定细节镜头；看清牌背蓝线头与血迹附着关系。

## KEY-03：冻结瞬间与回填三条依据

~~~text
社区洗衣房柜台外，沈禾摊开的右掌位于画面焦点；取衣牌背面朝上，
一小片带暗红血迹的蓝线头粘在牌背边缘。右手与牌完全静止，柜台横线
仍分隔双方，后景保留蒋姨已经落在证物上的目光。清晨冷白顶光，已经
停转的烘干机只是空间锚点。画面不展示牌正面的“17”，不加入递交、
翻牌、推镜或表情变化过程。
~~~

按成稿正文回填 SHOT-03 的三条依据（蒋姨虽在后景虚焦但需认出身份故入列；本镜不见牌正面与沈禾全身，故「控制」只写背面材质与右手特征）：

```markdown
- 图片提示词项：IMG-SHENHE-SHEET《沈禾角色板》（控制：身份、手部特征）；IMG-CLAIM-TAG《取衣牌道具板》（控制：牌形、背面材质、边缘磨损）
- 输入参考图：无（待补参考图：沈禾手部、取衣牌背面、本镜起始帧）
- 视觉依据：《视觉设定.md》·人物「沈禾」（控制：身份、右手特征）；人物「蒋姨」（控制：身份、视线方向）；道具「取衣牌」（控制：牌形、背面材质、蓝线头位置）；地点「社区洗衣房」（控制：柜台横线、冷白顶光）。
```

## 连续性交接与（情绪）括注交接

| 字段 | SHOT-01 结束 | SHOT-02 开始与结束 | SHOT-03 开始 |
|---|---|---|---|
| 沈禾右手 | 握牌 | 握牌 → 摊掌 | 摊掌 |
| 牌朝向 | 背面不可见 | 背面转向蒋姨 | 背面可见 |
| 蒋姨目光 | 沈禾脸 | 沈禾脸 → 右手 | 牌背 |
| 烘干机 | 转 | 转 → 停 | 停 |

剧本对白的表演括注是**写一次、转化两处**的唯一来源，分镜与视频提示词不得各自另起冲突的情绪词：

~~~md
## EP002-SC004 内 · 老楼梯间 · 夜
程野：（压着嗓子）你现在放回去，我就当没看见。
宋昭：（笑）你确定还找得回来？
~~~

| 位置 | 负责人 | 写什么 | 不能写什么 |
|---|---|---|---|
| 剧本括注 `（压着嗓子）` | 编剧 | 唯一情绪来源 | — |
| 本镜表演状态 | 分镜 | 可见的收敛：下颌收紧、身体不前倾、音量压在回声下 | 不升级成“低吼/怒斥”，不自动等同于切特写 |
| 下游语气与停顿 | 视频提示词 | 同一来源转化的呼吸、停顿与音量走向 | 不新起情绪词，不与分镜表演状态相反 |
