# 系统流题材卡

## 核心机制与两条分支路线

系统属于外挂类高概念，规则底表与剧中揭晓的分层管理见 [高概念与开篇奇招](../genre-and-hook-playbook.md#高概念与开篇奇招)。按剧集气质分两条主流打法，**不锁死“首集必须零副作用白送奖励”单一套路**：

- **直球高爽型（签到返现、神豪逆袭、行业加持）**：压迫感主要来自现实势利对手的当众欺压，系统奖励干脆利落到账，与当众变脸形成双响兑现；留住主角在心里跟系统贫嘴、卡规则漏洞的松弛喜感。
- **代价博弈 / 诡异规则型（规则任务、等价交换、带坑假系统）**：系统首集起即可附带严苛限制、使用代价或文字陷阱；看点在于主角摸透规则死穴、反手拿系统的限制设局坑杀对手或揪出系统背后的猫腻。

## 信息差与场面抓手

- **独家面板信息差**：旁人按肉眼所见的寒酸表象下注，主角凭脑内面板、任务条件或隐藏条款提前布套；无论哪种路线，破局主意都由主角自己拍板，不做照单跑腿的木偶。
- **高辨识度细节**：半空面板与跳动数字、任务倒计时、手机到账提示音、群聊与直播弹幕风向翻转、刚被摔在地上又被双手捧回的合同、按“拍板方 / 墙头草 / 吃瓜路人”分拨的现场反应。

## 阶段推进与集尾留钩

- **阶段推进**：前期立住现实困局与系统核心规则，完成首次兑现或规则破局；中期随着奖励池扩大或限制收紧，逼主角在两难奖励与更刁钻的对手设局间取舍；后期揭开系统来历或终极条款，收束主线。
- **集尾留钩**：弹出条件更苛刻或奖励翻倍的新阶段任务、刚到账的好处引来更贪婪的对手觊觎，或发现系统某条播报暗藏反转陷阱。

## 制作要点

系统面板、群聊刷屏与弹幕统一标 `[画面文字]` 交后期 UI 包装；底图只拍角色注视半空的眼神聚焦与微表情，构图预留贴字空位。系统提示音与屏幕花字分工配合（如语音报条件、屏幕跳数字），避免同一长句重复念两遍，面板数字与台词严格对齐。
