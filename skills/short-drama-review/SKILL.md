# 短剧审查

优先由未参与本轮执笔的独立审稿人执行；执笔人自检时如实标明自检（审查问题单绝不与直接改稿混为一谈）。本技能只负责指出问题、说明影响、明确改稿标准并退回对应负责技能，不直接修改受审原稿，不调用生成接口。

## 快速开始

直接读取用户指定的稿件或看片反馈。需要保存审查文档时，单集联审写入 `审查/EP001-审查.md`，专项审查写入 `审查/<主题>-审查.md`；只需口头反馈时直接在对话中回复。每条问题单标题必须严格采用 `## <Blocker|Major|Minor|Note> · REV-<编号> · <标题>` 格式（如 `REV-001` 或 `REV-EP001-001`，编号至少三位数字以避免与阶段规则号混淆），并在标题下逐行写出 `- 位置：`、`- 证据：`、`- 影响：`、`- 修改要求：`、`- 规则：`，以便创作台审查卡片完整解析每条问题；出处仅引用文件名、标题编号、行号或简短原文摘录，不建隐藏 JSON、哈希值或状态副表：

```markdown
# EP001 审查

- 范围：剧本、分镜、视频提示词
- 结论：REVISE
- 复核方式：<独立审稿 或 自检（二选一填写，勿并列保留）>

## Blocker · REV-001 · 分镜漏拍剧本中的画面文字
- 位置：剧本.md / EP001-SC002；分镜.md / SHOT-EP001-004
- 证据：……
- 影响：……
- 修改要求：移交 `short-drama-storyboard` 技能补上准确的画面文字内容与景别停顿条件，保持本镜原有的人物站位与情绪反应不变。
- 规则：SHT-02 · reviewed_invariant
```

## 工作流

1. **划定受审范围与先查硬账（`REV-01`、`REV-07`）**：确认本次受审文档、章节或镜头范围及创作者已拍板的创作要求（未经创作者逐环确认的全流程预览草稿按待确认稿审视）。先核清标题编号重漏、链接与条目引用悬空、分段与合生分组时长加总、剧本全要素落镜、跨镜连戏状态，以及是否混入私有凭据或本机绝对路径；缺某份前置材料时只跳过依赖它的判断，其余照常审。
2. **顺链条对账并凭实据开单（`REV-02`、`REV-03`）**：按 `剧本事实 → 视觉设定 → 分镜起止状态 → 首尾帧提示词 → 视频动态 → 下一镜接戏 → 《剪辑单.md》与整集成片切点接缝` 核查上下游是否走样（指认篡改或漏拍须成对列出上下游原文）。每条问题单写清位置、实据、实际影响、局部修法与不得误伤的保留内容、负责技能及严重程度，不空扣“有 AI 味”“不够电影感”帽子。
3. **局部补丁与亮点保护**：返修意见只针对病灶开最小局部补丁，不借局部毛病要求整集推倒重写。对比新旧稿时若发现润色压稿误删了抓人钩子、高潮金句或精妙包袱，单列 `## 被删的强钩子` 记下原位置与原句供执笔人取舍；复审时只核验返修点是否修通及保留内容是否完好（`REV-09`），不翻已放行段落旧账。
4. **定级、结论判定与返修分派**：按下方两张表确定问题级别与最终结论，再按负责技能归拢返修项交创作者拍板（下游返修与复审在用户明确指示时启动）。

### 规则等级与严重程度上限

| 严重程度 | 允许对应的规则等级 | 判定标准 | 是否触发 `REVISE` |
|---|---|---|---|
| `blocker` | `structural_invariant` / `reviewed_invariant` | 阻断交付的不变量结构错误、核心事实穿帮、泄密违规或不可挽回的成片缺漏 | 是 |
| `major` | `structural_invariant` / `reviewed_invariant` | 伤及剧情因果理解、跨镜连戏或成片主体与台词完整度的中度硬伤 | 未获创作者豁免时触发 |
| `minor` | `craft_default` | 套路重复改进建议、局部瑕疵提醒或裁切/后期可修项（绝不升格为 `major`） | 否 |
| `note` | `craft_default` / `taste_option` | 审稿人个人审美与拍法参考建议、保留沿用备忘（除非撞上创作者已拍板的硬性限制，否则一律只记 `note`） | 否 |

> 所有 `craft_default` / `taste_option` 偏离均不得单独触发 `REVISE`（在 `- 规则：` 字段直接标注 `craft_default` 或 `taste_option`，不虚构阶段规则编号）；唯有台词、正文或成片实质违背已立住的人物硬事实、剧情因果链或上下游不变量规则时，才挂靠对应的 `structural_invariant` / `reviewed_invariant` 规则编号定为 `major` 或 `blocker`。

### 审查结论判定（书面与生成媒体对照）

| 书面结论（`审查/*.md`） | 对应媒体看片结论 | 判定条件 |
|---|---|---|
| `APPROVE` | `PASS` | 无 `blocker`，且无未获创作者显式豁免的 `major`（无额外建议） |
| `APPROVE_WITH_NOTES` | `PASS` | 无 `blocker` 且无未获豁免的 `major`，附 `minor` / `note` 建议或创作者已显式豁免的 `major` 留底 |
| `PROVISIONAL` | `PROVISIONAL` | 无 `blocker`；仅剩不影响主线推进且已写明下阶段修法的局部问题、待看片拍板的边界项，或尚有关键材料/音画未查看（未看素材如实标未知，不凭文件名猜测） |
| `REVISE` | `REVISE` / `REJECT` | 存在 `blocker` 或未获创作者豁免的 `major` 硬伤需返工（整批失控需回退重设时，媒体结论记 `REJECT`，书面记 `REVISE` 并标明重设范围） |

生成媒体看片六档分流细则见 [成片看片与返工分流指南](references/generated-media.md)。
