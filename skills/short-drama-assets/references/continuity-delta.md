# 资产连续性与变化记录

## 连续性规则与记录要素（`CON-01` ~ `CON-06`）

- **`structural_invariant` CON-01（边界匹配）**：相连镜头或场次的前一结束状态与下一进入状态必须一致，或有明确修订说明；不得靠下游运动提示词掩盖跳变。
- **`reviewed_invariant` CON-02（因果可信）**：伤势、道具归属、天气、光态与知情状态不得无剧本原因瞬移或自动复位（如“灯闪了一下”不足以解释整栋渡站永久断电；上集末尾带伤而本集未提时，保留带伤并标 `unresolved`，不得默认痊愈）。
- **`craft_default` CON-03（只追有影响的增量）**：不在每场复制整张设定表，只记录后续镜头、提示词或跨集交接会依赖的状态变化（如人物造型/伤污/携带物、地点视角/时段/天气/光态、道具持有人/开合/破损/内容物/文字、跨集结束状态）。
- **`structural_invariant` CON-04 & CON-06（变化记录要素）**：每条变化在 `视觉设定.md` 对应条目中写明：
  1. **前态（`before`）与后态（`after`）**：复合事件拆为多条单维变化，不用“已更新”代替具体状态；
  2. **原因与来源**：指向剧本场景 ID 与动作/对白；
  3. **生效范围**：起止场次或集数，终点未定标为持续（`open_ended`）；
  4. **受影响下游条目**：列出已存在的 `IMG-...`、`SHOT-...` 或 `MOTION-...`（未来尚未建立的文档只注明需同步的事实，不预建占位引用）。
- **`taste_option` CON-05（非线性与有意断裂）**：蒙太奇、省略、梦境、闪回或主观画面可打破常规连续，但须写明断裂类型与进出边界；闪回使用对应历史造型/状态，不改写主时间线当前状态。

## 合成状态链示例

SC004 初始：顾禾穿 `造型「顾禾雨衣」`；铁皮匣闭合、内置号牌；值班室灯亮。

1. **顾禾开匣取牌**：铁皮匣由「闭合、内置号牌」变为「打开、空」；号牌由「匣内」转入「顾禾右手」。
2. **顾禾将号牌交魏叔**：号牌由「顾禾右手」转入「魏叔右手」（避免同一道具在两人手中复制）。
3. **配电箱跳闸**：值班室由「夜间常亮」变为「停电（`open_ended`）」。
4. **暴雨打湿右肩**：顾禾雨衣右肩变湿；本集结束状态固定为「魏叔持号牌、铁皮匣空且打开、值班室断电、顾禾雨衣右肩湿」，供下一集直接承接。
