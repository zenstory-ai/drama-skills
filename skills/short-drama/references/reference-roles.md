# 一张参考图可以决定什么

绑定参考图必须同时声明控制边界，防止身份参考越权决定服装、构图、背景或文字。

## 槽位五要素与九种用途

每张参考图在槽位声明中回答五件事：

1. **稳定槽位与显式顺序**：项目内真实图片用 `REF-...`，创作者在项目外准备并在生成时自行挂载的图用 `PLAN-...`；
2. **可见定位符与中文名称**：`REF-...` 写项目相对路径（如 `输入/参考图/许棠定妆.jpg《许棠定妆照》`），`PLAN-...` 写对应的 `IMG-...` 板子或 `SHOT-...` 冻结关键帧；
3. **用途**：只能取下表九个词之一，同时回答创作者“送哪张图”与执行端“映射哪个 role”；
4. **控制**：允许照着画的可见内容；
5. **不得控制**：必须保护的身份、文字、人数、道具和空间锚点。

分镜与视频的「输入参考图」可使用 `REF-...` 或 `PLAN-...`；图片提示词的「参考」字段只使用真实 `REF-...`（无参考时写 `无外部参考`）。一张图只占一个槽位，不写“全参考”：兼顾两项作用时，`用途` 写主要作用，次要作用写入 `控制`；同一路径在同镜绑定两次会被检查器拒收。帧参考默认只用 `起始帧`；确需 `结束帧` 时只能呈现 `SHOT-...` 已写明的终点。

| 用途 | 可以控制 | 默认不能控制 |
|---|---|---|
| 身份 | 稳定脸型、体态、识别标记 | 临时服装、姿势、场景、文字 |
| 造型状态 | 已决定的服装、伤损、湿污 | 新身份、无来源道具、背景方位 |
| 地理 | 入口、区域、固定锚点、方向关系 | 临时人物、剧情状态 |
| 构图 | 占画比例、视线布局、镜头一侧、留白 | 人物身份、服装、道具文字 |
| 尺度 | 主体之间或主体与环境的相对尺度 | 风格、身份、数量、动作结果 |
| 效果 | 已决定效果的形态、范围、材质 | 非目标对象的消失、复制或变形 |
| 起始帧 | 本镜起始构图与状态 | 尚未发生的动作和终态 |
| 结束帧 | 本镜明确终点 | 新终点或未由镜头承担的结果 |
| 风格 | 色彩层级、材质、阴影边缘、景深、密度 | 身份、固定地理、剧情、道具文字 |

## `身份` 与 `造型状态` 的界线

- **人物**：按「本集之内会不会变」划分。角色板同时固定长相与本集全程不变的服装时，只写一个 `身份` 槽位，并把 `本集造型` 列入 `控制`；仅当本集内发生换装、湿透、破损、血污等状态变化时，才另开 `造型状态` 槽位管那一次变化。
- **道具**：按「它是哪一件」还是「它此刻处在什么状态」划分。固定形制、配色、裂纹与磕角写 `身份`；亮屏/熄屏、开合、湿污、破损程度写 `造型状态`。两项都要固定且只有一张图时，`用途` 写主要项，另一项写入 `控制`。

## 观察边界

创作者给出的可核对说明或运行环境获授权读取的参考图可作为证据；两者皆无时保持“未验证”，不得声称水印、文字、裁切或身份已通过。负面提示词无法擦除参考图已有的像素。观众知情时机见 [观众揭示](audience-reveal.md)，补拍与母版关系见 [补拍与替代](pickup-and-alternate.md)。
