# 故事大纲与剧本核查清单

按归属分别路由：大纲、改编对照表与多集导入索引问题退回 `short-drama-develop`；单集《剧本.md》问题退回 `short-drama-write`。

## 1. 开发与改编阻断级核查（路由 → `short-drama-develop`）

- **推进与因果底线**：冲突升级须带来真实处境变化，不原地换大嗓门车轱辘重演（`STY-03 · reviewed_invariant`）；上下集承接与伏笔埋收引用均指向已知记录、未定项明标（`STY-05 · reviewed_invariant`）；揭秘与反转须从前文事实顺理成章推出并真正改写局势、认知或关系（`STY-09 · reviewed_invariant`）。
- **原著改编保真与重排衔接**：守住原著核心人物立场、处事路数、核心关系与主线脉络，合并人物/场景保住戏剧作用与信息差（`STY-07 · reviewed_invariant`，违背时按 `REV-03` 成对列原著与改动原文）；立项简报必保事实在本轮落地或标明延后集号（`STY-23 · reviewed_invariant`）；`move_earlier` / `cold_open` 重排须补足前置铺垫或时间线依据并调整原位（`STY-29 · reviewed_invariant`）。
- **多集剧本导入索引（`STY-18 · structural_invariant`）**：核查是否经精确字节索引读取并通过 `verify` 校验总长、区间、集号递增序与行号对应，原稿变动已重建索引且 `merge` 未写入索引声明外的未知集号。

## 2. 剧本阻断级核查（路由 → `short-drama-write`）

- **可演外化（`SCR-03 · reviewed_invariant`）**：关键剧情转折的心理变化须外化为可拍摄动作、物证状态变化或明确标注的 `[VO]`/`[OS]`，不拿大段纯心理说明替代戏剧行动。
- **制作标记语法与 `[连续性]` 边界**：`[画面文字]`、`[VO]`/`[OS]`、`[SFX]`、`[连续性]`、`[转场]` 使用规定固定语法且指代清晰（`SCR-05 · structural_invariant`）；`[连续性]` 只记录前文动作已演出的状态变化，不得靠一行备注空口断言镜头外“从未发生某事或从未接触某物”（`SCR-25 · reviewed_invariant`）。正文不混入镜头景别或生图咒语。
- **前文硬代价与上游原意守真**：后文动作公然推翻前文已写死的硬代价、伤病或物证前提时，按 `CON-02 · reviewed_invariant` 报错；创作者未提限制而执笔人擅自删改、磨平上游已拍板核心冲突原意时，按 `REV-03 · reviewed_invariant` 成对列上下游原文打回。

## 3. 多元题材防误杀护栏（`craft_default` / `taste_option`，不触发 `REVISE`）

以下各项属于创作工艺与题材调性取舍，确有损戏之处最多记 `minor` / `note` 建议，**绝不据此打回**：

- **不把“每场必有正面对手翻转”当跨题材死门槛**：悬疑线索勘验、规则怪谈异常铺垫、情感/生活流暗流拉扯与过场呼吸戏，只要推进了信息增量、悬念压迫感、关系分寸或连戏状态即合格。
- **高潮与阶段结算随题材而定**：不拿“高潮三要素缺一不可”作扣分门槛；悬疑揭拼图、怪谈留白寒意、生活流克制日常落点均成立（仅在公然推翻前文硬代价时按 `CON-02` 报错）。
- **金手指/系统设定**：分清底表规则与剧中揭晓进度，层层揭秘属正常悬念；仅拦截违背前文已亮明规则的吃书，或直出屏幕真字与全局禁字设定正面冲突的穿帮。
- **两难抉择、争议物证、精确倒计时、限定回合、原著新增项说明与备选拍法**：仅在剧本明确将其作为核心戏眼或创作者主动要求预留备选拍法时按工艺建议核对；日常决定、常规道具或保守替代拍法最高记 `minor` / `note`。

## 4. 节奏设定核对

仅当 `short-drama.json#/creator_authority/rhythm_profile` 为 `status: "accepted"` 时启用（缺失、`unset` 或 `proposed` 一律跳过）。对照已确认目标值做算术核对，超出区间处记为不阻断交付的 `craft_default` 提醒项（写明指标名、目标值、实测值与位置，创作者说明理由即可保留）：

| 指标字段 | 核对标准 |
|---|---|
| `first_hook_seconds` | 开集起算到首个危机、反常现象、冲突交锋或核心悬念落地的秒数。 |
| `beat_interval_seconds_max` | 相邻两处有效戏剧触点（冲突推进、关键动作或新信息揭晓）之间的最大间隔秒数。 |
| `opposed_reversals_per_episode_min` | 本集由带自身诉求的对手推动或受挫的反转次数。 |
| `end_on_peak` | 全集末拍是否收在高潮点或悬念引爆瞬间，未拖沓平缓总结。 |
| `reprise_previous_last_beat` | 开场是否重演衔接上一集末拍（`EP001` 不适用）。 |
| `vo_share_max` | `[VO]` 字数占总台词字数比例（去空白与括注、留标点；`[OS]` 仅计入分母）。 |
| `first_major_payoff_by_episode` | 全剧联审时核对首次重大看点兑现落在第几集。 |

分镜层面的 `target_avg_shot_seconds` 与 `close_shot_share_min` 见 [分镜、首尾帧与视频动态核查清单](rubric-visual-motion.md#2-镜头节奏指标核对)。

## 5. 三轮局部专项抽查

通读全集后，结合题材调性做三轮局部抽查（仅作 `craft_default` 诊断提醒，除非撞上阻断级不变量）：

1. **开场钩子抽查**：单读开场前几拍，看是否迅速切入情境而未堆砌冗长背景。**全面放行契合题材的文字钩子与声音钩子**（规则怪谈告示字卡、悬疑黑屏求救声/电话录音、生活流冷开台词），只要当场立住悬念或戏剧张力即予认可，绝不因首拍依赖文字或声音一刀切判不过。
2. **集尾收束抽查**：单读末场最后几拍，核查集尾钩子、反转余震或情绪落点是否干脆利落。
3. **中段推进抽查**：对抗爽剧查交锋反转是否头轻脚重；悬疑/怪谈/生活流查线索递进、规则试探或关系拉扯是否原地踏步水戏。
