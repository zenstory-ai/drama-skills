# 冲突、揭示、反转与回报的条件方法

## 1. 从承诺选择压力来源

| 承诺重心 | 可持续压力 | 可变化的回报 |
|---|---|---|
| 身份/伪装 | 暴露风险、两套义务、识别证据 | 观众多知道一层、角色被迫选边 |
| 职场/制度 | 签字权、时限、替罪链、程序筹码 | 规则被反用、责任归属改变 |
| 家庭/遗产 | 照护债、记忆版本、物件归属 | 关系真相或选择成本落地 |
| 复仇/追责 | 证据可信度、共犯关系、代价升级 | 对手失去一项保护，主角承担新债 |
| 悬疑/秘密 | 谁能看见什么、证据可否解释 | 排除一种解释，同时产生更难选择 |
| 轻奇幻 | 有限规则、使用代价、普通秩序摩擦 | 规则被聪明运用，而非不断加大法术 |
| 情感/关系 | 需求不对称、面子、承诺、边界 | 一方改变策略或公开真实代价 |

## 2. 区分四种动作

- **信息揭示**：观众或角色得知一件已经存在的事实。
- **局势反转**：已落地的事实让原计划、旧解释或关系位置失效。
- **情绪回报**：承诺的恐惧、甜、爽、痛、温暖真正落到可感知的结果上。
- **情节钩子**：新决定、危险、悬念逼着局面继续往下走。

同一次动作可以兼任多项功能，但判断时要分开：只亮出秘密却无人改变选择，完成的只是信息揭示，
未必构成局势反转；结尾只把半截话藏起来，属于故意扣住信息，未必能勾住观众继续往下看。

用同一个故事处境（女主追查亡母留下的老宅拆迁款去向）对照这四种动作的区别，看**作者具体改哪里、观众因此多看到什么**：

- **只停在信息揭示（缺反转）**：女主拿到银行流水单，当面质问继母：“拆迁款半年前就被你转进你娘家弟弟账户了！”继母冷笑承认：“是我转的又怎样？有本事你去告我！”随后甩袖离开——观众和女主虽然知道了真相，但继母毫发无损、女主下一步还是只能干生气，局面没有实质翻转。
- **从揭示推进成局势反转**：
  - **作者具体改哪里**：把“私下对质亮流水”改到继母精心安排的祠堂宗亲会上——继母先当着全族叔伯的面逼女主签《自愿放弃老宅拆迁款声明》，拍着胸脯发誓“那笔钱一分没动，全留在公账上给老宅翻修祠堂”；等族老们纷纷帮腔指责女主不孝时，女主再把银行流水单投屏到祠堂幕布上，亮出那笔钱半年前就用来给继母弟弟付了赌债别墅首付。
  - **观众因此多看到什么**：刚才还替继母撑腰的三位族老当场变脸，围住继母逼她交出修祠堂的公账，继母从“主持家法的长辈”瞬间沦为“私吞族产的众矢之的”，逼签计划彻底破产。
- **兑现情绪回报**：一直偏听偏信责骂女主的父亲看着幕布上的转账签名哑口无言，族老当场押着继母交出老宅房契与亡母留下的首饰木匣，观众憋了三集的闷气当场拿到实质爽感。
- **甩出情节钩子**：女主当众打开刚夺回来的亡母首饰木匣，里面却空无一物，只压着一张昨天刚开的城南当铺“绝当熔毁通知单”——距离母亲留下的金锁与遗嘱夹层被熔毁只剩最后两小时，逼着主角与观众立刻冲向下一集。

## 3. 公平揭示

揭示前检查：

1. 观众是否见过足够的可解释迹象？
2. 谁在此前能接触事实，谁不能？
3. 证据为何现在出现，而不是作者需要时凭空出现？
4. 新事实排除了什么旧解释？
5. 得知后谁必须改变行动？

有效揭示常通过重新连接旧事实，让观众和人物获得新的解释。

合成例：检修员早先发现巡检本少了一页签字，原以为只是有人撕走了末页想补签糊弄过去。直到她在主管桌上瞥见那本巡检册的订书针孔朝向反了，才猛然反应过来：被人重新拆装抽走的是夹在中间的事故责任页！原本“找人补签了事”的盘算当场作废，她必须立刻赶去护住那页纸上替人背锅的新徒弟。订书孔不是装饰，它直接改写了人物下一步怎么做；若前文压根没交代过页序和装订细节，这个反转就是作者硬塞。

## 4. 有因果的反转

**STY-09 · reviewed_invariant**：揭示/反转必须从已建立事实生长，并且让计划、
解释、关系位置或高代价选择至少一项真正改变。

写反转时先核对三步因果：**前文已经埋下了哪条事实或选择 → 它为什么让人物原定的盘算当场作废 → 人物现在被逼到了哪两个都要付代价的新选择面前**。

常见可用反转：

- **胜利触发对手有准备的程序反制**（如主角当众拿旧账本逼退副店长，副店长当天下午便以“台账外泄违规”为由走总公司流程冻结她的店长权限）；
- **证据是真的，但证明的是另一项责任**（如女主查出车祸当晚刹车线确实被人动过手脚，调出维修签字单却发现签字人是已故父亲——父亲是为了替欠赌债的弟弟顶罪才改了记录）；
- **被保护者拒绝保护方式**（如被包庇者不愿背“走后门”黑锅，当众站出来认账并反问主角为何私改台账连累全员）；
- **主角的长处暴露新的盲区**（如重生者靠前世记忆主动弃赛躲开“台上抄袭”陷阱，对手却顺势在后台走廊假摔拍下“嫉妒推人”的错位视频）；
- **关系盟友要求兑现此前承诺**（如主角刚借二叔的族老身份压下堂兄闹事，二叔转头就把早就拟好的老宅过户字据拍在桌上，要他按约定交出东厢房）；
- **规则没有失效，人物用规则改变了时间或权限**（如家族规定“满十八岁未成婚即收回掌家印”，对手故意在生辰宴前夜锁死婚书库房，女主却当众亮出亡母当年立下的“入赘不受库房婚书约束”旧宗规，当场招婿破局）。

弱反转：陌生人突然出现宣布一切都是梦。它改变信息，却没有从人物行动长出。

## 5. 回报先于下一股压力

每集至少明确一种已兑现结果（craft_default，不是数量门槛）：

- 主角确实救下/失去/赢得/公开/拒绝了什么；
- 一个旧问题获得部分可验证答案；
- 一段关系的边界真的改变；
- 承诺的能力、亲密、羞耻或恐惧得到一次完整呈现。

然后才问：这项结果让谁失去筹码、暴露什么、产生什么债，形成推向下一集的压力（`outgoing_pressure`）。
“马上要揭晓”不是回报。

## 6. 避免机械轮换

不要按集机械轮换“打脸—身份—误会—救场”。比较相邻集的机制：压力来源是否学习、主角策略是否改变、代价落在哪种价值、观众获得的是哪类回报（信息/关系/能力/情绪）、空间与制作负担是否可承受。规则分级定义与 `STY-*` 规则表见 [阶段契约](stage-contract.md#本阶段规则)。
