# 交付与验收

对渲染后的实际成片执行核对，区分实测数值、人工复核与未测项：

| 项 | 核对方式 |
|---|---|
| 时长、画幅与帧率 | 探测输出文件，核对实际渲染时长、帧率、画幅与交付规格差异 |
| 内容覆盖与台词 | 对照分镜、视频提示词与剧本回听成片，确认台词完整可辨、未采用镜头理由齐备 |
| 边界帧与接镜色彩 | 检查切点前后与 `verify` 点名的段落，在同场景同光态下比对可比区域（脸、衣物、中性面） |
| 声音与响度 | 回听 `verify` 列入「请回听」的切点及对白/环境声衔接，核对整片实测 LUFS 与真峰是否落在容差内 |
| 字幕与画内文字 | 抽帧核对逐字内容、发声对齐、字号折行、底部安全区及画内文字避让 |

## `verify` 诊断指标口径

- **分段色彩观测**：报告中间分段的平均亮度与蓝减红像素值，仅作参考，不代表局部区域接镜残差。
- **切点亮度变化**：切点前后两帧平均亮度差（`0–255`）超过 `20` 时列入「请逐帧查看」。
- **疑似坏帧**：与前后两帧均显著不同、而前后两帧彼此相近的单帧（含解码错位或画面文字入场故障动效），列入逐帧复核。
- **切点音量变化（`EDT-23`）**：切点前后各取 `0.4s`（距切点留 `30ms`，不越过相邻切点；不足 `0.1s` 标「未比」），取较响声道的 RMS 电平（静音记 `-70 dBFS`）。差值超过 `10 dB` 列入「请回听」以人工区分有意冲击/换场与音床硬切。

以上四项均为复核指引而非自动阻断门槛。交付时一并给出成片、剪辑单、中间文件、实测响度/真峰与时长差异报告。
