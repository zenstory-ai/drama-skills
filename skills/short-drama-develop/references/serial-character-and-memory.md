# 连续短剧的人物塑造、开篇切入与跨集连戏

开发长线连续短剧、把长篇小说拆成短集、往下续写新一集，或者发现写着写着人物人设走样、伏笔前后断档时，在 `story-craft.md` 和 `episode-design.md` 之外配合阅读本文件（规则分级与 `STY-*` 规则表见 [开发阶段职责与规则](stage-contract.md#本阶段规则)）。

## 1. 先理清人物前史，再找准开篇切入点

### 1.1 人物前史（心里有底，别塞进首集台词）

人物前史只梳理真能解释“他眼下为什么非这么选不可”的那几桩旧事（当年哪次吃亏养成了现在的处事习惯、哪笔旧债或难堪至今拿捏着他、哪桩陈年实情造成了双方的认知错位、哪块性格软肋早晚会惹祸），并按亮底时机分成三档管住，绝不在第 1 集借角色之口背简历：

- **第一集画面当场就得让观众看懂的（`audience_needs_now`）**：不交代就看不懂眼前这一下动作。比如写“冷链仓库夜班主管林岚常年替闯祸的弟弟兜底”，开场第一镜只需拍她凌晨两点熟门熟路翻开巡检本，模仿弟弟笔迹把空白温控栏补填成 `-18℃`。
- **作者心里有本账、根本不用台词点破的（`writer_needs`）**：五年前这套冷库核查规矩就是她亲手定的，用来指导她改账时手底下有多老练，用不着让配角在旁边夸她资历老。
- **先严严实实捂住、留到中后段引爆的（`withhold`）**：三年前父母住院那笔救命钱其实是弟弟赌博输光的窟窿，一直捂到中段翻出医院原始缴费单时再炸开。

### 1.2 开篇切入点

挑同时满足以下条件最多的一刻下刀开场（`craft_default · STY-11`，排第 1 集时须跟[首集开篇切入](episode-design.md#44-首集开篇切入)里的高光直入开场和冷开切入同台比对）：

1. 危机已经烧到眉毛，人物非动手不可；
2. 人物惯用的应付招数眼下还能顶一阵，但马上就要露馅闯祸；
3. 观众单看人物动作、手头物件、当面对峙或反常结果就能自己倒推出前因；
4. 第一集就能干脆演完一轮交锋见个分晓，绝不只做枯燥的背景科普；
5. 再往前切就会变成温吞的铺垫流水账，再往后切又会漏掉最抓人的那次关键抉择。

拿情感原著“妻子三年来一直靠忍让退步维系婚姻，丈夫与青梅竹马却拿十年前的愿望纸条一次次越界”做对比：
- **切得太早（铺垫流水账）**：从三年前领证、头一回翻出愿望纸条拍起，连演三场鸡毛蒜皮的拌嘴；
- **精准切在“老办法刚要付惨痛代价”的那一刻（立得住）**：直接从“青梅竹马把玄关婚纱照摘下换上两人合影，而第二天一早正是女主父亲做心脏搭桥手术等家属签字”切入——女主半句废话不吵，当场把满墙照片收进行李箱底，第二天独自签完手术同意书，转身就去民政局补办三年前被丈夫当众撕碎的结婚证。

## 2. 顺着人物性格与软肋推演他会怎么选

主要人物小传与双向拿捏关系写法见 [story-craft.md](story-craft.md) 第 3 节。如果是市井温情、轻喜剧或日常烟火题材，人物之间的拉扯完全可以落在“暗中替对方兜底却死鸭子嘴硬、刀子嘴豆腐心护短、出门在外报喜不报忧或好心办坏事的乌龙错位”上，不必给街坊亲人硬套苦大仇深的算计筹码。

## 3. 看清人物底色或促成人物转变：在硬仗与两难中推进弧光

人物弧光宜靠一桩桩逼他老办法失灵的具体危机推着走（`craft_default · STY-12`；少靠嘴上喊一句“我彻底醒悟了”代替行动转变）：

```text
原本的处事路数 → 撞上硬茬危机考验 → 咬牙死守老做法 / 试着换新活法 / 心软退回老路
→ 当场拿到的阶段结果 → 实打实咽下的苦果代价 → 迎头撞上下一回更要命的考验
```

继续拿“替弟弟改温控台账兜底的冷链主管林岚”举例，六步弧光台阶每一步都有戏可演：

- **尝到甜头继续护短**：替弟弟补签后顺顺当当瞒过早班抽检，心里更认定“只要把账面抹平就能保住弟弟饭碗”；
- **信念裂开第一道缝**：照老规矩改平周三夜班断电记录，不料第二天医院退回因失温变质的急用救命血清，头一回惊出冷汗发现自己改掉的那一格差点害死人；
- **试着立规矩又没狠下心**：下回弟弟再漏检时，她把钥匙拍在桌上逼弟弟自己进库核对，可听到抽检员脚步声时还是没忍住替他挡了五分钟；
- **心软打回原形**：眼看弟弟要被副站长开除、老母亲哭着打电话求情，林岚一咬牙又退回老路替弟弟背下了违规处分；
- **彻底斩断退路的决断**：撞破弟弟借夜班替外人夹带假药、还准备把伪造台账的罪名全推到她头上顶缸时，当众落锁封死冷库大门，亲手把那本带着自己补签笔迹的原始底账交给了总公司稽查组；
- **死不回头一条道走到黑**：看清了深渊还是执迷不悟替弟弟瞒到底，最终滑向悲剧或反面警示结局。

不强求每一集都让人物性格大转弯；人物没变的那几集，心里要清楚这一集是在攒铁证、把执念推向极端、往前拱外部任务，还是换由身边的配角发生了态度转变。

## 4. 每集留钩前必须先演完本集阶段结果

```text
本集急着办成的目标 → 真能拦住路的对手阻碍 → 主角当场拍板出招 → 本集阶段结果落地
→ 处境与代价真变了样 → 从这个结果里顺势长出留给下集的新危机
```

**`craft_default · STY-13`**：常规连载集在甩出集尾钩子之前，宜先演完一个能算到**本集主视角人物自己头上**的阶段结果（可以是赢回半局但露了马脚、输了一阵却顺手摸到了新铁证、自以为过关其实暗雷已经读秒、主动弃车保帅换目标，或者被对手焊死老路不得不换打法）。

如果破局转机是从外面送上门的（救兵赶到、铁证浮出水面、反派窝里反），必须同时拍清楚两头：主角前面干了哪件实事才引得这个转机**偏偏现在**赶到，以及接过转机后主角**当场拍板做了什么处置**。比如隐姓埋名的集团创始人在自家酒店暗访被势利经理羞辱，要是光站在原地挨骂干等秘书路过救驾，主角就沦为了看客；改成经理动手抢他拍下后厨脏乱差的手机、叫保安架他滚出员工后门，他为保住铁证当场一拳砸响大堂消防警报逼停保安、亮出集团巡查工牌调驻场审计组封账，这一下翻盘才真正长在主角自己的脊梁骨上。

## 5. 管好信息差与待回收伏笔

把“客观实情”“剧中人各自以为的版本”“观众知道多少”清清楚楚列在信息差对照表里（拿“妻子暗查装病失眠的丈夫”举例）：

| 事实编号（`fact_id`） | 实际底细 | 妻子（主动查证方） | 丈夫（隐瞒方） | 观众 | 画面里亮出的铁证 | 下一步捅破窗户纸的动作 |
|---|---|---|---|---|---|---|
| `FACT-01` | 丈夫昨晚根本没戴降噪耳机，半夜心率狂飙另有猫腻 | 已知（刚查实） | 还以为妻子蒙在鼓里深信不疑 | 跟妻子同一秒看清 | 掀开充电仓盖，手机弹窗显示两只耳机电量 100%、昨晚佩戴 0 分钟 | 妻子不动声色收走玄关备用钥匙，假装体贴陪他去闺蜜冥想馆抓现行 |

### 5.1 一份物证当场能坐实到哪一步

每条线索或物证可按三层卡准分寸（`craft_default · STY-15`）：

1. **画面可见物证（`visible_carrier`）**：观众和角色亲眼瞧见、亲耳听到的现场细节；
2. **当场能坐实的结论（`supported_claim`）**：光凭这件物证就能板上钉钉锤死的那一步实情；
3. **留待深挖的疑点（`unresolved_inference`）**：顺着它自然会起疑心，但非得等下一件独立铁证到手才能彻底锤死的幕后真相或同伙身份。

就像上面这张表里，蓝牙弹窗跳出“两只耳机电量 100%、昨晚佩戴 0 分钟”（`visible_carrier`），当场能锤死的只有“丈夫昨晚撒谎没戴耳机、半夜心率飙升肯定有鬼”（`supported_claim`），但单凭一副满电耳机绝对锤不死“昨晚摸进主卧的人究竟是谁”（`unresolved_inference`），千万别让女主看一眼耳机就跟开了天眼似的直接喊出小三名字。

## 6. 外部危机与人物情绪的张弛搭配

排分集与分场时，把**外部危机紧迫度**（倒计时死线、对手堵门逼宫、密闭险境）和**人物情绪起伏**（痛失所爱、当众受辱、亏欠自责、进退两难）搭成两条线一块看，记明跟上一阶段相比为什么收紧或错开喘口气（`craft_default · STY-14`）：

- **外紧内绷（双高）**：刺刀见红的当众摊牌与斩断后路的决裂（如订婚宴当众停掉全部副卡、甩出职务侵占审计单报警退婚）；
- **外紧内稳（外高内低）**：彻底死心后的干净利落反杀或按计划收网取证（如带着律师和搬家工人上门，面无表情清走名下所有资产）；
- **外缓内痛（外低内高）**：大战前夜的独处，或刚查明残酷真相后的心里余震（如刚拿到背叛铁证，一个人坐进车里盯着副驾储物格里替他备了五年的胃药久久没发动车子）；
- **外缓内平（双低）**：必不可少的换场过渡，尽量短平快带过，顺手在角落里露一点山雨欲来的反常苗头。

## 7. 维护跨集连戏备忘录（防忘防穿帮）

每写完并确认一集后，对照 [story-engine.md](../assets/story-engine.md) 里的「跨集连戏备忘录」只更新这一集真正变了的条目（人物动态、关系远近、信息差、待回收伏笔、危机与情绪张弛及上下集精确交接）；没变但下一集开场非接不可的细节放进精确交接栏，已经彻底翻篇结清的旧事浓缩成半句话或移出备忘；万一备忘摘要跟已确认的剧本正文有出入，一律以剧本正文为准。

## 8. 合成示例

顺接第 1.1 节冷链仓库主管林岚替开叉车的弟弟林浩补签温控台账的故事底子：

- **开篇切入点**：凌晨两点，林岚刚替弟弟把空白温控栏补填成 `-18℃`，三号冷库存放待检高价药材的恒温区突然亮起刺眼红灯警报：库内实测温度已飙升到 `+6℃`，而里侧卸货通道的大门正被人从里面反挂上粗铁链。

### 第一集怎么一步步演出来

- **本集目标**：林岚以为弟弟粗心忘关冷气阀门，想赶在早班质检组六点进场前刷主管卡冲进库里重启备用冷机、把升温警报压下去；
- **当场阻力与知情反转**：她刷卡撞开三号库内间门，迎头撞见弟弟林浩正和仓库副经理往无牌厢式货车上搬原装高价药材箱，脚底下堆着用来调包的受潮次品！弟弟非但不慌，反手把一把重扳手塞进她手里，逼她去后台把升温记录篡改成“设备故障跳闸”：“姐，反正门口巡检本上那行字是你亲手替我签的，现在捅出去，第一个停职坐牢的是你！”
- **主角当场抉择**：林岚一步步退回三号库门外总控箱旁，猛地一把扯下门口巡检本上刚替弟弟补签的那页纸死死攥进手心，反手一巴掌拍下直通总公司监控室的红色“货损封库”急停键，把三号库电动门与货运卷帘门从外头同时落锁，将亲弟弟、副经理连同无牌赃车死死关在库内；
- **本集阶段结果**：调包人赃并获被她亲手锁死在现场，她自己也彻底斩断了“私下抹平护短保弟弟”的老退路；
- **顺势长出的集尾悬念**：副经理隔着厚玻璃观察窗冷笑举起手机——半小时前那批高价药材的电子出库放行单上，审批人赫然是用林岚放在值班室抽屉里的主管工牌刷出来的；恰在此时，库外长廊里已经传来了总公司稽查组进场的急促脚步声。

### 人物弧光与张弛节奏核对

- **人物弧光台阶**：从“暗地里替弟弟补签平账”头一回被逼到“亲手拍下封库键把亲弟弟和赃货一块锁死在现场”（护短执念裂开第一道口子，但主管工牌被偷刷又把她推进了百口莫辩的新死局）；
- **外部危机紧迫度**：一路掐表收紧（凌晨补签 → 恒温库红灯报警 → 撞破调包遭亲弟拿笔迹反咬 → 狠心拍下封库键 → 惊见自己工牌早被偷刷放行）；
- **人物情绪起伏**：习以为常替弟善后的叹气 → 被亲弟弟拿补签字迹威胁时如坠冰窟 → 拍下封库键那一瞬的狠绝 → 看清自己工牌签名时被至亲推去顶罪的彻骨寒意。
