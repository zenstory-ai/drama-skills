# 连续短剧的人物、切入与跨集记忆

开发连续剧、从长篇材料切分短集、续写下一集，或人物与伏笔开始失去连续性时，在 `story-craft.md` 和 `episode-design.md` 之外读取本文件（规则分级与 `STY-*` 规则表见 [阶段契约](stage-contract.md#本阶段规则)）。

## 1. 先建前史储备，再选叙事切入窗口

### 1.1 前史储备

只储备能解释当前选择的过去（哪次旧事形成当前策略、哪个债务/羞耻仍在约束他、哪项旧事实造成双方认知差、哪个盲区会制造代价），并按出场时机分三类管理，不塞进首集对白：

- **观众此刻必须看见的（`audience_needs_now`）**：看懂当前行动所必需。例如写“冷链仓库夜班主管林岚常年替闯祸的弟弟兜底”，第一场只需拍她凌晨两点熟练翻开巡检本，模仿弟弟笔迹把空白温控栏补填成 `-18℃`。
- **作者心里有数、不必台词解释的（`writer_needs`）**：五年前冷库核查规矩是她亲手立的，用于指导动作熟练度，无需角色背诵履历。
- **暂时扣留、留作后续反转的（`withhold`）**：三年前父母住院救命钱实为弟弟赌博输掉的窟窿，留在中段翻出医院原始缴费单时再引爆。

### 1.2 叙事切入窗口

选择同时满足以下条件最多的一刻切入（`craft_default · STY-11`，第 1 集须与[首集入口](episode-design.md#44-首集入口)的收益入口和冷开比较）：

1. 压力已启动，人物必须采取行动；
2. 人物的惯常策略眼下仍有效，但即将显出代价；
3. 观众能从动作、物件、关系交锋或反常结果倒推出前因；
4. 本集能先完成一个局部行动，而非只介绍世界；
5. 切得更早会变成准备流水账，切得更晚会失去关键选择。

例如情感原著写妻子三年来靠“退让大度”维系婚姻（丈夫与青梅竹马拿十年前愿望纸条一次次越界）：
- **切得太早（背景流水账）**：从三年前领证、第一次发现愿望纸条拍起，连拍三场日常争吵；
- **切在“旧策略刚要付惨痛代价”的一刻（成立）**：直接从“青梅竹马把玄关婚纱照摘下换上两人合影、而次日正是女主父亲做心脏搭桥手术需家属签字”切入——女主不再争吵，当场把满墙照片收进行李箱底，次日独自签完手术同意书后去民政局补办三年前被丈夫撕毁的结婚证。

## 2. 用人物驱动力预测选择

人物行动模型与双向关系筹码见 [story-craft.md](story-craft.md) 第 3 节。在温情、喜剧或生活流题材中，关系张力可落在“替对方兜底却不说破、嘴硬护短、报喜不报忧或认知错位”上，不必给亲友硬套敌对筹码。

## 3. 把人物变化写成可追踪的压力测试

人物弧线通过触碰旧策略的具体事件推进（`reviewed_invariant · STY-12`；仅台词宣称“我变了”或情绪强度改变不算弧线移动）：

```text
进入策略 → 压力测试 → 仍按旧信念行动 / 尝试新行动 / 退回旧行动
→ 拿到的阶段性结果 → 支付的代价 → 下一次更难的测试
```

仍以“替弟弟改温控台账兜底的冷链主管林岚”为例，六种变化阶段均可成立：

- **确认**：替弟弟补签后瞒过早班抽检，更坚信“把账面做平就能护住弟弟饭碗”；
- **裂缝**：照旧改平周三夜班断电记录，次日医院退回因失温变质的急用血清，首次发现改掉的那一格差点害死人；
- **试探**：下次弟弟漏检时把钥匙拍在桌上逼他自己去核对，但仍在抽检员进门前替他挡了五分钟；
- **回撤**：弟弟差点被副站长开除、母亲哭着打电话求情，林岚心软退回老办法替弟弟背下违规；
- **不可逆选择**：发现弟弟借夜班替外人夹带私货并准备把伪造台账罪名推给她时，当众锁死冷库出货门，亲手把带自己补签笔迹的原始底本交给稽查组；
- **拒绝变化**：看清深渊仍一条道走到黑，走向悲剧或反面弧光。

不要求每集移动人物弧线；未移动时明确本集是在积累证据、加强信念、推进外部目标还是由配角承担变化。

## 4. 每集必须落地当集戏剧结果

```text
当前目标 → 有能力的阻碍 → 人物选择 → 当集戏剧结果
→ 状态/代价改变 → 从结果中长出的下一股压力
```

**`reviewed_invariant · STY-13`**：集尾钩子之前，本集必须产生一个能追溯到**本集主视角人物选择**的当集结果（部分成功但暴露弱点、失败但拿到新证据、误以为成功而代价启动、主动放弃原目标、或对手封死路径迫使换策）。

结果由外力送达（援兵、证据浮出、对手内讧）时，必须同时写清：主角此前的哪个动作促成它**现在**到达，以及拿到后**做了什么处置**。例如隐姓埋名的集团创始人在自家酒店暗访被势利经理羞辱，若只站着挨骂等秘书路过解围，主角就成了观众；若改成经理抢他拍下后厨隐患的手机并逼他滚出员工后门，他为保证据当众砸响大堂消防警报逼停保安、主动亮出工牌引驻场审计组进场，翻盘即成为主动选择的后果。

## 5. 管理信息权限与铺垫债务

将“世界事实”“角色认知”“观众知情”分列在最小信息权限表中（以“妻子查证装病失眠的丈夫”为例）：

| 事实编号（`fact_id`） | 世界事实 | 妻子（主动方） | 丈夫（对手方） | 观众 | 当前可见证据 | 下一次改变权限的动作 |
|---|---|---|---|---|---|---|
| `FACT-01` | 丈夫昨晚未戴降噪耳机，且半夜心率飙升另有隐情 | 已知（刚查出） | 误信妻子仍被蒙在鼓里 | 与妻子同步已知 | 充电仓弹窗显示两只耳机电量 100%、昨晚佩戴 0 分钟 | 妻子不动声色收走备用钥匙，假装顺从陪他去闺蜜冥想馆试探 |

### 5.1 证据结论边界

每条线索或证据分三层记录（`reviewed_invariant · STY-15`）：

1. **画面可见证据（`visible_carrier`）**：观众和人物亲眼看见、亲耳听见的事实；
2. **当场能坐实的结论（`supported_claim`）**：该证据直接钉死的那一步结论；
3. **尚未坐实的推断（`unresolved_inference`）**：顺着它能起疑、但须靠下一条独立证据才能坐实的真相或幕后黑手。

如上表中，蓝牙弹窗显示“两只耳机电量 100%、昨晚佩戴 0 分钟”（`visible_carrier`），当场能坐实的是“丈夫昨晚没戴耳机、半夜心率飙升另有隐情”（`supported_claim`），但不能单独坐实“昨晚进主卧的人是谁”（`unresolved_inference`），不可让角色单凭满电耳机当场喊出第三者名字。

## 6. 用双轨节奏安排张弛

分集与场景规划同时记录**外部压力**（时限、对手逼迫、空间风险）与**内在情感负荷**（失去、屈辱、愧疚、两难），并说明与上一单元相比为何升降或错位（`craft_default · STY-14`）：

- **外部高 / 情感高**：正面对决与不可撤回的摊牌（如订婚宴当众停掉副卡、甩出审计单宣布离婚）；
- **外部高 / 情感低**：心意已决后的利落反击或按计划取证（如带律师和搬家工人上门清退私人物品）；
- **外部低 / 情感高**：暴风雨前后的独处或发现真相后的余震（如刚发现背叛证据，坐进车里看着副驾上替他备了五年的胃药发怔）；
- **外部低 / 情感低**：必要过场交接，压短篇幅并埋下未安稳苗头。

## 7. 建立可恢复的跨集记忆

每集接受后按 [故事引擎](../assets/story-engine.md)「跨集记忆最小集」只更新发生变化的字段（人物、关系、信息权限、铺垫债务、节奏方向与精确交接）；未变化但下集必接的事实入精确交接，已完成事件压成一句或移出，摘要与已接受正文冲突时以正文为准。

## 8. 合成示例

沿用第 1.1 节冷链仓库主管林岚替开叉车的弟弟林浩补签温控台账的情境：

- **切入窗口**：林岚凌晨两点刚替弟弟把空白温控栏补填成 `-18℃`，三号冷库存放待检高价药材的恒温区突然亮起红灯警报：库内实际温度已升至 `+6℃`，而内侧卸货通道门栓正被人从里面反挂铁链。

### 第一集的具体动作

- **当前目标**：林岚以为弟弟忘关冷气阀门，想赶在早班质检组六点进场前刷卡进库重启备用机组、压下升温记录；
- **有能力的阻碍与知情反转**：她刷主管卡冲进三号库内间，撞见弟弟林浩正和仓库副经理往无牌厢式货车上搬原装药材箱，地上堆着调包进去的受潮次品！弟弟反把一把扳手塞进她手里，逼她去后台把升温改成“设备故障跳闸”：“姐，反正门口巡检本上那行字是你亲手替我签的，现在捅出去，第一个停职坐牢的是你！”
- **人物选择**：林岚退回三号库门外总控箱旁，一把扯下门口巡检本上刚替弟弟补签的那页纸攥进手心，反手拍下直通总公司监控室的红色“货损封库”急停键，将三号库电动门与货运卷帘门从外侧同时落锁，把弟弟、副经理连同无牌货车锁在库内；
- **当集戏剧结果**：调包现场与人证被亲手封死在库内，她也彻底断了自己“私下抹平保弟弟”的退路；
- **长出的下集压力**：副经理隔着观察窗冷笑亮出手机——半小时前那批药材的电子出库放行单上，审批人赫然是林岚放在值班室抽屉里的主管工牌刷出来的；此时库外走廊已传来总公司稽查组进场的脚步声。

### 人物与双轨节奏

- **人物弧线进展**：从“暗中替弟弟补签抹平”第一次被逼成“亲手拍下封库键把弟弟和脏货锁在现场”（旧信念裂开第一道缝，但工牌被偷刷将她推入自证清白的新险境）；
- **外部压力**：一路收紧（替弟补签→恒温区红灯报警→撞破调包与亲弟要挟→拍下封库键→发现工牌被偷刷）；
- **内在情感负荷**：习以为常的护短叹气 → 被亲弟拿字迹要挟时心头骤冷 → 拍下封库键时决绝 → 看见自己工牌签名时陷入被至亲背刺的寒意。
