# 短剧 Know-how 学习

通过定性阅读理解编剧、漫剧工作室与编导怎样把戏剧意图传递到可执行的文本制作规格，并将可迁移规律转化为去标识的公共知识候选。

## 授权与范围边界

- 仅在维护者主动调用本 skill、且当前会话已提供授权只读访问时读取非公开来源；连接细节、凭据、源名称与私有卡片只留在维护者指定的隔离工作区，严禁写入本 skill、公开技能树、公共候选或评测夹具。无授权或无法确认只读时停止读取来源，仅用合成材料演练。
- 只研究文本及其版本关系（创意简报、故事结构、剧本、资产/连续性、图片提示词、分镜/关键帧、视频提示词、审查与修订记录）；不生成、下载或检查图像、音频、视频。公开运行时永不连接非公开来源。

## 核心原则

- 题材语境、人物欲望、因果、信息差、情绪推进、表演动作、镜头意图与制作取舍由 agent 定性判断；脚本只做格式校验、文件比对、查重与隐私扫描，不为创作语义写规则匹配代码。
- 统计只用于描绘样本分布、发现覆盖缺口与安排下一次阅读，不得从频次、排名或相关性直接推导创作规则。
- 每条候选知识必须同时具备证据、反例或失败情形、冲突解释、适用边界和置信度；每次只提出最小可审查改动，经全新上下文盲测与独立审查通过后方可进入公共技能。

## 工作流

1. **确立只读授权与隔离工作区**：记录本轮目的、可读范围、禁读内容、输出位置与销毁要求；测试一次只读行为（不回显连接信息），建立私有研究目录与独立的去标识候选目录。
2. **按覆盖缺口选样**：按题材、受众承诺、核心机制、篇幅阶段、制作形态、场景功能、提示词职责与修订状态寻找缺口、对照组和反常样本，避免只读最热门或最易查询的项目。
3. **定性通读完整项目链**：从创意/改编约束 → 故事引擎与分集 → 单集剧本 → 资产与连续性 → 图片提示词 → 分镜与关键帧 → 视频提示词 → 审查与修订逐层通读（缺层记入 `missing_layers`，不靠外部常识补齐）。研究提示词与制作形态时结合 [prompt-production-learning.md](references/prompt-production-learning.md)。
4. **写私有观察卡与决策卡**：通读后按 [cards-and-coverage.md](references/cards-and-coverage.md) 写 `observation_card`（分离直接观察、agent 解释与未知）和 `decision_card`（记录候选结论、缩窄理由与替代解释），并更新题材 × 机制覆盖矩阵。
5. **用反例与冲突压缩边界**：主动寻找同机制失败、同题材例外、替代解释及上游成立但下游不可制作的情形，按 [synthesis-and-promotion.md](references/synthesis-and-promotion.md) 写成条件式规则（`applies_when` / `fails_or_changes_when`）；冲突未解释时保持 `conflict_pending`。
6. **去标识、去复刻与构建候选包**：按 [synthesis-and-promotion.md](references/synthesis-and-promotion.md) 彻底剥离源标识、原句与罕见桥段组合，用全新题材、关系、空间与动作重写合成例子，打包 `reference`、`rubric` 与 `synthetic fixture` 候选。
7. **全新上下文盲测与独立审查**：按 [blind-forward-eval.md](references/blind-forward-eval.md) 用干净上下文的 fresh agent 跑匿名 `baseline` / `candidate` 对照，并交由未参与摘取或写作的独立 reviewer 揭盲前盲评、揭盲后核对边界与隐私。
8. **晋升、缩窄或退休**：通过独立审查后，按 [promotion-ledger.md](references/promotion-ledger.md) 记录去标识的生命周期事件与回滚定位，将最小改动合入公共资料；后续出现反例、无增益或诱发模板化时及时缩窄或退休。
