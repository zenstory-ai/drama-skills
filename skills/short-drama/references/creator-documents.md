# 五份创作文档

正文优先供创作者阅读；下文的标题、引用和参考字段用于跨文档核对与投产定位，按所示语法填写，不为填满示例补造事实。

## `剧本.md`

- 一级标题以集号开头，如 `# EP001 集名`；每场用 `## EP001-SC001 内 · 地点 · 时间/天气`（空间性质可写 `内`、`外` 或 `内外`）。
- 对白用 `角色（可选表演提示）：台词`；画外音、画外对白、音效、可见文字、连续性和转场分别用 `[VO]`、`[OS]`、`[SFX]`、`[画面文字]`、`[连续性]`、`[转场]`，不要把含冒号的动作叙述误写成对白。
- 不为每段台词生成 block ID，不另写节拍表、索引或录音表（用户明确要求时除外）。

## `视觉设定.md`

按人物、造型、地点和道具分节，二级标题固定为 `## <人物|造型|地点|道具> · <名称>`（分镜「视觉依据」按此标题定位）。每项只写跨镜需保持的识别锚点、当前状态与变化原因，不抄剧情摘要，也不把瞬时姿势或机位升级成新资产。

```markdown
## 人物 · 许棠
- 识别锚点：窄长眼、左眉尾旧疤、肩背略绷。
- 本集造型：深灰旧西装，右袖口有雨水深痕。
- 状态变化：EP001-SC003 后右手掌沾血。
- 画面代称：Xutang
- 连续性锁：LOCK-XUTANG-SUIT《许棠深灰旧西装》（镜头：入画；图片提示词项：IMG-XUTANG-SHEET）· 锁面：dark-grey worn wool suit
```

- **画面代称**：提示词正文里直接称呼该条目的名字（按项目提示词语言写，多个写法用 `、` 分隔，至少两个字符）。未声明时回退条目名称；显式声明后只匹配所列代称（写 `画面代称：无` 则取消名称匹配，适用于「手机」「小雨」等易误撞普通词的条目）。当有效提示词语言非中文时，**所有人物条目**必须给出非中文代称或写 `画面代称：无`；地点和道具按需声明。
- **连续性锁**：跨镜出现且不随剧情改变的可见事实（服装主色形制、道具颜色材质、发型长度、伤口位置）才上锁，会变的部分留在 `状态变化`。一行一把锁：`LOCK-...` 本集唯一；`镜头：` 写 `入画`（所有「视觉依据」含本条目的镜头）、`全集` 或 `、` 分隔的 `SHOT-...` 列表（只在部分景别可见的服装/发型锁写在对应 `造型` 条目下）；`；图片提示词项：` 可选；`· 锁面：` 后写不含标点、动作和剧情的最小名词短语。生效范围内的冻结关键帧、`MOTION-...` 与被点名的 `IMG-...` 正文均须包含该锁面（忽略大小写）。

## `分镜.md`

每镜一个二级标题，镜头 ID 在本集内唯一稳定。一场戏拍成多镜时，在该场首个 `SHOT-...` 前写一段「场景站位」，各镜只写相对变化：

```markdown
## 场景站位 · EP001-SC001 · 旧走廊
- 固定锚点：走廊一端是江家的门，另一端是楼梯口；顶灯在门前
- 人物：许棠站在门外，面对门，背对楼梯口
- 轴线：许棠 ↔ 门；摄影机工作侧（即机位常驻的那一侧）：楼梯口一侧
- 变化：无
```

```markdown
## SHOT-EP001-001 · 门外停步
- 来源：EP001-SC001
- 时长：4s
- 目的：先让观众看见他不敢进门，再揭示门内争吵。
- 景别/机位：中近景，门框外侧，轻微低机位。
- 运镜：固定；他收手的那一下要自己被看见，机位不抢。
- 起点：许棠右手悬在门把上方。
- 唯一动作：门内玻璃落地声触发许棠收回右手，视线从门把转向门缝。
- 终点：许棠右手垂回身侧，视线落在门缝。
- 图片提示词项：IMG-XUTANG-SHEET《许棠角色板》（控制：身份、体态、本集造型）；IMG-CORRIDOR-NIGHT《夜间走廊场景板》（控制：空间地理、门位、光向）。
- 输入参考图：无（创作者已明确选择文生视频）。
- 视觉依据：《视觉设定.md》·人物「许棠」（控制：身份、体态、本集造型）；地点「旧走廊」（控制：空间地理、出入口、光向）。

### 冻结关键帧提示词
> 按项目提示词语言编写的冻结瞬间正文……
```

- 「运镜」写行为和理由（固定也写理由）。冻结关键帧提示词必须与“起点”一致，不得提前写入终点状态或塞入整段动作。
- **三类依据严格区分**：
  1. **图片提示词项**：《图片提示词.md》中的 `IMG-...《中文名》（控制：范围）`，只证明提示词条目存在；
  2. **输入参考图**：项目内真实可读图片（`REF-...`）或创作者在项目外准备、生成时自行挂载的图（`PLAN-...`）；
  3. **视觉依据**：每镜必写，冻结关键帧成稿后按画面实际需要认出的人物、地点和道具回填（画外人声、不可识别局部与临时杂物不入列；手部特写不写「本集造型」；确无可见条目时写 `无`）。关键帧正文提及某条目名称但其不在画面内时，在末尾追加 `；画外：人物「小明」`。

```markdown
- 视觉依据：《视觉设定.md》·地点「教室」（控制：课桌排列、窗位）；道具「旧书包」（控制：磨损、颜色）；画外：人物「小明」。
```

### `REF-...`、`PLAN-...` 与四种输入参考图状态

```markdown
REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
PLAN-<slot>（顺序：<n>）· <IMG-... 或 SHOT-...>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

- `用途` 只能取 `身份`、`造型状态`、`地理`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格` 之一（详见 [参考角色](reference-roles.md)）。一张图只占一个槽位，同一路径不得在同镜重复绑定；一镜最多一张 `起始帧`、一张 `结束帧`（有 `结束帧` 必有 `起始帧`）。
- `PLAN-...` 用于创作者在外部界面自行挂图（定位符填本项目已有的 `IMG-...` 或 `SHOT-...`；`顺序` 对应 `<Picture N>` 挂图次序），可与 `REF-...` 混用并统一连续编号。
- **四种准备状态**：
  1. **已绑定 `REF-...`**：真实文件在项目中，可进图生/参考生视频与内置生产技能；
  2. **已声明 `PLAN-...`**：创作者在项目外挂图（无项目内匹配图且创作者未另选时的默认路径），视频提示词照常产出，但需把真实文件放进项目改写为 `REF-...` 后才能走内置生产技能；
  3. **待补**：仅在创作者明确要求先等图进项目时使用（全无时写 `无（待补参考图：……）`，缺部分时在已有槽位后追加 `；待补参考图：……`），此时阻止产出最终视频提示词；
  4. **`无（创作者已明确选择文生视频）`**：创作者明确不用参考图，走文生视频。

以下四例对应提示词项与输入参考图的独立组合：

```markdown
- 图片提示词项：无
- 输入参考图：无（待补参考图：许棠身份、旧走廊地理、本镜起始帧）
- 视觉依据：《视觉设定.md》·人物「许棠」（控制：身份、造型）；地点「旧走廊」（控制：空间地理、出入口、光向）。
```

```markdown
- 图片提示词项：无
- 输入参考图：REF-XUTANG-LOOK（顺序：1）· 输入/参考图/许棠定妆.jpg《许棠定妆照》（用途：造型状态；控制：本集造型、面料质感；不得控制：镜头构图、动作、表情）
- 视觉依据：《视觉设定.md》·人物「许棠」（控制：身份、体态）。
```

```markdown
- 图片提示词项：IMG-XUTANG-SHEET《许棠角色板》（控制：身份、体态）
- 输入参考图：PLAN-SHOT-START（顺序：1）· SHOT-EP001-001《本镜冻结关键帧》（用途：起始帧；控制：起始构图、站位；不得控制：尚未发生的动作、终态）；PLAN-XUTANG（顺序：2）· IMG-XUTANG-SHEET《许棠角色板》（用途：身份；控制：脸型、体态、本集造型；不得控制：构图、动作、表情）
- 视觉依据：《视觉设定.md》·人物「许棠」（控制：身份、体态）；地点「旧走廊」（控制：空间地理、出入口）。
```

## `图片提示词.md`

每项一个可投产的角色板、场景板、道具板或状态图。标题用 `IMG-...`（提示词条目 ID，不代表已生成图片文件），正文放在 `### 可复制提示词` 引用块内：

```markdown
## IMG-XUTANG-SHEET · 许棠角色板
- 用途：锁定身份、体态和本集造型。
- 参考：无外部参考

### 可复制提示词
> 按项目提示词语言编写的正文……
```

## `视频提示词.md`

每个正式镜头对应一个 `MOTION-...` 条目（编号与 `SHOT-...` 一致），「输入参考图」与对应分镜逐字一致：

- `REF-...` / `PLAN-...` 就绪时写 `生成方式：图生视频`，静态视觉锚点只写执行动作所需且参考图未覆盖的可见起点，不把路径或槽位 ID 写进可复制正文；
- `输入参考图：无（创作者已明确选择文生视频）` 时写 `生成方式：文生视频`，必须写出包含人物、造型、地点、构图与光线的非空「静态视觉锚点」并原样并入可复制正文，不得用 `preserve/保持已有外观` 代替。
- 可复制正文里被引号或 `<d>` 包裹的中文台词必须与《剧本.md》或《视觉设定.md》逐字一致。
- 除非剧本或创作者明确要求，视频正文须显式声明全镜不生成非画内字幕、caption 和对白文字叠加；画内文字（标牌、屏幕等）按 `exact_readable` 政策逐字携带字符、语言、承载面与位置，不用全局 `no-text` 抹除。

```markdown
## MOTION-EP001-001 · 门外停步
- 分镜：SHOT-EP001-001
- 时长：4s
- 生成方式：文生视频
- 输入参考图：无（创作者已明确选择文生视频）。
- 静态视觉锚点：A lean young East Asian man in a dark-grey worn suit stands outside an old corridor door under cold overhead light.
- 起始帧：许棠右手悬在门把上方，视线落在门把上。
- 状态链：右手悬在门把上方 → 门内玻璃落地触发他收回右手并转移视线 → 右手收回，视线落到门缝
- 终点：右手收回；门内玻璃落地；人物视线转向门缝。

### 可复制提示词
> A lean young East Asian man in a dark-grey worn suit stands outside an old corridor door under cold overhead light. His right hand starts suspended above the handle, then withdraws……
```

相邻同场镜头打包进多镜容器时，保留逐镜 `MOTION-...` 并另写 `GROUP-...` 条目（检查器核对成员相邻、同场、时长等于成员之和、单镜不重复入组，以及引文与锁面）：

```markdown
## GROUP-EP001-01 · 门外到门内
- 成员：MOTION-EP001-001、MOTION-EP001-002
- 时长：8s
- 理由：同场连续，同一走廊地理与人物造型

### 可复制提示词
> 镜头1：…… 镜头2：……
```

## 共通规则

- `### 可复制提示词` 下的引用块是整段直接复制给单次生成的一条提示词（含方言分段的 `subject_definitions` / `overall_soundscape` 等），不放占位符、流程备注、文件哈希、内部路径或 QA 结论。
