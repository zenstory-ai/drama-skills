## 文档阶段收尾：从 152 个校验错误到 OK

五份文档写完后，`creator_markdown_check.py` 一次报了 152 个错误。**其中 148 个来自同一件事**：
`视觉设定.md` 的五把连续性锁都写着 `镜头：全集`（资产阶段没有 `SHOT-...` 可引用），

《图片提示词.md》缺的三条状态板（`IMG-PROP-NOTE`、`IMG-LOC-DRILLGROUND-DUSK`、
`IMG-LOC-EDITROOM-DAWN`），把 SHOT-002／009／011／017 的「待补参考图」改写成真实
`PLAN-...` 槽位。剩下 2 个错误是我自己写新板时把 `参考：` 字段写成了指向另一条 `IMG-...`，
而该字段只接受「无外部参考」或完整 REF 语法。

改完 `OK`。**这说明 148 个错误其实是一个阶段顺序问题的放大**，不是 148 处独立缺陷——
