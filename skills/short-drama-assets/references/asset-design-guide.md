# 视觉设定拆解指南

## 1. 时代背景与器物制式（`AST-14` / `AST-15`）

拆设定前，先从原著与剧本里的常用设备（全面屏智能手机、液晶屏、门禁卡）、传播渠道（短视频、直播、热搜）、流行语或明确年份推算故事年代，在 `视觉设定.md` 顶部写一行 `- 时代背景：`（年份或年代 + 设备、制服、家具、照明款式）：

```markdown
- 时代背景：当下（2020 年代）；设备：全面屏智能手机、轻薄笔记本、液晶显示器；制服：现行翻领常服；陈设：白色工位桌、网面办公椅；室内照明：冷白嵌入式 LED 面板灯。
```

- 原著与剧本看不出具体年代时标为「待创作者拍板」，不擅自默认成老年代。
- **防跨年代错位，放行合理日常旧化（`AST-14`）**：器物制式不得与故事年代打架（例如主角用智能手机抢单、刷直播，不得把出租屋或餐馆写成九十年代显像管电视、二八大杠配 BP 机）。符合角色境遇或场所日常使用的物理旧化质感词（如工装袖口磨毛、旧木柜台水渍、临河外墙斑驳、日晒褪色雨棚、`worn cuff`、`faded canvas`、`dusty top shelf`）均可正常使用；剧本只写某一件物件旧损时，只写在该道具或陈设上，不顺手把整间现代场所改成几十年前的老房子。

## 2. 顺场出场盘点与建档边界（`AST-01` / `AST-02` / `AST-06`）

顺读剧本正文，对照场景 ID 盘点人物、场所与物件的出场方式及可见描写，只把影响认人、跨场复用、提示词编写或前后连戏的事实写进 `视觉设定.md`：

- **实拍出镜 vs 其他出场方式**：
  - **画外音（只闻其声）**：登记人物（有对白时按需写角色声线），本场不挂出镜服装造型；
  - **照片、屏幕或画像中出现**：写明采用历史时期造型还是模糊剪影，不默认画成清晰当下正脸；
  - **仅台词提及**：不建视觉设定条目，只有镜头真要拍清某份文件或物件时才建档；
  - **揣在怀里未露面的随身物**（如“隔着衣襟按住怀里的账册”）：只记揣放位置与外衣隆起状态，不在未露面场次挂该道具参考图，防止生图模型把怀里物件直接画在手外；
  - **环境陈设 vs 独立戏用道具**：门窗、墙面开关和普通桌椅归地点 `固定陈设` 或环境陈设；需要特写辨认、上手操作、转手交接、看清字样或跨场连戏追踪的物件才单建 `道具` 条目。
- **指代消歧（`AST-02`）**：存在两种以上讲得通的身份或物件指向时，列清候选对象标为「待创作者拍板」，绝不硬猜：
  - 场上多人却只写代词“她/他”、或写“另一把钥匙”但归属不明 → 标待拍板；
  - 前文写外貌代称（如“穿雨衣的人”）、后文揭晓真名 → 核实证据吻合后合并入同一人物条目，不单凭衣服同色提前强并；
  - 同头衔不同人（两个“值班员”）分建条目，同一人换称呼（本名、职务、亲属称谓）归入同一条目；背景群演一旦开口说关键台词或交接核心道具即单建人物条目。

## 3. 固定本体、阶段状态与单镜动作切分（`AST-03`）

每次出场归入**沿用旧设定**、**新增造型/状态**、**新建条目**或**待创作者拍板**四类之一，严守三层边界：

| 类别 | 固定本体（不变则沿用） | 阶段造型或状态（新开造型/视角或记入本集状态） | 单镜临时动作（归分镜，不写进视觉设定） |
|---|---|---|---|
| 人物 | 五官骨相、头身体态、永久特征（痣/疤/断眉）、剧中身份 | 成套服装鞋履、盘发梳法、妆容、持续伤污包扎、年龄跨度、易容伪装 | 当镜神情、站坐姿势、视线落点、左右手动作、景别 |
| 地点 | 空间布局、功能分区、出入口连通、固定陈设、主材尺度 | 常用机位视角、陈设阶段变化、昼夜时段、晴雨天气、拉闸断电等光线状态 | 单镜机位高低、焦段选择、演员当镜走位 |
| 道具 | 款式尺寸、部件结构、主材肌理、永久专属印记 | 持有人归属、搁放位置、开合启停、破损染污、内装物、字迹变化 | 哪只手拿握、抬手递接瞬间、落在画面左或右 |

- **何时单立 `造型`/视角，何时只记 `本集状态`**：变化跨多场持续、反复重现或需单独出设定参考图（如换穿夜班雨衣跨三场、跳闸断电后持续半集）→ 单立 `造型` 条目或地点分视角状态，只写相比基础设定的差异；仅维持几镜的小范围变化（如右肩淋湿几镜、指尖沾灰擦掉）→ 直接记在 `本集状态` 里，不拆碎条目。
- **何时新建独立条目**：坐实为不同人物（双胞胎、冒名顶替者单建人物；本人易容仍归原人物的新造型）；同一建筑内布局与出入口独立的房间（候船厅与值班室分建两个地点并写明连通门洞）；需分别追踪流向的同款多件道具（调包的两块同款号牌分建两条道具）。
- **命名约定**：换装或阶段状态用 `主体名—后缀` 或自然短名（如 `顾禾—橙色雨衣`），场景分视角把朝向或状态写在括号里（如 `旧渡站值班室（北向断电）`）；其他文档引用 `视觉设定.md` 时直接写可见标题。

## 4. 人物与阶段造型要点（`AST-03` / `AST-13`）

- **人物固定 `外观特征`**：写清稳定的脸型骨相、眉眼鼻唇特征、发际线与发质、永久印记，不用“年轻漂亮”“气质冷峻”等空泛词顶替具体长相；补齐**正、侧、背面都能认人的体态或轮廓特征**（如窄下颌、后颈尖角发际、右肩略微前倾）以及**主要角色身高体型参照**（如“甲比乙高半头，站直齐门框下沿”）。
- **画风适配**：按项目视觉方向挑选有效辨识点——写实与厚涂侧重骨相比例与服装肌理，平涂漫剧或剪影感画风侧重发型外轮廓、肩背姿态、配饰几何形状与主色块对比；画风只改变表现手法，不擅改角色年龄体格。
- **阶段 `造型`**：只写同一时段能同时穿戴在身上的服装层次、发型妆面、穿戴配件及跨场持续伤势包扎（注明变化原因与起止场次），手持道具仍归道具条目。有对白的角色按需补充声线设定，详见 [角色声线与配音设定](voice-direction.md)。
- **跨语言 `- 提示词名称：`（`AST-13`）**：仅当下游提示词语言与条目标题语言不同、且提示词正文实际点名该条目时填写（如 `- 提示词名称：Guhe`；混合语言项目把实际用到的拼写用 `、` 并列，全集大小写统一）。若提示词正文从不点名，或日常道具名（如 `手机`、`钥匙`）容易与普通环境词重名误判，写 `- 提示词名称：无`；提示词语言与条目标题一致时无需填写。

## 5. 地点布局与分视角设定

- **先立空间结构，再写氛围质感**：写清房间宽窄、出入口连通方向与搬不走的 `固定陈设`。室内方位一律用陈设之间的相对位置（“旧木柜台与临河东窗平行”“配电箱钉在柜台后墙靠北门一端”）或固定朝向（北门、东窗）描述，不在地点本体里单写“左侧大窗”，防止分镜正反打一换机位左右全反；人物倚靠、撑扶或落座的家具写明人体高度参照（如“木柜台高约 90 厘米，台面齐成年人腰带”）。
- **分视角与环境状态**：多镜共用同一拍摄朝向或特定光线状态（如拉闸后顶灯熄灭、只剩河窗冷光）且需出参考图时，在地点条目下补写该视角的观看方向、同框陈设与光源状态；单镜临时仰俯拍或焦段变化留给分镜。

## 6. 道具形制与五类字迹规则

- **固定形制与状态流转**：写清尺寸参照（如手掌长、A4 对折大小）、结构部件、主材肌理与专属印记；开合启停、破损染污、内装物及持有人流转统一记入 `本集状态`（具体哪只手拿握、怎么递接交分镜逐镜安排）。区分**道具客观状态**与**人物知情状态**（匣内一直装着号牌是道具事实，角色撬开才看见是剧情知情节点）。拄拐、背负重物、手铐等持续限制行动的随身绑定写清部位与起止场次。
- **道具字迹处理五选一**：带文字、编号或界面的道具明确选定一种处理方式——
  1. **字迹清晰可读**：记准字句原文、语种、大小写与剧本出处，下游提示词不得同时挂全局禁字词；
  2. **只留版式轮廓**：保留标签、封条或印章的色块版式，不生成可辨认字符；
  3. **表面无字**：器物表面干净无字；
  4. **字句待创作者拍板**：剧本要求看清字样但具体字句未定，或原著含真实品牌商标（列清「保留原名 / 只画款式去标识 / 改虚构名」供拍板）；
  5. **只在后期叠加**：系统面板、悬浮弹窗或精准跳字只在后期合成，生图与视频保持对应区域干净留白。

## 7. 综合示例（渡站夜班场）

```markdown
## 人物 · 顾禾

- 外观特征：二十八岁上下女性，窄长脸，左眉尾有一道短缺口，黑色自然微卷发收在后颈，身材清瘦、站立时肩背略前倾。
- 角色声线：女中音偏干爽，语速平实利落，尾音收得脆；情绪紧绷时压低音量、换气短促。
- 提示词名称：Guhe

## 造型 · 顾禾—夜班雨衣

- 外观特征：灰绿工装夹克与深灰直筒裤外罩一件洗旧褪色的橙色长款防雨风衣，兜帽垂在肩后，袖口磨毛，黑色防滑短靴。
- 本集状态：EP001-SC004 出门前穿上至 SC006 脱下；SC005 巡检栈桥后风衣右肩被暴雨打湿变深。

## 地点 · 旧渡站值班室

- 外观特征：狭长平房内室；北门通候船厅，东墙开一扇临河横窗，西侧设一排高约 90 厘米（齐成年人腰带）的旧木柜台，柜台表面留有常年擦拭的浅水渍，灰色铁壳配电箱钉在柜台后墙靠北门一端。
- 本集状态：SC001–SC004 室内冷白荧光顶灯常亮；SC005 配电箱跳闸后顶灯全灭，仅东墙临河横窗透入雨夜冷蓝微光（北向视角从柜台内侧朝北门看，横窗落右后方）。

## 道具 · 铁皮号牌匣

- 外观特征：小臂长的扁长黑漆铁皮匣，带金属合页翻盖与铜搭扣，匣身右前角有一块旧凹坑；匣盖内侧白漆手写「潮位 7」（字迹清晰可读）。
- 本集状态：SC001–SC003 扣合锁死、内放带裂口的白瓷号牌，搁在旧木柜台下层隔板；SC004 顾禾开匣取出白瓷号牌后呈敞开空匣状态，盖内「潮位 7」字样露出，白瓷号牌转归顾禾随身携带。
```
