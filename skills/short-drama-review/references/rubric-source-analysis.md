# 原著与对标拆解核查清单

用于审查 `项目开发/source-analysis/` 下由 `$short-drama-novel-analyze` 产出的原著拆解文档（`_index.json`、`triage.md`、`chapters/*.md`、`story-units.md`、`rhythm-and-emotion.md`、`characters.md`、`world.md`、`adaptation-value.md`、`episode-candidates.jsonl`），以及由 `$short-drama-breakdown` 产出的 `项目开发/对标拆解.md`。

## 1. 章节索引与授权拆解范围核对（`NVA-01`、`NVA-03`）

若环境已安装 `short-drama-novel-analyze` 技能，可运行其索引校验命令；单独安装本技能时直接核对索引与原文行号：

```bash
python3 {novel-analyze 技能目录}/scripts/novel_index.py verify \
  项目开发/source-analysis/_index.json 输入/{原文文件}
python3 {novel-analyze 技能目录}/scripts/novel_index.py coverage \
  项目开发/source-analysis/_index.json 项目开发/source-analysis/chapters
```

- **索引结构核验（`NVA-01`）**：`verify` 退出码非零报错时判结构阻断，退回重建索引；网文原文常见的作者跳章号、重章号或过短过渡章由脚本归入 `warnings` 提醒，**不因原文跳号提醒直接判阻断**。抽查 `_index.json` 的章节切分粒度，防止把章内小节误切成独立章。
- **支持按创作者授权章节范围拆解（`NVA-03`）**：创作者指定只拆解授权章节区间（如前 50 章、第一卷或选定篇章）时，只要 `chapters/` 完整覆盖了**创作者本次划定的目标章节范围**，且汇总文档显眼注明了所覆盖的起止章号范围，即视为合规通过，**绝不拿“未拆完全书所有章节”一刀切判不过**。只有既未声明局部拆解范围、又无故漏拆目标区间内章节或混入无关凑数文件时，才报覆盖缺漏。

## 2. 抽样快评守界与原文事实对账（`NVA-02`、`NVA-05`、`NVA-07`）

- **`triage.md` 抽样范围守界（`NVA-05`）**：开头须写明抽读比例与实际抽读章号，评估统计仅基于已读抽样章节，不凭空推断未读章节，快评阶段也不提前越界产出 `episode-candidates.jsonl`。
- **回查原文防脑补与串行（`NVA-02`、`NVA-07`）**：抽查 `characters.md`、`world.md`、`adaptation-value.md` 中的等级体系、数额距离、关键台词归属与首次出场章号是否能回查到原文行号。原著未写明却被脑补成确定事实的，退回改为「原文未明确」或删去；重点排查把甲的台词安到乙头上或抄串相邻章节数字。

## 3. 逐章提炼、人物归并与影视化切集（`NVA-06`、`NVA-08`–`NVA-13`）

- **逐章提炼与同人合并（`NVA-06`、`NVA-08`）**：逐章情节点须写出具体动作或交锋如何改变了强弱势、知情范围、关系亲疏、筹码增减或死线压力，不拿“展现了惊人实力”“心中愤怒”充数；`characters.md` 不得单凭泛称（“红衣女子”“护卫统领”）草率合并人物，合并绰号与本名须有原文证据。
- **影视化改法与切集依据（`NVA-09`、`NVA-10`、`NVA-12`、`NVA-13`）**：原著纯心理或背景说明若保留入戏，须写明改用什么可见动作、物证或场面表现（不能换汤不换药全推给大段旁白）；分集候选按每集阶段结果与集尾悬念切分而非按固定章数字数机械平分。正式从哪章开篇、留哪条支线与总集数由创作者与 `$short-drama-develop` 拍板，拆书审查不拿创作取舍卡死流程（`NVA-12`）。

## 4. 本地对标拆解审查边界（`项目开发/对标拆解.md`）

审查 `$short-drama-breakdown` 产出的本地对标学习报告与差距表时，严守以下边界：

- **本地私有拆解允许写真实参考剧片名**：`项目开发/对标拆解.md` 属于创作者本地私有的研究与学习记录，**允许直接写明真实参考剧片名、集数与平台出处**以便创作者直观核对，绝不因为在本地拆解报告里写了真实剧名就判违规（仅在对外公开发布或入库公开示例时才要求脱敏）。
- **重点核查是否照搬专有设定与原句台词**：核查主项目的《剧本.md》《视觉设定.md》与提示词是否只提炼了节奏结构与视听手法，**严禁直接照搬对标剧的专有人名、独有世界观名词、原句台词或受保护的独创桥段**；同时核对同尺差距表是否标清了纸面估算（`plan`）与成片实测（`measure`）口径（`BRK-06`），且未把外部对标均值硬当成卡死本项目的强制门槛（`BRK-07`）。
