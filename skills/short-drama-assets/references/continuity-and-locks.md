# 跨场连戏与连戏锁指南

## 1. 跨场连戏状态记录（`CON-01` / `CON-02` / `CON-03` / `CON-05`）

`视觉设定.md` 只管跨场次、跨集数的状态接力，不在设定文档里反向抄录下游 `SHOT-...`、`IMG-...` 或 `MOTION-...` 台账：

- **前后衔接与变化有据（`CON-01`、`CON-02`）**：相邻场次的收尾状态与下一场开场状态自然接顺；人物伤势、持物归属、道具开合破损、昼夜晴雨与室内亮灭灯都必须有剧本动作或场次过渡支撑（上集末尾带伤而本集未提痊愈时，默认延续带伤或标待创作者拍板，不凭空复原）。
- **只记影响后续接戏的净变化（`CON-03`）**：在对应人物、造型、地点或道具条目的 `本集状态` 下简明写清「变化前后状态 + 触发场景 ID 与原因 + 起止有效范围（跨集延续时注明本集结束状态）」，无需每场重抄不变特征，也无需手工回填受影响的下游镜号。
- **非线性叙事例外（`CON-05`）**：回忆闪回、梦境幻觉、蒙太奇或明确的时间跳跃可打破常规连戏，但需点明对应的历史造型或主观状态及进出节点，不覆盖主时间线的当前状态。

示例（跨场与跨集收束写法）：

```markdown
- 本集状态：SC004 开场扣合、内装白瓷号牌搁于柜台下层；SC004 顾禾开匣取牌后保持敞开空匣（本集结束仍敞开搁在柜台面，白瓷号牌由顾禾转交魏叔随身收存）。
```

## 2. 跨镜连戏锁与下游适用范围（`CON-07`）

`- 连戏锁：` 用于锁死跨多镜或设定图反复出现、一旦画偏就会穿帮的静态核心外观（如主力制服颜色版型、关键信物主色材质）。全集精选几处关键服装或核心道具即可，不必给每条 `外观特征` 都加锁。

### 下游生效边界

- **必须原字带入 `锁定词` 的位置**：
  1. 连戏锁点名的**静态图片提示词**（`图片提示词.md` 对应 `IMG-...` 的 `### 可复制提示词`）；
  2. 锁定范围内镜头的**首帧提示词**（`分镜.md` 的 `### 首帧提示词`）；
  3. **未垫首帧或主体参考图的文生视频提示词**（`视频提示词.md` 中无参考图直出时的可复制提示词）。
- **图生视频免塞全身串**：已挂载首帧图或角色/道具主体参考图的图生视频，人物衣着与物件外观已由输入参考图锁定，视频动作提示词聚焦动态表演与运镜即可，**不必为了凑字面匹配重复硬塞一整串全身服装描述**（若项目运行开启了全量字面校验的连戏锁检查，服装锁应挂在 `造型` 条目下并仅在需要文字兜底时声明，避免给纯动作图生视频增加冗余词负担）。

### 语法与条目挂载位置

写在 `视觉设定.md` 对应条目下（无需回抄下游 `SHOT-...` 镜号列表，推荐直接用 `镜头：入画`）：

```markdown
## 造型 · 江晨松枝绿常服

- 外观特征：现行松枝绿翻领常服，浅绿衬衣配深绿领带，直筒长裤与黑皮鞋。
- 连戏锁：LOCK-JIANGCHEN-DRESS《江晨松枝绿常服》（镜头：入画；图片提示词项：IMG-JIANGCHEN-SHEET）· 锁定词：pine-green lapel service jacket
```

- `LOCK-...`：本集唯一编号；`《<名称>》` 写明所锁外观对象名称（支持中文或外文）。
- `镜头：`：默认填 `入画`（校验器自动按分镜 `出场设定` 匹配引用了该条目的镜头），也可填 `全集` 或用 `、` 分隔的指定 `SHOT-...`（三者不混写）。**服装连戏锁务必挂在 `造型` 条目下并填 `入画`**——若挂在 `人物` 条目下，手部或眼部特写引用该人物时也会被误判需要出现外套描述。
- `图片提示词项：`：可选，填需同步锁定的 `IMG-...`（多项用 `、` 分隔），无需约束设定图时整段省略。

### 锁定词写法与匹配规则

- **精炼静态名词短语**：用与下游提示词一致的语种写「颜色 + 材质/款式 + 物件」（如 `pale blue chunky knit wool sweater`、`chipped white enamel mug`），不带句号、动作时态、临时方位（如 `in her hand`、`on the desk`）或空泛画质词。生图/首帧（`format/prompt_language`）与视频（`video_prompt_language`）语种不一致时，优先用通用专名型号，或直接靠视觉设定文字说明而不挂跨语种逐字锁。
- **字面匹配边界**：校验忽略大小写与换行，锁定词内部不增删改词；英文前后缀粘连（如 `unchipped` 不算匹配 `chipped`）以及紧跟在 `no / without / 不要 / 没有 / 避免` 等否定词后面的排除写法均不算有效出现。
