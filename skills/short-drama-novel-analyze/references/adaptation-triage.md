# 改编价值快评

## 产出什么

产出 `triage.md`，回答**这本书值不值得花全量拆解的成本**。S5 用全量结果核对这份快评，并把印证或推翻的判断写进 `adaptation-value.md` 开头。

## 抽样怎么取

由脚本等距抽样（首尾必取，结果确定）：

```bash
python3 {技能目录}/scripts/novel_index.py sample \
  项目开发/source-analysis/_index.json --count 12
```

默认 12 章；书极长或框架复杂时可调大 `--count` 并在快评里注明。抽到的章正文极少（`char_count` 很小，多为卷首页）时往后顺延一章并记录。

快评只判断**功能与载体**，不写完整情节点表或人物表，不产出 `chapters/` 下的文件。

## 写六件事

`triage.md` 固定写六段：

### 1. 故事框架

从 [聚合与实体](aggregation-and-entities.md) 的框架表里选一个：升级流 / 复仇线 / 单元剧 / 多线交织 / 蜕变成长。抽样判不出时写「抽样不足以判断框架」并说明原因。

### 2. 三类判定比例

按 [改编价值](adaptation-value.md#三类判定) 的三类（`screen_ready` 可直接拍、`needs_carrier` 需换表现方式、`prose_only` 仅限文字）统计抽样各章归属，分母统一为实际阅读的抽样章数。`prose_only` 过半时直接说明全量拆解大概率不会改变结论。

### 3. 开篇替换点

回答**如果这本书改成短剧，第 1 集从哪里开始**：找**观众在此处收益最强、且能同时交代主角身份、眼前危机与目标的一处**（打脸、奇观、反转、身份揭露、奖励兑现、危机爆发、关系破冰或错位反差；旁观者群体改口或对手当众吃瘪同样算）。通常不在第一章，后文高潮也可提前做冷开。写清四条：

- 落在第几章（用索引的 `sequence`），收益类型是什么；
- 抽样里若另有更晚、更强的高光，一并列为冷开候选；
- 它之前的内容里，哪些是观众必须知道的，可怎样在开场后补入；
- 哪些是原著读者需要、短剧观众不需要的。

抽样里未见可用替换点时写「抽样内未见可用的开篇替换点」，并列入第 5 段风险。

### 4. 制作负担量级

抽样里出现的：最多几人同框、需要多少个不重复空间、有无群戏 / 动作 / 特效 / 可读文字 / 跨时间造型变化。按已接受制作形态给量级（形态未定时按两种形态各给一句）。

### 5. 三处最大改编风险

具体到抽到的哪一章、哪个功能，不写「改编难度较大」等空泛结论。

### 6. 分集候选量级

按抽样里的戏剧结果密度给量级（例如「约 20–30 集」），并注明由 N/M 章推算。

## 结论限于抽样范围

`triage.md` 第一行用脚本返回的 `coverage_ratio` 与 `total_chapters` 声明覆盖率：

```markdown
> 本快评基于抽样：读了 340 章中的 12 章（3.5%），章号见下表。以下判断仅为抽样假设，待全量拆解后核对。
```

只用读过的章做证据；需要提及抽样外内容时写「抽样未覆盖」。快评写完后向创作者报告覆盖率、六段结论、全量拆解预计耗时及直给建议（值得拆 / 不值得拆 / 拆但先砍掉某几卷），按 `SKILL.md` S1 约定停靠。
