# 短剧故事开发方法

在制作 `creative-brief.md` 与 `story-engine.md` 时使用本文件。规则分级与 `STY-*` 规则表见 [阶段契约](stage-contract.md#本阶段规则)。

## 1. 从题材词到戏剧承诺

“复仇”“甜宠”“悬疑”“家庭冲突”只说明货架位置，没有说明观众每次回来会得到什么。先回答五个问题（`craft_default · STY-01`）：

1. **主角**：观众跟着谁顶住压力、作出抉择？
2. **诉求**：这个人现在想拿到、守住、查清或摆脱什么？
3. **硬阻力**：谁或什么处境能让他的追求持续付出代价？
4. **独特矛盾**：主角最管用的做法，为什么同时会伤到他最在意的人或东西？
5. **反复回报**：每一集观众期待看到哪类局面变化——夺回主动、识破谎言、关系拉近、底牌见光、道德抉择，还是别的？

把答案压成一句可检验的工作陈述：

> 当【主角】用【惯用做法】追求【当前目标】时，【对抗机制】逼他付出【核心代价】；全剧反复兑现【观众回报】，直到【终局转折】让旧回路无法继续。

### 回报词本身不构成承诺：要写清它落在哪里

"后悔""复仇""守护""翻身"只是回报的名字；必须写清它落在关系变化、位置变化还是认知变化上，否则选出的事件无法兑现观众期待。以"让对方后悔"为例：

- **落在关系上**：观众要看的是那个人终于意识到自己弄丢了谁，收束常发生在一次无法挽回的转身或迟到的发现上。例如结婚五年嫌家里油烟伤味觉、从不下厨的主厨丈夫，在给女助理煮夜宵逼走妻子后，回到空屋翻出妻子五年来按他胃病忌口手抄的几百页药膳本，而女助理转头连他海鲜过敏都记错——观众等的是他捧着旧本子意识到“再也没人这么护着他”的那一下刺痛。
- **落在地位与实权上**：观众要看的是“离了我，你什么都不是”被当众坐实，必须有可核对的处境崩塌。例如丈夫瞒着妻子刷走她一百万副卡给小姑子办豪门订婚宴，还当着满堂宾客逼她签字把婚前别墅和公司股份送给小姑子当嫁妆；妻子当场停掉所有副卡、重置别墅门禁，并甩出小姑子虚报发票侵占八十万公款的审计单报警——观众等的是吸血一家当众付不出酒席尾款、从风光舞台直接跌进看守所的落差。

### 回报要先有舞台，再有能力

关系、家庭、复仇等靠积累兑现的题材，**先建立回报会被花掉的场合与对象，再让主角拿到能力**；在主角取得关键优势前，观众应已认得具体的人、具体的场合或具体的那句话（三者至少立起一项）。例如写“被赶出家门的学徒凭古画修复手艺翻身”：先立起“三天后师父要在行业大展上，拿抢走他父亲的残破古画当众给师弟挂帅”，再写他拿到失传的揭裱工具、摸出画心夹层里的暗记，观众从他拿起刀片起就在盼展台上的翻盘。

系统流、重生穿越、逆袭等爽文例外：奖励可先到位，被打脸的人与场合可同场建立（见 [题材卡](genre-cards.md)）。

### 承诺的压力测试

- 换掉人物姓名和职业后仍与大量故事无区别 → 独特矛盾不够具体；
- 对抗者只需解释一句话就会停止阻碍 → 阻力无结构性；
- 主角不行动也能得到结果 → 追求无主动性；
- 只有最终结局有回报，或每次回报完全同形 → 缺少单集兑现或变化空间。

## 2. 设计能持续运转的冲突引擎

### 2.1 写出一轮回路

```text
触发压力
→ 主角依据自己的信念选择做法
→ 对手/制度/关系作出有力反制
→ 主角拿到阶段性结果并承担新代价
→ 权力、信息、关系、暴露、资源、时间或身体状态改变
→ 新状态逼出下一轮更难的抉择
```

若删掉“选择”与“代价”仍能发生相同剧情，说明只是作者搬运事件。

### 2.2 检查引擎的六个部件

| 部件 | 开发问题 |
|---|---|
| 压力来源 | 哪个角色、规则、秘密、资源限制或关系义务会反复施压？ |
| 对抗能力 | 它为什么真的能阻挡主角，而不只是态度恶劣？ |
| 主角策略 | 主角通常怎样解决问题？该策略的优点和盲区是什么？ |
| 退出成本 | 主角为何不能离开、报警、坦白或轻易换目标？ |
| 变化空间 | 压力能在哪些状态维度改变，而不只是声量增加？ |
| 终止条件 | 什么事实、选择、关系或能力变化会让旧回路无法继续？ |

**`craft_default · STY-02`**：让压力来自多种相互作用的来源（人物意志、关系义务、现实约束）；单一坏人若无筹码，只能重复阻挠。

### 2.3 给引擎留出变化

每一轮只选对当前选择真正有影响的状态维度推进：

- **权力**：谁能决定规则、分配资源、定义事实；
- **知识**：谁知道什么，谁只知道一半，谁掌握可验证证据；
- **关系**：信任、债务、依赖、联盟和边界如何移动；
- **暴露**：秘密被谁看见，公开范围和被利用方式如何变化；
- **资源**：时间、场地、证件、金钱、工具或帮助者是否可用；
- **物理状态**：距离、伤势、持物、封闭空间、天气等怎样改变行动能力；
- **道德成本**：要赢这一轮，主角必须变成怎样的人或伤害谁。

## 3. 让人物成为压力的制造者

为主要人物写清“在压力下会怎么选、为什么这么选”：

- **表层目标**：此刻在明面上争取什么（如保住老街共享厨房的承包权）；
- **保护对象**：哪怕自己在明面上吃亏，也绝不肯牺牲谁或什么（如带进门的徒弟、瘫痪在床的母亲，或自己死守的职业体面）；
- **自我解释**：心里怎么替自己的做法找理由（如偏心母亲觉得“老大有本事，让着点没出息的弟弟怎么了”）；
- **惯常策略**：遇到麻烦第一反应怎么应付——私下兜底、讨好退让、拿规矩压人、先斩后奏还是借刀杀人；
- **筹码**：手里握着什么能迫使别人让步的东西（签字权、钥匙、底账、抚养权或关键把柄）；
- **盲区**：对自己、亲人或局势一直误判了什么；
- **底线与越线条件**：平时绝不会做什么，什么危机逼到头上会让他破例；
- **可变事实**：一旦看清哪件事实或哪段关系变了质，就会彻底换一套活法。

### 3.1 观众为什么站在他这边

为主视角人物至少答出以下四问中的一条，并落到第 1 集的可见画面上：

- **他正在承受什么不该由他承受的东西**？不公要具体可见（被顶掉的署名、被改的排班、当众被夺走的东西）。
- **他正在替谁扛**？替一个在第 1 集露过面的具体人物扛。
- **他想要的那样东西，观众是不是也想要**？尊严、被认出、护住一个人、把一件事做完。
- **他有什么本事是观众想借来用一次的**？看穿谎言、修好难题、难堪场合仍保体面。

### 3.2 关系中的双向压力

不要只写“母女”“上司下属”“旧恋人”，写成双向筹码与制约：

```text
一方需要另一方提供什么 / 害怕另一方看见什么 / 用什么约束另一方
另一方需要一方提供什么 / 害怕一方拿走什么 / 用什么反制一方
```

关键人物须拥有独立目标和可用筹码，而非只负责递线索或制造障碍。

## 4. 用状态变化判断升级

### 4.1 先写前后状态

对主要事件先核对（`reviewed_invariant · STY-03`）：

- 事件前后谁占主动？
- 新获得或失去的事实、证据、盟友、资源是什么？
- 哪段关系变得更近、更远或更不平等？
- 哪个选择现在不可撤回？下一步为什么更难、更贵或更暴露？

### 4.2 区分四种常见推进方式

- **扩张**：同一矛盾波及到新的人、更大的公开场合或更重的责任（如原本只是姐弟俩在店里争排班，闹到供货商当场断货、物业上门收钥匙）；
- **反制**：对手看穿了主角的套路并堵死老办法（如对手知道主角手里有录音备份，下一轮直接断网收手机、改用不留字据的口头指令压人）；
- **代价落地**：前一次选择欠下的雷现在炸了（如上一场为了护住徒弟私下涂改了交接单，这一场那张被涂改的单子反倒成了对手举报她造假的铁证）；
- **意义改变**：新浮出水面的证据让同一件旧事彻底翻了个个儿，但不推翻此前观众亲眼见过的画面（如一直以为父亲死死护着旧座钟是偏心舍不得给女儿，拧开后盖才发现里面塞满了三年来偷偷替她攒下的嫁妆存单）。

主要转折优先来自角色选择与此前压力的后果；偶然事件适合开启问题，不适合替人物解决核心困境。

## 5. 管理信息、证据与兑现

### 5.1 分开事实与认知

区分四件事：世界中实际发生了什么、每个角色相信什么及依据、观众何时知道什么、哪个可见证据能改变某人的判断。

### 5.2 铺垫记录的是义务

铺垫首次出现时须有**顺理成章的当场表面理由**，并在分集记录中对应 `setup_id`（`structural_invariant · STY-05`）：

- **首次出现的位置与表面理由**：在哪一集、借什么动作或物件自然带出，观众当时怎样理解；
- **埋下的期待或问题**：暗中为后面哪一步转折做准备；
- **兑现方式与局面变化**：在哪一集翻出，并当场改变谁的选择或处境；
- **改动牵连**：若悬置、改义或删改，受影响的是哪几集的兑现。

例如“订婚宴 88 万改口费刚进账一分钟就被自动划走”的连环局：
- **生硬塞伏笔（像作者提前剧透）**：第 1 集还没出事，镜头就莫名其妙给新娘三个月前在银行办卡时签字的特写，或者让旁白直接说“她不知道这张卡暗藏玄机”。
- **带当场表面理由埋入、后文翻盘兑现（自然）**：第 1 集在 ATM 机前查出余额为 0，婆婆质问新娘是不是故意拿错卡，新娘把卡退出来递到婆婆眼前：“妈，这卡是三个月前定亲时您和许浩亲自陪我去柜台办的改口费专卡，卡号也是您亲手抄的，我就这一张卡。”此时这句话的**表面理由**只是自证“没拿错卡”；等到第 3 集柜台查出“那笔钱被三个月前办卡当天刷脸签署的第三方代扣协议秒扣”时，这句前文铺垫立刻翻成抓内鬼的铁证——那张卡从头到尾只有三个月前办卡当天未婚夫拿着她的手机做过人脸识别！

## 6. 让主题进入选择

把主题写成难以同时满足的两项价值（如“诚实与保护”“自主与被看见”“规则公平与个体补偿”），让不同人物用有代价的选择给出不同答案，使核心冲突同时触碰外部目标与人物珍视的价值。

## 8. 从引擎走向分集

进入 [episode-design.md](episode-design.md) 前确认：第一集开始前压力为何已活跃、主角首次选择如何暴露策略与盲区、哪些状态维度有变化空间、哪些铺垫有兑现责任、终止条件距当前多远、规模是否符合边界。先设计必要的状态台阶，不从集数倒推重复事件。

## 9. 合成示例

> **背景起因与人物关系**：老城区一家低租金共享厨房正逢商业街改造，物业公司一心想抓“私自替班或值班台账造假”的违约把柄，好无偿收回租约改建高价商铺。管排班的年轻厨师叶澄为了保住十几个底层小摊主的饭碗，长期在有人突发急事时私下顶班、涂改明面上的纸质排班本压下违规记录，把真实的换班垫付账目记在冷柜后夹缝的一本私人底账里。

戏剧承诺：

> 她每次靠瞒报和私下调班替弱势摊主争来喘息之机，都会让明面上的账本破绽百出；观众一集集看她凭救场本事化险为夷，也看着原本受她庇护的摊主因信息不透明而猜忌倒戈，直到她必须在“自己一人暗中包办”和“把真实底账摊开让众人共担风险”之间做个了断。

引擎部件：

- **压力来源**：紧缺的一号猛火灶时段、彼此防备的摊主、随时准备抓违约把柄收铺的物业经理；
- **主角惯常策略**：有人出事她先暗中替班灭火，再涂改明面排班本应付物业巡检；
- **对手反制**：不明真相的老摊主抓着对不上号的排班表闹事争利，物业顺势拿“内部举报台账造假”当借口进场收权；
- **退出成本**：她自家生计也拴在这间厨房，更对带她入行的老伙计们许过“绝不让一个人被物业清退”的诺言；
- **变化空间**：谁摸清了私下改班的底细、排班钥匙在谁手里、摊主之间怎么重新站队；
- **引擎终止条件**：排班大权从她一人私下兜底变成众人按明规共担风险，或者厨房租约被物业正式收回。

- **原地重复而不升级**：又有摊主因家里有事迟到，大家再次争吵，叶澄再次帮人调开时段。
- **真正改变局面**：昨晚凌晨三点的一号猛火灶原本排的是老摊主齐曼，齐曼前两天私下跟退伍老兵新摊主老周换了班；不料老周因孩子半夜高烧惊厥送急诊没能赶到，叶澄怕物业早巡抓到“私自换班加空岗”直接罚没老周五千块押金清退，便亲自替老周守灶、代签了凌晨三点的《冷链鲜肉送货单》，并把明面排班本涂改回原定排班的齐曼名字以应付物业巡检。今早送货商按排班本上的名字拿着叶澄代签的黄色送货底联找齐曼结肉款，齐曼以为叶澄合谋抢占她的灶位还把肉账赖到自己头上，直接把送货底联拍在案板上当众对质。从此矛盾从“猛火灶档期怎么排”彻底变成“叶澄凭什么私改台账连累全员违约”，她在摊主中的威信与物业手里的收铺把柄同时变了。
