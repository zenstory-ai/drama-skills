# 场景空镜与地理保持

## 1. 地理优先与母版派生（`IMG-04`）

**`reviewed_invariant` IMG-04**：地点板提示词保持 `视觉设定.md` 已确认的布局、观察方向、固定锚点、材质与光向；默认不出现演员（`empty_stage`），不因装饰细节搬动门窗或掩盖尺度关系。

按「两两相对关系 + 视线终点」编写（而非无序物件清单）：
1. **空间身份与尺度**：空间用途、内外与整体尺度；
2. **观察位置与朝向**：从哪个入口或一侧看向哪里、可见边界（如“从卷帘门向内看，检修台沿右墙延伸，尽头唯一安全门正对通道”）；
3. **入口、动线与固定锚点**：门、窗、柱、柜台等不可移动物之间的距离与方位（写明如“柜台平行于窗、离窗约一米”，防止生成为孤岛）；
4. **材料、主次色与当前状态**：墙地顶材质、磨损，以及本版本的陈设、时段、天气与光态。

- **多视角从全视图母版派生（`craft_default`）**：同一地点需出两个以上观察方向（如正反打）时，先写一张同时包含主要分区、入口与固定锚点的全视图母版，各分视角均绑定母版作参考派生（通常一场戏控制在正、反打两个工作侧视角），出图后与母版核对锚点方位（纯左右镜像且无文字的可水平翻转使用，结构错位则重出）。

## 2. 跨视角光线对齐与空场政策（`IMG-10`）

**`reviewed_invariant` IMG-10**：同一地点在同一时段/天气状态下的所有观察视角，必须共享一致的光学事实（仅允许因观察朝向不同产生自然的顺/逆光与遮挡落影）：
- **主光来源**：同一扇窗、同一组实际灯具或同一片天空；
- **色温主次**：冷暖主次一致，不得一块板将暖色台灯作主光而另一块板压为次光；
- **光比与暗区方向**：亮暗落差量级与暗区所在空间方位一致；
- **灯具开关状态**：同一状态下不得一块板亮吊灯、另一块板熄灭。时段推进或停电改光时，该地点所有受影响视角同步按状态变化更新。

**`structural_invariant`（`empty_stage` 空场政策）**：
- `required`：严禁出现剧情角色、群众或叙事动作，仅保留固定家具与功能设备（与“主角站在门口”显式冲突）；
- `preferred`：以空场为主，仅允许无身份的中性尺度参照且不遮挡地理；
- `not_required`：允许背景人群或工作痕迹，但不得编造主角剧情事件。

## 3. 制作形态投影（`reviewed_invariant`）

根据项目视觉方向与制作形态选择空间表达手段（绘制形态用线条密度差、色块与留白建主次；写实形态用光比、景深与空气透视），但**形态简化与留白只能省去次要装饰，严禁抹掉入口、通道、安全门等本视角必须核对的固定地理锚点**，也不得为凑形态气氛擅自封锁出口或新增事故痕迹。
