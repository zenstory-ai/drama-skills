# 阻断级规则匿名对照盲评

## 适用范围

本流程**仅在提议新增或收紧阻断级门禁规则**（`structural_invariant` / `reviewed_invariant`）时启用，用于在合入前验证新门禁确实能防住真实硬伤且不误伤正常创作。

以下改动**免跑本流程**，完成脱敏核查并通过仓库现有回归测试即可落地：

- 新增或修订 `craft_default` / `taste_option` 参考经验；
- 凭明确反例、成片反证或模型能力演进，对过严、失效的既有规则执行降级、收窄范围或直接废止。

## 简化执行流程（2 生成 + 1 盲评）

1. **构造纯虚构对口测试题**：针对待测规则所在的创作阶段，编写采用全新题材、人物关系与场景的纯虚构输入材料。测试题至少覆盖一组目标常规场景（检验规则能否防住目标硬伤）和一组临界或反例场景（检验规则是否误拦合理变体），严禁沿用非公开项目的人物、原句或独有桥段组合。
2. **准备匿名 A/B 版本**：准备除本次待测规则外完全一致的两个技能版本，随机标记为版本 `A` 与版本 `B`（不带新旧、基准或候选字样）。
3. **2 个干净子会话匿名生成样本**：分别启动 2 个干净子会话，各自只加载其中一个匿名版本与同一套虚构测试题，以普通创作者口吻独立生成对口阶段样本。两子会话互不可见，不传入起草人意图说明、内部笔记或预设答案；生成后剔除本地路径与工具读取痕迹，只保留纯匿名阶段样本 `A` 与 `B`。
4. **1 个独立子会话盲评**：启动 1 个未参与素材研读与规则起草的独立子会话，在不告知 `A` / `B` 新旧对应关系的前提下，直接对照测试题与两份匿名样本逐项核查并给出采用或退回结论（不设虚构的盲调度人角色，也不拆分揭盲前后两轮锁定仪式）。

## 盲评核查项

独立盲评固定核查以下四项核心指标，不按总分加总或关键词命中自动判赢：

1. **目标效果**：在目标场景下，是否切实消除了原本会导致跨阶段断层、事实打架或交付失败的硬伤，而非只换了一套表面套话。
2. **反例误伤**：在临界场景或不同题材变体下，是否误杀原本合理的拍法与写法、强行扭曲人物选择，或逼出僵硬凑数的套路。
3. **指令膨胀成本**：是否平白增加了繁琐的填表步骤、重复声明或冗长提示词负担，干扰该阶段核心创作判断。
4. **脱敏合规**：规则表述、测试题与生成样本是否完全基于虚构或公开内容，未残留非公开来源特征，也未触发外部私有连接。

除上述四项必查外，可按所涉阶段选填对口补充维度（无需凑满固定八项）：

- **故事与剧本阶段**：戏剧因果链条、人物主动性、跨题材看点迁移；
- **视觉设定、分镜、提示词与剪辑阶段**：跨镜连贯性、参考素材分工、动作与运镜可生成性。

## 结论处理

- **准予合入**：新版在目标效果上确有实质提升，且无反例误伤、指令成本可控、脱敏合规时，方可作为阻断级规则合入，并将门禁设立依据与边界写入仓库 `.agents/notes/` 决策笔记。
- **降级、收窄或放弃**：若盲评发现临界样本被误伤、增益不明确或明显加重文牍负担，不得设为阻断门禁；应退回降级为 `craft_default` 经验建议、进一步收窄适用前提，或直接放弃。
