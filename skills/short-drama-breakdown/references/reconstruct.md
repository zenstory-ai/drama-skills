# 整集与多集还原

## 授权登记与目录约定

- **先登记权限、测出实参再建还原项目（`BRK-01`、`BRK-02`、`BRK-11` · `reviewed_invariant`）**：
  1. 开测前在 `输入/对标/<REF-ID>/对标登记.md`（外层已有主项目时可一并记入 `项目开发/对标拆解.md`）写明 `REF-ID`、素材路径、授权用途（`study`、`owned` 或附依据的 `licensed`）及是否允许上传外部模型服务；未确认允许外传时只跑本机离线测量脚本。
  2. 先跑 `measure` 拿到画幅比例与片长，再在 `输入/对标/<REF-ID>/还原/` 下建立独立还原项目目录（标题写 `<REF-ID> 还原`；若已安装 `short-drama` 技能，交由它按实测画幅比例初始化项目；独立运行时直接按标准目录约定创建 `还原/剧集/EPxxx/` 与 `还原/审查/` 即可，不跨技能调用其他技能目录中的脚本。`owned` 或 `licensed` 作品确认后可按 `BRK-11` 整套迁出为根项目，不把单集还原文件混进外层主项目的 `剧集/` 目录）。
- **落盘位置**：每集按需写入 `还原/剧集/EPxxx/` 下的《剧本.md》及后续《视觉设定.md》《分镜.md》《图片提示词.md》《视频提示词.md》（若已初始化独立项目，空的 `设定集/` 等默认目录留空即可，单集设定写进《视觉设定.md》）。跨集人物对照、相邻集接缝表、台词与画面校对记录、原片穿帮和抽检结果统一放在 `还原/审查/还原核对.md`，保持《剧本.md》正文干净可演。多集连拆按集序一口气做完，不在集与集之间停下等确认。

## 按目标选做法

- **只反推《剧本.md》**：暂不写分镜和提示词时，只跑 `measure`、`subtitle-sheet`、`subtitles` 并通看原片音画，对照带镜号时间的 `*.sheet.jpg`、带 `Txxx` 时间戳的 `*.subtitles.sheet*.jpg` 与原片音轨写出各集《剧本.md》和 `还原/审查/还原核对.md`。不跑全集 `shots` 单镜切片；遇到闪白转场、超过 4 秒的长镜或 `tail_candidate_cuts` 提示集尾疑似漏切时，再按秒抽帧核实。
- **还原全套五份文档**：需要继续还原《视觉设定.md》《分镜.md》《图片提示词.md》《视频提示词.md》用于细读调度或重制出片时，再对目标集加跑 `shots` 导出每镜切片与首中尾静帧，逐镜整理景别、机位、运镜、站位及起止画面。

## 多模态看片注意事项与无音视频降级路径

调用同时读取画面与音轨的多模态模型看片时（仅限已获准上传外部服务，或使用本机离线模型）：

- **看片按单集隔离，写稿跨集统名**：多集连拆时，**看片阶段**每集用独立子会话或单集目录分别读取，避免把后集才出现的名条、服装或剧情带进前集；**写《剧本.md》阶段**对已确认同人的角色全剧统一用片中亮明的真名（例如配角首集无名条露面、次集才出名条点明姓名，两集正文统一写该姓名，但 `[画面文字] 名条：…` 只写在原片实际出现的位置，并在 `还原核对.md` 记下首次出现该姓名的集数与秒数）。
- **核实音轨可读，并用拼版和原图补齐抽样盲区**：首次使用未知看片接口时，裁一段去掉底部字幕的对白小片盲听确认能听见音轨；整集视频直传模型通常每秒只抽约 1 帧且压缩分辨率，容易漏掉不足 1 秒的闪切物证或看糊小字——切镜与硬字幕条数以 `*.sheet.jpg` 和 `10fps` 的 `*.subtitles.sheet*.jpg` 为准，遇到手机屏幕、纸质单据、大屏列表等小字画面，用 `ffmpeg -ss <秒数> -i <原片> -frames:v 1` 抽原分辨率静帧看字。
- **无原生音视频多模态输入时的降级路径**：若当前智能体环境只能读图与文本、无法直接输入视频或音频，改用**外挂字幕（SRT/WebVTT）或本地 ASR 转写稿**配合 `breakdown_tool.py` 产出的 `*.sheet.jpg` 代表帧拼图、`*.subtitles.sheet*.jpg` 字幕拼版、`audio` 音轨响度/静音测量（及需要还原分镜时的 `shots` 首中尾静帧）完成还原；仅靠静帧与字幕无法确认的说话人归属、声线语气、`[VO]`/`[OS]` 区分、消音词或无字幕气声，须按 `BRK-12` 在 `还原/审查/还原核对.md` 中明确标为待确认盲区，不凭空补全。

## 实测与还原步骤

### 1. 跑测量脚本与字幕拼版

```bash
<PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" measure <各集.mp4> --out 输入/对标/<REF-ID>/measure
<PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" subtitle-sheet <代表集.mp4> --out 输入/对标/<REF-ID>/subtitles
<PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" subtitles <各集.mp4> --out 输入/对标/<REF-ID>/subtitles --band <左,上,右,下> [--color <字色>] [--min-share <比例>]
# 可选：没有全程铺满背景音乐时辅助看静音段
<PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" audio <各集.mp4> --out 输入/对标/<REF-ID>/audio
# 需要还原分镜与提示词时再对目标集跑：
<PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" shots <重点集.mp4> <重点集.measure.json>
```

- **校准字幕框与字色**：对照 `subtitle-rows.json` 的 `suggested_band` 与 `subtitle-sheet.jpg` 红色比例网格，确认上下左右包住双行折行与长句首尾字，同时收窄左右边界避开两侧竖排名条、左上地点字卡或居中系统面板；黄字或彩字加 `--color`（如 `FFD400`）。不同集版式变化时单独设 `--band`。
- **读字幕拼版校字**：`subtitles` 除了保存单条 `Txxx.png`，还会生成左侧带 `T001  00:01.6-00:03.1` 标号的分页总览图 `*.subtitles.sheet*.jpg`（每页最多 40 条），读 1–3 张总览图即可校完一整集硬字幕；极小单字（如“是”“嗯”）若漏扫，可调低 `--min-share` 或听音轨补齐。
- **检查首尾帧、长镜与集尾切点**：`measure` 生成的 `*.sheet.jpg` 给每镜标出起止秒数，首尾镜较长时额外附上开场 `OPEN` 与集尾 `END` 帧，并在 `*.measure.json` 记下末镜低阈值候选切点 `tail_candidate_cuts`。每集都要看 `END` 帧和最后 3 秒原片，超过 4 秒的长镜或场次交界处结合时间轴核对有没有未达默认阈值的硬切或地点字卡。
- **铺满配乐时直接听音轨**：成片全程垫着大音量配乐时，`audio` 的 `voiced_share` 会接近 `1.0`，分不出某段画面文字有没有配音念出，直接听原片音轨判断。

### 2. 通看全集并整理《剧本.md》

结合原片音画、`*.sheet.jpg` 与 `*.subtitles.sheet*.jpg` 梳理人物、场次、画面文字、音效与台词：

#### （1）对白与硬字幕校对（`craft_default`）

- **避敏字还原**：配音正常读出原字、硬字幕写成平台避敏字（如“死”写成“亖”）时，《剧本.md》还原为正常汉字，原写法记入 `还原核对.md`。
- **消音与打码词替换**：音轨滴声或抽空静音、字幕打马赛克或星号时，结合前后语境和残余声母在 `还原核对.md` 记下推断原意，正文换用贴合人物口吻的可播词，不把马赛克符号或半截断句写进正文。
- **错字、同音异写与配音漏字校对**：同音错字（如 `他/她/它`、`的/得`、`复查/复茶`、`报到/报道`）按配音和剧情改回正字；原片自动字幕在同集或跨集中把同一人名、机构名写成不同同音字（如“周叙/周旭”、“盛阳科技/晟阳科技”）时，优先按工牌、公章、合同或正式名条上的字形统一全剧写法，没有画面定字依据时选定一种统名并在 `还原核对.md` 记下异写；硬字幕通顺完整而合成配音漏字或误重读单字（如字幕“注销权限”而配音读成“注权限”，或误读“左上上角”）时，正文取完整通顺的词句，配音瑕疵记入台账；角色刻意的喜剧倒装、反讽口误或心虚结巴照原样保留。
- **残留小说旁白改为动作**：部分网文漫剧把小说第三人称动作描写（甚至在形容词处截断的残句，如“半空忽然炸开一团刺眼——”）直接录进配音和硬字幕。若只是复述画面已经演出的动作或属截断病句，直接改写为动作段描写，不留作角色 `[VO]`；表达言行反差、暗地盘算或浓缩前史的内心独白才保留 `[VO]`。
- **无字幕气口、误识单字与配乐采样**：推动情绪的无字幕轻笑、抽泣、倒吸气、惊呼写入对白括注或动作段；自动字幕把震惊吸气或叹息误标成半秒语气字（如满脸惊骇吸气却闪出“哼”）时，按神态和听感改为动作反应；垫底配乐自带的说唱采样、哼唱旋律或版权音频水印核对嘴型后剔除。
- **拆屏合并、同屏拆分与数字写法**：一句台词因单行字数拆成多屏时按语义和气口合回整句；同一屏字幕把画内应答和转身后的闭口心声拼在一起时，按音轨与嘴型拆成现场对白加 `[VO]`；口语倒数（如“三、二、一”）按自然台词写，工位号与精确金额（如 `B2工位`、`18,500元`）保留数字。

#### （2）按场次内外标 `[OS]` 与 `[VO]`（`craft_default`）

- **同场切反应镜不标 `[OS]`**：同一房间或场次里当面交谈的角色，画面切到听者反应、手部特写或背影时继续说话，在《剧本.md》里一律写成普通现场对白，不因为单镜没拍到嘴就标 `[OS]`。
- **隔断空间或通讯外放标 `[OS]`**：隔着门窗墙体喊话、场外未露面人物插话、电话听筒或直播连麦外放，标 `[OS] 角色（如：电话音 / 门外）：台词`。
- **闭口心声与系统音标 `[VO]`**：核对说话时嘴唇是否闭合、是否戴面具无发声动作，以及是否为仅主角能听见的系统音或回忆混响；跨镜头声桥（如屋顶刺客的临死心声延续压在室内主角画面上）按音色、人称与立场定准说话人，不把画面里拍到的人直接当说话人。

#### （3）人物行、画面文字与原片穿帮处理（`craft_default`）

- **篇首 `人物：` 行与身份称呼**：每集 `# EPxxx 集名` 下先写 `人物：角色A、角色B……`，把全集零台词但在场承载关系的人物和只开口一次的身份角色一并列全，方便估时脚本直接识别说话人。全剧无名条、字幕和台词点明姓名的角色用简短身份称呼（建议不超过 6 个汉字，如“黑衣探子甲”“女顾客”），不编造人名（`BRK-12 · reviewed_invariant`）；若全片只在单处生成画面小字里出现姓名且疑似笔画粘连错字（无配音印证、同屏其他字也有乱码），改用身份称呼并在 `还原核对.md` 注明原字形存疑。
- **画面文字与穿帮分类处理**：
  1. **关键物证与界面字**：没有对白念出的关键纸条、通知单、系统任务面板、推动剧情的弹幕与来电/短信通知，写成 `[画面文字] 载体：内容`。原片局部生成错字或屏幕数额与紧邻对白冲突时（如“上限”误作“上眼”、“核查”误作“核杳”、转账屏数字与角色当场说出的金额不符、设置页混入招牌乱码），正文按上下文改回准确字面，原片错字记入 `还原核对.md`。
  2. **角色出场名条**：需保留时统一写 `[画面文字] 名条：姓名｜身份`，不在后续场次重复写。
  3. **地点与时间字卡**：如“渡口候船厅”“北郊山道”，直接并入 `## EPxxx-SCxxx 内/外/内外 · 地点 · 时间` 场次标题；承担倒计时或悬念提示时才单列 `[画面文字]`。
  4. **漫剧气氛符号与拟声字**：画面飘过的问号、震惊符号或拟声字改为神态动作或 `[SFX]`，不写 `[画面文字]`。
  5. **常驻免责水印与片尾挂角字**：“纯属虚构”“画面由AI生成”“未完待续”与平台台标直接剔除。
  6. **无意连戏穿帮**：生成画面常见的室内陈设跳变、面巾或外套忽隐忽现、背景人物面壁僵立、点单数量与手拿数量不符等穿帮，《剧本.md》正文按该场主空间和合理连戏状态写，原片穿帮秒数与表现记入 `还原核对.md`。

#### （4）场次切分与跨集接缝（`craft_default`）

- **闪回与交叉剪辑**：完整往事单立回忆场次并在场头或 `[转场]` 标明时间线；穿插在当场思绪里的几秒短闪回用 `[转场]` 归拢，避免切成一串单句碎场。屋顶与室内过招、马车内外、连麦屏幕内外等同一戏剧段落的高频正反切合并为 `内外` 场次。
- **跨集人物表与定长硬切接缝**：多集连拆时，在 `还原/审查/还原核对.md` 维护全剧人物表（记下真名首次出现的集数与秒数）和相邻集接缝表（上集末句末帧、下集首句首帧、是否重放、持物与伤痕连戏）。遇到定长成片把同一通电话或半句话硬切成上下两集时，先拼回连续对话理顺说话人和前因后果，再按分集点切回各集《剧本.md》，并在集尾 `[连续性]` 与下集开头注释写明承接关系。

### 3. 逐镜补齐其余四份文档（需要全套文档时）

需要全套五份文档时，结合 `shots` 导出的单镜视频、首中尾静帧与 `candidate_cuts`（`frames > 1` 多为闪白或粒子闪烁，单帧突变常为漏检硬切；与模型判断吻合的记为镜内切，不吻合的单列交人工定夺，`BRK-12`），逐镜整理景别、机位、运镜、站位与起止画面，按对应负责技能规范写入《视觉设定.md》《分镜.md》《图片提示词.md》《视频提示词.md》。拿自有或已获授权（`owned` / `licensed`）的还原项目重新出片时：

- 修掉原片穿帮空间与僵立背景人物，交 `short-drama-assets` 与 `short-drama-storyboard` 技能理顺空间动线并在 `审查/` 记下改动；
- 分镜说明里的镜内切点拆成独立单镜，一秒上下的眼、嘴、手或道具特写单独成镜，不并入相邻镜；
- 强风格化画面的《视频提示词.md》优先挂首帧或主体参考图走图生视频，出片看戏剧节拍与台词完整度，不为凑原片秒数硬开倍速。

## 时间轴回挂与准确度抽检

写完还原文档后运行本技能测量回挂并完成核对，把抽检结果记入 `还原/审查/还原核对.md`：

1. **格式校验与时长估算**：若已安装 `short-drama` 与 `short-drama-write` 技能，可分别移交它们做文档格式核对（五份文档未齐时仅作部分核对）与单集剧本时长估算（不在 `剧集/EPxxx/` 下留下临时索引文件）；独立运行时直接对照标准文档格式与本集实测时长逐项自检，不跨技能调用其他技能目录中的脚本。
2. **字幕时间轴挂回 `measure`**：按 `T001 台词` 或 `T005-T010 合并的长句台词`（自动取首条起点至末条终点合并跨屏/跨镜拆条，非台词事件直接省略）写一份文本映射 `EPxxx.cues.txt`，挂回 `measure.json`（也可直接在 `*.subtitles.json` 的 `events` 里填 `text` 后挂接）：
   ```bash
   <PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" transcript 输入/对标/<REF-ID>/measure/<某集>.measure.json 输入/对标/<REF-ID>/subtitles/<某集>.cues.txt --subtitles 输入/对标/<REF-ID>/subtitles/<某集>.subtitles.json
   <PYTHON> "<SKILL_DIR>/scripts/breakdown_tool.py" profile REF=输入/对标/<REF-ID>/measure --opening 3
   ```
   若继续用纸面剧本对照原片实测时长，可交由 `short-drama-write` 技能做单集估时（需先在还原项目配置中填好 `format.pacing` 语速与 `seconds_per_action_paragraph`）。单集时长估算会把动作段与台词串行相加——无对白打斗或静默定格偏多时纸面时长偏短，`[VO]` 叠在连续动作上偏多时纸面时长偏长，不必因此删改动作描写（首集加长而后续集定长时，估时可按本集实测秒数指定目标时长）。

| 核对项 | 抽检做法 | 计法说明 |
|---|---|---|
