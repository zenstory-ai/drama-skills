# 打戏与动作段的分镜

**`SHT-31 · craft_default`**：剧本已写清谁打谁、用什么、结果如何时，按回合拆镜、摆机位、卖打击。武器或证物跨镜争夺按 [调度手册 · 动态对象与竞赛](blocking-playbooks.md#5-动态对象与竞赛)（`SHT-14`）记账。

## 1. 先写交手账

拆镜前把打斗写成回合链，每回合三格：

- **发起**：谁、用哪只手或脚、拿什么、从哪个固定锚点方向来（不写画左画右）；
- **应对**：闪、挡、接、反制，还是被打中；
- **结果**：距离、朝向、武器控制权、伤势/体力，以及下一回合谁先手。

每回合至少改变一项结果；连续两回合结果不变即重复，找不到变化时请写作技能合并或删减。台词、对视和喘息放在回合之间作换气点，不打断回合内部。

- ❌ **原地踏步的两回合**（位置、兵器和主动权全没变）：
  - 第 1 合：护卫甲从院门挥右拳砸向沈一舟 → 沈一舟抬双臂硬挡 → 两人退回原位。
  - 第 2 合：护卫甲挥木棍横扫 → 沈一舟后仰闪开 → 两人仍隔院心对峙。
- ✅ **每回合改写局面的交手账**：
  - 第 1 合（破开通路）：护卫甲从院门石阶冲上挥木棍当头砸下 → 沈一舟侧身让过（木棍砸碎廊下水缸），右掌顺势反抽对方脸颊 → 护卫甲跌出石阶昏倒，院门让开，三少爷带人从门外逼近。
  - 第 2 合（护人夺势）：三少爷跨进院门抬右掌狠抽苏清雪 → 沈一舟跨步挡在苏清雪身前，左手半空扣死三少爷右腕 → 远距冲撞变为贴身扣腕控制，随从投鼠忌器不敢上前；苏清雪低声劝阻成为换气点。

## 2. 一个回合装进一镜还是拆开

单次交手通常仅一两秒，短于目标模型最短原生时长。对照 [镜长从哪来](shot-craft.md#镜长从哪来-sht-28) 按顺序选择：

1. **多镜容器（默认推荐）**：向创作者提议把一个回合装进一次生成（「起手中景 → 打击特写 → 余波中景」），各拍仍各自成镜，由剪辑在切点紧剪。
2. **整回合一镜**：未启用多镜容器、且最短原生时长装得下完整回合时，把发起、应对、结果作为本镜「唯一动作」在稳定机位下一镜完成。镜长取装得下该回合的最短一档（给多长模型就会把动作拉多长，正文写“快”“一气呵成”无法压回真实速度）。
3. **单独成镜**：只留给远景交代不了的信息（武器脱手与落点、决定性一击、改变下一步选择的反应）；打中后的连带脱手/滚落若紧跟在打击后同镜生成常被略过，重要时单独成镜或作为下一镜起点。决定性一击的多角度冲击重复按 `SHT-08` 处理。

## 3. 把打击卖出去

- **落空、格挡、闪避、扣腕、砸中环境**：用稳定侧面或斜侧中景在一个画框内看清出手路线与空隙；武器砸在环境上（火星、水花、凹痕）比砸在人身上更易生成且显力道。
- **打到脸或身体**：两个运动身体在接触点极易生成走样，按以下方式卖打击，并标为高风险镜、给出降级实现（如切在拳到前一帧接反应镜）：
  - **连续镜头同侧遮挡**：摄影机在轴线同侧换到出手者肩后或斜后方，用前景肩臂挡住接触点（不越轴反打以免丢失方位）；
  - **多镜容器打击特写**：画面只留承受者，拳脚从画外闯入砸中、脸顺来力甩开，由剪辑裁短；
  - **同向反应与余波**：承受者头与身体顺来力方向甩开、退步失衡或捂住受击处，配合闷响、飞溅物或撞歪陈设。
- **贴身抱摔/缠斗**：一镜只写一次控制（哪只手臂箍住哪里 → 挣脱或放倒），中间角力用声音和一次发力带过，不写多步手部换位。

## 4. 多对手方位与竖屏景别

- **多对手方位**：在「场景站位」给每个对手记相对主角的固定锚点方位；每回合只有一个对手出手，其余停在可见等待位；主角转身换对手时先用全景/中全景重建方位，不在两个近景间直接跳轴。
- **竖屏景别**：新阶段首镜用全景/中全景交代步距与武器归属；交手用能看到双脚的中景/双人中全景；近景与特写只给握紧武器、脱手落点或决定性一击后的脸。9:16 竖屏横向窄，把横扫、侧踢摆成朝向/背离镜头的纵深或斜线，高举武器与高位腿法预留纵向空间。

## 5. 强度档（`taste_option`）

- **写实克制**：动作幅度接近真人，受击结果小而准，不加特效层；
- **商业强化**：动作更大、节奏更紧，允许冲击重复和适度夸张退位；
- **超现实**：允许击飞、法术与光效（特效形状、颜色与持续时间先在视觉设定定清）。

伤势按可见结果写（踉跄、捂肋、嘴角伤），血量与伤口细节随创作者强度选择与平台政策，不在分镜自行加码。
