# Agent Note: 对标拆解增加还原层——一集或多集还原成剧本、物料与提示词

Status: implemented

翻转 [对标拆解技能](2026-11-03-benchmark-breakdown-skill.md) 里「不复制对标的情节、台词与人物」与「它不写剧本、视觉设定」两处边界；原笔记的测量、对照与出片验证部分不变。

## Problem

创作者要的拆解是能还原：拿到一部对标，能看到它一集甚至连续多集的剧本、角色与场景物料、每一镜怎么生成，集与集之间怎么接。原来的 `short-drama-breakdown` 只量、拆、比：BRK-02 规定报告和交接不带剧名、人名、台词和桥段，阶段契约写明不写剧本与视觉设定，脚本也没有看片和听片的能力，画面只有每镜中点一帧。

2026-11-04 对比了 awesome-short-drama-skills 列表和延伸检索出的 13 个同类项目。列表的全流程组 23 个仓库里，除本套件外没有成片拆解模块；能还原的几家在别处：VediotoScripts 一次性产出分场剧本、画风圣经和逐镜关键帧与视频提示词（不是可复用技能，校验器写死 32 镜）；minimax-h3-video-reverse-skill 从逐镜事实契约编译 H3 提示词并有校验器，但写明没做过生成对照；剧灵把视频交 qwen-vl 加专门转写还原剧本，带平台抓取。没有一家做跨集衔接，也没有一家用原片回头量还原结果。

## Decision

### 还原层是对标目录里的一个套件项目

- 还原结果放在 `输入/对标/<REF-ID>/还原/`，在那里单独初始化一个套件项目，目录与文件格式和普通项目相同：`项目开发/`（分集地图、系列大纲）、`设定集/`（人物、造型、场景、场景视图、道具、道具状态，外加风格圣经与声音说明）、每集 `剧集/EP###/` 下的剧本、视觉设定、分镜、图片提示词、视频提示词五份文件，保真度核对写进它的 `审查/`。
- 五份文件的格式照各自负责技能的写法，技能里只按技能名路由（`$short-drama-write` 等），不链对方文件。
- 本项目各阶段不读还原项目（BRK-02）。登记用途为 `owned` 或 `licensed` 且记了依据时，还原项目可以离开对标目录（BRK-11）：整个复制成新项目，或让各阶段技能在它里面接着改，不合并进当前项目的剧集；`study` 用途下它只给本技能提炼机制和同尺对照。

### 规则改动

- **BRK-01** 登记增加允许用途（`study`、`owned`、`licensed`，后两种记依据）和是否允许把原片上传到外部模型服务；没登记允许外传时只做本机测量。
- **BRK-02** 对标原片、字幕裁图、逐镜小段和还原项目都留在 `输入/对标/<REF-ID>/`；报告和交接仍不带对标的剧名、人名、台词与独特桥段，BRK-11 允许的交接除外。
- **BRK-11**（`structural_invariant`）：还原结果只在 `owned` 或 `licensed` 且记了依据时离开对标目录。
- **BRK-12**（`reviewed_invariant`）：切点取测量值，有字幕的台词时间取字幕扫描值，锚不上的台词、名字和镜头事实标推断；模型报的切点对不上测量或候选切点时列给人判断；名字要有画面或台词证据，否则用身份称呼。

### 看片走 agent 一侧，脚本做确定性测量

- 新参考资料 `references/reconstruct.md` 写全流程：看片通道（`agy` 配 `gemini-4-argon-high`，每次调用新目录，先用裁掉字幕的片段确认听得到音轨）、整集听看一遍与逐镜看一遍的字段、对齐与自查、跨集统一身份与接缝表、写成套件文件的还原守则、保真度核对表和一组实测。
- `breakdown_tool.py` 新增四个子命令，只用标准库加 ffmpeg：
  - `subtitle-sheet`：从同一部剧几集里挑描边字最多的帧，四边标比例刻度拼成校准图，并记下每个高度带出现与换字的比例；由 agent 看图定字幕区和字色，脚本不自动认定哪行是对白字幕；
  - `subtitles`：在定好的字幕区里扫带深色描边的字形（默认看亮度，`--color` 时看颜色），给出每句烧录字幕的起止（约 0.1 秒）并存裁图；给了 `audio` 结果时记下有声时间里有字幕的比例，作扫描自检；
  - `audio`：`silencedetect` 与 `ebur128` 给出有声区间与响度，用来判断画面文字有没有人念；
  - `shots`：按测量切点切出每镜小段与首、中、尾三帧，并列出低阈值（默认 0.1）的镜内候选切点，相邻 0.3 秒内的并成一段。
- SKILL.md 工作流加「3a. 还原（需要时）」一步，description 加上还原的触发说法。

### 实测依据

同日用一部三维国漫画风、160 集的系统流漫剧还原前 12 集（854 秒）：台词 371 句，全量字错率 0.34%，两集抽查漏句为 0；抽 16 镜 12 对、3 部分对、1 错（集界第一镜认错人）。整集调用给的台词时间普遍早 0.3–0.6 秒，改用字幕扫描的时间；测量阈值 0.28 在一集里漏了 31 处镜内切，`shots` 的候选覆盖其中 27 处。模型给一位父亲编了一个没出现过的名字，还把两句监控时间当成台词；前者按名字证据规则剔除，后者用 `audio` 判定为没有人声。开头三集之后各集都是 50.03 秒，11 对接缝里 3 对断在半句上、5 对重放上一集结尾，所以多集还原按连续母版做。

## Alternatives considered

- **只在 `owned`/`licensed` 时才允许还原，学习用途不还原**。最强理由：最不容易出事，BRK-02 一字不改。不用：创作者拆对标的主要目的就是学习，学习用途拿不到逐镜事实，机制提炼仍靠每镜一帧和人眼；对标目录加流向规则已能挡住台词和人物进本项目。
- **像 VediotoScripts、剧灵那样直接全量复刻，还原结果直接流向下游**。最强理由：最贴近「还原出剧本、物料、提示词」的字面要求，少一层授权判断。不用：下游剧本与提示词会带上别人的台词和人物，违背套件的原创边界，创作者发布后承担侵权风险。
- **还原层只写本技能自定的逐镜事实 `timeline.json` 与人物表，配一个 `reconcile` 校验器**（提案阶段的方案，已写出一版实现）。最强理由：证据类型、镜号、切点冲突都能由脚本逐字段核对，格式不依赖别的技能。不用：实测里真正要的是能直接读、能接着改的剧本与提示词，逐镜事实只是中间产物；校验器的字段规则多半是审查者的语义判断，按规则分级不该写成阻断代码；还原项目沿用套件格式后，`plan` 能直接量还原剧本。
- **脚本自动找字幕区**（按行统计描边字形，取出现最多、换字最多的一带）。最强理由：一条命令完成，不依赖 agent 看图。不用：画面里带描边的字不只对白字幕，还有名条、系统面板、招牌和片尾字卡，哪一行是对白是语义判断；黄字、彩字在亮度统计里根本不出现。脚本只出校准图和行统计，由 agent 定区域，再用有声时间覆盖率自检。
- **把 Gemini 调用写进 `breakdown_tool.py`**（用 urllib 调 Gemini Files API）。最强理由：一条命令出全部结果。不用：原笔记已因联网与依赖否决过把识别放进脚本；本机也没有 API key，可用的通道是已登录的 agy。
- **逐帧做文字识别代替字幕扫描**。最强理由：一步拿到时间和文字。不用：标准库下限内没有 OCR，引入依赖违背脚本约定；模型读裁图已足够准，脚本只需给出可靠的起止时间。

## Consequences

- **收益**：一集或连续多集能还原成可读、可接着改的套件项目，人物和道具跨集统一，接缝有据；字幕扫描把台词时间从约 ±0.5 秒收到约 0.1 秒；候选切点补上测量漏掉的镜内切；保真度有字错率、漏句、节奏、幻觉抽查四类可复算的数字；自有作品能直接拿还原项目做续作或重制。
- **代价**：放宽了一条 `structural_invariant`，新增一条 `structural_invariant` 和一条 `reviewed_invariant`，CHANGELOG 记为变更；对标目录只是约定，挡不住人手复制；原片上传到 Google 要创作者逐部同意；每集两次 Argon 调用，个人配额会用尽（实测报 429 后约 6 天才重置），长剧要分批；说话人和造型描述靠模型，名字在冷门作品上可能编造，要按证据规则剔除；`licensed` 靠创作者自述，套件核实不了。
- **嵌套项目**：还原项目在本项目目录树里，创作台会把它并列列出；`还原/` 初始化之前，在对标目录里运行的项目工具会找到外层的本项目。参考资料要求先初始化、标题不写对标剧名；在 `$short-drama` 里加防护是另一项改动。
- **已知问题**：台词里夹拉丁字母时，`plan` 要求同时声明字速和词速，否则报缺单位；这条规则与写作阶段的时长估算共用，暂不在本技能里单独改。
- **字幕区校准实测**：22 部横屏三维漫剧各一集里，默认区域有 1 部整集扫不到字幕，重框后恢复；合成的竖屏、黄字、半透明底框样本在框定区域、设定字色后每种 95 句命中 92–95 句。采样宽度由 480 改为 720、最低占比由 0.004 改为 0.002 后，单字台词不再漏。细描边字幕仍会把一句拆成几段，参考资料要求读裁图时合并。
- **未验证**：还原出的提示词在 H3 上生成后与原片的接近程度（原笔记已测出三维文生守不住画风，参考资料因此要求挂起始帧）；真实的竖屏、黄字、底框字幕（本次只有合成样本）。
