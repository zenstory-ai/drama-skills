# 静帧段

## 适用条件与来源

静帧段仅在以下三种创作者明确选择下使用（不得因生成失败或耗时擅自把视频镜替换为静帧）：

1. 《视觉设定.md》「制作形态」声明为静态漫剧（关键帧切换加配音）。
2. 创作者要求在生成视频前先剪一版动态分镜（animatic）。
3. 某镜视频不可用，经创作者单镜同意用关键帧顶替。

来源写法（`render` 等比铺满居中裁切；重心不在中间的图先在外部裁好，同一张图可跨多段复用）：

- `SHOT-...`（默认）：对应《分镜.md》单镜，继承场景 ID 并参与同场景自动接镜。
- `IMG-...`：对应《图片提示词.md》资产/道具板，不追场景、不参与自动接镜，也不计入分镜覆盖。

## 每一镜的下落

- 含 `SHOT-...` 静帧时，《分镜.md》每镜须进片或列入「未采用镜头」；含视频段时，《视频提示词.md》每条 `MOTION-...` 同样须有下落（纯 `IMG-...` 剪辑单不查分镜覆盖）。
- 视频与静帧混剪时，同一镜（由《视频提示词.md》的 `分镜` 行关联）只需交代一次：用静帧顶替视频时不必另列 `MOTION-...` 未采用；用视频时不必另列 `SHOT-...`；未采用写 `MOTION-...` 即覆盖对应 `SHOT-...`（若未采用只写 `SHOT-...`，对应 `MOTION-...` 仍须说明未用原因）。

## 运镜

- **方向与语义**：`推近`（聚焦关键信息或反应）、`拉远`（交代处境或收尾）、`左移`/`右移`/`上移`/`下移`（指取景框移动方向；画面先按同幅度放大，边缘不穿帮）、`固定`（阅读屏幕/字条或特写落定）。
- **幅度 vs 速度**：`推近 8%` 按百分比走完全程并在每段头尾缓入缓出；`推近 2.5%/秒` 按渲染时长匀速运动，仅在起步/停止处加 `0.5s` 缓冲，同场相邻两段同向且均写速度时跨切点不减速。
- **同场连续运镜（`craft_default`）**：同一场保持统一速度（如 `2–3%/秒`）；相邻两段不直接反向（需换向时中间隔一段 `固定`）；`固定` 只留给停顿反应或面板亮出拍。`check` 对同场相邻速度差 `≥ 30%` 或反向给出提醒，不阻断渲染。

## 环境声

在同一场首段写 `- 环境声：[<起>] <路径>（起点：<秒>；增益：<dB>）`，循环铺满整场且跨切点不断；换场时在下一场首段写负数 `起` 让新环境声提前几百毫秒叠入过桥；场内需骤然安静时写 `- 环境声：<秒> 无`。

## 配音

- **先测有声起止再排时长**：测量配音文件有声部分（峰值以下 `40 dB` 内），按「开口前留白 + 句长 + 句后反应」定本段 `时长`、配音起点与字幕。重出配音后须重排。需跳过片头静音用 `（起点：<秒>）`；需截掉句尾多余笑声或气口时改写为 `音效` 并用 `起-止` 截取。
- **跨切点交叠**：
  - **L-cut**：`配音` 与 `字幕` 均写在说话段，声音与字幕止点跨入下一段听者反应画面。
  - **J-cut**：`配音` 写在下一段且 `起` 为负数（最早至上一段开头）；`字幕` 写在上一段开口时刻。
- **全局不越界与不重叠**：`check` 核对整片内所有配音与字幕不越过片尾（配音容差 `0.05s`），且任意两句配音有声区间、任意两条字幕均不重叠。视频段用 `配音` 替换原台词时，须先在外部清除原视频中的人声。
